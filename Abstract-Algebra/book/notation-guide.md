# Notation Guide

*A comprehensive reference for the symbols, conventions, and notational choices used throughout this text. Mathematical notation is not universal — it varies by country, era, and subfield. This guide records the choices made here, with brief explanations of where they originate and why.*

---

## 1. Groups

### 1.1 Group Letters and Elements

| Symbol | Meaning |
|--------|---------|
| $G, H, K$ | Groups (generic) |
| $N$ | Normal subgroup (the choice of $N$ signals normality by convention) |
| $A, B$ | Abelian groups (additive notation common) |
| $e$ or $1$ | Identity element (multiplicative); $0$ in additive notation |
| $g, h, k, x, y$ | Generic elements of a group |
| $|G|$ | Order of $G$ (cardinality) |
| $\mathrm{ord}(g)$ or $|g|$ | Order of an element $g$ |

### 1.2 Subgroups and Cosets

| Symbol | Meaning |
|--------|---------|
| $H \leq G$ | $H$ is a subgroup of $G$ |
| $H < G$ | $H$ is a proper subgroup |
| $H \trianglelefteq G$ | $H$ is a normal subgroup of $G$ |
| $H \triangleleft G$ | $H$ is a proper normal subgroup |
| $gH$ | Left coset of $H$ in $G$ with representative $g$ |
| $Hg$ | Right coset |
| $[G : H]$ | Index of $H$ in $G$ (number of cosets) |
| $G/H$ | Quotient group (only defined when $H \trianglelefteq G$) |

**Convention.** We write cosets multiplicatively as $gH$ when working in a general (possibly non-abelian) group, and as $g + H$ when $G$ is abelian and written additively.

### 1.3 Homomorphisms and Isomorphisms

| Symbol | Meaning |
|--------|---------|
| $\phi: G \to H$ | A group homomorphism from $G$ to $H$ |
| $\ker \phi$ | Kernel: $\{g \in G : \phi(g) = e_H\}$ |
| $\mathrm{im}\, \phi$ | Image: $\{\phi(g) : g \in G\}$ |
| $G \cong H$ | $G$ is isomorphic to $H$ |
| $\mathrm{Aut}(G)$ | Automorphism group of $G$ |
| $\mathrm{Inn}(G)$ | Inner automorphism group (conjugation maps) |
| $\mathrm{Out}(G)$ | Outer automorphism group: $\mathrm{Aut}(G)/\mathrm{Inn}(G)$ |
| $G \times H$ | Direct product |
| $G \rtimes_\phi H$ | Semidirect product with action $\phi: H \to \mathrm{Aut}(G)$ |

### 1.4 Named Groups

| Symbol | Meaning |
|--------|---------|
| $\mathbb{Z}/n\mathbb{Z}$ or $C_n$ | Cyclic group of order $n$ |
| $S_n$ | Symmetric group on $n$ letters |
| $A_n$ | Alternating group (even permutations) |
| $D_n$ or $D_{2n}$ | Dihedral group of order $2n$ (*Note:* $D_n$ means order $2n$ in this text) |
| $Q_8$ | Quaternion group of order 8 |
| $GL_n(F)$ | General linear group: invertible $n \times n$ matrices over $F$ |
| $SL_n(F)$ | Special linear group: matrices of determinant $1$ |
| $PGL_n(F)$ | Projective general linear group |
| $O_n(\mathbb{R})$ | Orthogonal group |
| $SO_n(\mathbb{R})$ | Special orthogonal group |
| $U_n$ | Unitary group |
| $SU_n$ | Special unitary group |
| $\mathrm{Sp}_{2n}(F)$ | Symplectic group |

### 1.5 Group Actions

| Symbol | Meaning |
|--------|---------|
| $G \curvearrowright X$ | $G$ acts on set $X$ |
| $g \cdot x$ or $gx$ | Action of $g$ on $x$ |
| $G_x$ or $\mathrm{Stab}_G(x)$ | Stabilizer of $x$ |
| $\mathrm{Orb}_G(x)$ or $Gx$ | Orbit of $x$ |
| $X/G$ | Set of orbits |
| $X^G$ | Fixed-point set: $\{x \in X : gx = x\ \forall g\}$ |
| $n_p$ | Number of Sylow $p$-subgroups of $G$ |

## 2. Rings

### 2.1 Rings and Their Elements

| Symbol | Meaning |
|--------|---------|
| $R, S, T$ | Rings (generic) |
| $1_R$ or $1$ | Multiplicative identity (when it exists) |
| $0_R$ or $0$ | Additive identity |
| $R^\times$ | Group of units (invertible elements) of $R$ |
| $\mathrm{char}(R)$ | Characteristic of $R$ |
| $R[x]$ | Polynomial ring in one variable over $R$ |
| $R[x_1, \ldots, x_n]$ | Polynomial ring in $n$ variables |
| $R[[x]]$ | Formal power series ring |
| $R(x)$ | Field of fractions of $R[x]$ (when $R$ is a domain) |
| $\mathrm{Frac}(R)$ | Field of fractions of an integral domain $R$ |

### 2.2 Ideals

| Symbol | Meaning |
|--------|---------|
| $I \trianglelefteq R$ | $I$ is an ideal of $R$ (two-sided) |
| $(a)$ or $aR$ | Principal ideal generated by $a$ |
| $(a_1, \ldots, a_k)$ | Ideal generated by elements $a_1, \ldots, a_k$ |
| $I + J$ | Sum of ideals |
| $IJ$ | Product of ideals |
| $I \cap J$ | Intersection of ideals |
| $\sqrt{I}$ | Radical of $I$: $\{r \in R : r^n \in I\text{ for some }n \geq 1\}$ |
| $\mathrm{nil}(R)$ | Nilradical of $R$ (radical of the zero ideal) |
| $\mathrm{rad}(R)$ | Jacobson radical |
| $R/I$ | Quotient ring |

### 2.3 Domain Hierarchy

| Symbol | Meaning |
|--------|---------|
| $R$ an ID | $R$ is an integral domain (no zero divisors) |
| $R$ a UFD | Unique factorization domain |
| $R$ a PID | Principal ideal domain |
| $R$ a ED | Euclidean domain |
| $p \mid a$ | $p$ divides $a$ in $R$ |
| $\gcd(a,b)$ | Greatest common divisor (defined up to units in a UFD) |
| $\mathrm{lcm}(a,b)$ | Least common multiple |
| $\mathrm{ht}(\mathfrak{p})$ | Height of a prime ideal $\mathfrak{p}$ |
| $\dim R$ | Krull dimension of $R$ |

**Convention.** Lowercase fraktur letters $\mathfrak{a}, \mathfrak{b}, \mathfrak{p}, \mathfrak{q}, \mathfrak{m}$ are used for ideals in commutative algebra, especially in Noetherian ring theory. $\mathfrak{p}$ and $\mathfrak{q}$ specifically denote prime ideals; $\mathfrak{m}$ denotes a maximal ideal.

## 3. Modules

### 3.1 Modules and Module Maps

| Symbol | Meaning |
|--------|---------|
| $M, N, L$ | Modules (generic) |
| $_R M$ | Left $R$-module $M$ |
| $M_R$ | Right $R$-module $M$ |
| $_R M_S$ | $(R,S)$-bimodule |
| $\mathrm{Hom}_R(M, N)$ | Set of $R$-module homomorphisms $M \to N$ |
| $\mathrm{End}_R(M)$ | Ring of $R$-module endomorphisms of $M$ |
| $M \oplus N$ | Direct sum (external or internal) |
| $\bigoplus_{i \in I} M_i$ | Arbitrary direct sum (coproduct in $_R\mathrm{Mod}$) |
| $\prod_{i \in I} M_i$ | Direct product |
| $M \otimes_R N$ | Tensor product of $M$ and $N$ over $R$ |
| $M^n$ or $R^n$ | Free module of rank $n$ |
| $\mathrm{Ann}_R(m)$ | Annihilator of $m \in M$: $\{r \in R : rm = 0\}$ |
| $\mathrm{Ann}_R(M)$ | Annihilator of $M$: $\{r \in R : rM = 0\}$ |

### 3.2 Exact Sequences

An exact sequence is written:
$$0 \to L \xrightarrow{f} M \xrightarrow{g} N \to 0$$

This is a **short exact sequence (SES)**: $f$ is injective, $g$ is surjective, and $\mathrm{im}(f) = \ker(g)$.

A **long exact sequence** extends in both directions.

| Notation | Meaning |
|----------|---------|
| $0 \to M$ | $M$ injects into the next term |
| $M \to 0$ | Preceding map surjects onto $M$ |
| $\mathrm{Ext}^n_R(M, N)$ | $n$-th Ext group (derived $\mathrm{Hom}$) |
| $\mathrm{Tor}_n^R(M, N)$ | $n$-th Tor group (derived $\otimes$) |

### 3.3 Special Modules

| Symbol | Meaning |
|--------|---------|
| $M$ free | $M \cong \bigoplus_I R$ for some index set $I$ |
| $M$ projective | Direct summand of a free module |
| $M$ injective | Every diagram with $M$ at the bottom fills in |
| $M$ flat | $M \otimes_R -$ is exact |
| $\mathrm{pd}_R(M)$ | Projective dimension |
| $\mathrm{id}_R(M)$ | Injective dimension |
| $\mathrm{fd}_R(M)$ | Flat dimension |
| $\mathrm{gl.dim}(R)$ | Global dimension: $\sup_M \mathrm{pd}_R(M)$ |

## 8. Additive vs. Multiplicative Notation

A persistent source of confusion is whether to write group operations multiplicatively (as $ab$, with identity $e$ or $1$) or additively (as $a + b$, with identity $0$). The convention in this text is:

**Multiplicative notation** is used when:
- Working with a general group that may not be abelian
- Discussing symmetric groups, matrix groups, or Galois groups
- Emphasising the group as the main object of study

**Additive notation** is used when:
- Working with an abelian group (modules over $\mathbb{Z}$, for instance)
- Discussing the additive structure of a ring or module
- Following the convention in homological algebra, where the group operation in $\mathrm{Hom}(M, N)$ is addition

In module theory, the underlying additive group $M$ of a module is written additively, while the scalar multiplication by the ring $R$ uses juxtaposition: $r \cdot m$ or simply $rm$.

**Watch for:** The notation $R/I$ for a quotient ring mirrors $G/N$ for a quotient group, but the elements $r + I$ are written additively because the additive group of $R$ is abelian.
