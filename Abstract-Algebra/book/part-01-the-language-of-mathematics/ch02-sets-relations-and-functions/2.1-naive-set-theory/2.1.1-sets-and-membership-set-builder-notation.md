# 2.1.1 Sets and Membership; Set-Builder Notation

The most primitive notion in modern mathematics is that of a **set**: a collection of objects, called its **elements** or **members**. We write $x \in A$ to mean that$x$ is an element of$A$, and$x \notin A$ to mean that it is not. This is a primitive notion — we do not define "collection" in terms of something simpler. Informal descriptions like "a set is a bunch of things thought of together" capture the intuition but cannot serve as a mathematical definition, because they either use circular language or invoke physical intuitions that do not scale reliably to infinite collections and the abstract objects of algebra. For now, we work with the intuition and return to the formal foundations when we encounter their limits in Section 2.1.4.

Sets are determined entirely by their elements: two sets are equal if and only if they have exactly the same members. This is the **axiom of extensionality**:
$$A = B \iff (\forall x,\, x \in A \iff x \in B).$$
This has an important practical consequence: to prove that $A = B$, it is sufficient — and necessary — to show that every element of$A$ belongs to$B$ and every element of$B$ belongs to$A$. This **double-containment** strategy is the standard proof technique for set equality. Its structure is exactly two universal implications, and it is the proof pattern we use every time we want to identify two sets that are defined by different conditions.

A set may be specified by listing its elements: $\{1, 3, 5, 7\}$ is the set whose elements are exactly 1, 3, 5, and 7. For larger or infinite sets, we use **set-builder notation**:$\{x \in A \mid P(x)\}$ denotes the subset of$A$ consisting of all elements satisfying the predicate$P$. For instance,$\{n \in \mathbb{Z} \mid n \text{ is divisible by } 3\}$ is the set of integer multiples of 3. The notation$\{f(x) \mid x \in A\}$ describes the image of a function$f$ applied to elements of$A$. It is important to note that in careful set theory we always specify a domain$A$ from which elements are drawn — the notation$\{x \mid P(x)\}$ without a constraining set leads to Russell's paradox, as we will see in Section 2.1.4.

Two sets deserve special mention. The **empty set** $\emptyset = \{\}$ is the unique set with no elements; its existence is guaranteed by an axiom of ZFC. The empty set is a subset of every set:$\emptyset \subseteq A$ for any$A$, because the statement$\forall x,\, x \in \emptyset \Rightarrow x \in A$ is vacuously true (there are no elements of$\emptyset$ to witness a failure). Notice that$\emptyset$ and$\{\emptyset\}$ are not the same: the first has no elements, while the second has exactly one element, which happens to itself be the empty set.

The **standard number sets** $\mathbb{N}$,$\mathbb{Z}$,$\mathbb{Q}$,$\mathbb{R}$, and$\mathbb{C}$ are the raw material of algebra and analysis, and they should be understood as specific, concrete sets — not as informal notions. Each is a set equipped with additional structure (operations, an ordering), but at the set level they are simply collections of elements. Throughout this book, when we define new algebraic structures, we always specify first the underlying set (the "carrier") and then the operations and relations defined on it.

\begin{definition}
A set $A$ is a \textbf{subset} of a set$B$, written$A \subseteq B$, if every element of$A$ is an element of$B$:$\forall x,\, x \in A \Rightarrow x \in B$. We write$A \subsetneq B$ (proper subset) when$A \subseteq B$ and$A \neq B$. Set equality is then characterized by:$A = B$ if and only if$A \subseteq B$ and$B \subseteq A$.
\end{definition}

\begin{example}
Prove that $\{n \in \mathbb{Z} \mid 6 \mid n\} \subseteq \{n \in \mathbb{Z} \mid 2 \mid n\}$.
\par
Let $A = \{n \in \mathbb{Z} \mid 6 \mid n\}$ and$B = \{n \in \mathbb{Z} \mid 2 \mid n\}$. Let$x \in A$ be arbitrary. Then$6 \mid x$, so$x = 6k$ for some$k \in \mathbb{Z}$. Then$x = 2(3k)$, so$2 \mid x$, meaning$x \in B$. Since$x$ was arbitrary,$A \subseteq B$.$\square$
\par
Note the direction: divisibility by 6 implies divisibility by 2, but not vice versa — $2 \in B$ but$2 \notin A$.
\end{example}

\begin{example}
Show that $\{n \in \mathbb{Z} \mid n^2 < 10\} = \{-3, -2, -1, 0, 1, 2, 3\}$.
\par
Let $A = \{n \in \mathbb{Z} \mid n^2 < 10\}$ and$B = \{-3, -2, -1, 0, 1, 2, 3\}$.
\par
$A \subseteq B$: Let$n \in A$, so$n^2 < 10$. We have$4^2 = 16 \geq 10$ and$(-4)^2 = 16 \geq 10$, so$|n| < 4$, meaning$n \in \{-3,-2,-1,0,1,2,3\} = B$.
\par
$B \subseteq A$: For each$n \in B$, check$n^2$:$(-3)^2 = 9 < 10$,$(\pm 2)^2 = 4 < 10$,$(\pm 1)^2 = 1 < 10$,$0^2 = 0 < 10$. All elements of$B$ satisfy$n^2 < 10$, so$B \subseteq A$.
\par
By double containment, $A = B$.$\square$
\end{example}

\begin{example}
Distinguish between $\in$ (membership) and$\subseteq$ (containment), and show both relations can hold simultaneously.
\par
Let $A = \{1, 2, \{1,2\}\}$. Then:
- $1 \in A$ (1 is an element of$A$).
- $\{1,2\} \in A$ (the set$\{1,2\}$ is an element of$A$).
- $\{1,2\} \subseteq A$ (every element of$\{1,2\}$ — namely 1 and 2 — belongs to$A$).
- $\{1\} \subseteq A$ but$\{1\} \notin A$ (the set$\{1\}$ is not among the three listed elements of$A$).
\par
The set $\{1,2\}$ appears in both roles here: as a member (element) of$A$ and as a subset of$A$. This is possible because$A$ contains sets as elements.
\end{example}

\begin{example}
The set-builder notation $\{x \in A \mid P(x)\}$ always yields a subset of the given domain$A$. Use this to express several standard algebraic subsets.
\par
(a) The even integers: $\{n \in \mathbb{Z} \mid 2 \mid n\}$.
\par
(b) The positive rationals: $\{q \in \mathbb{Q} \mid q > 0\}$.
\par
(c) The kernel of a group homomorphism $f: G \to H$:$\ker(f) = \{g \in G \mid f(g) = e_H\}$.
\par
(d) The ideal generated by an element $a$ in a commutative ring$R$:$(a) = \{ra \mid r \in R\}$.
\par
In each case the domain is specified first, then the property. Without the domain, the expression $\{x \mid f(x) = e_H\}$ would range over all possible objects, leading to the paradox of Section 2.1.4.
\end{example}

\begin{remark}
The distinction between $\in$ and$\subseteq$ — membership and containment — is the first place students conflate two different relationships and produce errors. Membership is a relation between an element and a set; containment is a relation between two sets. These must be kept separate:$A \in B$ means$A$ is one of the listed (or defined) members of$B$;$A \subseteq B$ means every member of$A$ is also a member of$B$. In algebra, both relationships appear constantly: an element belongs to a group, a subgroup is contained in a group, a coset is an element of the quotient group, and a normal subgroup is contained in the group. Confusing the two leads immediately to errors in the manipulation of cosets, ideals, and submodules.
\end{remark}
