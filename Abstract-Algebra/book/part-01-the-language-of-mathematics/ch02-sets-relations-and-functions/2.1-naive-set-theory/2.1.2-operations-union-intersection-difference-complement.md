# 2.1.2 Operations: Union, Intersection, Difference, Complement

Given sets, we want to build new ones from old. The four basic operations correspond to the four connectives of propositional logic applied to the membership predicate, and this correspondence is not coincidental — it is the reason the algebraic laws of sets mirror the algebraic laws of logic so precisely. Making the correspondence explicit turns the set operations from things to memorize into things that are inevitable once the predicate-logic viewpoint is adopted.

The **union** $A \cup B = \{x \mid x \in A \lor x \in B\}$ collects everything in either set. The **intersection**$A \cap B = \{x \mid x \in A \land x \in B\}$ retains only what belongs to both. The **set difference**$A \setminus B = \{x \mid x \in A \land x \notin B\}$ removes from$A$ all elements it shares with$B$. When all sets under discussion are subsets of a fixed **universal set**$U$, the **complement**$A^c = U \setminus A = \{x \in U \mid x \notin A\}$ consists of all elements of$U$ not in$A$. Venn diagrams make these operations geometrically vivid, but algebraic proofs — using the **element-chasing technique**, which works directly with the membership predicate — are required for rigor.

These operations satisfy a rich collection of algebraic laws. Union and intersection are each **commutative** ($A \cup B = B \cup A$,$A \cap B = B \cap A$) and **associative** ($A \cup (B \cup C) = (A \cup B) \cup C$, and similarly for$\cap$). They distribute over each other:$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$ and$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$. The identity elements are$\emptyset$ for union ($A \cup \emptyset = A$) and$U$ for intersection ($A \cap U = A$). These laws make$(\mathcal{P}(U), \cup, \cap)$ into a **Boolean algebra** — the same algebraic structure that governs propositional logic.

**De Morgan's laws** for sets — $(A \cup B)^c = A^c \cap B^c$ and$(A \cap B)^c = A^c \cup B^c$ — are the exact analogues of the propositional De Morgan laws from Section 1.1.2. To see why, observe that$x \in (A \cup B)^c$ means$x \notin A \cup B$, which means$\neg(x \in A \lor x \in B)$, which by propositional De Morgan gives$x \notin A \land x \notin B$, i.e.,$x \in A^c \cap B^c$. Every step in this argument is a translation between set-membership language and predicate logic. De Morgan's laws do not need to be memorized separately from their propositional versions — they are the same laws.

For infinite families of sets, we extend these operations to **indexed unions** $\bigcup_{i \in I} A_i = \{x \mid \exists i \in I,\, x \in A_i\}$ and **indexed intersections**$\bigcap_{i \in I} A_i = \{x \mid \forall i \in I,\, x \in A_i\}$. The distributive and De Morgan laws generalize to this setting. These indexed operations appear throughout algebra — the intersection of all subgroups of$G$ containing a set$S$ is precisely the subgroup generated by$S$, and the union of a chain of subgroups is again a subgroup (this is the key verification in Zorn's Lemma applications).

\begin{example}
Prove the distributive law $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ by element-chasing.
\par
Let $x$ be arbitrary. We show$x \in A \cap (B \cup C) \iff x \in (A \cap B) \cup (A \cap C)$:
\begin{align*}
x \in A \cap (B \cup C) &\iff x \in A \land x \in (B \cup C) \\
&\iff x \in A \land (x \in B \lor x \in C) \\
&\iff (x \in A \land x \in B) \lor (x \in A \land x \in C) && \text{(propositional distributivity)} \\
&\iff x \in (A \cap B) \lor x \in (A \cap C) \\
&\iff x \in (A \cap B) \cup (A \cap C).
\end{align*}
Since the equivalence holds for all $x$, the sets are equal.$\square$
\par
The proof uses the propositional distributive law $P \land (Q \lor R) \equiv (P \land Q) \lor (P \land R)$ — the set-theoretic identity is a direct transcription.
\end{example}

\begin{example}
Prove one of De Morgan's laws for sets: $(A \cup B)^c = A^c \cap B^c$.
\par
Let $x \in U$ be arbitrary.
\begin{align*}
x \in (A \cup B)^c &\iff x \notin A \cup B \\
&\iff \neg(x \in A \lor x \in B) \\
&\iff x \notin A \land x \notin B && \text{(De Morgan, propositional)} \\
&\iff x \in A^c \land x \in B^c \\
&\iff x \in A^c \cap B^c.
\end{align*}
$\square$
\end{example}

\begin{example}
Show that $A \setminus B = A \cap B^c$, and use this to compute$(A \setminus B) \cup (B \setminus A)$ in terms of$\cup$,$\cap$,$\setminus$.
\par
First: $x \in A \setminus B \iff x \in A \land x \notin B \iff x \in A \land x \in B^c \iff x \in A \cap B^c$.
\par
$(A \setminus B) \cup (B \setminus A) = (A \cap B^c) \cup (B \cap A^c)$. This set is called the **symmetric difference**$A \triangle B$: the set of elements in one but not both of$A$ and$B$. It equals$(A \cup B) \setminus (A \cap B)$ — everything in the union except what is in the intersection. Verify this as an exercise using element-chasing.
\end{example}

\begin{example}
Compute: for $A = \{1, 2, 3, 4, 5\}$ and$B = \{3, 4, 5, 6, 7\}$:
\par
$A \cup B = \{1, 2, 3, 4, 5, 6, 7\}$,$A \cap B = \{3, 4, 5\}$,$A \setminus B = \{1, 2\}$,$B \setminus A = \{6, 7\}$,$A \triangle B = \{1, 2, 6, 7\}$.
\par
Now verify the inclusion-exclusion formula: $|A \cup B| = |A| + |B| - |A \cap B|$.
$$|A \cup B| = 7,\quad |A| + |B| - |A \cap B| = 5 + 5 - 3 = 7. \checkmark$$
The formula corrects for the double-counting of elements in $A \cap B$.
\end{example}

\begin{remark}
The element-chasing technique — reducing every set identity to a propositional equivalence and applying the laws of Section 1.1.2 — is both reliable and general. It extends without modification to indexed operations and arbitrary cardinalities, unlike Venn-diagram arguments, which are limited to finitely many sets and can miss degenerate cases. The parallel between the Boolean algebra of sets and the Boolean algebra of propositions is not merely an analogy; it is an instance of a categorical duality. For the algebra in this book, the operational consequence is simple: whenever you need to prove or use a set-theoretic identity, element-chase.
\end{remark}
