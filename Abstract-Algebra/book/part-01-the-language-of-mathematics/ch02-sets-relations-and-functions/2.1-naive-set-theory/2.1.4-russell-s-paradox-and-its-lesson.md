# 2.1.4 Russell's Paradox and Its Lesson

Naive set theory assumes that for any property $P$ we may form the set$\{x \mid P(x)\}$ of all objects satisfying$P$. This principle — the **unrestricted comprehension axiom** — seems entirely natural: sets are supposed to be collections of things satisfying properties, and restricting which properties are allowed looks like an unwarranted interference. Bertrand Russell showed in 1901 that this apparently innocuous principle is flatly inconsistent.

Consider the collection $R = \{x \mid x \notin x\}$: the "set" of all sets that do not contain themselves as members. Most familiar sets satisfy this condition. The set of all even integers does not contain itself — it contains integers, not sets — so it belongs to$R$. The set of all finite sets does not contain itself, so it belongs to$R$. Now ask the decisive question: does$R$ belong to$R$?

\begin{itemize}
\item If $R \in R$, then$R$ satisfies the defining property of$R$, which requires$R \notin R$. Contradiction.
\item If $R \notin R$, then$R$ fails to contain itself, so$R$ satisfies the defining property, giving$R \in R$. Contradiction.
\end{itemize}

In both cases we derive a contradiction. The "set" $R$ simply cannot exist within any consistent theory. This is **Russell's paradox**.

The paradox might seem like a curiosity or a trick, but its import is profound. It shows that unrestricted comprehension is not merely imprecise or in need of fine-tuning — it is logically contradictory. Any formal system that includes unrestricted comprehension as an axiom is **inconsistent**: every statement, including every false statement, becomes provable. The lesson is not that some properties are "bad" and should be avoided; the lesson is that the domain from which we collect must itself be a pre-existing, already-formed set.

\begin{definition}
In **Zermelo–Fraenkel set theory (ZF)**, the **Axiom of Separation** (restricted comprehension) replaces unrestricted comprehension: given a set $A$ that already exists and a property$P$, the collection
$$\{x \in A \mid P(x)\}$$
is a set. We may carve out subsets of existing sets, but we cannot form a collection from scratch by specifying only a property.
\end{definition}

With this restriction in place, Russell's argument no longer applies. To form $R$ we would need to write$R = \{x \in A \mid x \notin x\}$ for some pre-existing set$A$. One can show that no such$A$ can be a set in ZF, so the construction is blocked. The cost of this resolution is that certain intuitively natural collections — "the set of all sets," "the set of all groups," "the set of all vector spaces" — are too large to be sets in ZF. They are instead called **proper classes**, and one must be careful not to treat them as elements of larger collections.

\begin{remark}
Proper classes arise naturally in algebra. The collection of all groups is a proper class; the collection of all rings is a proper class. When we say "the category of groups," we are working with a proper class of objects and a proper class of morphisms. For the algebra in this book, however, all the objects we study will be honest sets, and we will flag the rare occasions where class-sized collections genuinely arise.
\end{remark}

Russell's paradox belongs to a family of self-referential paradoxes that were resolved by the set-theoretic foundation of mathematics in the early twentieth century. Related paradoxes include Burali-Forti's paradox (the collection of all ordinal numbers has no largest element, yet as a well-ordered class would itself be an ordinal) and Cantor's paradox (the power set of the universe of sets is larger than the universe, yet cannot be). All of them arise from the same source: unrestricted self-reference in collections.

**Example 1.** Show that the "set" $U = \{x \mid x = x\}$ — the supposed set of all sets — leads to a contradiction via Russell's paradox.

If $U$ were a set, then by restricted comprehension$R = \{x \in U \mid x \notin x\}$ would be a set. But this is exactly Russell's$R$. Asking whether$R \in R$ yields a contradiction as above. Hence$U$ is not a set; it is a proper class.

**Example 2.** Let $A = \{1, 2, 3\}$. Form$\{x \in A \mid x \notin x\}$ using restricted comprehension and explain why no paradox arises.

Each element of $A$ is a natural number, not a set, so the condition$x \notin x$ is trivially satisfied (numbers do not contain themselves as members in the standard formalization). The result is simply$\{1, 2, 3\} = A$ itself. No paradox arises because we are collecting from a specific, pre-existing finite set. The restriction to$A$ is what blocks the self-referential loop.

**Example 3.** The **Barber paradox** (due to Russell as a popular illustration): a barber shaves exactly those people in the village who do not shave themselves. Does the barber shave himself?

If the barber shaves himself, he is someone who shaves himself, so by the rule he does not shave himself — contradiction. If he does not shave himself, he is someone who does not shave himself, so by the rule he shaves himself — contradiction. The resolution is simply that no such barber can exist. The paradox is not a genuine logical problem; it is a proof that the description is contradictory. Russell's paradox has the same structure, but applied to set membership, which is why it threatens the foundations of mathematics rather than merely showing that a fanciful barber is impossible.

**Example 4.** Verify that in ZF, if $A$ is any set then$A \notin A$.

The axiom of regularity (foundation) in ZF asserts that every non-empty set $A$ contains an element$a \in A$ such that$a \cap A = \emptyset$. Taking$A = \{A\}$ as a hypothetical set containing only itself, regularity would require$A \in \{A\}$ with$A \cap \{A\} = \emptyset$, i.e.,$A \cap \{A\} = \emptyset$. But$A \in \{A\}$ and$A \in A$, giving$A \in A \cap \{A\}$, a contradiction. Thus$A \notin A$ for every set$A$ in ZF. This shows that Russell's "offending" sets — sets that do not contain themselves — are in fact all sets, and the collection of all sets remains a proper class.
