# 2.1 Naive Set Theory

A set is a collection of objects, considered as a single entity. This is not a definition in the formal sense — it is an intuition, and the history of mathematics shows that intuitions about sets can lead into contradiction if left unexamined. Cantor's original conception, sometimes called *naive set theory*, proceeds from the *comprehension principle*: for any property $\varphi(x)$ one can form the set $\{x : \varphi(x)\}$ of all objects satisfying $\varphi$. This principle is powerful and convenient, and most working mathematicians use it daily without incident. Russell's Paradox (1901) showed that it is nonetheless logically untenable: taking $\varphi(x)$ to be "$x \notin x$" produces a set $R = \{x : x \notin x\}$ that is a member of itself if and only if it is not, an outright contradiction. The resolution requires restricting comprehension, and the full axiomatic treatment is deferred to Chapter 3 and its discussion of Zermelo–Fraenkel set theory. For now, the section works within the comfortable middle ground: sets of concrete mathematical objects, where paradoxes do not arise in practice.

The basic language of sets is built from membership ($a \in A$), the empty set ($\emptyset$, containing no elements), subset inclusion ($A \subseteq B$, meaning every element of $A$ is also in $B$), and equality ($A = B$, meaning $A \subseteq B$ and $B \subseteq A$ — extensionality). From two sets $A$ and $B$, one constructs new sets by the standard operations: union $A \cup B = \{x : x \in A \text{ or } x \in B\}$, intersection $A \cap B = \{x : x \in A \text{ and } x \in B\}$, set difference $A \setminus B = \{x : x \in A \text{ and } x \notin B\}$, and complement $A^c = \{x : x \notin A\}$ (relative to some understood universal set). These operations satisfy a rich family of algebraic identities: commutativity and associativity of union and intersection, the distributive laws $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ and its dual, De Morgan's laws $\overline{A \cup B} = \overline{A} \cap \overline{B}$ and $\overline{A \cap B} = \overline{A} \cup \overline{B}$. Every identity in this list has a perfect dual obtained by swapping $\cup \leftrightarrow \cap$ and $\emptyset \leftrightarrow A$ — a symmetry that recurs in the lattice-theoretic perspective on Boolean algebras.

The *power set* $\mathcal{P}(A) = \{S : S \subseteq A\}$ collects all subsets of $A$ into a single set. If $|A| = n$, then $|\mathcal{P}(A)| = 2^n$, which already hints at the cardinal inequality $|A| < |\mathcal{P}(A)|$ that will be proved in full generality in Section 3.2. The *Cartesian product* $A \times B = \{(a,b) : a \in A,\, b \in B\}$ of ordered pairs is the arena in which both relations (Section 2.2) and functions (Section 2.4) live. Working with Cartesian products also requires a clear account of what an ordered pair *is* as a set — the Kuratowski definition $(a, b) = \{\{a\}, \{a, b\}\}$ encodes order into set membership — though in practice one always uses the intuitive notion and relies on the Kuratowski definition only to confirm that the set-theoretic foundation is solid.
