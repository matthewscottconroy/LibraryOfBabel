# 2.2.3 Equivalence Relations and the Partition Theorem

One of the most pervasive ideas in all of mathematics is the declaration that two objects are "the same for our current purposes." Two integers are "the same modulo 7" if they leave the same remainder upon division by 7. Two matrices are "the same" if one can be obtained from the other by a change of basis. Two elements of a group are "the same" if they lie in the same coset of a given subgroup. The abstract framework governing all of these examples is that of an **equivalence relation**, and its fundamental structural theorem — that equivalence classes form a partition — is one of the most widely applied results in mathematics.

\begin{definition}
A relation $\sim$ on a set$A$ is an **equivalence relation** if it is:
\begin{itemize}
\item **reflexive**: $a \sim a$ for all$a \in A$,
\item **symmetric**: $a \sim b$ implies$b \sim a$ for all$a, b \in A$,
\item **transitive**: $a \sim b$ and$b \sim c$ imply$a \sim c$ for all$a, b, c \in A$.
\end{itemize}
The **equivalence class** of an element $a$ under$\sim$ is$[a] = \{b \in A \mid a \sim b\}$.
\end{definition}

By reflexivity, $a \in [a]$, so every element belongs to at least one equivalence class. The question of whether two classes can overlap is resolved decisively by the following key lemma, whose proof encapsulates the entire geometry of the situation.

\begin{lemma}
Let $\sim$ be an equivalence relation on$A$. For any$a, b \in A$, either$[a] = [b]$ or$[a] \cap [b] = \emptyset$.
\end{lemma}

*Proof.* Suppose $[a] \cap [b] \neq \emptyset$, and let$c \in [a] \cap [b]$. Then$a \sim c$ and$b \sim c$. By symmetry,$c \sim b$, and by transitivity with$a \sim c$, we get$a \sim b$. Now take any$x \in [a]$, meaning$a \sim x$. Since$b \sim a$ (by symmetry from$a \sim b$) and$a \sim x$, transitivity gives$b \sim x$, so$x \in [b]$. This shows$[a] \subseteq [b]$. By symmetry of the argument,$[b] \subseteq [a]$, so$[a] = [b]$.$\square$

\begin{definition}
A **partition** of a set $A$ is a collection$\{A_{i}\}_{i \in I}$ of non-empty, pairwise disjoint subsets of$A$ whose union is all of$A$:$\bigcup_{i \in I} A_{i} = A$ and$A_{i} \cap A_{j} = \emptyset$ for$i \neq j$.
\end{definition}

\begin{theorem}[Partition Theorem / Fundamental Theorem of Equivalence Relations]
Let $\sim$ be an equivalence relation on$A$. The collection of all equivalence classes$\{[a] \mid a \in A\}$ forms a partition of$A$. Conversely, given any partition$\{A_{i}\}$ of$A$, the relation$a \sim b \iff a \text{ and } b \text{ lie in the same part}$ is an equivalence relation whose equivalence classes are precisely the parts$A_{i}$.
\end{theorem}

*Proof sketch.* For the forward direction, non-emptiness follows from reflexivity ($a \in [a]$), the union covers$A$ for the same reason, and pairwise disjointness is the lemma above. For the converse, reflexivity holds because every element lies in its own part; symmetry holds because "same part" is a symmetric condition; transitivity holds because if$a$ and$b$ lie in$A_{i}$ and$b$ and$c$ lie in$A_{j}$, then$b \in A_{i} \cap A_{j}$, and since parts are disjoint$A_{i} = A_{j}$, so$a$ and$c$ lie in the same part.$\square$

This bijection — equivalence relations on $A$ correspond exactly to partitions of$A$ — is used constantly throughout algebra. Congruence modulo$n$ partitions$\mathbb{Z}$ into$n$ residue classes$[0], [1], \ldots, [n-1]$. The coset relation of a subgroup$H \leq G$ (declaring$a \sim b$ when$a^{-1}b \in H$) partitions$G$ into left cosets of equal size, and counting them yields Lagrange's theorem. The orbit relation of a group acting on a set partitions the set into orbits. In each case, the partition theorem guarantees the pieces are well-behaved and non-overlapping.

\begin{remark}
The number of partitions of an $n$-element set is the$n$-th **Bell number**$B_{n}$. The values begin$B_{0} = 1$,$B_{1} = 1$,$B_{2} = 2$,$B_{3} = 5$,$B_{4} = 15$,$B_{5} = 52$. This counts both the partitions and, equivalently, the equivalence relations on that set. Bell numbers grow super-exponentially and have a rich combinatorial theory of their own.
\end{remark}

**Example 1.** Let $A = \mathbb{Z}$ and$a \sim b$ iff$5 \mid (a - b)$. Verify the three axioms and describe the partition.

Reflexivity: $a - a = 0 = 5 \cdot 0$, so$a \sim a$. Symmetry: if$5 \mid (a - b)$ then$a - b = 5k$, so$b - a = 5(-k)$ and$5 \mid (b - a)$. Transitivity: if$a - b = 5j$ and$b - c = 5k$ then$a - c = 5(j+k)$. The equivalence classes are the five residue classes$[0] = \{\ldots, -10, -5, 0, 5, 10, \ldots\}$,$[1], [2], [3], [4]$. These five classes partition$\mathbb{Z}$.

**Example 2.** On the set of all lines in $\mathbb{R}^{2}$, define$\ell \sim m$ if$\ell$ is parallel to$m$ (including$\ell = m$). Show this is an equivalence relation and describe the equivalence classes.

Reflexivity: every line is parallel to itself. Symmetry: if $\ell \| m$ then$m \| \ell$. Transitivity: if$\ell \| m$ and$m \| n$ then$\ell$ and$n$ have the same slope (or both are vertical), so$\ell \| n$. The equivalence classes are the families of lines with the same slope together with the family of all vertical lines. Each class is parametrized by a direction in the projective line$\mathbb{P}^{1}(\mathbb{R})$.

**Example 3.** Let $A = \{1,2,3,4,5,6\}$ and define the partition$\{\{1,2\},\{3,4\},\{5,6\}\}$. Write down the equivalence relation as a set of ordered pairs.

The relation consists of all pairs $(a,b)$ where$a$ and$b$ lie in the same block:$R = \{(1,1),(1,2),(2,1),(2,2),(3,3),(3,4),(4,3),(4,4),(5,5),(5,6),(6,5),(6,6)\}$. There are$3 \times 4 = 12$ pairs (three blocks of size 2, each contributing$4 = 2^{2}$ pairs).

**Example 4.** On $\mathbb{R}^{2} \setminus \{(0,0)\}$, define$(x_{1},y_{1}) \sim (x_{2},y_{2})$ if there exists$\lambda \in \mathbb{R}^{\times}$ with$(x_{1},y_{1}) = \lambda(x_{2},y_{2})$. Verify the axioms and identify the quotient set.

Reflexivity: $(x,y) = 1 \cdot (x,y)$. Symmetry: if$(x_{1},y_{1}) = \lambda(x_{2},y_{2})$ then$(x_{2},y_{2}) = \lambda^{-1}(x_{1},y_{1})$. Transitivity: if$(x_{1},y_{1}) = \lambda(x_{2},y_{2})$ and$(x_{2},y_{2}) = \mu(x_{3},y_{3})$ then$(x_{1},y_{1}) = (\lambda\mu)(x_{3},y_{3})$. The equivalence class of$(x,y)$ is the line through the origin and$(x,y)$ (with the origin removed). The quotient set is the real projective line$\mathbb{RP}^{1}$, which is in bijection with the unit circle modulo antipodal identification. This construction is the starting point of projective geometry.
