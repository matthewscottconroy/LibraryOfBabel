# 2.3.1 Equivalence Classes and the Canonical Projection

When we have an equivalence relation $\sim$ on a set$A$, each element$a \in A$ determines a natural grouping: the set of all elements equivalent to$a$. This grouping is the central object of the quotient construction, and giving it a precise name and understanding its properties is the first step toward building the quotient set and, ultimately, quotient groups, rings, and modules.

\begin{definition}
Let $\sim$ be an equivalence relation on a set$A$. The **equivalence class** of$a \in A$ is the set
$$[a] = \{b \in A \mid a \sim b\}.$$
Any element $b \in [a]$ is called a **representative** of the class$[a]$.
\end{definition}

By reflexivity, $a \in [a]$, so every element belongs to at least one equivalence class. The fundamental structural fact is that two equivalence classes are either identical or completely disjoint, never partially overlapping.

\begin{proposition}
For any $a, b \in A$:$[a] = [b]$ if and only if$a \sim b$. Moreover,$[a] = [b]$ or$[a] \cap [b] = \emptyset$.
\end{proposition}

*Proof.* If $a \sim b$ and$x \in [a]$, then$a \sim x$, so$b \sim a \sim x$ by symmetry and transitivity, giving$x \in [b]$. Thus$[a] \subseteq [b]$, and by symmetry$[b] \subseteq [a]$, so$[a] = [b]$. Conversely, if$[a] = [b]$ then since$a \in [a] = [b]$, we have$a \in [b]$, i.e.,$b \sim a$, i.e.,$a \sim b$. The disjointness statement follows: if$[a] \cap [b] \neq \emptyset$, take$c \in [a] \cap [b]$; then$a \sim c$ and$b \sim c$, giving$a \sim b$ by symmetry and transitivity, so$[a] = [b]$.$\square$

This proposition has two important corollaries. First, any representative of an equivalence class can equally well serve as its "name": if $b \in [a]$ then$[b] = [a]$, so there is nothing special about the original representative$a$. Second, the equivalence classes partition$A$, as the partition theorem (Section 2.2.3) asserts.

\begin{definition}
The **canonical projection** (or **quotient map**) associated to $\sim$ is the function
$$\pi \colon A \to A/{\sim}, \quad \pi(a) = [a].$$
\end{definition}

The canonical projection is always **surjective**: every equivalence class $[a]$ is the image of the element$a$, so nothing in the codomain$A/{\sim}$ is missed. It is generally far from injective: distinct elements$a, a'$ with$a \sim a'$ satisfy$\pi(a) = [a] = [a'] = \pi(a')$.

The canonical projection is not merely a bookkeeping device; it satisfies a universal property that characterises it among all functions out of $A$. Informally,$\pi$ is the "most general" map that collapses$\sim$-related elements to a single point.

\begin{theorem}[Universal Property of the Canonical Projection]
Let $\sim$ be an equivalence relation on$A$ and let$f \colon A \to B$ be any function satisfying$f(a) = f(a')$ whenever$a \sim a'$. Then there is a unique function$\bar{f} \colon A/{\sim} \to B$ such that$f = \bar{f} \circ \pi$.
\end{theorem}

*Proof.* Define $\bar{f}([a]) = f(a)$. This is well-defined: if$[a] = [a']$ then$a \sim a'$, so$f(a) = f(a')$ by hypothesis. Uniqueness follows because$\pi$ is surjective: any function$g \colon A/{\sim} \to B$ with$f = g \circ \pi$ must satisfy$g([a]) = g(\pi(a)) = f(a) = \bar{f}([a])$ for every$[a]$.$\square$

This universal property is the precise formulation of the statement that $\pi$ "identifies exactly those elements that$\sim$ declares equal, and nothing more." We will see it reappear as the universal property of quotient groups (when$\sim$ is the coset relation of a normal subgroup), quotient rings, and quotient modules.

**Example 1.** Let $A = \mathbb{Z}$ with$a \sim b$ iff$4 \mid (a - b)$. Find$[0]$,$[1]$,$[7]$, and$[-3]$, and determine which pairs of these classes are equal.

$[0] = \{\ldots, -8, -4, 0, 4, 8, \ldots\}$, the set of multiples of 4.$[1] = \{\ldots, -7, -3, 1, 5, 9, \ldots\}$.$[7]$: since$7 - 3 = 4$, we have$7 \sim 3$, and since$3 - (-1) = 4$, we have$[7] = [3] = [-1] = \{\ldots, -5, -1, 3, 7, 11, \ldots\}$.$[-3]$:$-3 \equiv 1 \pmod 4$, so$[-3] = [1]$. Summary:$[7] = [3]$ and$[-3] = [1]$; the two classes are distinct.

**Example 2.** On $A = \{1,2,3,4,5,6\}$, let$\sim$ be defined by the partition$\{\{1,4\},\{2,5\},\{3,6\}\}$. Write down the canonical projection$\pi$ explicitly.

$\pi(1) = \{1,4\}$,$\pi(2) = \{2,5\}$,$\pi(3) = \{3,6\}$,$\pi(4) = \{1,4\}$,$\pi(5) = \{2,5\}$,$\pi(6) = \{3,6\}$. The codomain$A/{\sim}$ has three elements:$\{1,4\}$,$\{2,5\}$,$\{3,6\}$.

**Example 3.** Let $f \colon \mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$ be defined by$f(n) = [n \bmod 4]$. Verify that$f$ factors through the canonical projection$\pi \colon \mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$ in a trivial way, and use the universal property to confirm$\bar{f}$ is the identity.

Here $\sim$ is congruence mod 4, and the quotient map$\pi$ already sends$n \mapsto [n]$. The function$f = \pi$ itself. The induced map$\bar{f} \colon \mathbb{Z}/4\mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$ satisfies$\bar{f}([n]) = f(n) = [n]$, so$\bar{f} = \mathrm{id}$.

**Example 4.** On $\mathbb{R}^{2}$, define$(x_{1}, y_{1}) \sim (x_{2}, y_{2})$ iff$x_{1}^{2} + y_{1}^{2} = x_{2}^{2} + y_{2}^{2}$. Describe the equivalence classes and the quotient set$\mathbb{R}^{2}/{\sim}$.

Two points are equivalent iff they lie on the same circle centered at the origin (including the origin itself as the degenerate circle of radius 0). The equivalence class of $(x,y)$ is the circle of radius$r = \sqrt{x^{2} + y^{2}}$. The quotient set$\mathbb{R}^{2}/{\sim}$ is in bijection with$[0,\infty)$ via$[(x,y)] \mapsto \sqrt{x^{2} + y^{2}}$. The canonical projection$\pi \colon \mathbb{R}^{2} \to [0,\infty)$ is the norm function$(x,y) \mapsto \|(x,y)\|$.
