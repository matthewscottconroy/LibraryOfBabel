# 2.3.2 The Quotient Set $A/{\sim}$

The equivalence classes of $\sim$ partition$A$, and this partition is itself a set. The act of collecting all the classes together — treating each class as a single indivisible object — is the construction of the **quotient set**. This construction is the set-theoretic prototype of one of the most powerful tools in all of algebra: the passage to a quotient object that forgets distinctions the original relation declares irrelevant.

\begin{definition}
Let $\sim$ be an equivalence relation on a set$A$. The **quotient set** of$A$ by$\sim$ is
$$A/{\sim} \;=\; \{[a] \mid a \in A\},$$
the set whose elements are the equivalence classes of $\sim$. The elements of$A/{\sim}$ are the equivalence classes themselves, viewed as atomic objects.
\end{definition}

The quotient set $A/{\sim}$ is generally smaller than$A$: where$A$ had many individual elements,$A/{\sim}$ has one element for each cluster of mutually equivalent elements. Two elements$a, a'$ of$A$ — which were distinct as elements of$A$ — become the same element of$A/{\sim}$ when$a \sim a'$, because then$[a] = [a']$. The quotient "collapses" equivalent elements to a single point.

The precise relationship in size is: if $\sim$ has$k$ equivalence classes, then$|A/{\sim}| = k$, regardless of how many elements each class contains. In particular, the quotient of a finite set$A$ by an equivalence relation has at most$|A|$ elements, with equality precisely when$\sim$ is the identity relation (every element is in its own class).

\begin{example}
The integers modulo $n$. Define$a \sim b$ on$\mathbb{Z}$ when$n \mid (a - b)$ (congruence modulo$n$). The equivalence class of$a$ is$[a] = \{a + kn \mid k \in \mathbb{Z}\}$, the coset of$a$ modulo$n$. By the division algorithm, every integer$a$ satisfies$a = qn + r$ for a unique$r \in \{0, 1, \ldots, n-1\}$, so$a \sim r$ and every class has a unique representative in$\{0, 1, \ldots, n-1\}$. The quotient set has exactly$n$ elements:$A/{\sim} = \{[0], [1], \ldots, [n-1]\}$. This set, usually written$\mathbb{Z}/n\mathbb{Z}$ or$\mathbb{Z}_{n}$, will later be equipped with addition and multiplication to form a ring.
\end{example}

The quotient construction is the prototype of a broader pattern in mathematics: given a structured set and a "congruence" on it (an equivalence relation compatible with the structure), form the quotient and inherit the structure. Quotient groups, quotient rings, and quotient modules all follow this pattern. Whenever a homomorphism $\phi \colon G \to H$ is given, its kernel defines a congruence on$G$, and the quotient$G/\ker\phi$ is naturally isomorphic to the image$\phi(G)$ — this is the First Isomorphism Theorem, and the machinery is exactly what we are developing now.

\begin{remark}
The quotient construction is not limited to number-theoretic examples. The quotient of the set of paths in a topological space, where two paths are equivalent if one can be continuously deformed into the other (with fixed endpoints), gives the fundamental group — a central object in topology. The quotient of a vector space $V$ by a subspace$W$ gives a new vector space$V/W$ whose elements are cosets$v + W$. In each case, the set-level quotient is the same construction enriched with additional structure.
\end{remark}

A key point about quotient sets is their relationship to functions. The canonical projection $\pi \colon A \to A/{\sim}$ is the quintessential surjective function. Conversely, any surjective function$f \colon A \twoheadrightarrow B$ induces an equivalence relation on$A$ (by$a \sim_{f} a'$ iff$f(a) = f(a')$), and the quotient$A/{\sim_{f}}$ is in bijection with$B$ via$[a] \mapsto f(a)$. This gives the **canonical factorisation** of any function: every function$f \colon A \to B$ factors as a surjection$A \twoheadrightarrow f(A)$ followed by an injection$f(A) \hookrightarrow B$, and the surjection is the canonical projection$\pi \colon A \to A/{\sim_{f}}$ composed with the bijection$A/{\sim_{f}} \xrightarrow{\sim} f(A)$.

**Example 1.** Describe $\mathbb{Z}/6\mathbb{Z}$ explicitly by listing its elements and identifying the representative of$[14]$.

The elements are $[0],[1],[2],[3],[4],[5]$. Since$14 = 2 \cdot 6 + 2$, we have$14 \equiv 2 \pmod 6$, so$[14] = [2]$.

**Example 2.** Let $A = \{a,b,c,d,e\}$ and$\sim$ be defined by the partition$\{\{a,b,c\},\{d,e\}\}$. Describe$A/{\sim}$ and compute$|A/{\sim}|$.

$A/{\sim} = \{\{a,b,c\}, \{d,e\}\}$, which has two elements. The quotient "contracts" the five-element set to a two-element set. Note$|A/{\sim}| = 2$, which equals the number of parts of the partition.

**Example 3.** On $\mathbb{R}$, define$x \sim y$ iff$x - y \in \mathbb{Q}$. Describe the equivalence classes and the quotient set$\mathbb{R}/{\sim}$.

The class of $x$ is$[x] = x + \mathbb{Q} = \{x + q \mid q \in \mathbb{Q}\}$, a translate of$\mathbb{Q}$ by$x$. Two reals are equivalent iff their difference is rational; in other words, they have the same fractional part modulo$\mathbb{Q}$. The quotient$\mathbb{R}/{\sim}$ is the set of cosets of$\mathbb{Q}$ in$(\mathbb{R}, +)$. The cardinality of$\mathbb{R}/{\sim}$ is uncountable (it is, in fact,$|\mathbb{R}|$), and a system of representatives — one element chosen from each class — is called a **Vitali set**. The existence of a Vitali set requires the Axiom of Choice and provides the standard example of a non-measurable subset of$\mathbb{R}$.

**Example 4.** Let $f \colon \{1,2,3,4,5\} \to \{x,y,z\}$ be defined by$f(1) = x$,$f(2) = x$,$f(3) = y$,$f(4) = z$,$f(5) = z$. Write down the induced equivalence relation$\sim_{f}$ and the induced bijection$\overline{f}$.

The equivalence classes are the fibers of $f$:$f^{-1}(x) = \{1,2\}$,$f^{-1}(y) = \{3\}$,$f^{-1}(z) = \{4,5\}$. So$\sim_{f}$ has three classes:$[\{1,2\}], [\{3\}], [\{4,5\}]$. The induced map is$\overline{f} \colon \{[1,2],[3],[4,5]\} \to \{x,y,z\}$, sending$[\{1,2\}] \mapsto x$,$[\{3\}] \mapsto y$,$[\{4,5\}] \mapsto z$. This is a bijection, confirming the general factorisation theorem.
