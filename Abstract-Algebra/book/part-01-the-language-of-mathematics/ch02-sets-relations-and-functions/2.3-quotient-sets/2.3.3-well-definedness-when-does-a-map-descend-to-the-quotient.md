# 2.3.3 Well-Definedness: When Does a Map Descend to the Quotient?

Forming a quotient set raises an immediate question: if we want to define a function on $A/{\sim}$, we typically describe it by a formula involving representatives of equivalence classes. But each class has many representatives, and we must verify that the formula gives the same output regardless of which representative is chosen. This is the problem of **well-definedness**, and checking it is a non-negotiable step in every quotient construction. Skipping this check is the single most common source of errors in beginning algebra.

\begin{definition}
A function $f \colon A \to B$ **descends to the quotient** (or **is compatible with$\sim$**) if it is constant on equivalence classes: whenever$a \sim a'$ in$A$, we have$f(a) = f(a')$ in$B$. When this holds, the **induced map**$\bar{f} \colon A/{\sim} \to B$ is defined by$\bar{f}([a]) = f(a)$.
\end{definition}

The induced map $\bar{f}$ is well-defined precisely because$f$ is constant on classes: if$[a] = [a']$ then$a \sim a'$, so$f(a) = f(a')$, and thus$\bar{f}([a]) = f(a) = f(a') = \bar{f}([a'])$. The condition$a \sim a' \Rightarrow f(a) = f(a')$ is what we must verify before writing down$\bar{f}$; without it, the "function"$\bar{f}([a]) = f(a)$ is not a function at all, since the same class$[a] = [a']$ would be sent to two different values.

The standard proof format for well-definedness is: "Suppose $[a] = [a']$. Then$a \sim a'$. We must show$f(a) = f(a')$." The work goes into the last sentence; the rest is template.

\begin{example}
Define $f \colon \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ by$f(k) = [k \bmod n]$. The induced map from$\mathbb{Z}/m\mathbb{Z}$ to$\mathbb{Z}/n\mathbb{Z}$ (for$n \mid m$) is the "reduction" map sending$[k]_{m} \mapsto [k]_{n}$. Well-definedness: if$[a]_{m} = [a']_{m}$ then$m \mid (a - a')$; since$n \mid m$ we have$n \mid (a - a')$, so$[a]_{n} = [a']_{n}$. The check goes through.
\end{example}

To understand when the check fails, consider the function $g \colon \mathbb{Z} \to \mathbb{Z}$ defined by$g(n) = n/2$ and the quotient$\mathbb{Z}/4\mathbb{Z}$. We attempt to define$\bar{g} \colon \mathbb{Z}/4\mathbb{Z} \to \mathbb{Z}$ by$\bar{g}([n]) = n/2$. Take$[0] = [4]$: we need$\bar{g}([0]) = \bar{g}([4])$, but$g(0) = 0$ and$g(4) = 2$. The proposed map assigns two different values to the same class, so it is not well-defined. The formula$n/2$ does not respect the equivalence relation mod 4.

\begin{theorem}[Factorisation Theorem]
Let $\sim$ be an equivalence relation on$A$ and$f \colon A \to B$ any function. Then$f$ factors through the canonical projection$\pi \colon A \to A/{\sim}$ — i.e., there exists$\bar{f} \colon A/{\sim} \to B$ with$f = \bar{f} \circ \pi$ — if and only if$f$ is constant on equivalence classes. When such$\bar{f}$ exists it is unique, and:
\begin{itemize}
\item $\bar{f}$ is injective iff$f(a) = f(a')$ implies$a \sim a'$ (i.e.,$\sim$ is the kernel relation of$f$).
\item $\bar{f}$ is surjective iff$f$ is surjective.
\end{itemize}
\end{theorem}

The reason well-definedness deserves so much attention in algebra is that quotient constructions are ubiquitous: quotient groups, quotient rings, quotient modules, tensor products, localizations. In each case, the algebraic operations on the quotient are defined by formulas involving representatives, and the well-definedness check — verifying that the relevant equivalences are respected — is the heart of the construction.

For a concrete algebraic instance: in the quotient group $G/N$ (where$N$ is a normal subgroup), the product of cosets is defined by$[a][b] = [ab]$, i.e.,$(aN)(bN) = (ab)N$. The well-definedness check requires showing: if$aN = a'N$ and$bN = b'N$ (i.e.,$a' = an_{1}$ and$b' = bn_{2}$ for$n_{1}, n_{2} \in N$), then$a'b'N = abN$. Computing:$a'b' = an_{1}bn_{2} = ab(b^{-1}n_{1}b)n_{2}$. Since$N$ is normal,$b^{-1}n_{1}b \in N$, so$a'b' \in abN$ and$[a'b'] = [ab]$. The normality of$N$ is precisely what makes the coset multiplication well-defined.

**Example 1.** Determine whether $f(n) = n^{2}$ descends to a map$\mathbb{Z}/3\mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$.

We need: if $a \equiv b \pmod 3$ then$a^{2} \equiv b^{2} \pmod 3$. Write$b = a + 3k$. Then$b^{2} = a^{2} + 6ak + 9k^{2} = a^{2} + 3(2ak + 3k^{2})$, so$3 \mid (b^{2} - a^{2})$. Yes,$f$ descends. The induced map$\bar{f} \colon \mathbb{Z}/3\mathbb{Z} \to \mathbb{Z}/3\mathbb{Z}$ sends$[0] \mapsto [0]$,$[1] \mapsto [1]$,$[2] \mapsto [4] = [1]$.

**Example 2.** Determine whether $g(n) = 2^{n}$ descends to a map$\mathbb{Z}/4\mathbb{Z} \to \mathbb{Z}/4\mathbb{Z}$.

We need: $4 \mid (a - b) \Rightarrow 4 \mid (2^{a} - 2^{b})$. Take$a = 0$ and$b = 4$:$4 \mid (0 - 4)$. Check:$2^{0} = 1$ and$2^{4} = 16 \equiv 0 \pmod 4$. Since$1 \not\equiv 0 \pmod 4$, the map does not descend.

**Example 3.** On $\mathbb{Z}$, let$a \sim b$ iff$a \equiv b \pmod 6$. Show that the map$f(n) = n \bmod 2$ (i.e.,$f(n) = [n]_{2} \in \mathbb{Z}/2\mathbb{Z}$) descends to the quotient, and describe the induced map.

If $a \equiv b \pmod 6$ then$6 \mid (a - b)$, so$2 \mid (a - b)$, giving$a \equiv b \pmod 2$. Hence$f(a) = f(b)$ and$f$ descends. The induced map$\bar{f} \colon \mathbb{Z}/6\mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ sends$[0] \mapsto [0]$,$[1] \mapsto [1]$,$[2] \mapsto [0]$,$[3] \mapsto [1]$,$[4] \mapsto [0]$,$[5] \mapsto [1]$. It is surjective but not injective.

**Example 4.** Let $V = \mathbb{R}^{3}$ and$W = \{(x,y,z) \mid z = 0\} \cong \mathbb{R}^{2}$. Define$v \sim v'$ iff$v - v' \in W$. Show that$f(x,y,z) = z$ descends to the quotient$V/W$.

If $(x_{1},y_{1},z_{1}) \sim (x_{2},y_{2},z_{2})$ then$(x_{1}-x_{2},\, y_{1}-y_{2},\, z_{1}-z_{2}) \in W$, so$z_{1} - z_{2} = 0$, i.e.,$z_{1} = z_{2}$. Hence$f(v) = f(v')$ whenever$v \sim v'$, and$f$ descends. The induced map$\bar{f} \colon V/W \to \mathbb{R}$ sends the coset$[(x,y,z)]$ to$z$. This is a bijection (with inverse$z \mapsto [(0,0,z)]$), so$V/W \cong \mathbb{R}$ as a set, and in fact as a vector space.
