# 2.3 Quotient Sets

The most pervasive construction in abstract algebra is the *quotient*: given an algebraic object and a suitable notion of "sameness," one builds a new object by collapsing everything that counts as the same into a single entity. Quotient groups, quotient rings, and quotient modules are all instances of this one move. The set-theoretic foundation of all these constructions is the quotient set, and understanding it cleanly here will pay dividends throughout the rest of the book.

Given a set $A$ and an equivalence relation $\sim$ on $A$, the *quotient set* $A/{\sim}$ is the set of all equivalence classes: $A/{\sim} = \{[a] : a \in A\}$. The element $[a] = \{b \in A : b \sim a\}$ is a subset of $A$ viewed as a single element of the quotient. The *quotient map* $\pi: A \to A/{\sim}$ defined by $\pi(a) = [a]$ is automatically surjective — every equivalence class is non-empty, so it is the image of any of its members. The fundamental property of quotient sets is the *universal property*: if $f: A \to B$ is any function that is constant on equivalence classes (meaning $a \sim a'$ implies $f(a) = f(a')$), then there is a unique function $\bar{f}: A/{\sim} \to B$ satisfying $f = \bar{f} \circ \pi$. In other words, any function on $A$ that "respects" $\sim$ descends to a well-defined function on the quotient. This is not merely a technical convenience; it is the precise sense in which the quotient set is the "correct" codomain for $f$ when $f$ cannot distinguish between equivalent elements.

The integers modulo $n$ — the set $\mathbb{Z}/n\mathbb{Z} = \{[0], [1], \ldots, [n-1]\}$ — are the canonical example. The equivalence relation is congruence: $a \sim b$ iff $n \mid (a - b)$. The quotient map $\pi: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ sends each integer to its residue class. What makes $\mathbb{Z}/n\mathbb{Z}$ more than just a set is that the operations of addition and multiplication on $\mathbb{Z}$ are constant on equivalence classes: $[a] + [b] = [a+b]$ and $[a] \cdot [b] = [a \cdot b]$ are well-defined, regardless of which representatives $a$ and $b$ we choose. This well-definedness — the check that the result does not depend on the choice of representative — is a computation that must always be performed when one defines an operation on a quotient, and it is a skill the reader should practice explicitly. The notion of a *well-defined* map on a quotient recurs at the heart of every homomorphism theorem, quotient group, and tensor product construction throughout algebra.
