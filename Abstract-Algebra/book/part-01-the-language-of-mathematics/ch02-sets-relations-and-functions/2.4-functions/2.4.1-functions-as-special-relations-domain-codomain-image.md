# 2.4.1 Functions as Special Relations; Domain, Codomain, Image

Functions are the morphisms of set theory — the structure-preserving maps between sets — and they occupy an even more central role in algebra, where every homomorphism, isomorphism, and projection is a function equipped with extra properties. Getting the formal definition right, with careful attention to the distinct roles of domain, codomain, and image, is essential before any of those concepts can be made precise.

\begin{definition}
A **function** (or **map**) $f \colon A \to B$ is a relation$f \subseteq A \times B$ satisfying:
\begin{itemize}
\item (**Totality**) For every $a \in A$ there exists at least one$b \in B$ with$(a, b) \in f$.
\item (**Single-valuedness**) For every $a \in A$ there exists at most one$b \in B$ with$(a, b) \in f$.
\end{itemize}
The unique $b$ with$(a, b) \in f$ is called the **value** of$f$ at$a$, written$f(a)$. The set$A$ is the **domain** of$f$; the set$B$ is the **codomain** of$f$.
\end{definition}

Totality says $f$ is defined everywhere on$A$; single-valuedness says it is unambiguous. Together they express that every input has exactly one output. Both conditions are necessary: a relation that is total but not single-valued is a multi-valued map, not a function; a relation that is single-valued but not total is a partial function.

\begin{definition}
The **image** (or **range**) of $f$ is
$$\mathrm{im}(f) = f(A) = \{f(a) \mid a \in A\} \subseteq B.$$
More generally, for any subset $S \subseteq A$, the **direct image** of$S$ under$f$ is$f(S) = \{f(s) \mid s \in S\}$.
\end{definition}

The distinction between codomain and image is critical and easily confused. The function $f \colon \mathbb{R} \to \mathbb{R}$ defined by$f(x) = x^{2}$ has codomain$\mathbb{R}$ but image$[0, \infty)$ — not every real number is a perfect square. The function$g \colon \mathbb{R} \to [0,\infty)$ defined by the same formula has image equal to its codomain;$g$ is surjective while$f$ is not. These are different functions, even though the "formula" is identical, because the codomains differ. Two functions$f \colon A \to B$ and$g \colon A \to B$ are equal if and only if$f(a) = g(a)$ for every$a \in A$; the domain and codomain must also coincide, since they are part of the data of a function.

This definition places functions on a firm set-theoretic footing: a function is a specific set (a subset of $A \times B$), not a vague notion of a "rule" or "process." This matters when we want to compare two functions for equality, form the set$B^{A}$ of all functions from$A$ to$B$, or treat a function as an element of some larger structure.

\begin{remark}
The notation $B^{A}$ for the set of all functions from$A$ to$B$ is motivated by the cardinality formula$|B^{A}| = |B|^{|A|}$ for finite sets. When$B = \{0,1\}$ and$A$ is finite, the set$\{0,1\}^{A}$ of all indicator functions on$A$ bijects with$\mathcal{P}(A)$, recovering the formula$|\mathcal{P}(A)| = 2^{|A|}$. This notation extends to infinite sets in a meaningful way in the theory of cardinal arithmetic.
\end{remark}

In algebra we routinely work with sets whose elements are themselves functions. The symmetric group $S_{n}$ is the set of all bijections from$\{1, \ldots, n\}$ to itself. The set of all group homomorphisms from$G$ to$H$ is denoted$\mathrm{Hom}(G, H)$. The set of all linear maps from a vector space$V$ to$W$ is denoted$\mathrm{Hom}_{k}(V, W)$ or$\mathcal{L}(V, W)$. In each case, the elements of the set are functions, and the set-theoretic foundation makes this unambiguous.

**Example 1.** Determine whether the relation $R = \{(1,a),(2,a),(2,b),(3,c)\}$ on$\{1,2,3\} \times \{a,b,c\}$ is a function.

Element $2$ appears with two different second coordinates —$(2,a)$ and$(2,b)$ — violating single-valuedness. So$R$ is not a function. Removing$(2,b)$ would yield a valid function$\{1,2,3\} \to \{a,b,c\}$ with$f(1) = a$,$f(2) = a$,$f(3) = c$ and image$\{a,c\}$.

**Example 2.** Let $f \colon \mathbb{Z} \to \mathbb{Z}$ be defined by$f(n) = n^{3} - n$. Compute$f(0)$,$f(1)$,$f(-1)$,$f(2)$, and describe the image$f(\mathbb{Z})$.

$f(0) = 0$,$f(1) = 0$,$f(-1) = -1 + 1 = 0$,$f(2) = 8 - 2 = 6$. Since$n^{3} - n = n(n-1)(n+1)$ is the product of three consecutive integers, it is always divisible by$6$. Thus$f(\mathbb{Z}) \subseteq 6\mathbb{Z}$. In fact$f(\mathbb{Z}) = 6\mathbb{Z}$: for any$6k$, one can show$f$ achieves$6k$ for some integer input.

**Example 3.** Define $f \colon \mathcal{P}(\{1,2,3\}) \to \{0,1,2,3\}$ by$f(S) = |S|$ (the cardinality of the subset). Identify the domain, codomain, image, and verify$f$ is a well-defined function.

Domain: $\mathcal{P}(\{1,2,3\}) = \{\emptyset,\{1\},\{2\},\{3\},\{1,2\},\{1,3\},\{2,3\},\{1,2,3\}\}$, eight elements. Codomain:$\{0,1,2,3\}$. Values:$f(\emptyset) = 0$;$f(\{1\}) = f(\{2\}) = f(\{3\}) = 1$;$f(\{1,2\}) = f(\{1,3\}) = f(\{2,3\}) = 2$;$f(\{1,2,3\}) = 3$. The image is$\{0,1,2,3\}$ = codomain, so$f$ is surjective. It is not injective since multiple subsets share the same cardinality.

**Example 4.** Show that the set of all functions from $\{0,1\}$ to$A$ is in bijection with$A \times A$.

A function $f \colon \{0,1\} \to A$ is determined by its values$f(0) \in A$ and$f(1) \in A$, which are independent choices. The map$f \mapsto (f(0), f(1))$ is a bijection from the set of functions$A^{\{0,1\}}$ to$A \times A$. The inverse sends$(a, b) \mapsto$ the function with$f(0) = a$ and$f(1) = b$. This confirms$|A^{\{0,1\}}| = |A|^{2} = |A \times A|$.
