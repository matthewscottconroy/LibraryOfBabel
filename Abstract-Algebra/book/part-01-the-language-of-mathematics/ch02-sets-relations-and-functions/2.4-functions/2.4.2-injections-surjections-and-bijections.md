# 2.4.2 Injections, Surjections, and Bijections

Not all functions behave equally well as maps between sets. Depending on how inputs and outputs relate to each other, a function may lose information, fail to cover its target, or both. The three adjectives — injective, surjective, bijective — precisely classify these behaviors, and they appear throughout algebra as the defining conditions for "isomorphisms," "surjective homomorphisms," and "embeddings."

\begin{definition}
A function $f \colon A \to B$ is:
\begin{itemize}
\item **injective** (or **one-to-one**) if $f(a) = f(a')$ implies$a = a'$ for all$a, a' \in A$;
\item **surjective** (or **onto**) if for every $b \in B$ there exists$a \in A$ with$f(a) = b$;
\item **bijective** (or a **bijection**, a **one-to-one correspondence**) if it is both injective and surjective.
\end{itemize}
\end{definition}

Injectivity means $f$ does not "collapse" any two distinct inputs. Equivalently, every fiber$f^{-1}(\{b\}) = \{a \in A \mid f(a) = b\}$ has at most one element. The contrapositive formulation —$a \neq a'$ implies$f(a) \neq f(a')$ — captures the same condition: distinct inputs yield distinct outputs, so$f$ "preserves distinctness." The function$f \colon \mathbb{Z} \to \mathbb{Z}$ given by$f(n) = 2n$ is injective; the function$g \colon \mathbb{Z} \to \mathbb{Z}$ given by$g(n) = n^{2}$ is not, since$g(2) = g(-2) = 4$.

Surjectivity is a condition about the relationship between the image and the codomain: $f$ is surjective precisely when$\mathrm{im}(f) = B$. Every element of the codomain is "hit" by at least one input, so every fiber is non-empty. The function$h \colon \mathbb{Z} \to \mathbb{Z}$ given by$h(n) = 2n$ is not surjective (no integer maps to$1$), while$k \colon \mathbb{Z} \to \mathbb{Z}$ given by$k(n) = n - 5$ is surjective (every integer$b$ is the image of$b + 5$). Adjusting the codomain changes surjectivity without changing the function's values.

A bijective function $f \colon A \to B$ establishes a perfect matching between the elements of$A$ and those of$B$. No two elements of$A$ share an image (injectivity), and no element of$B$ is left without a preimage (surjectivity). Two finite sets have the same cardinality if and only if there exists a bijection between them — this is the foundational connection between bijections and the concept of size. In algebra, a bijective homomorphism that also has a homomorphism as its inverse is an **isomorphism**, the notion of "essentially the same structure." Bijections at the pure set level are the prototype for this idea.

\begin{proposition}
Let $f \colon A \to B$ be a function.
\begin{itemize}
\item $f$ is injective if and only if it has a left inverse: a function$g \colon B \to A$ with$g \circ f = \mathrm{id}_{A}$.
\item $f$ is surjective if and only if it has a right inverse: a function$h \colon B \to A$ with$f \circ h = \mathrm{id}_{B}$.
\item $f$ is bijective if and only if it has a two-sided inverse.
\end{itemize}
\end{proposition}

The right inverse statement requires a choice: for each $b \in B$, one must choose some$a_{b} \in f^{-1}(\{b\})$ and set$h(b) = a_{b}$. When$B$ is infinite, this choice from infinitely many non-empty sets is exactly an application of the Axiom of Choice.

\begin{remark}
For finite sets, injectivity and surjectivity are related by size. If $|A| = |B| = n$, then$f$ is injective iff it is surjective iff it is bijective — this is the finite analogue of the pigeonhole principle. For infinite sets the three conditions are genuinely independent: there exist injective non-surjective functions from$\mathbb{N}$ to$\mathbb{N}$ (e.g.,$n \mapsto 2n$), surjective non-injective functions (e.g.,$n \mapsto \lfloor n/2 \rfloor$), and bijections.
\end{remark}

**Example 1.** Determine whether $f \colon \mathbb{R} \to \mathbb{R}$,$f(x) = 3x - 7$, is injective, surjective, or bijective.

Injective: if $3x - 7 = 3y - 7$ then$x = y$. Yes. Surjective: for any$b \in \mathbb{R}$, set$x = (b+7)/3$; then$f(x) = b$. Yes. Bijective: both. The inverse function is$f^{-1}(b) = (b+7)/3$.

**Example 2.** Determine the injectivity and surjectivity of $f \colon \{1,2,3\} \to \{a,b,c,d\}$ defined by$f(1) = a$,$f(2) = c$,$f(3) = a$.

Not injective: $f(1) = f(3) = a$ but$1 \neq 3$. Not surjective: the element$b$ (and$d$) has no preimage. Image$= \{a, c\}$.

**Example 3.** Show that $f \colon \mathbb{N} \to \mathbb{N} \times \mathbb{N}$ defined by$f(n) = (n, 0)$ is injective but not surjective.

Injective: if $(n, 0) = (m, 0)$ then$n = m$. Not surjective: the pair$(1, 1)$ is not in the image, since$f(n) = (n, 0)$ always has second coordinate$0$.

**Example 4.** Let $f \colon A \to B$ and$g \colon B \to C$. Prove: if$g \circ f$ is injective then$f$ is injective; if$g \circ f$ is surjective then$g$ is surjective.

For injectivity: suppose $f(a) = f(a')$. Then$g(f(a)) = g(f(a'))$, so$(g \circ f)(a) = (g \circ f)(a')$. Since$g \circ f$ is injective,$a = a'$. For surjectivity: let$c \in C$. Since$g \circ f$ is surjective, there exists$a \in A$ with$(g \circ f)(a) = c$, i.e.,$g(f(a)) = c$. Setting$b = f(a) \in B$, we have$g(b) = c$, so$g$ is surjective. These two facts combine: the composition of injections is injective, and the composition of surjections is surjective.
