# 3.1.1 Equinumerosity: Bijections as the Measure of Size

How should we decide when two sets are "the same size"? For small finite sets the answer is obvious — count the elements and compare. But for infinite sets, or even for finite sets when we want a rigorous foundation, we need a definition that does not secretly rely on the very notion of counting we are trying to define. The answer, due in its modern form to Cantor, is beautifully simple: two sets are the same size precisely when we can pair their elements off perfectly, one-to-one and onto. This pairing is a bijection, and it serves as the fundamental measure of size for sets of every cardinality.

\begin{definition}
Two sets $A$ and$B$ are **equinumerous** (or have the **same cardinality**), written$A \sim B$ or$|A| = |B|$, if there exists a bijection$f \colon A \to B$.
\end{definition}

Notice that no numbers appear in this definition — size is measured purely by the existence or non-existence of a matching, not by any counting process. For finite sets, this recovers our ordinary notion: if you can pair the elements of $A$ with the elements of$\{1, 2, \ldots, n\}$ without leaving any out or reusing any, then$A$ has exactly$n$ elements, and we write$|A| = n$. The natural numbers serve as the reference standard because they are the "canonical" finite sets.

\begin{proposition}
Equinumerosity is an equivalence relation on sets: it is reflexive, symmetric, and transitive.
\end{proposition}

*Proof.* Reflexivity: the identity function $\mathrm{id}_{A} \colon A \to A$ is a bijection, so$A \sim A$. Symmetry: if$f \colon A \to B$ is a bijection then$f^{-1} \colon B \to A$ is also a bijection, so$A \sim B$ implies$B \sim A$. Transitivity: if$f \colon A \to B$ and$g \colon B \to C$ are bijections then$g \circ f \colon A \to C$ is a bijection, so$A \sim B$ and$B \sim C$ imply$A \sim C$.$\square$

These three properties mean that "having the same cardinality" partitions the universe of sets into equivalence classes. We call the equivalence class of a set $A$ its **cardinality**, and write it$|A|$ or$\mathrm{card}(A)$. For finite sets, cardinalities are identified with natural numbers$0, 1, 2, \ldots$. The cardinality of$\mathbb{N}$ is denoted$\aleph_{0}$ (aleph-naught), the smallest infinite cardinal. The cardinality of$\mathbb{R}$ is denoted$\mathfrak{c}$ (the continuum), and Cantor's theorem will show$\mathfrak{c} > \aleph_{0}$.

\begin{definition}
We say $|A| \leq |B|$ if there exists an injection$f \colon A \to B$. We say$|A| < |B|$ if$|A| \leq |B|$ and$|A| \neq |B|$.
\end{definition}

The Schröder–Bernstein theorem (Section 3.2.4) will show that $|A| \leq |B|$ and$|B| \leq |A|$ together imply$|A| = |B|$, making$\leq$ a partial order on cardinalities. The Well-Ordering Theorem (Section 3.3.3) then implies that any two cardinalities are comparable, making$\leq$ a total order.

The definition of equinumerosity, stripped of any reference to "counting," has surprising consequences for infinite sets. Two sets can look very different in size and yet be equinumerous — the integers and the natural numbers, the rationals and the integers, are all equinumerous with each other, as we will show. Sets can also look like they should be the same size and yet fail to be equinumerous — the real numbers are strictly larger than the natural numbers, in the precise sense that no bijection exists. Working through these examples consistently overturns naive intuition about infinity.

**Example 1.** Show that $|2\mathbb{N}| = |\mathbb{N}|$, where$2\mathbb{N} = \{0, 2, 4, 6, \ldots\}$ is the set of even natural numbers.

The function $f \colon \mathbb{N} \to 2\mathbb{N}$ defined by$f(n) = 2n$ is a bijection: it is injective (if$2n = 2m$ then$n = m$) and surjective (every even number$2k$ is the image of$k$). Hence$|\mathbb{N}| = |2\mathbb{N}|$. This is the simplest illustration of Galileo's paradox: a proper subset of an infinite set can be equinumerous with the whole set.

**Example 2.** Show that $|(0,1)| = |\mathbb{R}|$ by constructing an explicit bijection.

The function $f \colon (0,1) \to \mathbb{R}$ defined by$f(x) = \tan(\pi(x - 1/2))$ is a bijection. It is continuous, strictly increasing, and maps$(0,1)$ to all of$\mathbb{R}$: as$x \to 0^{+}$,$f(x) \to -\infty$; as$x \to 1^{-}$,$f(x) \to +\infty$. Alternatively,$f(x) = (2x-1)/(x(1-x))$ works. Both show the open interval and the real line are equinumerous despite one being bounded and the other unbounded.

**Example 3.** Show that $|\{0,1\}^{\mathbb{N}}| = |\mathcal{P}(\mathbb{N})|$, where$\{0,1\}^{\mathbb{N}}$ is the set of all binary sequences.

Define $\phi \colon \{0,1\}^{\mathbb{N}} \to \mathcal{P}(\mathbb{N})$ by$\phi(s) = \{n \in \mathbb{N} \mid s(n) = 1\}$, the "support" of the sequence$s$. This is a bijection: the inverse sends$S \subseteq \mathbb{N}$ to its indicator function$\mathbf{1}_{S}$. Hence the set of binary sequences and the power set of$\mathbb{N}$ have the same cardinality — both equal$\mathfrak{c} = 2^{\aleph_{0}}$.

**Example 4.** Prove that for any set $A$, the function$F \colon A \to \{\{a\} \mid a \in A\}$ sending$a \mapsto \{a\}$ is a bijection.

Injectivity: if $\{a\} = \{a'\}$ then$a = a'$. Surjectivity: every singleton$\{a\}$ is the image of$a$. Hence$A$ is equinumerous with the set of its singletons. This trivial bijection underlies the definition of cardinal arithmetic and the fact that$|A| = |\{\{a\} \mid a \in A\}|$.
