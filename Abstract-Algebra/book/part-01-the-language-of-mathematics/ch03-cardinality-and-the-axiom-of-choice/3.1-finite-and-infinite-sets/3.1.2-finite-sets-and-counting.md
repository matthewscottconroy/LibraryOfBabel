# 3.1.2 Finite Sets and Counting

Before confronting the genuinely new phenomena of infinite sets, we should verify that our definition of equinumerosity correctly captures the finite case and derives the familiar properties of counting as theorems rather than axioms. Treating finiteness rigorously requires a bit of care, but the payoff is a firm foundation on which all subsequent cardinality arguments rest.

\begin{definition}
A set $A$ is **finite** if it is equinumerous with the set$\{1, 2, \ldots, n\}$ for some$n \in \mathbb{N}$ (where$n = 0$ gives the empty set). The **cardinality** of$A$ is$|A| = n$, and we write$|A| = n$. A set is **infinite** if it is not finite.
\end{definition}

The first non-trivial fact we must prove is that the cardinality $n$ is uniquely determined by$A$: a finite set cannot be in bijection with two different initial segments$\{1, \ldots, m\}$ and$\{1, \ldots, n\}$ with$m \neq n$.

\begin{theorem}[Uniqueness of cardinality]
If $A$ is finite and$f \colon A \to \{1, \ldots, m\}$ and$g \colon A \to \{1, \ldots, n\}$ are both bijections, then$m = n$.
\end{theorem}

*Proof sketch.* The composition $g \circ f^{-1} \colon \{1,\ldots,m\} \to \{1,\ldots,n\}$ is a bijection. By induction one shows that a bijection from$\{1,\ldots,m\}$ to$\{1,\ldots,n\}$ exists only when$m = n$.$\square$

This uniqueness theorem is the foundation of counting: the number $n$ is the unique cardinality associated to a finite set$A$, and it is independent of the choice of bijection.

\begin{proposition}
For finite sets:
\begin{enumerate}
\item Any subset of a finite set is finite, and $|S| \leq |A|$ for$S \subseteq A$.
\item $|A \cup B| = |A| + |B| - |A \cap B|$ (inclusion-exclusion for two sets).
\item $|A \times B| = |A| \cdot |B|$.
\item $|\mathcal{P}(A)| = 2^{|A|}$.
\item $|B^{A}| = |B|^{|A|}$ (the number of functions from$A$ to$B$).
\end{enumerate}
\end{proposition}

These formulas are proved by constructing explicit bijections. For (3), a bijection from $A \times B$ to$\{1,\ldots,mn\}$ (where$|A|=m$,$|B|=n$) can be built by listing elements of$A \times B$ row by row. For (4), a bijection from$\mathcal{P}(A)$ to$\{0,1\}^{A}$ sends each subset to its indicator function, and$|\{0,1\}^{A}| = 2^{n}$ by (5).

\begin{theorem}[Pigeonhole Principle]
If $|A| > |B|$, then no injection from$A$ to$B$ exists. Equivalently, any function$f \colon A \to B$ with$|A| > |B|$ is not injective: there exist distinct$a, a' \in A$ with$f(a) = f(a')$.
\end{theorem}

The pigeonhole principle is named for the observation that if you try to house $n+1$ pigeons in$n$ pigeonholes, at least two must share a hole. Simple as it sounds, the principle underlies a remarkable number of arguments in combinatorics, number theory, and algebra.

\begin{remark}
A set $A$ is infinite if and only if it is equinumerous with a proper subset of itself. This is Dedekind's characterisation of infinite sets, and it can serve as an alternative definition. The natural numbers$\mathbb{N}$ are infinite in this sense:$f \colon \mathbb{N} \to \mathbb{N} \setminus \{0\}$ defined by$f(n) = n+1$ is a bijection onto a proper subset. No finite set has this property (by the uniqueness theorem above, a bijection from$A$ to a proper subset would require the subset to have the same cardinality as$A$, contradicting$|S| < |A|$ for strict subsets of finite sets).
\end{remark}

The study of finite sets is where our rigorous definition pays its first dividends: we see that counting is not a primitive notion but a theorem — the cardinality $|A|$ is the unique$n$ for which a bijection from$A$ to$\{1,\ldots,n\}$ exists. With this foundation in place, we are ready to ask what happens when we apply the same idea to infinite sets.

**Example 1.** Compute $|\mathcal{P}(\{a,b,c,d\})|$ and list all subsets of cardinality exactly 2.

$|\{a,b,c,d\}| = 4$, so$|\mathcal{P}(\{a,b,c,d\})| = 2^{4} = 16$. The subsets of size 2 are:$\{a,b\},\{a,c\},\{a,d\},\{b,c\},\{b,d\},\{c,d\}$ — there are$\binom{4}{2} = 6$ of them.

**Example 2.** A class has 30 students and 10 possible letter grades (A+, A, A-, B+, …). Prove at least 3 students receive the same grade.

This is the pigeonhole principle with 30 "pigeons" (students) and 10 "holes" (grades). If every grade were given to at most 2 students, the total number of students would be at most $10 \times 2 = 20 < 30$, a contradiction. Hence some grade is given to at least$\lceil 30/10 \rceil = 3$ students.

**Example 3.** Let $A = \{1, 2, 3, 4, 5\}$. How many functions are there from$A$ to$\{0,1\}$? How many are injective?

Total functions: $|\{0,1\}^{A}| = 2^{5} = 32$. Injective functions from$A$ to$\{0,1\}$: since$|A| = 5 > 2 = |\{0,1\}|$, the pigeonhole principle implies no injection exists. There are$0$ injective functions.

**Example 4.** Use bijections to prove $|A \cup B| = |A| + |B|$ when$A \cap B = \emptyset$ and both sets are finite.

Let $|A| = m$ and$|B| = n$. Choose bijections$f \colon \{1,\ldots,m\} \to A$ and$g \colon \{1,\ldots,n\} \to B$. Define$h \colon \{1,\ldots,m+n\} \to A \cup B$ by$h(k) = f(k)$ for$k \leq m$ and$h(k) = g(k-m)$ for$k > m$. Since$A$ and$B$ are disjoint,$h$ is injective; it is surjective because every element of$A \cup B$ lies in$A$ or$B$ and is covered by$f$ or$g$ respectively. Hence$h$ is a bijection, giving$|A \cup B| = m + n = |A| + |B|$.
