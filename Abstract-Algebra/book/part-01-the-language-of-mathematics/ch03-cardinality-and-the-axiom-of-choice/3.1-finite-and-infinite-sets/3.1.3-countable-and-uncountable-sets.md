# 3.1.3 Countable and Uncountable Sets

Once we move beyond finite sets, the first and most fundamental question is whether a given infinite set can be put into bijection with the natural numbers. This question divides the infinite world into two fundamentally different types, and the resulting distinction — between sets that can be listed and sets that cannot — is one of Cantor's most enduring contributions to mathematics.

\begin{definition}
A set $A$ is **countably infinite** if$|A| = |\mathbb{N}|$, i.e., if there exists a bijection$f \colon \mathbb{N} \to A$. A set is **countable** if it is either finite or countably infinite. A set is **uncountable** if it is infinite and not countably infinite.
\end{definition}

The reason "listability" is the right concept is that a bijection $f \colon \mathbb{N} \to A$ is exactly a way of writing out all elements of$A$ as an infinite sequence$a_{0}, a_{1}, a_{2}, \ldots$ without repetition or omission: we set$a_{n} = f(n)$. A countably infinite set is thus one whose elements can in principle be enumerated in a complete list. "In principle" is important: we do not require the list to be computable or constructive, only that such an enumeration exists.

\begin{proposition}
The following properties characterise countable sets:
\begin{enumerate}
\item Any subset of a countable set is countable.
\item A countable union of countable sets is countable.
\item The Cartesian product of two countable sets is countable.
\end{enumerate}
\end{proposition}

Property (2) means: if $A_{1}, A_{2}, A_{3}, \ldots$ are countable sets, then$\bigcup_{n \in \mathbb{N}} A_{n}$ is countable. The proof uses the diagonal enumeration technique of Section 3.2.1: arrange the elements of all the$A_{n}$ in an infinite grid and traverse the diagonals. Property (3) follows from (2) by writing$A \times B = \bigcup_{a \in A} \{a\} \times B$, which is a countable union (over the countable set$A$) of countable sets ($\{a\} \times B \cong B$).

The distinction between countable and uncountable is not merely a curiosity; it has genuine mathematical consequences. The set of all polynomials with integer coefficients is countable, as is the set of all algebraic numbers (roots of such polynomials). Since $\mathbb{R}$ is uncountable, "most" real numbers are transcendental — they cannot be roots of any polynomial with integer coefficients. This is not merely a philosophical observation: it is a precise statement about cardinality, and it was a striking result when first proved, since explicit transcendental numbers were hard to construct at the time.

\begin{definition}
A set $A$ is **denumerable** (another term for countably infinite) if it admits a bijection with$\mathbb{N}$. Some authors use "countable" to mean "countably infinite" and "at most countable" to mean "finite or countably infinite"; we use "countable" for the latter to avoid proliferation of terms.
\end{definition}

In logic and computability theory, countability governs what can be specified by a finite description. Any programming language over a finite alphabet generates only countably many programs; since there are uncountably many functions $\mathbb{N} \to \mathbb{N}$, most functions cannot be computed by any program. This is the cardinality-theoretic core of the undecidability results in theoretical computer science.

**Example 1.** Show that the set of all finite subsets of $\mathbb{N}$ is countable.

Let $\mathcal{F}(\mathbb{N})$ be the set of finite subsets of$\mathbb{N}$. For each$n \in \mathbb{N}$, the collection$\mathcal{F}_{n} = \{S \subseteq \mathbb{N} \mid |S| = n\}$ of$n$-element subsets is countable (it can be listed by enumerating$n$-tuples of natural numbers and discarding those with repetitions). Since$\mathcal{F}(\mathbb{N}) = \bigcup_{n=0}^{\infty} \mathcal{F}_{n}$ is a countable union of countable sets, it is countable.

**Example 2.** Show that any infinite set has a countably infinite subset.

Let $A$ be infinite. Since$A$ is non-empty, choose$a_{0} \in A$. Since$A \setminus \{a_{0}\}$ is infinite (hence non-empty), choose$a_{1} \in A \setminus \{a_{0}\}$. Continue inductively: at stage$n$, the set$A \setminus \{a_{0},\ldots,a_{n-1}\}$ is infinite, so choose$a_{n}$ from it. The resulting set$\{a_{0}, a_{1}, a_{2}, \ldots\}$ is a countably infinite subset of$A$. (This argument uses the Axiom of Choice — or at least a countable version of it — to make the infinitely many choices.)

**Example 3.** Prove that $\mathbb{Z}$ is countable by constructing an explicit bijection$f \colon \mathbb{N} \to \mathbb{Z}$.

Define $f(0) = 0$ and, for$n \geq 1$:
$$f(n) = \begin{cases} n/2 & \text{if } n \text{ is even} \\ -(n+1)/2 & \text{if } n \text{ is odd}. \end{cases}$$
The sequence begins $0, 1, -1, 2, -2, 3, -3, \ldots$. Injectivity and surjectivity are easily verified: every integer$k$ appears exactly once ($k > 0$ at position$2k$;$k \leq 0$ at position$-2k+1$). Hence$|\mathbb{Z}| = |\mathbb{N}| = \aleph_{0}$.

**Example 4.** Show that the union of countably many finite sets need not be finite, but is always countable.

The sets $A_{n} = \{n\}$ for$n \in \mathbb{N}$ are each finite (of size 1), but$\bigcup_{n} A_{n} = \mathbb{N}$ is infinite. This shows the union can be infinite. However, it is countable:$\mathbb{N}$ is countably infinite. More generally, the Proposition above guarantees that a countable union of countable sets is countable, and this bound is tight since$\mathbb{N} = \bigcup_{n} \{n\}$ shows we can achieve a countably infinite union.
