# 3.1 Finite and Infinite Sets

Counting is so natural that it seems to require no explanation. We say a set has $n$ elements if we can list its elements $a_1, a_2, \ldots, a_n$ without repetition or omission — that is, if we can construct a bijection between the set and the standard finite set $\{1, 2, \ldots, n\}$. This bijection-based definition of "same size" is the key insight that allows the concept to be extended from finite to infinite sets without loss of rigor. Two sets $A$ and $B$ are *equipotent*, written $|A| = |B|$, if there exists a bijection $f: A \to B$. For finite sets this agrees with the ordinary notion: if both sets can be put in bijection with $\{1, \ldots, n\}$, they can be put in bijection with each other. For infinite sets it is the only coherent definition available.

The surprising behavior of infinite sets under this definition was first explored systematically by Cantor and Dedekind in the 1870s. Dedekind proposed using it as the *definition* of infinity: a set $A$ is *infinite* if and only if there exists a bijection between $A$ and a proper subset of $A$. The natural numbers, for instance, are in bijection with the even natural numbers via $n \mapsto 2n$, and $\{0, 2, 4, \ldots\} \subsetneq \mathbb{N}$. Far from being a paradox, this is a theorem — it follows from the existence of an injection $\mathbb{N} \to \mathbb{N}$ with non-surjective image. Finite sets, by contrast, satisfy the *pigeonhole principle*: no injection from a finite set to a proper subset of itself exists. The pigeonhole principle, formalized as a theorem about bijections rather than an intuitive observation, is a surprisingly powerful tool whose consequences include fundamental results in combinatorics, number theory, and algebra.

The inequality relation on cardinalities is defined by injection: $|A| \leq |B|$ if there exists an injection $f: A \to B$. With this definition, $|A| < |B|$ means there is an injection from $A$ into $B$ but no bijection between them. The *Schröder–Bernstein theorem* — proved in this section without using the Axiom of Choice — establishes that $\leq$ on cardinalities is a partial order: if $|A| \leq |B|$ and $|B| \leq |A|$, then $|A| = |B|$. The proof constructs an explicit bijection from a pair of injections using a decomposition of $A$ and $B$ into orbits; it is one of the most elegant arguments in set theory. The theorem is essential because in practice one typically establishes $|A| = |B|$ by constructing two separate injections, one in each direction, rather than hunting for a single explicit bijection — and Schröder–Bernstein guarantees that this weaker construction is sufficient.
