# 3.2.2 Uncountability of $\mathbb{R}$: The Diagonal Argument

The previous section showed that infinite sets can be surprisingly small — $\mathbb{Q}$, despite its apparent density, is only countably infinite. Now we encounter the opposite surprise:$\mathbb{R}$ is genuinely, irremediably larger. No matter how cleverly you attempt to list the real numbers in a sequence$r_{1}, r_{2}, r_{3}, \ldots$, you will always miss some. This is Cantor's celebrated **diagonal argument**, first published in 1891, and it remains one of the most elegant and conceptually powerful proofs in all of mathematics.

\begin{theorem}[Cantor, 1891]
The set $\mathbb{R}$ is uncountable:$|\mathbb{R}| > |\mathbb{N}|$.
\end{theorem}

*Proof.* It suffices to show that the open interval $(0,1)$ is uncountable, since$(0,1)$ and$\mathbb{R}$ are equinumerous (Section 3.1.1). Suppose for contradiction that there is an enumeration$r_{1}, r_{2}, r_{3}, \ldots$ of all real numbers in$(0,1)$. Write each$r_{n}$ in its decimal expansion:
$$r_{n} = 0.d_{n1}\, d_{n2}\, d_{n3}\, \ldots$$
where $d_{nk} \in \{0, 1, \ldots, 9\}$. To avoid the ambiguity of terminating decimals (e.g.,$0.5000\ldots = 0.4999\ldots$), choose the expansion that does not terminate in infinitely many 9s.

Construct a new number $d \in (0,1)$ by the rule: the$n$-th decimal digit of$d$ is
$$d_{n} = \begin{cases} 3 & \text{if } d_{nn} \neq 3 \\ 7 & \text{if } d_{nn} = 3. \end{cases}$$
(Using 3 and 7 ensures $d$ never terminates in all 9s or all 0s, avoiding any ambiguity.) Then$d$ differs from$r_{n}$ in the$n$-th decimal place for every$n$:$d_{n} \neq d_{nn}$. Therefore$d \neq r_{n}$ for all$n$, contradicting the assumption that$\{r_{n}\}$ enumerated all of$(0,1)$.$\square$

The name "diagonal argument" is transparent from the structure of the proof: the digits $d_{11}, d_{22}, d_{33}, \ldots$ that we modify form the main diagonal of the infinite matrix whose rows are the decimal expansions of$r_{1}, r_{2}, r_{3}, \ldots$. We read down the diagonal and alter each digit, constructing a number that differs from every listed number at the very diagonal position where it was "supposed to match."

\begin{remark}
The diagonal argument is a template, not a one-off trick. The same proof shows that the set $\{0,1\}^{\mathbb{N}}$ of all infinite binary sequences is uncountable. More generally, for any set$A$ with$|A| \geq 2$, the set$A^{\mathbb{N}}$ of all$A$-valued sequences is uncountable. The argument appears in logic as the undecidability of the halting problem (Turing, 1936): the "machine that checks whether machine$n$ halts on input$n$" cannot be one of the listed machines, for if it were, a contradiction analogous to the above arises.
\end{remark}

The proof that $|\mathbb{R}| = |\mathcal{P}(\mathbb{N})|$ closes the circle. An infinite binary sequence$s = (s_{n})_{n \in \mathbb{N}} \in \{0,1\}^{\mathbb{N}}$ corresponds to a real number in$[0,1]$ via its binary expansion$\sum_{n=1}^{\infty} s_{n} / 2^{n}$, and this map is "almost" a bijection (it fails only at the countably many dyadic rationals, which have two binary representations). A careful adjustment confirms$|\{0,1\}^{\mathbb{N}}| = |\mathbb{R}|$. Combined with$|\{0,1\}^{\mathbb{N}}| = |\mathcal{P}(\mathbb{N})| = 2^{\aleph_{0}}$, we conclude$|\mathbb{R}| = 2^{\aleph_{0}} = \mathfrak{c}$, the cardinality of the continuum.

The existence of at least two distinct infinite cardinalities — $\aleph_{0} = |\mathbb{N}|$ and$\mathfrak{c} = |\mathbb{R}|$ — raises the immediate question: are there any cardinalities strictly between them? This is the **Continuum Hypothesis**, which asserts that no such intermediate cardinality exists. Gödel (1938) and Cohen (1963) showed that the Continuum Hypothesis is independent of the standard axioms of set theory (ZFC): it can neither be proved nor refuted from those axioms.

**Example 1.** Apply the diagonal argument to the set $\{0,1\}^{\mathbb{N}}$ of infinite binary sequences to show it is uncountable.

Suppose $s_{1}, s_{2}, s_{3}, \ldots$ is an enumeration of all binary sequences. Define a new sequence$d$ by$d_{n} = 1 - s_{n}(n)$ (flip the$n$-th bit of$s_{n}$). Then$d$ differs from$s_{n}$ in position$n$ for every$n$, so$d$ is not in the list. Contradiction:$\{0,1\}^{\mathbb{N}}$ is uncountable.

**Example 2.** Show that the set of all functions $\mathbb{N} \to \mathbb{N}$ is uncountable.

Suppose $f_{1}, f_{2}, \ldots$ is an enumeration of all such functions. Define$g \colon \mathbb{N} \to \mathbb{N}$ by$g(n) = f_{n}(n) + 1$. Then$g(n) \neq f_{n}(n)$ for every$n$, so$g \neq f_{n}$ for all$n$. Contradiction. The set$\mathbb{N}^{\mathbb{N}}$ is uncountable.

**Example 3.** Give a direct proof that $(0,1)$ and$[0,1]$ are equinumerous without using the Schröder–Bernstein theorem.

Define $f \colon [0,1] \to (0,1)$ as follows. Let$a_{n} = 1/(n+2)$ for$n = 0, 1, 2, \ldots$, so$a_{0} = 1/2$,$a_{1} = 1/3$, etc. Set$f(0) = 1/2$,$f(1) = 1/3$,$f(a_{n}) = a_{n+2}$ for$n \geq 0$, and$f(x) = x$ for$x \in (0,1) \setminus \{a_{0}, a_{1}, a_{2},\ldots\}$. One verifies$f$ is a bijection$(0,1]$ to$(0,1)$, and a similar construction handles the left endpoint. Alternatively, the Schröder–Bernstein approach (Section 3.2.4) is more transparent.

**Example 4.** Show that the set of irrational numbers is uncountable.

$\mathbb{R} = \mathbb{Q} \cup (\mathbb{R} \setminus \mathbb{Q})$. If$\mathbb{R} \setminus \mathbb{Q}$ were countable, then$\mathbb{R}$ would be a union of two countable sets (since$\mathbb{Q}$ is countable), hence countable — contradicting the theorem above. Therefore$\mathbb{R} \setminus \mathbb{Q}$ is uncountable, and in fact$|\mathbb{R} \setminus \mathbb{Q}| = |\mathbb{R}| = \mathfrak{c}$.
