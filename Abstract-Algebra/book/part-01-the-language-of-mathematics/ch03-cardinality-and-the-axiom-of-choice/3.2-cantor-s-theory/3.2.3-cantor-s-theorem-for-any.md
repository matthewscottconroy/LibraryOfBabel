# 3.2.3 Cantor's Theorem: $|A| < |\mathcal{P}(A)|$ for Any$A$

Having established that $|\mathbb{N}| < |\mathbb{R}|$, one might ask whether the continuum cardinality$\mathfrak{c} = |\mathbb{R}|$ is the largest that exists. The answer is definitively no — and not just because there are a few larger cardinalities waiting to be discovered, but because there is an endless hierarchy of strictly larger infinities. **Cantor's theorem** provides the universal mechanism for ascending this hierarchy: for any set$A$, the power set$\mathcal{P}(A)$ has strictly greater cardinality than$A$ itself.

\begin{theorem}[Cantor's Theorem]
For any set $A$,$|A| < |\mathcal{P}(A)|$.
\end{theorem}

*Proof.* We must show (i) $|A| \leq |\mathcal{P}(A)|$ and (ii)$|A| \neq |\mathcal{P}(A)|$.

For (i): the map $a \mapsto \{a\}$ is an injection$A \to \mathcal{P}(A)$, so$|A| \leq |\mathcal{P}(A)|$.

For (ii): we show no function $f \colon A \to \mathcal{P}(A)$ is surjective. Given any$f$, define the "diagonal set"
$$D = \{a \in A \mid a \notin f(a)\}.$$
Since $D \subseteq A$, we have$D \in \mathcal{P}(A)$. We claim$D \notin \mathrm{im}(f)$. Suppose for contradiction that$D = f(a_{0})$ for some$a_{0} \in A$. Ask whether$a_{0} \in D$:
\begin{itemize}
\item If $a_{0} \in D$, then by definition of$D$,$a_{0} \notin f(a_{0}) = D$. Contradiction.
\item If $a_{0} \notin D$, then$a_{0}$ fails the condition defining$D$, meaning$a_{0} \in f(a_{0}) = D$. Contradiction.
\end{itemize}
Both cases are impossible, so $D \neq f(a_{0})$ for any$a_{0}$, and$f$ is not surjective.$\square$

Notice the deep structural similarity between this proof and Russell's paradox (Section 2.1.4). The diagonal set $D = \{a \mid a \notin f(a)\}$ has the same self-referential flavor as$R = \{x \mid x \notin x\}$. In fact, Russell's paradox is essentially what happens when one tries to apply Cantor's argument with$A$ being "the set of all sets" and$f$ the identity: the diagonal set$\{x \mid x \notin x\}$ is Russell's$R$, and the proof shows it cannot be in any set, hence "the set of all sets" does not exist.

Cantor's theorem gives a strictly increasing chain of cardinalities:
$$|\mathbb{N}| < |\mathcal{P}(\mathbb{N})| < |\mathcal{P}(\mathcal{P}(\mathbb{N}))| < \cdots,$$
with no largest term. In cardinal arithmetic, these are $\aleph_{0} < 2^{\aleph_{0}} < 2^{2^{\aleph_{0}}} < \cdots$. One can show that$|\mathcal{P}(\mathbb{N})| = |\mathbb{R}| = \mathfrak{c}$ by the binary sequence argument: subsets of$\mathbb{N}$ correspond to binary sequences, which correspond to reals in$[0,1]$ via binary expansions (with countably many identifications). So the first step up from$\aleph_{0}$ in this chain is the continuum.

\begin{corollary}
There is no largest cardinality, and there is no "set of all sets."
\end{corollary}

*Proof.* Given any cardinal $\kappa = |A|$, Cantor's theorem gives$|A| < |\mathcal{P}(A)|$, so$\kappa < 2^{\kappa}$. Hence no cardinal is the largest. If there were a set$U$ of all sets, then$\mathcal{P}(U) \subseteq U$ (every subset of$U$ is itself a set, hence an element of$U$), giving$|\mathcal{P}(U)| \leq |U|$, contradicting Cantor's theorem.$\square$

The question of which cardinalities lie between $\aleph_{0}$ and$\mathfrak{c}$ is the **Continuum Hypothesis** (CH): CH asserts that no cardinality$\kappa$ satisfies$\aleph_{0} < \kappa < \mathfrak{c}$. More generally, the **Generalized Continuum Hypothesis** (GCH) asserts$2^{\aleph_{\alpha}} = \aleph_{\alpha + 1}$ for every ordinal$\alpha$. Both are independent of ZFC.

**Example 1.** Apply Cantor's theorem with $A = \{1,2,3\}$ explicitly. Find the diagonal set$D$ for the function$f(1) = \{2\}$,$f(2) = \{1,2\}$,$f(3) = \emptyset$.

$f(1) = \{2\}$: is$1 \in f(1) = \{2\}$? No. So$1 \in D$.$f(2) = \{1,2\}$: is$2 \in f(2)$? Yes. So$2 \notin D$.$f(3) = \emptyset$: is$3 \in f(3) = \emptyset$? No. So$3 \in D$. Hence$D = \{1,3\}$. Verify:$D \neq f(1) = \{2\}$,$D \neq f(2) = \{1,2\}$,$D \neq f(3) = \emptyset$. Indeed$D$ is not in the image.

**Example 2.** Verify that $|\mathcal{P}(\mathbb{N})| = |\{0,1\}^{\mathbb{N}}|$ by constructing an explicit bijection.

The bijection $\phi \colon \mathcal{P}(\mathbb{N}) \to \{0,1\}^{\mathbb{N}}$ sends$S \subseteq \mathbb{N}$ to its characteristic function$\mathbf{1}_{S}$, where$\mathbf{1}_{S}(n) = 1$ if$n \in S$ and$0$ otherwise. The inverse sends a sequence$(b_{n}) \in \{0,1\}^{\mathbb{N}}$ to$\{n \mid b_{n} = 1\}$. This is a bijection.

**Example 3.** Show that $|\mathbb{R}^{2}| = |\mathbb{R}|$.

It suffices to show $|(0,1)^{2}| = |(0,1)|$. Define a bijection by "interleaving decimal digits": for$(x,y) = (0.x_{1}x_{2}x_{3}\ldots, 0.y_{1}y_{2}y_{3}\ldots)$, map to$0.x_{1}y_{1}x_{2}y_{2}x_{3}y_{3}\ldots \in (0,1)$. (One must be careful about non-uniqueness of decimal representations, but the necessary adjustments are routine.) Alternatively, Cantor's theorem gives$|(0,1)^{2}| \leq |(\mathcal{P}(\mathbb{N}))^{2}| = |\mathcal{P}(\mathbb{N}) \times \mathcal{P}(\mathbb{N})| = |\mathcal{P}(\mathbb{N} \times \mathbb{N})| = |\mathcal{P}(\mathbb{N})|$, and the injection$(0,1) \hookrightarrow (0,1)^{2}$ (via$x \mapsto (x,x)$) gives the other inequality, so by Schröder–Bernstein$|(0,1)^{2}| = |(0,1)|$.

**Example 4.** Construct an injection from $\mathcal{P}(\mathbb{N})$ into$\mathbb{R}$, confirming$\mathfrak{c} = |\mathbb{R}| \geq |\mathcal{P}(\mathbb{N})| = 2^{\aleph_{0}}$.

Map $S \subseteq \mathbb{N}$ to the real number$\sum_{n \in S} 3^{-(n+1)} \in [0, 1/2]$. This is an injection: two distinct subsets$S \neq T$ differ in some smallest index$n_{0}$; comparing the$n_{0}$-th "ternary digit" of the corresponding sums shows they are distinct. Hence$|\mathcal{P}(\mathbb{N})| \leq |\mathbb{R}|$. Combined with$|\mathbb{R}| \leq |\mathcal{P}(\mathbb{N})|$ (via binary expansions), Schröder–Bernstein gives$|\mathbb{R}| = |\mathcal{P}(\mathbb{N})| = 2^{\aleph_{0}}$.
