# 3.2 Cantor's Theory

Once the bijection-based definition of equipotence is in place, the natural question is: are all infinite sets the same size? The answer is no, and establishing this requires Cantor's diagonal argument — one of the most celebrated proofs in the history of mathematics. The argument shows that $|\mathbb{N}| < |\mathbb{R}|$: the real numbers are *uncountable*, meaning no bijection from $\mathbb{N}$ to $\mathbb{R}$ can exist. The proof is indirect: given any function $f: \mathbb{N} \to [0,1]$ — any proposed enumeration of the reals in $[0,1]$ as decimal expansions $f(n) = 0.d_1^{(n)} d_2^{(n)} d_3^{(n)} \cdots$ — one constructs a real number $x = 0.x_1 x_2 x_3 \cdots$ by choosing the $n$-th digit $x_n$ to differ from $d_n^{(n)}$. By construction, $x$ differs from $f(n)$ in the $n$-th decimal place for every $n$, so $x \neq f(n)$ for all $n$, and thus $x$ is not in the image of $f$. No enumeration can be complete. A set is called *countable* if it is either finite or in bijection with $\mathbb{N}$; the diagonal argument shows $\mathbb{R}$ is uncountable. By contrast, $\mathbb{Z}$ and $\mathbb{Q}$ are both countable (the rationals can be enumerated by the zigzag argument through the integer lattice), which means the "gap" between countable and uncountable sets sits strictly between the rationals and the reals.

The diagonal argument is not specific to the real numbers; it is a general combinatorial principle. *Cantor's theorem* states that for any set $A$ — finite or infinite — there is no surjection from $A$ to its power set $\mathcal{P}(A)$, and therefore $|A| < |\mathcal{P}(A)|$. The proof runs the same diagonal construction: given any $f: A \to \mathcal{P}(A)$, form $D = \{a \in A : a \notin f(a)\}$; then $D \in \mathcal{P}(A)$ but $D \neq f(a)$ for any $a$ (if $a \in D$ then $a \notin f(a)$, so $D \neq f(a)$; if $a \notin D$ then $a \in f(a)$, so again $D \neq f(a)$). This single theorem implies that cardinalities form a proper class, not a set: starting from $\mathbb{N}$, iterating $A \mapsto \mathcal{P}(A)$ produces an inexhaustible tower $|\mathbb{N}| < |\mathcal{P}(\mathbb{N})| < |\mathcal{P}(\mathcal{P}(\mathbb{N}))| < \cdots$. Moreover, $|\mathcal{P}(\mathbb{N})| = |\mathbb{R}|$: a bijection can be constructed via binary expansions of real numbers in $[0,1]$.

The *Continuum Hypothesis* (CH) asks whether there is a set $S$ with $|\mathbb{N}| < |S| < |\mathbb{R}|$ — a cardinality strictly between countable and continuum. Cantor spent years trying to prove there is no such $S$ but could not. Gödel showed in 1938 that CH is *consistent* with the standard axioms of set theory (ZF + AC): one cannot disprove CH from those axioms. Cohen showed in 1963 that CH is *independent*: one cannot prove it either. Together, these results place CH in the same category as the Parallel Postulate in geometry — an independent statement whose affirmation or denial leads to different but equally consistent theories. The techniques Cohen developed (forcing) are now a fundamental tool in mathematical logic, but the independence of CH also carries a philosophical message: the infinite hierarchy of cardinalities is genuinely underdetermined by the axioms we have chosen, and new axioms are needed if one wishes to settle questions about it.
