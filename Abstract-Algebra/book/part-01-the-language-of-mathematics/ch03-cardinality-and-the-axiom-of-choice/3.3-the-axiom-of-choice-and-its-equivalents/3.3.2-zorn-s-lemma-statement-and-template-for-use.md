# 3.3.2 Zorn's Lemma: Statement and Template for Use

The Axiom of Choice, in its raw form, says we can choose elements from sets. But in algebra we rarely need to choose elements directly; what we need instead is to know that certain structures exist — bases of vector spaces, maximal ideals of rings, maximal subgroups of groups. For these existence problems, Zorn's Lemma is the right formulation of AC. It is logically equivalent to AC, but its language is perfectly suited to the most common class of existence proofs in abstract algebra.

\begin{definition}
Let $(P, \leq)$ be a partially ordered set. A **chain** in$P$ is a subset$C \subseteq P$ in which every two elements are comparable. An **upper bound** for a subset$S \subseteq P$ is an element$u \in P$ with$s \leq u$ for all$s \in S$. An element$m \in P$ is **maximal** if there is no$p \in P$ with$m < p$ (i.e., no element strictly exceeds$m$).
\end{definition}

\begin{theorem}[Zorn's Lemma]
If $(P, \leq)$ is a non-empty partially ordered set in which every chain has an upper bound in$P$, then$P$ has at least one maximal element.
\end{theorem}

Note: a maximal element $m$ is not necessarily a maximum — it is possible that elements of$P$ are incomparable to$m$. A maximum element (if it exists) is one that is$\geq$ every other element. Maximal elements need not be unique; multiple incomparable maximal elements can coexist.

The proof that Zorn's Lemma follows from AC uses transfinite induction: starting from any element of $P$, one extends a chain through$P$ by repeatedly using AC to choose an element above the current chain (if one exists), stopping only when no such extension is possible — which means the last element chosen is maximal. The Well-Ordering Theorem is needed to index this transfinite process. The reverse — AC follows from Zorn's Lemma — is also provable, completing the equivalence.

Applying Zorn's Lemma follows a reliable four-step template. Understanding and practicing this template is one of the most useful skills in abstract algebra.

\begin{enumerate}
\item[\textbf{Step 1.}] \textbf{Define the poset.} Identify what the elements of $P$ are (typically "partial solutions" or "partial witnesses" to the existence problem) and what the partial order is (typically inclusion$\subseteq$ or extension of a function).

\item[\textbf{Step 2.}] \textbf{Verify the chain condition.} Given any chain $C \subseteq P$, exhibit an upper bound for$C$ in$P$. The upper bound is typically the union$\bigcup_{c \in C} c$. One must check that this union is actually an element of$P$ (i.e., satisfies the properties defining$P$).

\item[\textbf{Step 3.}] \textbf{Invoke Zorn's Lemma.} Conclude that $P$ has a maximal element$m$.

\item[\textbf{Step 4.}] \textbf{Exploit maximality.} Show that $m$'s maximality forces it to be a "complete solution." Any partial solution that cannot be extended must already be a full solution; otherwise we could extend it, contradicting maximality.
\end{enumerate}

This template is so standardized that once it has been practiced a few times, it is recognized across wildly different contexts. In every application, only the specifics of Steps 1 and 4 change — the poset and the argument that maximality implies completeness. Step 2 (the chain union) and Step 3 (Zorn invocation) are essentially the same in every proof.

\begin{remark}
The name "Zorn's Lemma" is historical: it was formulated by Max Zorn in 1935 as a tool to avoid transfinite induction in algebra, though equivalent principles appeared earlier in work of Hausdorff and Kuratowski. It is called a "lemma" because Zorn introduced it as a tool for proving theorems, not as a foundational principle — but it is logically equivalent to AC, making it an axiom in disguise.
\end{remark}

**Example 1.** Show that every non-empty poset in which every chain is finite has a maximal element, without invoking Zorn's Lemma.

Suppose for contradiction that $P$ has no maximal element. Then every element has a strict upper bound. Start with any$p_{0} \in P$; choose$p_{1} > p_{0}$, then$p_{2} > p_{1}$, etc. This produces an infinite chain$p_{0} < p_{1} < p_{2} < \cdots$, contradicting the assumption that every chain is finite. Hence$P$ has a maximal element. (This argument uses countable choice but not the full AC; for arbitrary posets, Zorn's Lemma is needed.)

**Example 2.** Use Zorn's Lemma to show that every partially ordered set has a maximal chain (a chain that cannot be extended).

Step 1: Let $P$ be the set of all chains in the poset$(A, \leq)$, ordered by inclusion. Step 2: Given a chain$\mathcal{C}$ in$P$ (a chain of chains), its union$\bigcup_{C \in \mathcal{C}} C$ is again a chain in$(A, \leq)$: for any$x, y \in \bigcup C$, we have$x \in C_{1}$ and$y \in C_{2}$ for some$C_{1}, C_{2} \in \mathcal{C}$; since$\mathcal{C}$ is a chain,$C_{1} \subseteq C_{2}$ or$C_{2} \subseteq C_{1}$, so both$x$ and$y$ lie in the larger of the two, which is a chain, making$x$ and$y$ comparable. Step 3: Zorn gives a maximal element$M \in P$. Step 4:$M$ is a chain in$(A,\leq)$ that cannot be extended (no element of$A$ can be added while preserving chainhood), i.e.,$M$ is a maximal chain.

**Example 3.** Identify the poset $P$ and the maximality argument in the proof that every vector space has a basis.

Step 1: $P =$ the set of all linearly independent subsets of$V$, ordered by inclusion. Step 2: the union of a chain of linearly independent sets is linearly independent (any finite linear relation involves finitely many vectors, hence lies in one set of the chain). Step 3: Zorn gives a maximal linearly independent set$B$. Step 4:$B$ spans$V$, because if some$v \in V$ were not in$\mathrm{span}(B)$, then$B \cup \{v\}$ would be linearly independent and strictly larger than$B$, contradicting maximality.

**Example 4.** Why does the proof in Example 3 fail for "largest" instead of "maximal"?

A "largest" linearly independent set would be one containing every other linearly independent set — a maximum. But a basis is not necessarily the unique maximal independent set; it is just some maximal one. Zorn's Lemma produces maximal elements, not maximum elements, and this is the correct notion here: we need some basis to exist, not a unique "largest" one. In fact, all bases of a given vector space have the same cardinality (the dimension), but this is a separate theorem proved after the existence of any basis is established.
