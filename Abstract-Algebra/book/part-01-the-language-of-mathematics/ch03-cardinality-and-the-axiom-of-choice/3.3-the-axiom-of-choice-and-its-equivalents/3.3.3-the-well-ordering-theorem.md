# 3.3.3 The Well-Ordering Theorem

The natural numbers $\mathbb{N}$ have a special property that goes beyond merely being totally ordered: every non-empty subset of$\mathbb{N}$ has a smallest element. This is the property of being **well-ordered**, and it is what makes mathematical induction valid — to prove every natural number has a property, it suffices to rule out the existence of a smallest counterexample. The **Well-Ordering Theorem** asserts that every set, including$\mathbb{R}$, can be equipped with a well-ordering. This is a far stronger claim than merely asserting that every set admits a total order.

\begin{definition}
A **well-ordering** on a set $A$ is a total order$\leq$ on$A$ such that every non-empty subset$S \subseteq A$ has a minimum element: an element$s_{0} \in S$ with$s_{0} \leq s$ for all$s \in S$.
\end{definition}

The standard order on $\mathbb{N}$ is a well-ordering. The standard order on$\mathbb{Z}$ is not: the set of negative integers$\mathbb{Z}_{<0}$ has no minimum. The standard order on$\mathbb{R}$ is not: the open interval$(0,1)$ has no minimum. The question is whether$\mathbb{R}$ can be equipped with a different, non-standard ordering that is a well-ordering.

\begin{theorem}[Well-Ordering Theorem — WO]
Every set can be well-ordered: for any set $A$, there exists a well-ordering on$A$.
\end{theorem}

The Well-Ordering Theorem is equivalent to the Axiom of Choice. Both are additional principles independent of the remaining ZF axioms, and neither implies the other without the other axioms present. The implication AC $\Rightarrow$ WO uses AC to build the well-ordering transfinitely: enumerate$A$ by repeatedly using AC to choose a "first" element from the remaining elements of$A$ and placing it next in the order. The reverse implication WO$\Rightarrow$ AC is easier: given a collection of non-empty sets$\{A_{i}\}$, well-order$\bigcup A_{i}$ and define the choice function$f(i) =$ the minimum element of$A_{i}$ in this well-ordering.

\begin{theorem}[Equivalences]
Over ZF, the following are all equivalent:
\begin{enumerate}
\item The Axiom of Choice (AC).
\item Zorn's Lemma (ZL).
\item The Well-Ordering Theorem (WO).
\item Every surjective function has a right inverse.
\item The Cartesian product of any family of non-empty sets is non-empty.
\end{enumerate}
\end{theorem}

The equivalence of (1), (2), (3) is the main content of this section and Section 3.3.2. The equivalence of (4) and (5) with (1) follows from the reformulations discussed in Section 3.3.1. This web of equivalences confirms that these are all different ways of expressing the same fundamental assumption about the set-theoretic universe.

One important consequence of WO is that any two infinite cardinalities are comparable. Without AC, it is conceivable that two cardinalities could be incomparable — neither injects into the other. The Well-Ordering Theorem rules this out: if every set can be well-ordered, then sets can be compared by mapping them to ordinals, and ordinals are totally ordered. Hence any two cardinals $|A|$ and$|B|$ satisfy$|A| \leq |B|$ or$|B| \leq |A|$.

The well-ordering of $\mathbb{R}$ guaranteed by WO is a striking example of a purely existential result. No one can write down a well-ordering of the real numbers — no formula in any reasonable language can specify which real comes first, second, etc. — and it is a theorem of ZF (without AC) that no definable well-ordering of$\mathbb{R}$ exists in a precise sense. The contrast between "exists" (AC gives it) and "can be explicitly constructed" (it cannot) is a recurring theme wherever the Axiom of Choice appears.

\begin{remark}
Transfinite induction on well-ordered sets is one of the most powerful proof techniques in set theory and algebra. Given a property $P$ and a well-ordered set$(A, \leq)$, to prove$P(a)$ for all$a \in A$ it suffices to show: for every$a \in A$, if$P(b)$ holds for all$b < a$ (the inductive hypothesis) then$P(a)$ holds. This is valid because if$P$ fails for some$a$, the set$\{a \in A \mid \neg P(a)\}$ has a minimum element, and the inductive step applied to this minimum yields a contradiction. Transfinite induction underlies the construction of the real numbers from Cauchy sequences, the theory of ordinal and cardinal arithmetic, and many arguments in algebra involving "minimal counterexamples."
\end{remark}

**Example 1.** Show directly (without invoking WO) that $\mathbb{Q}^{+}$ can be well-ordered.

Since $\mathbb{Q}^{+}$ is countably infinite, there is a bijection$f \colon \mathbb{N} \to \mathbb{Q}^{+}$. Define a total order on$\mathbb{Q}^{+}$ by$q \prec r$ iff$f^{-1}(q) < f^{-1}(r)$ in$\mathbb{N}$. This is a well-ordering: the$\prec$-minimum of any non-empty$S \subseteq \mathbb{Q}^{+}$ is$f(m)$ where$m = \min_{n \in \mathbb{N}} \{f^{-1}(s) \mid s \in S\}$, which exists since non-empty subsets of$\mathbb{N}$ have minima. This shows every countable set can be well-ordered using only countable choice, not the full WO.

**Example 2.** Use the Well-Ordering Theorem to prove the Axiom of Choice.

Given non-empty sets $\{A_{i}\}_{i \in I}$, well-order$U = \bigcup_{i \in I} A_{i}$ by a well-ordering$\leq$. Define$f(i) = \min_{\leq}(A_{i})$, the minimum element of$A_{i}$ with respect to$\leq$. Since each$A_{i}$ is a non-empty subset of the well-ordered set$U$, it has a minimum element, so$f(i)$ is well-defined. The function$f \colon I \to U$ with$f(i) \in A_{i}$ is the desired choice function.

**Example 3.** Show that the ordinary ordering of $\mathbb{Z}$ is not a well-ordering, and that$\mathbb{Z}$ can nevertheless be well-ordered.

The set $\mathbb{Z}_{<0} = \{-1,-2,-3,\ldots\}$ is a non-empty subset of$\mathbb{Z}$ with no minimum under$\leq$, so$\leq$ is not a well-ordering. However, the ordering induced by the bijection$f \colon \mathbb{N} \to \mathbb{Z}$ (from Example 3 of Section 3.1.3) is a well-ordering:$a \prec b$ iff$f^{-1}(a) < f^{-1}(b)$ in$\mathbb{N}$. Under this ordering, the sequence is$0, 1, -1, 2, -2, 3, -3, \ldots$, and every non-empty subset has a first element in this listing.

**Example 4.** State the principle of transfinite induction and explain why it follows from well-ordering.

Let $(A, \leq)$ be a well-ordered set and$P$ a property of elements of$A$. Suppose: for every$a \in A$, if$P(b)$ holds for all$b < a$, then$P(a)$ holds. Conclude:$P(a)$ holds for all$a \in A$. Proof: suppose not. Let$S = \{a \in A \mid \neg P(a)\}$. Since$(A, \leq)$ is a well-ordering and$S$ is non-empty,$S$ has a minimum element$a_{0}$. For every$b < a_{0}$,$b \notin S$, so$P(b)$ holds. By hypothesis,$P(a_{0})$ holds, contradicting$a_{0} \in S$.
