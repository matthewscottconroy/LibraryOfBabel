# 4.2.3 Examples: $F^{n}$,$M_{m \times n}(F)$,$F[x]$, Function Spaces

The power of the axiomatic definition of a vector space is most visible when we survey the range of examples it covers. The same eight axioms that describe arrows in the plane also govern matrices, polynomials, continuous functions, and solutions to differential equations. Proving a theorem once, for an abstract vector space, instantly yields a result about all of these at once. The examples in this section are not just illustrations — they are the main objects of study in large parts of mathematics, and understanding them as vector spaces opens the door to applying every tool we develop.

The most familiar example is $F^{n}$, the set of all ordered$n$-tuples$(a_1, \ldots, a_n)$ with entries in$F$. Addition is componentwise:$(a_1, \ldots, a_n) + (b_1, \ldots, b_n) = (a_1 + b_1, \ldots, a_n + b_n)$. Scalar multiplication scales each component:$\lambda(a_1, \ldots, a_n) = (\lambda a_1, \ldots, \lambda a_n)$. This is the prototype that motivates the definition, and verifying the axioms here amounts to checking arithmetic in$F$. For$F = \mathbb{R}$ and$n = 2$ or$n = 3$ we recover the geometric vectors of calculus and physics. The standard basis vectors$e_i$ (with$1$ in position$i$ and$0$ elsewhere) provide a concrete coordinate system: any vector$(a_1, \ldots, a_n) = a_1 e_1 + \cdots + a_n e_n$.

The set $M_{m \times n}(F)$ of all$m \times n$ matrices with entries in$F$ is a vector space under entry-wise addition and scalar multiplication. The zero vector is the zero matrix (all entries zero). This example shows that "vectors" need not be one-dimensional objects; they can be rectangular arrays of scalars. The space$M_{m \times n}(F)$ has dimension$mn$: the elementary matrices$E_{ij}$ (with$1$ in position$(i,j)$ and$0$ elsewhere) form a basis. The important special case$M_{n \times n}(F)$ of square matrices carries additional structure — multiplication of matrices — making it a ring, but as a vector space it simply has dimension$n^2$.

Polynomials over $F$ provide an infinite-dimensional example that is still concretely tractable. The set$F[x]$ of all polynomials in one variable with coefficients in$F$ is a vector space under the usual addition of polynomials and multiplication of a polynomial by a scalar. If we restrict to polynomials of degree at most$n$, we get a finite-dimensional subspace$F[x]_{\leq n}$ of dimension$n+1$: the monomials$1, x, x^2, \ldots, x^n$ form a basis, since any polynomial of degree at most$n$ is uniquely a linear combination of these. The full polynomial ring$F[x]$ is infinite-dimensional, with the countable set$\{1, x, x^2, x^3, \ldots\}$ as a basis (in the algebraic sense of a Hamel basis).

Perhaps the most striking examples are the **function spaces**. The set of all continuous functions $f: [a,b] \to \mathbb{R}$ is a vector space: you can add two continuous functions and scale one by a real number, and the result is again continuous. The zero vector is the constant function$0$. This space is infinite-dimensional — no finite set of continuous functions spans all of them. More algebraically, the solution set of any homogeneous linear ordinary differential equation with continuous coefficients forms a vector space. The equation$y'' + y = 0$ has solution space$\{A\cos x + B\sin x \mid A, B \in \mathbb{R}\}$, a two-dimensional space with basis$\{\cos x, \sin x\}$. The dimension equals the order of the equation, a consequence of the existence and uniqueness theorem for ODEs.

The connection between differential equations and linear algebra runs deep. The derivative operator $D$ and the solution spaces it creates belong to the same conceptual framework as matrices and their null spaces. What looks like analysis is at its core linear algebra over a function space. This connection motivates the study of linear operators on infinite-dimensional spaces in functional analysis.

**Example 1.** Show that $\{(x, y, z) \in \mathbb{R}^{3} \mid x + 2y - z = 0\}$ is a vector space (as a subspace of$\mathbb{R}^{3}$). The zero vector$(0,0,0)$ satisfies the equation. If$(x_1, y_1, z_1)$ and$(x_2, y_2, z_2)$ satisfy it, then$(x_1 + x_2) + 2(y_1 + y_2) - (z_1 + z_2) = (x_1 + 2y_1 - z_1) + (x_2 + 2y_2 - z_2) = 0 + 0 = 0$, so their sum satisfies it. Scalar multiples clearly satisfy it. This is a$2$-dimensional subspace with basis$\{(-2, 1, 0), (1, 0, 1)\}$.

**Example 2.** The set $P_3 = \mathbb{R}[x]_{\leq 3}$ of polynomials of degree at most$3$ is a vector space of dimension$4$ over$\mathbb{R}$. A basis is$\{1, x, x^2, x^3\}$. Alternatively, the set$\{1, x-1, (x-1)^2, (x-1)^3\}$ is also a basis (shifted monomials centered at$1$), useful for Taylor expansion around$x = 1$. Both span the same space, but give different coordinate representations of each polynomial.

**Example 3.** The set of $2 \times 2$ symmetric matrices over$\mathbb{R}$ is a vector space under the usual matrix operations. A matrix$A = \begin{pmatrix} a & b \\ b & d \end{pmatrix}$ is determined by three free parameters$(a, b, d)$, so this space has dimension$3$. A basis is$\left\{ \begin{pmatrix}1&0\\0&0\end{pmatrix}, \begin{pmatrix}0&1\\1&0\end{pmatrix}, \begin{pmatrix}0&0\\0&1\end{pmatrix} \right\}$. The sum of two symmetric matrices is symmetric, and a scalar multiple of a symmetric matrix is symmetric, confirming it is a vector space.

**Example 4.** Consider the set $V = \mathbb{R}^{+}$ (positive real numbers) with "addition"$u \oplus v = uv$ (ordinary multiplication) and "scalar multiplication"$\lambda \odot v = v^{\lambda}$. Check the axioms: the "zero vector" is$1$ (since$v \cdot 1 = v$), and "addition" is abelian since multiplication is commutative. The scalar multiplication axioms:$\lambda \odot (u \oplus v) = (uv)^{\lambda} = u^{\lambda} v^{\lambda} = (\lambda \odot u) \oplus (\lambda \odot v)$;$((\lambda + \mu) \odot v) = v^{\lambda+\mu} = v^{\lambda} v^{\mu} = (\lambda \odot v) \oplus (\mu \odot v)$;$(\lambda\mu) \odot v = v^{\lambda\mu} = (v^{\mu})^{\lambda} = \lambda \odot (\mu \odot v)$; and$1 \odot v = v^1 = v$. All axioms hold! This exotic example shows the vector space axioms allow quite unexpected models.

**Example 5.** The solution space of $y'' - y' - 2y = 0$. The characteristic equation is$r^2 - r - 2 = (r-2)(r+1) = 0$, giving roots$r = 2$ and$r = -1$. The general solution is$y = Ae^{2x} + Be^{-x}$, a two-dimensional real vector space with basis$\{e^{2x}, e^{-x}\}$. One checks:$e^{2x}$ satisfies the equation (substitute:$4e^{2x} - 2e^{2x} - 2e^{2x} = 0$, yes), as does$e^{-x}$ (substitute:$e^{-x} + e^{-x} - 2e^{-x} = 0$, yes). Any linear combination$Ae^{2x} + Be^{-x}$ satisfies it by linearity of differentiation.
