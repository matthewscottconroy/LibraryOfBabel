# 4.2.4 The Zero Space and Trivial Examples

Among all vector spaces over a field $F$, the smallest possible example is the **zero space**$\{\mathbf{0}\}$, consisting of just the zero vector. It satisfies all the axioms with scalar multiplication defined by$\lambda \cdot \mathbf{0} = \mathbf{0}$ for all$\lambda \in F$ — there is nothing else it could do, since the only vector is$\mathbf{0}$. The zero space has dimension$0$: its only basis is the empty set$\emptyset$, which spans it because every vector (that is,$\mathbf{0}$ alone) is a linear combination of no vectors, namely the empty sum. Degenerate as this looks, the zero space plays a genuine role: it is the kernel of an injective linear map, the intersection of complementary subspaces, and the image of the zero map. Any general argument must handle it cleanly.

Equally important is the observation that every field $F$ is a vector space over itself. Addition of vectors is just addition in$F$, and scalar multiplication is just multiplication in$F$. The unit element$1 \in F$ is a basis, since every$v \in F$ satisfies$v = v \cdot 1$, so this space has dimension$1$. This example connects field theory and linear algebra at their most basic level, and it generalizes: any extension field$E \supseteq F$ is automatically a vector space over$F$, and the dimension of$E$ over$F$ — called the **degree** of the field extension, written$[E : F]$ — is one of the central invariants in Galois theory. For example,$[\mathbb{C} : \mathbb{R}] = 2$ and$[\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$.

These two extremes — dimension $0$ and dimension$1$ — illuminate what the definition requires at its limits. A zero-dimensional space is not "nothing"; it is a perfectly valid vector space that simply contains only the identity element. A one-dimensional space is not "too small to be interesting"; over different fields the same underlying set can have different dimension, and the one-dimensional case already carries the entire structure of the field itself.

Another trivial-seeming but important class of examples: for any $n$-dimensional vector space$V$, the "trivial" subspaces are$\{\mathbf{0}\}$ and$V$ itself. Any theorem about subspaces must treat these as valid cases. For instance, the subspace sum formula$\dim(U + W) = \dim U + \dim W - \dim(U \cap W)$ applies when$U = \{\mathbf{0}\}$: then$U + W = W$,$U \cap W = \{\mathbf{0}\}$, and the formula gives$\dim W = 0 + \dim W - 0$, which checks out.

The zero space also makes sense of universal constructions. A linear map $T: V \to W$ always has$T(\mathbf{0}_V) = \mathbf{0}_W$; the zero map$0: V \to W$ (sending every vector to$\mathbf{0}_W$) is linear; and the identity map$\mathrm{id}_V: V \to V$ is linear. These are the "boundary" elements in the space of linear maps$\mathcal{L}(V, W)$. Keeping these trivial examples in mind prevents errors when a general theorem is applied at a boundary case.

**Example 1.** Show that $\mathbb{R}$ is a$1$-dimensional vector space over$\mathbb{R}$. Any nonzero real number$r$ is a basis:$\{r\}$ spans$\mathbb{R}$ because every$v \in \mathbb{R}$ satisfies$v = (v/r) \cdot r$, and it is independent because$\lambda r = 0$ with$r \neq 0$ forces$\lambda = 0$. So$\dim_{\mathbb{R}}\mathbb{R} = 1$.

**Example 2.** Compute $\dim_{\mathbb{Q}}\mathbb{Q}(\sqrt{2},\sqrt{3})$. We have$\mathbb{Q} \subseteq \mathbb{Q}(\sqrt{2}) \subseteq \mathbb{Q}(\sqrt{2}, \sqrt{3})$. Since$[\mathbb{Q}(\sqrt{2}) : \mathbb{Q}] = 2$ (basis$\{1, \sqrt{2}\}$) and$[\mathbb{Q}(\sqrt{2},\sqrt{3}) : \mathbb{Q}(\sqrt{2})] = 2$ (since$\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$ and$\sqrt{3}$ satisfies$x^2 - 3$), the tower law gives$[\mathbb{Q}(\sqrt{2},\sqrt{3}) : \mathbb{Q}] = 4$. A basis over$\mathbb{Q}$ is$\{1, \sqrt{2}, \sqrt{3}, \sqrt{6}\}$.

**Example 3.** Verify that the zero space $\{0\}$ satisfies the vector space axioms. The only vector is$0$; addition:$0 + 0 = 0$, associativity and commutativity trivially hold,$0$ is its own additive inverse. Scalar multiplication:$\lambda \cdot 0 = 0$ for all$\lambda$. All four scalar axioms: (VS1)$\lambda(0+0) = \lambda \cdot 0 = 0 = 0 + 0$; (VS2)$(\lambda+\mu) \cdot 0 = 0 = 0 + 0$; (VS3)$(\lambda\mu)\cdot 0 = 0 = \lambda(\mu \cdot 0)$; (VS4)$1 \cdot 0 = 0$. All hold.

**Example 4.** The vector space $F$ over$F$ has a unique basis: any single nonzero element. If$\mathcal{B} = \{a\}$ with$a \neq 0$, then$\mathrm{span}(\{a\}) = \{\lambda a \mid \lambda \in F\} = F$ (since$v = (va^{-1}) \cdot a$ for any$v$) and$\{a\}$ is independent (as$\lambda a = 0$ and$a \neq 0$ forces$\lambda = 0$). Note that$|\mathcal{B}| = 1$ regardless of whether$F$ is$\mathbb{Q}$,$\mathbb{R}$,$\mathbb{C}$, or$\mathbb{F}_{p}$ — the dimension is always$1$.

**Example 5.** Let $V = \{0\}$ and$W$ be any vector space. The unique linear map$T: V \to W$ sends$0_V \mapsto 0_W$. Its kernel is$\ker T = \{0_V\} = V$ (everything maps to zero) and its image is$\mathrm{im}\, T = \{0_W\}$ (there is nothing to map to anything else). The rank-nullity theorem gives$\dim(\ker T) + \dim(\mathrm{im}\, T) = 0 + 0 = 0 = \dim V$. The trivial space makes every formula work at the boundary.
