# 4.3.2 Examples of Subspaces; Non-Examples

The subspace test becomes most useful when we apply it to concrete sets and train our intuition for which geometric or algebraic conditions force a subset to be a subspace. The key insight is simple: a subspace must contain the origin, and it must be "straight" — closed under the linear operations — so any set with a bend, offset, or boundary that excludes the zero vector will fail. Developing fluency with this intuition is essential before moving to the more structural questions about intersections, sums, and direct decompositions.

In $\mathbb{R}^{3}$, the lines and planes that pass through the origin are subspaces. A line through the origin has the form$\{t\mathbf{v} \mid t \in \mathbb{R}\}$ for some nonzero vector$\mathbf{v}$; it contains$\mathbf{0}$ (take$t = 0$) and is clearly closed under addition and scalar multiplication by inspection. A plane through the origin can be described as the solution set of a single homogeneous linear equation$ax + by + cz = 0$; again,$\mathbf{0}$ satisfies this equation, and any linear combination of solutions is a solution by linearity of the equation in$(x,y,z)$. By contrast, a line or plane that does not pass through the origin — say, the plane$x + y + z = 1$ — fails the first condition: the zero vector$(0,0,0)$ does not satisfy the equation.

The distinction between homogeneous and inhomogeneous equations points to a general pattern. The solution set of any homogeneous linear system $A\mathbf{x} = \mathbf{0}$ is always a subspace of$F^{n}$ — this is the **null space** or **kernel** of the matrix$A$ — because the zero vector is always a solution ($A\mathbf{0} = \mathbf{0}$), and linear combinations of solutions are solutions (if$A\mathbf{u} = \mathbf{0}$ and$A\mathbf{v} = \mathbf{0}$, then$A(\lambda\mathbf{u} + \mu\mathbf{v}) = \lambda A\mathbf{u} + \mu A\mathbf{v} = \mathbf{0}$). The solution set of an inhomogeneous system$A\mathbf{x} = \mathbf{b}$ with$\mathbf{b} \neq \mathbf{0}$, by contrast, is never a subspace: the zero vector is not a solution, since$A\mathbf{0} = \mathbf{0} \neq \mathbf{b}$.

The inhomogeneous solution set is instead a **coset** of the null space — a translate of a subspace by a particular solution. If $\mathbf{x}_0$ is one solution to$A\mathbf{x} = \mathbf{b}$, then the complete solution set is$\{\mathbf{x}_0 + \mathbf{v} \mid \mathbf{v} \in \ker A\}$. This is a familiar structure: it is the exact analogue of cosets in group theory, and it appears throughout algebra whenever we solve equations in the presence of a kernel.

Non-examples are just as instructive as examples. The set $\{(x, y) \in \mathbb{R}^{2} \mid xy = 0\}$ (the union of the two coordinate axes) fails (S2):$(1,0)$ and$(0,1)$ are both in the set, but$(1,0) + (0,1) = (1,1)$ is not. The set$\{(x, y) \in \mathbb{R}^{2} \mid x \geq 0\}$ (the right half-plane) fails (S3):$(1, 0)$ is in the set, but$(-1)(1,0) = (-1, 0)$ is not. The set$\{(x, y) \in \mathbb{R}^{2} \mid x + y = 1\}$ (a line not through the origin) fails (S1). Recognizing which condition fails, and why, builds intuition about the geometry of subspaces.

**Example 1.** Identify all subspaces of $\mathbb{R}^{2}$. They are:$\{\mathbf{0}\}$ (dimension$0$), all lines through the origin$\{t\mathbf{v} \mid t \in \mathbb{R}\}$ for nonzero$\mathbf{v}$ (dimension$1$), and$\mathbb{R}^{2}$ itself (dimension$2$). There are no others: any subspace$W$ with a nonzero vector$\mathbf{v}$ contains the line through$\mathbf{v}$; if$W$ also contains a vector$\mathbf{w}$ not on that line, then$W$ contains all linear combinations$a\mathbf{v} + b\mathbf{w}$, which by linear independence of$\mathbf{v}$ and$\mathbf{w}$ span all of$\mathbb{R}^{2}$.

**Example 2.** Is the set of $2 \times 2$ invertible matrices a subspace of$M_{2 \times 2}(\mathbb{R})$? No: the zero matrix is not invertible, so (S1) fails immediately. Alternatively, the sum of two invertible matrices need not be invertible:$I + (-I) = 0$, which is not invertible.

**Example 3.** Let $V = \mathcal{C}(\mathbb{R})$ (continuous functions$\mathbb{R} \to \mathbb{R}$) and$W = \{f \in \mathcal{C}(\mathbb{R}) \mid f(0) = f(1)\}$. This is a subspace: the zero function satisfies$0(0) = 0 = 0(1)$; if$f(0) = f(1)$ and$g(0) = g(1)$, then$(f+g)(0) = f(0)+g(0) = f(1)+g(1) = (f+g)(1)$; and$(\lambda f)(0) = \lambda f(0) = \lambda f(1) = (\lambda f)(1)$. So$W$ is a subspace.

**Example 4.** The set $W = \{(x, y, z) \in \mathbb{R}^{3} \mid x^2 = y^2\}$ consists of all points with$|x| = |y|$. Geometrically, this is the union of the planes$x = y$ and$x = -y$. Check (S2):$(1, 1, 0) \in W$ (since$1^2 = 1^2$) and$(1, -1, 0) \in W$ (since$1^2 = (-1)^2$), but their sum$(2, 0, 0) \notin W$ (since$4 \neq 0$). So$W$ is not a subspace.

**Example 5.** The column space of a matrix $A \in M_{m \times n}(F)$ is the subspace$\mathrm{col}(A) = \{Ax \mid x \in F^{n}\} \subseteq F^{m}$. This is the image of the linear map$x \mapsto Ax$, hence a subspace. Concretely,$\mathrm{col}(A) = \mathrm{span}(\text{columns of } A)$. For example, if$A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$, then$\mathrm{col}(A) = \mathrm{span}\left\{\begin{pmatrix}1\\3\end{pmatrix}, \begin{pmatrix}2\\4\end{pmatrix}\right\} = \mathbb{R}^{2}$ (the columns are linearly independent). For a matrix with proportional columns, the column space has dimension$1$.
