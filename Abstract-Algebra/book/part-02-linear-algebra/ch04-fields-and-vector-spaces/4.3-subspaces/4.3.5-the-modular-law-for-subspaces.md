# 4.3.5 The Modular Law for Subspaces

When three subspaces interact, the relationship between their intersections and sums is governed by a classical identity. The **modular law** states: if $A$,$B$,$C$ are subspaces of a vector space$V$ with$A \subseteq B$, then

$$B \cap (A + C) = A + (B \cap C).$$

This might look like a routine set identity, but it is not — the analogous statement without the hypothesis $A \subseteq B$ is false in general. The inclusion$A + (B \cap C) \subseteq B \cap (A + C)$ holds for any three subspaces (we verify this below), but equality requires the nesting condition.

Let us prove the modular law under the assumption $A \subseteq B$. The containment$A + (B \cap C) \subseteq B \cap (A + C)$ is always valid: if$x = a + d$ with$a \in A$ and$d \in B \cap C$, then$x \in A + C$ (since$d \in C$) and$x \in B$ (since$a \in A \subseteq B$ and$d \in B$). For the reverse inclusion, take$x \in B \cap (A + C)$. Write$x = a + c$ with$a \in A$ and$c \in C$. Since$A \subseteq B$ we have$a \in B$, and$c = x - a \in B$ (as$x \in B$ and$a \in B$). So$c \in B \cap C$. Then$x = a + c$ with$a \in A$ and$c \in B \cap C$, so$x \in A + (B \cap C)$. Both inclusions hold, giving equality.

To see why the hypothesis matters, consider what happens without it. In $\mathbb{R}^{3}$, take$A = \mathrm{span}\{e_1\}$,$C = \mathrm{span}\{e_2\}$, and$B = \mathrm{span}\{e_2, e_3\}$. Then$A \not\subseteq B$. We compute:
\begin{align*}
B \cap (A + C) &= \mathrm{span}\{e_2, e_3\} \cap \mathrm{span}\{e_1, e_2\} = \mathrm{span}\{e_2\}, \\
A + (B \cap C) &= \mathrm{span}\{e_1\} + (\mathrm{span}\{e_2, e_3\} \cap \mathrm{span}\{e_2\}) = \mathrm{span}\{e_1\} + \mathrm{span}\{e_2\} = \mathrm{span}\{e_1, e_2\}.
\end{align*}
These are different: $\mathrm{span}\{e_2\} \neq \mathrm{span}\{e_1, e_2\}$. The law fails without$A \subseteq B$.

The modular law is the vector space instance of a general identity that holds in any **modular lattice** — a partially ordered set in which the lattice operations satisfy this law. The lattice of subspaces of $V$, ordered by inclusion, is indeed modular (though not distributive in general). The same identity holds in the lattice of subgroups of an abelian group, in the lattice of ideals of a ring, and in the lattice of submodules of any module. Recognizing the modular law in these contexts allows us to apply the same lattice-theoretic reasoning across all of them.

The distinction between modular and distributive lattices is worth noting. A distributive lattice satisfies $A \cap (B + C) = (A \cap B) + (A \cap C)$ without any nesting hypothesis, but the lattice of subspaces fails this in general. Take$A = \mathrm{span}\{e_1 + e_2\}$,$B = \mathrm{span}\{e_1\}$,$C = \mathrm{span}\{e_2\}$ in$\mathbb{R}^{2}$: then$A \cap (B + C) = A \cap \mathbb{R}^{2} = A$, but$(A \cap B) + (A \cap C) = \{\mathbf{0}\} + \{\mathbf{0}\} = \{\mathbf{0}\} \neq A$. So subspace lattices are modular but not distributive.

In practice, the modular law is most often used to control dimensions in more complex configurations than the basic formula $\dim(U + W) = \dim U + \dim W - \dim(U \cap W)$. It also appears in the proof of the Jordan–Hölder theorem and in the study of composition series, where one needs to compare submodules nested inside each other. The law is, in a precise sense, the minimal additional structure that a lattice of subobjects must have for the isomorphism theorems to go through cleanly.

**Example 1.** Verify the modular law with $A = \mathrm{span}\{e_1\}$,$B = \mathrm{span}\{e_1, e_2\}$,$C = \mathrm{span}\{e_2, e_3\}$ in$\mathbb{R}^{3}$. Here$A \subseteq B$. Compute:$A + C = \mathrm{span}\{e_1, e_2, e_3\} = \mathbb{R}^{3}$, so$B \cap (A + C) = B = \mathrm{span}\{e_1, e_2\}$. Also$B \cap C = \mathrm{span}\{e_2\}$, so$A + (B \cap C) = \mathrm{span}\{e_1\} + \mathrm{span}\{e_2\} = \mathrm{span}\{e_1, e_2\} = B$. The two sides agree.

**Example 2.** Verify the modular law for polynomials. Let $A = \mathrm{span}\{1\}$,$B = \mathrm{span}\{1, x\}$,$C = \mathrm{span}\{x, x^2\}$ in$\mathbb{R}[x]_{\leq 2}$. Note$A \subseteq B$. Then$A + C = \mathrm{span}\{1, x, x^2\} = \mathbb{R}[x]_{\leq 2}$, so$B \cap (A + C) = B$. And$B \cap C = \mathrm{span}\{x\}$, so$A + (B \cap C) = \mathrm{span}\{1, x\} = B$. Both sides equal$B$.

**Example 3.** Use the modular law to prove: if $A \subseteq B$ and$A + C = B + C$, then$A + (B \cap C) = B + (A \cap C)$. By the modular law (with$A \subseteq B$):$A + (B \cap C) = B \cap (A + C) = B \cap (B + C) = B$ (since$B \subseteq B + C$). Also$A \cap C \subseteq B \cap C$ (as$A \subseteq B$), so$B + (A \cap C) \subseteq B + (B \cap C) = B$. And$B = A + (B \cap C) \subseteq B + (A \cap C)$ since$A \subseteq B$. So both sides equal$B$.

**Example 4.** Show that the lattice of subgroups of $\mathbb{Z}/12\mathbb{Z}$ is modular. The subgroups (by Lagrange's theorem) are$\langle 0 \rangle$,$\langle 6 \rangle \cong \mathbb{Z}/2\mathbb{Z}$,$\langle 4 \rangle \cong \mathbb{Z}/3\mathbb{Z}$,$\langle 3 \rangle \cong \mathbb{Z}/4\mathbb{Z}$,$\langle 2 \rangle \cong \mathbb{Z}/6\mathbb{Z}$, and$\mathbb{Z}/12\mathbb{Z}$ itself. Take$A = \langle 6 \rangle \subseteq B = \langle 2 \rangle$ and$C = \langle 4 \rangle$. Then$B \cap (A + C)$:$A + C = \langle 6, 4 \rangle = \langle \gcd(6,4) \rangle = \langle 2 \rangle = B$ (since$6 = 3 \cdot 2$ and$4 = 2 \cdot 2$), so$B \cap (A + C) = B = \langle 2 \rangle$. And$A + (B \cap C) = \langle 6 \rangle + (\langle 2 \rangle \cap \langle 4 \rangle) = \langle 6 \rangle + \langle 4 \rangle = \langle 2 \rangle = B$. The law holds.

**Example 5.** Demonstrate that the Dedekind modular identity gives a dimension formula. Suppose $A \subseteq B$ with$\dim A = a$,$\dim B = b$,$\dim C = c$,$\dim(B \cap C) = k$. Then$\dim(B \cap (A + C)) = \dim(A + (B \cap C)) = \dim A + \dim(B \cap C) - \dim(A \cap (B \cap C)) = a + k - \dim(A \cap C)$ (using$A \subseteq B$ so$A \cap B \cap C = A \cap C$). The modular law ensures this computation is consistent regardless of which side we compute from.
