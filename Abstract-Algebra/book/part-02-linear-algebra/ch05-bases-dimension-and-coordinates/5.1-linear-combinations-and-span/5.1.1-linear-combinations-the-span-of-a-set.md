# 5.1.1 Linear Combinations; the Span of a Set

The most basic thing we can do with a collection of vectors is form weighted sums of them. Given vectors $v_1, \ldots, v_k$ in a vector space$V$ over a field$F$, a **linear combination** of these vectors is any expression of the form$a_1 v_1 + a_2 v_2 + \cdots + a_k v_k$, where each coefficient$a_i$ belongs to$F$. The coefficients may be anything — zero, negative, irrational — the only restriction is that they come from the field. A linear combination with all coefficients zero yields the zero vector; this is the **trivial** linear combination. Any other combination is nontrivial.

The reason linear combinations are the fundamental object of study is that they are exactly what the vector space axioms allow us to compute. The axioms guarantee we can add vectors and scale them; composing these operations gives linear combinations, and the axioms ensure the result is well-defined and still lies in $V$. Every other construction in linear algebra — span, independence, bases, linear maps — is defined in terms of linear combinations.

\begin{definition}
The \textbf{span} of a set $S \subseteq V$, written$\mathrm{span}(S)$, is the collection of all linear combinations of elements of$S$:
$$\mathrm{span}(S) = \left\{ \sum_{i=1}^{k} a_i v_i \;\middle|\; k \geq 0,\; v_i \in S,\; a_i \in F \right\}.$$
When $S = \{v_1, \ldots, v_k\}$ is finite, this simplifies to$\mathrm{span}(S) = \{a_1 v_1 + \cdots + a_k v_k \mid a_i \in F\}$.
\end{definition}

The span of the empty set is defined to be $\{\mathbf{0}\}$, the trivial subspace. This is the right convention: the empty sum of vectors should be zero (the "no-term" linear combination evaluates to the additive identity), and the smallest subspace containing nothing should be as small as possible.

Notice that $\mathrm{span}(S)$ is always a subspace of$V$: it contains the zero vector (take all coefficients equal to zero), it is closed under addition (adding two linear combinations yields another linear combination of the same set), and it is closed under scalar multiplication (scaling a linear combination scales all its coefficients). So forming the span is a way of generating a subspace from a raw set of vectors.

For a single nonzero vector $v$,$\mathrm{span}(\{v\}) = \{av \mid a \in F\}$ is the line through the origin in the direction of$v$ — every point on this line is a scalar multiple of$v$. For two linearly independent vectors$v, w$ in$\mathbb{R}^{3}$, the span$\mathrm{span}(\{v,w\})$ is the plane through the origin containing both vectors. The span is the answer to the question: what can we reach by scaling and adding these vectors? It is the subspace "generated" by the given vectors.

**Example 1.** Compute $\mathrm{span}\{(1,0,0), (0,1,0)\}$ in$\mathbb{R}^{3}$. A general linear combination is$a(1,0,0) + b(0,1,0) = (a,b,0)$, with$a, b$ ranging over all reals. This is the$xy$-plane$\{(x,y,0) \mid x, y \in \mathbb{R}\}$, a two-dimensional subspace. The vector$(1,1,1)$ does not lie in this span, since no choice of$a, b$ gives$(a,b,0) = (1,1,1)$ (the third coordinate would need to be$1$ but is always$0$).

**Example 2.** In $\mathbb{R}[x]_{\leq 2}$, compute$\mathrm{span}\{1 + x,\; x + x^2\}$. A general combination is$a(1+x) + b(x+x^2) = a + (a+b)x + bx^2$. This is all polynomials$p + qx + rx^2$ where$r = b$,$q = a + b$,$p = a$; given$p$ and$r$ freely,$q = p + r$. So the span is$\{p + (p+r)x + rx^2 \mid p, r \in \mathbb{R}\} = \{p(1+x) + r(x+x^2) \mid p, r \in \mathbb{R}\}$, a two-dimensional subspace.

**Example 3.** Show that $\mathrm{span}\{(1,2), (2,4)\} = \mathrm{span}\{(1,2)\}$ in$\mathbb{R}^{2}$. The second vector$( 2,4) = 2(1,2)$ is already a scalar multiple of the first. Any combination$a(1,2) + b(2,4) = a(1,2) + 2b(1,2) = (a+2b)(1,2)$ is a scalar multiple of$(1,2)$. Conversely,$c(1,2) = c(1,2) + 0(2,4)$ lies in the two-vector span. So both spans are the same line through the origin.

**Example 4.** Determine whether $(3, 1, 4) \in \mathrm{span}\{(1,0,1), (0,1,2)\}$ in$\mathbb{R}^{3}$. We need$a(1,0,1) + b(0,1,2) = (3,1,4)$, giving the system$a = 3$,$b = 1$,$a + 2b = 4$. Substituting:$3 + 2(1) = 5 \neq 4$. The system is inconsistent, so$(3,1,4)$ is not in the span.

**Example 5.** In $M_{2 \times 2}(\mathbb{R})$, find$\mathrm{span}\left\{ \begin{pmatrix}1&0\\0&0\end{pmatrix}, \begin{pmatrix}0&0\\0&1\end{pmatrix} \right\}$. A general combination$a\begin{pmatrix}1&0\\0&0\end{pmatrix} + b\begin{pmatrix}0&0\\0&1\end{pmatrix} = \begin{pmatrix}a&0\\0&b\end{pmatrix}$. This is exactly the set of diagonal$2 \times 2$ matrices, a two-dimensional subspace of the four-dimensional space$M_{2 \times 2}(\mathbb{R})$.
