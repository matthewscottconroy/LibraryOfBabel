# 5.1.2 Span as the Smallest Subspace; Spanning Sets

We just saw that $\mathrm{span}(S)$ is always a subspace. But it is more than just a subspace — it is the *smallest* subspace containing$S$. This minimal property is a universal property, and it characterizes the span completely. Understanding the span through this lens connects linear algebra to a broader algebraic pattern: in group theory, the subgroup generated by a set is the smallest subgroup containing it; in ring theory, the ideal generated by a set is the smallest ideal. The span is the vector-space instance of this construction.

\begin{proposition}
$\mathrm{span}(S)$ is the smallest subspace of$V$ containing$S$: equivalently,$\mathrm{span}(S) = \bigcap \{W \subseteq V \text{ subspace} \mid S \subseteq W\}$.
\end{proposition}

\begin{proof}
We showed $\mathrm{span}(S)$ is itself a subspace containing$S$. Now suppose$W$ is any subspace with$S \subseteq W$. Since$W$ is closed under addition and scalar multiplication, every linear combination of elements of$S$ must also lie in$W$. So$\mathrm{span}(S) \subseteq W$. This shows$\mathrm{span}(S)$ is contained in every subspace containing$S$, hence in their intersection. But$\mathrm{span}(S)$ itself is in this intersection (it is a subspace containing$S$), so it equals the intersection.
\end{proof}

The characterization of span as an intersection is important in proofs: to show $\mathrm{span}(S) \subseteq W$ for a subspace$W$, it suffices to check$S \subseteq W$ and that$W$ is indeed a subspace. We never need to verify every linear combination explicitly; containment of generators plus the subspace property does all the work.

\begin{definition}
We say that $S$ \textbf{spans}$V$, or that$S$ is a \textbf{spanning set} for$V$, if$\mathrm{span}(S) = V$. This means every vector in$V$ can be written as a linear combination of elements of$S$.
\end{definition}

Finding efficient spanning sets — ones that are as small as possible — is the central organizing problem of this chapter. A spanning set that is also as economical as possible, with no redundant vectors, is precisely a basis. The reduction process that removes unnecessary vectors from a spanning set is the subject of the next subsection.

Given a spanning set $S$, the fact that$\mathrm{span}(S) = V$ tells us every vector in$V$ is "reachable" from$S$. But the spanning set may contain redundancies: some vectors in$S$ might already be in the span of the rest of$S$. Identifying and removing these redundancies is both computationally and theoretically useful. The resulting minimal spanning set is a basis, and once we have a basis we can compute coordinates, define linear maps unambiguously, and count dimension.

The relationship between spanning and generation should be seen clearly: $\mathrm{span}(S)$ is the subspace generated by$S$, and$S$ spans$V$ when the generated subspace is all of$V$. Different generating sets for the same subspace are equally valid — the subspace is intrinsic, while the choice of generators is a matter of convenience.

**Example 1.** Show that $\{e_1, e_2, e_3\} = \{(1,0,0), (0,1,0), (0,0,1)\}$ spans$\mathbb{R}^{3}$. Any vector$(a,b,c) = ae_1 + be_2 + ce_3$, so every vector is a linear combination of$e_1, e_2, e_3$. This spanning set is the standard basis.

**Example 2.** Show that $\{(1,1), (1,-1)\}$ spans$\mathbb{R}^{2}$. We need to solve$a(1,1) + b(1,-1) = (x,y)$ for arbitrary$(x,y)$: this gives$a + b = x$ and$a - b = y$, so$a = (x+y)/2$ and$b = (x-y)/2$. Since these are valid (defined for all$x, y \in \mathbb{R}$), the set spans$\mathbb{R}^{2}$.

**Example 3.** Find a spanning set for the null space of $A = \begin{pmatrix} 1 & 2 & 3 \\ 0 & 0 & 0 \end{pmatrix}$. The equation$Ax = 0$ gives$x_1 + 2x_2 + 3x_3 = 0$, so$x_1 = -2x_2 - 3x_3$. Setting$(x_2, x_3) = (1, 0)$ gives$(-2, 1, 0)$; setting$(x_2, x_3) = (0, 1)$ gives$(-3, 0, 1)$. The null space is$\mathrm{span}\{(-2,1,0), (-3,0,1)\}$, a two-dimensional subspace.

**Example 4.** Show that the set $\{1, x-1, (x-1)^2\}$ spans$\mathbb{R}[x]_{\leq 2}$ by expressing$1$,$x$,$x^2$ in terms of it. We have$1 = 1$,$x = 1 + (x-1)$,$x^2 = 1 + 2(x-1) + (x-1)^2$. So the standard basis$\{1, x, x^2\}$ lies in the span of$\{1, x-1, (x-1)^2\}$, hence the set spans$\mathbb{R}[x]_{\leq 2}$.

**Example 5.** Determine the smallest subspace of $M_{2 \times 2}(\mathbb{R})$ containing$A = \begin{pmatrix}1&1\\0&0\end{pmatrix}$ and$B = \begin{pmatrix}0&0\\1&1\end{pmatrix}$. It is$\mathrm{span}\{A, B\} = \{aA + bB \mid a, b \in \mathbb{R}\} = \left\{\begin{pmatrix}a&a\\b&b\end{pmatrix} \mid a, b \in \mathbb{R}\right\}$, the set of matrices with equal entries in each row. This is a two-dimensional subspace of$M_{2 \times 2}(\mathbb{R})$, and it is the smallest subspace containing both$A$ and$B$.
