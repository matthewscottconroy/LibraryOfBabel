# 5.1.3 Reducing a Spanning Set

A spanning set can be wasteful. If one of the vectors in the set is already a linear combination of the others, it contributes nothing new to the span, and we can remove it without losing coverage. This observation leads to a simple but important algorithm for extracting a basis from any finite spanning set. The procedure is constructive — it terminates in finitely many steps and produces an explicit minimal spanning set.

The key observation is: if $v_j \in \mathrm{span}(v_1, \ldots, \hat{v}_j, \ldots, v_m)$ (the hat indicates omission), then$\mathrm{span}(v_1, \ldots, v_m) = \mathrm{span}(v_1, \ldots, \hat{v}_j, \ldots, v_m)$. One inclusion is trivial (the right set is a subset of the left). For the other: any linear combination$\sum a_i v_i$ involving$v_j$ can be rewritten by substituting the expression for$v_j$ in terms of the other vectors, obtaining a combination of the remaining vectors. So removing$v_j$ does not shrink the span.

The reduction algorithm works as follows. Given a finite spanning set $\{v_1, \ldots, v_m\}$ for$V$, scan through the vectors:

\begin{enumerate}
\item Check whether $v_1 = \mathbf{0}$. If so, remove it (the zero vector adds nothing to any span).
\item For each subsequent $v_j$, check whether$v_j \in \mathrm{span}(v_1, \ldots, v_{j-1})$. If yes, remove$v_j$. If no, retain it.
\item Repeat until the list cannot be shortened.
\end{enumerate}

The algorithm terminates because each step strictly reduces the number of vectors, and the original set is finite. The key claim is that removing a redundant vector truly does not change the span, which we argued above. After the algorithm halts, the resulting set $\{u_1, \ldots, u_k\}$ spans$V$ (span was preserved at each step) and is linearly independent (if it were dependent, some$u_j$ would be in the span of its predecessors, contradicting the fact that the algorithm did not remove it). A spanning set that is also independent is exactly a basis.

This gives us a practical method: any finite spanning set contains a basis as a subset, and the reduction algorithm finds one. Moreover, the algorithm shows that in any finite-dimensional space, a basis can always be extracted from a given spanning set — we need not construct a basis from scratch.

There is also a dual process: starting from an independent set, we can add vectors one at a time (from outside the current span) until the set spans all of $V$. The two processes — reduce from a spanning set, extend from an independent set — are the two complementary ways to arrive at a basis, and both will be used throughout the chapter.

**Example 1.** Reduce $\{(1,0,0), (0,1,0), (2,3,0)\}$ in$\mathbb{R}^{3}$ to a basis (of its span). Check: is$(2,3,0) \in \mathrm{span}\{(1,0,0),(0,1,0)\}$? Yes:$(2,3,0) = 2(1,0,0) + 3(0,1,0)$. Remove$(2,3,0)$. The set$\{(1,0,0),(0,1,0)\}$ is independent (neither is a scalar multiple of the other) and spans the$xy$-plane. This is a basis for$\mathrm{span}$ of the original set.

**Example 2.** Reduce $\{v_1, v_2, v_3, v_4\} = \{(1,2,3), (2,4,6), (1,0,1), (2,2,4)\}$ in$\mathbb{R}^{3}$. Is$v_2 \in \mathrm{span}\{v_1\}$? Yes:$v_2 = 2v_1$. Remove$v_2$. Now check$v_3 = (1,0,1) \in \mathrm{span}\{v_1\} = \{t(1,2,3)\}$? We need$(1,0,1) = t(1,2,3)$, so$t = 1$ from the first entry, but$2t = 0$ gives$t = 0$. Contradiction. Retain$v_3$. Check$v_4 = (2,2,4) \in \mathrm{span}\{v_1, v_3\}$? Need$a(1,2,3) + b(1,0,1) = (2,2,4)$: from row 2,$2a = 2$ so$a = 1$; from row 1,$1 + b = 2$ so$b = 1$; check row 3:$3 + 1 = 4$. Yes! Remove$v_4$. Result: basis$\{(1,2,3),(1,0,1)\}$ for the span (which is a$2$-dimensional subspace of$\mathbb{R}^{3}$).

**Example 3.** Reduce $\{1+x, x+x^2, 1+x^2, 2+x+x^2\}$ in$\mathbb{R}[x]_{\leq 2}$. Let$p_1 = 1+x$,$p_2 = x+x^2$,$p_3 = 1+x^2$,$p_4 = 2+x+x^2$. Check$p_3 \in \mathrm{span}\{p_1, p_2\}$: need$a(1+x) + b(x+x^2) = 1+x^2$, so$a = 1$,$a + b = 0$ (giving$b = -1$), and$b = 1$. Contradiction. Retain$p_3$. Now check$p_4 \in \mathrm{span}\{p_1, p_2, p_3\}$: need$a(1+x) + b(x+x^2) + c(1+x^2) = 2+x+x^2$, so$a + c = 2$,$a + b = 1$,$b + c = 1$. Adding all three:$2(a+b+c) = 4$, so$a+b+c = 2$, giving$c = 1$,$a = 1$,$b = 0$. Check:$1(1+x) + 0 + 1(1+x^2) = 2 + x + x^2$. Yes! Remove$p_4$. Result: basis$\{1+x, x+x^2, 1+x^2\}$ for$\mathbb{R}[x]_{\leq 2}$.

**Example 4.** Show that removing a non-redundant vector does shrink the span. In $\mathbb{R}^{2}$, start with$\{(1,0),(0,1)\}$. Is$(0,1) \in \mathrm{span}\{(1,0)\}$? Only if$(0,1) = t(1,0) = (t,0)$ for some$t$, requiring$0 = 1$. No. If we removed$(0,1)$ anyway, the span would shrink from$\mathbb{R}^{2}$ to the$x$-axis. This illustrates that the reduction algorithm is correct precisely because it only removes redundant vectors.

**Example 5.** Carry out the reduction as a matrix computation. The vectors $(1,2,3)$,$(2,4,6)$,$(1,0,1)$,$(2,2,4)$ become rows of the matrix$\begin{pmatrix}1&2&3\\2&4&6\\1&0&1\\2&2&4\end{pmatrix}$. Row-reduce:$R_2 \leftarrow R_2 - 2R_1$ gives row of zeros (so$v_2$ is redundant);$R_3 \leftarrow R_3 - R_1$ gives$(0,-2,-2)$ (nonzero, so$v_3$ is independent);$R_4 \leftarrow R_4 - 2R_1$ gives$(0,-2,-2)$, which equals$R_3$, so$v_4 \in \mathrm{span}\{v_1, v_3\}$. The pivot rows after reduction correspond to the basis vectors found in Example 2.
