# 5.1 Linear Combinations and Span

The first question one asks about a set of vectors is: what can be built from them? A linear combination of vectors $v_1, \ldots, v_k \in V$ is any expression of the form $c_1 v_1 + \cdots + c_k v_k$ with coefficients $c_i \in F$. The span of the set is the collection of all such expressions — it is the set of everything reachable from $v_1, \ldots, v_k$ by scaling and adding. This section makes these informal ideas precise and establishes the span's fundamental properties.

The central fact is that the span of any set is a subspace. The proof is immediate from the subspace test: any linear combination of linear combinations is again a linear combination, so the span is closed under addition and scalar multiplication. Conversely, the span of $S$ is the smallest subspace containing $S$: it is the intersection of all subspaces that contain $S$, and this intersection is itself a subspace. This "smallest subspace" characterization is often more useful in proofs than the explicit sum formula, because it makes the span's universal property visible.

A set $S$ is called a spanning set (or generating set) for $V$ if $\mathrm{span}(S) = V$. The existence of a finite spanning set is what defines finite-dimensionality, and it is the assumption that makes everything in this chapter finite and concrete. The section observes that spanning sets can be large and redundant: adding any vector to a spanning set still yields a spanning set. The interesting question — how small can a spanning set be made? — leads directly to the notion of a basis in Section 5.3. A first step is the spanning set reduction theorem: if one vector in a spanning set is a linear combination of the others, it can be removed without losing the spanning property. By applying this iteratively, any finite spanning set can be trimmed to a minimal one.

The section also addresses a subtle point about the span of the empty set. By convention, $\mathrm{span}(\emptyset) = \{\mathbf{0}\}$, since the empty sum evaluates to the additive identity. This convention is not arbitrary: it ensures that the span operation is consistent with the subspace lattice, where the zero subspace is the bottom element. It also correctly captures the fact that the only "thing you can build" from no vectors at all is zero.
