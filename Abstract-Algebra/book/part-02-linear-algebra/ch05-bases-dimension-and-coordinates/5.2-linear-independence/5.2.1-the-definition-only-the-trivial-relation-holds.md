# 5.2.1 The Definition: Only the Trivial Relation Holds

Spanning is about coverage: can we reach every vector? But spanning alone is not enough for a basis — we also want no redundancy. Redundancy among vectors means that one of them can be expressed in terms of the others, which in turn means there is a nontrivial way to combine them to produce zero. This leads to the central definition, and the geometric intuition is clear: independent vectors point in "genuinely different directions," while dependent vectors share some direction with the others.

\begin{definition}
A finite list of vectors $v_1, \ldots, v_k$ in$V$ is \textbf{linearly independent} if the only solution to
$$a_1 v_1 + a_2 v_2 + \cdots + a_k v_k = \mathbf{0}$$
is the trivial one: $a_1 = a_2 = \cdots = a_k = 0$. The list is called \textbf{linearly dependent} if a nontrivial solution exists — that is, if some$a_i \neq 0$.
\end{definition}

The condition says, in words, that no vector in the list is a linear combination of the others. To see the equivalence: if $a_j \neq 0$, then we can solve for
$$v_j = -\frac{1}{a_j}\sum_{i \neq j} a_i v_i,$$
expressing $v_j$ as a linear combination of the rest. Conversely, if some$v_j = \sum_{i \neq j} b_i v_i$, then$v_j - \sum_{i \neq j} b_i v_i = \mathbf{0}$ is a nontrivial relation (the coefficient of$v_j$ is$1 \neq 0$).

The definition extends naturally to infinite sets: an infinite set $S$ is linearly independent if every finite subset of$S$ is linearly independent. This is the right definition because linear combinations are always finite sums — we never form infinite sums in the algebraic setting of a general vector space (as opposed to the analytic setting of a Hilbert space, where convergence allows it).

Note that the zero vector is always linearly dependent on its own: $1 \cdot \mathbf{0} = \mathbf{0}$ is a nontrivial relation. So any set containing the zero vector is automatically dependent. For a single nonzero vector$v$, the set$\{v\}$ is independent because$av = \mathbf{0}$ forces$a = 0$ (since if$a \neq 0$ then$v = a^{-1} \cdot \mathbf{0} = \mathbf{0}$, contradicting$v \neq \mathbf{0}$). For two vectors, independence means neither is a scalar multiple of the other. In$\mathbb{R}^{2}$, two vectors are dependent precisely when they are parallel — they lie on the same line through the origin. Linear independence is the algebraic condition that isolates this geometric notion of "pointing in genuinely different directions."

Testing for independence in $F^{n}$ amounts to solving a homogeneous linear system. The vectors$v_1, \ldots, v_k$ are independent if and only if the system$[v_1 \mid v_2 \mid \cdots \mid v_k]\,\mathbf{a} = \mathbf{0}$ has only the trivial solution$\mathbf{a} = \mathbf{0}$, i.e., if and only if the matrix with these vectors as columns has trivial null space, i.e., if and only if rank equals$k$. Row reduction makes this test algorithmic.

**Example 1.** Are $(1,2,3)$ and$(2,4,6)$ in$\mathbb{R}^{3}$ linearly independent? We need$a(1,2,3) + b(2,4,6) = (0,0,0)$, giving$a + 2b = 0$,$2a + 4b = 0$,$3a + 6b = 0$. All three reduce to$a + 2b = 0$, so$a = -2b$ with$b$ free. Taking$b = 1$ gives the nontrivial solution$a = -2$,$b = 1$: indeed$-2(1,2,3) + 1(2,4,6) = (0,0,0)$. The list is dependent; note$(2,4,6) = 2(1,2,3)$.

**Example 2.** Are $(1,0,0)$,$(0,1,0)$,$(0,0,1)$ linearly independent in$\mathbb{R}^{3}$? The equation$a(1,0,0) + b(0,1,0) + c(0,0,1) = (a,b,c) = (0,0,0)$ forces$a = b = c = 0$. Independent.

**Example 3.** In $\mathbb{R}[x]_{\leq 2}$, are$\{1, x, x^2\}$ independent? The equation$a \cdot 1 + b \cdot x + c \cdot x^2 = 0$ (the zero polynomial, i.e., the polynomial all of whose coefficients are$0$) requires$a = 0$,$b = 0$,$c = 0$, since a nonzero polynomial cannot be identically zero. Independent.

**Example 4.** Are $\{1, \sin^2 x, \cos^2 x\}$ linearly independent in$\mathcal{C}(\mathbb{R})$ (as real-valued functions)? The equation$a \cdot 1 + b \sin^2 x + c \cos^2 x = 0$ must hold for all$x \in \mathbb{R}$. Using the identity$\sin^2 x + \cos^2 x = 1$:$a + b\sin^2 x + c\cos^2 x = (a + c) + b\sin^2 x + (c-c)\cos^2 x$. Rewrite as$a + c + b\sin^2 x + c\cos^2 x - c(\sin^2 x + \cos^2 x) = a + b\sin^2 x + c\cos^2 x$. Setting$x = 0$:$a + c = 0$; setting$x = \pi/2$:$a + b = 0$; plugging back gives$b = c$. So$b = c$ and$a = -b$. The nontrivial solution$a = -1$,$b = c = 1$ gives$-1 + \sin^2 x + \cos^2 x = 0$. The set is **dependent**.

**Example 5.** Test independence of $\{(1,1,0), (1,0,1), (0,1,1)\}$ in$\mathbb{R}^{3}$ using a matrix. Form$A = \begin{pmatrix}1&1&0\\1&0&1\\0&1&1\end{pmatrix}$ (vectors as columns). Row reduce:$R_2 \leftarrow R_2 - R_1$ gives$\begin{pmatrix}1&1&0\\0&-1&1\\0&1&1\end{pmatrix}$; then$R_3 \leftarrow R_3 + R_2$:$\begin{pmatrix}1&1&0\\0&-1&1\\0&0&2\end{pmatrix}$. Three pivots, so rank$= 3 = k$. The only solution to$A\mathbf{a} = \mathbf{0}$ is$\mathbf{a} = \mathbf{0}$. The vectors are **independent**.
