# 5.2.2 Detecting Dependence; the Dependence Lemma

Given a dependent list of vectors, we want to know exactly which ones are redundant — that is, which ones can be expressed as a linear combination of the others. The Dependence Lemma answers this question precisely and constructively: it identifies a specific vector in the list that is a linear combination of its predecessors, and shows that removing it leaves the span unchanged.

\begin{lemma}[Dependence Lemma]
Let $V$ be a vector space over$F$, and let$(v_1, \ldots, v_k)$ be a linearly dependent list of vectors in$V$. Then there exists an index$j \in \{1, \ldots, k\}$ such that$v_j \in \mathrm{span}(v_1, \ldots, v_{j-1})$. Moreover,$\mathrm{span}(v_1, \ldots, v_k) = \mathrm{span}(v_1, \ldots, \hat{v}_j, \ldots, v_k)$, where the hat denotes omission of$v_j$.
\end{lemma}

The proof is short and illuminating. Since the list is dependent, there exist scalars $a_1, \ldots, a_k \in F$, not all zero, with$\sum_{i=1}^{k} a_i v_i = 0$. Let$j$ be the largest index for which$a_j \neq 0$. Then we can solve for$v_j$:

$$v_j = -\frac{1}{a_j} \sum_{i=1}^{j-1} a_i v_i,$$

which expresses $v_j$ as a linear combination of$v_1, \ldots, v_{j-1}$. The choice of$j$ as the largest nonzero index is deliberate: it ensures the indices$j+1, \ldots, k$ do not appear in the relation (their coefficients are zero), so the expression involves only predecessors. Now any linear combination involving$v_j$ can have$v_j$ replaced by its expression in terms of$v_1, \ldots, v_{j-1}$, so the span is preserved upon removal of$v_j$.

\begin{remark}
The convention of taking $j$ to be the largest nonzero index is not essential — any nonzero index would work for the span-preservation claim — but it gives a canonical and constructive choice. In practice, one often takes the first index at which a dependence appears, which amounts to the smallest$j$ for which$v_j \in \mathrm{span}(v_1, \ldots, v_{j-1})$.
\end{remark}

The Dependence Lemma is the mechanism behind spanning-set reduction. If we have a spanning set that is not independent, the lemma tells us which vector to remove. We iterate: after removing $v_j$, the remaining list may still be dependent, so we apply the lemma again. Since the list is finite, this process terminates in a finite number of steps with an independent spanning set — that is, a basis. This is the reduction algorithm of Section 5.1.3, now understood as a repeated application of the Dependence Lemma.

**Example 1.** Consider the list $(v_1, v_2, v_3)$ in$\mathbb{R}^3$ where$v_1 = (1, 0, 0)$,$v_2 = (0, 1, 0)$, and$v_3 = (2, 3, 0)$. Check dependence:$2v_1 + 3v_2 - v_3 = 0$, so the relation$a_1 = 2$,$a_2 = 3$,$a_3 = -1$ is nontrivial. The largest nonzero index is$j = 3$, and indeed$v_3 = 2v_1 + 3v_2 \in \mathrm{span}(v_1, v_2)$. Removing$v_3$ leaves$(v_1, v_2)$, which spans the same subspace (the$xy$-plane) and is independent.

**Example 2.** Let $V = F[x]$ be the space of polynomials over a field$F$, and consider the list$(1, x, x^2, x^2 + x + 1)$. The fourth polynomial satisfies$p_4 = p_1 + p_2 + p_3$, giving a dependence relation$-p_1 - p_2 - p_3 + p_4 = 0$ with the largest nonzero index being$j = 4$. So$p_4 \in \mathrm{span}(p_1, p_2, p_3)$, and we may remove it. The remaining list$(1, x, x^2)$ spans the same subspace (polynomials of degree at most$2$) and is independent.

**Example 3.** In $\mathbb{R}^2$, consider the three vectors$u_1 = (1, 1)$,$u_2 = (2, 2)$,$u_3 = (0, 1)$. We have$u_2 = 2u_1$, so$-2u_1 + u_2 = 0$, a nontrivial relation. The largest nonzero index is$j = 2$, and$u_2 \in \mathrm{span}(u_1)$. After removing$u_2$, we have$(u_1, u_3) = ((1,1), (0,1))$. Check:$a(1,1) + b(0,1) = (a, a+b) = 0$ forces$a = 0$ and$b = 0$, so$(u_1, u_3)$ is independent. It also spans$\mathbb{R}^2$, confirming it is a basis.

The Dependence Lemma is also the key tool in the proof of the Steinitz Exchange Lemma (Section 5.3.4), which in turn establishes that all bases of a finite-dimensional space have the same cardinality. The argument there uses the lemma to show that if an independent set is introduced into a spanning set, one can always exchange out a vector from the spanning set while preserving the spanning property — and the justification for the exchange is precisely that the exchanged vector becomes expressible in terms of the others. In this way, the Dependence Lemma sits at the foundation of the entire dimension theory of vector spaces.

\begin{proposition}
If $(v_1, \ldots, v_k)$ is linearly independent and$(v_1, \ldots, v_k, u)$ is linearly dependent, then$u \in \mathrm{span}(v_1, \ldots, v_k)$.
\end{proposition}

\begin{proof}
Since $(v_1, \ldots, v_k, u)$ is dependent, there is a nontrivial relation$\sum_{i=1}^k a_i v_i + bu = 0$. If$b = 0$, then$\sum a_i v_i = 0$ with not all$a_i$ zero, contradicting independence of$(v_1, \ldots, v_k)$. So$b \neq 0$, and solving gives$u = -b^{-1}\sum a_i v_i \in \mathrm{span}(v_1, \ldots, v_k)$.
\end{proof}

This proposition is the flip side of the Dependence Lemma: adding a vector to an independent list creates a dependence if and only if the new vector was already in the span. Together, these two facts give a complete picture of when lists are independent and when they are not, and they will be used constantly in what follows.
