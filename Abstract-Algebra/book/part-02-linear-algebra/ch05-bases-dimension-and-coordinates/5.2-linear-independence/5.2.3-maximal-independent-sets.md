# 5.2.3 Maximal Independent Sets

An independent set captures the idea of a collection of vectors with no redundancies. But independence alone says nothing about how large the set is relative to the ambient space — an independent set might span only a proper subspace, leaving room to add more vectors while preserving independence. The notion of a maximal independent set fills this gap: it is an independent set that cannot be enlarged without introducing a dependence.

\begin{definition}
A linearly independent subset $\mathcal{I} \subseteq V$ is called **maximal** (or a **maximal independent set**) if for every$v \in V \setminus \mathcal{I}$, the set$\mathcal{I} \cup \{v\}$ is linearly dependent.
\end{definition}

The key observation is that if $\mathcal{I}$ is independent and fails to span$V$, then$\mathcal{I}$ is not maximal: pick any$v \notin \mathrm{span}(\mathcal{I})$. By the proposition at the end of Section 5.2.2, if$\mathcal{I} \cup \{v\}$ were dependent, then$v$ would be in$\mathrm{span}(\mathcal{I})$, contradicting our choice. Therefore$\mathcal{I} \cup \{v\}$ is independent, and$\mathcal{I}$ was not maximal. Contrapositing: a maximal independent set must span$V$.

The converse holds as well. If $\mathcal{I}$ is independent and$\mathrm{span}(\mathcal{I}) = V$, then any$v \in V$ is a linear combination of elements of$\mathcal{I}$, so$\mathcal{I} \cup \{v\}$ is dependent (again by the proposition of Section 5.2.2). Thus$\mathcal{I}$ is maximal. Combining both directions:

\begin{proposition}
A linearly independent set $\mathcal{I} \subseteq V$ is maximal if and only if$\mathrm{span}(\mathcal{I}) = V$, i.e., if and only if$\mathcal{I}$ is a basis.
\end{proposition}

This equivalence says that the maximal independent sets are exactly the bases, and it provides an alternative entry point into the definition of basis: rather than requiring both independence and spanning separately, one can define a basis as a maximal independent set. The two formulations are equivalent, and the choice between them is largely a matter of taste. The maximal-independence formulation is particularly suited to existence arguments, because it invites the use of Zorn's Lemma.

\begin{theorem}[Existence of a Basis via Zorn's Lemma]
Every vector space has a maximal linearly independent set, and hence a basis.
\end{theorem}

\begin{proof}
Let $\mathcal{P}$ be the collection of all linearly independent subsets of$V$, partially ordered by inclusion. This poset is nonempty: the empty set (or any singleton$\{v\}$ with$v \neq 0$) is independent. Let$\mathcal{C} = \{\mathcal{I}_\alpha\}$ be a chain in$\mathcal{P}$, i.e., a totally ordered subcollection. We claim$\mathcal{I} = \bigcup_\alpha \mathcal{I}_\alpha$ is independent. Any finite subset$\{w_1, \ldots, w_r\} \subseteq \mathcal{I}$ is drawn from finitely many members$\mathcal{I}_{\alpha_1}, \ldots, \mathcal{I}_{\alpha_r}$ of the chain; since the chain is totally ordered, one of these contains all the others, so the entire finite subset lies in some single$\mathcal{I}_\alpha \in \mathcal{P}$, which is independent. Hence$\mathcal{I}$ is independent, providing an upper bound for$\mathcal{C}$ in$\mathcal{P}$. By Zorn's Lemma,$\mathcal{P}$ has a maximal element$\mathcal{B}$, which is independent by definition and spans$V$ by the proposition above.
\end{proof}

\begin{remark}
This application of Zorn's Lemma is genuinely non-constructive: for infinite-dimensional spaces like $\mathbb{R}$ over$\mathbb{Q}$, no explicit Hamel basis can be written down. The existence of a basis for every vector space is in fact equivalent to the Axiom of Choice. For finite-dimensional spaces, the constructive argument via spanning-set reduction (Section 5.1.3) is sufficient and preferable.
\end{remark}

**Example 1.** In $\mathbb{R}^3$, the set$\{e_1, e_2\}$ where$e_1 = (1,0,0)$ and$e_2 = (0,1,0)$ is independent but not maximal: adding$e_3 = (0,0,1)$ preserves independence because$e_3 \notin \mathrm{span}(e_1, e_2)$ (the$xy$-plane). The set$\{e_1, e_2, e_3\}$ is maximal: any vector$v = (a, b, c) \in \mathbb{R}^3$ satisfies$v = ae_1 + be_2 + ce_3$, so$\{e_1, e_2, e_3, v\}$ is dependent for every$v$.

**Example 2.** In $\mathbb{R}^2$, consider the set$\{(1, 1)\}$. It is independent. Is it maximal? No:$(0, 1) \notin \mathrm{span}((1,1))$ (the span is the line$y = x$), so we can add$(0,1)$ to get an independent set$\{(1,1), (0,1)\}$. This new set is maximal, since it spans$\mathbb{R}^2$.

**Example 3.** In the polynomial space $F_{\leq 2}[x]$ of polynomials of degree at most$2$, the set$\{1, x\}$ is independent but does not span:$x^2$ is not a polynomial of degree at most$1$. We add$x^2$ to get$\{1, x, x^2\}$, which is independent and spans$F_{\leq 2}[x]$, hence is maximal.

The characterization of bases as maximal independent sets does more than provide an alternative definition. It places bases into the general framework of extremal set theory: just as maximal ideals in ring theory and ultrafilters in set theory are important because they represent "complete" objects that cannot be extended, a maximal independent set is a "complete" independent family that cannot be made any larger. This perspective unifies the theory and clarifies why Zorn's Lemma is the right tool for existence. Section 5.3.2 will take up the full existence argument more carefully, but the conceptual picture should already be clear: bases exist precisely because the ordered collection of independent sets admits maximal elements.
