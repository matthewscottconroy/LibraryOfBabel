# 5.2 Linear Independence

If span asks "what can we build?", linear independence asks "is anything being counted twice?" A finite list of vectors $v_1, \ldots, v_k$ is linearly independent if the only solution to $c_1 v_1 + \cdots + c_k v_k = \mathbf{0}$ is the trivial one $c_1 = \cdots = c_k = 0$. Equivalently, no vector in the list is a linear combination of the others. Independence is the condition that every vector in the span of the list has a unique representation as a linear combination — independence eliminates ambiguity in coordinates.

The section carefully develops the theory of dependence before proving its most useful structural result. The dependence lemma states: if $v_1, \ldots, v_k$ is linearly dependent, then there exists some index $j \geq 2$ such that $v_j \in \mathrm{span}(v_1, \ldots, v_{j-1})$, and furthermore $\mathrm{span}(v_1, \ldots, v_k) = \mathrm{span}(v_1, \ldots, \hat{v}_j, \ldots, v_k)$, where the hat denotes omission. In other words, among a dependent list, we can always find a "redundant" vector that can be discarded without shrinking the span. This lemma is the engine behind the reduction of spanning sets to bases and the proof of the exchange lemma in Section 5.3.

A key observation is that independence is a property of an ordered list, not just a set, because the zero vector — which is always dependent on itself — interacts badly with independence. More precisely: any list containing the zero vector is dependent, and any sub-list of an independent list is independent. The contrapositive of the latter is useful: if adding a vector to an independent set creates a dependent set, then the new vector lies in the span of the original set.

The section concludes with the notion of maximal independent sets. An independent set $S \subseteq V$ is maximal if adding any vector $v \notin S$ to it creates a dependent set — meaning $v \in \mathrm{span}(S)$, so $S$ already spans $V$. Maximal independent sets are therefore spanning sets, and spanning independent sets are what the next section will call bases. The characterization of maximality gives a clean way to verify that a proposed basis is in fact one: check independence, then check that adding any element outside it creates dependence.
