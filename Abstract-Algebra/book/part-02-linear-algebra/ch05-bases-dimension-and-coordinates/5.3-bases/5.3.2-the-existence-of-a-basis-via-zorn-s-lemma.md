# 5.3.2 The Existence of a Basis via Zorn's Lemma

Before we can use bases freely, we need to know they exist in every vector space, not just in the examples we happen to construct by hand. For finite-dimensional spaces this is not difficult: start with any spanning set and reduce it by the algorithm of Section 5.1.3. But for infinite-dimensional spaces — such as $F[x]$ over$F$, or$\mathbb{R}$ viewed as a vector space over$\mathbb{Q}$, or any function space — a direct construction is impossible, and we need a set-theoretic principle of a fundamentally different character.

The principle required is Zorn's Lemma, which we state precisely.

\begin{theorem}[Zorn's Lemma]
Let $(P, \leq)$ be a nonempty partially ordered set in which every chain (totally ordered subset) has an upper bound in$P$. Then$P$ has at least one maximal element — an element$m \in P$ such that there is no$p \in P$ with$m < p$.
\end{theorem}

Zorn's Lemma is not provable from the axioms of Zermelo–Fraenkel set theory (ZF) alone; it is equivalent to the Axiom of Choice. This equivalence is a theorem, not an assumption. Invoking Zorn's Lemma is therefore a genuine use of a non-constructive axiom, and for the existence of bases in infinite-dimensional spaces this is unavoidable: it is known that "every vector space has a basis" implies the Axiom of Choice (over ZF), so no proof can avoid some such assumption.

\begin{theorem}[Existence of a Basis]
Every vector space $V$ over a field$F$ has a basis.
\end{theorem}

\begin{proof}
Let $\mathcal{P}$ denote the collection of all linearly independent subsets of$V$, partially ordered by inclusion. This collection is nonempty: if$V = \{0\}$ then the empty set is a basis (and$\mathcal{P} = \{\emptyset\}$); otherwise any singleton$\{v\}$ with$v \neq 0$ is independent, so$\mathcal{P}$ contains at least one nonempty element.

Let $\mathcal{C} = \{\mathcal{I}_\alpha\}_{\alpha \in A}$ be a chain in$\mathcal{P}$, i.e., a collection of independent sets totally ordered by inclusion. Define$\mathcal{I} = \bigcup_{\alpha \in A} \mathcal{I}_\alpha$. We claim$\mathcal{I} \in \mathcal{P}$, i.e., that$\mathcal{I}$ is linearly independent. Let$\{w_1, \ldots, w_r\}$ be any finite subset of$\mathcal{I}$. Each$w_k$ lies in some$\mathcal{I}_{\alpha_k}$. Since$\mathcal{C}$ is a chain, among$\mathcal{I}_{\alpha_1}, \ldots, \mathcal{I}_{\alpha_r}$ one contains all the others; say$\mathcal{I}_{\alpha_j}$ is the largest. Then$\{w_1, \ldots, w_r\} \subseteq \mathcal{I}_{\alpha_j}$, which is independent. Hence any finite subset of$\mathcal{I}$ is independent. This is exactly the definition of linear independence (which is a condition on finite subsets), so$\mathcal{I}$ is independent. The set$\mathcal{I}$ is an upper bound for$\mathcal{C}$ in$\mathcal{P}$.

Since every chain in $\mathcal{P}$ has an upper bound in$\mathcal{P}$, Zorn's Lemma yields a maximal element$\mathcal{B} \in \mathcal{P}$. By definition,$\mathcal{B}$ is linearly independent. If some$v \in V$ were not in$\mathrm{span}(\mathcal{B})$, then$\mathcal{B} \cup \{v\}$ would be independent (by the proposition of Section 5.2.2), strictly larger than$\mathcal{B}$, contradicting maximality. Therefore$\mathrm{span}(\mathcal{B}) = V$, and$\mathcal{B}$ is a basis.
\end{proof}

\begin{remark}
The proof uses independence of $V$ only implicitly, through the structure of$\mathcal{P}$. It applies uniformly to every vector space regardless of its size or the nature of its field. The basis$\mathcal{B}$ produced is an algebraic (Hamel) basis: every element of$V$ is a \emph{finite} linear combination of elements of$\mathcal{B}$. This finiteness condition is built into the definition of linear independence, which only considers finite relations.
\end{remark}

**Example 1.** For $V = F^n$, the standard basis$\{e_1, \ldots, e_n\}$ is constructed explicitly and Zorn's Lemma is not needed. But the theorem guarantees existence even in this case as a special instance of the general result.

**Example 2.** For $V = F[x]$, the monomials$\{1, x, x^2, x^3, \ldots\}$ form a Hamel basis, and this can be verified directly: they are independent (no finite nontrivial relation among distinct monomials) and span$F[x]$ (every polynomial is a finite linear combination of monomials). Zorn's Lemma is not needed here either, since we have an explicit countable basis.

**Example 3.** For $V = \mathbb{R}$ over$\mathbb{Q}$, a Hamel basis exists by the theorem, but no explicit basis can be constructed: the existence requires the Axiom of Choice in an essential way. Such a basis$\mathcal{H}$ has the property that every real number is a unique finite$\mathbb{Q}$-linear combination of elements of$\mathcal{H}$. The cardinality of$\mathcal{H}$ equals the cardinality of$\mathbb{R}$ (uncountable), since countably many rational coefficients applied to countably many basis elements can produce only countably many real numbers.

The theorem tells us that the concept of dimension is well-defined in complete generality: every vector space has a basis, and as we will see in Section 5.4.1, any two bases have the same cardinality. The existence result via Zorn's Lemma is therefore not merely an existence theorem — it is the foundation for the entire theory of dimension for arbitrary vector spaces.
