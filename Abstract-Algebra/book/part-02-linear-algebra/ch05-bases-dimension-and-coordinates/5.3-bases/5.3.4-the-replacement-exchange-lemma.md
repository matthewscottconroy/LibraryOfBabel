# 5.3.4 The Replacement (Exchange) Lemma

The Replacement Lemma, sometimes called the Steinitz Exchange Lemma, is the technical engine behind one of the most important facts in linear algebra: all bases of a finite-dimensional vector space have the same size. The lemma itself is a precise statement about the interaction between independent sets and spanning sets, and its proof is a beautiful iterative argument.

\begin{lemma}[Steinitz Exchange Lemma]
Let $V$ be a vector space over$F$. Suppose$\{v_1, \ldots, v_m\}$ spans$V$ and$\{u_1, \ldots, u_k\}$ is a linearly independent subset of$V$. Then$k \leq m$, and there exists a set of$k$ distinct indices$j_1, \ldots, j_k \in \{1, \ldots, m\}$ such that the set
\par
$$\{u_1, \ldots, u_k, v_1, \ldots, v_m\} \setminus \{v_{j_1}, \ldots, v_{j_k}\}$$
\par
still spans $V$.
\end{lemma}

\begin{proof}
We proceed by induction on $k$. For$k = 0$ there is nothing to show. Assume inductively that after introducing$u_1, \ldots, u_{k-1}$, we have exchanged out$k-1$ of the$v_i$'s to obtain a spanning set of the form$\{u_1, \ldots, u_{k-1}, v_{i_1}, \ldots, v_{i_{m-k+1}}\}$. Now introduce$u_k$. Since this set spans$V$, we can write:

$$u_k = c_1 u_1 + \cdots + c_{k-1} u_{k-1} + d_{i_1} v_{i_1} + \cdots + d_{i_{m-k+1}} v_{i_{m-k+1}}.$$

Not all $d_{i_j}$ can be zero: if they were, then$u_k$ would be a linear combination of$u_1, \ldots, u_{k-1}$, contradicting independence of$\{u_1, \ldots, u_k\}$. So some$d_{i_j} \neq 0$, say$d_{i_s} \neq 0$. We can solve for$v_{i_s}$:

$$v_{i_s} = d_{i_s}^{-1}\!\left(u_k - c_1 u_1 - \cdots - c_{k-1}u_{k-1} - \sum_{\ell \neq s} d_{i_\ell} v_{i_\ell}\right).$$

Therefore $v_{i_s}$ is in the span of$\{u_1, \ldots, u_k, v_{i_1}, \ldots, \widehat{v_{i_s}}, \ldots, v_{i_{m-k+1}}\}$, and this new set spans$V$ (any vector that previously required$v_{i_s}$ can now use$u_k$ instead). This completes the inductive step. After$k$ steps, we have used up$k$ of the$m$ available$v_i$'s, so we needed$k \leq m$.
\end{proof}

\begin{theorem}[Invariance of Basis Size]
Any two bases of a finite-dimensional vector space $V$ have the same cardinality.
\end{theorem}

\begin{proof}
Let $\mathcal{B} = \{b_1, \ldots, b_n\}$ and$\mathcal{C} = \{c_1, \ldots, c_m\}$ be two bases. Since$\mathcal{B}$ spans$V$ and$\mathcal{C}$ is independent, the Replacement Lemma gives$m \leq n$. Since$\mathcal{C}$ spans$V$ and$\mathcal{B}$ is independent, we get$n \leq m$. Therefore$n = m$.
\end{proof}

This result is the foundation on which the concept of dimension rests. Without it, "dimension" would not be well-defined — we could find a basis of size $3$ and another of size$5$ for the same space, and "3-dimensional" would mean nothing. The Replacement Lemma rules this out.

**Example 1.** In $\mathbb{R}^3$, the standard basis$\{e_1, e_2, e_3\}$ and the basis$\{(1,1,0), (0,1,1), (1,0,1)\}$ both have size$3$. This is not a coincidence: the theorem guarantees it. Let us trace one exchange step explicitly. Take the spanning set$\{e_1, e_2, e_3\}$ and introduce$u_1 = (1, 1, 0) = e_1 + e_2$. The coefficient of$e_1$ is nonzero, so we exchange$e_1$ out, yielding the spanning set$\{(1,1,0), e_2, e_3\}$. Check:$e_1 = (1,1,0) - e_2$, so any vector expressible in$\{e_1, e_2, e_3\}$ remains expressible in$\{(1,1,0), e_2, e_3\}$.

**Example 2.** Consider $\mathbb{R}^2$ with spanning set$\{(1,0), (0,1), (1,1)\}$ (three vectors,$m = 3$) and independent set$\{(1,2), (3, 4)\}$ ($k = 2$). The lemma guarantees$k = 2 \leq 3 = m$, which is satisfied. Explicitly: introduce$(1,2) = (1,0) + 2(0,1)$; exchange out$(0,1)$ since its coefficient is$2 \neq 0$. Now span with$\{(1,0), (1,2), (1,1)\}$. Introduce$(3,4) = 3(1,0) + (3,4) - 3(1,0)$; more carefully,$(3,4) = 3(1,2) - 2(1,0) + 0 \cdot (1,1)$; the coefficient of$(1,0)$ is$-2 \neq 0$, so exchange it out. Resulting span:$\{(1,2), (3,4), (1,1)\}$, which still spans$\mathbb{R}^2$.

**Example 3.** Let $V = F_{\leq 2}[x]$ with spanning set$\{1, x, x^2\}$ ($m = 3$) and independent set$\{1+x, 1+x+x^2\}$ ($k = 2$). Introduce$u_1 = 1+x = 1 \cdot 1 + 1 \cdot x + 0 \cdot x^2$; exchange out$x$ (nonzero coefficient). Spanning set becomes$\{1, 1+x, x^2\}$. Introduce$u_2 = 1+x+x^2 = 1 \cdot 1 + 0 \cdot (1+x) + 1 \cdot x^2$; exchange out$x^2$ (nonzero coefficient). Final spanning set:$\{1, 1+x, 1+x+x^2\}$, which spans$F_{\leq 2}[x]$.

The Replacement Lemma also implies a useful bound: any independent set in an $n$-dimensional space has at most$n$ elements. This is sometimes the most efficient way to prove that a set of$n$ vectors forms a basis — if the space is known to have dimension$n$, independence alone suffices (by Rank-Nullity or by the$n$-vector criterion discussed in the next subsection). The lemma thus converts dimension from a count into a tool for testing when you have "enough" or "not too many" vectors.
