# 5.3 Bases

A basis for a vector space $V$ is a linearly independent spanning set. The definition is simple, but unpacking it reveals a remarkable thing: a basis is simultaneously a minimal spanning set (remove any element and it no longer spans) and a maximal independent set (add any element and it becomes dependent). The section proves all four standard equivalent characterizations — spanning-and-independent, minimal spanning, maximal independent, and the unique-representation property — and shows that each one captures a different facet of what it means to be a reference frame for $V$.

The unique-representation property is perhaps the most important for computation: $\mathcal{B} = (b_1, \ldots, b_n)$ is a basis for $V$ if and only if every $v \in V$ can be written as $v = c_1 b_1 + \cdots + c_n b_n$ in exactly one way. The coordinates $(c_1, \ldots, c_n)$ are then completely determined by $v$ and $\mathcal{B}$. This is the property that makes a basis an "address system" for the space: every vector has a unique address, and conversely every $n$-tuple of scalars corresponds to a unique vector. The coordinate isomorphism $V \cong F^n$ formalized in Section 5.4 rests entirely on this.

The two main structural theorems of this section are the extension theorem (any linearly independent set extends to a basis) and the reduction theorem (any spanning set contains a basis). Both are proved for finite-dimensional spaces using the dependence lemma from Section 5.2. Together they guarantee that bases exist and are "efficient" in a precise sense. The exchange lemma — every independent set of size $m$ can be exchanged with $m$ elements from any basis of size $n$, with $n \geq m$ guaranteed — is the key result that makes the invariance of dimension possible.

For infinite-dimensional spaces, the existence of a basis requires the Axiom of Choice, formalized via Zorn's Lemma: in any partially ordered set, every chain has an upper bound implies the existence of a maximal element. Applied to the poset of independent subsets ordered by inclusion, this yields a maximal independent set — a Hamel basis. The section discusses this carefully, distinguishing the Hamel basis of an abstract vector space (where every element is a finite linear combination of basis elements) from the orthonormal basis of a Hilbert space (where infinite convergent series are permitted). The two notions diverge dramatically in infinite dimensions, and conflating them is a common source of confusion.
