# 5.4.1 The Invariance of Dimension: All Bases Have the Same Size

We have established that every finite-dimensional vector space has a basis, and in fact many bases. A natural question arises: can two different bases have different sizes? If so, the notion of "dimension" would be ambiguous — a space would have no single well-defined dimension. The answer is no, and this is one of the foundational results of linear algebra.

\begin{theorem}[Invariance of Dimension]
Any two bases of a vector space $V$ have the same cardinality.
\end{theorem}

For finite-dimensional spaces, the proof follows directly from the Replacement Lemma. Suppose $\mathcal{B} = \{b_1, \ldots, b_n\}$ and$\mathcal{C} = \{c_1, \ldots, c_m\}$ are both bases of$V$. Since$\mathcal{B}$ spans$V$ and$\mathcal{C}$ is independent, the Replacement Lemma gives$m \leq n$. Symmetrically, since$\mathcal{C}$ spans$V$ and$\mathcal{B}$ is independent, we get$n \leq m$. Therefore$n = m$, and the two bases have the same size.

\begin{definition}
The **dimension** of a vector space $V$, written$\dim V$ (or$\dim_F V$ when the field requires emphasis), is the common cardinality of all its bases. A vector space is **finite-dimensional** if it has a finite basis, and **infinite-dimensional** otherwise.
\end{definition}

\begin{remark}
For infinite-dimensional spaces, the invariance theorem still holds, but requires cardinal arithmetic. If $\mathcal{B}$ and$\mathcal{C}$ are two infinite bases, one shows$|\mathcal{B}| \leq |\mathcal{C}|$ and$|\mathcal{C}| \leq |\mathcal{B}|$ by a more careful exchange argument, yielding$|\mathcal{B}| = |\mathcal{C}|$ by the Schröder–Bernstein theorem. The dimension of$F[x]$ over$F$ is$\aleph_0$; the dimension of$\mathbb{R}$ over$\mathbb{Q}$ is$|\mathbb{R}| = 2^{\aleph_0}$.
\end{remark}

The invariance of dimension is remarkable because it says that the linear structure of $V$ determines a single numerical invariant — its dimension — completely independent of all coordinate choices. No matter which basis we select, we get the same count. This is what makes dimension a genuine property of the space, not of any particular description of it.

\begin{corollary}
Let $V$ be an$n$-dimensional vector space over$F$. A subset$\mathcal{B} \subseteq V$ with exactly$n$ elements is a basis if and only if it is independent (equivalently, if and only if it spans$V$).
\end{corollary}

\begin{proof}
If $\mathcal{B}$ has$n$ elements and is independent, the Replacement Lemma applied to$\mathcal{B}$ (independent) and any basis$\{b_1,\ldots,b_n\}$ (spanning) gives$n \leq n$; the full exchange argument shows$\mathcal{B}$ spans as well. The symmetric argument covers spanning.
\end{proof}

This corollary is practically invaluable: in an $n$-dimensional space, any independent set of size$n$ automatically spans, and any spanning set of size$n$ is automatically independent. We need check only one of the two conditions.

**Example 1.** $\dim \mathbb{R}^n = n$ over$\mathbb{R}$. The standard basis$\{e_1, \ldots, e_n\}$ has$n$ elements. Any other basis — such as$\{(1,0,\ldots,0), (1,1,0,\ldots,0), (1,1,1,0,\ldots,0), \ldots, (1,1,\ldots,1)\}$ — also has exactly$n$ elements.

**Example 2.** $\dim M_{m \times n}(F) = mn$ over$F$. The elementary matrices$\{E_{ij} : 1 \leq i \leq m, 1 \leq j \leq n\}$ form a basis of size$mn$, so the dimension is$mn$.

**Example 3.** $\dim F_{\leq n}[x] = n+1$ over$F$. The monomial basis$\{1, x, x^2, \ldots, x^n\}$ has$n+1$ elements. A different basis is$\{1, x-a, (x-a)^2, \ldots, (x-a)^n\}$ for any fixed$a \in F$ (the Taylor expansion basis around$a$); it also has$n+1$ elements.

**Example 4.** Using the corollary: in $\mathbb{R}^3$, to verify$\{(1,1,0), (0,1,1), (1,0,1)\}$ is a basis, it suffices to check independence. Suppose$a(1,1,0) + b(0,1,1) + c(1,0,1) = 0$. This gives$a + c = 0$,$a + b = 0$,$b + c = 0$. From the first two:$c = -a$ and$b = -a$. Substituting:$-a + (-a) = -2a = 0$, so$a = 0$ and hence$b = c = 0$. The set is independent and has size$3 = \dim \mathbb{R}^3$, so it is a basis.

Dimension is the first complete invariant we have encountered. Its invariance is the simplest case of a general principle in mathematics: when a structure admits a well-defined notion of "size" or "rank" that is preserved under isomorphism, that quantity is an invariant. For vector spaces, dimension is so complete an invariant that it classifies spaces up to isomorphism (as Section 6.3.2 will show) — a fact that has no analogue for more complicated algebraic structures like groups or rings, where invariants are far less decisive.
