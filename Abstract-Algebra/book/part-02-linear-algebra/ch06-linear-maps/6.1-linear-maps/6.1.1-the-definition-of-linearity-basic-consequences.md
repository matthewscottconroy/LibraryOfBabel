# 6.1.1 The Definition of Linearity; Basic Consequences

Vector spaces are interesting in themselves, but the real power of linear algebra comes from studying maps between them. Not every function from one vector space to another is worth studying — we want maps that interact with addition and scalar multiplication in the way the structure demands. These are the linear maps, and they are the morphisms of the category of vector spaces.

\begin{definition}
Let $V$ and$W$ be vector spaces over the same field$F$. A function$T: V \to W$ is called **linear** (or a **linear map**, **linear transformation**, or **$F$-linear map**) if
\par
$$T(au + bv) = aT(u) + bT(v)$$
\par
for all scalars $a, b \in F$ and all vectors$u, v \in V$.
\end{definition}

Equivalently — and this is how one often checks linearity in practice — $T$ is linear if and only if it preserves addition ($T(u + v) = T(u) + T(v)$) and preserves scalar multiplication ($T(av) = aT(v)$). The two-in-one form is convenient for proofs; the separated form is convenient for verification.

Several basic consequences follow immediately from the definition.

\begin{proposition}[Basic Consequences of Linearity]
Let $T: V \to W$ be linear. Then:
\begin{enumerate}
\item $T(0_V) = 0_W$.
\item $T(-v) = -T(v)$ for all$v \in V$.
\item $T\!\left(\sum_{i=1}^n a_i v_i\right) = \sum_{i=1}^n a_i T(v_i)$ for all$a_i \in F$,$v_i \in V$.
\end{enumerate}
\end{proposition}

\begin{proof}
(1): Set $a = b = 0$ in the defining condition:$T(0) = 0 \cdot T(u) + 0 \cdot T(v) = 0$. (2): Apply linearity with$a = -1$ and$b = 0$. (3): By induction on$n$, using (1) as the base case$n = 0$.
\end{proof}

Item (3) is especially important: a linear map commutes with all finite linear combinations. This is the operative identity for nearly every computation, and it has a fundamental structural consequence.

\begin{theorem}[Linear Maps are Determined by Their Values on a Basis]
Let $\mathcal{B} = (b_1, \ldots, b_n)$ be an ordered basis of$V$, and let$w_1, \ldots, w_n \in W$ be arbitrary vectors. Then there exists a unique linear map$T: V \to W$ satisfying$T(b_i) = w_i$ for each$i = 1, \ldots, n$.
\end{theorem}

\begin{proof}
*Existence:* Every $v \in V$ has a unique expansion$v = x_1 b_1 + \cdots + x_n b_n$. Define$T(v) = x_1 w_1 + \cdots + x_n w_n$. This is well-defined (the expansion is unique) and linear (check:$T(av + bw) = aT(v) + bT(w)$ directly from the definition). By construction,$T(b_i) = w_i$.

*Uniqueness:* If $T'$ is any linear map with$T'(b_i) = w_i$, then for any$v = \sum x_i b_i$, linearity gives$T'(v) = \sum x_i T'(b_i) = \sum x_i w_i = T(v)$.
\end{proof}

This theorem is the cornerstone of computations with linear maps. It says that specifying a linear map is exactly the same as specifying where it sends each basis vector — no more, no less. One is free to assign $w_1, \ldots, w_n$ to be any vectors in$W$ whatsoever (there is no independence or spanning condition required on the$w_i$'s), and there will be a unique linear map realizing that assignment.

**Example 1.** Define $T: \mathbb{R}^2 \to \mathbb{R}^2$ by$T(e_1) = (1, 2)$ and$T(e_2) = (3, 4)$. Then for any$(x, y) = xe_1 + ye_2$, linearity gives$T(x, y) = x(1,2) + y(3,4) = (x + 3y, 2x + 4y)$. The map is completely determined by the two image vectors.

**Example 2.** Let $V = F_{\leq 2}[x]$ and$W = F_{\leq 1}[x]$. Define$D: V \to W$ by$D(1) = 0$,$D(x) = 1$,$D(x^2) = 2x$ — i.e.,$D$ is the formal derivative. Then$D(a + bx + cx^2) = D(a) \cdot 0 + D(bx) \cdot 1 + D(cx^2) \cdot 2x$... rather, by linearity,$D(a + bx + cx^2) = aD(1) + bD(x) + cD(x^2) = 0 + b + 2cx = b + 2cx$. This is consistent with the derivative formula.

**Example 3.** Verify that $T: \mathbb{R}^2 \to \mathbb{R}^2$ defined by$T(x, y) = (x + y^2, x - y)$ is NOT linear. Check$T(0,0) = (0,0)$, fine. But$T(2(0,1)) = T(0,2) = (4, -2)$, while$2T(0,1) = 2(1,-1) = (2,-2)$. These disagree (since$4 \neq 2$), so$T$ is not linear. The presence of$y^2$ breaks homogeneity.

**Example 4.** Let $V = W = \mathbb{R}^n$ and$T(v) = Av$ for a fixed matrix$A \in M_{n \times n}(\mathbb{R})$. Then$T(au + bv) = A(au + bv) = a(Au) + b(Av) = aT(u) + bT(v)$, so matrix multiplication always defines a linear map. As we shall see in Chapter 7, every linear map between finite-dimensional spaces arises this way once bases are chosen.

The definition of linearity is short, but it encodes something deep: linear maps are the structure-preserving maps of vector spaces, in the same way that group homomorphisms preserve the group operation and ring homomorphisms preserve both operations. The categorical perspective — that vector spaces form a category with linear maps as morphisms — will be articulated further in Section 6.3.3, but the reader should keep this perspective in mind throughout.
