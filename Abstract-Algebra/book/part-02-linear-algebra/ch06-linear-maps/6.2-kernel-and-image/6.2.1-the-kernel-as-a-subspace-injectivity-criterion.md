# 6.2.1 The Kernel as a Subspace; Injectivity Criterion

When we apply a linear map $T: V \to W$, some vectors may be sent to zero. The set of all such vectors is called the **kernel** of$T$ and captures a fundamental aspect of how$T$ behaves: the kernel is the obstruction to injectivity and the measure of information lost.

\begin{definition}
The **kernel** (or **null space**) of a linear map $T: V \to W$ is the set
\par
$$\ker T = \{v \in V \mid T(v) = 0_W\}.$$
\par
The **nullity** of $T$ is$\mathrm{null}(T) = \dim(\ker T)$.
\end{definition}

\begin{proposition}
$\ker T$ is a subspace of$V$.
\end{proposition}

\begin{proof}
Three conditions: (1) $T(0_V) = 0_W$, so$0_V \in \ker T$. (2) If$u, v \in \ker T$, then$T(u+v) = T(u) + T(v) = 0 + 0 = 0$, so$u+v \in \ker T$. (3) If$v \in \ker T$ and$a \in F$, then$T(av) = aT(v) = 0$, so$av \in \ker T$.
\end{proof}

\begin{theorem}[Injectivity Criterion]
A linear map $T: V \to W$ is injective if and only if$\ker T = \{0_V\}$.
\end{theorem}

\begin{proof}
If $T$ is injective and$T(v) = 0 = T(0)$, then injectivity forces$v = 0$. Conversely, if$\ker T = \{0\}$ and$T(u) = T(v)$, then$T(u - v) = T(u) - T(v) = 0$, so$u - v \in \ker T = \{0\}$, giving$u = v$.
\end{proof}

This criterion reduces injectivity — a condition about all pairs of inputs — to a single local condition: that zero is the only element mapping to zero. In practice, this is how one checks injectivity for a linear map: compute the kernel and verify it is trivial.

The size of the kernel measures how much information $T$ loses. If$\ker T$ is large, many distinct vectors are identified by$T$ (they differ by an element of$\ker T$), so$T$ is far from injective. If$\ker T = \{0\}$, no information is lost.

\begin{proposition}
Let $T: V \to W$ be linear and let$x_0 \in V$ with$T(x_0) = b$. Then the set of all solutions to$T(x) = b$ is the coset$x_0 + \ker T = \{x_0 + v : v \in \ker T\}$.
\end{proposition}

\begin{proof}
If $T(x) = b = T(x_0)$, then$T(x - x_0) = 0$, so$x - x_0 \in \ker T$, i.e.,$x \in x_0 + \ker T$. Conversely, any$x = x_0 + v$ with$v \in \ker T$ satisfies$T(x) = T(x_0) + T(v) = b + 0 = b$.
\end{proof}

This proposition is the linear algebra instance of a pattern that recurs throughout algebra: the set of solutions to an equation $T(x) = b$ is a coset of the kernel. When the kernel is trivial, there is at most one solution; when it is nontrivial, solutions come in entire cosets (affine subspaces).

**Example 1.** Let $T: \mathbb{R}^3 \to \mathbb{R}^2$ be defined by$T(x, y, z) = (x + y, y + z)$. Find$\ker T$: we need$x + y = 0$ and$y + z = 0$, so$x = -y$ and$z = -y$. The kernel is$\ker T = \{(-t, t, -t) : t \in \mathbb{R}\} = \mathrm{span}((-1, 1, -1))$, a line through the origin in$\mathbb{R}^3$. Since$\ker T \neq \{0\}$,$T$ is not injective. The nullity is$1$.

**Example 2.** Let $D: F_{\leq n}[x] \to F_{\leq n-1}[x]$ be differentiation. A polynomial has zero derivative iff it is constant. So$\ker D = \{a \in F : a \text{ is a constant polynomial}\} = F_{\leq 0}[x]$, which has dimension$1$. The nullity of$D$ is$1$, confirming$D$ is not injective.

**Example 3.** Let $T: M_{2 \times 2}(F) \to M_{2 \times 2}(F)$ be defined by$T(A) = A - A^T$ (the skew-symmetric part times$2$, roughly). Compute$\ker T$:$T(A) = 0$ iff$A = A^T$ iff$A$ is symmetric. So$\ker T$ is the space of symmetric$2 \times 2$ matrices, which has dimension$3$. The nullity of$T$ is$3$.

**Example 4.** Injectivity criterion in action: the map $T: \mathbb{R}^2 \to \mathbb{R}^2$,$T(x,y) = (x - y, x + y)$ is linear. Compute$\ker T$:$x - y = 0$ and$x + y = 0$ give$x = y = 0$. So$\ker T = \{0\}$ and$T$ is injective. Since$T$ maps$\mathbb{R}^2$ to itself with trivial kernel, it is also surjective (by Section 6.2.4), hence an isomorphism.

The kernel is the first of two fundamental subspaces associated to $T$; the second is the image, which we study in the next subsection. Together they are connected by the Rank-Nullity Theorem (Section 6.2.3), which is the fundamental quantitative identity for linear maps.
