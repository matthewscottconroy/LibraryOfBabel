# 6.2.2 The Image as a Subspace; Surjectivity Criterion

Complementing the kernel — which tells us what $T$ collapses — the image tells us what$T$ produces. The image is the "reach" of$T$: the set of all vectors in$W$ that$T$ can output.

\begin{definition}
The **image** (or **range**) of a linear map $T: V \to W$ is
\par
$$\mathrm{im}\, T = \{T(v) \mid v \in V\} \subseteq W.$$
\par
The **rank** of $T$ is$\mathrm{rank}(T) = \dim(\mathrm{im}\, T)$.
\end{definition}

\begin{proposition}
$\mathrm{im}\, T$ is a subspace of$W$.
\end{proposition}

\begin{proof}
(1) $0_W = T(0_V) \in \mathrm{im}\, T$. (2) If$T(u), T(v) \in \mathrm{im}\, T$, then$T(u) + T(v) = T(u + v) \in \mathrm{im}\, T$. (3) If$T(v) \in \mathrm{im}\, T$ and$a \in F$, then$aT(v) = T(av) \in \mathrm{im}\, T$.
\end{proof}

\begin{proposition}[Surjectivity Criterion]
$T: V \to W$ is surjective if and only if$\mathrm{im}\, T = W$.
\end{proposition}

This is merely the definition of surjectivity restated. A map with large rank fills out much of $W$; a map with small rank has a highly compressed image. The rank measures how "large" the output of$T$ is.

\begin{proposition}[Image from a Spanning Set]
If $\{v_1, \ldots, v_n\}$ is a spanning set (or a basis) of$V$, then
\par
$$\mathrm{im}\, T = \mathrm{span}(T(v_1), \ldots, T(v_n)).$$
\end{proposition}

\begin{proof}
Any $v \in V$ writes as$v = \sum a_i v_i$, so$T(v) = \sum a_i T(v_i) \in \mathrm{span}(T(v_1), \ldots, T(v_n))$.
\end{proof}

This makes the image computable: take the images of a basis, and their span is the image. In the matrix representation $T = T_A$, the image of$T$ is exactly the **column space** of$A$ — the subspace of$F^m$ spanned by the columns of$A$ — because$T_A(e_j) = Ae_j$ is the$j$-th column of$A$.

\begin{remark}
The rank of $T$ coincides with the rank of any matrix representing$T$ (once bases are chosen), since the matrix representation is an isomorphism preserving dimension. The rank is also equal to the dimension of the row space of any matrix for$T$, a less obvious fact that follows from the theory of row reduction (Section 7.5).
\end{remark}

**Example 1.** Let $T: \mathbb{R}^3 \to \mathbb{R}^2$ be$T(x, y, z) = (x + y, y + z)$. From Example 1 of Section 6.2.1,$\mathrm{null}(T) = 1$. The image:$T(e_1) = (1,0)$,$T(e_2) = (1,1)$,$T(e_3) = (0,1)$. These span$\mathbb{R}^2$ (since$(1,0)$ and$(0,1)$ are already in the image). So$\mathrm{im}\, T = \mathbb{R}^2$ and$\mathrm{rank}(T) = 2$. The map is surjective.

**Example 2.** Let $T: \mathbb{R}^2 \to \mathbb{R}^3$ be$T(x, y) = (x + y, x - y, 2x)$. The image is$\mathrm{span}(T(e_1), T(e_2)) = \mathrm{span}((1,1,2), (1,-1,0))$. These two vectors are independent (neither is a scalar multiple of the other), so$\mathrm{rank}(T) = 2 < 3 = \dim \mathbb{R}^3$. The image is a$2$-dimensional plane in$\mathbb{R}^3$, so$T$ is not surjective.

**Example 3.** Differentiation $D: F_{\leq n}[x] \to F_{\leq n-1}[x]$:$\mathrm{im}\, D = F_{\leq n-1}[x]$ (every polynomial of degree$\leq n-1$ is the derivative of a polynomial of degree$\leq n$), so$D$ is surjective and$\mathrm{rank}(D) = n$.

**Example 4.** The projection $\pi_U: V \to V$ onto$U$ along$W$ (with$V = U \oplus W$):$\mathrm{im}\, \pi_U = U$ (every$u \in U$ satisfies$\pi_U(u) = u$) and$\ker \pi_U = W$ (every$w \in W$ satisfies$\pi_U(w) = 0$). So$\mathrm{rank}(\pi_U) = \dim U$ and$\mathrm{null}(\pi_U) = \dim W$. This is consistent with rank-nullity:$\dim U + \dim W = \dim V$.

The image of $T$ is also used to characterize when the equation$T(v) = w$ is solvable: it has a solution iff$w \in \mathrm{im}\, T$. Combined with the coset description of the solution set from Section 6.2.1, we have a complete picture: solvability is controlled by the image, and the solution set (when nonempty) is an affine subspace of dimension$\mathrm{null}(T)$.

**Example 5.** The image of a matrix multiplication map: for $A = \begin{pmatrix}1&2&1\\0&1&2\\1&3&3\end{pmatrix}$ and$T_A: \mathbb{R}^3 \to \mathbb{R}^3$, the image is spanned by the columns:$(1,0,1)^T$,$(2,1,3)^T$,$(1,2,3)^T$. Check whether these span$\mathbb{R}^3$ by computing$\det(A) = 1(3-6) - 2(0-2) + 1(0-1) = -3 + 4 - 1 = 0$. So$\det A = 0$, meaning rank$< 3$. The image is a proper subspace of$\mathbb{R}^3$. More precisely, the third column$(1,2,3)^T = (1,0,1)^T + (0,2,2)^T$... row reduction reveals rank$2$, so$\mathrm{im}\, T_A$ is a$2$-dimensional plane in$\mathbb{R}^3$.

The image and kernel together give a complete picture of how a linear map distributes information. The image tells us "what can be achieved" (the range of outputs), and the kernel tells us "what is indistinguishable" (the fibers of $T$ all have the same size, namely$|\ker T|$ in the finite case). The first isomorphism theorem for vector spaces ($V / \ker T \cong \mathrm{im}\, T$) formalizes this: the map$T$ factors as$V \twoheadrightarrow V/\ker T \xrightarrow{\sim} \mathrm{im}\, T \hookrightarrow W$, a surjection followed by an isomorphism followed by an injection.
