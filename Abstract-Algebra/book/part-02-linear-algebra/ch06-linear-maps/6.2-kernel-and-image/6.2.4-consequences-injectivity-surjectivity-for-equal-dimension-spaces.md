# 6.2.4 Consequences: Injectivity $\Leftrightarrow$ Surjectivity for Equal-Dimension Spaces

The Rank-Nullity Theorem has a striking corollary for maps between spaces of the same finite dimension. In that setting, injectivity and surjectivity are not independent — each implies the other, and both imply bijectivity. This is a genuinely non-trivial fact that has no analogue for general functions between infinite sets.

\begin{theorem}
Let $V$ and$W$ be finite-dimensional vector spaces with$\dim V = \dim W = n$, and let$T: V \to W$ be linear. Then the following are equivalent:
\begin{enumerate}
\item[(a)] $T$ is injective.
\item[(b)] $T$ is surjective.
\item[(c)] $T$ is bijective (an isomorphism).
\end{enumerate}
\end{theorem}

\begin{proof}
By Rank-Nullity, $\mathrm{null}(T) + \mathrm{rank}(T) = n$.

(a) $\Rightarrow$ (b): If$T$ is injective,$\ker T = \{0\}$, so$\mathrm{null}(T) = 0$, hence$\mathrm{rank}(T) = n$. Since$\mathrm{im}\, T \subseteq W$ and$\dim(\mathrm{im}\, T) = n = \dim W$, we get$\mathrm{im}\, T = W$ by the subspace dimension criterion (Section 5.4.2), so$T$ is surjective.

(b) $\Rightarrow$ (a): If$T$ is surjective,$\mathrm{im}\, T = W$, so$\mathrm{rank}(T) = n$, hence$\mathrm{null}(T) = 0$, giving$\ker T = \{0\}$, so$T$ is injective.

(a) and (b) together give (c) directly.
\end{proof}

\begin{remark}
The reason this is remarkable is the contrast with infinite-dimensional spaces. The right-shift $(a_1, a_2, a_3, \ldots) \mapsto (0, a_1, a_2, \ldots)$ on$\ell^2$ (the Hilbert space of square-summable sequences) is injective but not surjective; its adjoint (the left shift$(a_1, a_2, \ldots) \mapsto (a_2, a_3, \ldots)$) is surjective but not injective. So the equivalence genuinely requires finite-dimensionality, and is the linear algebra analogue of the combinatorial fact that an injection from a finite set to itself is a bijection (the pigeonhole principle).
\end{remark}

This theorem has immediate practical consequences. To show that a linear map between equal-dimensional spaces is an isomorphism, it suffices to check just one of injectivity or surjectivity — whichever is easier.

**Example 1.** The coordinate map $[\,\cdot\,]_{\mathcal{B}}: V \to F^n$ is an isomorphism. To see this, note it is linear (verified in Section 5.4.3) and injective (if$[v]_{\mathcal{B}} = 0$ then all coordinates are zero, so$v = 0$). Since$\dim V = n = \dim F^n$, injectivity implies surjectivity by the theorem, so it is an isomorphism.

**Example 2.** The evaluation map $\mathrm{ev}_a: F_{\leq n}[x] \to F^{n+1}$ defined by$\mathrm{ev}_a(p) = (p(a_0), \ldots, p(a_n))$ for distinct points$a_0, \ldots, a_n \in F$. This map has kernel consisting of polynomials of degree$\leq n$ vanishing at all$n+1$ points$a_0, \ldots, a_n$. A nonzero polynomial of degree$\leq n$ has at most$n$ roots, so it cannot vanish at all$n+1$ distinct points. Thus$\ker \mathrm{ev}_a = \{0\}$, the map is injective, both spaces have dimension$n+1$, and so$\mathrm{ev}_a$ is an isomorphism. This is the algebraic content of polynomial interpolation: specifying$n+1$ values at distinct points uniquely determines a polynomial of degree$\leq n$.

**Example 3.** Let $T: M_{n \times n}(F) \to M_{n \times n}(F)$ be$T(A) = A^T$ (transpose). Then$T$ is linear ($\dim$ domain$= \dim$ codomain$= n^2$), and$\ker T = \{A : A^T = 0\} = \{0\}$. So$T$ is injective, hence an isomorphism. (Indeed,$(A^T)^T = A$, so$T^{-1} = T$.)

**Example 4.** The map $T: \mathbb{R}^2 \to \mathbb{R}^2$ defined by$T(x, y) = (ax + by, cx + dy)$ is an isomorphism iff it is injective iff$\ker T = \{0\}$. The kernel is trivial iff$ax + by = 0$ and$cx + dy = 0$ implies$x = y = 0$, iff the system has only the trivial solution, iff$\det \begin{pmatrix}a & b \\ c & d\end{pmatrix} = ad - bc \neq 0$. So$T$ is an isomorphism iff the determinant of its matrix is nonzero — a fact that generalizes to all$n$.

The theorem also gives a simple numerical criterion: a linear map $T: F^n \to F^n$ (given by an$n \times n$ matrix$A$) is an isomorphism iff$\mathrm{rank}(A) = n$, iff$A$ is invertible, iff$\det(A) \neq 0$. These equivalences are all immediate consequences of the Rank-Nullity Theorem combined with the present result.

**Example 5.** The Frobenius endomorphism: over a finite field $\mathbb{F}_q$ (where$q = p^k$ for a prime$p$), the map$\phi: \mathbb{F}_q \to \mathbb{F}_q$ defined by$\phi(x) = x^p$ is a field automorphism, hence a linear isomorphism over the prime subfield$\mathbb{F}_p$. This is injective (over a field,$x^p = y^p$ implies$x = y$ since$x^p - y^p = (x-y)^p$ in characteristic$p$) and the domain and codomain have the same dimension over$\mathbb{F}_p$, so it is an isomorphism.

The theorem has a counterpart for modules over rings: an injective endomorphism of a Noetherian module is an isomorphism (Hopkins' theorem), and a surjective endomorphism of an Artinian module is an isomorphism (a dual result). In both cases, a finiteness condition on the module plays the role of finite-dimensionality for vector spaces. For general modules, neither implication holds, and the precise conditions under which it does form an active area of commutative algebra.

\begin{corollary}[Criteria for an $n \times n$ Matrix to be Invertible]
For $A \in M_{n \times n}(F)$, the following are equivalent: (a)$A$ is invertible; (b)$A$ is injective as a linear map$F^n \to F^n$; (c)$A$ is surjective as a linear map$F^n \to F^n$; (d)$\ker A = \{0\}$; (e)$\mathrm{rank}(A) = n$; (f) the RREF of$A$ is$I_n$; (g)$\det A \neq 0$.
\end{corollary}
