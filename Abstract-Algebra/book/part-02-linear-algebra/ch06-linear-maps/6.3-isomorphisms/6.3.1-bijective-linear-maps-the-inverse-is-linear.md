# 6.3.1 Bijective Linear Maps; the Inverse is Linear

A bijective function between sets has an inverse function. When the bijection is also linear, something stronger is true: the inverse function is automatically linear as well. This is not obvious — a priori, a bijection between vector spaces could have a wildly non-linear inverse — but the algebraic structure of linear maps prevents this from happening.

\begin{definition}
A **linear isomorphism** from $V$ to$W$ is a bijective linear map$T: V \to W$. When such a map exists, we say$V$ and$W$ are **isomorphic** and write$V \cong W$.
\end{definition}

\begin{theorem}
If $T: V \to W$ is a linear isomorphism, then$T^{-1}: W \to V$ is also linear.
\end{theorem}

\begin{proof}
Let $w_1, w_2 \in W$ and$a, b \in F$. Since$T$ is bijective, there exist unique$v_1, v_2 \in V$ with$T(v_1) = w_1$ and$T(v_2) = w_2$. Then

\begin{align*}
T^{-1}(aw_1 + bw_2) &= T^{-1}(aT(v_1) + bT(v_2)) \\
&= T^{-1}(T(av_1 + bv_2)) \\
&= av_1 + bv_2 \\
&= aT^{-1}(w_1) + bT^{-1}(w_2).
\end{align*}

The second equality uses linearity of $T$; the third uses the definition of$T^{-1}$.
\end{proof}

\begin{corollary}
The isomorphism relation $\cong$ is an equivalence relation on the class of all vector spaces over$F$:$V \cong V$ (identity map),$V \cong W$ iff$W \cong V$ ($T^{-1}$ is also an isomorphism), and$U \cong V$ and$V \cong W$ implies$U \cong W$ (composition of isomorphisms is an isomorphism).
\end{corollary}

The reason this matters is that isomorphic spaces are, from the perspective of linear algebra, indistinguishable. Any statement about the linear structure of $V$ — about subspaces, dimensions, linear maps in or out — translates to the corresponding statement about$W$ through the isomorphism. Isomorphism is the correct notion of "sameness" in the category of vector spaces over$F$.

\begin{remark}
The automorphism group $\mathrm{Aut}(V) = \{T \in \mathrm{End}(V) : T \text{ is an isomorphism}\}$ is a group under composition. Once a basis of$V$ is chosen,$\mathrm{Aut}(V) \cong GL_n(F)$, the general linear group of invertible$n \times n$ matrices over$F$. This group plays a central role in the Galois theory of field extensions, in representation theory, and in geometry.
\end{remark}

**Example 1.** The map $T: \mathbb{R}^2 \to \mathbb{R}^2$ defined by$T(x, y) = (x + y, x - y)$ is bijective (its matrix$\begin{pmatrix}1&1\\1&-1\end{pmatrix}$ has determinant$-2 \neq 0$). The inverse: from$u = x + y$ and$v = x - y$, we get$x = (u+v)/2$ and$y = (u-v)/2$, so$T^{-1}(u, v) = ((u+v)/2, (u-v)/2)$. This is linear, as the theorem guarantees.

**Example 2.** The coordinate map $[\,\cdot\,]_{\mathcal{B}}: V \to F^n$ is a linear isomorphism (Section 5.4.3). Its inverse is the map$F^n \to V$ given by$(x_1, \ldots, x_n) \mapsto x_1 b_1 + \cdots + x_n b_n$ — clearly linear.

**Example 3.** The map $T: F_{\leq n}[x] \to F_{\leq n}[x]$ defined by$T(p)(x) = p(x + 1)$ (shifting the argument) is a linear isomorphism. Linearity:$T(ap + bq)(x) = (ap + bq)(x+1) = aT(p)(x) + bT(q)(x)$. Inverse:$T^{-1}(q)(x) = q(x-1)$. This isomorphism is useful in finite differences and combinatorics.

**Example 4.** The exponential map $\exp: (\mathbb{R}, +) \to (\mathbb{R}_{>0}, \cdot)$ is a group isomorphism, but NOT a linear isomorphism between vector spaces (it does not preserve addition:$\exp(x + y) \neq \exp(x) + \exp(y)$). This example underscores that isomorphism depends on the category: "isomorphism" means different things for different algebraic structures, and we must always specify which structure we are preserving.

The key consequence is that once we have an isomorphism $T: V \to W$, we can transfer all structural questions from$V$ to$W$ and back. In particular, since every$n$-dimensional space is isomorphic to$F^n$ via the coordinate map, any question about abstract$n$-dimensional spaces reduces to a question about column vectors — which is exactly the bridge that makes matrix computation useful.

**Example 5.** The isomorphism $\mathcal{L}(V,W) \cong M_{m \times n}(F)$: given ordered bases on$V$ and$W$, the map$T \mapsto [T]_{\mathcal{B}}^{\mathcal{C}}$ is a linear isomorphism by Section 7.3.3. Its inverse sends a matrix$A$ to the unique linear map$T$ satisfying$T(b_j) = \sum_i A_{ij} c_i$. This isomorphism transports the vector space structure of$\mathcal{L}(V,W)$ to$M_{m \times n}(F)$ and back.

\begin{proposition}[Transfer of Subspaces via Isomorphism]
If $T: V \to W$ is a linear isomorphism and$U \subseteq V$ is a subspace, then$T(U)$ is a subspace of$W$ with$\dim T(U) = \dim U$. Conversely, every subspace of$W$ arises as$T(U)$ for a unique subspace$U \subseteq V$.
\end{proposition}

\begin{proof}
$T(U)$ is a subspace:$T(0_V) = 0_W \in T(U)$; if$T(u_1), T(u_2) \in T(U)$ then$T(u_1) + T(u_2) = T(u_1 + u_2) \in T(U)$; if$T(u) \in T(U)$ then$aT(u) = T(au) \in T(U)$. The restriction$T|_U: U \to T(U)$ is an isomorphism (injective by injectivity of$T$, surjective onto$T(U)$ by definition), so$\dim T(U) = \dim U$. Conversely, for any$W' \subseteq W$, set$U = T^{-1}(W') = \{v \in V: T(v) \in W'\}$, which is a subspace of$V$ with$T(U) = W'$.
\end{proof}

This proposition shows that isomorphic vector spaces have perfectly matched lattices of subspaces. The isomorphism is not just a bijection on points but a bijection on all substructures, preserving all the algebraic relationships among them.
