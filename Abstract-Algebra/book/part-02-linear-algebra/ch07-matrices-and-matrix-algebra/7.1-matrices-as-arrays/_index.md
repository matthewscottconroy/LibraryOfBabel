# 7.1 Matrices as Arrays

A matrix is a rectangular array of $m$ rows and $n$ columns, with entries in a field $F$. The set of all such arrays is denoted $M_{m \times n}(F)$, or sometimes $F^{m \times n}$. Before any interpretation is attached, a matrix is simply a datum: a way of organizing $mn$ scalars into a grid. The section introduces the notation $A = (a_{ij})$ where $a_{ij}$ denotes the entry in row $i$ and column $j$, establishes the row and column conventions, and defines the operations that make $M_{m \times n}(F)$ a vector space.

Matrix addition and scalar multiplication are defined entry-wise: $(A + B)_{ij} = a_{ij} + b_{ij}$ and $(cA)_{ij} = c a_{ij}$. These operations satisfy the vector space axioms, and with them $M_{m \times n}(F)$ becomes an $mn$-dimensional vector space over $F$. A natural basis consists of the elementary matrices $E_{ij}$, which have a 1 in position $(i,j)$ and zeros everywhere else. The transpose $A^T$ of a matrix $A$ is defined by $(A^T)_{ij} = a_{ji}$, reflecting the matrix across its main diagonal. The transpose operation is a linear involution satisfying $(A^T)^T = A$ and, as will be shown later, $(AB)^T = B^T A^T$.

The section then introduces several important families of square matrices. A matrix is symmetric if $A = A^T$ and skew-symmetric if $A = -A^T$; every square matrix decomposes uniquely into its symmetric and skew-symmetric parts as $A = \frac{1}{2}(A + A^T) + \frac{1}{2}(A - A^T)$. Diagonal matrices have nonzero entries only on the main diagonal, and triangular matrices have all zeros either above (lower triangular) or below (upper triangular) the diagonal. These special forms arise naturally in the computational algorithms of Sections 7.5 and in the spectral theory of Chapters 9–10.

A conceptual point worth emphasizing: at this stage, matrices are arrays and nothing more. The geometric meaning — that a matrix represents a linear map in specific coordinates — is developed in Section 7.3. Knowing this in advance can make the algebraic rules feel better motivated: the transpose, the identity matrix, and the specific definition of matrix multiplication are all consequences of the requirement that matrices faithfully represent linear maps and their composition. The current section lays the syntactic groundwork; the semantic content follows once bases are in play.
