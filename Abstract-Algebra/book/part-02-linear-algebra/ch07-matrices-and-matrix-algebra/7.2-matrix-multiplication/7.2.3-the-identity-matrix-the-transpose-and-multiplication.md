# 7.2.3 The Identity Matrix; the Transpose and Multiplication

Two fundamental algebraic identities govern the interaction of matrix multiplication with the identity matrix and the transpose operation. These identities make $M_{n \times n}(F)$ into a ring with unity and reveal a structural duality between multiplication and transposition.

\begin{definition}
The **identity matrix** $I_n \in M_{n \times n}(F)$ is the matrix with$(I_n)_{ij} = \delta_{ij}$ — ones on the main diagonal and zeros elsewhere.
\end{definition}

\begin{proposition}
For any $A \in M_{m \times n}(F)$:$I_m A = A$ and$A I_n = A$.
\end{proposition}

\begin{proof}
$(I_m A)_{ij} = \sum_k (I_m)_{ik} A_{kj} = \sum_k \delta_{ik} A_{kj} = A_{ij}$. Similarly for$A I_n$.
\end{proof}

The identity matrix makes $M_{n \times n}(F)$ into a **unital ring**: it has an associative multiplication with an identity element. Combined with the distributive laws (Section 7.2.1),$M_{n \times n}(F)$ satisfies all the ring axioms. The invertible elements form the **general linear group**$GL_n(F) = \{A \in M_{n \times n}(F) : A \text{ is invertible}\}$, a group under multiplication.

\begin{theorem}[Transpose of a Product]
For any $A \in M_{m \times n}(F)$ and$B \in M_{n \times p}(F)$,
\par
$$(AB)^T = B^T A^T.$$
\end{theorem}

\begin{proof}
The $(i,j)$ entry of$(AB)^T$ is$(AB)_{ji} = \sum_k A_{jk} B_{ki}$. The$(i,j)$ entry of$B^T A^T$ is$\sum_k (B^T)_{ik} (A^T)_{kj} = \sum_k B_{ki} A_{jk}$. These are equal.
\end{proof}

The reversal of order in $(AB)^T = B^T A^T$ is a pattern ubiquitous in algebra:
- In groups: $(ab)^{-1} = b^{-1}a^{-1}$.
- For linear maps: $(T \circ S)^* = S^* \circ T^*$ (dual maps, Section 6.3.3).
- In category theory: any contravariant functor reverses arrows.

Each of these is a manifestation of the same principle: operations that "reverse" a structure consistently reverse the order of composition.

\begin{corollary}
If $A$ is invertible, then$(A^T)^{-1} = (A^{-1})^T$.
\end{corollary}

\begin{proof}
$A^T (A^{-1})^T = (A^{-1} A)^T = I_n^T = I_n$. Similarly$(A^{-1})^T A^T = I_n$.
\end{proof}

\begin{remark}
The identity $(AB)^T = B^T A^T$ shows that the product of two symmetric matrices need not be symmetric: if$A^T = A$ and$B^T = B$, then$(AB)^T = B^T A^T = BA$, which equals$AB$ only when$A$ and$B$ commute. So symmetry is not preserved under multiplication in general — a useful counterexample to any overly optimistic conjectures.
\end{remark}

**Example 1.** Verify $I_2 A = A$ for$A = \begin{pmatrix}3&-1\\2&4\end{pmatrix}$:$\begin{pmatrix}1&0\\0&1\end{pmatrix}\begin{pmatrix}3&-1\\2&4\end{pmatrix} = \begin{pmatrix}3&-1\\2&4\end{pmatrix}$. Trivially true from the formula.

**Example 2.** Verify $(AB)^T = B^T A^T$ for$A = \begin{pmatrix}1&2\\3&4\end{pmatrix}$,$B = \begin{pmatrix}0&1\\1&0\end{pmatrix}$. We have$AB = \begin{pmatrix}2&1\\4&3\end{pmatrix}$, so$(AB)^T = \begin{pmatrix}2&4\\1&3\end{pmatrix}$. On the other hand,$B^T = \begin{pmatrix}0&1\\1&0\end{pmatrix}$ and$A^T = \begin{pmatrix}1&3\\2&4\end{pmatrix}$, so$B^T A^T = \begin{pmatrix}0&1\\1&0\end{pmatrix}\begin{pmatrix}1&3\\2&4\end{pmatrix} = \begin{pmatrix}2&4\\1&3\end{pmatrix}$. They agree.

**Example 3.** Product of symmetric matrices need not be symmetric: $A = \begin{pmatrix}1&1\\1&2\end{pmatrix}$,$B = \begin{pmatrix}2&1\\1&1\end{pmatrix}$ are both symmetric.$AB = \begin{pmatrix}3&2\\4&3\end{pmatrix}$. But$(AB)^T = \begin{pmatrix}3&4\\2&3\end{pmatrix} \neq AB$. So$AB$ is not symmetric (unless$AB = BA$, which does not hold here:$BA = \begin{pmatrix}3&4\\2&3\end{pmatrix}$, confirming$AB \neq BA$ and$(AB)^T = BA$).

**Example 4.** The transpose and the inverse commute: for $A = \begin{pmatrix}2&1\\1&1\end{pmatrix}$,$\det A = 1$, so$A^{-1} = \begin{pmatrix}1&-1\\-1&2\end{pmatrix}$. Then$(A^{-1})^T = \begin{pmatrix}1&-1\\-1&2\end{pmatrix}$ (it happens to be symmetric here). And$(A^T)^{-1} = \begin{pmatrix}1&-1\\-1&2\end{pmatrix}$ as well (since$A$ is symmetric,$A^T = A$, and$(A^T)^{-1} = A^{-1}$).

**Example 5.** The identity matrix as a multiplicative unit: for $A \in M_{2 \times 3}(\mathbb{R})$,$I_2 A = A$ (the$2 \times 2$ identity acts on the left) and$A I_3 = A$ (the$3 \times 3$ identity acts on the right). For example,$\begin{pmatrix}1&0\\0&1\end{pmatrix}\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix} = \begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$ and$\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}\begin{pmatrix}1&0&0\\0&1&0\\0&0&1\end{pmatrix} = \begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$.

The identity matrix and the transpose identity $(AB)^T = B^T A^T$ together capture the basic algebraic structure of$M_{n \times n}(F)$ as an involutive algebra: a unital associative$F$-algebra equipped with an anti-involution$A \mapsto A^T$ satisfying$(AB)^T = B^T A^T$,$(A^T)^T = A$, and$(aA)^T = aA^T$. This abstract structure — an algebra with an anti-involution — is exactly the right framework for studying symmetric bilinear forms (where$A$ is symmetric) and skew-symmetric forms (where$A$ is skew-symmetric), and it generalizes to$*$-algebras in the complex setting and to self-dual codes in coding theory.

\begin{remark}
An **orthogonal matrix** is a square matrix $Q \in M_{n \times n}(\mathbb{R})$ satisfying$Q^T Q = I_n$. By the identity$(Q^T Q)^T = Q^T (Q^T)^T = Q^T Q$, the condition$Q^T Q = I_n$ is equivalent to$Q^T = Q^{-1}$. The set of orthogonal matrices forms a group under multiplication, the **orthogonal group**$O(n)$. These are precisely the matrices representing isometries (distance-preserving linear maps) of$\mathbb{R}^n$.
\end{remark}
