# 7.3.1 Representing $T: V \to W$ by Choosing Bases

A linear map $T: V \to W$ is an abstract object: it transforms vectors in one vector space into vectors in another without reference to any particular coordinate system. To compute with$T$ concretely, we need to translate it into numbers, and this requires choosing bases. The result is the **matrix of$T$**, which turns the abstract transformation into an explicit array of scalars.

\begin{definition}
Let $V$ be$n$-dimensional with ordered basis$\mathcal{B} = (b_1, \ldots, b_n)$, and$W$ be$m$-dimensional with ordered basis$\mathcal{C} = (c_1, \ldots, c_m)$. The **matrix of$T$ with respect to$\mathcal{B}$ and$\mathcal{C}$**, written$[T]_{\mathcal{B}}^{\mathcal{C}}$, is the$m \times n$ matrix whose$j$-th column is$[T(b_j)]_{\mathcal{C}}$ — the coordinate vector of the image of the$j$-th basis vector of$V$, expressed in the basis$\mathcal{C}$ of$W$.
\end{definition}

That is: write $T(b_j) = \sum_{i=1}^{m} A_{ij} c_i$ for each$j$, and set$[T]_{\mathcal{B}}^{\mathcal{C}} = (A_{ij})$.

\begin{theorem}[Fundamental Equation]
For every $v \in V$,
\par
$$[T(v)]_{\mathcal{C}} = [T]_{\mathcal{B}}^{\mathcal{C}} \cdot [v]_{\mathcal{B}}.$$
\end{theorem}

\begin{proof}
Write $v = \sum_{j=1}^{n} \alpha_j b_j$, so$[v]_{\mathcal{B}} = (\alpha_1, \ldots, \alpha_n)^T$. By linearity,$T(v) = \sum_{j=1}^{n} \alpha_j T(b_j) = \sum_{j=1}^{n} \alpha_j \sum_{i=1}^{m} A_{ij} c_i = \sum_{i=1}^{m} \left(\sum_{j=1}^{n} A_{ij} \alpha_j\right) c_i$. So the$i$-th coordinate of$T(v)$ in$\mathcal{C}$ is$\sum_j A_{ij} \alpha_j = ([T]_{\mathcal{B}}^{\mathcal{C}} \cdot [v]_{\mathcal{B}})_i$.
\end{proof}

The fundamental equation says that the diagram

$$V \xrightarrow{T} W, \quad F^n \xrightarrow{[T]_{\mathcal{B}}^{\mathcal{C}} \cdot (-)} F^m$$

commutes (where the vertical maps are the coordinate isomorphisms). This is the precise sense in which the matrix "represents" the map.

**Example 1.** Let $T: \mathbb{R}^2 \to \mathbb{R}^3$ be$T(x,y) = (x+y, x-y, 2y)$. With the standard bases$\mathcal{B} = (e_1, e_2)$ and$\mathcal{C} = (f_1, f_2, f_3)$, compute:

$$T(e_1) = (1,1,0) = 1 \cdot f_1 + 1 \cdot f_2 + 0 \cdot f_3, \quad [T(e_1)]_{\mathcal{C}} = \begin{pmatrix}1\\1\\0\end{pmatrix},$$
$$T(e_2) = (1,-1,2) = 1 \cdot f_1 + (-1) \cdot f_2 + 2 \cdot f_3, \quad [T(e_2)]_{\mathcal{C}} = \begin{pmatrix}1\\-1\\2\end{pmatrix}.$$

So $[T]_{\mathcal{B}}^{\mathcal{C}} = \begin{pmatrix}1&1\\1&-1\\0&2\end{pmatrix}$. Check:$[T(1,1)]_{\mathcal{C}} = [T]_{\mathcal{B}}^{\mathcal{C}} \cdot \begin{pmatrix}1\\1\end{pmatrix} = \begin{pmatrix}2\\0\\2\end{pmatrix}$, which corresponds to$(2,0,2) = T(1,1)$. Correct.

**Example 2.** Differentiation $D: F_{\leq 2}[x] \to F_{\leq 1}[x]$ with$\mathcal{B} = (1, x, x^2)$ and$\mathcal{C} = (1, x)$:

$$D(1) = 0 = 0 \cdot 1 + 0 \cdot x, \quad D(x) = 1 = 1 \cdot 1 + 0 \cdot x, \quad D(x^2) = 2x = 0 \cdot 1 + 2 \cdot x.$$

So $[D]_{\mathcal{B}}^{\mathcal{C}} = \begin{pmatrix}0&1&0\\0&0&2\end{pmatrix}$.

**Example 3.** If $\mathcal{B} = \mathcal{C}$ (same basis for domain and codomain, when$V = W$), we write$[T]_{\mathcal{B}} = [T]_{\mathcal{B}}^{\mathcal{B}}$. For the rotation$R_\theta: \mathbb{R}^2 \to \mathbb{R}^2$ with standard basis:$R_\theta(e_1) = (\cos\theta, \sin\theta)$ and$R_\theta(e_2) = (-\sin\theta, \cos\theta)$, so$[R_\theta] = \begin{pmatrix}\cos\theta & -\sin\theta \\ \sin\theta & \cos\theta\end{pmatrix}$.

The matrix $[T]_{\mathcal{B}}^{\mathcal{C}}$ depends on the choice of bases; different bases give different matrices. The question of how these matrices are related when we change bases is taken up in Section 7.4. The key takeaway is that every abstract linear map becomes a concrete matrix once we commit to bases — and that matrix completely encodes the action of$T$.

**Example 4.** The inclusion map $\iota: \mathbb{R}^2 \to \mathbb{R}^3$ defined by$\iota(x,y) = (x, y, 0)$. With the standard bases$\mathcal{B} = (e_1, e_2)$ and$\mathcal{C} = (f_1, f_2, f_3)$:$\iota(e_1) = (1,0,0) = f_1$ and$\iota(e_2) = (0,1,0) = f_2$. So$[\iota]_{\mathcal{B}}^{\mathcal{C}} = \begin{pmatrix}1&0\\0&1\\0&0\end{pmatrix}$. This is a$3 \times 2$ matrix, confirming that$\iota$ maps$\mathbb{R}^2$ (dimension$2$) to$\mathbb{R}^3$ (dimension$3$).

**Example 5.** Effect of changing basis on the matrix: let $T = \mathrm{id}: \mathbb{R}^2 \to \mathbb{R}^2$ be the identity, but with$\mathcal{B} = (e_1, e_2)$ (standard) and$\mathcal{C} = ((1,1),(1,-1))$. Then$\mathrm{id}(e_1) = e_1 = (1,1)/2 + (1,-1)/2$, so$[\mathrm{id}(e_1)]_{\mathcal{C}} = (1/2, 1/2)^T$. Similarly$[\mathrm{id}(e_2)]_{\mathcal{C}} = (1/2, -1/2)^T$. So$[\mathrm{id}]_{\mathcal{B}}^{\mathcal{C}} = \frac{1}{2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}$, which is the transition matrix from$\mathcal{B}$ to$\mathcal{C}$.

The columns-are-images-of-basis-vectors rule is the operational definition of the matrix. To compute $[T]_{\mathcal{B}}^{\mathcal{C}}$ in practice: (1) apply$T$ to each basis vector$b_j$ of$V$; (2) express each$T(b_j)$ in the basis$\mathcal{C}$ of$W$; (3) these coordinate vectors are the columns of$[T]_{\mathcal{B}}^{\mathcal{C}}$. This three-step recipe is used throughout the book whenever we need to compute with a linear map explicitly.

\begin{remark}
Note the asymmetry: the domain basis $\mathcal{B}$ indexes the columns (we compute$T$ on each basis vector of$V$), while the codomain basis$\mathcal{C}$ indexes the rows (we express the result in terms of the basis of$W$). The matrix is$m \times n$ (rows$=$ codomain dimension, columns$=$ domain dimension), consistent with how matrix-vector multiplication works:$[T]_{\mathcal{B}}^{\mathcal{C}} \in M_{m \times n}(F)$ acts on column vectors in$F^n$ and produces column vectors in$F^m$. Keeping track of this asymmetry is essential for multi-step computations involving several maps in sequence.
\end{remark}
