# 7.3.2 Matrix Multiplication = Composition of Maps

Here is the conceptual heart of the chapter: the row–column rule for matrix multiplication is not an arbitrary definition, but the only definition consistent with composition of linear maps. Let us make this precise.

\begin{theorem}
Let $S: U \to V$ and$T: V \to W$ be linear maps, with ordered bases$\mathcal{A}$ on$U$,$\mathcal{B}$ on$V$, and$\mathcal{C}$ on$W$. Then
\par
$$[T \circ S]_{\mathcal{A}}^{\mathcal{C}} = [T]_{\mathcal{B}}^{\mathcal{C}} \cdot [S]_{\mathcal{A}}^{\mathcal{B}}.$$
\end{theorem}

\begin{proof}
Apply the fundamental equation of Section 7.3.1 twice: for any $u \in U$,

\begin{align*}
[(T \circ S)(u)]_{\mathcal{C}} &= [T(S(u))]_{\mathcal{C}} \\
&= [T]_{\mathcal{B}}^{\mathcal{C}} \cdot [S(u)]_{\mathcal{B}} \\
&= [T]_{\mathcal{B}}^{\mathcal{C}} \cdot \left([S]_{\mathcal{A}}^{\mathcal{B}} \cdot [u]_{\mathcal{A}}\right) \\
&= \left([T]_{\mathcal{B}}^{\mathcal{C}} \cdot [S]_{\mathcal{A}}^{\mathcal{B}}\right) \cdot [u]_{\mathcal{A}}.
\end{align*}

The third step uses the fundamental equation for $S$; the fourth uses associativity of matrix multiplication. This computation shows that$T \circ S$ acts on$[u]_{\mathcal{A}}$ the same way as the matrix product$[T]_{\mathcal{B}}^{\mathcal{C}} \cdot [S]_{\mathcal{A}}^{\mathcal{B}}$, so by uniqueness of the matrix (which is determined by where basis vectors go),$[T \circ S]_{\mathcal{A}}^{\mathcal{C}} = [T]_{\mathcal{B}}^{\mathcal{C}} \cdot [S]_{\mathcal{A}}^{\mathcal{B}}$.
\end{proof}

This theorem is the reason matrix multiplication is defined the way it is. The row–column rule is the unique multiplication on arrays of scalars that makes the identification of linear maps with matrices consistent with composition. Before this section, matrix multiplication might have seemed like an arbitrary convention; after it, the convention is revealed as forced upon us by geometry.

\begin{corollary}
Several further identities follow immediately:
\begin{enumerate}
\item $[\mathrm{id}_V]_{\mathcal{B}}^{\mathcal{B}} = I_n$ (the identity map has matrix equal to the identity matrix).
\item If $T$ is an isomorphism, then$[T^{-1}]_{\mathcal{C}}^{\mathcal{B}} = \left([T]_{\mathcal{B}}^{\mathcal{C}}\right)^{-1}$ (the matrix of the inverse is the inverse of the matrix).
\item Matrix multiplication is associative (since composition of functions is).
\end{enumerate}
\end{corollary}

**Example 1.** Composition of two linear maps on $\mathbb{R}^2$:$S(x,y) = (x+y, x-y)$ and$T(x,y) = (2x, 3y)$. With the standard basis,$[S] = \begin{pmatrix}1&1\\1&-1\end{pmatrix}$ and$[T] = \begin{pmatrix}2&0\\0&3\end{pmatrix}$. The composition$T \circ S$ has matrix$[T \circ S] = [T][S] = \begin{pmatrix}2&0\\0&3\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix} = \begin{pmatrix}2&2\\3&-3\end{pmatrix}$. Check:$(T \circ S)(x,y) = T(x+y, x-y) = (2(x+y), 3(x-y)) = (2x+2y, 3x-3y)$. The matrix$\begin{pmatrix}2&2\\3&-3\end{pmatrix}$ gives$(2x+2y, 3x-3y)$. Consistent.

**Example 2.** Differentiation and evaluation: let $D: F_{\leq 2}[x] \to F_{\leq 1}[x]$ be differentiation and$E: F_{\leq 1}[x] \to \mathbb{R}$ be evaluation at$x = 1$ (i.e.,$E(a + bx) = a + b$). With bases$(1, x, x^2)$ and$(1, x)$ and the standard basis for$\mathbb{R}$:$[D] = \begin{pmatrix}0&1&0\\0&0&2\end{pmatrix}$ (from Section 7.3.1) and$[E] = \begin{pmatrix}1&1\end{pmatrix}$ (since$E(1) = 1$ and$E(x) = 1$). Then$[E \circ D] = [E][D] = \begin{pmatrix}1&1\end{pmatrix}\begin{pmatrix}0&1&0\\0&0&2\end{pmatrix} = \begin{pmatrix}0&1&2\end{pmatrix}$. Check:$(E \circ D)(a + bx + cx^2) = E(b + 2cx) = b + 2c$. The matrix gives$(0 \cdot a + 1 \cdot b + 2 \cdot c) = b + 2c$. Correct.

**Example 3.** The matrix of $\mathrm{id}_V$ is$I_n$:$[\mathrm{id}_V(b_j)]_{\mathcal{B}} = [b_j]_{\mathcal{B}} = e_j$, so the$j$-th column of$[\mathrm{id}_V]_{\mathcal{B}}$ is$e_j$, which gives$I_n$.

The payoff is substantial. Every algebraic identity about linear maps — associativity of composition, the identity map as a multiplicative unit, inverses of invertible maps — translates directly into the corresponding identity for matrices. Linear algebra, as a computational discipline, is powered entirely by this translation.

**Example 4.** Three compositions in sequence: $R: \mathbb{R}^3 \to \mathbb{R}^3$,$S: \mathbb{R}^3 \to \mathbb{R}^2$,$T: \mathbb{R}^2 \to \mathbb{R}$. With matrices$[R] \in M_{3 \times 3}$,$[S] \in M_{2 \times 3}$,$[T] \in M_{1 \times 2}$: the composition$T \circ S \circ R$ has matrix$[T][S][R] \in M_{1 \times 3}$. By associativity of matrix multiplication, this can be computed as$([T][S])[R]$ or$[T]([S][R])$ — both give the same answer.

**Example 5.** Powers of a linear operator: if $T: V \to V$ is a linear operator and$[T] = A$ (in some basis), then$[T^n] = A^n$ for all$n \geq 0$, where$T^0 = \mathrm{id}$ corresponds to$A^0 = I_n$. This means we can compute$T^{100}$ by computing$A^{100}$ via matrix multiplication (or more cleverly, by diagonalizing$A$ if possible and then raising the diagonal entries to the$100$th power).

The theorem also has an important corollary about when a matrix is invertible as a linear map: $T: V \to V$ is an isomorphism iff$[T]_{\mathcal{B}}$ is an invertible matrix (for any/every basis$\mathcal{B}$). The inverse map$T^{-1}$ then has matrix$([T]_{\mathcal{B}})^{-1}$. This is because$[T \circ T^{-1}]_{\mathcal{B}} = [T]_{\mathcal{B}} \cdot [T^{-1}]_{\mathcal{B}} = [\mathrm{id}]_{\mathcal{B}} = I_n$, so$[T^{-1}]_{\mathcal{B}} = ([T]_{\mathcal{B}})^{-1}$.

\begin{remark}
The categorical statement underlying the theorem is that the assignment $T \mapsto [T]_{\mathcal{B}}^{\mathcal{C}}$ is a \emph{functor} from the category of finite-dimensional$F$-vector spaces (with linear maps as morphisms) to the category of matrices over$F$ (with matrix multiplication as composition). Choosing bases for all objects simultaneously turns the abstract category into a concrete, computable one. This perspective — that choosing bases is a choice of "coordinates" on the category of vector spaces — is one of the motivations for the more invariant approach of category theory.
\end{remark}
