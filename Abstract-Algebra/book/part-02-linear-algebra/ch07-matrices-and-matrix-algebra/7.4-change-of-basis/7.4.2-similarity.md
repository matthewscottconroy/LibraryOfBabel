# 7.4.2 Similarity: $A' = P^{-1}AP$

When we change the basis for a vector space $V$, the matrix representing a linear operator$T: V \to V$ changes in a specific way. The resulting transformation$A \mapsto P^{-1}AP$ defines a fundamental equivalence relation on square matrices.

\begin{theorem}[Change-of-Basis Formula for Operators]
Let $T: V \to V$ be a linear operator. Let$\mathcal{B}$ and$\mathcal{B}'$ be two ordered bases of$V$, and let$P = P_{\mathcal{B}' \to \mathcal{B}}$ be the transition matrix. Then
\par
$$[T]_{\mathcal{B}'} = P^{-1} [T]_{\mathcal{B}} P.$$
\end{theorem}

\begin{proof}
The coordinate map $[\,\cdot\,]_{\mathcal{B}}$ gives an isomorphism$V \cong F^n$ sending$T$ to$[T]_{\mathcal{B}}$. Changing to$\mathcal{B}'$ means composing with the change-of-coordinates map. More precisely, applying the fundamental equation twice:

$$[T(v)]_{\mathcal{B}'} = P^{-1} [T(v)]_{\mathcal{B}} = P^{-1} [T]_{\mathcal{B}} [v]_{\mathcal{B}} = P^{-1} [T]_{\mathcal{B}} P [v]_{\mathcal{B}'}.$$

The last step uses $[v]_{\mathcal{B}} = P [v]_{\mathcal{B}'}$. Since this holds for all$v$, the matrix of$T$ in$\mathcal{B}'$ is$P^{-1}[T]_{\mathcal{B}}P$.
\end{proof}

\begin{definition}
Two square matrices $A, A' \in M_{n \times n}(F)$ are called **similar** if there exists an invertible matrix$P \in GL_n(F)$ such that$A' = P^{-1}AP$.
\end{definition}

\begin{proposition}
Similarity is an equivalence relation on $M_{n \times n}(F)$.
\end{proposition}

\begin{proof}
Reflexive: $A = I^{-1}AI$. Symmetric: if$A' = P^{-1}AP$, then$A = (P^{-1})^{-1}A'(P^{-1}) = PA'P^{-1}$. Transitive: if$A' = P^{-1}AP$ and$A'' = Q^{-1}A'Q$, then$A'' = Q^{-1}P^{-1}APQ = (PQ)^{-1}A(PQ)$.
\end{proof}

The equivalence classes under similarity correspond exactly to linear operators on $V$: all matrices representing the same operator$T$ (in all possible ordered bases of$V$) form a single similarity class. The central question of matrix theory — and of the later chapters on eigenvalues and canonical forms — is: within each similarity class, what is the simplest representative?

**Example 1.** In $\mathbb{R}^2$, the rotation$R_{\pi/2}$ has matrix$A = \begin{pmatrix}0&-1\\1&0\end{pmatrix}$ in the standard basis. In the basis$\mathcal{B}' = ((1,i),(1,-i))$ over$\mathbb{C}$, where$i = \sqrt{-1}$, the transition matrix is$P = \begin{pmatrix}1&1\\i&-i\end{pmatrix}$. Then$P^{-1}AP = \begin{pmatrix}i&0\\0&-i\end{pmatrix}$ (a diagonal matrix). Over$\mathbb{C}$, every rotation can be diagonalized; over$\mathbb{R}$, this is impossible for non-trivial rotations.

**Example 2.** Two $2 \times 2$ matrices are similar iff they have the same trace and determinant (when the characteristic polynomial has distinct roots). Take$A = \begin{pmatrix}2&1\\0&3\end{pmatrix}$ and$B = \begin{pmatrix}3&0\\1&2\end{pmatrix}$. Both have trace$5$, determinant$6$, and characteristic polynomial$(\lambda-2)(\lambda-3) = \lambda^2 - 5\lambda + 6$. Both are diagonalizable over$F$ (distinct eigenvalues$2$ and$3$), so both are similar to$\mathrm{diag}(2,3) = \begin{pmatrix}2&0\\0&3\end{pmatrix}$. Hence$A \sim B$.

**Example 3.** Two matrices that are NOT similar: $A = \begin{pmatrix}1&1\\0&1\end{pmatrix}$ (a Jordan block) and$I_2 = \begin{pmatrix}1&0\\0&1\end{pmatrix}$. Both have trace$2$ and determinant$1$, but$A \neq I_2$. However,$P^{-1}I_2 P = I_2$ for any$P$, so$I_2$ is only similar to itself. Since$A \neq I_2$, they are not similar. The distinction is captured by the Jordan form:$I_2$ has a$1 \times 1$ +$1 \times 1$ Jordan form, while$A$ is itself a$2 \times 2$ Jordan block.

The concept of similarity underlies all of eigenvalue theory and canonical form theory. Finding the simplest matrix in a similarity class — whether that is a diagonal matrix (when the operator is diagonalizable), a Jordan canonical form (over algebraically closed fields), or a rational canonical form (over general fields) — is the main algorithmic problem of the latter chapters of this book.

**Example 4.** The effect of similarity on eigenvalues: if $A' = P^{-1}AP$ and$Av = \lambda v$ (so$v$ is an eigenvector of$A$ with eigenvalue$\lambda$), then$A'(P^{-1}v) = P^{-1}AP(P^{-1}v) = P^{-1}Av = P^{-1}(\lambda v) = \lambda(P^{-1}v)$. So$P^{-1}v$ is an eigenvector of$A'$ with the same eigenvalue$\lambda$. This confirms that eigenvalues are similarity invariants: similar matrices have the same set of eigenvalues (with the same multiplicities, as the characteristic polynomial is invariant).

\begin{remark}
The similarity orbit of a matrix $A$ — i.e., the set$\{P^{-1}AP : P \in GL_n(F)\}$ — is a subset of$M_{n \times n}(F)$ called a **conjugacy class** of$GL_n(F)$ acting on$M_{n \times n}(F)$ by conjugation. Understanding which orbits exist, what their closures are, and how they are stratified is a deep question in algebraic geometry and representation theory, related to the theory of nilpotent orbits, flag varieties, and the Springer correspondence.
\end{remark}

The practical takeaway is: when working with a linear operator $T$, we are free to choose whatever basis makes the computation most convenient, knowing that any two such choices give similar matrices. The "simplest" representative in the similarity class — diagonal if possible, Jordan normal form otherwise — is the form we seek for spectral analysis and for solving linear differential and difference equations.
