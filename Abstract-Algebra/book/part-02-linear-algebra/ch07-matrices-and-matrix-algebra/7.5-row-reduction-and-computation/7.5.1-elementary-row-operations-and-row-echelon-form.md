# 7.5.1 Elementary Row Operations and Row Echelon Form

Solving a system of linear equations is one of the oldest problems in mathematics, and row reduction (Gaussian elimination) is the systematic procedure that makes it tractable. The idea is to simplify a linear system by replacing it with an equivalent one — having exactly the same solution set — until the system is easy to read off.

\begin{definition}
The three types of **elementary row operations** on a matrix $A \in M_{m \times n}(F)$ are:
\begin{enumerate}
\item[(R1)] \textbf{Row swap}: interchange row $i$ and row$j$ ($i \neq j$).
\item[(R2)] \textbf{Row scaling}: multiply row $i$ by a nonzero scalar$c \in F^\times$.
\item[(R3)] \textbf{Row replacement}: add $c$ times row$j$ to row$i$ (for$i \neq j$,$c \in F$).
\end{enumerate}
\end{definition}

Each elementary row operation preserves the solution set of the linear system $Ax = b$: swapping rows just reorders equations; scaling scales both sides of an equation; row replacement adds a multiple of one equation to another without changing the solution set.

\begin{proposition}
Each elementary row operation corresponds to left-multiplication by an invertible **elementary matrix** $E$, obtained by applying that operation to the identity matrix$I_m$. In particular, each elementary row operation is invertible (undone by another row operation of the same type).
\end{proposition}

\begin{proof}
For (R1): swapping rows $i$ and$j$ in$I_m$ gives the permutation matrix$E_{ij}^{(1)}$; then$E_{ij}^{(1)} A$ is$A$ with rows$i$ and$j$ swapped. Applying the same operation again gives$I_m$, so$(E_{ij}^{(1)})^2 = I_m$ and the operation is self-inverse. For (R2): scaling row$i$ by$c$ gives$E_i^{(c)}$ (diagonal matrix with$c$ in position$(i,i)$, ones elsewhere); its inverse scales row$i$ by$c^{-1}$. For (R3): adding$c$ times row$j$ to row$i$ gives the unitriangular matrix$E_{ij}^{(c)} = I_m + cE_{ij}^{\mathrm{std}}$; its inverse is$I_m - cE_{ij}^{\mathrm{std}}$.
\end{proof}

Applying a sequence of row operations to $A$ gives$E_k \cdots E_1 A$ for elementary matrices$E_1, \ldots, E_k$; their product$E = E_k \cdots E_1$ is invertible (as a product of invertible matrices), so the row space of$E_k \cdots E_1 A$ is the same as that of$A$.

\begin{definition}
A matrix is in **row echelon form** (REF) if:
\begin{enumerate}
\item All zero rows are at the bottom.
\item The **leading entry** (leftmost nonzero entry) of each nonzero row lies strictly to the right of the leading entry of the row above it.
\end{enumerate}
The leading entries are called **pivots**.
\end{definition}

Any matrix can be reduced to row echelon form by systematically applying the algorithm: find the leftmost nonzero column, bring a nonzero entry to the top (by a row swap if needed), scale to normalize (optional at this stage), then eliminate all entries below it using row replacement. Repeat for the submatrix below and to the right of the current pivot. This algorithm terminates in finitely many steps.

**Example 1.** Reduce $A = \begin{pmatrix}0 & 2 & 4 \\ 1 & 3 & 5 \\ 2 & 4 & 6\end{pmatrix}$ to REF.

Swap rows 1 and 2: $\begin{pmatrix}1&3&5\\0&2&4\\2&4&6\end{pmatrix}$. Subtract$2 \times$ row 1 from row 3:$\begin{pmatrix}1&3&5\\0&2&4\\0&-2&-4\end{pmatrix}$. Add row 2 to row 3:$\begin{pmatrix}1&3&5\\0&2&4\\0&0&0\end{pmatrix}$. This is REF with pivots in columns 1 and 2; rank is$2$.

**Example 2.** Reduce $B = \begin{pmatrix}2&4&-2\\4&9&-3\\-2&-3&7\end{pmatrix}$.

Scale row 1 by $1/2$... or better: subtract$2 \times$ row 1 from row 2:$\begin{pmatrix}2&4&-2\\0&1&1\\-2&-3&7\end{pmatrix}$. Add row 1 to row 3:$\begin{pmatrix}2&4&-2\\0&1&1\\0&1&5\end{pmatrix}$. Subtract row 2 from row 3:$\begin{pmatrix}2&4&-2\\0&1&1\\0&0&4\end{pmatrix}$. REF with 3 pivots; rank is$3$, so$B$ is invertible.

**Example 3.** The matrix $\begin{pmatrix}1&2&3\\4&5&6\\7&8&9\end{pmatrix}$: after eliminating,$R_2 \to R_2 - 4R_1 = (0,-3,-6)$ and$R_3 \to R_3 - 7R_1 = (0,-6,-12)$. Then$R_3 \to R_3 - 2R_2 = (0,0,0)$. REF:$\begin{pmatrix}1&2&3\\0&-3&-6\\0&0&0\end{pmatrix}$. Rank$2$; the rows are dependent (the middle row is the arithmetic mean of outer rows in the original).

Row echelon form is not unique — different sequences of row operations can yield different echelon forms — but the number of pivots (the rank) is always the same. The next subsection shows that by continuing the reduction process we can reach a unique canonical form.

The row echelon form has a natural interpretation in terms of the linear map $T_A: F^n \to F^m$. The pivot columns of the REF correspond to the pivot columns of$A$ — those columns that form a basis for the column space of$A$. The non-pivot columns correspond to the free variables, i.e., the dimensions of the null space. The rank equals the number of pivots, which equals$\dim(\mathrm{col}(A))$ by the theory developed in Sections 6.2.2 and 6.2.3.

\begin{proposition}[Row Operations Preserve Row Space]
Row operations do not change the row space of a matrix: $\mathrm{row}(A) = \mathrm{row}(EA)$ for any elementary matrix$E$.
\end{proposition}

\begin{proof}
Multiplication by $E$ on the left replaces each row of$A$ by a linear combination of the rows of$A$. Therefore every row of$EA$ is in$\mathrm{row}(A)$, so$\mathrm{row}(EA) \subseteq \mathrm{row}(A)$. Since$E$ is invertible,$A = E^{-1}(EA)$, and the same argument gives$\mathrm{row}(A) \subseteq \mathrm{row}(EA)$.
\end{proof}

\begin{remark}
Row operations do NOT preserve the column space in general. For example, swapping two rows of $A$ changes which linear combinations of the columns appear in the column space. However, the dimension of the column space (the rank) is preserved, because rank equals the number of pivots, and the pivots are a well-defined property of the matrix (as we prove in Section 7.5.2 via uniqueness of RREF).
\end{remark}

**Example 4.** Elementary matrices explicitly: the row operation "add $2$ times row 1 to row 2" on a$3 \times n$ matrix corresponds to left-multiplication by$E = \begin{pmatrix}1&0&0\\2&1&0\\0&0&1\end{pmatrix}$. Its inverse is$\begin{pmatrix}1&0&0\\-2&1&0\\0&0&1\end{pmatrix}$ (subtract$2$ times row 1 from row 2). The product$E_k \cdots E_1 A$ (where$E_1, \ldots, E_k$ are all the elementary matrices applied in sequence) equals the REF of$A$ if we stop after forward elimination, or the RREF if we continue through back-substitution.
