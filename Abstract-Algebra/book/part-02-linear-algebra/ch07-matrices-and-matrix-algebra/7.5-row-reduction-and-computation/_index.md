# 7.5 Row Reduction and Computation

Row reduction is the fundamental algorithm of computational linear algebra. It converts any matrix into a simplified form by a sequence of elementary row operations, and from that simplified form one can read off the rank, a basis for the null space, the general solution to a linear system, and (when applicable) the matrix inverse. Despite being an algorithm, row reduction has a clean theoretical foundation: each elementary row operation corresponds to left-multiplication by an invertible elementary matrix, so the reduction process is a structured factorization, not an ad hoc manipulation.

The three elementary row operations are: (I) swap two rows; (II) multiply a row by a nonzero scalar; (III) add a scalar multiple of one row to another. Any matrix can be brought to row echelon form — where all nonzero rows appear above zero rows, and each nonzero row's leading entry (called a pivot) lies strictly to the right of the pivot in the row above — by performing these operations in a systematic order. Row echelon form is not unique, but reduced row echelon form (RREF), where each pivot is 1 and all other entries in the pivot's column are 0, is unique for any given matrix. The uniqueness of RREF is a theorem, not obvious from the algorithm, and its proof requires a careful inductive argument.

The applications are numerous. For a linear system $Ax = b$, augmenting $A$ with the column $b$ and row-reducing reveals: whether the system is consistent (no pivot in the last column of the augmented matrix), what the particular solution looks like (reading off the pivot variables), and what the null space of $A$ looks like (free variables parameterize it). The rank of $A$ equals the number of pivots, and the nullity equals the number of free variables, making RREF a direct computational proof of rank-nullity for any specific matrix. To compute $A^{-1}$ for an invertible square matrix, one augments with the identity $[A \mid I]$ and row-reduces: the result is $[I \mid A^{-1}]$.

The section also clarifies the theoretical relationship between row operations and matrix factorization. If $E_1, E_2, \ldots, E_k$ are the elementary matrices corresponding to the row operations that bring $A$ to RREF $R$, then $E_k \cdots E_2 E_1 A = R$, or equivalently $A = E_1^{-1} E_2^{-1} \cdots E_k^{-1} R$. When $A$ is square and invertible, $R = I$ and the product $E_1^{-1} \cdots E_k^{-1}$ is $A^{-1}$. The LU decomposition arises by tracking only the type-III operations in a specific order, yielding the factorization $A = LU$ into lower and upper triangular matrices, which is the practical algorithm behind most numerical linear algebra software.
