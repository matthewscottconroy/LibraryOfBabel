# Chapter 7 — Matrices and Matrix Algebra

A matrix is a rectangular array of scalars, but that description undersells what matrices are really for. The central insight of this chapter is that matrices are the coordinate representations of linear maps. Once a basis has been chosen for each of the domain and codomain, every linear map $T: V \to W$ corresponds uniquely to an $m \times n$ matrix $[T]_{\mathcal{B}}^{\mathcal{C}}$, and every operation on linear maps — composition, inversion, addition — corresponds to an operation on matrices. This correspondence converts abstract questions about linear maps into concrete computational questions about arrays of numbers, and the resulting algebra of matrices is one of the most powerful calculational tools in all of mathematics.

The chapter begins with matrices as pure arrays, establishing notation and the elementary operations. Matrix addition and scalar multiplication are defined entry-wise, making $M_{m \times n}(F)$ a vector space of dimension $mn$. The more interesting operation is matrix multiplication, whose definition — the row-column rule — appears at first to be arbitrary but is revealed to be precisely the rule that makes composition of linear maps correspond to multiplication of matrices. Associativity of matrix multiplication follows from associativity of composition; non-commutativity follows from the non-commutativity of composition of linear maps. The transpose, identity matrix, symmetric and skew-symmetric matrices, and block decompositions round out the initial toolkit.

The chapter's conceptual heart is the matrix of a linear map. Given ordered bases $\mathcal{B} = (b_1, \ldots, b_n)$ for $V$ and $\mathcal{C} = (c_1, \ldots, c_m)$ for $W$, the matrix $[T]_{\mathcal{B}}^{\mathcal{C}}$ is built by computing $T(b_j)$ for each basis vector and writing its $\mathcal{C}$-coordinates as the $j$-th column. The main theorem is the composition rule: $[S \circ T]_{\mathcal{B}}^{\mathcal{E}} = [S]_{\mathcal{C}}^{\mathcal{E}} [T]_{\mathcal{B}}^{\mathcal{C}}$, meaning that matrix multiplication is the translation of map composition into coordinates. This result is not merely convenient; it is the reason matrix multiplication is defined the way it is.

Change of basis occupies a substantial section of the chapter, because a single linear map $T: V \to V$ has many different matrix representations depending on which basis is chosen for $V$. Two matrices $A$ and $B$ representing the same linear map in different bases are related by $B = P^{-1} A P$ for some invertible matrix $P$ — they are called similar. Similarity is an equivalence relation, and each similarity class corresponds to exactly one linear operator (up to isomorphism). The scalars left unchanged by similarity — the trace, the determinant, and more generally the characteristic polynomial — are the intrinsic invariants of the operator, independent of any basis. Understanding which matrix in a similarity class is the "simplest" representative is the problem of canonical forms, developed in Chapters 9 and 10.

The chapter closes with row reduction, the algorithmic workhorse of linear algebra. Gaussian elimination reduces a matrix to row echelon form by a sequence of elementary row operations, each of which corresponds to left-multiplication by an elementary matrix. The reduced row echelon form is unique, and reading it off yields the rank of the matrix, a basis for the null space, and the general solution to the system $Ax = b$. The connection between the row space, column space, and null space — all encoded in the reduced row echelon form — provides a complete geometric picture of what a matrix does as a linear map.
