# 8.2.4 Row Reduction: The Efficient Method

For matrices of size $n \geq 4$, neither the Leibniz formula nor cofactor expansion is efficient: the former requires$n!$ operations and the latter requires computing a full tree of$(n-1) \times (n-1)$ minors (though with caching this costs$O(n \cdot (n-1)!)$). Row reduction offers an approach that is both theoretically clean and computationally practical, running in$O(n^3)$ arithmetic operations — the same asymptotic cost as ordinary Gaussian elimination.

The method exploits the consequences from Section 8.1.3, which tell us precisely how each elementary row operation transforms the determinant:
- Swapping two rows multiplies $\det$ by$-1$.
- Scaling a row by $c \neq 0$ multiplies$\det$ by$c$.
- Adding a multiple of one row to another leaves $\det$ unchanged.

We apply these operations systematically — exactly as in Gaussian elimination — until the matrix is **upper triangular**. For an upper triangular matrix $U$, the only nonzero term in the Leibniz formula is the one indexed by the identity permutation (all other permutations require some entry below the diagonal, which is zero). Thus$\det(U) = \prod_{i=1}^n U_{ii}$, the product of the diagonal entries (the pivots).

The algorithm: reduce $A$ to upper triangular form$U$ via a sequence of elementary row operations. Let$s$ be the number of row swaps performed, and let$c_1, \ldots, c_k$ be the scaling factors used (if any rows were scaled). No row additions contribute any factor. Then:
$$\det(A) = (-1)^s \cdot \frac{1}{c_1 \cdots c_k} \cdot \prod_i U_{ii}.$$
In practice, one typically avoids explicit row scalings (to keep computations over integers or simple fractions) and uses partial pivoting — swapping rows to place the largest available entry in the pivot position.

The row-reduction method also immediately identifies singular matrices: if a zero pivot is encountered during the reduction, the process signals that $A$ has zero determinant. Specifically, when the algorithm attempts to reduce column$j$ and finds all entries in or below the pivot position to be zero, it cannot proceed without creating a zero row. This means$\det(A) = 0$, which is consistent with the geometric interpretation that$A$ collapses$n$-dimensional volume to zero — meaning the rows of$A$ are linearly dependent.

In exact arithmetic (over $\mathbb{Q}$ or a finite field), this algorithm computes$\det(A)$ in$O(n^3)$ field operations. In floating-point arithmetic, care must be taken with rounding: using partial pivoting (swapping to put the largest pivot in position at each step) avoids catastrophic cancellation and yields numerically stable results. This is the standard algorithm used in production numerical linear algebra libraries.

\begin{example}
**Example 1.** Compute $\det\begin{pmatrix}2&1&3\\4&5&6\\1&2&1\end{pmatrix}$ by row reduction. Subtract 2 times row 1 from row 2 (Type III):
$R_2 \leftarrow R_2 - 2R_1$: row 2 becomes$(0, 3, 0)$. Subtract$\frac{1}{2}$ row 1 from row 3 (Type III):$R_3 \leftarrow R_3 - \frac{1}{2}R_1$: row 3 becomes$(0, \frac{3}{2}, -\frac{1}{2})$. Matrix is now$\begin{pmatrix}2&1&3\\0&3&0\\0&\frac{3}{2}&-\frac{1}{2}\end{pmatrix}$. Subtract$\frac{1}{2}$ row 2 from row 3:$R_3 \leftarrow R_3 - \frac{1}{2}R_2$: row 3 becomes$(0, 0, -\frac{1}{2})$. Upper triangular with diagonal$2, 3, -\frac{1}{2}$. No row swaps, no row scalings.$\det = 2 \cdot 3 \cdot (-\frac{1}{2}) = -3$.
\end{example}

\begin{example}
**Example 2.** A row swap is needed. Let $A = \begin{pmatrix}0&2&1\\3&1&4\\1&2&3\end{pmatrix}$. The$(1,1)$ entry is$0$, so we must pivot. Swap rows 1 and 3: multiply accumulated sign by$-1$. New matrix:$\begin{pmatrix}1&2&3\\3&1&4\\0&2&1\end{pmatrix}$. Now eliminate:$R_2 \leftarrow R_2 - 3R_1$: row 2 becomes$(0,-5,-5)$. Row 3 is already$0$ in column 1. Upper triangularize column 2:$R_3 \leftarrow R_3 - (-\frac{2}{5})R_2 = R_3 + \frac{2}{5}R_2$: row 3 becomes$(0,0,1-2) = (0,0,-1)$. Upper triangular:$\begin{pmatrix}1&2&3\\0&-5&-5\\0&0&-1\end{pmatrix}$. One swap, no scalings.$\det(A) = (-1)^1 \cdot (1)(-5)(-1) = (-1)(5) = -5$.
\end{example}

\begin{example}
**Example 3.** Detect singularity. Let $A = \begin{pmatrix}1&2&3\\2&4&6\\1&1&1\end{pmatrix}$. Subtract 2 times row 1 from row 2: row 2 becomes$(0,0,0)$. A zero row appears. We conclude$\det(A) = 0$ immediately. Indeed, row 2 =$2 \times$ row 1, so the rows are linearly dependent.
\end{example}

\begin{example}
**Example 4.** Combine scaling and swaps carefully. Let $A = \begin{pmatrix}0&3\\5&2\end{pmatrix}$. To avoid fractions, swap rows first:$\begin{pmatrix}5&2\\0&3\end{pmatrix}$, one swap (sign factor$-1$). This is already upper triangular with diagonal$5, 3$.$\det(A) = (-1)(5)(3) = -15$. Verify directly:$\det = 0 \cdot 2 - 3 \cdot 5 = -15$. Correct.
\end{example}
