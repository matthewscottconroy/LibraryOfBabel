# 8.3.3 Cramer's Rule

Cramer's rule gives an explicit formula for the solution to a linear system $Ax = b$ when$A$ is invertible. It is a direct consequence of the adjugate formula from the previous section, and while it is not competitive with row reduction as a computational method, it plays an important role in proofs where one needs to know that a solution depends smoothly or algebraically on parameters.

Let $A$ be an invertible$n \times n$ matrix and$b \in F^n$. Define$A_j(b)$ to be the matrix obtained from$A$ by replacing its$j$-th column with$b$, leaving all other columns unchanged. Then the unique solution$x = A^{-1}b$ has components

$$x_j = \frac{\det(A_j(b))}{\det(A)}, \qquad j = 1, \ldots, n.$$

The derivation is clean. Since $x = A^{-1}b = \frac{1}{\det(A)}\mathrm{adj}(A) \cdot b$, the$j$-th component is
$$x_j = \frac{1}{\det(A)} \sum_{k=1}^n \mathrm{adj}(A)_{jk} b_k = \frac{1}{\det(A)} \sum_{k=1}^n C_{kj} b_k.$$
The sum $\sum_k C_{kj} b_k$ is the cofactor expansion of$\det(A_j(b))$ along column$j$ (using the entries$b_k$ in place of the original column$j$ entries, with cofactors$C_{kj}$ unchanged since columns other than$j$ are unchanged). This gives Cramer's rule.

Computationally, Cramer's rule requires evaluating $n+1$ determinants of$n \times n$ matrices — a total cost of$O(n^4)$ via row reduction (computing$n+1$ determinants each in$O(n^3)$), compared to$O(n^3)$ for directly row-reducing the augmented system$[A | b]$. So for numerical work, Cramer's rule is never preferred. Its theoretical value lies elsewhere.

The primary application is in arguments where one needs to control how solutions depend on parameters. If the entries of $A$ and$b$ depend on a parameter$t$ (analytically, smoothly, or polynomially), then$x_j(t) = \det(A_j(b(t)))/\det(A(t))$ inherits that regularity as long as$\det(A(t)) \neq 0$. This is used in establishing the implicit function theorem in differential geometry, where one needs to know that the solution to an implicit equation is smooth in the parameters; Cramer's rule provides explicit smooth formulas. It is also used in number theory when arguing that solutions over$\mathbb{Z}$ or$\mathbb{Q}$ inherit integrality or rationality from the data.

A second application is in proofs about invariance. Because Cramer's rule is a coordinate formula, it allows one to write invariant-theoretic statements about solutions to linear systems in terms of determinants, which are in turn related to exterior powers (Section 12.4). The deepest connection is to the theory of resultants and the Nullstellensatz, but even at this level Cramer's rule is the entry point.

\begin{example}
**Example 1.** Solve $\begin{pmatrix}2&1\\5&3\end{pmatrix}\begin{pmatrix}x\\y\end{pmatrix} = \begin{pmatrix}4\\11\end{pmatrix}$ using Cramer's rule. Here$\det(A)=1$. Then:
$$x_1 = \frac{\det\begin{pmatrix}4&1\\11&3\end{pmatrix}}{1} = 12-11=1, \qquad x_2 = \frac{\det\begin{pmatrix}2&4\\5&11\end{pmatrix}}{1} = 22-20=2.$$
Solution: $(x,y) = (1,2)$. Check:$2(1)+1(2)=4$,$5(1)+3(2)=11$. Correct.
\end{example}

\begin{example}
**Example 2.** Solve a $3 \times 3$ system. Consider$A = \begin{pmatrix}1&0&2\\0&1&-1\\1&1&0\end{pmatrix}$ and$b = \begin{pmatrix}5\\1\\4\end{pmatrix}$. First,$\det(A) = 1(0+1)-0+2(0-1) = 1-2=-1$. Now:
$$x_1 = \frac{\det\begin{pmatrix}5&0&2\\1&1&-1\\4&1&0\end{pmatrix}}{-1}.$$
Expanding along column 1: $5\det\begin{pmatrix}1&-1\\1&0\end{pmatrix}-1\det\begin{pmatrix}0&2\\1&0\end{pmatrix}+4\det\begin{pmatrix}0&2\\1&-1\end{pmatrix} = 5(0+1)-1(0-2)+4(0-2)=5+2-8=-1$. So$x_1 = (-1)/(-1)=1$. Similarly one finds$x_2=2, x_3=2$.
\end{example}

\begin{example}
**Example 3.** Cramer's rule shows continuity of solutions. Let $A(t) = \begin{pmatrix}t&1\\1&t\end{pmatrix}$ and$b = \begin{pmatrix}1\\0\end{pmatrix}$ for$t \neq \pm 1$ (so$\det(A(t))=t^2-1\neq 0$). By Cramer's rule:
$$x_1(t) = \frac{\det\begin{pmatrix}1&1\\0&t\end{pmatrix}}{t^2-1} = \frac{t}{t^2-1}, \qquad x_2(t) = \frac{\det\begin{pmatrix}t&1\\1&0\end{pmatrix}}{t^2-1} = \frac{-1}{t^2-1}.$$
Both are rational (hence smooth) functions of $t$ for$t \neq \pm 1$, illustrating how Cramer's rule certifies smoothness of solutions in parameters.
\end{example}

\begin{example}
**Example 4.** Over the integers. Let $A \in M_3(\mathbb{Z})$ with$\det(A) = 1$ (a unimodular matrix) and$b \in \mathbb{Z}^3$. By Cramer's rule, each$x_j = \det(A_j(b))/\det(A) = \det(A_j(b)) \in \mathbb{Z}$ (since$\det(A_j(b))$ is an integer determinant with all integer entries). So any unimodular integer matrix maps integer right-hand sides to integer solutions. This is the key property of the modular group$SL_2(\mathbb{Z})$ and its higher-dimensional analogs.
\end{example}
