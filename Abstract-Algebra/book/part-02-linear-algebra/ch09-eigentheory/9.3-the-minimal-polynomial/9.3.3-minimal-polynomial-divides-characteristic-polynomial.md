# 9.3.3 Minimal Polynomial Divides Characteristic Polynomial

The Cayley–Hamilton theorem established that $m_T \mid p_T$. We now examine the relationship between these two polynomials more carefully, asking both about divisibility and about which information each one carries. The answer reveals a precise dictionary: both polynomials share the same roots, but they count multiplicities differently.

\begin{theorem}
The minimal polynomial $m_T$ and the characteristic polynomial$p_T$ satisfy:
\begin{enumerate}
\item $m_T \mid p_T$.
\item $m_T$ and$p_T$ have exactly the same irreducible factors over$F$ (though possibly with different multiplicities).
\end{enumerate}
\end{theorem}

The divisibility $m_T \mid p_T$ was established in Section 9.3.2. For part (2): every eigenvalue is a root of$m_T$ (as we show below), and every root of$m_T$ is a root of$p_T$ by divisibility, and roots of$p_T$ are eigenvalues. So the two polynomials have the same roots, hence the same irreducible factors over$F$.

**Every eigenvalue is a root of $m_T$.** Suppose$Tv = \lambda v$ with$v \neq 0$. Then$m_T(T)v = m_T(\lambda)v$. Since$m_T(T) = 0$, we get$m_T(\lambda) v = 0$, hence$m_T(\lambda) = 0$ (as$v \neq 0$). So every eigenvalue is a root of$m_T$.

\begin{example}
**Example 1.** Let $T$ have Jordan form$J = \mathrm{diag}(J_2(3), J_1(3)) = \begin{pmatrix}3&1&0\\0&3&0\\0&0&3\end{pmatrix}$. The characteristic polynomial is$p_T(x) = (x-3)^3$ and the minimal polynomial is$m_T(x) = (x-3)^2$, since$(J - 3I)^2 = \begin{pmatrix}0&0&0\\0&0&0\\0&0&0\end{pmatrix}$ but$(J - 3I) \neq 0$. Here$m_T \mid p_T$ and both have$(x-3)$ as their only irreducible factor, but with different multiplicities (2 vs. 3).
\end{example}

\begin{example}
**Example 2.** Let $T$ have Jordan form$J = \mathrm{diag}(J_1(1), J_1(2), J_2(2))$. The characteristic polynomial is$p_T(x) = (x-1)(x-2)^3$ and the minimal polynomial is$m_T(x) = (x-1)(x-2)^2$. The exponent of$(x-2)$ in$m_T$ is 2, matching the largest Jordan block size for eigenvalue 2.
\end{example}

The general pattern is:

\begin{proposition}
If the Jordan form of $T$ contains Jordan blocks of sizes$k_1 \geq k_2 \geq \cdots$ for eigenvalue$\lambda$, then the factor$(x-\lambda)^{k_1}$ appears in$m_T$ (with exponent$k_1$, the largest block size), while$p_T$ contains$(x-\lambda)^{k_1 + k_2 + \cdots}$.
\end{proposition}

This means $m_T$ "sees" only the size of the largest Jordan block at each eigenvalue, while$p_T$ sees their total. In particular,$m_T = p_T$ if and only if each eigenvalue has exactly one Jordan block, a condition equivalent to the rational canonical form having a single companion matrix block for each eigenvalue.

\begin{example}
**Example 3.** For $T = \mathrm{diag}(J_3(\lambda), J_3(\lambda))$ (two Jordan blocks of size 3 for the same eigenvalue),$p_T(x) = (x-\lambda)^6$ while$m_T(x) = (x-\lambda)^3$. The minimal polynomial "collapses" the two blocks to their common maximum size.
\end{example}

\begin{example}
**Example 4.** For a diagonal matrix $D = \mathrm{diag}(\lambda_1, \lambda_2, \ldots, \lambda_n)$ with distinct diagonal entries,$m_D(x) = \prod_{i}(x - \lambda_i) = p_D(x)$: minimal and characteristic polynomials coincide.
\end{example}

\begin{remark}
The relationship $m_T \mid p_T$ combined with$p_T \mid m_T^n$ (since$m_T^n$ certainly annihilates$T$ when$\deg m_T \cdot n \geq \deg p_T$) places$m_T$ and$p_T$ as two extremes of the same divisibility chain. In the module-theoretic treatment of Part V, the invariant factors$f_1 \mid f_2 \mid \cdots \mid f_r$ of$V$ as an$F[x]$-module interpolate between them:$m_T = f_r$ (the largest invariant factor) and$p_T = \prod_i f_i$ (their product).
\end{remark}
