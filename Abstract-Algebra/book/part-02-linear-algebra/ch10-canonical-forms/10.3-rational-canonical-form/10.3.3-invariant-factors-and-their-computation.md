# 10.3.3 Invariant Factors and Their Computation

The invariant factors $f_1 \mid f_2 \mid \cdots \mid f_r$ are the complete invariants of$T$ up to similarity over$F$: two operators are similar if and only if they have identical invariant factor sequences. But how do we compute them from a given matrix?

**Module-theoretic description.** The vector space $V$ is an$F[x]$-module via$f(x) \cdot v = f(T)(v)$. Since$F[x]$ is a PID, the structure theorem for finitely generated modules over a PID applies:
$$V \cong F[x]/(f_1) \oplus F[x]/(f_2) \oplus \cdots \oplus F[x]/(f_r)$$
with $f_1 \mid f_2 \mid \cdots \mid f_r$. The polynomials$f_i$ are the invariant factors of this module decomposition, uniquely determined by$T$. The full module-theoretic proof appears in Part V; here we focus on the computational side.

**Smith normal form.** The most systematic approach uses the Smith normal form of the **characteristic matrix** $xI - A \in M_n(F[x])$. Using elementary row and column operations over$F[x]$ (adding polynomial multiples of rows/columns, swapping rows or columns, multiplying a row or column by a nonzero scalar in$F$), we reduce$xI - A$ to a diagonal matrix$\mathrm{diag}(d_1, d_2, \ldots, d_n)$ with$d_i \mid d_{i+1}$. The nonunit diagonal entries (those$d_i$ not equal to$1$) are the invariant factors.

\begin{example}
**Example 1.** Let $A = \begin{pmatrix}2&0\\0&2\end{pmatrix}$. Then$xI - A = \begin{pmatrix}x-2&0\\0&x-2\end{pmatrix}$. This is already diagonal with$d_1 = x-2$,$d_2 = x-2$. The invariant factors are$f_1 = x - 2$ and$f_2 = x - 2$ (with$f_1 \mid f_2$). Minimal polynomial:$f_2 = x - 2$. Characteristic polynomial:$(x-2)^2$.
\end{example}

\begin{example}
**Example 2.** Let $A = \begin{pmatrix}2&1\\0&2\end{pmatrix} = J_2(2)$. Then$xI - A = \begin{pmatrix}x-2&-1\\0&x-2\end{pmatrix}$. Column-add$(x-2)$ times column 2 to column 1:$\begin{pmatrix}(x-2)^2-(-1)(0)&-1\\-1(x-2)&x-2\end{pmatrix}$... Actually let us do it cleanly: swap the columns to get$\begin{pmatrix}-1&x-2\\x-2&0\end{pmatrix}$, multiply row 1 by$-1$:$\begin{pmatrix}1&-(x-2)\\x-2&0\end{pmatrix}$, clear column 1 by adding$-(x-2)$ times row 1 to row 2:$\begin{pmatrix}1&-(x-2)\\0&(x-2)^2\end{pmatrix}$, clear row 1:$\begin{pmatrix}1&0\\0&(x-2)^2\end{pmatrix}$. So$d_1 = 1$,$d_2 = (x-2)^2$. Single invariant factor$f_1 = (x-2)^2$. Minimal polynomial$= (x-2)^2 =$ characteristic polynomial.
\end{example}

\begin{example}
**Example 3.** Let $A$ have$p_A(x) = (x-1)(x-2)(x-3)$ with distinct eigenvalues. The Smith normal form of$xI - A$ has$d_1 = d_2 = 1$ and$d_3 = (x-1)(x-2)(x-3)$, since the GCD of all$2 \times 2$ minors of$xI - A$ (when the eigenvalues are distinct) equals 1. Single invariant factor$f_1 = (x-1)(x-2)(x-3)$.
\end{example}

The key invariance theorem:

\begin{theorem}
The Smith normal form of $xI - A$ (equivalently, the invariant factors) depends only on the similarity class of$A$: if$A$ and$B$ are similar over$F$, then$xI - A$ and$xI - B$ are equivalent over$F[x]$ and have the same Smith normal form.
\end{theorem}

The minimal polynomial equals $f_r$, the largest invariant factor, and can be read off as the last diagonal entry of the Smith normal form. If only the minimal polynomial is needed, a more direct computation using the Cayley–Hamilton theorem and polynomial division often suffices — one tests whether$(T - \lambda_1 I)^{a_1 - 1} \cdots$ annihilates$T$ to determine the exponents appearing in$m_T$.

\begin{remark}
The GCD of all $k \times k$ minors of$xI - A$ (the$k$-th determinantal divisor$D_k$) satisfies$D_k = d_1 d_2 \cdots d_k$, giving an alternative computation of the Smith normal form via determinantal divisors:$d_k = D_k / D_{k-1}$.
\end{remark}
