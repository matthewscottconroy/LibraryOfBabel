# 11.5.3 Rank, Pseudoinverse, and Least Squares via SVD

The SVD $A = U\Sigma V^*$ puts three fundamental computational problems — determining rank, inverting non-square or rank-deficient matrices, and solving least-squares systems — on a single unified footing.

**Rank.** The rank of $A$ reads off immediately from the SVD:$\mathrm{rank}(A)$ equals the number of nonzero singular values$r$. More than a formula, this is a geometric fact: the image of$A$ has dimension exactly$r$, spanned by the first$r$ left singular vectors$u_1, \ldots, u_r$ (the "left singular vectors with positive singular values"), while the null space of$A$ is spanned by the last$n - r$ right singular vectors$v_{r+1}, \ldots, v_n$. Thus the SVD gives simultaneously orthonormal bases for all four fundamental subspaces:
- $\mathrm{Col}(A) = \mathrm{span}\{u_1, \ldots, u_r\}$
- $\mathrm{Null}(A) = \mathrm{span}\{v_{r+1}, \ldots, v_n\}$
- $\mathrm{Row}(A) = \mathrm{span}\{v_1, \ldots, v_r\}$
- $\mathrm{Null}(A^*) = \mathrm{span}\{u_{r+1}, \ldots, u_m\}$

**The Moore–Penrose Pseudoinverse.** When $A$ is square and invertible,$A^{-1} = V\Sigma^{-1}U^*$. For a non-square or rank-deficient matrix, the natural generalization is:

\begin{definition}
The **Moore–Penrose pseudoinverse** is $A^+ = V\Sigma^+ U^*$, where$\Sigma^+$ is obtained from$\Sigma$ by replacing each nonzero singular value$\sigma_i$ by$1/\sigma_i$ (and transposing). Explicitly, if$\Sigma \in M_{m \times n}$ with positive entries$\sigma_1, \ldots, \sigma_r$, then$\Sigma^+ \in M_{n \times m}$ has$(\Sigma^+)_{ii} = 1/\sigma_i$ for$i \leq r$ and$0$ elsewhere.
\end{definition}

\begin{example}
**Example 1.** For $A = \begin{pmatrix}3&0\\0&2\\0&0\end{pmatrix}$:$\Sigma = \begin{pmatrix}3&0\\0&2\\0&0\end{pmatrix}$,$\Sigma^+ = \begin{pmatrix}1/3&0&0\\0&1/2&0\end{pmatrix}$. Then$A^+ = V\Sigma^+ U^* = I_2 \cdot \begin{pmatrix}1/3&0&0\\0&1/2&0\end{pmatrix} \cdot I_3 = \begin{pmatrix}1/3&0&0\\0&1/2&0\end{pmatrix}$.
\end{example}

The pseudoinverse satisfies four Moore–Penrose conditions: $AA^+A = A$,$A^+AA^+ = A^+$,$(AA^+)^* = AA^+$,$(A^+A)^* = A^+A$.

**Least squares.** Given an overdetermined system $Ax = b$ ($m > n$, generally inconsistent), the minimum-norm least-squares solution is$\hat{x} = A^+ b = V\Sigma^+ U^* b$.

\begin{example}
**Example 2.** Fit a line $y = \alpha + \beta x$ to data:$A = \begin{pmatrix}1&0\\1&1\\1&2\end{pmatrix}$,$b = (1,2,2)^T$. The least-squares solution is$\hat{x} = A^+ b = (A^T A)^{-1} A^T b$ (when$A$ has full column rank). Computing:$A^T A = \begin{pmatrix}3&3\\3&5\end{pmatrix}$,$A^T b = (5, 6)^T$. Solving:$\hat{x} = \begin{pmatrix}7/6\\1/2\end{pmatrix}$, i.e.,$\alpha = 7/6$,$\beta = 1/2$.
\end{example}

The SVD-based computation is more stable: in the orthonormal bases given by $U$ and$V$, the system becomes$\Sigma c = d$ (where$c = V^* x$ and$d = U^* b$), and for the overdetermined directions (rows beyond rank$r$) the best we can do is set those components of$c$ to zero — precisely what$\Sigma^+$ does.

\begin{example}
**Example 3 (Rank-deficient).** For $A = \begin{pmatrix}1&1\\2&2\\0&0\end{pmatrix}$ (rank 1):$A^+ b$ gives the minimum-norm least-squares solution, projecting$b$ onto the column space of$A$ and finding the smallest preimage.
\end{example}
\par
\begin{remark}
The SVD-based least-squares computation avoids forming $A^T A$, which squares the condition number. For a matrix$A$ with condition number$\kappa = \sigma_1/\sigma_n$, the normal equations$A^T A x = A^T b$ involve$A^T A$ with condition number$\kappa^2$, making the system much more sensitive to perturbations. The QR decomposition and SVD are the numerically preferred alternatives in applications.
\end{remark}
