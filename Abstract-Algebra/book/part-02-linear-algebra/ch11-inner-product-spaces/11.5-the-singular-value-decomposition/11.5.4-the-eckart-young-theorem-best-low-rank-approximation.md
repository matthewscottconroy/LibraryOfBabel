# 11.5.4 The Eckart–Young Theorem: Best Low-Rank Approximation

Given a matrix $A$, what is the best rank-$k$ approximation to it? The Eckart–Young theorem (1936) gives a complete and elegant answer.

Write the SVD of $A \in M_{m \times n}$ as$A = U\Sigma V^* = \sum_{i=1}^r \sigma_i u_i v_i^*$, where$r = \mathrm{rank}(A)$ and each term$\sigma_i u_i v_i^*$ is a rank-1 matrix (an outer product). Define the **truncated SVD**$A_k = \sum_{i=1}^k \sigma_i u_i v_i^*$ for$k \leq r$.

\begin{theorem}[Eckart–Young]
For any unitarily invariant norm $\|\cdot\|$:
$$\min_{\mathrm{rank}(B) \leq k} \|A - B\| = \|A - A_k\|.$$
The minimizer $A_k$ is unique (in the case of distinct singular values). In particular:
$$\|A - A_k\|_2 = \sigma_{k+1} \quad \text{and} \quad \|A - A_k\|_F = \sqrt{\sigma_{k+1}^2 + \cdots + \sigma_r^2}.$$
\end{theorem}

**Proof of the operator norm case.** Suppose $B$ has rank$\leq k$. Its null space has dimension$\geq n - k$. The span of$v_1, \ldots, v_{k+1}$ has dimension$k+1$. By dimension counting, there exists a unit vector$x$ in$\mathrm{span}\{v_1, \ldots, v_{k+1}\} \cap \ker(B)$. Write$x = \sum_{i=1}^{k+1} c_i v_i$ with$\sum |c_i|^2 = 1$. Then:
$$\|(A-B)x\| = \|Ax\| = \left\|\sum_{i=1}^{k+1} c_i \sigma_i u_i\right\| = \sqrt{\sum_{i=1}^{k+1} |c_i|^2 \sigma_i^2} \geq \sigma_{k+1}.$$
So $\|A - B\|_2 \geq \sigma_{k+1} = \|A - A_k\|_2$.

\begin{example}
**Example 1.** Let $A = \begin{pmatrix}4&3\\0&0\end{pmatrix}$. Singular values:$\sigma_1 = 5$,$\sigma_2 = 0$ (rank 1). The best rank-0 approximation is$A_0 = 0$ with error$\|A\|_2 = 5$.
\end{example}

\begin{example}
**Example 2.** Let $A = \begin{pmatrix}3&2&2\\2&3&-2\end{pmatrix}$. Singular values (computed from$A^T A$):$\sigma_1 = \sqrt{18+1} = \ldots$. Concretely,$AA^T = \begin{pmatrix}17&6\\6&17\end{pmatrix}$, eigenvalues$23$ and$11$. So$\sigma_1 = \sqrt{23}$,$\sigma_2 = \sqrt{11}$. Best rank-1 approximation:$A_1 = \sigma_1 u_1 v_1^T$, with error$\|A - A_1\|_2 = \sigma_2 = \sqrt{11}$.
\end{example}

\begin{example}
**Example 3 (Image compression).** A grayscale $800 \times 600$ image stored as a matrix$A$ with$r$ nonzero singular values. The rank-$k$ truncation$A_k$ requires storing$k(800 + 600 + 1) = 1401k$ numbers instead of$480000$. For$k = 50$:$70050$ numbers, a compression ratio of about$7:1$, with approximation error$\|A - A_{50}\|_F^2 = \sum_{i=51}^r \sigma_i^2$.
\end{example}

\begin{example}
**Example 4.** In collaborative filtering for recommendation systems, user-item rating data forms a sparse matrix $R \in M_{m \times n}$. The SVD truncation$R_k$ imputes missing ratings and captures the$k$ principal "latent factors" (e.g., genres, styles). The Eckart–Young theorem justifies this as the best rank-$k$ model for the observed data.
\end{example}
\par
\begin{remark}
The Eckart–Young theorem holds for all **unitarily invariant norms** — those satisfying $\|UAV\| = \|A\|$ for all unitary$U, V$. These include the operator norm$\|\cdot\|_2$ and the Frobenius norm$\|\cdot\|_F$, as well as the Schatten$p$-norms$\|A\|_p = (\sum_i \sigma_i^p)^{1/p}$. The proof in each case reduces to the fact that unitarily invariant norms depend only on the singular values, and Schur-convexity arguments show the singular value vector of$A_k$ is closest to that of$A$ in the majorization order. This connection to majorization and convexity makes the Eckart–Young theorem part of a broader theory of matrix inequalities.
\end{remark}
