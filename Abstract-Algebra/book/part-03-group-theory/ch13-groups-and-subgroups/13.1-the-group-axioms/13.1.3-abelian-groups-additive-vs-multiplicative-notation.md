# 13.1.3 Abelian Groups; Additive vs. Multiplicative Notation

Among all groups, those in which the operation happens to be commutative occupy a special position. A group $(G, \cdot)$ is called **abelian** (or **commutative**) if$ab = ba$ for all$a, b \in G$. The term honors Niels Henrik Abel, whose work on the insolubility of the quintic first drew attention to the role of commutativity in algebraic problems. Abelian groups are in many ways easier to analyze --- their subgroup structure is more transparent, and the classification of finite abelian groups is both complete and elegant (Chapter 16). Nonabelian groups, by contrast, are where much of the depth of the subject lives.

The commutativity condition is stronger than it might appear. In a nonabelian group, two elements $a$ and$b$ can fail to commute in arbitrarily complicated ways: the commutator$[a, b] = aba^{-1}b^{-1}$ measures the failure, and the subgroup generated by all commutators — the derived subgroup or commutator subgroup$G' = [G, G]$ — controls how far$G$ is from being abelian. In an abelian group,$[a, b] = e$ for all$a, b$, and the derived subgroup is trivial.

The distinction between abelian and nonabelian groups motivates a notational convention that we adopt throughout the book. For **abelian groups**, we typically write the operation as addition and denote it $+$. The identity becomes$0$, the inverse of$a$ becomes$-a$, and repeated application of the operation is written$na$ for$n \in \mathbb{Z}$: explicitly,$na = a + a + \cdots + a$ ($n$ times) for$n > 0$,$0a = 0$, and$na = (-a) + (-a) + \cdots + (-a)$ ($|n|$ times) for$n < 0$. The integers$(\mathbb{Z}, +)$, the rationals$(\mathbb{Q}, +)$, and the cyclic group$\mathbb{Z}/n\mathbb{Z}$ are the canonical examples in additive notation.

For groups that may be nonabelian --- or when we wish to emphasize the multiplicative nature of the operation --- we write the operation as juxtaposition or $\cdot$, the identity as$e$ or$1$, the inverse of$a$ as$a^{-1}$, and repeated application as$a^n$. The symmetric group$S_n$, the dihedral group$D_n$, and the general linear group$GL_n(F)$ are all written multiplicatively.

The key point is that the two notations describe the same abstract structure; the choice is purely a matter of convention adapted to context. The law $(ab)^{-1} = b^{-1}a^{-1}$ in multiplicative notation becomes$-(a + b) = (-b) + (-a) = -a + (-b) = -(a+b)$ in additive notation — which, in an abelian group where$-b + (-a) = -a + (-b)$, collapses to the familiar$-(a + b) = -a - b$. Translating between the two is a basic but necessary skill. We will always flag when a group is assumed abelian, since many theorems hold only under that assumption.

**Example 1.** The group $\mathbb{Z}/n\mathbb{Z}$ is abelian, written additively. Its elements are the residue classes$\{0, 1, 2, \ldots, n-1\}$ (writing representatives), and the operation is addition modulo$n$:$\bar{a} + \bar{b} = \overline{a+b}$. For$n = 6$:$\bar{4} + \bar{5} = \overline{9} = \bar{3}$, since$9 \equiv 3 \pmod{6}$. The identity is$\bar{0}$ and$-\bar{a} = \overline{n - a}$ (so$-\bar{4} = \bar{2}$ in$\mathbb{Z}/6\mathbb{Z}$). Since addition of integers is commutative, so is addition modulo$n$, making$\mathbb{Z}/n\mathbb{Z}$ abelian.

**Example 2.** The group $S_3$ is nonabelian, written multiplicatively. Take$\sigma = (1\;2)$ and$\tau = (2\;3)$ in$S_3$. Then$\sigma\tau$:$1 \mapsto 2 \mapsto 3$,$2 \mapsto 1 \mapsto 1$,$3 \mapsto 3 \mapsto 2$, wait: applying$\tau$ first, then$\sigma$:$\tau(1) = 1$,$\tau(2) = 3$,$\tau(3) = 2$; then$\sigma(1) = 2$,$\sigma(3) = 3$,$\sigma(2) = 1$. So$\sigma\tau(1) = \sigma(1) = 2$,$\sigma\tau(2) = \sigma(3) = 3$,$\sigma\tau(3) = \sigma(2) = 1$, giving$\sigma\tau = (1\;2\;3)$. On the other hand,$\tau\sigma$: apply$\sigma$ first, then$\tau$:$\tau(\sigma(1)) = \tau(2) = 3$,$\tau(\sigma(2)) = \tau(1) = 1$,$\tau(\sigma(3)) = \tau(3) = 2$, giving$\tau\sigma = (1\;3\;2)$. Since$(1\;2\;3) \neq (1\;3\;2)$,$S_3$ is nonabelian.

**Example 3.** The Klein four-group $V_4 = \{e, a, b, c\}$ is an abelian group of order 4, with multiplication table defined by$a^2 = b^2 = c^2 = e$,$ab = c$,$bc = a$,$ca = b$, and every element commuting. Written additively, this is$\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$, with elements$\{(0,0), (1,0), (0,1), (1,1)\}$ and componentwise addition modulo 2. This is abelian but not cyclic: every nonidentity element has order 2, so no single element generates the whole group. It illustrates that "abelian" and "cyclic" are distinct conditions.

**Example 4.** In additive notation, the statement "$a$ and$b$ commute" becomes simply "$a + b = b + a$," which holds automatically in any additive group (since we reserve additive notation for abelian groups). In multiplicative notation for a potentially nonabelian group, the statement "the center$Z(G)$ consists of those elements commuting with all others" translates directly:$Z(G) = \{g \in G : gx = xg \text{ for all } x \in G\}$. In additive notation for an abelian group this would be$Z(G) = G$ trivially, which is correct — every element commutes with every other. The notational choice thus makes certain facts either visible or invisible, and using the right notation is itself part of doing good mathematics.

**Example 5.** The group $(\mathbb{R}^*, \cdot)$ of nonzero reals under multiplication is abelian:$ab = ba$ for all nonzero reals. Written multiplicatively with identity$1$ and inverses$a^{-1} = 1/a$. If we were to write it additively (which would be nonstandard but possible), the operation$a \star b = ab$ would be written$a + b$, the identity$1$ would be written$0$, and$a^{-1}$ would be$-a$. This would be confusing precisely because the "additive" symbol$+$ would denote multiplication of real numbers. The convention of reserving additive notation for abelian groups, and noting explicitly when a group is abelian, prevents such confusion.
