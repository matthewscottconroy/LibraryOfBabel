# 13.3.4 The Order of an Element; Finite vs. Infinite Order

Recall that the order of an element $g \in G$ is defined as$\mathrm{ord}(g) = |\langle g \rangle|$, the size of the cyclic subgroup it generates. Equivalently,$\mathrm{ord}(g)$ is the smallest positive integer$n$ with$g^n = e$, or$\infty$ if no such integer exists. These two descriptions agree: if$g^n = e$ for some minimal$n > 0$, then$\langle g \rangle = \{e, g, g^2, \ldots, g^{n-1}\}$ has exactly$n$ elements, and all these powers are distinct (if$g^i = g^j$ with$0 \leq i < j < n$, then$g^{j-i} = e$ with$0 < j - i < n$, contradicting minimality of$n$).

The order of an element behaves in a predictable way under taking powers. If $g$ has finite order$n$, then$g^k = e$ if and only if$n \mid k$. Moreover, the order of$g^k$ is$n/\gcd(n, k)$: the cyclic subgroup$\langle g^k \rangle$ is the same as$\langle g^{\gcd(n,k)} \rangle$, which has order$n/\gcd(n,k)$. This formula is used constantly when determining which powers of a generator are themselves generators.

In a finite group, every element has finite order. This is immediate: since the sequence $e, g, g^2, g^3, \ldots$ takes values in the finite set$G$, some two of its terms must coincide, say$g^i = g^j$ with$i < j$. Cancellation gives$g^{j-i} = e$, so$g$ has finite order dividing$j - i$. Moreover, by Lagrange's theorem (Chapter 14), the order of every element in a finite group divides the order of the group:$\mathrm{ord}(g) \mid |G|$.

The order of a product $ab$ is generally not determined by$\mathrm{ord}(a)$ and$\mathrm{ord}(b)$ alone. In$S_3$, for example, two elements of order$2$ can multiply to give an element of order$3$. This subtlety has no analogue in arithmetic, where knowing the "size" of two numbers determines the size of their product. The failure of a simple product formula for orders in nonabelian groups is one of the first indications that group theory demands genuinely new thinking beyond ordinary algebra. The situation improves dramatically in abelian groups: if$\gcd(\mathrm{ord}(a), \mathrm{ord}(b)) = 1$ and$ab = ba$, then$\mathrm{ord}(ab) = \mathrm{ord}(a)\cdot\mathrm{ord}(b)$.

This section sets the stage for the detailed study of cyclic groups and subgroups in Section 13.4, where we analyze exactly which orders can occur and how elements of various orders relate to the structure of the whole group.

**Example 1.** In $\mathbb{Z}/18\mathbb{Z}$, find the order of$\bar{6}$. Using the formula:$\mathrm{ord}(\bar{6}) = 18/\gcd(6, 18) = 18/6 = 3$. Verify:$3 \cdot \bar{6} = \overline{18} = \bar{0}$, and$1 \cdot \bar{6} = \bar{6} \neq \bar{0}$,$2 \cdot \bar{6} = \overline{12} \neq \bar{0}$. Yes, the order is$3$.

**Example 2.** Find all elements of order $4$ in$\mathbb{Z}/12\mathbb{Z}$. An element$\bar{k}$ has order$4$ iff$12/\gcd(k,12) = 4$ iff$\gcd(k, 12) = 3$. The values$k \in \{0, 1, \ldots, 11\}$ with$\gcd(k, 12) = 3$ are$k = 3$ and$k = 9$ (since$\gcd(3,12) = 3$ and$\gcd(9, 12) = 3$). So the elements of order$4$ are$\bar{3}$ and$\bar{9}$.

**Example 3.** Demonstrate that $\mathrm{ord}(ab)$ can differ from$\mathrm{ord}(a)\cdot\mathrm{ord}(b)$ in$S_3$. Take$a = (1\;2)$ and$b = (2\;3)$, both of order$2$. Their product:$ab = (1\;2)(2\;3)$:$1 \to 1 \to 2$... applying$(2\;3)$ first:$1 \to 1$,$2 \to 3$,$3 \to 2$; then$(1\;2)$:$1 \to 2$,$3 \to 3$,$2 \to 1$; net:$1 \to 2$,$2 \to 3$,$3 \to 1$, so$ab = (1\;2\;3)$, which has order$3$. Thus$\mathrm{ord}(ab) = 3 \neq 4 = \mathrm{ord}(a) \cdot \mathrm{ord}(b)$. The noncommutativity of$S_3$ is responsible:$a$ and$b$ do not commute, so no simple order formula holds.

**Example 4.** In a finite abelian group, if $a$ has order$m$ and$b$ has order$n$ with$\gcd(m,n) = 1$, show$ab$ has order$mn$. Let$k = \mathrm{ord}(ab)$. Since$(ab)^{mn} = a^{mn}b^{mn} = (a^m)^n (b^n)^m = e^n e^m = e$ (using commutativity and the orders of$a$ and$b$), we have$k \mid mn$. Conversely,$(ab)^k = a^k b^k = e$, so$a^k = b^{-k}$. The element$a^k$ has order$m/\gcd(m,k)$ and$b^{-k}$ has order$n/\gcd(n,k)$. Since$a^k = b^{-k}$, these orders are equal:$m/\gcd(m,k) = n/\gcd(n,k)$. Since$\gcd(m,n) = 1$, one shows$m \mid k$ and$n \mid k$, hence$mn \mid k$. Combined with$k \mid mn$, we get$k = mn$.

**Example 5.** Find the order of the element $A = \begin{pmatrix}0 & -1 \\ 1 & -1\end{pmatrix}$ in$GL_2(\mathbb{R})$. Compute successive powers:
\begin{align*}
A^2 &= \begin{pmatrix}0&-1\\1&-1\end{pmatrix}\begin{pmatrix}0&-1\\1&-1\end{pmatrix} = \begin{pmatrix}-1&1\\-1&0\end{pmatrix}, \\
A^3 &= A^2 \cdot A = \begin{pmatrix}-1&1\\-1&0\end{pmatrix}\begin{pmatrix}0&-1\\1&-1\end{pmatrix} = \begin{pmatrix}1&0\\0&1\end{pmatrix} = I.
\end{align*}
So $A^3 = I$ and$A^1 \neq I$,$A^2 \neq I$, giving$\mathrm{ord}(A) = 3$. The matrix$A$ is a rotation by$120°$ in disguise --- specifically,$A$ represents a rotation of the plane when viewed in the right basis. The cyclic subgroup$\langle A \rangle = \{I, A, A^2\}$ is isomorphic to$\mathbb{Z}/3\mathbb{Z}$.
