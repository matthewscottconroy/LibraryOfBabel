# 13.4.3 Generators of $\mathbb{Z}/n\mathbb{Z}$ and Euler's$\phi$-Function

Once we know that every finite cyclic group of order $n$ is isomorphic to$\mathbb{Z}/n\mathbb{Z}$, a natural question presents itself: which elements of$\mathbb{Z}/n\mathbb{Z}$ are generators? The answer connects group theory directly to elementary number theory, and brings Euler's totient function into the picture in a completely natural way.

An element $\bar{k} \in \mathbb{Z}/n\mathbb{Z}$ is a generator if and only if$\langle \bar{k} \rangle = \mathbb{Z}/n\mathbb{Z}$, which happens precisely when successive multiples of$k$ modulo$n$ cycle through all residues before returning to$0$. To see when this occurs, note that$\langle \bar{k} \rangle = \langle \overline{\gcd(k,n)} \rangle$ — the subgroup generated by$\bar{k}$ is the same as the subgroup generated by$\overline{\gcd(k,n)}$. This is because$\gcd(k,n)$ is a linear combination of$k$ and$n$ (by Bezout's lemma), so$\overline{\gcd(k,n)}$ is a multiple of$\bar{k}$ in$\mathbb{Z}/n\mathbb{Z}$, and conversely$\bar{k}$ is a multiple of$\overline{\gcd(k,n)}$. Therefore$\langle \bar{k} \rangle = \mathbb{Z}/n\mathbb{Z}$ if and only if$\gcd(k, n) = 1$: the generators of$\mathbb{Z}/n\mathbb{Z}$ are exactly those elements$\bar{k}$ for which$k$ is coprime to$n$.

\begin{definition}
\textbf{Euler's totient function} $\phi(n)$ is defined for positive integers$n$ by
$$\phi(n) = |\{k \in \mathbb{Z} : 1 \leq k \leq n,\; \gcd(k,n) = 1\}|,$$
the count of integers in $\{1, \ldots, n\}$ coprime to$n$.
\end{definition}

The number of generators of $\mathbb{Z}/n\mathbb{Z}$ is therefore$\phi(n)$. The function$\phi$ has the explicit formula$\phi(n) = n \prod_{p \mid n} (1 - 1/p)$, where the product runs over distinct prime divisors$p$ of$n$. For a prime$p$,$\phi(p) = p - 1$; for a prime power,$\phi(p^k) = p^k - p^{k-1}$; and$\phi$ is multiplicative: if$\gcd(m,n) = 1$ then$\phi(mn) = \phi(m)\phi(n)$.

**Example 1.** The generators of $\mathbb{Z}/12\mathbb{Z}$ are the elements$\bar{k}$ with$\gcd(k, 12) = 1$. The integers from 1 to 12 coprime to 12 are$1, 5, 7, 11$, so there are$\phi(12) = 4$ generators:$\bar{1}, \bar{5}, \bar{7}, \bar{11}$. One checks: the multiples of$5$ modulo 12 are$5, 10, 3, 8, 1, 6, 11, 4, 9, 2, 7, 0$, which visits all residues exactly once before returning to$0$.

**Example 2.** For $n = 8$, the integers coprime to 8 in$\{1, \ldots, 8\}$ are$1, 3, 5, 7$, giving$\phi(8) = 4$ generators of$\mathbb{Z}/8\mathbb{Z}$. Note that$\bar{2}$ is not a generator: the multiples of 2 modulo 8 are$2, 4, 6, 0, 2, 4, 6, 0, \ldots$, cycling only through even residues and generating the subgroup$\{0, 2, 4, 6\}$ of order 4.

**Example 3.** For a prime $p$, every element$\bar{k}$ with$1 \leq k \leq p-1$ satisfies$\gcd(k,p) = 1$, so every nonzero element of$\mathbb{Z}/p\mathbb{Z}$ is a generator. Thus$\mathbb{Z}/p\mathbb{Z}$ has$\phi(p) = p - 1$ generators.

**Example 4.** The unit group $(\mathbb{Z}/n\mathbb{Z})^* = \{\bar{k} : \gcd(k,n) = 1\}$ is a group of order$\phi(n)$ under multiplication. By Lagrange's theorem applied to this group,$a^{\phi(n)} \equiv 1 \pmod{n}$ for all$a$ with$\gcd(a, n) = 1$ — this is Euler's theorem. For example,$\phi(10) = 4$, so$3^4 = 81 \equiv 1 \pmod{10}$, i.e.,$81$ ends in digit 1. Alternatively,$7^4 = 2401 \equiv 1 \pmod{10}$.

**Example 5.** Gauss proved that $(\mathbb{Z}/p\mathbb{Z})^*$ is cyclic for every prime$p$. An element generating this group is called a **primitive root modulo$p$**. For$p = 7$:$\phi(6) = 2$, so there are 2 primitive roots. Testing$\bar{2}$:$2^1 = 2$,$2^2 = 4$,$2^3 = 1 \pmod{7}$ — order 3, not a generator. Testing$\bar{3}$:$3^1 = 3$,$3^2 = 2$,$3^3 = 6$,$3^4 = 4$,$3^5 = 5$,$3^6 = 1 \pmod{7}$ — order 6, so$\bar{3}$ is a primitive root. The other is$\bar{5} = \bar{3}^5$.

The appearance of $\phi(n)$ here is the first of many connections between group theory and number theory. Even the simplest groups — the cyclic ones — carry nontrivial arithmetic content. The function$\phi$ reappears when we compute the order of the unit group$(\mathbb{Z}/n\mathbb{Z})^*$, and again in Euler's theorem, which we derived from Lagrange's theorem in Section 14.1.4. More broadly, the interplay between generators, divisibility, and Euler's function prefigures the structure of the multiplicative groups of fields and the theory of cyclotomic polynomials.
