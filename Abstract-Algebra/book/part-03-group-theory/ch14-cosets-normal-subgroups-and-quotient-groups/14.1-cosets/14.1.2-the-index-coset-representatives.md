# 14.1.2 The Index $[G:H]$; Coset Representatives

Since the left cosets of $H$ in$G$ partition$G$ into disjoint pieces, we can ask how many pieces there are. The answer is a fundamental invariant.

\begin{definition}
The \textbf{index} of $H$ in$G$, written$[G:H]$, is the number of distinct left cosets of$H$ in$G$. It is a well-defined cardinal number, finite when$G$ and$H$ are both finite (or more generally when the number of cosets is finite, even if$G$ itself is infinite).
\end{definition}

When $G$ is finite, counting elements gives the fundamental relation$|G| = [G:H] \cdot |H|$, since$G$ is partitioned into$[G:H]$ cosets each of size$|H|$. This equation is valid for every subgroup$H \leq G$, with no assumption of normality. It is a purely combinatorial statement about the coset partition and is the content of Lagrange's theorem.

A **set of coset representatives** (also called a **transversal**) for $H$ in$G$ is a set$T \subseteq G$ consisting of exactly one element from each left coset. That is,$T$ chooses a representative$t \in gH$ for each coset$gH$, so that$G$ decomposes as a disjoint union$G = \bigsqcup_{t \in T} tH$. The choice of transversal is not unique — any element of a coset can serve as its representative — but having a transversal is often notationally convenient when we need to reason about all cosets simultaneously.

The index satisfies a multiplicativity property: if $K \leq H \leq G$, then$[G:K] = [G:H] \cdot [H:K]$. This follows from the fact that each coset$gH$ of$H$ in$G$ is partitioned by the cosets of$K$ it contains, and each coset of$H$ contains exactly$[H:K]$ cosets of$K$.

**Example 1.** In $\mathbb{Z}$ with$H = 3\mathbb{Z}$, the three cosets are$0 + 3\mathbb{Z}$,$1 + 3\mathbb{Z}$, and$2 + 3\mathbb{Z}$, and$\{0, 1, 2\}$ is a natural transversal. The index is$[\mathbb{Z} : 3\mathbb{Z}] = 3$. Notice that in this example$G$ is infinite but the index is finite, illustrating that index is a measure of the "relative size" of$H$ in$G$, not of$G$ alone.

**Example 2.** In $S_3$ with$H = \langle (12) \rangle$ (order 2), we have$[S_3 : H] = |S_3|/|H| = 6/2 = 3$. A transversal is$\{e, (13), (23)\}$, since$eH, (13)H, (23)H$ are the three distinct left cosets computed in Section 14.1.1.

**Example 3.** In $G = \mathbb{Z}/12\mathbb{Z}$ with$H = \langle \bar{4} \rangle$ (order 3), the index is$[G:H] = 12/3 = 4$. A transversal is$\{\bar{0}, \bar{1}, \bar{2}, \bar{3}\}$.

**Example 4.** Consider $G = \mathbb{Z}$ and$K = 6\mathbb{Z} \leq H = 2\mathbb{Z} \leq G$. Then$[\mathbb{Z} : 2\mathbb{Z}] = 2$,$[2\mathbb{Z} : 6\mathbb{Z}] = 3$, and$[\mathbb{Z} : 6\mathbb{Z}] = 6 = 2 \cdot 3$. This confirms the index multiplicativity formula.

**Example 5.** In $D_4 = \langle r, s \rangle$ (order 8) with$H = \langle s \rangle = \{e, s\}$ (order 2), the index$[D_4 : H] = 4$. A transversal is$\{e, r, r^2, r^3\}$, giving the four cosets$H, rH, r^2H, r^3H$.

\begin{proposition}
If $[G:H] = 2$, then$H \trianglelefteq G$.
\end{proposition}

\begin{proof}
There are exactly two left cosets: $H$ and$G \setminus H$. Similarly, there are two right cosets:$H$ and$G \setminus H$. For any$g \in G$, if$g \in H$ then$gH = H = Hg$. If$g \notin H$ then$gH = G \setminus H = Hg$. In all cases$gH = Hg$, so$H$ is normal.
\end{proof}

\begin{remark}
The index $[G:H]$ can be infinite even when$H$ is nontrivial. For instance,$[\mathbb{Q} : \mathbb{Z}] = \infty$, since the cosets$q + \mathbb{Z}$ for$q \in [0,1) \cap \mathbb{Q}$ are all distinct. The theory of group actions in Chapter 16 provides a powerful framework for computing indices via the orbit-stabilizer theorem.
\end{remark}
