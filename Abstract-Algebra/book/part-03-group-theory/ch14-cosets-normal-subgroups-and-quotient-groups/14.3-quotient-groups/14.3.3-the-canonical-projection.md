# 14.3.3 The Canonical Projection $\pi: G \to G/N$

Associated to every normal subgroup $N \trianglelefteq G$ is a natural surjective homomorphism from$G$ to the quotient group$G/N$.

\begin{definition}
The \textbf{canonical projection} (also called the \textbf{quotient map}) is the function $\pi: G \to G/N$ defined by$\pi(g) = gN$. It sends each element of$G$ to the coset that contains it.
\end{definition}

This map is a group homomorphism: $\pi(ab) = (ab)N = (aN)(bN) = \pi(a)\pi(b)$, where the middle equality uses the definition of coset multiplication in$G/N$. It is surjective because every coset$gN$ is the image of$g$. Its kernel is:
$$\ker(\pi) = \{g \in G : \pi(g) = N\} = \{g \in G : gN = N\} = N,$$
since $gN = N$ if and only if$g \in N$.

The canonical projection satisfies a fundamental **universal property**: if $\varphi: G \to H$ is any group homomorphism with$N \subseteq \ker(\varphi)$, then$\varphi$ factors uniquely through$\pi$. That is, there exists a unique homomorphism$\bar{\varphi}: G/N \to H$ such that$\varphi = \bar{\varphi} \circ \pi$. The map$\bar{\varphi}$ is defined by$\bar{\varphi}(gN) = \varphi(g)$. Well-definedness requires$N \subseteq \ker(\varphi)$: if$gN = g'N$ then$g'^{-1}g \in N \subseteq \ker(\varphi)$, so$\varphi(g'^{-1}g) = e$, giving$\varphi(g) = \varphi(g')$. Uniqueness follows because$\pi$ is surjective: any map$\psi: G/N \to H$ with$\varphi = \psi \circ \pi$ must satisfy$\psi(gN) = \psi(\pi(g)) = \varphi(g) = \bar{\varphi}(gN)$.

The universal property should be thought of as saying that $G/N$ is the "most efficient" group that$G$ can map into while killing$N$. Any other group with the same property is isomorphic to$G/N$. This idea — defining an object by the maps into or out of it, rather than by an explicit construction — is a preview of the categorical thinking that pervades modern algebra.

**Example 1.** The canonical projection $\pi: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ sends$k \mapsto \bar{k}$. It is surjective with kernel$n\mathbb{Z}$. The universal property says: any homomorphism$\varphi: \mathbb{Z} \to H$ with$n\mathbb{Z} \subseteq \ker\varphi$ (i.e.,$\varphi(n) = e$) factors as$\varphi = \bar{\varphi} \circ \pi$ for a unique$\bar{\varphi}: \mathbb{Z}/n\mathbb{Z} \to H$. This is because$\varphi$ is determined by$\varphi(1)$, and if$\varphi(1)^n = \varphi(n) = e$, then$\varphi(1)$ has order dividing$n$, so$\bar{\varphi}(\bar{k}) = \varphi(1)^k$ is well-defined.

**Example 2.** The projection $\pi: S_n \to S_n/A_n \cong \mathbb{Z}/2\mathbb{Z}$ is the sign homomorphism. Its universal property: any homomorphism$\varphi: S_n \to H$ that sends every even permutation to$e$ factors through the sign map.

**Example 3.** In $G = Q_8$, the projection$\pi: Q_8 \to Q_8/\langle -1 \rangle \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ sends$1 \mapsto (\bar{0},\bar{0})$,$-1 \mapsto (\bar{0},\bar{0})$,$i \mapsto (\bar{1},\bar{0})$,$-i \mapsto (\bar{1},\bar{0})$,$j \mapsto (\bar{0},\bar{1})$,$-j \mapsto (\bar{0},\bar{1})$,$k \mapsto (\bar{1},\bar{1})$,$-k \mapsto (\bar{1},\bar{1})$.

**Example 4.** The projection $\pi: GL_n(\mathbb{F}) \to PGL_n(\mathbb{F}) = GL_n(\mathbb{F})/(\mathbb{F}^* I)$ sends a matrix to its equivalence class under scalar multiplication. Geometrically,$PGL_n(\mathbb{F})$ acts faithfully on projective space$\mathbb{P}^{n-1}(\mathbb{F})$.

**Example 5.** For $G = D_4$ and$N = \langle r^2 \rangle$, the projection$\pi: D_4 \to D_4/N$ sends$r \mapsto rN$ (an element of order 2 in the quotient, since$r^2 \in N$) and$s \mapsto sN$ (also order 2). The quotient$D_4/N \cong \mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ is generated by$rN$ and$sN$.

\begin{remark}
The universal property of the canonical projection is equivalent to the First Isomorphism Theorem, which states that if $\varphi: G \to H$ is surjective with kernel$N$, then the induced map$\bar{\varphi}: G/N \to H$ is an isomorphism. The canonical projection is thus the "initial" homomorphism in the category of group homomorphisms out of$G$ that kill$N$ — a perspective that unifies the isomorphism theorems under the umbrella of categorical universality.
\end{remark}
