# 15.1.2 Isomorphisms, Endomorphisms, Automorphisms

Not all homomorphisms are created equal. Their utility and meaning vary depending on whether they are injective, surjective, or both — and whether the domain and codomain coincide. These distinctions are important enough to warrant their own vocabulary.

\begin{definition}
Let $\varphi: G \to H$ be a group homomorphism.
\begin{itemize}
\item $\varphi$ is an \textbf{isomorphism} if it is bijective. We write$G \cong H$ and say$G$ and$H$ are \textbf{isomorphic}.
\item $\varphi$ is an \textbf{endomorphism} if$G = H$.
\item $\varphi$ is an \textbf{automorphism} if it is both an isomorphism and an endomorphism: a bijective homomorphism$G \to G$.
\item $\varphi$ is a \textbf{monomorphism} (or \textbf{embedding}) if it is injective.
\item $\varphi$ is an \textbf{epimorphism} if it is surjective.
\end{itemize}
\end{definition}

Isomorphism is the correct notion of "sameness" for groups: isomorphic groups have identical algebraic structure and differ only in the labeling of their elements. An isomorphism cannot change the order of any element, since $\varphi(g)^n = \varphi(g^n) = \varphi(e) = e$ if and only if$g^n = e$. More generally, isomorphic groups have the same number of elements of each order, the same number of subgroups of each order, and the same subgroup lattice structure.

**Example 1.** $\mathbb{Z}/2\mathbb{Z} \times \mathbb{Z}/2\mathbb{Z}$ and$\mathbb{Z}/4\mathbb{Z}$ are not isomorphic, though both have order 4. The first has three elements of order 2 (namely$(\bar{1},\bar{0})$,$(\bar{0},\bar{1})$,$(\bar{1},\bar{1})$) and no element of order 4. The second has two elements of order 4 (namely$\bar{1}$ and$\bar{3}$). An isomorphism must preserve element orders, so none can exist.

**Example 2.** $D_3 \cong S_3$. The dihedral group$D_3$ (symmetries of a triangle) and the symmetric group$S_3$ (permutations of 3 elements) are isomorphic: label the vertices$1,2,3$ and map each symmetry of the triangle to the permutation it induces on vertices. This gives an isomorphism$D_3 \to S_3$.

**Example 3.** The map $\varphi: \mathbb{Z} \to \mathbb{Z}$ given by$\varphi(n) = 2n$ is an injective endomorphism (monomorphism) that is not surjective: it misses all odd integers. The map$\psi: \mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ given by$\psi(n) = \bar{n}$ is a surjective epimorphism that is not injective.

**Example 4.** The identity map $\mathrm{id}_G: G \to G$ is always an automorphism. For$G = \mathbb{Z}/n\mathbb{Z}$, the map$\varphi_m(\bar{k}) = \overline{mk}$ is an automorphism if and only if$\gcd(m,n) = 1$. So$\mathrm{Aut}(\mathbb{Z}/n\mathbb{Z}) \cong (\mathbb{Z}/n\mathbb{Z})^*$.

**Example 5.** In $GL_n(\mathbb{F})$, the map$A \mapsto (A^T)^{-1}$ (inverse transpose) is an automorphism. It is bijective, and$((AB)^T)^{-1} = (B^T A^T)^{-1} = (A^T)^{-1}(B^T)^{-1}$, confirming the homomorphism property.

The inverse of a bijective homomorphism is itself a homomorphism: if $\varphi: G \to H$ is an isomorphism and$ab = c$ in$G$, then$\varphi(a)\varphi(b) = \varphi(c)$ in$H$, and applying$\varphi^{-1}$ gives$\varphi^{-1}(\varphi(a))\varphi^{-1}(\varphi(b)) = \varphi^{-1}(\varphi(c))$, so$\varphi^{-1}$ preserves multiplication in$H$. This confirms that isomorphism is a genuine equivalence relation on the class of groups.

\begin{proposition}
The automorphisms of $G$ form a group$\mathrm{Aut}(G)$ under composition.
\end{proposition}

\begin{proof}
The composite of two bijective homomorphisms is a bijective homomorphism. The identity map is an automorphism. The inverse of a bijective homomorphism is a bijective homomorphism (as shown above). Composition is associative. So $\mathrm{Aut}(G)$ satisfies all four group axioms.
\end{proof}

\begin{remark}
Isomorphism is a strictly weaker relation than equality. Two groups can be isomorphic without being equal as sets. The phrase "up to isomorphism" is ubiquitous in algebra and means "as abstract groups, ignoring the labeling of elements." When we say "the cyclic group of order $n$," we mean the unique isomorphism class, not a specific set.
\end{remark}
