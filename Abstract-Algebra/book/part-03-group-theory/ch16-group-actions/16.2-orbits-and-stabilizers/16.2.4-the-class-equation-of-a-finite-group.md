# 16.2.4 The Class Equation of a Finite Group

Among all group actions, conjugation — the action of $G$ on itself by$g \cdot x = gxg^{-1}$ — is the most structurally revealing. Its orbits are the **conjugacy classes** of$G$, and the resulting partition of$|G|$ is the **class equation**.

Since the conjugacy classes partition $G$, we can write$|G|$ as a sum over all distinct classes. Elements whose conjugacy class has size 1 are exactly those fixed by all conjugations — the elements of the center$Z(G)$. For every conjugacy class of size greater than 1, the Orbit-Stabilizer Theorem gives$|\mathrm{cl}(x)| = [G : C_G(x)]$, where$C_G(x)$ is the centralizer of$x$.

\begin{theorem}[Class Equation]
For a finite group $G$,
$$|G| = |Z(G)| + \sum_{i} [G : C_G(x_i)],$$
where the sum runs over one representative $x_i$ from each conjugacy class of size greater than$1$.
\end{theorem}

Each term $[G : C_G(x_i)]$ is a divisor of$|G|$ greater than 1 by construction. The class equation therefore imposes strong divisibility constraints on the structure of$G$.

**Example 1.** $S_3$. Conjugacy classes:$\{e\}$ (size 1),$\{(12),(13),(23)\}$ (size 3),$\{(123),(132)\}$ (size 2). Class equation:$6 = 1 + 3 + 2$. The center$Z(S_3) = \{e\}$. Centralizers:$C_{S_3}((12))$ has order$6/3 = 2$,$C_{S_3}((123))$ has order$6/2 = 3$.

**Example 2.** $D_4 = \langle r,s : r^4=s^2=e, srs=r^{-1} \rangle$. Conjugacy classes:$\{e\}$,$\{r^2\}$,$\{r,r^3\}$,$\{s,sr^2\}$,$\{sr,sr^3\}$. Class equation:$8 = 1 + 1 + 2 + 2 + 2$. Center$Z(D_4) = \{e, r^2\}$ (size 2).

**Example 3.** $Q_8 = \{\pm 1, \pm i, \pm j, \pm k\}$. Conjugacy classes:$\{1\}$,$\{-1\}$,$\{i,-i\}$,$\{j,-j\}$,$\{k,-k\}$. Class equation:$8 = 1 + 1 + 2 + 2 + 2$. (Same class equation as$D_4$, but different group.) Center$Z(Q_8) = \{1,-1\}$.

**Example 4.** $A_4$. Conjugacy classes (some elements of$S_4$ split when restricted to$A_4$):$\{e\}$ (size 1),$\{(12)(34),(13)(24),(14)(23)\}$ (size 3),$\{(123),(134),(142),(234)\}$ (size 4),$\{(132),(143),(124),(243)\}$ (size 4). Class equation:$12 = 1 + 3 + 4 + 4$. Center$Z(A_4) = \{e\}$.

**Example 5.** $p$-groups. If$|G| = p^n$ for a prime$p$, then$p$ divides each$[G:C_G(x_i)]$ (since each is a divisor of$p^n$ greater than 1, hence divisible by$p$). The class equation gives$p \mid |Z(G)|$, so$Z(G) \neq \{e\}$.

\begin{theorem}
Every non-trivial $p$-group has non-trivial center: if$|G| = p^n$ with$n \geq 1$, then$|Z(G)| \geq p$.
\end{theorem}

\begin{proof}
Each $[G:C_G(x_i)]$ divides$|G| = p^n$ and is$>1$, so$p \mid [G:C_G(x_i)]$. Summing:$|G| = |Z(G)| + \sum_i [G:C_G(x_i)]$ with$p$ dividing both$|G|$ and each summand, forces$p \mid |Z(G)|$.
\end{proof}

**Example 6.** The class equation of $S_4$. The conjugacy classes are determined by cycle type:$\{e\}$ (size 1), three double transpositions$\{(12)(34),(13)(24),(14)(23)\}$ (size 3), six transpositions$\{(12),(13),(14),(23),(24),(34)\}$ (size 6), eight 3-cycles (size 8), six 4-cycles (size 6). Class equation:$24 = 1 + 3 + 6 + 8 + 6$. The center$Z(S_4) = \{e\}$ (only the identity commutes with all permutations in$S_4$).

\begin{remark}
The class equation is a cornerstone of the proof of the Sylow theorems, the study of $p$-groups, and the analysis of simple groups. It shows, for instance, that$A_5$ is simple: any normal subgroup must be a union of conjugacy classes including$\{e\}$, and the class sizes in$A_5$ are 1, 15, 20, 12, 12 — no nonempty proper subset of$\{1, 15, 20, 12, 12\}$ summing to a divisor of 60 (other than 1 and 60 themselves) exists. In representation theory, the number of conjugacy classes of$G$ equals the number of irreducible complex representations of$G$, connecting the class equation to the character theory of finite groups.
\end{remark}
