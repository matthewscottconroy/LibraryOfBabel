# 19.1.1 Torsion Elements; the Torsion Subgroup

When working with abelian groups (written additively), elements come in two flavors: those that eventually "wind back to zero" when repeatedly added to themselves, and those that never do. This distinction is fundamental to the structure theory of abelian groups and provides the first coarse decomposition that the full classification theorem will refine.

\begin{definition}
Let $A$ be an abelian group. An element$a \in A$ is a **torsion element** if$na = 0$ for some positive integer$n$. The smallest such$n$ is the **order** of$a$, denoted$\mathrm{ord}(a)$. An element is **torsion-free** if$na = 0$ implies$n = 0$. The group$A$ is a **torsion group** if every element has finite order, and **torsion-free** if the only torsion element is$0$.
\end{definition}

\begin{proposition}
The set $T(A) = \{a \in A : na = 0 \text{ for some } n \geq 1\}$ is a subgroup of$A$, called the **torsion subgroup**.
\end{proposition}

\begin{proof}
If $na = 0$ and$mb = 0$, then$mn(a+b) = n(ma) + m(nb) = m \cdot 0 + n \cdot 0 = 0$, so$a+b \in T(A)$. If$na = 0$, then$n(-a) = -(na) = 0$, so$-a \in T(A)$. The zero element satisfies$1 \cdot 0 = 0$, so$0 \in T(A)$.
\end{proof}

The quotient $A/T(A)$ is torsion-free: if$\bar{a} = a + T(A)$ satisfies$n\bar{a} = \overline{na} = 0$ in$A/T(A)$, then$na \in T(A)$, so$m(na) = 0$ for some$m$, meaning$(mn)a = 0$, thus$a \in T(A)$ and$\bar{a} = 0$. This shows the exact sequence$0 \to T(A) \to A \to A/T(A) \to 0$ splits the torsion from the torsion-free part.

\begin{example}
**Example 1.** In $A = \mathbb{Z}/6\mathbb{Z}$, every element is torsion:$6 \cdot \bar{k} = \overline{6k} = 0$. So$T(\mathbb{Z}/6\mathbb{Z}) = \mathbb{Z}/6\mathbb{Z}$ and the quotient is trivial. More precisely,$\mathrm{ord}(\bar{1}) = 6$,$\mathrm{ord}(\bar{2}) = 3$,$\mathrm{ord}(\bar{3}) = 2$.
\end{example}

\begin{example}
**Example 2.** In $A = \mathbb{Z}$, only$0$ is torsion: if$n \cdot k = 0$ for$k \in \mathbb{Z}$ and$n \geq 1$, then$k = 0$. So$T(\mathbb{Z}) = \{0\}$ and$\mathbb{Z}$ is torsion-free.
\end{example}

\begin{example}
**Example 3.** In $A = \mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z}$, an element$(k, \bar{m})$ is torsion iff$n(k, \bar{m}) = (nk, \overline{nm}) = (0,0)$ for some$n \geq 1$. Since$nk = 0$ in$\mathbb{Z}$ requires$k = 0$, we get$T(A) = \{0\} \oplus \mathbb{Z}/3\mathbb{Z} \cong \mathbb{Z}/3\mathbb{Z}$. The quotient$A/T(A) \cong \mathbb{Z}$ is torsion-free.
\end{example}

\begin{example}
**Example 4.** In $A = \mathbb{Q}/\mathbb{Z}$, every element$\frac{p}{q} + \mathbb{Z}$ is torsion:$q \cdot \frac{p}{q} = p \in \mathbb{Z}$, so$q \cdot (\frac{p}{q} + \mathbb{Z}) = 0$. Thus$T(\mathbb{Q}/\mathbb{Z}) = \mathbb{Q}/\mathbb{Z}$ is a torsion group. It is an important example of a divisible abelian torsion group, and plays a role in the theory of injective modules.
\end{example}

\begin{example}
**Example 5.** The $p$-primary component$A[p^\infty] = \{a \in A : p^n a = 0 \text{ for some } n\}$ is a subgroup of$T(A)$, the **$p$-torsion**. The torsion subgroup decomposes as a direct sum of its$p$-primary components:
$$T(A) \cong \bigoplus_p A[p^\infty]$$
(where the sum is over all primes $p$). For$A = \mathbb{Z}/12\mathbb{Z}$,$A[2^\infty] \cong \mathbb{Z}/4\mathbb{Z}$ and$A[3^\infty] \cong \mathbb{Z}/3\mathbb{Z}$, and$T(A) = A \cong \mathbb{Z}/4\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z}$ (matching the Chinese Remainder Theorem decomposition).
\end{example}

\begin{remark}
For a finitely generated abelian group $A$, the structure theorem (Section 19.2) will show that$T(A)$ is a finite group and$A/T(A)$ is free abelian. Moreover, the exact sequence$0 \to T(A) \to A \to A/T(A) \to 0$ always splits (since$A/T(A)$ is free, hence projective as a$\mathbb{Z}$-module), so$A \cong T(A) \oplus \mathbb{Z}^r$ for some$r \geq 0$. This splitting is the first step in the full classification.
\end{remark}
