# 19.3.1 Classifying Abelian Groups of a Given Order

One of the most immediate applications of the structure theorem is the systematic enumeration of all abelian groups of a given finite order. The structure theorem, combined with the primary decomposition, reduces this to a partition-counting problem.

\begin{theorem}
The number of abelian groups of order $n = p_1^{a_1} \cdots p_s^{a_s}$ (up to isomorphism) is$\prod_{i=1}^s p(a_i)$, where$p(k)$ denotes the number of integer partitions of$k$.
\end{theorem}

\begin{proof}[Proof sketch]
By the primary decomposition, any abelian group of order $n$ is a direct product$A \cong P_1 \times \cdots \times P_s$ where$P_i$ has order$p_i^{a_i}$. The$p_i$-primary components are independent. Each$P_i$ is an abelian group of order$p_i^{a_i}$, which by the structure theorem decomposes as$\mathbb{Z}/p_i^{b_1} \oplus \cdots \oplus \mathbb{Z}/p_i^{b_t}$ where$b_1 + \cdots + b_t = a_i$ and$b_j \geq 1$. Such data corresponds exactly to a partition of$a_i$. Since partitions of different primes are independent, the total count is$\prod_i p(a_i)$.
\end{proof}

\begin{example}
**Example 1.** All abelian groups of order $12 = 2^2 \cdot 3^1$. Partitions of$2$:$\{2\}$ and$\{1,1\}$. Partitions of$1$:$\{1\}$.
\par
- Partition $(2)$ of$a_2=2$ and$(1)$ of$a_3=1$:$P_2 = \mathbb{Z}/4\mathbb{Z}$,$P_3 = \mathbb{Z}/3\mathbb{Z}$. Group:$\mathbb{Z}/4\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z} \cong \mathbb{Z}/12\mathbb{Z}$.
- Partition $(1,1)$ of$a_2=2$ and$(1)$ of$a_3=1$:$P_2 = \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/2\mathbb{Z}$,$P_3 = \mathbb{Z}/3\mathbb{Z}$. Group:$\mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/6\mathbb{Z}$.
\par
Count: $p(2) \cdot p(1) = 2 \cdot 1 = 2$. In invariant factor form:$\mathbb{Z}/12\mathbb{Z}$ (invariant factor$12$) and$\mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/6\mathbb{Z}$ (invariant factors$2, 6$; check$2 \mid 6$: yes).
\end{example}

\begin{example}
**Example 2.** All abelian groups of order $20 = 2^2 \cdot 5^1$.
\par
- Partition $(2)$ for$2^2$,$(1)$ for$5^1$:$\mathbb{Z}/4\mathbb{Z} \oplus \mathbb{Z}/5\mathbb{Z} \cong \mathbb{Z}/20\mathbb{Z}$.
- Partition $(1,1)$ for$2^2$,$(1)$ for$5^1$:$\mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/5\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/10\mathbb{Z}$.
\par
Two abelian groups of order $20$. The cyclic group$\mathbb{Z}/20\mathbb{Z}$ has an element of order$20$; the other does not (max order is$\mathrm{lcm}(2,10) = 10$).
\end{example}

\begin{example}
**Example 3.** All abelian groups of order $30 = 2 \cdot 3 \cdot 5$. Here$a_2 = a_3 = a_5 = 1$, so$p(1) = 1$ for each prime. Count:$1 \cdot 1 \cdot 1 = 1$. There is exactly one abelian group of order$30$:$\mathbb{Z}/30\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z} \oplus \mathbb{Z}/5\mathbb{Z}$. Any squarefree order$n$ has exactly one abelian group, the cyclic group$\mathbb{Z}/n\mathbb{Z}$.
\end{example}

\begin{example}
**Example 4.** All abelian groups of order $360 = 2^3 \cdot 3^2 \cdot 5^1$. Partitions of$3$:$\{3\}, \{2,1\}, \{1,1,1\}$, giving$p(3) = 3$. Partitions of$2$:$\{2\}, \{1,1\}$, giving$p(2) = 2$. Partitions of$1$:$p(1) = 1$. Total:$3 \cdot 2 \cdot 1 = 6$ abelian groups.
\par
The six groups (listed by their $2$- and$3$-primary parts, with$5$-part always$\mathbb{Z}/5\mathbb{Z}$):
\par
| $2$-part |$3$-part | Group |
|---|---|---|
| $\mathbb{Z}/8\mathbb{Z}$ |$\mathbb{Z}/9\mathbb{Z}$ |$\mathbb{Z}/360\mathbb{Z}$ |
| $\mathbb{Z}/8\mathbb{Z}$ |$\mathbb{Z}/3\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z}$ |$\mathbb{Z}/3\mathbb{Z} \oplus \mathbb{Z}/120\mathbb{Z}$ |
| $\mathbb{Z}/4\mathbb{Z} \oplus \mathbb{Z}/2\mathbb{Z}$ |$\mathbb{Z}/9\mathbb{Z}$ |$\mathbb{Z}/2\mathbb{Z} \oplus \mathbb{Z}/180\mathbb{Z}$ |
| $\mathbb{Z}/4\mathbb{Z} \oplus \mathbb{Z}/2\mathbb{Z}$ |$\mathbb{Z}/3\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z}$ |$\mathbb{Z}/6\mathbb{Z} \oplus \mathbb{Z}/60\mathbb{Z}$ |
| $(\mathbb{Z}/2\mathbb{Z})^3$ |$\mathbb{Z}/9\mathbb{Z}$ |$(\mathbb{Z}/2\mathbb{Z})^2 \oplus \mathbb{Z}/90\mathbb{Z}$ |
| $(\mathbb{Z}/2\mathbb{Z})^3$ |$\mathbb{Z}/3\mathbb{Z} \oplus \mathbb{Z}/3\mathbb{Z}$ |$(\mathbb{Z}/6\mathbb{Z})^2 \oplus \mathbb{Z}/10\mathbb{Z}$ |
\end{example}

\begin{remark}
This classification immediately implies that for any $n$, there are only finitely many abelian groups of order$n$ up to isomorphism — a nontrivial statement that the structure theorem makes explicit and computable. The function$f(n) =$ number of abelian groups of order$n$ is a multiplicative arithmetic function:$f(mn) = f(m)f(n)$ when$\gcd(m,n)=1$, and$f(p^k) = p(k)$ (the number of partitions of$k$). The structure theorem thus connects abstract algebra to the combinatorics of partitions.
\end{remark}
