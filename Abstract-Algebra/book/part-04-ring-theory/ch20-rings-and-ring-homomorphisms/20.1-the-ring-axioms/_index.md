# 20.1 The Ring Axioms

A ring is a set equipped with two binary operations — addition and multiplication — satisfying a precise set of axioms that codify the algebraic behavior familiar from the integers. The additive structure is required to be an abelian group: addition is commutative, associative, has an identity element $0$, and every element has an additive inverse. The multiplicative structure need only be a monoid: multiplication is associative and has an identity element $1$, but inverses are not required. The two operations interact through the distributive laws: $a(b + c) = ab + ac$ and $(a + b)c = ac + bc$ for all $a, b, c$ in the ring. These axioms are the minimal package that supports the kind of arithmetic we actually want to do.

Within the class of rings, several special conditions single out important subclasses. A ring is commutative if $ab = ba$ for all elements; non-commutative rings, such as matrix rings, require separate treatment for many results. The requirement that $1 \neq 0$ excludes the trivial zero ring (which is sometimes useful as a degenerate case). Among the elements of a ring, three types deserve immediate attention: units are elements with multiplicative inverses; zero divisors are nonzero elements $a$ for which there exists a nonzero $b$ with $ab = 0$ or $ba = 0$; and nilpotent elements are elements $a$ with $a^n = 0$ for some positive integer $n$. These three classes are mutually exclusive for nonzero elements: a unit cannot be a zero divisor, and a nilpotent element in a domain must be zero.

The characteristic of a ring $R$ is the additive order of the multiplicative identity: the smallest positive $n$ with $n \cdot 1 = 0$, or $0$ if no such $n$ exists. This single integer encodes a great deal about the arithmetic of $R$. In an integral domain, the characteristic must be $0$ or a prime $p$, since if $mn = 0$ in the characteristic means $(m \cdot 1)(n \cdot 1) = 0$ and one factor must vanish. This constraint will be fundamental when we study polynomial rings over finite fields and when we construct field extensions in Chapter 23. Establishing these foundational notions carefully — and training the intuition on canonical examples like $\mathbb{Z}/n\mathbb{Z}$ — is the work of this section.
