# 20.3.2 Kernel and Image; Isomorphisms

A ring homomorphism $\phi: R \to S$ carries two naturally defined subsets — its kernel and its image — and each has a distinctive ring-theoretic character. The kernel is not merely a subgroup but an ideal, and the image is a subring. This asymmetry between the two sides of a homomorphism is one of the essential structural features of ring theory, distinguishing it from the more symmetric situation in group theory.

The kernel and image together encode the entire behavior of $\phi$: the kernel measures what$\phi$ collapses to zero, and the image records what$\phi$ sees in$S$. The First Isomorphism Theorem — that$R/\ker\phi \cong \mathrm{im}\,\phi$ — says that the homomorphism is determined, up to isomorphism, by these two subsets.

\begin{definition}
The \emph{kernel} of $\phi$ is$\ker\phi = \{r \in R : \phi(r) = 0\}$. The \emph{image} is$\mathrm{im}\,\phi = \{\phi(r) : r \in R\}$.
\end{definition}

The kernel $\ker\phi$ is an **ideal** of$R$. Since$\phi$ is a group homomorphism of additive groups,$\ker\phi$ is a subgroup of$(R, +)$. For the ideal property: take$r \in \ker\phi$ and any$s \in R$. Then$\phi(sr) = \phi(s)\phi(r) = \phi(s) \cdot 0 = 0$, so$sr \in \ker\phi$. Similarly$rs \in \ker\phi$. The absorption property — that multiplying an element of the kernel by any ring element stays in the kernel — is precisely the defining property of an ideal, and it distinguishes kernels from arbitrary subgroups.

The image $\mathrm{im}\,\phi$ is a **subring** of$S$. It contains$1_S = \phi(1_R)$, is closed under addition ($\phi(a) + \phi(b) = \phi(a + b) \in \mathrm{im}\,\phi$), is closed under multiplication ($\phi(a)\phi(b) = \phi(ab) \in \mathrm{im}\,\phi$), and is closed under additive inverses ($-\phi(a) = \phi(-a) \in \mathrm{im}\,\phi$). Thus$\mathrm{im}\,\phi$ is a ring in its own right, and$\phi: R \to \mathrm{im}\,\phi$ is a surjective ring homomorphism.

A ring homomorphism is injective if and only if $\ker\phi = \{0\}$. The proof is the same as for groups: if$\phi(r) = \phi(s)$, then$\phi(r - s) = 0$, so$r - s \in \ker\phi$, and if the kernel is trivial then$r = s$.

\begin{definition}
A bijective ring homomorphism is a \emph{ring isomorphism}, written $R \cong S$. Isomorphic rings are indistinguishable from the ring-theoretic perspective.
\end{definition}

The First Isomorphism Theorem, proved carefully in Chapter 21, states that the induced map $\bar\phi: R/\ker\phi \to \mathrm{im}\,\phi$ is a ring isomorphism. This is the central result that converts homomorphisms into quotient ring constructions.

**Example 1.** For the projection $\pi: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$,$k \mapsto \bar{k}$: the kernel is$n\mathbb{Z}$, the set of multiples of$n$, and the image is all of$\mathbb{Z}/n\mathbb{Z}$. The first isomorphism theorem gives$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}/n\mathbb{Z}$ (as expected). This is the prototypical kernel computation.

**Example 2.** The evaluation map $\mathrm{ev}_i: \mathbb{R}[x] \to \mathbb{C}$,$f \mapsto f(i)$, has kernel$(x^2 + 1)$ (since$x^2 + 1$ is the minimal polynomial of$i$ over$\mathbb{R}$) and image$\{a + bi : a, b \in \mathbb{R}\} = \mathbb{C}$. The first isomorphism theorem gives$\mathbb{R}[x]/(x^2 + 1) \cong \mathbb{C}$, the fundamental construction of the complex numbers as a quotient.

**Example 3.** The reduction map $\rho: \mathbb{Z}[x] \to \mathbb{F}_p[x]$ sending$\sum a_i x^i \mapsto \sum \bar{a}_i x^i$ (reducing coefficients mod$p$) is a surjective ring homomorphism with kernel$p\mathbb{Z}[x] = \{pf : f \in \mathbb{Z}[x]\}$. The first isomorphism theorem gives$\mathbb{Z}[x]/p\mathbb{Z}[x] \cong \mathbb{F}_p[x]$. This reduction map is fundamental in irreducibility testing (see §23.2.4).

**Example 4.** The map $\phi: \mathbb{C} \to M_2(\mathbb{R})$ defined by$a + bi \mapsto \begin{pmatrix} a & -b \\ b & a \end{pmatrix}$ is an injective ring homomorphism. The kernel is$\{0\}$ (if$a = b = 0$ the matrix is zero). The image is the subring of rotation matrices$\left\{ \begin{pmatrix} a & -b \\ b & a \end{pmatrix} : a, b \in \mathbb{R} \right\} \cong \mathbb{C}$. This realizes$\mathbb{C}$ as a subring of$M_2(\mathbb{R})$.

**Example 5.** The trace map $\mathrm{tr}: M_n(F) \to F$ is a homomorphism of additive groups (satisfying condition (1)) but not a ring homomorphism:$\mathrm{tr}(AB) \neq \mathrm{tr}(A)\mathrm{tr}(B)$ in general, and$\mathrm{tr}(I) = n \neq 1$ for$n \geq 2$. This illustrates that not every natural linear map between rings is a ring homomorphism; the multiplicativity condition is a genuine constraint.
