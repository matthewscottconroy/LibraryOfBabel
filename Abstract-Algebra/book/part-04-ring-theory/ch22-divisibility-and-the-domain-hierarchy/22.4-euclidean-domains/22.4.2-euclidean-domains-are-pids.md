# 22.4.2 Euclidean Domains Are PIDs

Every Euclidean domain is a PID. The proof is elegant and short — it uses the division algorithm to show that any ideal has a generator, namely an element of minimum norm. This argument generalizes the classical proof that every ideal of $\mathbb{Z}$ is principal (taking the smallest positive element).

Let $R$ be a Euclidean domain with norm$N$, and let$I$ be any nonzero ideal of$R$. Among all nonzero elements of$I$, choose$a \in I$ with$N(a)$ as small as possible (a minimum exists because$\mathbb{Z}_{\geq 0}$ is well-ordered and the set of norms of nonzero elements of$I$ is a nonempty subset of$\mathbb{Z}_{\geq 0}$). We claim$I = (a)$.

The inclusion $(a) \subseteq I$ is clear: since$a \in I$ and$I$ is closed under multiplication by elements of$R$, every multiple$ra$ belongs to$I$. For the reverse inclusion, take any$b \in I$. By the division algorithm, write$b = qa + r$ with$r = 0$ or$N(r) < N(a)$. Since$b \in I$ and$qa \in I$ (as$a \in I$ and$I$ is closed under multiplication), we have$r = b - qa \in I$. If$r \neq 0$, then$N(r) < N(a)$ with$r \in I$, contradicting the minimality of$N(a)$. Therefore$r = 0$, so$b = qa \in (a)$.

This proof generalizes the argument for $\mathbb{Z}$ (where one takes the smallest positive integer in an ideal) and for$F[x]$ (where one takes the polynomial of smallest degree). The common structure is the well-ordering of the norm: because$N$ takes values in the non-negative integers, every nonempty set of norms has a minimum. The division algorithm then provides the existence of the remainder, and the minimality forces it to be zero.

The converse of this theorem is false: not every PID is Euclidean. The ring $\mathbb{Z}\left[\frac{1 + \sqrt{-19}}{2}\right]$ is a classical example of a PID that cannot be equipped with any Euclidean norm. The proof that it is a PID uses class number calculations; the proof that it is not Euclidean requires showing that any purported Euclidean norm fails for certain specific elements. This demonstrates that the inclusion$\text{ED} \subset \text{PID}$ is strict, and the domain hierarchy contains genuinely distinct levels.

**Example 1.** In $\mathbb{Z}$: the ideal$I = \{0, \pm 6, \pm 12, \pm 18, \ldots\}$. The minimum norm element is$6$ (with$N(6) = 6$). The claim is$I = (6)$, i.e., all multiples of$6$. Any element of$I$ is a multiple of$6$ by definition, so$I = 6\mathbb{Z} = (6)$. The proof via the division algorithm: take any$b \in I$; divide by$6$:$b = 6q + r$ with$0 \leq r < 6$; since$b \in I$ and$6 \in I$,$r = b - 6q \in I$; minimality of$N(6) = 6$ forces$r = 0$.

**Example 2.** In $\mathbb{Q}[x]$: the ideal$I$ generated by$\{x^2 - 1, x^3 - 1\}$ is the ideal$(x-1)$ (since$\gcd(x^2-1, x^3-1) = x-1$ as computed in §22.3.3). The minimum-degree element of$I$ is$x - 1$ (degree$1$). The proof: take any$f \in I$; divide by$x-1$:$f = (x-1)q + r$ where$r$ is a constant;$r = f - (x-1)q \in I$;$r$ is a nonzero constant would imply$I$ contains a unit, making$I = \mathbb{Q}[x]$, but$1 \notin I$ (since$1$ is not divisible by both$x^2-1$ and$x^3-1$); so$r = 0$.

**Example 3.** In $\mathbb{Z}[i]$: the ideal$(2+i, 3+i)$. The GCD of$2+i$ and$3+i$:$3+i - (2+i) = 1$. So$\gcd(2+i, 3+i) = 1$, and the ideal$(2+i, 3+i) = (1) = \mathbb{Z}[i]$. The minimum-norm element of$I$ is$1$ (norm$1$), confirming$I = \mathbb{Z}[i]$.

**Example 4.** An example where finding the minimum-norm element requires the Euclidean algorithm: in $\mathbb{Z}[i]$, find the generator of the ideal$I = (6, 4+2i)$. Compute$\gcd(6, 4+2i)$: factor$6 = 2 \cdot 3 = -i(1+i)^2 \cdot 3$. Factor$4+2i = 2(2+i) = -i(1+i)^2(2+i)$. Common factor:$-i(1+i)^2 = 2(-i) \cdot ...$. Actually$2 \mid 4+2i$ (since$(4+2i)/2 = 2+i \in \mathbb{Z}[i]$) and$2 \mid 6$. Check if$(2+i) \mid 6$:$6/(2+i) = 6(2-i)/5 = (12-6i)/5 \notin \mathbb{Z}[i]$. So the GCD is$2$, and the ideal$(6, 4+2i) = (2)$ in$\mathbb{Z}[i]$.

**Example 5.** Non-Euclidean PIDs: the ring $\mathcal{O} = \mathbb{Z}[\frac{1+\sqrt{-19}}{2}]$ is the ring of integers of$\mathbb{Q}(\sqrt{-19})$. It has class number$1$ (every ideal is principal), making it a PID. However, one can show that no Euclidean norm exists: if$N$ were such a norm, one could show that for the element$\omega = \frac{1+\sqrt{-19}}{2}$, the norm of every "remainder" in the division algorithm must be smaller than the norms of$\omega$ and its conjugate, but this leads to a contradiction. The proof requires showing that the unit group is$\{\pm 1\}$ and carefully analyzing the norm function; see Samuel (1971) for details.
