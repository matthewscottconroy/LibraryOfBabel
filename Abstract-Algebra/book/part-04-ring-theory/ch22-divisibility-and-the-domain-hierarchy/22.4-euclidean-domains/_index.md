# 22.4 Euclidean Domains

A Euclidean domain is an integral domain $R$ equipped with a Euclidean norm: a function $N \colon R \setminus \{0\} \to \mathbb{Z}_{\geq 0}$ such that for any $a, b \in R$ with $b \neq 0$, there exist $q, r \in R$ with $a = qb + r$ and either $r = 0$ or $N(r) < N(b)$. This single axiom — division with remainder — is enough to run the Euclidean algorithm and prove that every Euclidean domain is a PID. The algorithm terminates because the norms of successive remainders strictly decrease, and the last nonzero remainder is a GCD of the original elements.

The prototypes are $\mathbb{Z}$ with $N(n) = |n|$ and $F[x]$ with $N(f) = \deg f$. More interesting is the ring $\mathbb{Z}[i]$ of Gaussian integers with $N(a+bi) = a^2+b^2$: given Gaussian integers $\alpha, \beta$ with $\beta \neq 0$, we compute $\alpha/\beta \in \mathbb{C}$ and round to the nearest Gaussian integer $q$, leaving a remainder $r = \alpha - q\beta$ whose norm satisfies $N(r) < N(\beta)$ because the distance from any complex number to the nearest Gaussian integer is at most $\frac{\sqrt{2}}{2} < 1$. A similar argument applies to $\mathbb{Z}[\omega]$ where $\omega = e^{2\pi i/3}$ is a primitive cube root of unity (the Eisenstein integers). Each of these examples has number-theoretic applications: the Euclidean algorithm in $\mathbb{Z}[i]$ classifies which primes are sums of two squares, while the algorithm in $\mathbb{Z}[\omega]$ classifies which primes are represented by the form $x^2 + xy + y^2$.

A subtle and important point is that the class of Euclidean domains is strictly smaller than the class of PIDs. The ring $\mathbb{Z}\!\left[\frac{1+\sqrt{-19}}{2}\right]$ — the ring of integers of $\mathbb{Q}(\sqrt{-19})$ — is a PID, as can be shown by computing its class group. But it is not Euclidean with respect to the usual number-field norm, nor with respect to any norm whatsoever — this was proved by Pierre Samuel in 1971. This fact, while technically demanding, underscores a conceptual point: the Euclidean algorithm is a sufficient but not necessary condition for being a PID, and the hierarchy Euclidean $\subsetneq$ PID $\subsetneq$ UFD $\subsetneq$ domain is genuinely strict at every step.
