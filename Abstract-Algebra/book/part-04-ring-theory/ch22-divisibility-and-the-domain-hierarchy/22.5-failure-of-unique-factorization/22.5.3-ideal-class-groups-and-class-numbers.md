# 22.5.3 Ideal Class Groups and Class Numbers

Unique factorization of ideals in a Dedekind domain recovers much of the structure lost when element factorization fails. To measure precisely how far a Dedekind domain is from having unique element factorization, one forms a group that quantifies the obstruction — the ideal class group. This group is a central invariant of algebraic number theory, connecting the concrete arithmetic of rings to deep questions in analysis and representation theory.

In a Dedekind domain $R$ with fraction field$K$, a *fractional ideal* is a nonzero$R$-submodule$\mathfrak{a} \subseteq K$ such that$d\mathfrak{a} \subseteq R$ for some nonzero$d \in R$. Equivalently,$\mathfrak{a} = d^{-1} I$ for some ideal$I \trianglelefteq R$ and some$d \in R \setminus \{0\}$. Fractional ideals form an abelian group$\mathcal{F}(R)$ under multiplication (with$R$ itself as identity, and$\mathfrak{a}^{-1} = \{x \in K : x\mathfrak{a} \subseteq R\}$ as the inverse). The fact that inverses exist is a special property of Dedekind domains — it fails in more general Noetherian domains.

The *ideal class group* $\mathrm{Cl}(R)$ is the quotient of$\mathcal{F}(R)$ by the subgroup of principal fractional ideals$\mathcal{P}(R) = \{(a) = aR : a \in K^\times\}$. Two fractional ideals$\mathfrak{a}$ and$\mathfrak{b}$ are in the same ideal class if$\mathfrak{a} = c\mathfrak{b}$ for some$c \in K^\times$, i.e., if they are isomorphic as$R$-modules (via multiplication by$c$). The class group$\mathrm{Cl}(R) = \mathcal{F}(R)/\mathcal{P}(R)$ measures the failure of every ideal to be principal.

The class group measures the failure of unique factorization. An ideal class is trivial (equals the identity in $\mathrm{Cl}(R)$) if and only if the corresponding ideal is principal. So$\mathrm{Cl}(R)$ is the trivial group if and only if every ideal is principal — that is, if and only if$R$ is a PID (which, for Dedekind domains, is equivalent to being a UFD). The non-trivial elements of$\mathrm{Cl}(R)$ are exactly the "non-principal ideal classes," and their presence is what allows non-unique element factorization.

In $\mathbb{Z}[\sqrt{-5}]$, the class group has order$2$, generated by the class of$\mathfrak{p}_2 = (2, 1+\sqrt{-5})$. The generator$\mathfrak{p}_2$ is not principal: there is no element$\alpha \in \mathbb{Z}[\sqrt{-5}]$ with$(\alpha) = \mathfrak{p}_2$. The class$[\mathfrak{p}_2]$ has order$2$:$\mathfrak{p}_2^2 = (2)$ is principal. The two elements of$\mathrm{Cl}(\mathbb{Z}[\sqrt{-5}])$ are the class of principal ideals$[(1)]$ and the non-principal class$[\mathfrak{p}_2]$. The non-unique factorization of$6$ is a direct consequence.

For rings of integers $\mathcal{O}_K$ of number fields$K$, the class group is finite, and its order is the *class number*$h_K$. Class numbers are central objects in algebraic number theory.

**Example 1.** $\mathcal{O}_{\mathbb{Q}(\sqrt{-5})} = \mathbb{Z}[\sqrt{-5}]$ (this is the full ring of integers since$-5 \equiv 3 \pmod 4$). Class number$h = 2$. The two ideal classes are: the principal class (ideals of the form$(\alpha)$) and the non-principal class (ideals of the form$\mathfrak{p}_2 \cdot (\alpha) = (2,1+\sqrt{-5}) \cdot (\alpha)$). Every ideal is either principal or of this non-principal form.

**Example 2.** $\mathcal{O}_{\mathbb{Q}(\sqrt{-23})}$: class number$h = 3$. The class group is$\mathbb{Z}/3\mathbb{Z}$. The prime$2$ splits as$(2) = \mathfrak{p}_2 \mathfrak{p}_2'$ in$\mathcal{O}_{\mathbb{Q}(\sqrt{-23})}$ (since$-23 \equiv 1 \pmod 8$ means$2$ splits). The prime ideal$\mathfrak{p}_2$ is not principal but$\mathfrak{p}_2^3$ is principal. This corresponds to the classical result that there exist elements of$\mathbb{Q}(\sqrt{-23})$ whose cube (but not square or itself) is a rational integer.

**Example 3.** The class number $1$ rings: for imaginary quadratic fields,$h_K = 1$ (meaning$\mathcal{O}_K$ is a UFD, hence a PID, hence a Euclidean domain in the known cases) for exactly 9 values of$d < 0$:$d \in \{-1, -2, -3, -7, -11, -19, -43, -67, -163\}$. This was conjectured by Gauss and proved (Goldfeld's theorem uses deep analytic methods including work of Gross–Zagier). For$d = -163$: the class number is$1$ and the ring$\mathbb{Z}\left[\frac{1+\sqrt{-163}}{2}\right]$ is a Euclidean domain — the largest imaginary quadratic Euclidean domain.

**Example 4.** Connection to Diophantine equations: the equation $x^2 + 5 = y^3$ (a Mordell-type equation) can be attacked using the ideal class group of$\mathbb{Z}[\sqrt{-5}]$. Factoring:$y^3 = x^2 + 5 = (x + \sqrt{-5})(x - \sqrt{-5})$. Since the class number is$2$, not$1$, we cannot immediately conclude the two factors are cubes — the argument requires tracking their ideal classes. The class group of order$2$ means that$(x + \sqrt{-5})$ and$(x - \sqrt{-5})$ (as ideals) must be either both principal or both in the non-principal class. Careful analysis using the class group structure then gives the solutions.

**Example 5.** The Brauer–Siegel theorem connects class numbers to regulators (the logarithmic measure of the unit group) via the analytic class number formula: $h_K \cdot R_K \sim \sqrt{|d_K|}$ as the discriminant$d_K \to \infty$, with a correction factor from the residue of the Dedekind zeta function$\zeta_K(s)$ at$s = 1$. For imaginary quadratic fields (where$R_K = 1$), this gives$h_K \sim \sqrt{|d_K|}/(2\pi)$ asymptotically. The fact that$h_K \to \infty$ as$|d_K| \to \infty$ (for imaginary quadratic fields) follows from this formula, and it means there are only finitely many imaginary quadratic fields with any given class number.
