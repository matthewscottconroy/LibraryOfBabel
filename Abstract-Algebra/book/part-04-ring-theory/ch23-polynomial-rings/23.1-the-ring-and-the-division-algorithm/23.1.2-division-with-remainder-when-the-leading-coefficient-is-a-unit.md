# 23.1.2 Division with Remainder When the Leading Coefficient Is a Unit

Over the integers, we can divide with remainder: given $a$ and$b \neq 0$, there exist unique$q$ and$r$ with$a = qb + r$ and$0 \leq r < |b|$. The polynomial ring$R[x]$ admits an analogous algorithm, but the key hypothesis is not that$R$ is a field — only that the leading coefficient of the divisor is a unit in$R$.

To see why, recall how long division of polynomials works. To divide $f = a_n x^n + \cdots$ by$g = b_m x^m + \cdots$ (with$n \geq m$), we kill the leading term of$f$ by subtracting$\frac{a_n}{b_m} x^{n-m} \cdot g$, which requires forming$\frac{a_n}{b_m} = a_n \cdot b_m^{-1}$. This quotient exists in$R$ precisely when$b_m$ is a unit. We then recurse on the remainder, which has strictly smaller degree, ensuring the process terminates.

The precise statement is: if $f, g \in R[x]$ and the leading coefficient of$g$ is a unit in$R$, then there exist **unique**$q, r \in R[x]$ with$f = qg + r$ and either$r = 0$ or$\deg r < \deg g$. Uniqueness follows from degree considerations: if$f = qg + r = q'g + r'$ with both remainders of smaller degree, then$(q - q')g = r' - r$ has degree less than$\deg g$, forcing$q = q'$ and$r = r'$.

The most important special case is when $R = F$ is a field, since every nonzero element of a field is a unit. The full power of this case is developed in the next subsection.

**Example 1.** In $\mathbb{Z}[x]$: divide$f = 5x^3 + 3x - 2$ by$g = x^2 + 1$ (leading coefficient$1$, a unit in$\mathbb{Z}$). Divide:$5x^3 \div x^2 = 5x$; subtract$5x \cdot (x^2+1) = 5x^3 + 5x$; remainder so far:$(5x^3+3x-2) - (5x^3+5x) = -2x-2$. Now$-2x-2$ has degree$1 < 2 = \deg g$, so we stop. Result:$5x^3+3x-2 = (5x)(x^2+1) + (-2x-2)$, i.e.,$q = 5x$,$r = -2x-2$.

**Example 2.** In $\mathbb{Z}[x]$: attempt to divide$f = 2x^2 + 1$ by$g = 3x + 1$ (leading coefficient$3$, NOT a unit in$\mathbb{Z}$). To kill$2x^2$, we need$\frac{2}{3} x \cdot (3x+1)$, but$\frac{2}{3} \notin \mathbb{Z}$. So the standard division algorithm does not work over$\mathbb{Z}$. However, over$\mathbb{Q}$ (where$3$ is a unit), it does:$2x^2 + 1 = \frac{2}{3}x \cdot (3x+1) + (1 - \frac{2}{3}x) = \frac{2}{3}x \cdot (3x+1) + (-\frac{2}{3}x+1)$. Then$(-\frac{2}{3}x + 1) \div (3x+1)$:$-\frac{2}{3}x \div 3x = -\frac{2}{9}$;$(-\frac{2}{9})(3x+1) = -\frac{2}{3}x - \frac{2}{9}$; remainder$= (-\frac{2}{3}x+1) - (-\frac{2}{3}x - \frac{2}{9}) = 1 + \frac{2}{9} = \frac{11}{9}$. So$2x^2+1 = (\frac{2}{3}x - \frac{2}{9})(3x+1) + \frac{11}{9}$ over$\mathbb{Q}$, but this does not give a division in$\mathbb{Z}[x]$.

**Example 3.** In $\mathbb{Z}[x]$: the "pseudo-division" algorithm handles the case when the leading coefficient is not a unit by multiplying$f$ by a power of the leading coefficient of$g$. Specifically, there exist$q, r \in \mathbb{Z}[x]$ with$b_m^k f = qg + r$ and$\deg r < \deg g$, where$k = \deg f - \deg g + 1$. For example, divide$f = 2x^2 + 1$ by$g = 3x + 1$ with$k = 2-1+1 = 2$: compute$3^2 f = 9(2x^2+1) = 18x^2 + 9$. Divide:$18x^2 \div 3x = 6x$;$6x(3x+1) = 18x^2 + 6x$; remainder$(18x^2+9) - (18x^2+6x) = -6x+9$. Then$-6x \div 3x = -2$;$-2(3x+1) = -6x-2$; remainder$(-6x+9)-(-6x-2) = 11$. So$9(2x^2+1) = (6x-2)(3x+1) + 11$.

**Example 4.** In $(\mathbb{Z}/8\mathbb{Z})[x]$: divide$f = 3x^2 + 5x + 1$ by$g = 3x + 1$. Leading coefficient of$g$ is$3$. Is$3$ a unit mod$8$?$3 \cdot 3 = 9 \equiv 1 \pmod 8$, so$3^{-1} = 3$. So$3$ IS a unit in$\mathbb{Z}/8\mathbb{Z}$, and division is possible. Kill$3x^2$: need$(3)(3^{-1}x)(3x+1) = x(3x+1) = 3x^2+x$. Subtract:$(3x^2+5x+1) - (3x^2+x) = 4x+1$. Now$4x+1$ has degree$1 < 1$... wait,$\deg(4x+1) = 1 = \deg g$. Kill$4x$: need$(4x)(3^{-1} \cdot 1)(3x+1) \cdot ...$: quotient step is$4 \cdot 3 = 12 \equiv 4$... Hmm: to kill$4x$, subtract$\frac{4}{3} \cdot (3x+1) = 4 \cdot 3 \cdot (3x+1) / ...$ This becomes:$4x/3x = 4/3 = 4 \cdot 3^{-1} = 4 \cdot 3 = 12 \equiv 4$. So subtract$4(3x+1) = 12x + 4 \equiv 4x+4$. Remainder:$(4x+1) - (4x+4) = -3 \equiv 5$. So$3x^2+5x+1 = (x+4)(3x+1) + 5$ in$(\mathbb{Z}/8\mathbb{Z})[x]$.

**Example 5.** The uniqueness of $q$ and$r$: in$\mathbb{Q}[x]$, the quotient and remainder are unique. But in$\mathbb{Z}[x]$ with monic divisor$g$, they are also unique: if$f = qg + r = q'g + r'$ with$\deg r, \deg r' < \deg g$, then$(q-q')g = r'-r$ has degree less than$\deg g$ on the right, while degree$\geq \deg g$ on the left (since$g$ is monic,$\deg((q-q')g) = \deg(q-q') + \deg g$ unless$q = q'$). So$q = q'$ and$r = r'$. Uniqueness is a feature of the monic (or unit-leading-coefficient) hypothesis.
