# 23.2.2 Rational Root Test; Irreducibility over $\mathbb{Q}$

A central problem in algebra is deciding whether a given polynomial with integer (or rational) coefficients is irreducible over $\mathbb{Q}$. The simplest tool is a divisibility constraint on rational roots. If$f = a_n x^n + \cdots + a_0 \in \mathbb{Z}[x]$ has a rational root$p/q$ written in lowest terms, then$p$ divides the constant term$a_0$ and$q$ divides the leading coefficient$a_n$. This **rational root test** reduces the search for rational roots to a finite (and usually short) list of candidates.

The underlying reason is an instance of Gauss's lemma: if a monic polynomial with integer coefficients factors over $\mathbb{Q}$, it already factors over$\mathbb{Z}$. More generally, Gauss's lemma says that the product of primitive polynomials (those whose coefficient GCD is$1$) is again primitive. It follows that irreducibility over$\mathbb{Z}$ is the same as irreducibility over$\mathbb{Q}$, at least for primitive polynomials. This equivalence is what makes the rational root test work: a rational factor of$f$ can be cleared of denominators to give an integer factor.

For polynomials of degree $\leq 3$, the rational root test is sufficient: if no candidate$p/q$ is a root, the polynomial is irreducible over$\mathbb{Q}$. For degree$\geq 4$, the rational root test rules out linear factors but not quadratic or higher factors, and additional techniques are needed.

**Example 1.** $f = 2x^3 - 5x^2 + x + 2$. Rational root candidates:$\pm \{1, 2, 1/2\}$. Check$f(1) = 2-5+1+2 = 0$. So$(x-1) \mid f$. Divide:$f = (x-1)(2x^2-3x-2) = (x-1)(2x+1)(x-2)$. All roots are rational ($1, -1/2, 2$), consistent with the rational root test.

**Example 2.** $g = x^3 - 3x + 1$. Rational root candidates:$\pm 1$.$g(1) = 1-3+1 = -1 \neq 0$;$g(-1) = -1+3+1 = 3 \neq 0$. No rational roots, so$g$ is irreducible over$\mathbb{Q}$ (degree 3 with no rational roots).

**Example 3.** $h = 6x^4 - 7x^3 - 11x^2 + 19x - 6$. Rational root candidates:$\pm\{1, 2, 3, 6, 1/2, 3/2, 1/3, 2/3, 1/6\}$. Check$h(1) = 6-7-11+19-6 = 1 \neq 0$;$h(-1) = 6+7-11-19-6 = -23 \neq 0$;$h(2/3) = 6(16/81) - 7(8/27) - 11(4/9) + 19(2/3) - 6 = ...$. This is tedious; instead factor by trial:$h = (2x-1)(3x^3-2x^2-\ldots)$. Finding factors systematically shows$h = (2x-1)(3x-2)(x-1)(x+3)$ — all rational roots.

**Example 4.** Gauss's lemma gives content: the polynomial $3x^2 + 6x + 3 = 3(x+1)^2$ is not primitive (content$= 3$). Dividing by the content gives the primitive part$x^2 + 2x + 1 = (x+1)^2$. The factorization$3(x+1)^2$ is valid over$\mathbb{Z}$. Gauss's lemma says: to factor$3x^2+6x+3$ over$\mathbb{Q}$, first extract the content$3$, then factor the primitive part over$\mathbb{Z}$ (or equivalently over$\mathbb{Q}$).

**Example 5.** Irreducibility of $f = x^4 + 2x^2 + 2$ over$\mathbb{Q}$: no rational roots (check$\pm 1, \pm 2$:$f(1) = 5$,$f(-1) = 5$,$f(2) = 26$). So no linear factors. Check for quadratic factors:$x^4+2x^2+2 = (x^2+ax+b)(x^2-ax+c)$. Expanding:$x^4 + (c+b-a^2)x^2 + a(c-b)x + bc$. Matching:$c+b-a^2 = 2$,$a(c-b) = 0$,$bc = 2$. From$a(c-b) = 0$:$a = 0$ or$c = b$. If$a = 0$:$b+c = 2$ and$bc = 2$; so$b$ and$c$ are roots of$t^2 - 2t + 2 = 0$, discriminant$4-8 = -4 < 0$, no real solutions. If$c = b$:$2b - a^2 = 2$ and$b^2 = 2$, so$b = \pm\sqrt{2}$, irrational. No rational factorization. By Gauss's lemma,$f$ is irreducible over$\mathbb{Q}$.
