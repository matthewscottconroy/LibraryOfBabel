# 23.2.4 Reduction Modulo $p$: Irreducibility Tests

A flexible and often decisive technique for proving irreducibility over $\mathbb{Q}$ is to reduce the polynomial modulo a prime$p$ and check irreducibility over the finite field$\mathbb{F}_p$. The principle: if$f \in \mathbb{Z}[x]$ has the same degree as its reduction$\bar{f} \in \mathbb{F}_p[x]$ (i.e.,$p \nmid$ the leading coefficient of$f$) and$\bar{f}$ is irreducible over$\mathbb{F}_p$, then$f$ is irreducible over$\mathbb{Q}$.

The reasoning relies on Gauss's lemma. Any factorization $f = gh$ over$\mathbb{Q}$ would give$\bar{f} = \bar{g}\bar{h}$ over$\mathbb{F}_p$, with$\deg\bar{g} = \deg g$ and$\deg\bar{h} = \deg h$ (because$p$ doesn't divide the leading coefficient). If$\bar{f}$ is irreducible, no such factorization exists with both factors of positive degree, so one of$g$ or$h$ must be a unit (nonzero constant).

The real practical advantage is that irreducibility over $\mathbb{F}_p$ is decidable by a finite computation: for degrees$2$ and$3$, just check all$p$ elements for roots; for degree$4$, also check factorizations into irreducible quadratics. The finite field is small enough to exhaust.

An important caveat: if $\bar{f}$ factors over$\mathbb{F}_p$, this tells us nothing about$f$ over$\mathbb{Q}$. The test is one-directional. If every prime$p$ yields a reducible$\bar{f}$, we must fall back on other methods.

**Example 1.** $f = x^3 + x + 1$ over$\mathbb{Q}$. Reduce mod$2$:$\bar{f} = x^3 + x + 1 \in \mathbb{F}_2[x]$. Check roots:$\bar{f}(0) = 1 \neq 0$,$\bar{f}(1) = 1+1+1 = 1 \neq 0$ (in$\mathbb{F}_2$,$3 = 1$). No roots, so$\bar{f}$ is irreducible over$\mathbb{F}_2$ (degree 3 with no roots). Therefore$f$ is irreducible over$\mathbb{Q}$.

**Example 2.** $f = x^4 + x + 1$ over$\mathbb{Q}$. Reduce mod$2$:$\bar{f} = x^4 + x + 1 \in \mathbb{F}_2[x]$. Check roots:$\bar{f}(0) = 1$,$\bar{f}(1) = 1+1+1 = 1$. No roots. Check quadratic factors: the only monic irreducible quadratic over$\mathbb{F}_2$ is$x^2+x+1$. Does$(x^2+x+1)^2 = x^4+x^2+1 = \bar{f}$? No:$x^4+x^2+1 \neq x^4+x+1$. So$\bar{f}$ has no quadratic factors and is irreducible over$\mathbb{F}_2$. Therefore$f$ is irreducible over$\mathbb{Q}$.

**Example 3.** $f = x^4 - 10x^2 + 1$ over$\mathbb{Q}$. Try$p = 3$:$\bar{f} = x^4 - x^2 + 1 = x^4 + 2x^2 + 1 = (x^2+1)^2$ in$\mathbb{F}_3$ (since$-1 \equiv 2 \pmod 3$ and$2 \equiv -1 \pmod 3$, so$x^4 + 2x^2 + 1 = (x^2+1)^2$). This factors! Try$p = 5$:$\bar{f} = x^4 + 0 \cdot x^2 + 1 = x^4+1 \in \mathbb{F}_5[x]$. Check: is$x^4+1$ irreducible over$\mathbb{F}_5$? Elements of$\mathbb{F}_5$:$0^4+1=1$,$1^4+1=2$,$2^4+1=17\equiv 2$,$3^4+1 = 82 \equiv 2$,$4^4+1=257\equiv 2$. No roots. Quadratic factors: a monic quadratic over$\mathbb{F}_5$ is$x^2+bx+c$;$(x^2+bx+c)(x^2-bx+d) = x^4+(c+d-b^2)x^2+b(d-c)x+cd$. Matching$x^4+1$:$c+d=b^2$,$b(d-c)=0$,$cd=1$. If$b=0$:$c+d=0$ and$cd=1$, so$c, d$ roots of$t^2+1=0$ over$\mathbb{F}_5$:$t=2$ gives$4+1=5\equiv 0$, YES! So over$\mathbb{F}_5$,$x^2+1 = (x-2)(x+2)$ (since$2^2 = 4 \equiv -1$), meaning$x^4+1 = (x^2+2)(x^2-2) = (x^2+2)(x^2+3)$ over$\mathbb{F}_5$. So the mod 5 test also fails.

Over $\mathbb{Q}$: factor$x^4-10x^2+1$. Let$u = x^2$:$u^2 - 10u + 1 = 0$ gives$u = 5 \pm 2\sqrt{6}$. So$f = (x^2 - 5 - 2\sqrt{6})(x^2 - 5 + 2\sqrt{6})$ over$\mathbb{R}$, and both factors have irrational coefficients — so$f$ is actually irreducible over$\mathbb{Q}$! But no prime reduction gives us an irreducible reduction. This shows the limitation of the mod-$p$ test: it can confirm irreducibility when it works, but failure of the test for all primes does not imply reducibility.

**Example 4.** $f = x^4 + 4$ over$\mathbb{Q}$. Try$p = 3$:$\bar{f} = x^4 + 1 \in \mathbb{F}_3$. Check:$0^4+1=1$,$1^4+1=2$,$2^4+1=17\equiv 2$. No roots. Quadratic factors:$(x^2+bx+c)(x^2-bx+d) = x^4+(c+d-b^2)x^2+b(d-c)x+cd$. Matching:$c+d-b^2=0$,$b(d-c)=0$,$cd=1$. If$b=0$:$c+d=0$,$cd=1$. Over$\mathbb{F}_3$:$c+d \equiv 0$ and$cd \equiv 1$. So$c$ and$d$ are roots of$t^2+1 \equiv t^2-2 \equiv 0$ over$\mathbb{F}_3$:$t^2 \equiv 2$. Check:$0^2=0$,$1^2=1$,$2^2=4\equiv 1$. No solution, so no quadratic factorization with$b=0$. If$d=c$:$2c-b^2=0$ and$c^2=1$, so$c=\pm 1$ and$b^2=\pm 2$. Over$\mathbb{F}_3$:$b^2 \equiv 2$ has no solution (squares mod 3 are$0,1$). So$\bar{f}$ is irreducible over$\mathbb{F}_3$, and$f$ is irreducible over$\mathbb{Q}$. (But wait:$x^4+4 = (x^2+2)^2 - (2x)^2 = (x^2+2x+2)(x^2-2x+2)$ over$\mathbb{Z}$! So$f$ factors and is NOT irreducible over$\mathbb{Q}$. The mod 3 test failed to detect this because the factorization disappears mod 3.)

This example shows that the mod-$p$ test can be wrong: it claimed$\bar{f}$ was irreducible mod 3, hence$f$ should be irreducible — but$f$ factors over$\mathbb{Q}$! The resolution: the test is correct logically (if$\bar{f}$ is irreducible mod$p$ and degrees match, then$f$ is irreducible), but our computation above must have an error. Let us recheck:$x^4+4 \bmod 3$:$4 \equiv 1 \pmod 3$, so$\bar{f} = x^4+1 \in \mathbb{F}_3[x]$. And we are claiming$x^4+1$ is irreducible over$\mathbb{F}_3$. But the factorization$x^4+4 = (x^2+2x+2)(x^2-2x+2)$ over$\mathbb{Z}$ reduces mod 3 to$(x^2+2x+2)(x^2+x+2) = (x^2-x-1)(x^2+x-1)$ over$\mathbb{F}_3$. Check: over$\mathbb{F}_3$,$-1 \equiv 2$, so$(x^2+2x+2)(x^2-2x+2) \bmod 3 = (x^2+2x+2)(x^2+x+2)$. Multiply:$x^4+x^3+2x^2+2x^3+2x^2+4x+2x^2+2x+4 = x^4 + 3x^3 + 6x^2 + 6x + 4 \equiv x^4 + 0 + 0 + 0 + 1 = x^4+1$. So$x^4+1 = (x^2+2x+2)(x^2+x+2)$ over$\mathbb{F}_3$ after all! The test does give a factorization mod 3, confirming the theorem is consistent.

**Example 5.** Practical strategy: for a given polynomial, try small primes $p = 2, 3, 5, 7$ and see if any gives an irreducible reduction. If yes, done. If all fail to give irreducibility, try Eisenstein (possibly with a substitution). If that fails too, attempt direct factorization into low-degree pieces.
