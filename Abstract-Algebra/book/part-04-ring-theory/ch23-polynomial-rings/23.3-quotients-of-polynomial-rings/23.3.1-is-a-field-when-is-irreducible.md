# 23.3.1 $F[x]/(f)$ Is a Field When$f$ Is Irreducible

One of the most powerful constructions in algebra is building a field in which a given polynomial has a root. The idea is simple: we want to work "as if $f$ had a root," so we impose that relation by taking a quotient. If$f \in F[x]$ is irreducible, the ideal$(f)$ is a maximal ideal of$F[x]$. Since$F[x]$ is a PID and$f$ is irreducible (hence prime — the two notions coincide in a PID),$(f)$ is a prime ideal, and prime ideals in a PID are maximal. A quotient by a maximal ideal is a field, so$F[x]/(f)$ is a field.

The elements of $F[x]/(f)$ are cosets$g + (f)$. Since every polynomial can be reduced modulo$f$ via the division algorithm, each coset has a unique representative of degree less than$\deg f$. If$\deg f = n$, then the elements of$F[x]/(f)$ are uniquely represented as$a_0 + a_1\alpha + \cdots + a_{n-1}\alpha^{n-1}$, where$\alpha = x + (f)$ is the image of$x$ and the coefficients$a_i$ range over$F$. So$F[x]/(f)$ is an$F$-vector space of dimension$n = \deg f$.

The key point is that $\alpha$ is a root of$f$ inside this new field. Substituting$\alpha$ for$x$ in$f$ gives$f(\alpha) = f(x) + (f) = 0 + (f)$, the zero coset. In other words, modding out by$(f)$ is precisely what "adds a root of$f$" to$F$. The field$F[x]/(f)$ is the simplest field containing$F$ and a root of$f$.

The inverse of a nonzero element $g + (f)$ (with$\gcd(f, g) = 1$ since$f$ is irreducible and$\deg g < \deg f$) can be found using the extended Euclidean algorithm: there exist$u, v \in F[x]$ with$uf + vg = 1$, so$vg \equiv 1 \pmod{f}$, and the inverse of$g + (f)$ is$v + (f)$.

**Example 1.** $F = \mathbb{R}$,$f = x^2 + 1$ (irreducible over$\mathbb{R}$). The field$\mathbb{R}[x]/(x^2+1)$ has elements$a + b\alpha$ with$a, b \in \mathbb{R}$ and$\alpha^2 = -1$. This is isomorphic to$\mathbb{C}$ via$\alpha \mapsto i$. Every complex number has a multiplicative inverse:$(a+bi)^{-1} = \frac{a-bi}{a^2+b^2}$ for$(a,b) \neq (0,0)$.

**Example 2.** $F = \mathbb{Q}$,$f = x^3 - 2$ (irreducible by Eisenstein at$p = 2$). The field$\mathbb{Q}[x]/(x^3-2) \cong \mathbb{Q}(\sqrt[3]{2})$ has elements$a + b\alpha + c\alpha^2$ with$a, b, c \in \mathbb{Q}$ and$\alpha^3 = 2$. To find the inverse of$\alpha$: we need$v \in \mathbb{Q}[x]$ with$v(x) \cdot x \equiv 1 \pmod{x^3-2}$. Use extended Euclidean:$\gcd(x, x^3-2) = 1$ (since$x$ doesn't divide$x^3-2 = x \cdot x^2 - 2$). Extended algorithm:$x^3-2 = x^2 \cdot x + (-2)$, so$-2 = (x^3-2) - x^2 \cdot x$, giving$1 = (-1/2) \cdot x^2 \cdot x + (1/2)(x^3-2)$. Mod$x^3-2$:$1 \equiv (-x^2/2) \cdot x$, so$\alpha^{-1} = -\alpha^2/2$.

Check: $\alpha \cdot (-\alpha^2/2) = -\alpha^3/2 = -2/2 = -1$... that's$-1$, not$1$. Let me redo:$x^3 - 2 = x^3 - 2$. To invert$x$ mod$x^3-2$:$x \cdot x^2 = x^3 = 2 + (x^3-2)$. So$x \cdot x^2 \equiv 2 \pmod{x^3-2}$, giving$x \cdot (x^2/2) \equiv 1$. So$\alpha^{-1} = \alpha^2/2$.

Check: $\alpha \cdot \alpha^2/2 = \alpha^3/2 = 2/2 = 1$. Correct.

**Example 3.** $F = \mathbb{F}_2$,$f = x^2 + x + 1$ (irreducible over$\mathbb{F}_2$, as checked earlier). The field$\mathbb{F}_2[x]/(x^2+x+1) = \mathbb{F}_4$ has elements$\{0, 1, \alpha, \alpha+1\}$ with$\alpha^2 + \alpha + 1 = 0$, i.e.,$\alpha^2 = \alpha+1$. Multiplication table:$\alpha \cdot \alpha = \alpha+1$;$\alpha \cdot (\alpha+1) = \alpha^2 + \alpha = (\alpha+1)+\alpha = 1$ (the unit!);$(\alpha+1)(\alpha+1) = \alpha^2+1 = (\alpha+1)+1 = \alpha$. So the multiplicative group$\mathbb{F}_4^\times = \{1, \alpha, \alpha+1\}$ is cyclic of order 3, generated by$\alpha$.

**Example 4.** $F = \mathbb{F}_3$,$f = x^2 + 1$ (irreducible over$\mathbb{F}_3$ since$0^2+1=1$,$1^2+1=2$,$2^2+1=5\equiv 2$, none zero). The field$\mathbb{F}_9 = \mathbb{F}_3[x]/(x^2+1)$ has$9$ elements:$\{a+b\alpha : a, b \in \mathbb{F}_3\}$ with$\alpha^2 = -1 \equiv 2 \pmod 3$. The multiplicative group$\mathbb{F}_9^\times$ is cyclic of order$8$. Finding a generator:$\alpha$ has order ?$\alpha^2 = 2$,$\alpha^4 = 4 \equiv 1$. So$|\alpha| = 4$, not$8$. Try$1+\alpha$:$(1+\alpha)^2 = 1 + 2\alpha + \alpha^2 = 1 + 2\alpha + 2 = 3 + 2\alpha \equiv 2\alpha$.$(2\alpha)^2 = 4\alpha^2 = 4 \cdot 2 = 8 \equiv 2$.$(2)^2 = 4 \equiv 1$. So$(1+\alpha)^8 = 1$, and the order divides$8$. Check$(1+\alpha)^4 = (2\alpha)^2 = 2 \neq 1$. So$|1+\alpha| = 8$, and$1+\alpha$ generates$\mathbb{F}_9^\times$.

**Example 5.** The irreducibility hypothesis is essential. If $f$ is reducible, say$f = gh$ with$\deg g, \deg h \geq 1$, then$(g + (f))(h + (f)) = gh + (f) = f + (f) = 0 + (f)$, but$g + (f) \neq 0$ and$h + (f) \neq 0$ (since$\deg g, \deg h < \deg f$). So$F[x]/(f)$ has zero divisors and is not an integral domain, let alone a field. For example,$\mathbb{Q}[x]/(x^2-1) \cong \mathbb{Q} \times \mathbb{Q}$ (by CRT, since$x^2-1 = (x-1)(x+1)$) has zero divisors.
