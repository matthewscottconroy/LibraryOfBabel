# 23.3.2 Adjoining a Root: $F(\alpha) \cong F[x]/(\mathrm{min}_{F,\alpha})$

Suppose we are given a field $F$ and an algebraic element$\alpha$ — an element satisfying some polynomial equation over$F$ — living in some larger field. The smallest subfield of that larger field containing both$F$ and$\alpha$ is denoted$F(\alpha)$ and called the **simple extension** of$F$ by$\alpha$. The structure of$F(\alpha)$ is completely determined by the minimal polynomial of$\alpha$ over$F$.

Recall that the **minimal polynomial** $\mathrm{min}_{F,\alpha}$ is the monic polynomial of smallest degree in$F[x]$ satisfied by$\alpha$. It is irreducible: if it factored as$gh$ over$F$, then evaluating at$\alpha$ gives$g(\alpha)h(\alpha) = 0$, and since we are in a field (hence a domain), one factor vanishes, giving a polynomial of smaller degree satisfied by$\alpha$ — a contradiction. The evaluation map$F[x] \to F(\alpha)$ sending$x \mapsto \alpha$ is a ring homomorphism whose kernel is exactly the ideal$(\mathrm{min}_{F,\alpha})$, by minimality. Since$\mathrm{min}_{F,\alpha}$ is irreducible, this ideal is maximal, and the image$F[\alpha]$ (polynomials in$\alpha$) is already a field. Thus$F[\alpha] = F(\alpha)$ and the first isomorphism theorem gives$F(\alpha) \cong F[x]/(\mathrm{min}_{F,\alpha})$.

The isomorphism has a concrete payoff: the dimension of $F(\alpha)$ over$F$ equals the degree$n = \deg(\mathrm{min}_{F,\alpha})$, and the powers$1, \alpha, \ldots, \alpha^{n-1}$ form an$F$-basis. Every element of$F(\alpha)$ is uniquely a linear combination$a_0 + a_1\alpha + \cdots + a_{n-1}\alpha^{n-1}$ with$a_i \in F$, and arithmetic is done by reducing higher powers of$\alpha$ using the relation$\alpha^n = -(a_{n-1}\alpha^{n-1} + \cdots + a_0)$.

**Example 1.** $F = \mathbb{Q}$,$\alpha = \sqrt{2}$. Minimal polynomial:$x^2 - 2$ (monic, degree 2, satisfied by$\sqrt{2}$, and irreducible over$\mathbb{Q}$). So$\mathbb{Q}(\sqrt{2}) \cong \mathbb{Q}[x]/(x^2-2)$, with$F$-basis$\{1, \sqrt{2}\}$ and$[F(\alpha):F] = 2$. Arithmetic:$(a + b\sqrt{2})(c + d\sqrt{2}) = ac + 2bd + (ad+bc)\sqrt{2}$.

**Example 2.** $F = \mathbb{Q}$,$\alpha = \sqrt[3]{2}$. Minimal polynomial:$x^3 - 2$ (irreducible by Eisenstein at$p=2$). So$\mathbb{Q}(\sqrt[3]{2}) \cong \mathbb{Q}[x]/(x^3-2)$,$F$-basis$\{1, \sqrt[3]{2}, \sqrt[3]{4}\}$,$[F(\alpha):F] = 3$. Arithmetic:$(\sqrt[3]{2})^3 = 2$, so$(\sqrt[3]{4})^2 = (\sqrt[3]{2})^4 = 2\sqrt[3]{2}$.

**Example 3.** $F = \mathbb{Q}$,$\alpha = \zeta_5 = e^{2\pi i/5}$ (a primitive 5th root of unity). Minimal polynomial:$\Phi_5(x) = x^4+x^3+x^2+x+1$ (irreducible over$\mathbb{Q}$). So$\mathbb{Q}(\zeta_5) \cong \mathbb{Q}[x]/(x^4+x^3+x^2+x+1)$,$F$-basis$\{1, \zeta_5, \zeta_5^2, \zeta_5^3\}$,$[\mathbb{Q}(\zeta_5):\mathbb{Q}] = 4$. Note$\zeta_5^4 = -\zeta_5^3 - \zeta_5^2 - \zeta_5 - 1$ in this field.

**Example 4.** $F = \mathbb{F}_2$,$\alpha$ a root of$f = x^4 + x + 1 \in \mathbb{F}_2[x]$ (irreducible, as checked in §23.2.4). Then$\mathbb{F}_2(\alpha) = \mathbb{F}_2[x]/(x^4+x+1) = \mathbb{F}_{16}$, the unique field with$16 = 2^4$ elements. The basis over$\mathbb{F}_2$ is$\{1, \alpha, \alpha^2, \alpha^3\}$, and the relation is$\alpha^4 = \alpha + 1$. The multiplicative group$\mathbb{F}_{16}^\times$ is cyclic of order$15$.

**Example 5.** The degree formula is multiplicative: if $F \subset K \subset L$ is a tower of field extensions with$[K:F] = m$ and$[L:K] = n$, then$[L:F] = mn$. This is because an$F$-basis of$L$ can be built by combining an$F$-basis of$K$ with a$K$-basis of$L$. For instance,$[\mathbb{Q}(\sqrt{2}, \sqrt{3}) : \mathbb{Q}] = [\mathbb{Q}(\sqrt{2},\sqrt{3}):\mathbb{Q}(\sqrt{2})] \cdot [\mathbb{Q}(\sqrt{2}):\mathbb{Q}]$. Since$\sqrt{3} \notin \mathbb{Q}(\sqrt{2})$ (check: if$\sqrt{3} = a+b\sqrt{2}$, then$3 = a^2+2b^2+2ab\sqrt{2}$, so$ab=0$ and$a^2+2b^2=3$;$b=0$ gives$a^2=3$, impossible;$a=0$ gives$2b^2=3$, impossible), the second degree is$2$, giving$[\mathbb{Q}(\sqrt{2},\sqrt{3}):\mathbb{Q}] = 4$ with basis$\{1, \sqrt{2}, \sqrt{3}, \sqrt{6}\}$.
