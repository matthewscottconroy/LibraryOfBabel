# 25.2.2 Quotient Modules $M/N$; Well-Definedness

The quotient construction is one of the most powerful tools in algebra: it allows us to "forget" the information contained in a submodule, producing a new module that captures only the behavior of $M$ "modulo$N$." The quotient group construction in group theory and the quotient ring construction in ring theory are both special cases of this procedure, and the module version combines both.

Given a submodule $N \leq M$, we want to form a module$M/N$ in which elements of$N$ are declared to be zero. The underlying set consists of cosets of$N$ in$M$: two elements$m, m' \in M$ are declared equal in$M/N$ if and only if$m - m' \in N$. We write$m + N$ for the coset of$m$ and define addition by$(m + N) + (m' + N) = (m + m') + N$.

Since $N$ is a subgroup of$(M, +)$, the cosets of$N$ partition$M$, and the addition is well-defined: if$m + N = m_1 + N$ (so$m - m_1 \in N$) and$m' + N = m_1' + N$ (so$m' - m_1' \in N$), then$(m + m') - (m_1 + m_1') = (m - m_1) + (m' - m_1') \in N$, so$(m + m') + N = (m_1 + m_1') + N$. With this addition,$M/N$ is an abelian group, and the quotient map$\pi: M \to M/N$,$\pi(m) = m + N$, is a surjective group homomorphism.

Now we need a scalar multiplication to make $M/N$ into an$R$-module. The only natural definition is
$$r(m + N) = rm + N.$$
The essential question is whether this is well-defined: does the coset $rm + N$ depend only on the coset$m + N$, or does it depend on the choice of representative$m$?

Suppose $m + N = m' + N$, so that$m' = m + n$ for some$n \in N$. Then$rm' = r(m + n) = rm + rn$. For$rm' + N = rm + N$ to hold, we need$rn \in N$. This is guaranteed precisely because$N$ is a \emph{submodule}: it is closed under scalar multiplication by$R$, so$rn \in N$ for any$r \in R$ and$n \in N$.

This verification pinpoints the significance of the submodule condition. If $N$ were merely a subgroup (not closed under the$R$-action), then$rn$ might not belong to$N$, and the scalar multiplication$r(m + N) = rm + N$ would depend on the choice of representative. For$\mathbb{Z}$-modules (abelian groups), every subgroup is a$\mathbb{Z}$-module, so every subgroup gives a valid quotient. But for$R$-modules over a non-trivial ring, the submodule condition is genuinely necessary.

\begin{definition}
Let $N \leq M$ be a submodule. The \emph{quotient module}$M/N$ is the abelian group of cosets$m + N$ (for$m \in M$), equipped with the$R$-action$r(m + N) = rm + N$. The \emph{quotient map} is the surjective$R$-linear map$\pi: M \to M/N$,$\pi(m) = m + N$, with$\ker \pi = N$.
\end{definition}

\begin{example}
Let $R = \mathbb{Z}$,$M = \mathbb{Z}$, and$N = n\mathbb{Z}$ for a positive integer$n$. Then$M/N = \mathbb{Z}/n\mathbb{Z}$, the cyclic group of order$n$. The coset$m + n\mathbb{Z}$ is the residue class of$m$ modulo$n$, and the$\mathbb{Z}$-action on$\mathbb{Z}/n\mathbb{Z}$ is the usual modular arithmetic. This is the simplest and most familiar quotient module.
\end{example}

\begin{example}
Let $R = F[x]$,$M = F[x]$ (as a module over itself), and$N = (f)$ for some polynomial$f \in F[x]$. Then$M/N = F[x]/(f)$, the polynomial ring modulo$f$. The cosets are residue classes of polynomials modulo$f$, and scalar multiplication by$g \in F[x]$ is$g \cdot (h + (f)) = gh + (f)$. When$f$ is irreducible,$F[x]/(f)$ is a field extension of$F$. When$f = x^n$, the quotient is the ring of polynomials of degree less than$n$, on which$x$ acts as a nilpotent shift operator — this is the$F[x]$-module corresponding to the nilpotent Jordan block of size$n$.
\end{example}

\begin{example}
Let $M = R^2$ (the free module of rank 2 over$R = \mathbb{Z}$) and$N = \{(a, b) : 2a + 3b = 0\}$. Then$N$ is a submodule of$\mathbb{Z}^2$. The quotient$M/N$ is isomorphic (by the First Isomorphism Theorem) to the image of the map$\mathbb{Z}^2 \to \mathbb{Z}$ sending$(a, b) \mapsto 2a + 3b$; since$\gcd(2, 3) = 1$, this map is surjective and$M/N \cong \mathbb{Z}$.
\end{example}

\begin{example}
Let $R = F[x]$ and let$V$ be the$F[x]$-module corresponding to the linear operator$T$ on an$F$-vector space. The$T$-invariant subspaces of$V$ correspond exactly to$F[x]$-submodules of$V$ (since a subspace$W$ is$T$-invariant if and only if$x \cdot w = Tw \in W$ for all$w \in W$). The quotient$V/W$ is then the$F[x]$-module corresponding to the operator induced by$T$ on the quotient space$V/W$. This is the module-theoretic description of restriction and induction for operators, which will yield the rational canonical form in Chapter 27.
\end{example}

The quotient module $M/N$ is the "coarsest" module that can be obtained from$M$ by identifying elements of$N$ with zero. In categorical terms, it is the cokernel of the inclusion$N \hookrightarrow M$: any module map$f: M \to P$ that kills$N$ (i.e.,$f(N) = 0$) factors uniquely through the quotient map as$M \to M/N \to P$. This universal property of the quotient will be the basis for the First Isomorphism Theorem in Section 25.3.2.
