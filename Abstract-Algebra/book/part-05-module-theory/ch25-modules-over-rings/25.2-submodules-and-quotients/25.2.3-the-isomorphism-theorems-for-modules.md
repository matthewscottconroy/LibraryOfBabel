# 25.2.3 The Isomorphism Theorems for Modules

The isomorphism theorems for groups (Chapter 10) and for rings (Chapter 18) have direct analogues for modules. The statements are nearly identical, and the proofs are equally straightforward — yet the theorems are among the most frequently applied results in all of algebra. The reason is that they give us the main tool for identifying two modules as isomorphic: rather than constructing an explicit bijective $R$-linear map and checking it has a two-sided inverse, we construct a surjection with the right kernel and apply the First Isomorphism Theorem.

The fundamental observation underlying all three theorems is that module homomorphisms interact well with quotients: if $f: M \to N$ is$R$-linear, then the "essential content" of$f$ — stripped of the redundancy in$\ker f$ — is captured by the induced map on the quotient$M/\ker f$.

\begin{theorem}[First Isomorphism Theorem]
Let $f: M \to N$ be an$R$-linear map. Then$\mathrm{im}\, f$ is a submodule of$N$,$\ker f$ is a submodule of$M$, and the map
$$\bar{f}: M/\ker f \longrightarrow \mathrm{im}\, f, \quad \bar{f}(m + \ker f) = f(m),$$
is an isomorphism of $R$-modules.
\end{theorem}

To verify well-definedness: if $m + \ker f = m' + \ker f$, then$m - m' \in \ker f$, so$f(m - m') = 0$, giving$f(m) = f(m')$. Thus$\bar{f}$ is well-defined. It is$R$-linear:$\bar{f}(r(m + \ker f)) = \bar{f}(rm + \ker f) = f(rm) = rf(m) = r\bar{f}(m + \ker f)$. It is injective: if$\bar{f}(m + \ker f) = 0$, then$f(m) = 0$, so$m \in \ker f$, giving$m + \ker f = 0$ in$M/\ker f$. It is surjective onto$\mathrm{im}\, f$ by definition.

\begin{theorem}[Second Isomorphism Theorem]
Let $A$ and$B$ be submodules of$M$. Then$A + B = \{a + b : a \in A, b \in B\}$ and$A \cap B$ are both submodules of$M$, and there is a natural isomorphism
$$(A + B)/B \cong A/(A \cap B).$$
\end{theorem}

The map witnessing this isomorphism sends $a + B$ to$a + (A \cap B)$ for$a \in A$. The proof checks that this is well-defined (if$a + B = a' + B$, then$a - a' \in B$; since also$a - a' \in A$, we have$a - a' \in A \cap B$, so$a + (A \cap B) = a' + (A \cap B)$), surjective, and has kernel zero. One can also derive it from the First Isomorphism Theorem by considering the composition$A \hookrightarrow A + B \twoheadrightarrow (A + B)/B$ and noting that the kernel of$A \to (A+B)/B$ is$A \cap B$.

\begin{theorem}[Third Isomorphism Theorem]
Let $N \subseteq L \subseteq M$ be submodules. Then$L/N$ is a submodule of$M/N$, and
$$(M/N)/(L/N) \cong M/L.$$
\end{theorem}

The intuition is that "quotienting by $N$ first and then by$L/N$ is the same as quotienting by$L$ directly." The isomorphism is induced by the map$m + N \mapsto m + L$, which is a well-defined surjection from$M/N$ to$M/L$ with kernel$L/N$.

\begin{example}
Let $R = \mathbb{Z}$,$M = \mathbb{Z}$, and$f: \mathbb{Z} \to \mathbb{Z}/n\mathbb{Z}$ the natural quotient map. Then$\ker f = n\mathbb{Z}$ and$\mathrm{im}\, f = \mathbb{Z}/n\mathbb{Z}$. The First Isomorphism Theorem gives$\mathbb{Z}/n\mathbb{Z} \cong \mathbb{Z}/n\mathbb{Z}$, which is tautological here. A more interesting example: the map$f: \mathbb{Z} \to \mathbb{Z}/6\mathbb{Z}$ defined by$f(1) = 2$ (i.e.,$f(n) = 2n \bmod 6$) has$\ker f = 3\mathbb{Z}$ and$\mathrm{im}\, f = \{0, 2, 4\} \cong \mathbb{Z}/3\mathbb{Z}$, giving$\mathbb{Z}/3\mathbb{Z} \cong 2\mathbb{Z}/6\mathbb{Z}$ via$\bar{n} \mapsto 2n \bmod 6$.
\end{example}

\begin{example}
For the Second Isomorphism Theorem, let $M = \mathbb{Z}$,$A = 2\mathbb{Z}$,$B = 3\mathbb{Z}$. Then$A + B = \mathbb{Z}$ (since$\gcd(2,3)=1$) and$A \cap B = 6\mathbb{Z}$. The theorem gives$\mathbb{Z}/3\mathbb{Z} = (2\mathbb{Z} + 3\mathbb{Z})/3\mathbb{Z} \cong 2\mathbb{Z}/(2\mathbb{Z} \cap 3\mathbb{Z}) = 2\mathbb{Z}/6\mathbb{Z} \cong \mathbb{Z}/3\mathbb{Z}$. Both sides are isomorphic to$\mathbb{Z}/3\mathbb{Z}$, consistent with the theorem.
\end{example}

\begin{example}
For the Third Isomorphism Theorem, let $M = \mathbb{Z}$,$L = 2\mathbb{Z}$,$N = 6\mathbb{Z}$. Then$N \subseteq L \subseteq M$ and$(M/N)/(L/N) = (\mathbb{Z}/6\mathbb{Z})/(2\mathbb{Z}/6\mathbb{Z})$. The subgroup$2\mathbb{Z}/6\mathbb{Z} = \{0, 2, 4\}$ inside$\mathbb{Z}/6\mathbb{Z}$. The quotient$(\mathbb{Z}/6\mathbb{Z})/(\{0,2,4\})$ has cosets$\{0,2,4\}$ and$\{1,3,5\}$, giving a group of order 2, which is$\mathbb{Z}/2\mathbb{Z} \cong \mathbb{Z}/2\mathbb{Z} = M/L$.
\end{example}

\begin{example}
Let $R = F[x]$,$M = F[x]$,$N = (x^6)$,$L = (x^2)$. Then$N \subseteq L$ and$M/N = F[x]/(x^6)$,$L/N = (x^2)/(x^6) \subseteq F[x]/(x^6)$. The Third Isomorphism Theorem gives$(F[x]/(x^6))/((x^2)/(x^6)) \cong F[x]/(x^2)$. This reflects the fact that passing from polynomials modulo$x^6$ to polynomials modulo$x^2$ "forgets" the information in the higher-degree terms, collapsing to the smaller quotient.
\end{example}

The three isomorphism theorems taken together describe how the lattice of submodules behaves under the quotient operation. The First Theorem identifies domains and images; the Second explains how sums and intersections interact; the Third shows that quotienting is transitive. In the theory of composition series, these theorems combine to prove the Jordan--H\"{o}lder theorem for modules: any two composition series of a module have the same length and the same set of composition factors (up to order and isomorphism). That theorem, which measures the "atomic" decomposition of a module, rests entirely on the First and Second Isomorphism Theorems applied repeatedly.
