# 25.5.1 Generating Sets; Finitely Generated Modules

One of the most important ways to measure the complexity of a module is to ask how many elements are needed to describe it completely. A generating set for a module plays the same role as a spanning set for a vector space: it guarantees that every element is accessible as a linear combination of the generators. But unlike the vector space case, a generating set for a module over a general ring need not contain "independent" elements, and the number of generators needed does not always determine the module up to isomorphism.

\begin{definition}
Let $M$ be an$R$-module. A subset$S \subseteq M$ \emph{generates}$M$ if every$m \in M$ can be expressed as a finite$R$-linear combination$m = r_1 s_1 + r_2 s_2 + \cdots + r_k s_k$ with$r_i \in R$ and$s_i \in S$. The module$M$ is \emph{finitely generated} if it has a finite generating set$\{m_1, \ldots, m_n\}$.
\end{definition}

The smallest submodule of $M$ containing$S$ is exactly$\langle S \rangle = RS = \{r_1 s_1 + \cdots + r_k s_k : r_i \in R, s_i \in S, k \geq 0\}$. Thus$S$ generates$M$ if and only if$\langle S \rangle = M$.

The condition of finite generation is both a finiteness assumption and a tractability assumption: it says that $M$ is "fully described" by a finite amount of data (namely, the list$m_1, \ldots, m_n$ and the ring$R$). Over a field, finitely generated modules are finite-dimensional vector spaces, and the structure theorem is simply:$M \cong F^n$ for some$n$ (the dimension). Over$\mathbb{Z}$, finitely generated modules are finitely generated abelian groups, whose classification is the Fundamental Theorem (Chapter 27). Over$F[x]$, finitely generated modules correspond to finite-dimensional vector spaces with a linear operator.

\begin{example}
The $\mathbb{Z}$-module$\mathbb{Z}$ is generated by$\{1\}$: every integer$n$ is$n \cdot 1$. The$\mathbb{Z}$-module$\mathbb{Z}/6\mathbb{Z}$ is generated by$\{\bar{1}\}$: every element is$n \cdot \bar{1}$ for some$n$. Both are finitely generated.
\end{example}

\begin{example}
The $\mathbb{Z}$-module$\mathbb{Q}$ is \emph{not} finitely generated. If$\mathbb{Q} = \langle p_1/q_1, \ldots, p_k/q_k \rangle_{\mathbb{Z}}$, then every element would be an integer linear combination of these fractions. But the element$1/(q_1 q_2 \cdots q_k + 1)$ cannot be expressed in this form (its denominator involves a prime not dividing any$q_i$). More formally, the denominators of any finite generating set are bounded, preventing us from generating fractions with denominators exceeding that bound.
\end{example}

\begin{example}
The polynomial ring $R = F[x]$ is finitely generated as an$R$-module over itself:$\{1\}$ generates$R$ (since every polynomial is$f \cdot 1$). But$R = F[x]$ as an$F$-module (i.e., as an$F$-vector space) is not finitely generated:$F[x]$ has infinite$F$-dimension, with basis$\{1, x, x^2, x^3, \ldots\}$.
\end{example}

The ring-theoretic condition that pairs naturally with finite generation is Noetherianness:

\begin{definition}
A ring $R$ is \emph{Noetherian} if every ideal of$R$ is finitely generated, or equivalently, if every ascending chain of ideals$I_1 \subseteq I_2 \subseteq I_3 \subseteq \cdots$ eventually stabilizes:$I_n = I_{n+1} = \cdots$ for all sufficiently large$n$.
\end{definition}

The analogous condition for modules — that every ascending chain of submodules stabilizes — is called the \emph{ascending chain condition} (ACC). A module satisfying ACC is \emph{Noetherian}.

\begin{theorem}
If $R$ is a Noetherian ring, then every finitely generated$R$-module is Noetherian: every submodule of a finitely generated$R$-module is itself finitely generated.
\end{theorem}

This theorem is enormously useful: it says that over a Noetherian ring, the class of finitely generated modules is closed under taking submodules. Noetherian rings include $\mathbb{Z}$, all fields, all polynomial rings$F[x_1, \ldots, x_n]$ over a field (by the Hilbert Basis Theorem), and all rings of algebraic integers. Principal ideal domains are Noetherian (every ideal is generated by one element). Thus the hypothesis of finite generation is not merely a convenience in the structure theorem of Chapter 27 — it is the correct hypothesis for the theorem to hold.

\begin{example}
Let $R = F[x_1, x_2, x_3, \ldots]$ be the polynomial ring in infinitely many variables. This ring is \emph{not} Noetherian: the chain of ideals$(x_1) \subsetneq (x_1, x_2) \subsetneq (x_1, x_2, x_3) \subsetneq \cdots$ does not stabilize. The module$R$ over itself is finitely generated (by$\{1\}$), but the submodule$(x_1, x_2, x_3, \ldots) = \bigoplus_{n \geq 1} x_n R$ is not finitely generated. This shows that the Noetherian hypothesis in the preceding theorem is necessary.
\end{example}

The generating set condition is not the same as having a basis (a \emph{free} generating set — one whose elements satisfy no nontrivial linear relations). Most finitely generated modules do not have a basis in this stronger sense; only free modules do. The structure theorem for modules over PIDs precisely characterizes how far a finitely generated module is from being free: it has a free part and a torsion part, and the torsion part is measured by the invariant factors. Finite generation is the hypothesis that makes this decomposition computable.
