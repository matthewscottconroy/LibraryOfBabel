# 29.2.3 Simple Extensions: $F(\alpha) \cong F[x]/(\mathrm{min}_{F,\alpha})$

Given a field extension $E/F$ and an element$\alpha \in E$, the *simple extension*$F(\alpha)$ is the smallest subfield of$E$ that contains both$F$ and$\alpha$. It is the intersection of all subfields of$E$ containing$F$ and$\alpha$, and equivalently the set of all elements expressible as$f(\alpha)/g(\alpha)$ with$f, g \in F[x]$ and$g(\alpha) \neq 0$. Simple extensions are the building blocks of all finite extensions — the primitive element theorem, proved later, says that every finite separable extension is in fact simple — and understanding$F(\alpha)$ completely is the first essential task of field theory.

The structure of $F(\alpha)$ depends entirely on whether$\alpha$ is algebraic or transcendental over$F$. These two cases are genuinely different, and together they cover all possibilities.

\begin{theorem}[Structure of Simple Extensions]
Let $E/F$ be a field extension and$\alpha \in E$.
\begin{itemize}
\item If $\alpha$ is algebraic over$F$ with minimal polynomial$f = \mathrm{min}_{F,\alpha}$ of degree$n$, then$F(\alpha) \cong F[x]/(f)$ as$F$-algebras, and$[F(\alpha):F] = n$.
\item If $\alpha$ is transcendental over$F$, then$F(\alpha) \cong F(x)$ (the rational function field) as$F$-algebras, and$[F(\alpha):F] = \infty$.
\end{itemize}
\end{theorem}

When $\alpha$ is algebraic, the isomorphism$F(\alpha) \cong F[x]/(f)$ is the content of the first isomorphism theorem applied to the evaluation map$\mathrm{ev}_\alpha: F[x] \to E$. The kernel is$(f)$, the image is$F[\alpha]$. Since$f$ is irreducible,$(f)$ is a maximal ideal in$F[x]$, so the quotient$F[x]/(f)$ is a field. Thus$F[\alpha]$ is already a field, and$F[\alpha] = F(\alpha)$ (we do not need to adjoin inverses; every nonzero element of$F[\alpha]$ already has its inverse in$F[\alpha]$). The elements$1, \alpha, \alpha^2, \ldots, \alpha^{n-1}$ are the images of$1, x, x^2, \ldots, x^{n-1}$ under$\mathrm{ev}_\alpha$, and they form an$F$-basis for$F[x]/(f)$. Therefore$[F(\alpha):F] = n$.

The key insight is constructive: the isomorphism $F(\alpha) \cong F[x]/(f)$ means that to adjoin a root of an irreducible polynomial$f \in F[x]$, one never needs to find that root "somewhere in the world." One can build the extension abstractly by passing to the quotient ring$F[x]/(f)$, where$\bar{x}$ is the desired root. This is the universal construction: given$f$ irreducible over$F$, define$E = F[x]/(f)$; then$E$ is a field,$E$ is a degree-$n$ extension of$F$, and$f$ has a root in$E$ (namely$\bar{x}$). Every irreducible polynomial over every field has a root in some extension, and this extension is constructible without appeal to any larger ambient structure. This perspective is essential for building splitting fields and algebraic closures.

Arithmetic in $F(\alpha) \cong F[x]/(f)$ has a completely explicit description. Two elements are polynomials$p(\alpha)$ and$q(\alpha)$ of degree less than$n$. Their sum is$p(\alpha) + q(\alpha)$, computed coefficient-wise. Their product is computed as follows: multiply$p$ and$q$ as polynomials in$F[x]$, obtaining a polynomial of degree up to$2n - 2$; then reduce modulo$f$ using the relation$f(\alpha) = 0$, which expresses$\alpha^n$ as a$F$-linear combination of$1, \alpha, \ldots, \alpha^{n-1}$. The result has degree less than$n$ and represents the product in$F(\alpha)$.

**Example 1.** The field $\mathbb{Q}(\sqrt{2}) \cong \mathbb{Q}[x]/(x^2 - 2)$. Elements are$a + b\bar{x}$ with$a, b \in \mathbb{Q}$. Multiplication:$(a + b\bar{x})(c + d\bar{x}) = ac + (ad + bc)\bar{x} + bd\bar{x}^2 = ac + (ad+bc)\bar{x} + bd \cdot 2$ (using$\bar{x}^2 = 2$)$= (ac + 2bd) + (ad + bc)\bar{x}$. This matches the familiar formula for$\mathbb{Q}(\sqrt{2})$ with$\bar{x} = \sqrt{2}$.

**Example 2.** The field $\mathbb{F}_4 = \mathbb{F}_2[x]/(x^2 + x + 1)$. Here$f = x^2 + x + 1$ is irreducible over$\mathbb{F}_2$ (neither$0$ nor$1$ is a root:$0 + 0 + 1 = 1 \neq 0$ and$1 + 1 + 1 = 1 \neq 0$ in$\mathbb{F}_2$). Let$\omega = \bar{x}$. Then$\omega^2 = -\omega - 1 = \omega + 1$ (since$-1 = 1$ in$\mathbb{F}_2$). The four elements of$\mathbb{F}_4$ are$\{0, 1, \omega, \omega + 1\}$. Multiplication table:$\omega \cdot \omega = \omega + 1$,$\omega \cdot (\omega+1) = \omega^2 + \omega = (\omega+1) + \omega = 1$,$(\omega+1)(\omega+1) = \omega^2 + 1 = (\omega+1) + 1 = \omega$.

**Example 3.** The field $\mathbb{Q}(\zeta_5) \cong \mathbb{Q}[x]/(\Phi_5)$ where$\Phi_5 = x^4 + x^3 + x^2 + x + 1$ is the$5$th cyclotomic polynomial (irreducible over$\mathbb{Q}$). Elements are$a + b\zeta_5 + c\zeta_5^2 + d\zeta_5^3$ with$a, b, c, d \in \mathbb{Q}$. The relation$\zeta_5^4 = -\zeta_5^3 - \zeta_5^2 - \zeta_5 - 1$ allows reduction of any power$\zeta_5^k$ for$k \geq 4$. The degree is$[\mathbb{Q}(\zeta_5):\mathbb{Q}] = 4$.

**Example 4.** Over $\mathbb{Q}$, adjoin a root of the irreducible polynomial$f = x^3 - x - 1$. (Irreducibility: no rational roots, checked by testing$\pm 1$;$f(1) = -1$ and$f(-1) = 1$.) The simple extension$\mathbb{Q}(\alpha) \cong \mathbb{Q}[x]/(x^3 - x - 1)$ has degree$3$, with basis$\{1, \alpha, \alpha^2\}$ and the relation$\alpha^3 = \alpha + 1$. To find$(1 + \alpha^2)^{-1}$: we need$g(\alpha)$ such that$(1 + \alpha^2)g(\alpha) = 1$. Apply the extended Euclidean algorithm in$\mathbb{Q}[x]$ to compute$\gcd(1 + x^2, x^3 - x - 1)$. One finds$1 = (x+1)(1+x^2) + (-x^2 - x + 1)(x^3 - x - 1) / \ldots$; working through gives$(1 + \alpha^2)^{-1} = c_0 + c_1 \alpha + c_2 \alpha^2$ for specific$c_i \in \mathbb{Q}$.

**Example 5.** The splitting field of $x^4 + 1$ over$\mathbb{Q}$. The polynomial$x^4 + 1$ is the$8$th cyclotomic polynomial$\Phi_8$, which is irreducible over$\mathbb{Q}$ (by Eisenstein on$f(x+1)$ or by direct argument). Adjoining a root$\zeta = e^{i\pi/4} = \frac{\sqrt{2}}{2}(1 + i)$ gives$\mathbb{Q}(\zeta)$ of degree$4$ over$\mathbb{Q}$. One can show that$\zeta + \zeta^{-1} = \sqrt{2} \in \mathbb{Q}(\zeta)$ and$\zeta - \zeta^{-1} = i\sqrt{2} \in \mathbb{Q}(\zeta)$, so all four roots$\zeta, \zeta^3, \zeta^5, \zeta^7$ lie in$\mathbb{Q}(\zeta)$ and$\mathbb{Q}(\zeta)$ is already the splitting field. This illustrates that a single adjunction can be enough to split a polynomial of higher degree.

The abstract construction $F[x]/(f)$ for irreducible$f$ is one of the most productive ideas in algebra: it is the mechanism by which every algebraically closed field is built from$\mathbb{Q}$ or$\mathbb{F}_p$ by iterated simple extensions, the mechanism by which every finite field of any prime power order is constructed, and the starting point for the entire theory of algebraic closures.
