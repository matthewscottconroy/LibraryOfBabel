# 29.2.4 Algebraic Extensions; Algebraic Closure under Composition

An extension $E/F$ is called *algebraic* if every element of$E$ is algebraic over$F$. This is the most natural global version of the algebraicity condition: not just some elements, but all of them, satisfy polynomial equations over the base field. Simple extensions generated by a single algebraic element are algebraic by definition. But algebraicity is more interesting when extensions are built iteratively — by adjoining infinitely many elements, or by composing two algebraic extensions — and the key theorem is that algebraic extensions are stable under these operations.

\begin{theorem}[Transitivity of Algebraicity]
If $E/K$ is algebraic and$K/F$ is algebraic, then$E/F$ is algebraic.
\end{theorem}

The proof is a clean application of the Tower Law and degree arguments. Take any $\alpha \in E$. Since$E/K$ is algebraic,$\alpha$ satisfies a polynomial$f = a_n x^n + a_{n-1}x^{n-1} + \cdots + a_0$ with coefficients$a_i \in K$. Since$K/F$ is algebraic, each$a_i$ is algebraic over$F$. Now consider the tower
$$F \subseteq F(a_0, a_1, \ldots, a_n) \subseteq F(a_0, a_1, \ldots, a_n, \alpha).$$
The intermediate field $L = F(a_0, \ldots, a_n)$ is generated over$F$ by finitely many algebraic elements. Each$a_i$ has finite degree over the previously adjoined elements, so$[L:F]$ is finite by the Tower Law (applied inductively). Since$\alpha$ satisfies$f \in L[x]$ and$f$ is nonzero (the$a_i$ are well-defined elements of$L$),$\alpha$ is algebraic over$L$. Therefore$[L(\alpha):L]$ is finite. By the Tower Law,
$$[F(a_0, \ldots, a_n, \alpha):F] = [F(a_0, \ldots, a_n, \alpha):L] \cdot [L:F]$$
is finite, so $\alpha$ is algebraic over$F$. Since$\alpha \in E$ was arbitrary,$E/F$ is algebraic.

This closure property is what makes algebraic extensions the correct domain for Galois theory. One can adjoin roots of polynomials, then adjoin roots of polynomials with those roots as coefficients, and so on indefinitely — and remain entirely within the algebraic world. Transcendence never intrudes if it was never present in the first place.

A second important closure property is that the algebraic elements form a field. The set of elements of $E$ that are algebraic over$F$ is closed under addition, subtraction, multiplication, and taking nonzero inverses.

\begin{proposition}
If $\alpha, \beta \in E$ are algebraic over$F$, then so are$\alpha \pm \beta$,$\alpha \beta$, and (if$\alpha \neq 0$)$\alpha^{-1}$.
\end{proposition}

The proof: since $\alpha$ and$\beta$ are algebraic over$F$, the extension$F(\alpha, \beta)/F$ has finite degree (by iterated simple extensions and the Tower Law). Any element of$F(\alpha, \beta)$ — including$\alpha + \beta$,$\alpha\beta$, etc. — is algebraic over$F$ by the theorem "finite implies algebraic" (proved in §29.2.5). The set of algebraic elements in$E$ over$F$ is therefore a subfield of$E$, called the *algebraic closure of$F$ in$E$*.

When $E = \bar{F}$ is the algebraic closure of$F$, the algebraic closure of$F$ in$\bar{F}$ is$\bar{F}$ itself — every element of$\bar{F}$ is algebraic over$F$ by the definition of algebraic closure. More interestingly, when$E = \mathbb{C}$ and$F = \mathbb{Q}$, the algebraic closure of$\mathbb{Q}$ in$\mathbb{C}$ is the field$\bar{\mathbb{Q}}$ of algebraic numbers, which is a proper subfield of$\mathbb{C}$.

**Example 1.** The field $\mathbb{Q}(\sqrt{2}, \sqrt[3]{5})/\mathbb{Q}$ is algebraic. Both$\sqrt{2}$ and$\sqrt[3]{5}$ are algebraic over$\mathbb{Q}$, and the tower$\mathbb{Q} \subseteq \mathbb{Q}(\sqrt{2}) \subseteq \mathbb{Q}(\sqrt{2}, \sqrt[3]{5})$ has finite total degree$2 \cdot 3 = 6$ (since$[\mathbb{Q}(\sqrt{2}, \sqrt[3]{5}):\mathbb{Q}(\sqrt{2})] = 3$, as$x^3 - 5$ remains irreducible over$\mathbb{Q}(\sqrt{2})$ by comparing degrees). Every element is algebraic over$\mathbb{Q}$ because the extension is finite.

**Example 2.** The algebraic closure $\bar{\mathbb{Q}}/\mathbb{Q}$ is algebraic but infinite. It contains$\sqrt[n]{2}$ for every$n \geq 1$, and$[\mathbb{Q}(\sqrt[n]{2}):\mathbb{Q}] = n$ grows without bound. So$[\bar{\mathbb{Q}}:\mathbb{Q}] = \infty$. Yet every element of$\bar{\mathbb{Q}}$ is algebraic over$\mathbb{Q}$ by the very definition of$\bar{\mathbb{Q}}$. This is the canonical example of an infinite algebraic extension.

**Example 3.** The element $\sqrt{2} + \sqrt[3]{3}$ is algebraic over$\mathbb{Q}$, since it lies in$\mathbb{Q}(\sqrt{2}, \sqrt[3]{3})$, which is a finite algebraic extension. The degree of$\sqrt{2} + \sqrt[3]{3}$ over$\mathbb{Q}$ equals$[\mathbb{Q}(\sqrt{2} + \sqrt[3]{3}):\mathbb{Q}]$, which one can show equals$6$ (since$\mathbb{Q}(\sqrt{2}+\sqrt[3]{3}) = \mathbb{Q}(\sqrt{2}, \sqrt[3]{3})$ in this case, as$[\mathbb{Q}(\sqrt{2}, \sqrt[3]{3}):\mathbb{Q}] = 6$ and the primitive element has degree$\leq 6$, with equality forced by irreducibility of its minimal polynomial).

**Example 4.** The compositum $\mathbb{Q}^{\mathrm{ab}}/\mathbb{Q}$ of all abelian extensions of$\mathbb{Q}$ is an infinite algebraic extension. By the Kronecker–Weber theorem,$\mathbb{Q}^{\mathrm{ab}} = \bigcup_{n \geq 1} \mathbb{Q}(\zeta_n)$, the union of all cyclotomic fields. Each$\mathbb{Q}(\zeta_n)/\mathbb{Q}$ is algebraic (degree$\phi(n)$), and the union of an ascending chain of algebraic extensions is algebraic: any element of$\mathbb{Q}^{\mathrm{ab}}$ lies in some$\mathbb{Q}(\zeta_n)$ and is therefore algebraic over$\mathbb{Q}$.

**Example 5.** If $K/F$ is algebraic and$\alpha$ is transcendental over$K$, then$\alpha$ is transcendental over$F$. This follows from the contrapositive: if$\alpha$ were algebraic over$F$, then it would be algebraic over$K$ (since$K/F$ is algebraic and algebraicity is transitive, applied in the other direction:$F(\alpha)/F$ algebraic and$K/F$ algebraic would give$K(\alpha)/F$ algebraic... more precisely, if$\alpha$ is algebraic over$F$ with minimal polynomial$g \in F[x]$, then$g \in K[x]$ as well, so$\alpha$ is algebraic over$K$). The transcendence of$\alpha$ over$K$ therefore implies transcendence over$F$. This logical contrapositive is useful in practice: to show something is transcendental over$F$, it suffices to show it is transcendental over some algebraic extension of$F$.

The closure properties of algebraic extensions — stable under composition, stable under field operations — make the class of algebraic extensions the natural category in which to develop Galois theory. These properties ensure that the constructions we need (splitting fields, algebraic closures, Galois extensions of Galois extensions) remain within the algebraic realm, and they provide the framework for the fundamental theorem.
