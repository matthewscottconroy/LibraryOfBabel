# 30.3.1 Statement: Finite Separable Extensions Are Simple

A field extension $E/F$ is *simple* if it is generated by a single element:$E = F(\theta)$ for some$\theta \in E$. Such an element is called a *primitive element* for the extension. Simple extensions are the most transparent kind — their structure is completely described by the minimal polynomial of$\theta$, and all arithmetic in$E$ reduces to polynomial arithmetic modulo that minimal polynomial. The question, then, is: when can we guarantee that a finite extension is simple?

\begin{definition}
A field extension $E/F$ is *simple* if$E = F(\theta)$ for some$\theta \in E$. Such a$\theta$ is called a *primitive element* of the extension.
\end{definition}

The answer is the Primitive Element Theorem: if $E/F$ is a finite separable extension, then$E = F(\theta)$ for some$\theta \in E$. Every finite separable extension is simple. This is a non-trivial result. A finite extension$E/F$ is automatically generated by finitely many elements — for instance, one element per basis vector — but the theorem says something stronger: a single well-chosen element suffices, provided the extension is separable. The primitive element$\theta$ has degree$[E:F]$ over$F$, so$1, \theta, \theta^2, \ldots, \theta^{[E:F]-1}$ forms a basis of$E$ over$F$.

\begin{theorem}[Primitive Element Theorem]
Let $E/F$ be a finite separable extension. Then there exists$\theta \in E$ such that$E = F(\theta)$. Equivalently,$E \cong F[x]/\big(f(x)\big)$ where$f = \mathrm{min}_{F,\theta}$ is a separable irreducible polynomial in$F[x]$ of degree$[E:F]$.
\end{theorem}

The hypothesis of separability cannot be dropped. A finite extension $E/F$ has only finitely many intermediate fields if and only if it is simple — this characterization, the *finite intermediate fields criterion*, shows that the existence of a primitive element is equivalent to a lattice-theoretic property. For finite separable extensions, the Galois correspondence (once established) shows the lattice of intermediate fields is in bijection with subgroups of a finite group, hence finite. This finiteness then forces a primitive element to exist.

\begin{proposition}
Let $E/F$ be a finite extension with$F$ infinite. Then$E$ is a simple extension if and only if there are only finitely many intermediate fields$F \subseteq K \subseteq E$.
\end{proposition}

The connection between separability and finiteness of intermediate fields is at the heart of the theorem. A finite inseparable extension can have infinitely many intermediate fields — for instance, $\mathbb{F}_p(s^{1/p}, t^{1/p})/\mathbb{F}_p(s,t)$ has infinitely many intermediate fields of the form$\mathbb{F}_p(s,t)(as^{1/p} + bt^{1/p})$ for varying$[a:b] \in \mathbb{P}^1$ — and consequently fails to be simple. The Primitive Element Theorem draws a clean boundary: simple$\iff$ finitely many intermediate fields$\iff$ separable (for finite extensions over infinite fields; over finite fields, every finite extension is simple by the cyclicity of the multiplicative group).

**Example 1.** The extension $\mathbb{Q}(\sqrt{2}, \sqrt{3})/\mathbb{Q}$ has degree$4$ and is separable. A primitive element is$\theta = \sqrt{2} + \sqrt{3}$. Computing:$\theta^2 = 5 + 2\sqrt{6}$,$\theta^3 = 11\sqrt{2} + 9\sqrt{3}$, and$\theta^4 = 49 + 20\sqrt{6}$. Eliminating the irrationalities, one finds the minimal polynomial$x^4 - 10x^2 + 1$ of$\theta$ over$\mathbb{Q}$. Since this has degree$4 = [\mathbb{Q}(\sqrt{2},\sqrt{3}):\mathbb{Q}]$, we conclude$\mathbb{Q}(\sqrt{2}+\sqrt{3}) = \mathbb{Q}(\sqrt{2}, \sqrt{3})$.

**Example 2.** For any number field $K = \mathbb{Q}(\alpha_1, \ldots, \alpha_k)$, the Primitive Element Theorem guarantees the existence of$\theta \in K$ with$K = \mathbb{Q}(\theta)$. This is the defining property of a number field in the classical sense: a finite extension of$\mathbb{Q}$ generated by a single algebraic number. The theorem confirms that the two definitions — as a finite extension vs.\ as$\mathbb{Q}(\theta)$ for a single algebraic number — are equivalent.

**Example 3.** The extension $\mathbb{F}_{p^n}/\mathbb{F}_p$ is separable and finite of degree$n$. A primitive element is any generator$\theta$ of the cyclic group$\mathbb{F}_{p^n}^*$: since every element of$\mathbb{F}_{p^n}$ is a power of$\theta$, certainly$\mathbb{F}_p(\theta) = \mathbb{F}_{p^n}$. The minimal polynomial of$\theta$ over$\mathbb{F}_p$ is an irreducible polynomial of degree$n$; such polynomials are called *primitive polynomials* over$\mathbb{F}_p$.

**Example 4.** Consider $E = \mathbb{Q}(2^{1/3}, \omega)$ where$\omega = e^{2\pi i/3}$. This is the splitting field of$x^3 - 2$ over$\mathbb{Q}$, of degree$6$. The Primitive Element Theorem guarantees a single generator$\theta$ with$\mathbb{Q}(\theta) = E$. The element$\theta = 2^{1/3} + \omega$ works: one computes$\theta, \theta^2, \ldots, \theta^6$, finds a$\mathbb{Q}$-linear relation, and thereby recovers the minimal polynomial of$\theta$, which has degree$6$.

**Example 5.** The cyclotomic field $\mathbb{Q}(\zeta_n)$ is already a simple extension by construction, with primitive element$\zeta_n$ itself. Its minimal polynomial is the$n$th cyclotomic polynomial$\Phi_n(x)$, which is irreducible over$\mathbb{Q}$ and has degree$\phi(n)$. Since$[\mathbb{Q}(\zeta_n):\mathbb{Q}] = \phi(n)$, the cyclotomic polynomial is the minimal polynomial of$\zeta_n$, consistent with the Primitive Element Theorem.

The practical value of the theorem is significant. When working with a finite separable extension $E/F$, one can always find$\theta$ such that$E = F(\theta)$. This reduces all computations in$E$ — finding conjugates, computing norms and traces, understanding the Galois group — to computations with the single polynomial$\mathrm{min}_{F,\theta}$. The primitive element need not be unique; different choices of$\theta$ give different (but isomorphic) descriptions of$E$ as a quotient ring$F[x]/(f)$.

\begin{remark}
The Primitive Element Theorem connects naturally to the modern theory of étale algebras. A finite $F$-algebra$A$ is étale (a product of separable field extensions of$F$) if and only if$A \cong F[x]/(f)$ for some separable polynomial$f$ — not necessarily irreducible. When$f$ is irreducible, this is exactly$E = F(\theta)$ for$\theta$ a root of$f$. The theorem thus identifies simple separable extensions with the irreducible components of étale$F$-algebras, and this perspective is the starting point for Grothendieck's treatment of the fundamental group of a scheme in terms of finite étale covers.
\end{remark}
