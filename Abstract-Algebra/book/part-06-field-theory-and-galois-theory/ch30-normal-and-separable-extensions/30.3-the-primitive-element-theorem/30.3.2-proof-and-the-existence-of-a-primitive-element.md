# 30.3.2 Proof and the Existence of a Primitive Element

The proof of the Primitive Element Theorem splits naturally into two cases: when the base field $F$ is infinite, and when it is finite. The two arguments are structurally different: the infinite case uses a linear algebra–style counting argument, while the finite case uses the cyclic structure of the multiplicative group.

For infinite $F$, the key idea is that a primitive element can be found as a simple linear combination of two generators. It suffices to handle the case$E = F(\alpha, \beta)$, since the general case follows by induction: if$E = F(\alpha_1, \ldots, \alpha_k)$, one first finds$\theta_1$ with$F(\alpha_1, \alpha_2) = F(\theta_1)$, then$\theta_2$ with$F(\theta_1, \alpha_3) = F(\theta_2)$, and so on. For$E = F(\alpha, \beta)$ with both$\alpha$ and$\beta$ having separable minimal polynomials over$F$, the claim is that$\theta = \alpha + c\beta$ is a primitive element for all but finitely many$c \in F$.

To see why, let $f = \mathrm{min}_{F,\alpha}$ and$g = \mathrm{min}_{F,\beta}$, with roots$\alpha = \alpha_1, \alpha_2, \ldots, \alpha_m$ and$\beta = \beta_1, \beta_2, \ldots, \beta_n$ in$\bar{F}$. For a given$c$, set$\theta = \alpha_1 + c\beta_1$ and consider the polynomials$f(x)$ and$g\!\left(\frac{\theta - x}{c}\right)$ as polynomials in$x$ over$F(\theta)$. Their common roots are exactly those$\alpha_i$ for which$\theta = \alpha_i + c\beta_j$ for some$j$. If$c$ is chosen so that$\alpha_i + c\beta_j \neq \theta$ for all$(i,j) \neq (1,1)$, then the only common root of$f(x)$ and$g((\theta - x)/c)$ in$\bar{F}$ is$\alpha_1 = \alpha$. This means$\mathrm{min}_{F(\theta),\alpha}$ has degree$1$, so$\alpha \in F(\theta)$, and consequently$\beta = (\theta - \alpha)/c \in F(\theta)$, giving$F(\theta) = F(\alpha, \beta) = E$.

The values of $c$ that must be excluded satisfy$\alpha_i + c\beta_j = \alpha_1 + c\beta_1$ for some$(i,j) \neq (1,1)$, i.e.,$c = (\alpha_1 - \alpha_i)/(\beta_j - \beta_1)$ when$\beta_j \neq \beta_1$. There are at most$(m-1) \cdot n$ such values. Since$F$ is infinite, it contains elements outside this finite excluded set.

\begin{theorem}[Primitive Element Theorem — Infinite Case]
Let $E/F$ be a finite separable extension with$F$ infinite. For any$\alpha, \beta \in E$ with$E = F(\alpha, \beta)$, all but finitely many$c \in F$ satisfy$F(\alpha + c\beta) = E$.
\end{theorem}

For finite $F$, the argument is more elegant. The multiplicative group$E^*$ is cyclic of order$|E| - 1$ (proved in §32.3.3), and any generator$\theta$ of$E^*$ satisfies$F(\theta) = E$ because every non-zero element of$E$ is a power of$\theta$.

\begin{theorem}[Primitive Element Theorem — Finite Case]
Let $E/F$ be a finite extension of finite fields. Any generator$\theta$ of the cyclic group$E^*$ is a primitive element:$F(\theta) = E$.
\end{theorem}

The two cases together establish the Primitive Element Theorem in full generality.

**Example 1.** Let $E = \mathbb{Q}(\sqrt{2}, \sqrt{3})$,$F = \mathbb{Q}$. The minimal polynomials are$f = x^2 - 2$ (roots$\pm\sqrt{2}$) and$g = x^2 - 3$ (roots$\pm\sqrt{3}$). The excluded values of$c$ from the proof are$c = (\sqrt{2} - (-\sqrt{2}))/(\pm\sqrt{3} - \sqrt{3})$, giving$c = \mp\sqrt{2/3}$, which are irrational. So every rational$c$ works. Taking$c = 1$:$\theta = \sqrt{2} + \sqrt{3}$ is a primitive element. The minimal polynomial of$\theta$ over$\mathbb{Q}$ is$x^4 - 10x^2 + 1$, verifying$[\mathbb{Q}(\theta):\mathbb{Q}] = 4 = [E:\mathbb{Q}]$.

**Example 2.** Let $E = \mathbb{Q}(\sqrt[3]{2}, \omega)$ where$\omega = e^{2\pi i/3}$, a degree-$6$ Galois extension of$\mathbb{Q}$. Take$\alpha = \sqrt[3]{2}$ and$\beta = \omega$. The roots of$\mathrm{min}_{\mathbb{Q},\alpha} = x^3 - 2$ are$\sqrt[3]{2}, \omega\sqrt[3]{2}, \omega^2\sqrt[3]{2}$, and the roots of$\mathrm{min}_{\mathbb{Q},\beta} = x^2 + x + 1$ are$\omega, \omega^2$. The excluded values of$c$ are$(\sqrt[3]{2} - \omega^k\sqrt[3]{2})/(\omega^j - \omega)$ for various$k, j$, all of which are irrational. So$c = 1$ gives$\theta = \sqrt[3]{2} + \omega$, a primitive element. One can confirm the minimal polynomial of$\theta$ over$\mathbb{Q}$ has degree$6$ by computing the$6$ images under the Galois group:$\sqrt[3]{2}+\omega$,$\omega\sqrt[3]{2}+\omega$,$\omega^2\sqrt[3]{2}+\omega$,$\sqrt[3]{2}+\omega^2$,$\omega\sqrt[3]{2}+\omega^2$,$\omega^2\sqrt[3]{2}+\omega^2$ — all distinct.

**Example 3.** For $\mathbb{F}_{16}/\mathbb{F}_2$: let$f(x) = x^4 + x + 1$, irreducible over$\mathbb{F}_2$. Let$\alpha$ be a root. Then$\mathbb{F}_2(\alpha) = \mathbb{F}_{16}$. To verify$\alpha$ is also a generator of$\mathbb{F}_{16}^*$ (i.e., a primitive element in the multiplicative sense), check that$|\mathbb{F}_{16}^*| = 15 = 3 \cdot 5$ and that$\alpha^3 \neq 1$ and$\alpha^5 \neq 1$. One computes$\alpha^4 = \alpha + 1$,$\alpha^5 = \alpha^2 + \alpha$,$\alpha^{15} = 1$ (by Fermat), and$\alpha^5 \neq 1$ since$\alpha^2 + \alpha \neq 1$ in$\mathbb{F}_2(\alpha)$. So$\alpha$ has order$15$ and generates$\mathbb{F}_{16}^*$.

**Example 4.** For $\mathbb{F}_9/\mathbb{F}_3$, use$f(x) = x^2 + 1$ (irreducible over$\mathbb{F}_3$). Let$\alpha$ be a root, so$\alpha^2 = -1 = 2$ in$\mathbb{F}_3$. The group$\mathbb{F}_9^*$ has order$8$. Check:$\alpha^2 = 2$,$\alpha^4 = (2)^2 = 4 = 1$ mod$3$. So$\alpha$ has order$4$, not$8$:$\alpha$ does not generate$\mathbb{F}_9^*$. Try$\beta = \alpha + 1$:$\beta^2 = \alpha^2 + 2\alpha + 1 = 2 + 2\alpha + 1 = 2\alpha$,$\beta^4 = (2\alpha)^2 = 4\alpha^2 = \alpha^2 = 2 \neq 1$,$\beta^8 = 2^2 = 4 = 1$. So$\beta = \alpha+1$ has order$8$ and is a primitive generator of$\mathbb{F}_9^*$, hence a primitive element for$\mathbb{F}_9/\mathbb{F}_3$.

**Example 5.** For $\mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5})/\mathbb{Q}$ (degree$8$): apply the two-generator step three times. Step 1:$\theta_1 = \sqrt{2} + \sqrt{3}$ gives$\mathbb{Q}(\theta_1) = \mathbb{Q}(\sqrt{2},\sqrt{3})$ (by Example 1). Step 2: Apply the argument to$\mathbb{Q}(\theta_1)(\sqrt{5})$. The excluded$c$-values for Step 2 are irrational, so$c = 1$ gives$\theta_2 = \theta_1 + \sqrt{5} = \sqrt{2}+\sqrt{3}+\sqrt{5}$ as a primitive element for$\mathbb{Q}(\sqrt{2},\sqrt{3},\sqrt{5})/\mathbb{Q}$. The minimal polynomial of$\theta_2$ over$\mathbb{Q}$ is$x^8 - 40x^6 + 352x^4 - 960x^2 + 576$, of degree$8 = [E:\mathbb{Q}]$.

\begin{remark}
The explicit value of $c$ matters in computational applications. In computer algebra systems, primitive elements are computed by choosing small integer values of$c$ (typically$c = 1$) and verifying that the minimal polynomial of$\alpha + c\beta$ has the expected degree. The proof guarantees that all but finitely many choices work, so the smallest valid$c$ is typically$1$. For number fields arising in algebraic number theory, the primitive element computation is a standard algorithm implemented in systems such as PARI/GP, Magma, and SageMath, and it underlies the canonical representation of number fields as$\mathbb{Q}[x]/(f(x))$.
\end{remark}
