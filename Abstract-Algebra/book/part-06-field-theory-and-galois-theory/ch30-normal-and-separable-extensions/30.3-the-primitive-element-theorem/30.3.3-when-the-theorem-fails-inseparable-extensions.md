# 30.3.3 When the Theorem Fails: Inseparable Extensions

The Primitive Element Theorem is sharp: it fails in the presence of inseparability. The standard counterexample illustrates the failure precisely. Let $k$ be a perfect field of characteristic$p$ (for concreteness, take$k = \mathbb{F}_p$), and let$F = k(x, y)$ be the rational function field in two independent variables. The extension$E = F(x^{1/p}, y^{1/p})$ adjoins$p$th roots of both$x$ and$y$, and has degree$[E:F] = p^2$: the elements$1, x^{1/p}, y^{1/p}, x^{1/p}y^{1/p}$ form a basis of$E$ over$F$, formally verified by showing$F$-linear independence using the inseparability of the minimal polynomials.

\begin{proposition}
The extension $E = F(x^{1/p}, y^{1/p})$ over$F = \mathbb{F}_p(x,y)$ has degree$p^2$ over$F$ and is not simple: there is no$\theta \in E$ with$F(\theta) = E$.
\end{proposition}

*Proof.* Any $\theta \in E$ can be written as$\theta = a + b x^{1/p} + c y^{1/p} + d x^{1/p} y^{1/p}$ with$a, b, c, d \in F$. By the Frobenius in characteristic$p$:
$$\theta^p = a^p + b^p (x^{1/p})^p + c^p (y^{1/p})^p + d^p (x^{1/p}y^{1/p})^p = a^p + b^p x + c^p y + d^p xy \in F$$
since $a^p, b^p, c^p, d^p \in F$ (taking$p$th powers of elements of$F = k(x,y)$ gives elements of$F$). This means$\theta$ satisfies$t^p - \theta^p \in F[t]$, a polynomial of degree$p$, so$[F(\theta):F] \leq p$. Since$[E:F] = p^2 > p \geq [F(\theta):F]$, we have$F(\theta) \subsetneq E$ for every$\theta \in E$.$\square$

The failure is precisely due to inseparability. The key step — that $\theta^p \in F$ for every$\theta \in E$ — reflects the fact that the Frobenius maps all of$E$ into the subfield$F$. In a purely inseparable extension of exponent$1$ (i.e.,$\alpha^p \in F$ for all$\alpha \in E$), every element satisfies a polynomial of degree at most$p$ over$F$, regardless of$[E:F]$.

Understanding when the theorem fails motivates the study of $p$-bases: an analogue of vector space bases adapted to inseparable extensions. A$p$-basis of$E$ over$F$ is a set$\{t_i\}$ such that$E = F(t_i^{1/p} : i)$ and this generation is minimal (no proper subset generates$E$ over$F$ by$p$th roots). In the example above,$\{x, y\}$ is a$p$-basis for$E/F$: we have$E = F(x^{1/p}, y^{1/p})$ and neither generator alone suffices.

The lattice-theoretic explanation of the failure is equally illuminating. The intermediate fields between $F$ and$E = F(x^{1/p}, y^{1/p})$ of degree$p$ over$F$ are parametrized by lines in$\mathbb{F}_p^2$: for each$[a:b] \in \mathbb{P}^1(\mathbb{F}_p)$, the field$F(ax^{1/p} + by^{1/p})$ is an intermediate field of degree$p$ over$F$. There are$|\mathbb{P}^1(\mathbb{F}_p)| = p+1$ such intermediate fields. Since$p+1 \geq 3$ for$p \geq 2$, the lattice of intermediate fields is more complex than any simple extension could produce, confirming the non-simplicity.

**Example 1.** Take $p = 2$,$F = \mathbb{F}_2(s, t)$,$E = F(s^{1/2}, t^{1/2})$, so$[E:F] = 4$. The three intermediate fields of degree$2$ over$F$ are$F(s^{1/2})$,$F(t^{1/2})$, and$F((s+t)^{1/2}) = F(s^{1/2}+t^{1/2})$. (In characteristic$2$,$(s+t)^{1/2} = s^{1/2} + t^{1/2}$.) No single element of$E$ can simultaneously lie outside all three proper subfields and generate all of$E$: for any$\theta \in E$,$\theta^2 \in F$, so$F(\theta)$ is one of these degree-$2$ subfields, not all of$E$.

**Example 2.** Let $F = \mathbb{F}_2(t)$ and$E = F(t^{1/2})$. This is purely inseparable of degree$2$, but$E/F$ is simple:$E = F(t^{1/2})$ is generated by the single element$t^{1/2}$. The key distinction from Example 1: here the$p$-basis of$E/F$ has exactly one element$\{t\}$, and a single purely inseparable generator does give a simple extension. The theorem fails only when the$p$-basis has two or more elements.

**Example 3.** Over $p = 3$,$F = \mathbb{F}_3(x, y)$,$E = F(x^{1/3}, y^{1/3})$: now$[E:F] = 9$. Any$\theta \in E$ satisfies$\theta^3 \in F$, so$[F(\theta):F] \leq 3 < 9$. The intermediate fields of degree$3$ over$F$ are parametrized by$\mathbb{P}^1(\mathbb{F}_3)$, which has$|\mathbb{P}^1(\mathbb{F}_3)| = 4$ elements, giving four distinct intermediate fields of degree$3$:$F(x^{1/3})$,$F(y^{1/3})$,$F(x^{1/3}+y^{1/3})$,$F(x^{1/3}+2y^{1/3})$. Again, no single generator can span$E$ over$F$.

**Example 4.** Generalizing, for $F = \mathbb{F}_p(t_1, \ldots, t_r)$ and$E = F(t_1^{1/p}, \ldots, t_r^{1/p})$, the extension has degree$p^r$ and has$|\mathbb{P}^{r-1}(\mathbb{F}_p)| = (p^r - 1)/(p-1)$ intermediate fields of degree$p$ over$F$. For$r \geq 2$, this is at least$p+1 \geq 3$, ruling out simplicity. The theorem fails for all such extensions. The$p$-basis$\{t_1, \ldots, t_r\}$ has$r$ elements, and the "inseparable dimension" of$E/F$ is$r$.

**Example 5.** A mixed example: let $F = \mathbb{Q}$ and consider$E = \mathbb{Q}(\sqrt{2}, 3^{1/2})$, which is the same as$\mathbb{Q}(\sqrt{2}, \sqrt{3})$. This is a separable extension ($\mathrm{char} = 0$), and by the Primitive Element Theorem, it is simple. The element$\sqrt{2} + \sqrt{3}$ is a primitive element. By contrast, over$F = \mathbb{F}_2(x,y)$ the completely analogous extension$E = F(x^{1/2}, y^{1/2})$ is inseparable and not simple. The distinction is characteristic: in characteristic$0$, the "square root" adjunction is separable; in characteristic$2$, it is purely inseparable.

The Primitive Element Theorem thus stands as a clean boundary marker: it holds precisely for finite separable extensions (over any field), and its failure is a precise diagnostic for inseparability. The quantitative statement connecting the two: a finite extension $E/F$ is simple if and only if it has only finitely many intermediate fields, which holds if and only if$E/F$ is separable when$F$ is infinite. Over a finite field, every finite extension is simple regardless of separability, because the multiplicative group argument applies without the separability assumption.
