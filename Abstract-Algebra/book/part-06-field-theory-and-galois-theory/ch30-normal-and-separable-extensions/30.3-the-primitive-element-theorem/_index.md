# 30.3 The Primitive Element Theorem

The Primitive Element Theorem states that every finite separable extension $K/F$ is a simple extension: there exists a single element $\theta \in K$ such that $K = F(\theta)$. Such an element $\theta$ is called a primitive element of the extension. The theorem is at once surprising and elegant — even an extension like $\mathbb{Q}(\sqrt{2}, \sqrt{3})$, which was built by adjoining two separate elements, is in fact generated by a single one. The element $\theta = \sqrt{2} + \sqrt{3}$ does the job: one can recover both $\sqrt{2}$ and $\sqrt{3}$ from $\theta$ using field operations and the minimal polynomial of $\theta$.

The proof proceeds by showing that if $F$ is infinite, one can always find a single linear combination $\theta = \alpha + c\beta$ (for some $c \in F$) that generates $F(\alpha, \beta)$. The key insight is that if $m$ and $n$ are the degrees of the minimal polynomials of $\alpha$ and $\beta$ over $F$, then there are at most $mn$ values of $c$ that would fail to give a generator, and if $F$ is infinite, we can always avoid those values. For finite fields, every finite extension is already simple because the multiplicative group of a finite field is cyclic, so any generator of that cyclic group serves as a primitive element.

The theorem fails for inseparable extensions, and the reason is illuminating. In an inseparable extension, there can be infinitely many intermediate fields between $F$ and $K$ (a situation that cannot occur in a simple extension $F(\theta)$, which has only finitely many intermediate fields — at most one for each monic divisor of $m_\theta$). The Primitive Element Theorem is therefore equivalent to the statement that $K/F$ has only finitely many intermediate fields when $K/F$ is finite and separable. Understanding this equivalence casts the theorem in a new light: simplicity of an extension is not just a formal convenience but a structural property about the finiteness of the intermediate-field lattice, which is precisely what the Galois correspondence will make visible in Chapter 31.
