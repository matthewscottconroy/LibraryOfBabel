# 31.1.3 The Order Theorem: $|\mathrm{Gal}(E/F)| = [E:F]$

The most striking quantitative fact about Galois extensions is that the size of the symmetry group equals the size of the extension as a vector space. For a Galois extension $E/F$, the Order Theorem states$|\mathrm{Gal}(E/F)| = [E:F]$. This is far from obvious: the degree$[E:F]$ is a linear-algebraic invariant, measuring how many$F$-linearly independent directions$E$ contains, while$|\mathrm{Gal}(E/F)|$ counts field-theoretic symmetries. That these two quite differently defined numbers agree is the quantitative heart of Galois theory.

\begin{theorem}[Order Theorem]
Let $E/F$ be a finite Galois extension. Then$|\mathrm{Gal}(E/F)| = [E:F]$.
\end{theorem}

The proof rests on Artin's theorem (detailed in §31.1.4), which operates in the opposite direction. If $H$ is any finite group of automorphisms of a field$E$, then Artin's theorem guarantees$[E : E^H] = |H|$, where$E^H$ is the fixed field of$H$. Now take$H = \mathrm{Gal}(E/F)$: the Galois condition on$E/F$ ensures that$E^H = F$ (the only elements fixed by all automorphisms are those in$F$). Applying Artin's theorem:$[E:F] = [E:E^H] = |H| = |\mathrm{Gal}(E/F)|$.

The Order Theorem immediately reveals the cost of failing to be Galois. If $E/F$ is not Galois — for instance, if it is a non-normal or inseparable extension — then$|\mathrm{Aut}(E/F)| < [E:F]$. For example:
- $\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q}$ has degree$3$ but$|\mathrm{Aut}(\mathbb{Q}(\sqrt[3]{2})/\mathbb{Q})| = 1$ (the extension is separable but not normal).
- $\mathbb{F}_p(t^{1/p})/\mathbb{F}_p(t)$ has degree$p$ but$|\mathrm{Aut}| = 1$ (the extension is normal but not separable).

In each case, the automorphism group is too small to recover the full lattice of intermediate fields via any correspondence.

The equality $|\mathrm{Gal}(E/F)| = [E:F]$ is therefore both a theorem about Galois extensions and a practical diagnostic. To verify that a specific extension$E/F$ is Galois, one strategy is to exhibit$[E:F]$ distinct$F$-automorphisms of$E$, which immediately forces the extension to be Galois and the Galois group to be exactly those automorphisms. Alternatively, showing$E$ is the splitting field of a separable polynomial gives the Galois property without needing to find automorphisms explicitly.

**Example 1.** $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$: degree$2$, Galois group$\cong \mathbb{Z}/2\mathbb{Z}$ of order$2$. We exhibit the two automorphisms:$\mathrm{id}$ and$\sigma: \sqrt{2} \mapsto -\sqrt{2}$. Since$|\mathrm{Gal}| = 2 = [\mathbb{Q}(\sqrt{2}):\mathbb{Q}]$, the Order Theorem is confirmed.

**Example 2.** $\mathbb{Q}(\sqrt[3]{2}, \omega)/\mathbb{Q}$ (splitting field of$x^3 - 2$): degree$6$, Galois group$\cong S_3$ of order$6$. The six automorphisms are determined by the$3$ choices for$\sqrt[3]{2}$ and$2$ choices for$\omega$, giving$|S_3| = 6 = [E:\mathbb{Q}]$, consistent with the Order Theorem.

**Example 3.** $\mathbb{Q}(\zeta_7)/\mathbb{Q}$ where$\zeta_7 = e^{2\pi i/7}$: degree$\phi(7) = 6$, Galois group$\mathrm{Gal}(\mathbb{Q}(\zeta_7)/\mathbb{Q}) \cong (\mathbb{Z}/7\mathbb{Z})^* \cong \mathbb{Z}/6\mathbb{Z}$ of order$6$. The six automorphisms are$\sigma_k: \zeta_7 \mapsto \zeta_7^k$ for$k = 1, 2, 3, 4, 5, 6$. Check:$|G| = 6 = [\mathbb{Q}(\zeta_7):\mathbb{Q}]$.

**Example 4.** $E = \mathbb{Q}(\sqrt{2}, \sqrt{3}, \sqrt{5})$ over$\mathbb{Q}$: degree$8$. The Galois group is$(\mathbb{Z}/2\mathbb{Z})^3$ of order$8$, generated by$\sigma_a: \sqrt{a} \mapsto -\sqrt{a}$ for$a \in \{2,3,5\}$ (each independently). The$8 = 2^3$ automorphisms come from choosing independently whether to negate each of$\sqrt{2}$,$\sqrt{3}$,$\sqrt{5}$. The subgroup lattice of$(\mathbb{Z}/2\mathbb{Z})^3$ has$16$ subgroups (including trivial and full group), corresponding to$16$ intermediate fields.

**Example 5.** $\mathbb{Q}(\sqrt[4]{2}, i)/\mathbb{Q}$ (splitting field of$x^4 - 2$): degree$8$. The Galois group is the dihedral group$D_4$ of order$8$, generated by$\sigma: \sqrt[4]{2} \mapsto i\sqrt[4]{2},\ i \mapsto i$ (a$4$-cycle on the roots) and$\tau: \sqrt[4]{2} \mapsto \sqrt[4]{2},\ i \mapsto -i$ (complex conjugation). One checks$\sigma^4 = 1$,$\tau^2 = 1$,$\tau\sigma\tau^{-1} = \sigma^{-1}$, giving$D_4$. Since$|D_4| = 8 = [\mathbb{Q}(\sqrt[4]{2},i):\mathbb{Q}]$, the Order Theorem holds.

The Order Theorem also calibrates expectations for the Galois correspondence. The fundamental theorem will assert a bijection between subgroups of $\mathrm{Gal}(E/F)$ and intermediate fields$F \subseteq K \subseteq E$. The structure of the lattice of subgroups of$\mathrm{Gal}(E/F)$ is therefore the same as the structure of the lattice of intermediate fields. For a Galois extension of prime degree$p$, the Galois group is$\mathbb{Z}/p\mathbb{Z}$, which has only two subgroups (trivial and full), so the extension has no non-trivial intermediate fields — a clean consequence of the Order Theorem and the Galois correspondence together.

\begin{remark}
The Order Theorem can fail spectacularly for infinite algebraic extensions. The algebraic closure $\bar{\mathbb{Q}}/\mathbb{Q}$ is an infinite Galois extension with Galois group$\mathrm{Gal}(\bar{\mathbb{Q}}/\mathbb{Q})$ a profinite group of uncountable cardinality, while$[\bar{\mathbb{Q}}:\mathbb{Q}]$ is infinite. For finite extensions, however, the order theorem is a complete characterization:$E/F$ is Galois if and only if$|\mathrm{Aut}(E/F)| = [E:F]$, and when this holds,$\mathrm{Aut}(E/F) = \mathrm{Gal}(E/F)$ acts faithfully and transitively on the set of roots of any irreducible polynomial over$F$ that has a root in$E$.
\end{remark}
