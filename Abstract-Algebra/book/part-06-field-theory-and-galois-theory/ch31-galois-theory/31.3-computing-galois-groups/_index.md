# 31.3 Computing Galois Groups

The fundamental theorem is only as useful as one's ability to compute the Galois group of a given extension. This section develops the main tools for doing so. The starting observation is that $\text{Gal}(K/F)$ acts faithfully on the set of roots of any polynomial $f \in F[x]$ that splits completely over $K$, giving an embedding of $\text{Gal}(K/F)$ into the symmetric group $S_n$ where $n = \deg f$. When $f$ is irreducible over $F$, this action is transitive, so the image is a transitive subgroup of $S_n$ — a significant constraint that rules out many candidate groups. The order of $\text{Gal}(K/F)$ must equal $[K:F]$, providing another constraint that narrows the field further.

Two tools refine the permutation-group picture. The discriminant $\Delta(f) = \prod_{i < j}(\alpha_i - \alpha_j)^2$ of a polynomial detects whether the Galois group lies inside the alternating group $A_n$: $\text{Gal}(f/F) \subseteq A_n$ if and only if $\sqrt{\Delta} \in F$. For cubics and quartics, this single test, combined with degree constraints, often determines the group completely. Reduction modulo primes provides a second, independent tool: if $f \in \mathbb{Z}[x]$ reduces to a polynomial $\bar{f} \in \mathbb{F}_p[x]$ with a factorization pattern corresponding to a particular cycle type in $S_n$, then $\text{Gal}(f/\mathbb{Q})$ contains an element of that cycle type. By reducing modulo several primes, one accumulates enough cycle types to pin down the group.

Cyclotomic extensions are a family where explicit computation is always possible. The $n$-th cyclotomic field $\mathbb{Q}(\zeta_n)$, where $\zeta_n = e^{2\pi i/n}$, has Galois group $\text{Gal}(\mathbb{Q}(\zeta_n)/\mathbb{Q}) \cong (\mathbb{Z}/n\mathbb{Z})^*$: the automorphism $\sigma_k$ is defined by $\sigma_k(\zeta_n) = \zeta_n^k$ for any $k$ with $\gcd(k,n) = 1$, and these account for all automorphisms. For $n = p$ prime, $(\mathbb{Z}/p\mathbb{Z})^*$ is cyclic of order $p-1$, yielding a cyclic Galois group. The subgroup structure of these cyclic and abelian groups is completely understood, and the Galois correspondence for cyclotomic fields provides a clean family of examples in which every intermediate field can be described explicitly — connecting Galois theory to the arithmetic of roots of unity and, ultimately, to class field theory.
