# 32.3.3 $(\mathbb{F}_{p^n}^*, \cdot)$ Is Cyclic

The multiplicative group of a finite field is as simple as a group can be: it is cyclic. Specifically, $\mathbb{F}_{p^n}^* = \mathbb{F}_{p^n} \setminus \{0\}$ under multiplication is a cyclic group of order$p^n - 1$. This is a non-trivial fact — there exist finite abelian groups of every order$p^n - 1$ that are not cyclic — and its proof uses an elegant argument exploiting the constraint that a polynomial of degree$d$ over a field has at most$d$ roots.

\begin{theorem}
Let $F$ be a finite field. Then the multiplicative group$F^* = F \setminus \{0\}$ is cyclic.
\end{theorem}

\begin{proof}
Let $|F^*| = m$ (so$m = p^n - 1$ if$|F| = p^n$). Since$F^*$ is a finite abelian group, by the structure theorem for finitely generated abelian groups it decomposes as a direct product of cyclic groups:
$$F^* \cong \mathbb{Z}/d_1\mathbb{Z} \times \mathbb{Z}/d_2\mathbb{Z} \times \cdots \times \mathbb{Z}/d_r\mathbb{Z}$$
with $d_1 \mid d_2 \mid \cdots \mid d_r$ and$d_1 d_2 \cdots d_r = m$. The exponent of$F^*$ — the least common multiple$\mathrm{lcm}(d_1, \ldots, d_r) = d_r$ — has the property that$x^{d_r} = 1$ for every$x \in F^*$. Therefore every element of$F^*$ is a root of$x^{d_r} - 1$. Since$F$ is a field, the polynomial$x^{d_r} - 1$ has at most$d_r$ roots in$F$. Thus$m = |F^*| \leq d_r$. On the other hand,$d_r \leq d_1 d_2 \cdots d_r = m$ (since each$d_i \geq 1$). Therefore$d_r = m$. But$d_r = \mathrm{lcm}(d_1,\ldots,d_r)$ and$d_r = d_1 d_2 \cdots d_r$ only if$r = 1$ (the factors must be pairwise coprime and multiply to their lcm, which forces each factor to be 1 except the last, i.e.,$d_1 = d_2 = \cdots = d_{r-1} = 1$). So$F^* \cong \mathbb{Z}/m\mathbb{Z}$ is cyclic.$\square$
\end{proof}

A generator of $\mathbb{F}_{p^n}^*$ is called a *primitive root* of$\mathbb{F}_{p^n}$. Equivalently,$g$ is a primitive root if every non-zero element of$\mathbb{F}_{p^n}$ is a power of$g$:$\mathbb{F}_{p^n}^* = \{1, g, g^2, \ldots, g^{p^n-2}\}$. The number of primitive roots is$\phi(p^n - 1)$ (the number of generators of the cyclic group$\mathbb{Z}/(p^n-1)\mathbb{Z}$), where$\phi$ is Euler's totient function. Primitive roots are not unique, but they exist and are plentiful.

The cyclicity of $\mathbb{F}_{p^n}^*$ has important structural and computational consequences. Structurally, it means that the multiplicative structure of$\mathbb{F}_{p^n}$ is completely described by a single generator. Computationally, it provides the discrete logarithm structure: every$\alpha \in \mathbb{F}_{p^n}^*$ has a unique exponent$k \in \{0, 1, \ldots, p^n-2\}$ with$\alpha = g^k$, called the *discrete logarithm* of$\alpha$ to base$g$. The difficulty of computing discrete logarithms in finite fields (given$g$ and$\alpha$, find$k$) is the basis of the Diffie–Hellman key exchange and the discrete logarithm problem, foundational to modern public-key cryptography.

\begin{remark}
The same proof applies to any finite subgroup of the multiplicative group of any field: a finite subgroup of $F^*$ is cyclic. In particular, the cyclicity of$\mathbb{F}_{p^n}^*$ is a special case of the general fact that every finite subgroup of the multiplicative group of a field is cyclic. This applies over$\mathbb{Q}$ as well: the finite subgroups of$\mathbb{Q}^*$ are exactly$\{1\}$ and$\{1, -1\}$, both cyclic. Over$\mathbb{C}$, the finite subgroups of$\mathbb{C}^*$ are the groups of$n$th roots of unity$\mu_n \cong \mathbb{Z}/n\mathbb{Z}$, all cyclic.
\end{remark}

**Example 1.** $\mathbb{F}_5^* = \{1, 2, 3, 4\}$ under multiplication mod 5: cyclic of order 4. Primitive roots:$g = 2$ (since$2^1 = 2$,$2^2 = 4$,$2^3 = 3$,$2^4 = 1$, so$2$ generates the whole group); also$g = 3$ (since$3 = 2^3$ has order 4). The elements$1$ (order 1) and$4 = 2^2$ (order 2) are not primitive roots. There are$\phi(4) = 2$ primitive roots.

**Example 2.** $\mathbb{F}_7^* = \{1, 2, 3, 4, 5, 6\}$ under multiplication mod 7: cyclic of order 6. A primitive root:$g = 3$ (since$3^1 = 3$,$3^2 = 2$,$3^3 = 6$,$3^4 = 4$,$3^5 = 5$,$3^6 = 1$ mod 7). The other primitive root among$\{1,\ldots,6\}$ is$g = 5$ (since$5 = 3^5$, which has order$6/\gcd(5,6) = 6$). There are$\phi(6) = 2$ primitive roots.

**Example 3.** $\mathbb{F}_4^* = \{1, \alpha, \alpha+1\}$ (where$\alpha^2 + \alpha + 1 = 0$ over$\mathbb{F}_2$): cyclic of order 3. The primitive roots are$\alpha$ and$\alpha+1$ (both have order 3 since$\alpha^3 = 1$:$\alpha^2 = \alpha+1$,$\alpha^3 = \alpha \cdot \alpha^2 = \alpha(\alpha+1) = \alpha^2+\alpha = (\alpha+1)+\alpha = 1$). There are$\phi(3) = 2$ primitive roots, both non-rational.

**Example 4.** $\mathbb{F}_{8}^*$: cyclic of order$7$ (a prime). Every non-identity element has order 7, so every non-zero element of$\mathbb{F}_8$ except 1 is a primitive root. There are$\phi(7) = 6$ primitive roots (all non-unit elements), consistent with$7$ being prime and$\phi(7) = 6$.

**Example 5.** Finding a primitive root of $\mathbb{F}_{p^n}$ in practice: since there are$\phi(p^n-1)$ primitive roots, one can test random elements. For$\mathbb{F}_{17}^*$ (cyclic of order 16): an element$g$ is a primitive root iff$g^{16/q} \neq 1$ for every prime$q \mid 16$. The only prime factor of$16 = 2^4$ is$2$, so$g$ is a primitive root iff$g^8 \neq 1$ mod 17. Testing$g = 3$:$3^2 = 9$,$3^4 = 81 \equiv 13$,$3^8 \equiv 13^2 = 169 \equiv 16 \equiv -1 \neq 1$ mod 17. So$3$ is a primitive root of$\mathbb{F}_{17}$, and$\mathbb{F}_{17}^* = \langle 3 \rangle$.
