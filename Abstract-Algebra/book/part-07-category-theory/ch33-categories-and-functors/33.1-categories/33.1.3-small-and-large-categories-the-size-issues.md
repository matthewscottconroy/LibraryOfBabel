# 33.1.3 Small and Large Categories; the Size Issues

One of the first surprises in category theory is that the most natural and important categories are not sets in the usual sense. When one forms the category $\mathbf{Grp}$ of all groups, the word "all" is literal: there is a group structure on every non-empty set (at minimum, the trivial group), and since there are proper-class many sets, there are proper-class many groups. The collection$\mathrm{ob}(\mathbf{Grp})$ cannot be a set without contradiction, and yet$\mathbf{Grp}$ is one of the most important categories in mathematics.

The standard vocabulary for navigating this issue begins with three definitions. A category $\mathcal{C}$ is called *small* if both$\mathrm{ob}(\mathcal{C})$ and the collection of all morphisms$\coprod_{A, B} \mathrm{Hom}(A, B)$ are sets. It is called *locally small* if each individual hom-set$\mathrm{Hom}(A, B)$ is a set, even though the collection of all objects may be a proper class. It is called *large* if the objects form only a proper class. The categories$\mathbf{Set}$,$\mathbf{Grp}$,$\mathbf{Ring}$,$R\text{-}\mathbf{Mod}$, and$\mathbf{Top}$ are all large but locally small: for any two groups$G$ and$H$, the set of group homomorphisms$\mathrm{Hom}(G, H)$ is a genuine set (it is a subset of the set of functions from the underlying set of$G$ to the underlying set of$H$).

The size issue is not merely a technical inconvenience to be swept under the rug — it is a genuine foundational concern. The naive analogy with "the set of all sets" makes the problem precise: in unguarded set theory, admitting $\{x : x \notin x\}$ as a set leads to Russell's paradox. Similarly, being cavalier about the category of all categories leads to analogous paradoxes. The standard resolutions draw on additional set-theoretic assumptions, and different foundations lead to different but equivalent approaches.

One resolution, due to Grothendieck, posits the existence of *universes*: a universe $\mathcal{U}$ is a set closed under all set-forming operations — pairing, power sets, unions indexed by sets in$\mathcal{U}$, and so on — and containing all the sets one ordinarily uses. Relative to$\mathcal{U}$, one calls a set *small* if it belongs to$\mathcal{U}$, and *large* otherwise. The category of all$\mathcal{U}$-small sets is then$\mathbf{Set}_{\mathcal{U}}$, which is itself a large category (its collection of objects is not in$\mathcal{U}$, since$\mathcal{U}$ is not an element of itself). The existence of Grothendieck universes is equivalent to the existence of inaccessible cardinals, an axiom beyond the usual ZFC. Another approach works in a two-sorted metatheory, such as the von Neumann–Bernays–Gödel (NBG) system, which has both sets and classes as primitive notions. In NBG, one distinguishes set-sized collections from proper classes, and the category of all sets is a legitimate mathematical object without paradox.

The practical consequence is that most working category theory is carried out under implicit size assumptions. Most categories one encounters in algebra and topology are large but locally small, and the assumption of local smallness is what makes the Yoneda lemma work — it ensures that $\mathrm{Hom}(A, B)$ is a genuine set, so that natural transformations form sets. The truly small categories are often combinatorial: any finite category, any poset viewed as a category, any group or monoid viewed as a one-object category. Understanding where size hypotheses enter proofs is part of learning to work carefully with category theory at an advanced level.

\begin{definition}
A category $\mathcal{C}$ is \emph{small} if$\mathrm{ob}(\mathcal{C})$ is a set and$\mathrm{Hom}_{\mathcal{C}}(A, B)$ is a set for all$A, B$. It is \emph{locally small} if$\mathrm{Hom}_{\mathcal{C}}(A, B)$ is a set for all$A, B$ but$\mathrm{ob}(\mathcal{C})$ may be a proper class.
\end{definition}

**Example 1.** The category $\mathbf{2}$ with objects$\{0, 1\}$ and a single non-identity morphism$0 \to 1$ is small: it has finitely many objects and morphisms. More generally, any finite category — one with finitely many objects and morphisms — is small. Finite categories arise naturally as the index shapes for specific limit or colimit constructions.

**Example 2.** Any poset $(P, \leq)$ viewed as a category is small if and only if$P$ is a set (which it always is, in usual set theory). So the poset$(\mathbb{N}, \leq)$ of natural numbers with the usual ordering is a small category: countably many objects, with at most one morphism between any two. The poset$(\mathbb{R}, \leq)$ is also a small category. These small poset-categories are among the most important index categories for limits and colimits.

**Example 3.** Any group $G$ viewed as a one-object category$\mathbf{B}G$ is small if and only if$G$ is a set-sized group (which every group is, in standard set theory). The category$\mathbf{B}\mathbb{Z}$ associated to the integers under addition is a small category with one object and a countable morphism set.

**Example 4.** The category $\mathbf{Set}$ of all sets is large (its objects form a proper class) but locally small: for any two sets$A$ and$B$, the set of all functions$A \to B$ is a legitimate set (it injects into the power set of$A \times B$). The category$\mathbf{Grp}$ is similarly large and locally small. These are the categories that appear in practice most often, and local smallness is the hypothesis under which the Yoneda embedding (Section 34.2.4) functions.

**Example 5.** The functor category $[\mathcal{C}, \mathcal{D}]$ (Section 34.1.3) is small whenever$\mathcal{C}$ is small and$\mathcal{D}$ is locally small. The smallness of$\mathcal{C}$ ensures that a natural transformation (a family of morphisms indexed by$\mathrm{ob}(\mathcal{C})$) is a set-sized object. If$\mathcal{C}$ is merely locally small, the functor category may fail to be locally small, which is one of the technical reasons why size hypotheses appear in theorems about functor categories and adjoint functors.

The interplay between size and category theory reappears throughout: in the adjoint functor theorems (Section 35.2.4), in the theory of locally presentable categories, and in the construction of the homotopy category. A working category theorist must be able to identify when a size hypothesis is genuinely needed and when it is merely a convention, and developing this sensitivity is part of the subject.
