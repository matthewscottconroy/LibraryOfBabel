# 33.2.1 Monomorphisms (Generalized Injections)

The notion of an injective function — one where distinct inputs yield distinct outputs — is defined in terms of elements. One says $f \colon A \to B$ is injective if$f(a_{1}) = f(a_{2})$ implies$a_{1} = a_{2}$. But category theory is meant to describe structure entirely through morphisms, without reference to elements. The question is: how does one capture injectivity using only the arrows of a category?

The resolution is the notion of a *monomorphism*, which tests injectivity using the left-cancellation property. The key observation is that for a function $f \colon A \to B$, injectivity is equivalent to: for any set$C$ and any two functions$g, h \colon C \to A$, if$f \circ g = f \circ h$ as functions$C \to B$, then$g = h$. The proof is elementary: if$f(g(c)) = f(h(c))$ for all$c \in C$ and$f$ is injective, then$g(c) = h(c)$ for all$c$, so$g = h$. Conversely, to show the cancellation property implies injectivity, take$C = \{*\}$ and let$g, h$ be the constant functions picking two preimages. This cancellation property makes perfect sense in any category.

\begin{definition}
A morphism $f \colon A \to B$ in a category$\mathcal{C}$ is a \emph{monomorphism} (or is \emph{monic}) if it is left-cancellable: for any object$C$ and any two morphisms$g, h \colon C \to A$, the equation$f \circ g = f \circ h$ implies$g = h$.
\end{definition}

Monomorphisms in $\mathbf{Set}$ are exactly the injective functions, as the argument above shows. In$\mathbf{Grp}$, the monomorphisms are precisely the injective group homomorphisms: if$f \colon G \to H$ is an injective homomorphism and$f \circ g = f \circ h$ for homomorphisms$g, h \colon K \to G$, then for any$k \in K$,$f(g(k)) = f(h(k))$, and injectivity of$f$ forces$g(k) = h(k)$. The same reasoning applies in$\mathbf{Ring}$,$R\text{-}\mathbf{Mod}$, and$\mathbf{Top}$ (where monomorphisms are injective continuous maps).

The value of the categorical formulation is that it makes sense in every category, including those where "element" has no meaning. In a poset-as-category, every morphism is a monomorphism vacuously (there is at most one morphism from any object to another, so the left-cancellation condition holds trivially). In the category of matrices over a field, a linear map $f \colon V \to W$ is a monomorphism if and only if it is injective — the categorical notion coincides with the linear-algebraic one.

\begin{proposition}
In any category $\mathcal{C}$:
\begin{enumerate}
  \item The identity morphism $\mathrm{id}_{A}$ is a monomorphism for every object$A$.
  \item If $f \colon A \to B$ and$g \colon B \to C$ are monomorphisms, then$g \circ f$ is a monomorphism.
  \item If $g \circ f$ is a monomorphism, then$f$ is a monomorphism.
\end{enumerate}
\end{proposition}

\begin{proof}
(1) is immediate from the unit law. For (2): if $(g \circ f) \circ h = (g \circ f) \circ k$, then$g \circ (f \circ h) = g \circ (f \circ k)$, and monic$g$ gives$f \circ h = f \circ k$, then monic$f$ gives$h = k$. For (3): if$f \circ h = f \circ k$, then$g \circ (f \circ h) = g \circ (f \circ k)$, i.e.,$(g \circ f) \circ h = (g \circ f) \circ k$, and monic$g \circ f$ gives$h = k$.
\end{proof}

**Example 1.** In $\mathbf{Set}$, the inclusion$\iota \colon \{1, 2\} \hookrightarrow \{1, 2, 3\}$ is a monomorphism: if two functions$g, h \colon C \to \{1, 2\}$ satisfy$\iota \circ g = \iota \circ h$, then$g(c) = h(c)$ for all$c$ (since$\iota$ is injective). The function$f \colon \{1, 2, 3\} \to \{1, 2, 3\}$ sending$1 \mapsto 1$,$2 \mapsto 2$,$3 \mapsto 2$ is not a monomorphism: take$g \colon \{*\} \to \{1, 2, 3\}$ with$g(*) = 2$ and$h(*)= 3$; then$f \circ g = f \circ h$ (both equal the constant function to$2$) but$g \neq h$.

**Example 2.** In $\mathbf{Ab}$, the morphism$\cdot 2 \colon \mathbb{Z} \to \mathbb{Z}$ sending$n \mapsto 2n$ is a monomorphism: if$2g(x) = 2h(x)$ for all$x$ (where$g, h \colon A \to \mathbb{Z}$ are homomorphisms), then$g(x) = h(x)$ for all$x$, since$\mathbb{Z}$ is torsion-free. The map$\pi \colon \mathbb{Z} \to \mathbb{Z}/2\mathbb{Z}$ is not monic: the two maps$g = 0$ and$h = \mathrm{id}$ from$\mathbb{Z}/2\mathbb{Z}$ to$\mathbb{Z}$ would both give zero after composing with$\pi$ — but wait, there are only two group maps$\mathbb{Z}/2\mathbb{Z} \to \mathbb{Z}$ and both are zero (since$\mathbb{Z}$ is torsion-free), so the failure of$\pi$ to be monic is witnessed differently: take$g = 0$ and$h = \cdot 1$ from$\mathbb{Z}$ to$\mathbb{Z}$; then$\pi \circ (2g) = \pi \circ (2h)$ does not immediately help. Instead: take$g = \mathrm{id}_{\mathbb{Z}}$ and$h = 0 \colon \mathbb{Z} \to \mathbb{Z}$; then$\pi \circ g \neq \pi \circ h$ but we want the other direction. The correct witness is:$\pi \circ \mathrm{id} = \pi \circ (n \mapsto n + 2)$ as maps from$\mathbb{Z}$? No. The simplest witness that$\pi$ is not monic is: take$g, h \colon \mathbb{Z} \to \mathbb{Z}$ with$g = \mathrm{id}$ and$h = (n \mapsto n - 2)$; then$\pi \circ g = \pi \circ h$ (since$\pi(n) = \pi(n - 2)$ for all$n$), but$g \neq h$.

**Example 3.** In the category of Hausdorff topological spaces, any topological embedding (homeomorphism onto its image) is a monomorphism. More precisely, any injective continuous map is monic in $\mathbf{Top}$ — the argument is the same as in$\mathbf{Set}$ since injectivity is a set-level property.

**Example 4.** In $R\text{-}\mathbf{Mod}$, the monomorphisms are precisely the injective module homomorphisms. The kernel of$f \colon M \to N$ is zero if and only if$f$ is a monomorphism: if$f$ has trivial kernel and$f \circ g = f \circ h$, then$f \circ (g - h) = 0$, so$\mathrm{im}(g - h) \subseteq \ker(f) = 0$, giving$g = h$. In an abelian category more generally, a morphism is monic if and only if its kernel is$0$.

**Example 5.** In any category, a *split monomorphism* is a morphism $f \colon A \to B$ that has a left inverse: a morphism$r \colon B \to A$ with$r \circ f = \mathrm{id}_{A}$. Every split monomorphism is a monomorphism: if$f \circ g = f \circ h$, then$r \circ (f \circ g) = r \circ (f \circ h)$, giving$g = h$. The converse fails in general: the inclusion$\iota \colon \mathbb{Z} \hookrightarrow \mathbb{Q}$ in$\mathbf{Ab}$ is a monomorphism but not a split monomorphism (there is no group homomorphism$\mathbb{Q} \to \mathbb{Z}$ that is a left inverse to$\iota$, since$\mathbb{Q}$ is divisible and$\mathbb{Z}$ is not).

The monomorphism condition captures exactly what one needs for diagram-chasing involving injective maps, and as the next section shows, the dual notion — epimorphisms — can exhibit genuinely unexpected behavior that separates categorical from set-theoretic thinking.
