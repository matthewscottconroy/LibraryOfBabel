# 34.2 The Yoneda Lemma

The Yoneda lemma is a theorem about representable functors — functors of the form $\text{Hom}(A, -)$ for a fixed object $A$. These are the most basic functors a category produces from within itself: $\text{Hom}(A, -)$ sends each object $B$ to the set of morphisms $A \to B$, and sends each morphism $f: B \to C$ to post-composition $f \circ -: \text{Hom}(A, B) \to \text{Hom}(A, C)$. A functor $F: \mathcal{C} \to \mathbf{Set}$ is called *representable* if it is naturally isomorphic to $\text{Hom}(A, -)$ for some object $A$. Representability is an extremely strong condition that, when it holds, gives a complete description of $F$ in terms of a single universal object.

The Yoneda lemma asserts: for any locally small category $\mathcal{C}$, any object $A$, and any functor $F: \mathcal{C} \to \mathbf{Set}$, there is a natural bijection $\text{Nat}(\text{Hom}(A, -), F) \cong F(A)$. The proof is a single forced calculation: given a natural transformation $\alpha: \text{Hom}(A, -) \Rightarrow F$, its component at $A$ sends $\text{id}_A \in \text{Hom}(A, A)$ to some element $\alpha_A(\text{id}_A) \in F(A)$. Naturality forces the value of $\alpha_B$ on any morphism $f: A \to B$ to equal $F(f)(\alpha_A(\text{id}_A))$. Thus $\alpha$ is completely determined by the single element $\alpha_A(\text{id}_A) \in F(A)$, and every element of $F(A)$ arises this way. The bijection is as simple as it appears, and yet it contains the entire content of the lemma.

The philosophical import is striking. An object $A$ is, categorically speaking, the same as the functor it represents. This is made precise by the *Yoneda embedding* $y: \mathcal{C} \to [\mathcal{C}^{\text{op}}, \mathbf{Set}]$, which sends each object $A$ to the presheaf $\text{Hom}(-, A)$ and each morphism $f: A \to B$ to the natural transformation given by post-composition with $f$. The Yoneda lemma implies that this embedding is fully faithful: the morphisms from $y(A)$ to $y(B)$ in the presheaf category are in natural bijection with the morphisms from $A$ to $B$ in $\mathcal{C}$. In particular, $A \cong B$ in $\mathcal{C}$ if and only if $\text{Hom}(-, A) \cong \text{Hom}(-, B)$ as functors — objects are determined by their maps.

The applications range from the abstract to the immediately computable. Universal properties — products, coproducts, kernels, free objects — can all be expressed as representability conditions, and the Yoneda lemma guarantees their uniqueness up to unique isomorphism. Grothendieck's *functor of points* approach to algebraic geometry, where a scheme $X$ is identified with the functor $R \mapsto X(R) = \text{Hom}(\text{Spec}(R), X)$, rests entirely on the Yoneda philosophy. Within module theory, the Yoneda lemma applied to $\text{Hom}_R(M, -)$ characterizes projective modules and underpins the theory of injective hulls and projective covers. The lemma is not merely a foundational curiosity — it is a computational tool of the first order.
