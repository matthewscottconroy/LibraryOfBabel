# 41.4.3 Collapse Arguments; Sparse Page Computations

The most common technique for concluding that a spectral sequence computation is complete is to argue that the spectral sequence *collapses* at some page $E_r$ — that is, all differentials$d_s = 0$ for$s \geq r$. When this happens,$E_r = E_\infty$, and the computation reduces to understanding a single page. The primary method for establishing collapse is a *sparsity argument*: one identifies regions of the page where no non-zero differential can exist, and uses this to conclude that all differentials must vanish globally.

The sparsity argument works as follows. If $E_r^{p,q} = 0$ for$q$ in some range, then the differentials$d_r: E_r^{p,q} \to E_r^{p-r, q+r-1}$ are automatically zero whenever either the source or target is in the vanishing region. If the$E_r$ page is concentrated on two horizontal lines$q = 0$ and$q = m$, for instance, then$d_r = 0$ for all$r < m$ (no differential can reach from one line to the other in fewer than$m$ steps) and also for all$r > m+1$ (the differentials are too long and would overshoot). At$r = m+1$, the only potentially non-zero differentials go from$E_{m+1}^{p, 0}$ to$E_{m+1}^{p - (m+1), m}$, and one checks each such differential separately. If these also vanish (by degree, rank, or comparison arguments), the spectral sequence collapses at$E_2$.

The rank or dimension argument is equally important. If the spectral sequence converges to a known group $H^*$ and the sum of ranks of$E_2^{p,q}$ along each anti-diagonal$p + q = n$ already equals the rank of$H^n$, then every differential must be zero (since a non-zero differential would reduce the rank of a later page below the rank of the target). This argument is available whenever one has independent information about the target — from topology (knowing the Betti numbers of a space), from representation theory (knowing the dimension of a representation space), or from an independent computation of$H^*$ by other means. When it applies, it gives a clean and complete proof of collapse without computing any differential directly.

A third strategy uses *naturality* of the spectral sequence. If a map of group extensions $f: (1 \to N \to G \to Q \to 1) \to (1 \to N' \to G' \to Q' \to 1)$ induces an isomorphism on$E_2$ pages, then it induces isomorphisms on all subsequent pages and on$H^*$. More subtly, if one knows that some particular$d_r$ must commute with a certain endomorphism of the spectral sequence, and that endomorphism acts as multiplication by a unit on both source and target, then$d_r$ must be zero. This occurs, for instance, when the spectral sequence has a$\mathbb{Z}/2$-symmetry that acts as$-1$ on the relevant groups.

\begin{example}
**Example 1.** Sparsity collapse for a two-row $E_2$ page. Suppose$E_2^{p,q} = 0$ for$q \neq 0, 2$ (the page lives on rows 0 and 2). Then$d_2: E_2^{p,2} \to E_2^{p+2, 1} = 0$ (row 1 is empty), and$d_2: E_2^{p,0} \to E_2^{p+2, -1} = 0$ (negative rows are zero). So$d_2 = 0$ everywhere. Similarly$d_3: E_3^{p,2} \to E_3^{p+3, 0}$ is the only potentially non-trivial differential. If row 0 and row 2 have known groups, one checks$d_3$ explicitly. If$d_3 = 0$ as well (e.g., by the rank argument), then$E_4 = E_\infty = E_2$.
\end{example}

\begin{example}
**Example 2.** Rank collapse for the Hopf fibration. The Serre spectral sequence for $S^1 \to S^3 \to S^2$ (Hopf fibration) has$E_2^{p,q} = H^p(S^2) \otimes H^q(S^1)$. The non-zero groups are at$(0,0), (0,1), (2,0), (2,1)$, all equal to$\mathbb{Z}$. The target is$H^*(S^3) = \mathbb{Z}$ in degrees 0 and 3 only. Along the anti-diagonal$p + q = 2$:$\sum \mathrm{rank}(E_2^{p,q}) = \mathrm{rank}(E_2^{0,2}) + \mathrm{rank}(E_2^{2,0}) = 0 + 1 = 1$, but$\mathrm{rank}(H^2(S^3)) = 0$. So something must kill$E_2^{2,0} = \mathbb{Z}$. The only possible differential is$d_2: E_2^{0,1} \to E_2^{2,0}$, a map$\mathbb{Z} \to \mathbb{Z}$. For rank to work out,$d_2$ must be an isomorphism. This forces$d_2 = \pm 1$ (multiplication by$\pm 1$), the spectral sequence collapses at$E_3$, and the rank argument is self-consistent.
\end{example}

\begin{example}
**Example 3.** Sparse $E_2$ page for the LHS spectral sequence of$1 \to \mathbb{Z} \to \mathbb{Z}^2 \to \mathbb{Z} \to 1$ (with$M = \mathbb{Z}$). Here$N = \mathbb{Z}$,$G = \mathbb{Z}^2$,$Q = \mathbb{Z}$. Since$\mathbb{Z}$ has cohomological dimension 1,$H^q(\mathbb{Z}, \mathbb{Z}) = 0$ for$q \geq 2$. So the$E_2$ page is non-zero only in rows$q = 0$ and$q = 1$. The only possibly non-trivial differential is$d_2: E_2^{0,1} \to E_2^{2,0}$. Comparing with the known result$H^*(\mathbb{Z}^2, \mathbb{Z}) = \mathbb{Z}$ in degrees 0 and 2 (the cohomology of the torus$T^2$), the rank argument forces$d_2 = 0$ (since$\mathrm{rank}(H^2(\mathbb{Z}^2, \mathbb{Z})) = 1$ and$\sum_{p+q=2} \mathrm{rank}(E_2^{p,q}) = \mathrm{rank}(E_2^{0,2}) + \mathrm{rank}(E_2^{1,1}) + \mathrm{rank}(E_2^{2,0}) = 0 + 1 + 1 = 2 \neq 1$). Wait: in this case$d_2$ must be non-trivial to kill one generator, giving$E_3^{2,0} = \mathbb{Z}$ and$E_3^{1,1} = 0$, consistent with$H^2 = \mathbb{Z}$.
\end{example}

\begin{example}
**Example 4.** Collapse by multiplicative structure. For the Serre spectral sequence of the path-loop fibration $\Omega S^n \to PS^n \to S^n$ (with$PS^n$ contractible), one has$H^*(PS^n; \mathbb{Z}) = \mathbb{Z}$ concentrated in degree 0. The spectral sequence must converge to$\mathbb{Z}$ in degree 0 and 0 elsewhere. The$E_2$ page is$H^*(S^n) \otimes H^*(\Omega S^n)$. Starting from the known answer, the differentials are forced: a generator$\iota \in H^n(S^n)$ must transgress to a class in$H^{n-1}(\Omega S^n)$, and the multiplicative structure of the spectral sequence determines the rest. For$n$ even, the spectral sequence has a non-trivial extension pattern; for$n$ odd, it collapses (after one differential) to give$H^*(\Omega S^n; \mathbb{Z}) = \mathbb{Z}[x]$ with$|x| = n-1$.
\end{example}
\par
\begin{remark}
Collapse arguments and sparsity are the computational backbone of spectral sequence theory in practice. The key insight is that one does not need to compute differentials directly — often it suffices to show that they must be zero for structural reasons. The most powerful such reasons are: (1) the target group of the differential is zero (sparsity), (2) the rank of the $E_r$ page already matches the rank of the target (rank argument), (3) the differential must commute with an endomorphism that acts invertibly (naturality/symmetry), and (4) the differential must be compatible with a ring or module structure that forces it to be zero (multiplicative structure). Mastery of these techniques, combined with patience in tracking the filtration, is what makes spectral sequences into an effective computational tool rather than a theoretical abstraction.
\end{remark}
