# 43.3.3 Number of Irreducibles = Number of Conjugacy Classes

One of the most beautiful results in the theory is the identification of two quantities that seem, on their face, to have nothing to do with each other: the number of irreducible representations of $G$ over$\mathbb{C}$ equals the number of conjugacy classes of$G$. The number of irreducibles is an algebraic invariant — it depends on the representation theory of$\mathbb{C}[G]$ — while the number of conjugacy classes is a purely group-theoretic invariant. Their equality is a deep structural coincidence that the Artin–Wedderburn framework makes transparent.

\begin{theorem}
The number of isomorphism classes of irreducible $\mathbb{C}$-representations of$G$ equals the number of conjugacy classes of$G$.
\end{theorem}

\begin{proof}
The proof passes through the center of $\mathbb{C}[G]$. We compute$\dim_{\mathbb{C}} Z(\mathbb{C}[G])$ in two ways.

\textbf{First way:} A natural $\mathbb{C}$-basis for$Z(\mathbb{C}[G])$ consists of the \emph{conjugacy class sums}: for each conjugacy class$C \subseteq G$, the element$\hat{C} = \sum_{g \in C} g$ lies in$Z(\mathbb{C}[G])$ because for any$h \in G$:
$$h \hat{C} h^{-1} = \sum_{g \in C} hgh^{-1} = \sum_{g' \in C} g' = \hat{C},$$
since conjugation by $h$ permutes elements within$C$. Conversely, any central element$z = \sum_g a_g g$ satisfies$a_{hgh^{-1}} = a_g$ for all$h$ (by$hz = zh$), so the coefficients are constant on conjugacy classes, and$z$ is a linear combination of class sums. Thus$\{\hat{C} : C \text{ conjugacy class}\}$ is a basis for$Z(\mathbb{C}[G])$, and$\dim_{\mathbb{C}} Z(\mathbb{C}[G]) =$ (number of conjugacy classes).

\textbf{Second way:} Under the Artin–Wedderburn isomorphism $\mathbb{C}[G] \cong \prod_{i=1}^r M_{n_i}(\mathbb{C})$, the center maps isomorphically to the product of the centers:
$$Z\!\left(\prod_i M_{n_i}(\mathbb{C})\right) \cong \prod_i Z(M_{n_i}(\mathbb{C})) \cong \prod_i \mathbb{C} \cong \mathbb{C}^r,$$
which has dimension $r$ — the number of irreducibles. Equating:$r =$ number of conjugacy classes.
\end{proof}

This connects to a deeper principle. The space of class functions $\mathrm{Cl}(G, \mathbb{C})$ — functions$f: G \to \mathbb{C}$ constant on conjugacy classes — has two natural bases:
- The \emph{indicator functions} $\delta_C$ for each conjugacy class$C$ (value 1 on$C$, 0 elsewhere);
- The \emph{irreducible characters} $\chi_1, \ldots, \chi_r$.

The theorem says both bases have the same size $r$. Character orthogonality (Chapter 44) then shows the irreducible characters form an \emph{orthonormal} basis for$\mathrm{Cl}(G, \mathbb{C})$ with respect to the inner product$\langle f_1, f_2 \rangle = \frac{1}{|G|}\sum_g f_1(g)\overline{f_2(g)}$.

\begin{example}
For $G = S_3$: three conjugacy classes ($\{e\}$, transpositions, 3-cycles) and three irreducible representations (trivial, sign, standard). The character table is a$3 \times 3$ matrix.
\end{example}

\begin{example}
For $G = S_4$: five conjugacy classes ($\{e\}$,$(12)$-type,$(123)$-type,$(12)(34)$-type,$(1234)$-type) and five irreducible representations. The character table is a$5 \times 5$ matrix.
\end{example}

\begin{example}
For $G = \mathbb{Z}/n\mathbb{Z}$: the group is abelian, so every element is its own conjugacy class, giving$n$ conjugacy classes. Indeed, there are$n$ irreducible representations (all 1-dimensional, given by$\chi_k(\sigma^j) = \zeta^{jk}$), confirming the count.
\end{example}

\begin{example}
For $G = D_4 = \langle r, s \mid r^4 = s^2 = e, \, srs^{-1} = r^{-1} \rangle$: the conjugacy classes are$\{e\}$,$\{r^2\}$,$\{r, r^3\}$,$\{s, r^2s\}$,$\{rs, r^3s\}$ — five in total. Hence$D_4$ has exactly five irreducible representations, with dimensions satisfying$\sum n_i^2 = 8$ and$r = 5$: the unique solution is$(1,1,1,1,2)$. The center$Z(D_4) = \{e, r^2\}$, and indeed$|G|/|Z(G)| = 8/2 = 4 = 2^2$ forces$n_{\max} \leq 2$ from the divisibility constraint$n_i \mid [G:Z(G)]$.
\end{example}

\begin{remark}
The result $r =$ number of conjugacy classes does not have a simple bijective proof at the level of individual representations and classes. There is no canonical bijection between irreducible representations and conjugacy classes (unlike, say, the bijection between characters of an abelian group and its elements via Pontryagin duality). The equality is an equality of cardinalities, and it is best understood as an equality of dimensions of two vector spaces —$\mathrm{Cl}(G, \mathbb{C})$ and the center of$\mathbb{C}[G]$ — that happen to be equal for a structural reason.
\end{remark}

The equality $r = k(G)$ has many important corollaries. One is that$G$ is abelian if and only if all irreducible representations are 1-dimensional — since$G$ abelian means every element is its own conjugacy class, so$k(G) = |G|$, and then$\sum_i n_i^2 = |G| = k(G) = r$ forces all$n_i = 1$. Conversely, if all$n_i = 1$ then$k(G) = r = |G|$, meaning every element is its own conjugacy class, i.e.,$G$ is abelian.

\begin{proposition}
$G$ is abelian if and only if all irreducible representations of$G$ over$\mathbb{C}$ are 1-dimensional.
\end{proposition}

This can also be seen via Schur's lemma: over an algebraically closed field, an irreducible representation of an abelian group must be 1-dimensional, because every group element $g$ commutes with all other elements, so$\rho(g)$ commutes with$\rho(h)$ for all$h$, making$\rho(g)$ a$G$-equivariant endomorphism of$V$, hence a scalar by Schur's lemma.

\begin{example}
For $G = (\mathbb{Z}/2\mathbb{Z})^n$:$|G| = 2^n$ and$k(G) = 2^n$ (all elements central), so there are$2^n$ irreducibles all of dimension 1. They are the$2^n$ group homomorphisms$G \to \{+1,-1\}$, one for each subset of the$n$ generators (send the generators in the subset to$-1$ and the others to$+1$). The group algebra decomposes as$\mathbb{C}[(\mathbb{Z}/2\mathbb{Z})^n] \cong \mathbb{C}^{2^n}$.
\end{example}
\par
The theorem $r = k(G)$ is not merely combinatorial; it has implications for the structure of$G$ itself. For instance, a group$G$ for which$k(G)$ is large (close to$|G|$) must be "close to abelian" in the sense that most elements are in small conjugacy classes. The precise measure of this is given by the commuting probability$\Pr_{g,h \in G}[gh = hg] = k(G)/|G|$, which by the above equals$r/|G| = (\sum_i 1)/(\sum_i n_i^2)$. For an abelian group this is 1; for$S_3$ it is$3/6 = 1/2$; for$S_n$ with large$n$ it tends to 0.
