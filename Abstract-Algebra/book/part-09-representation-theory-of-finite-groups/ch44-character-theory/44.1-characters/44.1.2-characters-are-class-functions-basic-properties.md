# 44.1.2 Characters Are Class Functions; Basic Properties

Having defined the character as a function $\chi_V: G \to k$, the first question is: what special properties does it satisfy? The answer organizes the study of character theory: characters are class functions, and their values at specific types of group elements satisfy precise constraints.

\begin{definition}
A function $f: G \to k$ is a \emph{class function} if$f(hgh^{-1}) = f(g)$ for all$g, h \in G$ — equivalently,$f$ is constant on each conjugacy class of$G$.
\end{definition}

\begin{proposition}
For any representation $(V, \rho)$, the character$\chi_V$ is a class function.
\end{proposition}

\begin{proof}
$\chi_V(hgh^{-1}) = \mathrm{tr}(\rho(h)\rho(g)\rho(h)^{-1}) = \mathrm{tr}(\rho(g)) = \chi_V(g)$, using the cyclicity of trace.
\end{proof}

Consequently, the character is determined by its values on conjugacy class representatives, which is already a significant reduction. For a group with $r$ conjugacy classes, the character is specified by just$r$ numbers rather than$|G|$ numbers.

Several further basic properties follow directly from the definitions:

\begin{proposition}[Basic properties of characters]
Let $(V, \rho)$ be a representation of$G$ over$\mathbb{C}$. Then:
\begin{enumerate}
\item $\chi_V(e) = \dim V$ (the character at the identity gives the dimension).
\item $\chi_V(g^{-1}) = \overline{\chi_V(g)}$ for all$g \in G$.
\item $|\chi_V(g)| \leq \dim V$ for all$g \in G$.
\item $\chi_V(g)$ is a sum of$\dim V$ roots of unity, hence an algebraic integer.
\item If $g$ has order$m$, then$\chi_V(g)$ is a sum of$m$th roots of unity.
\end{enumerate}
\end{proposition}

\begin{proof}
(1) $\chi_V(e) = \mathrm{tr}(\rho(e)) = \mathrm{tr}(\mathrm{Id}_V) = \dim V$.

(2) Since $G$ is finite, every$g \in G$ has finite order, so$\rho(g)^m = \mathrm{Id}$ for some$m \geq 1$. Thus$\rho(g)$ is diagonalizable (over$\mathbb{C}$) with eigenvalues$\lambda_1, \ldots, \lambda_n$ that are$m$th roots of unity, all of modulus 1. The eigenvalues of$\rho(g)^{-1} = \rho(g^{-1})$ are$\lambda_1^{-1}, \ldots, \lambda_n^{-1}$. Since$|\lambda_i| = 1$, we have$\lambda_i^{-1} = \overline{\lambda_i}$. Thus$\chi_V(g^{-1}) = \sum \lambda_i^{-1} = \sum \overline{\lambda_i} = \overline{\sum \lambda_i} = \overline{\chi_V(g)}$.

(3) $|\chi_V(g)| = |\sum \lambda_i| \leq \sum |\lambda_i| = n = \dim V$.

(4) and (5) follow from the eigenvalue analysis.
\end{proof}

\begin{example}
For $S_3$ with standard representation (dim 2):$\chi_{\mathrm{std}}(e) = 2$,$\chi_{\mathrm{std}}((12)) = 0$ (a sum of two square roots of unity:$1$ and$-1$),$\chi_{\mathrm{std}}((123)) = -1$ (a sum of two cube roots of unity:$\zeta_3$ and$\zeta_3^2 = \overline{\zeta_3}$, summing to$-1$). One checks$|\chi_{\mathrm{std}}(g)| \leq 2$ in all cases.
\end{example}

\begin{example}
For $G = Q_8$ with the 2-dimensional representation$\rho: Q_8 \to GL_2(\mathbb{C})$ given by$\rho(i) = \begin{pmatrix}i & 0 \\ 0 & -i\end{pmatrix}$,$\rho(j) = \begin{pmatrix}0 & -1 \\ 1 & 0\end{pmatrix}$,$\rho(k) = \begin{pmatrix}0 & -i \\ -i & 0\end{pmatrix}$: one computes$\chi(1) = 2$,$\chi(-1) = \mathrm{tr}\begin{pmatrix}-1&0\\0&-1\end{pmatrix} = -2$,$\chi(i) = \mathrm{tr}\begin{pmatrix}i&0\\0&-i\end{pmatrix} = 0$, and by symmetry$\chi(j) = \chi(k) = 0$.
\end{example}

These properties together constrain character values quite sharply. The value $\chi_V(e) = \dim V$ must be a positive integer; the values at other group elements are sums of roots of unity. The conjugation symmetry$\chi_V(g^{-1}) = \overline{\chi_V(g)}$ means that for real characters (those taking real values everywhere),$\chi_V$ is symmetric under the inversion map$g \mapsto g^{-1}$. When$g$ is conjugate to its own inverse (which occurs, for example, for all elements of$S_n$ since permutations are conjugate to their inverses), the character value must be real.

\begin{remark}
The space of class functions $\mathrm{Cl}(G, \mathbb{C})$ has dimension equal to the number of conjugacy classes of$G$. The characters of all representations span this space (by first orthogonality), and the irreducible characters form an orthonormal basis. The basic properties above constrain any candidate for an irreducible character: it must be a class function whose value at$e$ is a positive integer, whose values are sums of roots of unity, and whose norm$\langle \chi, \chi \rangle = 1$.
\end{remark}

\begin{example}
For $G = A_4$: the element$(12)(34)$ is conjugate to$(13)(24)$ and$(14)(23)$, so these three form a conjugacy class. For any representation$\rho$,$\chi(\{(12)(34)\}) = \chi(\{(13)(24)\}) = \chi(\{(14)(23)\})$. Moreover,$(12)(34)$ has order 2, so eigenvalues of$\rho((12)(34))$ are$\pm 1$, and$\chi((12)(34)) \in \mathbb{Z}$ is an integer. For the 3-dimensional irreducible, one computes$\chi_4((12)(34)) = -1$: the double transposition sends$(e_1,e_2,e_3) \mapsto (e_2,e_1,e_4,e_3)$ in the permutation representation, and after removing the trivial direction, the trace is$-1$.
\end{example}

The property $\chi_V(g^{-1}) = \overline{\chi_V(g)}$ has a useful consequence for real-valued characters. If every element of$G$ is conjugate to its inverse (which holds for all symmetric groups, since a permutation$\sigma$ and$\sigma^{-1}$ have the same cycle type), then$\chi_V(g^{-1}) = \chi_V(g)$ (by the class function property), so$\chi_V(g) = \overline{\chi_V(g)}$, i.e., all character values are real. For$S_n$, this gives the well-known fact that all irreducible character values are integers (they are real algebraic integers, hence lie in$\mathbb{Z}$ after the extra constraint that they belong to the character field$\mathbb{Q}$).

\begin{proposition}
If every element of $G$ is conjugate to its inverse, then$\chi_V(g) \in \mathbb{R}$ for all irreducible$V$ and all$g \in G$. If additionally$G$ is "rational" (every element is conjugate to all of its generators), then all character values are in$\mathbb{Z}$.
\end{proposition}
