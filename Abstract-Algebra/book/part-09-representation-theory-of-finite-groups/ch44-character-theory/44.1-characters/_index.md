# 44.1 Characters

Given a representation $\rho: G \to GL(V)$, define the character $\chi_\rho: G \to k$ by $\chi_\rho(g) = \text{tr}(\rho(g))$. The trace of a matrix is invariant under change of basis — $\text{tr}(PMP^{-1}) = \text{tr}(M)$ for any invertible $P$ — so isomorphic representations have identical characters. The central question of this section is whether the converse holds: can the character alone distinguish non-isomorphic representations? The answer is yes, and establishing this is the main work of the section.

The first basic properties of characters follow immediately from properties of the trace. Since $\text{tr}(AB) = \text{tr}(BA)$, we have $\chi(hgh^{-1}) = \text{tr}(\rho(hgh^{-1})) = \text{tr}(\rho(h)\rho(g)\rho(h)^{-1}) = \text{tr}(\rho(g)) = \chi(g)$. Characters are therefore class functions: functions $G \to k$ that are constant on conjugacy classes. This is not merely a formal observation — it means characters live in the finite-dimensional vector space $\text{Cl}(G)$ of class functions, whose dimension equals the number of conjugacy classes. The behavior of characters under the basic operations of representation theory is equally clean: $\chi_{V \oplus W} = \chi_V + \chi_W$, $\chi_{V \otimes W} = \chi_V \cdot \chi_W$, and $\chi_{V^*}(g) = \overline{\chi_V(g)}$ when $k = \mathbb{C}$ (since the eigenvalues of $\rho(g)^{-1} = \rho(g^{-1})$ are the reciprocals of those of $\rho(g)$, and for unitary representations reciprocal equals complex conjugate).

The character $\chi(e) = \text{tr}(\text{id}_V) = \dim V$ records the degree of the representation, and the character values $\chi(g)$ for $g \neq e$ encode far more subtle information. For a representation over $\mathbb{C}$, the eigenvalues of $\rho(g)$ are roots of unity (since $g$ has finite order), so each $\chi(g)$ is a sum of roots of unity and in particular an algebraic integer. The absolute value satisfies $|\chi(g)| \leq \chi(e)$, with equality if and only if $\rho(g)$ is a scalar matrix — a constraint that detects whether $g$ lies in the kernel of the representation. These analytic properties of character values are elementary but will be used repeatedly in the applications of character theory, including the proof of Burnside's theorem.
