# 44.2.3 Second Orthogonality: Column Orthogonality of the Character Table

The character table is a square matrix, and the first orthogonality relation says that its rows are orthonormal in a suitable sense. A natural question is what happens when one considers columns instead. The \emph{second orthogonality relation} provides the answer, and together the two relations give a complete description of the invertibility and structure of the character table as a matrix.

\begin{theorem}[Second Orthogonality]
For any two group elements $g, h \in G$:
$$\sum_{i=1}^r \chi_i(g)\,\overline{\chi_i(h)} = \begin{cases} |C_G(g)| & \text{if } g \sim h \text{ (i.e., } g \text{ and } h \text{ are conjugate)}, \\ 0 & \text{otherwise,}\end{cases}$$
where the sum is over all irreducible characters $\chi_i$ and$|C_G(g)|$ is the order of the centralizer of$g$ in$G$.
\end{theorem}

Equivalently, in terms of conjugacy classes $C_j$ (indexed by$j = 1, \ldots, r$) with representatives$g_j$:
$$\sum_{i=1}^r \chi_i(g_j)\,\overline{\chi_i(g_k)} = |C_G(g_j)|\,\delta_{jk} = \frac{|G|}{|C_j|}\,\delta_{jk}.$$

The proof derives second orthogonality from first orthogonality using the invertibility of the character table matrix. Let $X$ be the$r \times r$ character table matrix with$X_{ij} = \chi_i(g_j)$, and let$D$ be the diagonal matrix with$D_{jj} = |C_j|/|G|$ (the probability of landing in class$j$ under the uniform measure). First orthogonality states$XDX^* = I$, where$X^*$ is the conjugate transpose. Multiplying on the right:$X^*XD = I$, hence$X^*X = D^{-1}$. In components:
$$\sum_i \overline{X_{ij}} X_{ik} = (D^{-1})_{jk} = \frac{|G|}{|C_j|}\,\delta_{jk},$$
which is second orthogonality.

\begin{example}
For $G = S_3$: the character table is
\[
\begin{array}{c|ccc}
 & e & (12) & (123) \\
\hline
\chi_1 & 1 & 1 & 1 \\
\chi_2 & 1 & -1 & 1 \\
\chi_3 & 2 & 0 & -1
\end{array}
\]
Column for $g = (12)$:$\sum_i |\chi_i((12))|^2 = 1 + 1 + 0 = 2 = |C_{S_3}((12))| = 2$. \checkmark
\par
Column for $g = (123)$:$\sum_i |\chi_i((123))|^2 = 1 + 1 + 1 = 3 = |C_{S_3}((123))| = 3$. \checkmark
\par
Cross-column $g = (12)$,$h = (123)$:$\sum_i \chi_i((12))\overline{\chi_i((123))} = 1 \cdot 1 + (-1) \cdot 1 + 0 \cdot (-1) = 0$. \checkmark
\end{example}

\begin{example}
For $G = D_4$ with classes$C_1 = \{e\}$ (size 1),$C_2 = \{r^2\}$ (size 1),$C_3 = \{r,r^3\}$ (size 2),$C_4 = \{s,r^2s\}$ (size 2),$C_5 = \{rs,r^3s\}$ (size 2): second orthogonality on the identity column gives$\sum_i |\chi_i(e)|^2 = \sum_i n_i^2 = 1+1+1+1+4 = 8 = |C_G(e)| = |D_4|$. This is just the dimension formula again!
\end{example}

To see why this matters: the second orthogonality relation allows one to recover information about conjugacy classes from the character table. Together, the two orthogonality relations say that the character table matrix $X$ is invertible with$X^{-1} = D \cdot X^*$ (where$D_{jj} = |C_j|/|G|$). This invertibility is the statement that the character table encodes complete information about both the representation theory (row structure) and the class structure (column structure) of$G$.

\begin{remark}
Second orthogonality has a direct application to centralizer orders. If one knows the character table, one can compute $|C_G(g)|$ without any group-theoretic calculation:$|C_G(g)| = \sum_i |\chi_i(g)|^2$. This is a remarkable fact: a purely algebraic quantity (the centralizer order) is computable from the analytic data (character values) via the second orthogonality formula.
\end{remark}

\begin{example}
For $G = A_4$: the character table (to be verified) has four rows and four columns. The character values for the 3-dimensional irreducible$\chi_4$:$\chi_4(e) = 3$,$\chi_4((12)(34)) = -1$ (since the 4 double transpositions act on the standard 3-dimensional representation),$\chi_4((123)) = 0$,$\chi_4((132)) = 0$. Column norm at the double transposition class (size 3):$\sum_i |\chi_i((12)(34))|^2 = 1 + 1 + 1 + 1 = 4 = |C_{A_4}((12)(34))|$. Check: centralizer of$(12)(34)$ in$A_4$ contains$\{e, (12)(34), (13)(24), (14)(23)\} = V_4$, so$|C_{A_4}((12)(34))| = 4$ \checkmark.
\end{example}

The two orthogonality relations together give a complete set of necessary conditions for a matrix to be a character table. Remarkably, they are also essentially sufficient: any square matrix of complex numbers satisfying row orthonormality and column orthonormality (with the appropriate class-size weights) that has positive-integer first column (satisfying the dimension formula) and algebraic-integer entries (lying in the appropriate cyclotomic field) is the character table of some finite group. This "characterization theorem" is a deep result that confirms the character table as the canonical complete invariant of the representation theory of $G$.

\begin{remark}
The two orthogonality relations can be summarized elegantly using the Fourier transform on $G$. The map$f \mapsto \hat{f}$ defined by$\hat{f}(\chi_i) = \sum_{g \in G} f(g) \chi_i(g^{-1})$ (the group Fourier transform) sends class functions to sequences of operators on the irreducible representation spaces. The Plancherel formula$\sum_g |f(g)|^2 = \frac{1}{|G|} \sum_i n_i \|\hat{f}(\chi_i)\|^2_{\mathrm{HS}}$ (where$\|\cdot\|_{\mathrm{HS}}$ is the Hilbert-Schmidt norm) generalizes both orthogonality relations to arbitrary functions on$G$.
\end{remark}
