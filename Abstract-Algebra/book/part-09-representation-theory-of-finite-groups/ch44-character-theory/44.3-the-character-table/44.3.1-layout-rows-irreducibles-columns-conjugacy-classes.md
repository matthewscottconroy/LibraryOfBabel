# 44.3.1 Layout: Rows = Irreducibles, Columns = Conjugacy Classes

The \emph{character table} of $G$ is the compact encoding of all irreducible characters and their values. It is organized as an$r \times r$ matrix — square precisely because the number of irreducibles equals the number of conjugacy classes — and it condenses an enormous amount of structural information about$G$ into a single combinatorial object.

\begin{definition}
The \emph{character table} of $G$ is the$r \times r$ matrix$X$ with$X_{ij} = \chi_i(g_j)$, where$\chi_1, \ldots, \chi_r$ are the irreducible characters (indexed by row) and$g_1, \ldots, g_r$ are representatives of the conjugacy classes$C_1, \ldots, C_r$ of$G$ (indexed by column).
\end{definition}

By convention, the first row corresponds to the trivial character $\chi_1 \equiv 1$ (all entries equal to$1$), and the first column corresponds to the identity class$C_1 = \{e\}$. Since$\chi_i(e) = \dim V_i = n_i$, the first column records the dimensions of all irreducible representations. This column must satisfy the dimension formula$\sum_i n_i^2 = |G|$.

\begin{example}
The character table of $S_3$ (computed fully in §44.3.3):
$$
\begin{array}{c|ccc}
S_3 & e & (12) & (123) \\
\hline
\chi_1 & 1 & 1 & 1 \\
\chi_2 & 1 & -1 & 1 \\
\chi_3 & 2 & 0 & -1
\end{array}
$$
Rows: trivial, sign, standard. Columns: three conjugacy classes. First column: $(1,1,2)$, satisfying$1+1+4=6=|S_3|$.
\end{example}

From the character table one can read off a remarkable amount of group-theoretic information:

\textbf{Dimensions of irreducibles.} The first column gives all $n_i = \chi_i(e)$.

\textbf{Class sizes.} By second orthogonality, $|C_G(g_j)| = \sum_i |\chi_i(g_j)|^2$, so$|C_j| = |G|/|C_G(g_j)|$ is readable from the column norms.

\textbf{Abelianness.} $G$ is abelian if and only if all$n_i = 1$ (equivalently, the first column is all ones).

\textbf{Normal subgroups.} Every normal subgroup of $G$ is an intersection of kernels of irreducible representations, where$\ker \chi_i = \{g : \chi_i(g) = n_i\}$. So normal subgroups are readable from the table (§44.4.3).

\textbf{Derived subgroup.} The 1-dimensional characters of $G$ are exactly the characters that factor through$G/[G,G]$. The number of 1-dimensional characters equals$|G/[G,G]| = |G^{\mathrm{ab}}|$, so the derived subgroup index is readable from the character table.

\begin{example}
For $S_4$: the character table has five rows. Three 1-dimensional characters — trivial, sign, and... wait:$S_4^{\mathrm{ab}} = S_4/A_4 \cong \mathbb{Z}/2\mathbb{Z}$, so there are only two 1-dimensional characters (trivial and sign). The dimensions are$(1,1,2,3,3)$, where the two 3-dimensional irreducibles can be distinguished by their character values on the five conjugacy classes.
\end{example}

The orthogonality relations mean the character table is an invertible matrix satisfying explicit orthogonality conditions on its rows and columns, making it far from arbitrary. The row orthogonality $XDX^* = I$ (where$D_{jj} = |C_j|/|G|$) and column orthogonality$X^*X = D^{-1}$ together overdetermine the character table: there are many more constraints than free entries.

\begin{remark}
The character table does not uniquely determine $G$ up to isomorphism: there are non-isomorphic groups with identical character tables. The smallest examples have order 16. However, the character table determines: the order of$G$, the number of elements of each order, whether$G$ is solvable (by Burnside's theorem and its consequences), and all normal subgroup structure. It is one of the most powerful single invariants of a finite group.
\end{remark}

The structure of the character table also encodes arithmetic data about the group. The \emph{Frobenius–Schur indicator} $\nu_2(\chi_i) = \frac{1}{|G|}\sum_{g \in G} \chi_i(g^2)$ takes values$+1$,$0$, or$-1$, detecting whether the irreducible$V_i$ admits a real form ($+1$), is "complex type" with$V_i \not\cong V_i^*$ ($0$), or is "quaternionic type" ($-1$). This indicator is computable directly from the character table (since$\chi_i(g^2)$ is determined by which column$g^2$ falls in, and the column is determined by$g$'s class), yet it encodes deep information about the real structure of the representation.

\begin{example}
For $G = S_3$: all character values are real (the table has only real entries), and$S_3$ has no non-trivial quaternionic representations. Frobenius–Schur indicators:$\nu_2(\chi_1) = 1$,$\nu_2(\chi_2) = 1$,$\nu_2(\chi_3) = 1$ (all real type).
\par
For $G = \mathbb{Z}/3\mathbb{Z}$: the non-trivial 1-dimensional characters$\chi_1, \chi_2$ (with values$\omega, \omega^2$) are complex type:$\nu_2(\chi_1) = \frac{1}{3}(1 + \omega^2 + \omega^4) = \frac{1}{3}(1 + \omega^2 + \omega) = 0$. These characters are not self-conjugate ($\chi_1^* = \chi_2 \neq \chi_1$).
\end{example}

The character table also encodes the \emph{structure constants} of the center $Z(\mathbb{C}[G])$: the product of class sums satisfies$\hat{C}_j \cdot \hat{C}_k = \sum_l a_{jk}^l \hat{C}_l$ where$a_{jk}^l = \frac{|C_j||C_k|}{|G|}\sum_i \frac{\chi_i(g_j)\chi_i(g_k)\overline{\chi_i(g_l)}}{n_i}$ is computable from character values. These non-negative integers$a_{jk}^l$ count the number of ways to write a fixed element$g_l$ as a product$g'g''$ with$g' \in C_j$ and$g'' \in C_k$, encoding the multiplicative structure of conjugacy classes.
