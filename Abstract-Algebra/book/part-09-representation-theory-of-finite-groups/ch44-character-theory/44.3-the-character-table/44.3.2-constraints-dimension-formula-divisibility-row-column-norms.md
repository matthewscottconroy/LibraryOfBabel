# 44.3.2 Constraints: Dimension Formula, Divisibility, Row/Column Norms

The entries of the character table are far from arbitrary. A system of interlocking constraints governs what values can appear, and together these constraints are often strong enough to determine the character table of a group without constructing any representations explicitly. The art of computing character tables by hand consists in applying these constraints systematically until the table is uniquely pinned down.

\textbf{The dimension formula.} The most fundamental constraint is $\sum_i n_i^2 = |G|$ (derived in §43.3.2), where$n_i = \chi_i(e) = \dim V_i$. For small groups, this severely limits the possible dimension sequences.

\textbf{Row orthonormality.} Each row $\chi_i$ of the character table satisfies$\langle \chi_i, \chi_i \rangle = 1$:
$$\frac{1}{|G|} \sum_j |C_j|\, |\chi_i(g_j)|^2 = 1, \quad \text{i.e., } \sum_j |C_j|\, |\chi_i(g_j)|^2 = |G|.$$
This is a real constraint on the magnitudes of character values.

\textbf{Column norms (second orthogonality).} Each column satisfies $\sum_i |\chi_i(g)|^2 = |C_G(g)|$.

\textbf{The divisibility constraint.} Each $n_i = \dim V_i$ divides$|G|$. More sharply,$n_i$ divides$[G : Z(G)] = |G|/|Z(G)|$. This follows from the theory of algebraic integers applied to the class equation.

\begin{theorem}[Divisibility of irreducible degrees]
For each irreducible representation $V_i$ of$G$,$\dim V_i$ divides$|G|$.
\end{theorem}

The proof uses the fact that $\frac{|G|}{n_i} = \frac{|G|\langle \chi_i, \chi_i \rangle}{n_i} = \sum_j \frac{|C_j|\, |\chi_i(g_j)|^2}{n_i}$. One shows each summand is an algebraic integer (using the eigenvalue of the class sum on$V_i$), so the sum is an algebraic integer. Since it is also rational, it is an ordinary integer, giving$n_i \mid |G|$.

\textbf{Integrality.} All character values $\chi_i(g)$ are algebraic integers lying in the cyclotomic field$\mathbb{Q}(\zeta_{|G|})$. Since elements of$G$ have order dividing$|G|$, the eigenvalues of$\rho_i(g)$ are$|G|$th roots of unity, and sums thereof are in$\mathbb{Q}(\zeta_{|G|})$.

\textbf{Galois action.} The Galois group $\mathrm{Gal}(\mathbb{Q}(\zeta_{|G|})/\mathbb{Q})$ acts on the set of irreducible characters: if$\sigma_k: \zeta \mapsto \zeta^k$ (with$\gcd(k, |G|) = 1$), then$\sigma_k(\chi_i)$ is the character$g \mapsto \chi_i(g^k)$, which is another irreducible character (possibly$\chi_i$ itself if$\chi_i$ is rational-valued).

\begin{example}
For $A_4$:$|A_4| = 12$,$r = 4$, dimensions$(1,1,1,3)$. The center$Z(A_4) = \{e\}$, so divisibility gives$n_i \mid 12$. The three 1-dimensional characters come from$A_4^{\mathrm{ab}} = A_4/V_4 \cong \mathbb{Z}/3\mathbb{Z}$, so they take values in$\{1, \omega, \omega^2\}$ where$\omega = e^{2\pi i/3}$. The Galois action swaps$\chi_2$ (values involving$\omega$) and$\chi_3$ (values involving$\omega^2$). The 3-dimensional character$\chi_4$ is rational-valued (fixed by all Galois automorphisms).
\end{example}

\begin{example}
Applying all constraints to $G = S_4$:$|G| = 24$,$r = 5$. Dimension formula forces$(n_1, \ldots, n_5) = (1,1,2,3,3)$. Center$Z(S_4) = \{e\}$, so$n_i \mid 24$ (no extra info here). Abelianization$S_4^{\mathrm{ab}} = S_4/A_4 \cong \mathbb{Z}/2\mathbb{Z}$, so exactly two 1-dimensional characters (trivial and sign). The 2-dimensional irreducible comes from the quotient$S_4 \to S_3$ (via$S_4/V_4 \cong S_3$) composed with the 2-dimensional irreducible of$S_3$. The two 3-dimensional irreducibles are distinguished by: row orthogonality with the other rows, integrality (all values$\in \mathbb{Z}$ since$S_4$-characters are rational-valued), and column norms.
\end{example}

In practice, starting with the dimension formula to fix the possible $n_i$, then imposing row and column norms, and finally using divisibility and integrality, often uniquely pins down all entries of the character table. The character table is highly overdetermined: for a group with$r$ conjugacy classes, there are$r^2$ entries but roughly$r^2$ independent constraints from row and column orthogonality, integrality, and conjugation symmetry.

\begin{example}
Applying all constraints to $G = Q_8$:$|Q_8| = 8$, five conjugacy classes. Dimensions:$(1,1,1,1,2)$. The abelianization$Q_8/[Q_8,Q_8] = Q_8/\{1,-1\} \cong (\mathbb{Z}/2\mathbb{Z})^2$ has four characters; the four 1-dimensional irreducibles are the inflations of these. For the 2-dimensional irreducible$\chi_5$:$\chi_5(1) = 2$, and$\chi_5(-1)$: since$-1 \in Z(Q_8)$, it acts as a scalar$\lambda I$ with$\chi_5(-1) = 2\lambda$. Since$(-1)^2 = 1$,$\lambda^2 = 1$, so$\lambda = \pm 1$ and$\chi_5(-1) = \pm 2$. Column norm at$-1$:$\sum_i |\chi_i(-1)|^2 = 1+1+1+1+|\chi_5(-1)|^2 = 8$ (since$|C_{Q_8}(-1)| = |Q_8| = 8$ as$-1$ is central). So$|\chi_5(-1)|^2 = 4$, giving$\chi_5(-1) = -2$ (the minus sign is forced by row orthogonality with the trivial character:$\langle \chi_5, \chi_1 \rangle = \frac{1}{8}(1\cdot2 + 1\cdot\chi_5(-1) + 2\cdot0 + 2\cdot0 + 2\cdot0) = \frac{2+\chi_5(-1)}{8} = 0$ forces$\chi_5(-1) = -2$). Character values at$\pm i, \pm j, \pm k$: from row norm$\frac{1}{8}(4 + 4 + 2|\chi_5(i)|^2 + 2|\chi_5(j)|^2 + 2|\chi_5(k)|^2) = 1$, giving$|\chi_5(i)|^2 + |\chi_5(j)|^2 + |\chi_5(k)|^2 = 0$, so all are zero.
\end{example}

\begin{remark}
The integrality constraint combined with divisibility is sometimes enough to pin down a unique entry. For instance, if a character value $\chi_i(g)$ must be a sum of$n_i$th roots of unity (algebraic integer), must satisfy$|\chi_i(g)| \leq n_i$, must be real (when$g \sim g^{-1}$), and must be divisible by certain integers from divisibility constraints, there may be only finitely many possibilities — often just one. This "by exclusion" approach is powerful for groups of moderate size without needing to construct explicit matrices.
\end{remark}
