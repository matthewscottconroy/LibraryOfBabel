# 44.3 The Character Table

The character table of $G$ is a square matrix $X$ with rows indexed by irreducible representations $V_1, \ldots, V_r$ and columns indexed by conjugacy classes $C_1, \ldots, C_r$, with entry $X_{ij} = \chi_i(g_j)$ for any representative $g_j \in C_j$. That the matrix is square — $r$ rows and $r$ columns, the same number of irreducibles as conjugacy classes — is the conclusion of the Artin–Wedderburn analysis of Section 43.2, and it underlies the entire discussion. The character table is not just a compact summary of the irreducible characters: it encodes, in principle, all representation-theoretic information about $G$.

The orthogonality relations impose strong constraints on the entries. The first relation says the rows are orthonormal: $\frac{1}{|G|} \sum_j |C_j| X_{ij} \overline{X_{i'j}} = \delta_{ii'}$. The second says the (appropriately weighted) columns are orthonormal: $\sum_i X_{ij} \overline{X_{ij'}} = \frac{|G|}{|C_j|} \delta_{jj'}$. Additional constraints come from the dimension formula $\sum_i (\dim V_i)^2 = |G|$, the fact that each $\chi_i(e) = \dim V_i$ is a positive integer dividing $|G|$, and the fact that the first row must be the trivial character (all 1's) if the trivial representation is included. For small groups, these constraints together with a small amount of case analysis often determine the table completely, without computing any representations explicitly.

The character table for $S_3$ is the standard worked example: three conjugacy classes (identity, three transpositions, two 3-cycles), three irreducibles (trivial of dimension 1, sign of dimension 1, standard of dimension 2), and the $3 \times 3$ table that can be read off from the explicit representations. Computing the character table for $D_4$ and $Q_8$ requires more care, since both groups have 5 conjugacy classes and the dimension formula $1 + 1 + 1 + 1 + 4 = 8$ forces four 1-dimensional and one 2-dimensional irreducible, but the actual character values depend on the group structure. The procedure for building a character table — identify conjugacy classes, use the dimension formula, then determine values using orthogonality and known examples — is systematized in this section into a practicable algorithm.
