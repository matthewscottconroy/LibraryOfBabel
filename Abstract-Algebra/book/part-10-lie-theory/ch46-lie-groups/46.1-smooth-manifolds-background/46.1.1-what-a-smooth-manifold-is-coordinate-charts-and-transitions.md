# 46.1.1 What a Smooth Manifold Is: Coordinate Charts and Transitions

The study of Lie groups begins with a problem that is conceptually prior to any algebra: how to speak coherently about smoothness on a space that has no preferred global coordinate system. Euclidean space $\mathbb{R}^n$ comes equipped with standard coordinates, and one defines smoothness of a function on$\mathbb{R}^n$ by demanding that all partial derivatives exist and are continuous. But the rotation group$SO(3)$, for instance, is not naturally an open subset of any Euclidean space — it is a curved three-dimensional object winding through the space of$3\times 3$ matrices. We want to say that certain functions on$SO(3)$ are smooth, but we need a definition that does not privilege any particular coordinate patch.

The notion of a smooth manifold resolves this tension elegantly. The key observation is that smoothness is a *local* property: a function on a space is smooth if and only if it is smooth when expressed in coordinates near each point. If the space looks locally like $\mathbb{R}^n$ — meaning each point has a neighborhood that can be identified homeomorphically with an open subset of$\mathbb{R}^n$ — then one can test smoothness in coordinates. The only subtlety is consistency: if a region$U$ is covered by two coordinate patches, one needs to know that "smooth in the first coordinate system" is equivalent to "smooth in the second." This is exactly what the transition map condition guarantees.

\begin{definition}
A \emph{smooth $n$-manifold} is a Hausdorff, second-countable topological space$M$ together with a collection of pairs$\{(U_\alpha, \phi_\alpha)\}$ called an \emph{atlas}, where:
\begin{itemize}
\item The open sets $U_\alpha$ cover$M$:$M = \bigcup_\alpha U_\alpha$.
\item Each $\phi_\alpha: U_\alpha \to \mathbb{R}^n$ is a homeomorphism onto its image (an open subset of$\mathbb{R}^n$). The pair$(U_\alpha, \phi_\alpha)$ is called a \emph{coordinate chart}.
\item Whenever $U_\alpha \cap U_\beta \neq \emptyset$, the \emph{transition map}$\phi_\beta \circ \phi_\alpha^{-1}: \phi_\alpha(U_\alpha \cap U_\beta) \to \phi_\beta(U_\alpha \cap U_\beta)$ is a smooth ($C^\infty$) map between open subsets of$\mathbb{R}^n$.
\end{itemize}
One also requires the atlas to be maximal (any chart compatible with all charts in the atlas is already in the atlas), but in practice one specifies a smaller atlas and extends it.
\end{definition}

The transition map condition does exactly what it promises: it ensures that the notion of smoothness is chart-independent. If a function $f: M \to \mathbb{R}$ appears smooth in the coordinate system given by$\phi_\alpha$ (meaning$f \circ \phi_\alpha^{-1}$ is smooth as a function on$\mathbb{R}^n$), then in any overlapping chart$\phi_\beta$ the composite$f \circ \phi_\beta^{-1} = (f \circ \phi_\alpha^{-1}) \circ (\phi_\alpha \circ \phi_\beta^{-1})$ is a composite of smooth maps, hence smooth. So the smooth functions on$M$ are well defined, independent of any particular chart.

The dimension $n$ of the Euclidean pieces is a topological invariant of$M$ — one cannot have a manifold that looks like$\mathbb{R}^2$ near some points and$\mathbb{R}^3$ near others (assuming connectedness). This number$n = \dim M$ is the manifold dimension.

**Example 1.** The simplest smooth manifold is $\mathbb{R}^n$ itself, covered by the single identity chart$\phi = \mathrm{id}: \mathbb{R}^n \to \mathbb{R}^n$. Since there is only one chart, there are no transition maps to check, and the manifold axioms are trivially satisfied.

**Example 2.** The unit circle $S^1 = \{(x,y) \in \mathbb{R}^2 : x^2 + y^2 = 1\}$ is a smooth$1$-manifold. One atlas uses two charts:$U_+ = S^1 \setminus \{(0,1)\}$ and$U_- = S^1 \setminus \{(0,-1)\}$, each mapped to$\mathbb{R}$ by stereographic projection. The north-pole stereographic projection sends$(x,y) \mapsto x/(1-y)$ and the south-pole projection sends$(x,y) \mapsto x/(1+y)$. The transition map on the overlap (where both are defined) is$t \mapsto 1/t$, which is smooth on$\mathbb{R} \setminus \{0\}$. Similarly, the$n$-sphere$S^n$ is a smooth$n$-manifold covered by two stereographic projection charts.

**Example 3.** The general linear group $GL_n(\mathbb{R})$ of invertible$n \times n$ real matrices is a smooth manifold of dimension$n^2$. Regard$M_n(\mathbb{R})$, the space of all$n \times n$ matrices, as$\mathbb{R}^{n^2}$ by listing the matrix entries. Then$GL_n(\mathbb{R}) = \det^{-1}(\mathbb{R} \setminus \{0\})$ is an open subset of$\mathbb{R}^{n^2}$ (since the determinant is a continuous function), so it inherits a smooth manifold structure from$\mathbb{R}^{n^2}$ via the single chart given by the inclusion. This is the starting example for all of matrix Lie group theory.

**Example 4.** The real projective space $\mathbb{R}P^n = ({\mathbb{R}^{n+1} \setminus \{0\}}) / \mathbb{R}^\times$ of lines through the origin in$\mathbb{R}^{n+1}$ is a smooth$n$-manifold. It is covered by$n+1$ charts$U_i = \{[x_0:\cdots:x_n] : x_i \neq 0\}$, each homeomorphic to$\mathbb{R}^n$ via$[x_0:\cdots:x_n] \mapsto (x_0/x_i, \ldots, \hat{x}_i/x_i, \ldots, x_n/x_i)$. The transition maps are rational functions with nonvanishing denominators, hence smooth. Projective spaces appear in Lie theory as flag varieties, on which Lie groups act in ways that govern the structure of their representations.

The key insight underlying all of this is that the transition map condition does exactly what it promises: it ensures that any notion of smoothness defined in one chart is automatically smoothness in every other chart. The collection of smooth functions $C^\infty(M)$ is thus a well-defined ring, and it is this ring — together with its derivations, which model tangent vectors — that carries the infinitesimal information about$M$. For Lie theory, the manifolds of greatest interest are the Lie groups themselves, and the next few sections develop the tools (smooth maps, tangent spaces) needed to analyze them.
