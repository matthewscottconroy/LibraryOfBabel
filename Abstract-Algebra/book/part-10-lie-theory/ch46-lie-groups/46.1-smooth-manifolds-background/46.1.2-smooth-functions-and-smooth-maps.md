# 46.1.2 Smooth Functions and Smooth Maps

Once a smooth manifold is defined, one immediately wants to know what it means for a function on that manifold to be smooth. The answer is entirely local: one tests smoothness by expressing the function in coordinates near each point and checking the classical calculus definition there. The compatibility of the atlas then guarantees the answer is independent of which chart one uses.

\begin{definition}
A function $f: M \to \mathbb{R}$ on a smooth manifold$M$ is \emph{smooth} (or$C^\infty$) if for every chart$(U_\alpha, \phi_\alpha)$, the composite
$$f \circ \phi_\alpha^{-1}: \phi_\alpha(U_\alpha) \subseteq \mathbb{R}^n \to \mathbb{R}$$
is smooth in the ordinary sense. The set of all smooth real-valued functions on $M$ is denoted$C^\infty(M)$ and forms a commutative$\mathbb{R}$-algebra under pointwise addition and multiplication.
\end{definition}

The same idea extends to maps between two manifolds. A map $F: M \to N$ between smooth manifolds is \emph{smooth} if for every chart$(U, \phi)$ on$M$ and every chart$(V, \psi)$ on$N$ with$F(U) \subseteq V$, the composite
$$\psi \circ F \circ \phi^{-1}: \phi(U) \to \psi(V)$$
is smooth as a map between open subsets of Euclidean spaces. Again, the atlas compatibility conditions ensure this is independent of the chart choices. Smooth maps between manifolds compose smoothly: if $F: M \to N$ and$G: N \to P$ are both smooth, then$G \circ F: M \to P$ is smooth.

A smooth map $F: M \to N$ is a \emph{diffeomorphism} if it is bijective and its inverse$F^{-1}: N \to M$ is also smooth. Diffeomorphic manifolds are considered identical from the differential-geometric viewpoint: they carry the same smooth structure, the same smooth functions, and the same calculus. Diffeomorphisms are the isomorphisms in the category of smooth manifolds.

This structure is categorical in nature. Smooth manifolds as objects and smooth maps as morphisms form a category, conventionally denoted $\mathbf{Man}^\infty$. A Lie group will be an object in this category that simultaneously carries a group structure, with all group operations being morphisms — the precise confluence of the algebraic and the geometric that sits at the heart of the theory.

**Example 1.** Any polynomial map $F: \mathbb{R}^m \to \mathbb{R}^n$ is smooth. More generally, any rational function on an open set where the denominator does not vanish is smooth. The matrix multiplication map$\mu: M_n(\mathbb{R}) \times M_n(\mathbb{R}) \to M_n(\mathbb{R})$ is polynomial (each entry of$AB$ is a degree-2 polynomial in the entries of$A$ and$B$), hence smooth. Restricting to the open subset$GL_n(\mathbb{R})$, this shows that matrix multiplication on the general linear group is smooth.

**Example 2.** The inversion map $\iota: GL_n(\mathbb{R}) \to GL_n(\mathbb{R})$,$A \mapsto A^{-1}$, is smooth. By Cramer's rule, each entry of$A^{-1}$ is a rational function of the entries of$A$ with denominator$\det(A) \neq 0$ on$GL_n(\mathbb{R})$. Since rational functions with nonvanishing denominators are smooth,$\iota$ is smooth. These two observations — smooth multiplication and smooth inversion — are precisely what make$GL_n(\mathbb{R})$ a Lie group.

**Example 3.** The exponential map $\exp: M_n(\mathbb{R}) \to M_n(\mathbb{R})$, defined by$\exp(X) = \sum_{k=0}^\infty X^k/k!$, is smooth. Each partial sum is a polynomial in the entries of$X$, and the series converges uniformly on compact subsets, so the limit is smooth. Restricted to any closed subgroup$G \leq GL_n$, the exponential map$\exp: \mathfrak{g} \to G$ is the fundamental bridge between the Lie algebra$\mathfrak{g}$ and the group$G$.

**Example 4.** The determinant function $\det: GL_n(\mathbb{R}) \to \mathbb{R}^\times$ is smooth (it is a polynomial in matrix entries). Its restriction to$SL_n(\mathbb{R}) = \det^{-1}(1)$ is a smooth embedding of$SL_n$ into$GL_n$. The kernel of a smooth group homomorphism is always a closed (hence smooth) subgroup, so the inclusion$SL_n \hookrightarrow GL_n$ is smooth. The differential of$\det$ at the identity turns out to be the trace functional, as one computes by differentiating$\det(I + tX)$ at$t=0$:$\frac{d}{dt}\big|_{t=0} \det(I + tX) = \mathrm{tr}(X)$.

The smooth functions on a manifold $M$ encode all of its geometric information. The tangent vectors at a point will be defined as derivations of$C^\infty(M)$ (Section 46.1.3), and the Lie algebra of a Lie group will emerge as a space of derivations compatible with the group structure (Section 47.1.2). Understanding smooth maps and the category they generate is therefore the necessary prerequisite for the algebraic theory that follows.
