# 47.1.3 The Lie Algebra of a Matrix Group: $\{X : e^{tX} \in G\}$

For matrix Lie groups, the abstract definition of the Lie algebra via tangent spaces and left-invariant vector fields translates into a beautifully concrete description. The Lie algebra of $G \leq GL_n$ is the set$\mathfrak{g} = \{X \in M_n : e^{tX} \in G \text{ for all } t \in \mathbb{R}\}$, with the Lie bracket given by the matrix commutator$[X, Y] = XY - YX$.

The key to computing $\mathfrak{g}$ for any specific matrix group is to use the properties of the matrix exponential, particularly the formula$\det(e^X) = e^{\mathrm{tr}(X)}$ and the identity$(e^X)^T = e^{X^T}$. One differentiates the defining equation of$G$ at the identity: if$G$ is defined by$F(A) = C$ for some smooth function$F$ with$F(I) = C$, then$\mathfrak{g} = \ker(dF_I)$.

**Example 1.** $\mathfrak{gl}_n(\mathbb{R}) = M_n(\mathbb{R})$. For$G = GL_n(\mathbb{R})$ there is no constraint on$X$, so$\mathfrak{gl}_n = M_n(\mathbb{R})$.

**Example 2.** $\mathfrak{sl}_n(\mathbb{R}) = \{X \in M_n(\mathbb{R}) : \mathrm{tr}(X) = 0\}$. For$G = SL_n(\mathbb{R}) = \{\det A = 1\}$, the condition$\det(e^{tX}) = e^{t\,\mathrm{tr}(X)} = 1$ for all$t$ forces$\mathrm{tr}(X) = 0$. Dimension:$n^2 - 1$.

**Example 3.** $\mathfrak{o}(n) = \{X \in M_n(\mathbb{R}) : X + X^T = 0\}$, the skew-symmetric matrices. For$G = O(n) = \{A^T A = I\}$, differentiate$(e^{tX})^T e^{tX} = I$ at$t = 0$:$e^{tX^T} e^{tX} = I$, so differentiating gives$X^T + X = 0$. Dimension:$n(n-1)/2$.

**Example 4.** $\mathfrak{sp}(2n) = \{X \in M_{2n}(\mathbb{R}) : X^T J + JX = 0\}$. For$G = Sp(2n) = \{A^T J A = J\}$, differentiate to get$(e^{tX})^T J e^{tX} = J$, differentiating at$t=0$:$X^T J + JX = 0$. Dimension:$n(2n+1)$.

**Example 5.** $\mathfrak{u}(n) = \{X \in M_n(\mathbb{C}) : X + X^* = 0\}$, the skew-Hermitian matrices. For$G = U(n) = \{A^* A = I\}$, differentiate$(e^{tX})^* e^{tX} = I$ to get$X^* + X = 0$.

The general method — differentiate the defining equation of $G$ at the identity to get the linear constraint defining$\mathfrak{g}$ — works uniformly for all matrix Lie groups and makes the Lie algebra computations tractable. It also confirms the dimension count: a constraint imposing$k$ scalar equations on$M_n(\mathbb{R})$ reduces the dimension from$n^2$ by$k$, giving$\dim G = n^2 - k$.

The matrix commutator $[X,Y] = XY - YX$ is the Lie bracket in all these cases, confirmed by the general theory of left-invariant vector fields specialized to matrix groups. Let us verify the closure of$\mathfrak{g}$ under the bracket for one case:

For $\mathfrak{so}(n)$: if$X^T = -X$ and$Y^T = -Y$, then$[X,Y]^T = (XY - YX)^T = Y^T X^T - X^T Y^T = (-Y)(-X) - (-X)(-Y) = YX - XY = -[X,Y]$. So$[X,Y]$ is again skew-symmetric, confirming$[\mathfrak{so}(n), \mathfrak{so}(n)] \subseteq \mathfrak{so}(n)$.

For $\mathfrak{sl}_n$: if$\mathrm{tr}(X) = \mathrm{tr}(Y) = 0$, then$\mathrm{tr}([X,Y]) = \mathrm{tr}(XY) - \mathrm{tr}(YX) = 0$ (trace is cyclic). So$[\mathfrak{sl}_n, \mathfrak{sl}_n] \subseteq \mathfrak{sl}_n$.

These closure verifications — which are trivial computations with the matrix commutator — illustrate why the matrix Lie group setting is so computationally accessible. The abstract axioms of Lie algebras (antisymmetry, Jacobi identity) are all inherited from the matrix commutator, and one never needs to verify them separately. The power of this framework becomes apparent in Chapters 48-50, where the structure theory (solvability, semisimplicity, root systems) and representation theory (highest weights, Weyl character formula) are developed using the concrete properties of these specific Lie algebras.
