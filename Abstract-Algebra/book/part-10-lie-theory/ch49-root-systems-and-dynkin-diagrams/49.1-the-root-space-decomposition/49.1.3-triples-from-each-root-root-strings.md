# 49.1.3 $\mathfrak{sl}_2$-Triples from Each Root; Root Strings

The one-dimensionality of root spaces and the pairing of roots $\alpha$ with$-\alpha$ together suggest a copy of$\mathfrak{sl}_2$ hiding inside$\mathfrak{g}$ for each root. This is indeed what happens. For each$\alpha \in \Phi$, one can find vectors$e_\alpha \in \mathfrak{g}_\alpha$ and$f_\alpha \in \mathfrak{g}_{-\alpha}$ and an element$h_\alpha \in \mathfrak{h}$ such that$[e_\alpha, f_\alpha] = h_\alpha$,$[h_\alpha, e_\alpha] = 2e_\alpha$, and$[h_\alpha, f_\alpha] = -2f_\alpha$. The triple$\{e_\alpha, f_\alpha, h_\alpha\}$ is called an$\mathfrak{sl}_2$-triple because it satisfies exactly the defining relations of$\mathfrak{sl}_2$. The normalization$[h_\alpha, e_\alpha] = 2e_\alpha$ (with coefficient 2 rather than 1) is conventional and reflects the standard choice of basis for$\mathfrak{sl}_2$.

The element $h_\alpha \in \mathfrak{h}$ is called the *coroot* of$\alpha$ and is often written$\alpha^\vee$. It is uniquely determined by$\alpha$ (once the normalization is fixed), and the map$\alpha \mapsto \alpha^\vee$ sends roots to coroots, defining a dual root system$\Phi^\vee$. The coroot is the element of$\mathfrak{h}$ corresponding to$\alpha$ under the identification$\mathfrak{h} \cong \mathfrak{h}^*$ given by the Killing form, rescaled by$2/\langle \alpha, \alpha \rangle$.

The representation theory of the $\mathfrak{sl}_2$-triple for$\alpha$ now acts on$\mathfrak{g}$ itself, and this action organizes the other roots into *root strings*. For two roots$\alpha, \beta \in \Phi$, the$\alpha$-string through$\beta$ is the set of all roots of the form$\beta + n\alpha$ for$n \in \mathbb{Z}$; this string forms an unbroken sequence$\beta - p\alpha, \ldots, \beta, \ldots, \beta + q\alpha$ for non-negative integers$p$ and$q$. Because the spaces$\mathfrak{g}_{\beta + n\alpha}$ form a module over the$\mathfrak{sl}_2$-triple for$\alpha$, the representation theory of$\mathfrak{sl}_2$ constrains the length of this string via the formula$p - q = \langle \beta, \alpha^\vee \rangle$, where$\langle \beta, \alpha^\vee \rangle = \beta(h_\alpha)$ is an integer called the *Cartan integer*. This integrality condition is the algebraic heart of root system theory.

The key insight is that the $\mathfrak{sl}_2$-triple machinery converts questions about the structure of$\mathfrak{g}$ into questions about finite-dimensional$\mathfrak{sl}_2$-representations, which are completely classified. This is the unifying thread: the structure of a general semisimple Lie algebra is understood by reducing every question to$\mathfrak{sl}_2$-theory applied along each root direction.

**Example 1.** For $\mathfrak{sl}_2$: the single$\mathfrak{sl}_2$-triple is$\{e, f, h\}$ itself. There is only one positive root$\alpha$, one negative root$-\alpha$, and no root strings to speak of (no root$\alpha + n\alpha$ for$n \geq 1$ exists). The Cartan integer$\langle \alpha, \alpha^\vee \rangle = 2$.

**Example 2.** For $\mathfrak{sl}_3$: the$\mathfrak{sl}_2$-triple for$\alpha_1$ is$\{E_{12}, E_{21}, H_1\}$. The$\alpha_1$-string through$\alpha_2$:$\alpha_2, \alpha_2 + \alpha_1$ (since$\alpha_2 - \alpha_1$ is not a root). We have$q = 1$ (can add$\alpha_1$ once to get$\alpha_1 + \alpha_2$),$p = 0$ (cannot subtract$\alpha_1$), giving$p - q = -1 = \langle \alpha_2, \alpha_1^\vee \rangle = -1$. Verified: the Cartan integer$A_{21} = -1$.

**Example 3.** For $\mathfrak{sl}_3$, the$\alpha_1$-string through$-\alpha_2$:$-\alpha_2, -\alpha_2 + \alpha_1 = \alpha_1 - \alpha_2$... but$\alpha_1 - \alpha_2$ is not a root in$A_2$. So the string has length 1: just$-\alpha_2$. One computes$\langle -\alpha_2, \alpha_1^\vee \rangle = -\langle \alpha_2, \alpha_1^\vee \rangle = 1$, so$p = 0$,$q = -1$... actually the string starts at$-\alpha_2$ and goes up with$q$ steps: from$-\alpha_2 - q\alpha_1 = -\alpha_2$ ($q = 0$ since cannot subtract$\alpha_1$ from$-\alpha_2$ to get a root) to$-\alpha_2 + p\alpha_1$, where$p = \langle -\alpha_2, -\alpha_1^\vee \rangle + q$... let us just note$p - q = \langle -\alpha_2, \alpha_1^\vee \rangle = 1$. Since$-\alpha_2 + \alpha_1 = \alpha_1 - \alpha_2$ is not a root,$p = 1$ and$q = 0$.

**Example 4.** For $G_2$ (exceptional, rank 2): the root system has 6 short and 6 long roots. The long root string through the short simple root$\alpha_s$ (adjacent to the long simple root$\alpha_l$ in the Dynkin diagram with triple bond) has Cartan integer$\langle \alpha_s, \alpha_l^\vee \rangle = -1$, while$\langle \alpha_l, \alpha_s^\vee \rangle = -3$. This means the$\alpha_s$-string through$\alpha_l$ has length$1 - (-3) + 1 = ?$... specifically$p - q = 3$, so if$p = 3, q = 0$: the string$\{\alpha_l, \alpha_l + \alpha_s, \alpha_l + 2\alpha_s, \alpha_l + 3\alpha_s\}$ has length 4. This large root string length (only possible in$G_2$ for simple Lie algebras) is what makes$G_2$ exceptional.

The $\mathfrak{sl}_2$-triple technique, applied systematically, produces all the structure constants of$\mathfrak{g}$ from the root system data, leading directly to the Chevalley basis (Section 49.4.1) and Serre's presentation (Section 49.4.2).
