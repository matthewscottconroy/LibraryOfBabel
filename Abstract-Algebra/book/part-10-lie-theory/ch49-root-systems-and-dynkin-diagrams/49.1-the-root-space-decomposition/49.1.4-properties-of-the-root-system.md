# 49.1.4 Properties of the Root System

The root set $\Phi$ extracted from a semisimple Lie algebra is not just any finite set of vectors in$\mathfrak{h}^*$: it satisfies a collection of properties that can be verified from the Lie algebra structure. Using the Killing form to identify$\mathfrak{h}^*$ with a real inner product space$\mathbb{R}^\ell$ where$\ell = \mathrm{rank}(\mathfrak{g})$, the root system satisfies four fundamental properties.

First, $\Phi$ spans$\mathfrak{h}^* \cong \mathbb{R}^\ell$ — the roots are sufficiently numerous to detect every direction in the weight space. Second, if$\alpha \in \Phi$ then$-\alpha \in \Phi$, and no other scalar multiple$n\alpha$ for$|n| \geq 2$ is a root — roots come in opposite pairs, and no root is a longer or shorter copy of another root. Third, for any two roots$\alpha$ and$\beta$, the Cartan integer$\langle \beta, \alpha^\vee \rangle = 2\langle \beta, \alpha \rangle / \langle \alpha, \alpha \rangle$ is an integer. This is the integrality condition, ultimately a consequence of$\mathfrak{sl}_2$-representation theory: the weight of$\beta$ in the$\mathfrak{sl}_2$-module determined by$\alpha$ must be integral. Fourth, the reflection$s_\alpha(\beta) = \beta - \langle \beta, \alpha^\vee \rangle \alpha$ sends$\Phi$ to$\Phi$ for every root$\alpha$. This reflection is a Euclidean reflection through the hyperplane perpendicular to$\alpha$, and the closure of$\Phi$ under these reflections is a strong geometric symmetry.

The key insight is that these four properties can be abstracted away from the Lie algebra entirely, yielding the definition of an abstract root system (Section 49.2.1). This abstraction is powerful: it means that root systems can be classified as purely geometric/combinatorial objects, independently of any Lie algebra, and then the classification of Lie algebras follows from the classification of root systems.

The integrality condition severely restricts the possible angles between roots: $\langle \beta, \alpha^\vee \rangle \langle \alpha, \beta^\vee \rangle = 4\cos^2\theta \in \{0, 1, 2, 3\}$, meaning the only possible angles between roots are$30°$,$45°$,$60°$,$90°$,$120°$,$135°$, and$150°$. This small list of possibilities is what makes the classification finite. The product$\langle \beta, \alpha^\vee \rangle \langle \alpha, \beta^\vee \rangle$ being an integer in$\{0,1,2,3\}$ also determines the length ratio: if$\langle \beta, \alpha^\vee \rangle = -k$ and$\langle \alpha, \beta^\vee \rangle = -1$, then$|\alpha|^2 / |\beta|^2 = k$.

There are also important properties about how roots interact with the bracket: $[\mathfrak{g}_\alpha, \mathfrak{g}_{-\alpha}] = \mathbb{C} \cdot h_\alpha$ (1-dimensional, spanned by the coroot), and for$\alpha + \beta \neq 0$:$[\mathfrak{g}_\alpha, \mathfrak{g}_\beta] = \mathfrak{g}_{\alpha + \beta}$ if$\alpha + \beta \in \Phi$, and$[\mathfrak{g}_\alpha, \mathfrak{g}_\beta] = 0$ if$\alpha + \beta \notin \Phi \cup \{0\}$.

**Example 1.** For $A_1 = \{\pm\alpha\}$ (the root system of$\mathfrak{sl}_2$):$\langle \alpha, \alpha^\vee \rangle = 2$ (always),$s_\alpha(\alpha) = \alpha - 2\alpha = -\alpha \in \Phi$. The reflection simply negates the root. The only possible angle with itself is$0°$ (same root) or$180°$ (opposite root).

**Example 2.** For $A_2$ (root system of$\mathfrak{sl}_3$): 6 roots at angles$60°$ apart. The angle between$\alpha_1$ and$\alpha_2$ is$120°$ (they are simple roots with a single edge in the Dynkin diagram). We have$\langle \alpha_1, \alpha_2^\vee \rangle = -1$,$\langle \alpha_2, \alpha_1^\vee \rangle = -1$ (equal, since all roots have the same length in$A_n$). Product:$(-1)(-1) = 1 = 4\cos^2(120°) = 4 \cdot 1/4$. Confirmed.

**Example 3.** For $B_2$ (root system of$\mathfrak{so}(5)$): 8 roots, with simple roots$\alpha_1$ (long) and$\alpha_2$ (short) at$135°$. The Cartan integers:$\langle \alpha_2, \alpha_1^\vee \rangle = -1$,$\langle \alpha_1, \alpha_2^\vee \rangle = -2$. Product:$(-1)(-2) = 2 = 4\cos^2(135°) = 4 \cdot 1/2$. The length ratio:$|\alpha_1|/|\alpha_2| = \sqrt{2}$ (long root is$\sqrt{2}$ times the short root). The reflection$s_{\alpha_1}(\alpha_2) = \alpha_2 - (-1)\alpha_1 = \alpha_1 + \alpha_2 \in \Phi$. Confirmed: reflections preserve$\Phi$.

**Example 4.** Property 2 (no multiples as roots) is specific to Lie algebras over $\mathbb{C}$: for$\mathfrak{g}$ semisimple, if$\alpha \in \Phi$ then$2\alpha \notin \Phi$. The argument: if both$\alpha$ and$2\alpha$ were roots, then$\mathfrak{g}_{2\alpha}$ would be a weight space in the$\mathfrak{sl}_2$-module for$\alpha$ with weight$2 \cdot \langle 2\alpha, \alpha^\vee \rangle / 2 = 4$... one derives a contradiction from the representation theory of$\mathfrak{sl}_2$ by showing the weight-4 space must appear only from weight$2 = \langle \alpha, \alpha^\vee \rangle$, but this forces$\mathfrak{g}_{2\alpha} = 0$.

These four properties are the complete and sufficient characterization: any root system satisfying them arises from a semisimple Lie algebra, and the root system determines the Lie algebra completely. This is the content of the reconstruction theorem in Section 49.4.3.
