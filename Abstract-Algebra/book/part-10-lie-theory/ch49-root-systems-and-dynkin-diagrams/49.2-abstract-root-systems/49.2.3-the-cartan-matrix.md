# 49.2.3 The Cartan Matrix $A_{ij} = \langle \alpha_i, \alpha_j^\vee \rangle$

Once a set of simple roots $\alpha_1, \ldots, \alpha_\ell$ is chosen, the root system is determined by a finite matrix of integers. The *Cartan matrix* is the$\ell \times \ell$ integer matrix with entries$A_{ij} = \langle \alpha_i, \alpha_j^\vee \rangle = 2\langle \alpha_i, \alpha_j \rangle / \langle \alpha_j, \alpha_j \rangle$. The entry$A_{ij}$ measures how many times the simple root$\alpha_j$ contributes to the reflection of$\alpha_i$: the reflection$s_{\alpha_j}(\alpha_i) = \alpha_i - A_{ij} \alpha_j$ is again in$\Phi$. In this sense the Cartan matrix records the "overlap" between simple roots, normalized by the length of the root being reflected over.

The diagonal entries are always $A_{ii} = 2$, since$\langle \alpha_i, \alpha_i^\vee \rangle = 2\langle \alpha_i, \alpha_i \rangle / \langle \alpha_i, \alpha_i \rangle = 2$. The off-diagonal entries$A_{ij}$ for$i \neq j$ are non-positive integers (since simple roots have obtuse angles between them), and the integrality constraint forces$A_{ij} \in \{0, -1, -2, -3\}$. Moreover, the product$A_{ij} A_{ji}$ equals$4\cos^2\theta_{ij}$ where$\theta_{ij}$ is the angle between$\alpha_i$ and$\alpha_j$, so$A_{ij} A_{ji} \in \{0, 1, 2, 3\}$. This tight constraint is what makes the classification finite.

The Cartan matrix encodes all information about the root system: from $A$ one can recover the angles and length ratios of the simple roots, then apply simple reflections to generate all roots. However, the Cartan matrix is not symmetric in general —$A_{ij} \neq A_{ji}$ when$\alpha_i$ and$\alpha_j$ have different lengths (one being longer than the other by a factor of$\sqrt{2}$ or$\sqrt{3}$). This asymmetry is important: it distinguishes, for example, the root systems$B_n$ and$C_n$, which have the same Dynkin diagram shape but with the arrow pointing in opposite directions.

The Cartan matrix is uniquely determined (up to simultaneous permutation of rows and columns, which corresponds to relabeling the simple roots) by the choice of simple roots. Conversely, given the Cartan matrix one can reconstruct the root system completely: the simple roots are placed in a Euclidean space with inner products read off from $A$, and then all positive roots are generated by applying simple reflections.

**Example 1.** For $A_1$: the$1 \times 1$ Cartan matrix is$A = (2)$. This encodes the single simple root and its self-pairing.

**Example 2.** For $A_2$ ($\mathfrak{sl}_3$):$A = \begin{pmatrix} 2 & -1 \\ -1 & 2 \end{pmatrix}$. Off-diagonal:$A_{12} = \langle \alpha_1, \alpha_2^\vee \rangle = -1$,$A_{21} = \langle \alpha_2, \alpha_1^\vee \rangle = -1$. The matrix is symmetric, reflecting the fact that all roots in$A_n$ have the same length.$A_{12} A_{21} = 1$, giving$4\cos^2\theta = 1$, so$\cos^2\theta = 1/4$,$\theta = 120°$. Correct for adjacent nodes in$A_2$.

**Example 3.** For $B_2$ ($\mathfrak{so}(5)$ or$\mathfrak{sp}(4)$):$A = \begin{pmatrix} 2 & -1 \\ -2 & 2 \end{pmatrix}$. Here$A_{12} = -1$,$A_{21} = -2$, giving product$2$, so$4\cos^2\theta = 2$,$\theta = 135°$. The length ratio:$|\alpha_1|^2 / |\alpha_2|^2 = A_{21}/A_{12} = 2$, so$|\alpha_1|/|\alpha_2| = \sqrt{2}$ (the first root is longer). This agrees with the$B_2$ root system.

**Example 4.** For $G_2$:$A = \begin{pmatrix} 2 & -1 \\ -3 & 2 \end{pmatrix}$. Here$A_{12} = -1$,$A_{21} = -3$, product$3$, so$4\cos^2\theta = 3$,$\theta = 150°$. Length ratio:$|\alpha_1|^2/|\alpha_2|^2 = 3$, so$|\alpha_1|/|\alpha_2| = \sqrt{3}$. The second simple root is shorter by a factor of$\sqrt{3}$. This is the most "extreme" root system — the triple bond in the Dynkin diagram corresponds to this$A_{21} = -3$.

The Cartan matrix is the concrete data from which everything about the Lie algebra is computed: the root system, the Weyl group, the dimensions of representations, and the structure constants via Serre's relations (Section 49.4.2).
