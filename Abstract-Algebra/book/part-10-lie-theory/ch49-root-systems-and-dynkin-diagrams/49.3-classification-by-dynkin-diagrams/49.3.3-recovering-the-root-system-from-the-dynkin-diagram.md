# 49.3.3 Recovering the Root System from the Dynkin Diagram

The Dynkin diagram determines the Cartan matrix, and the Cartan matrix determines the simple roots up to isometry. From this data, one can reconstruct the entire root system by a systematic procedure. The simple roots $\alpha_1, \ldots, \alpha_\ell$ are placed in a Euclidean space$V \cong \mathbb{R}^\ell$ with inner products$\langle \alpha_i, \alpha_j \rangle$ read off from$A_{ij}$ (using the relation$A_{ij} = 2\langle \alpha_i, \alpha_j \rangle / \langle \alpha_j, \alpha_j \rangle$ and the length information encoded by arrows). The positive roots are then generated by applying simple reflections: one starts with the simple roots themselves and repeatedly reflects through the hyperplanes$H_{\alpha_i}$, generating new roots until the process closes.

This generation process is finite because the root system is finite: each application of a simple reflection either produces a root already seen or produces a new positive root, and the number of positive roots is bounded by $|\Phi^+|$. The total number of positive roots is$|\Phi^+| = \ell(w_0)$, the length of the longest element of the Weyl group, since$w_0$ sends every positive root to a negative root and does so minimally. For the type$A_n$ root system, the positive roots are$\alpha_i + \alpha_{i+1} + \cdots + \alpha_j$ for all$1 \leq i \leq j \leq n$, giving$|\Phi^+| = \binom{n+1}{2}$, which equals$\ell(w_0)$ for$W = S_{n+1}$ (the number of inversions in the longest permutation).

The reconstruction procedure reveals the full combinatorial richness of the root system. For $A_2$ (rank 2, Dynkin diagram with one edge), one recovers six roots arranged as the vertices of a regular hexagon, with the Weyl group$S_3$ acting as the symmetry group of the hexagon. For$G_2$ (rank 2, triple edge), the twelve roots form two concentric regular hexagons of different radii, with the Weyl group acting as the dihedral group of order 12. In higher ranks, the geometry becomes much more complex, but the principle is the same: the Dynkin diagram, through the Cartan matrix, completely determines where the roots sit in Euclidean space.

The reconstruction also gives a recursive structure: for type $A_n$, the positive roots are exactly the "intervals"$[\alpha_i, \alpha_j] = \alpha_i + \cdots + \alpha_j$ in the Dynkin diagram. This visual simplicity is one reason type$A_n$ is the most computationally tractable — its root system and representation theory can often be described in terms of the combinatorics of intervals in$\{1, \ldots, n+1\}$.

**Example 1.** Recover the root system of $A_2$ from its Dynkin diagram: simple roots$\alpha_1, \alpha_2$ with$|\alpha_1| = |\alpha_2| = 1$ and$\langle \alpha_1, \alpha_2 \rangle = -1/2$ (angle$120°$, one edge). Apply$s_{\alpha_1}$ to$\alpha_2$:$s_{\alpha_1}(\alpha_2) = \alpha_2 - \langle \alpha_2, \alpha_1^\vee \rangle \alpha_1 = \alpha_2 - (-1)\alpha_1 = \alpha_1 + \alpha_2$. Apply$s_{\alpha_2}$ to$\alpha_1$:$\alpha_1 + \alpha_2$. Now$s_{\alpha_1}(\alpha_1 + \alpha_2) = (\alpha_1 + \alpha_2) - 2\alpha_1 = \alpha_2 - \alpha_1$... this is$-(\alpha_1 - \alpha_2)$... wait, let us recompute:$s_{\alpha_1}(\alpha_1 + \alpha_2) = \alpha_1 + \alpha_2 - \langle \alpha_1+\alpha_2, \alpha_1^\vee \rangle \alpha_1 = \alpha_1 + \alpha_2 - (2 + (-1))\alpha_1 = \alpha_2$. So the process generates$\{\alpha_1, \alpha_2, \alpha_1 + \alpha_2\}$ as positive roots (correct,$|\Phi^+| = 3$ for$A_2$).

**Example 2.** Recover $B_2$: simple roots$\alpha_1$ (long, length$\sqrt{2}$) and$\alpha_2$ (short, length 1) with$A_{12} = -1$,$A_{21} = -2$. Apply$s_{\alpha_2}$ to$\alpha_1$:$\alpha_1 - A_{12}\alpha_2 = \alpha_1 + \alpha_2$. Apply$s_{\alpha_1}$ to$\alpha_2$:$\alpha_2 - A_{21}\alpha_1 = \alpha_2 + 2\alpha_1$... but$\alpha_2 - (-2)\alpha_1 = 2\alpha_1 + \alpha_2$. The 4 positive roots:$\alpha_1$ (long),$\alpha_2$ (short),$\alpha_1 + \alpha_2$ (short),$2\alpha_1 + \alpha_2$... let me verify:$|2\alpha_1 + \alpha_2|^2 = 4|\alpha_1|^2 + 4\langle\alpha_1,\alpha_2\rangle + |\alpha_2|^2 = 4 \cdot 2 + 4(-1) + 1 = 5$... actually for$B_2$ in standard coordinates$\alpha_1 = e_1 - e_2$,$\alpha_2 = e_2$, so positive roots are$e_1 - e_2$,$e_2$,$e_1$,$e_1 + e_2$.

**Example 3.** Recover $G_2$: simple roots$\alpha_1$ (long) and$\alpha_2$ (short) with$A_{12} = -1$,$A_{21} = -3$, and lengths$|\alpha_1|^2 = 3$,$|\alpha_2|^2 = 1$. Starting: apply$s_{\alpha_2}$ to$\alpha_1$:$\alpha_1 + \alpha_2$. Apply$s_{\alpha_1}$ to$\alpha_2$:$\alpha_2 + 3\alpha_1$. Continue:$2\alpha_1 + \alpha_2$,$3\alpha_1 + \alpha_2$,$3\alpha_1 + 2\alpha_2$. Six positive roots total:$\alpha_1, \alpha_2, \alpha_1 + \alpha_2, 2\alpha_1 + \alpha_2, 3\alpha_1 + \alpha_2, 3\alpha_1 + 2\alpha_2$.

**Example 4.** The highest root: in each root system, there is a unique root $\theta$ that is the maximum in the root partial order. For$A_n$:$\theta = \alpha_1 + \cdots + \alpha_n$. For$B_n$:$\theta = \alpha_1 + 2\alpha_2 + \cdots + 2\alpha_n$ (long, height$2n-1$). For$E_8$:$\theta = 2\alpha_1 + 3\alpha_2 + 4\alpha_3 + 5\alpha_4 + 6\alpha_5 + 4\alpha_6 + 2\alpha_7 + 3\alpha_8$ (height 29, the highest root of$E_8$). The Coxeter number$h = \langle \theta + \rho, \rho^\vee \rangle$ is a fundamental invariant.

The reconstruction from the Dynkin diagram is entirely explicit and algorithmic, and it shows that the classification of simple Lie algebras is genuinely constructive: each of the nine types gives a concrete root system, from which the Lie algebra can be written down via generators and relations (Serre's relations, Section 49.4.2).
