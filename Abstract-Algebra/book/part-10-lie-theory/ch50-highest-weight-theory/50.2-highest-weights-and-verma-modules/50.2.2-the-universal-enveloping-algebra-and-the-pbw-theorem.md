# 50.2.2 The Universal Enveloping Algebra $\mathcal{U}(\mathfrak{g})$ and the PBW Theorem

To make the study of Lie algebra representations into a module-theoretic problem, one passes from the Lie algebra $\mathfrak{g}$ to an associative algebra whose modules are precisely the$\mathfrak{g}$-representations. The *universal enveloping algebra*$\mathcal{U}(\mathfrak{g})$ serves this role: it is the associative algebra generated by$\mathfrak{g}$ subject to the single relation$XY - YX = [X,Y]$ for all$X, Y \in \mathfrak{g}$. This relation is exactly what forces a module over$\mathcal{U}(\mathfrak{g})$ to be the same thing as a Lie algebra representation of$\mathfrak{g}$. The passage from$\mathfrak{g}$ to$\mathcal{U}(\mathfrak{g})$ is universal: any Lie algebra homomorphism$\mathfrak{g} \to A$ (where$A$ is an associative algebra with the commutator bracket) extends uniquely to an algebra homomorphism$\mathcal{U}(\mathfrak{g}) \to A$.

The fundamental structural theorem about $\mathcal{U}(\mathfrak{g})$ is the *Poincaré–Birkhoff–Witt theorem*: if$X_1, \ldots, X_n$ is any ordered basis of$\mathfrak{g}$, then the monomials$X_1^{a_1} \cdots X_n^{a_n}$ with$a_i \geq 0$ form a vector space basis of$\mathcal{U}(\mathfrak{g})$. The content of PBW is that while elements of$\mathcal{U}(\mathfrak{g})$ can be written in many ways due to the commutation relations, ordered monomials give a canonical normal form. In particular,$\mathcal{U}(\mathfrak{g})$ is infinite-dimensional as a vector space (unless$\mathfrak{g} = 0$) but has a well-understood basis.

The key consequence for representation theory is that $\mathcal{U}(\mathfrak{g})$ has a triangular decomposition mirroring that of$\mathfrak{g}$. Using the PBW theorem with an ordering where negative root vectors come first, then Cartan elements, then positive root vectors, one obtains$\mathcal{U}(\mathfrak{g}) \cong \mathcal{U}(\mathfrak{n}^-) \otimes \mathcal{U}(\mathfrak{h}) \otimes \mathcal{U}(\mathfrak{n}^+)$ as vector spaces. This means that acting on a highest weight vector (which is annihilated by$\mathcal{U}(\mathfrak{n}^+)$ and is a weight vector for$\mathcal{U}(\mathfrak{h})$) by$\mathcal{U}(\mathfrak{g})$ is the same as acting by$\mathcal{U}(\mathfrak{n}^-)$, that is, by products of lowering operators$f_\alpha$.

The PBW basis for $\mathcal{U}(\mathfrak{n}^-)$ then gives explicit spanning sets for highest weight modules. For$\mathfrak{sl}_2$:$\mathcal{U}(\mathfrak{n}^-) = \{f^n : n \geq 0\}$, so a Verma module$M(\lambda)$ has basis$\{f^n v_\lambda : n \geq 0\}$ — an infinite-dimensional module with weights$\lambda, \lambda - 2, \lambda - 4, \ldots$ going all the way to$-\infty$.

**Example 1.** $\mathcal{U}(\mathfrak{sl}_2)$: generated by$e, f, h$ with relations$he - eh = 2e$,$hf - fh = -2f$,$ef - fe = h$. PBW basis:$\{f^a h^b e^c : a, b, c \geq 0\}$. The element$fe - ef = -h$ can be rewritten as$fe = ef - h$, allowing one to always move$e$'s to the right of$f$'s.

**Example 2.** For $\mathfrak{sl}_3$:$\mathcal{U}(\mathfrak{sl}_3)$ has PBW basis$\{f_{\alpha_1}^{a_1} f_{\alpha_2}^{a_2} f_{\alpha_1+\alpha_2}^{a_3} h_1^{b_1} h_2^{b_2} e_{\alpha_1}^{c_1} e_{\alpha_2}^{c_2} e_{\alpha_1+\alpha_2}^{c_3} : a_i, b_j, c_k \geq 0\}$ (in some fixed ordering of the root vectors). This is the PBW normal form.

**Example 3.** The Casimir element in $\mathcal{U}(\mathfrak{sl}_2)$:$C = h^2 + 2ef + 2fe = h^2 + 4ef + 2(-h) = h^2 + 4ef - 2h$... the standard form is$C = h^2/2 + fe + ef = h^2/2 + 2fe + h$ (depending on normalization). In any form,$C$ is central in$\mathcal{U}(\mathfrak{sl}_2)$:$[h, C] = [e, C] = [f, C] = 0$. On$V_n$,$C$ acts by$n(n+2)/2$ times the identity (or some similar formula depending on normalization), confirming Schur's lemma.

**Example 4.** The universal property: the adjoint representation $\mathrm{ad}: \mathfrak{sl}_2 \to \mathfrak{gl}(\mathfrak{sl}_2)$ extends to an algebra homomorphism$\mathcal{U}(\mathfrak{sl}_2) \to \mathfrak{gl}(\mathfrak{sl}_2)$, the "adjoint action" of$\mathcal{U}$ on$\mathfrak{g}$. The element$C$ maps to the Casimir operator on the adjoint representation, which acts on$V_2 \cong \mathfrak{sl}_2$ by the scalar$2(2+2)/2 = 4$ (or the appropriate value for the spin-1 representation).

The universal enveloping algebra is the algebraic machine that converts representation theory into module theory, enabling the use of all the machinery of ring theory (Noetherian rings, projective modules, derived categories) in the study of Lie algebra representations.
