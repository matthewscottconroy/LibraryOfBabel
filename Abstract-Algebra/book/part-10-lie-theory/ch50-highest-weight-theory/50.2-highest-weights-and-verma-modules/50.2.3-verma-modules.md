# 50.2.3 Verma Modules $M(\lambda) = \mathcal{U}(\mathfrak{g}) \otimes_{\mathcal{U}(\mathfrak{b})} k_\lambda$

For any $\lambda \in \mathfrak{h}^*$ — not yet required to be dominant or integral — one can ask: what is the "largest" or "freest" possible$\mathfrak{g}$-module with a highest weight vector of weight$\lambda$? The answer is the Verma module. It is the analogue of a free module in ring theory: imposing only the minimal constraints, it is the universal object from which all other highest weight modules are obtained as quotients.

The construction is by induction. The Borel subalgebra is $\mathfrak{b} = \mathfrak{h} \oplus \mathfrak{n}^+$, where$\mathfrak{n}^+ = \bigoplus_{\alpha > 0} \mathfrak{g}_\alpha$ is the nilpotent radical. One defines a one-dimensional$\mathfrak{b}$-module$k_\lambda$ by having$\mathfrak{n}^+$ act by zero and$\mathfrak{h}$ act by the functional$\lambda$. The *Verma module* is then$M(\lambda) = \mathcal{U}(\mathfrak{g}) \otimes_{\mathcal{U}(\mathfrak{b})} k_\lambda$, the module induced from$k_\lambda$ up to$\mathfrak{g}$. Its generator$v_\lambda = 1 \otimes 1$ is a highest weight vector of weight$\lambda$, and the universal property ensures that every$\mathfrak{g}$-module with a highest weight vector of weight$\lambda$ is a quotient of$M(\lambda)$.

By the PBW theorem, $M(\lambda)$ has a vector space basis$\{f_{\alpha_1}^{a_1} \cdots f_{\alpha_N}^{a_N} v_\lambda : a_i \geq 0\}$, where$\alpha_1, \ldots, \alpha_N$ are the positive roots in some fixed order and the$a_i$ are non-negative integers. Each basis vector$f_{\alpha_1}^{a_1} \cdots f_{\alpha_N}^{a_N} v_\lambda$ is a weight vector of weight$\lambda - \sum a_i \alpha_i$, so$M(\lambda)$ decomposes into weight spaces, all of which lie at or below$\lambda$ in the weight order. Every weight space$M(\lambda)_\mu$ is finite-dimensional (its dimension is the number of ways to write$\lambda - \mu$ as a non-negative integer combination of positive roots — the *Kostant partition function*), and$M(\lambda)_\lambda$ is one-dimensional, spanned by$v_\lambda$.

The Verma module is generally infinite-dimensional, but it contains the finite-dimensional irreducible $L(\lambda)$ as a quotient when$\lambda$ is dominant integral. The structure of Verma modules and their submodules is a rich topic in its own right (the Bernstein–Gelfand–Gelfand theory and the Kazhdan–Lusztig conjecture), but for the purposes of classifying finite-dimensional representations, the key fact is that each Verma module has a unique irreducible quotient.

**Example 1.** For $\mathfrak{sl}_2$ and$\lambda = n$ (a non-negative integer):$M(n)$ has basis$\{f^k v_n : k \geq 0\}$, with$h \cdot f^k v_n = (n-2k) f^k v_n$. The element$f^{n+1} v_n$ generates a proper submodule (it is annihilated by$e$, since$e f^{n+1} v_n = (n+1)(n-(n+1)+1)f^n v_n = 0$). The irreducible quotient$L(n) = M(n)/M(n-2)$ is the$(n+1)$-dimensional irreducible$V_n$.

**Example 2.** For $\mathfrak{sl}_2$ and$\lambda = -1/2$ (not integral):$M(-1/2)$ is irreducible (it has no proper submodules), and it is infinite-dimensional. This is a "Verma module which is already irreducible" — no finite-dimensional quotient exists since$-1/2$ is not a non-negative integer.

**Example 3.** For $\mathfrak{sl}_3$ and$\lambda = \omega_1$ (first fundamental weight):$M(\omega_1)$ has basis$\{f_{\alpha_1}^{a_1} f_{\alpha_2}^{a_2} f_{\alpha_1+\alpha_2}^{a_3} v_{\omega_1} : a_i \geq 0\}$ (infinite-dimensional). The irreducible quotient$L(\omega_1) = \mathbb{C}^3$ is 3-dimensional. The maximal proper submodule$J(\omega_1)$ is generated by$f_{\alpha_1}^2 v_{\omega_1}$ (since$\langle \omega_1, \alpha_1^\vee \rangle = 1$, the vector$f_{\alpha_1}^2 v_{\omega_1}$ is a highest weight vector of weight$\omega_1 - 2\alpha_1 = -\omega_1 + \omega_2$) and$f_{\alpha_2} v_{\omega_1}$ (since$\langle \omega_1, \alpha_2^\vee \rangle = 0$,$f_{\alpha_2} v_{\omega_1}$ is a highest weight vector).

**Example 4.** The Kostant partition function $p(\mu)$ for$\mathfrak{sl}_2$:$p(n) = 1$ for$n \geq 0$ even,$0$ for$n < 0$ — the number of ways to write$n$ as a non-negative integer multiple of$2$ (the single positive root). So$\dim M(\lambda)_{\lambda - 2k} = 1$ for all$k \geq 0$. For$\mathfrak{sl}_3$: the partition function$p(a\alpha_1 + b\alpha_2)$ counts the number of ways to write$a\alpha_1 + b\alpha_2$ as a non-negative integer combination of$\alpha_1, \alpha_2, \alpha_1+\alpha_2$ — this is the number of triples$(c_1, c_2, c_3)$ with$c_1 + c_3 = a$,$c_2 + c_3 = b$,$c_i \geq 0$, which equals$\min(a, b) + 1$.

The Verma module is the "universal" highest weight module — it is the most natural construction one can make from a highest weight, and understanding its structure (in particular its submodule structure and the irreducible quotient) is the heart of highest weight theory.
