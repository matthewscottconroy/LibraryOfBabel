# 51.2.1 Block Decomposition of $k[G]$

Even though the group algebra $k[G]$ in characteristic$p \mid |G|$ is far from semisimple, it still admits a decomposition that organizes the module category into independent sectors. The *block decomposition* achieves this: it breaks$k[G]$ into indecomposable two-sided ideals — the blocks — and the representation theory of$k[G]$ splits accordingly into independent pieces. This is the coarser organizational principle that replaces the simple module classification in the modular setting.

The block decomposition arises from the center $Z(k[G])$. A central element$e \in Z(k[G])$ with$e^2 = e$ is an *idempotent*, and if$e$ is also *primitive* (not expressible as a sum of two orthogonal idempotents), the two-sided ideal$B = k[G]e$ is indecomposable as a two-sided ideal. The identity$1 \in Z(k[G])$ can be uniquely written as$1 = e_1 + e_2 + \cdots + e_r$ where the$e_i$ are primitive central idempotents with$e_i e_j = 0$ for$i \neq j$. This gives the block decomposition$k[G] = B_1 \oplus B_2 \oplus \cdots \oplus B_r$ with$B_i = k[G]e_i$. The blocks$B_i$ are the *blocks of$k[G]$*, and each is itself an indecomposable algebra.

The center $Z(k[G])$ is spanned by class sums: for each conjugacy class$\mathcal{C} \subset G$, the element$\hat{\mathcal{C}} = \sum_{g \in \mathcal{C}} g$ lies in$Z(k[G])$. The primitive central idempotents of$k[G]$ are more subtle to describe explicitly than in the semisimple case; in characteristic 0, they are given by the orthogonality relations for characters, but in characteristic$p$, the Idempotents can only be described modulo the Jacobson radical. The key point is that$Z(k[G])/J(Z(k[G]))$ is a semisimple commutative algebra, and its minimal idempotents lift (non-uniquely) to primitive central idempotents of$k[G]$ by a standard lifting theorem for idempotents over local rings.

Every $k[G]$-module$M$ decomposes canonically as$M = e_1 M \oplus e_2 M \oplus \cdots \oplus e_r M$, and each component$e_i M$ is either all of$M$ or zero — if$M$ is indecomposable, it belongs to exactly one block. In particular, every simple module, every PIM, and every ordinary irreducible character (via the ring map$Z(k[G]) \to Z(k[G]/J(k[G]))$) belongs to exactly one block. Two indecomposable modules belong to the same block if and only if they can be connected by a chain of indecomposable modules sharing a common composition factor. This transitivity condition makes the block decomposition well-defined and is the correct equivalence relation on modules in the modular setting.

The number of blocks equals the number of primitive central idempotents, which equals $\dim_k Z(k[G]/J(k[G]))$, which equals the number of simple$k[G]$-modules. But the blocks themselves have varying sizes and complexity, measured by their *defect groups* (see \S51.2.2). Blocks of *defect 0* — those that contain a single simple module that is also projective — are particularly clean: they are matrix algebras, and the representation theory within such a block is as simple as the semisimple case.

A crucial feature of the block decomposition is that it also applies to ordinary (characteristic 0) representations, via the ring map $Z(\mathcal{O}[G]) \to Z(k[G])$ (where$\mathcal{O}$ is the ring of integers of a$p$-adic field). The reduction modulo$p$ sends ordinary irreducible characters to Brauer characters, and this reduction respects blocks: an ordinary irreducible character belongs to the same block as a Brauer character if and only if its reduction modulo$p$ involves that Brauer character as a composition factor. This compatibility means the block structure partitions both the ordinary and modular character tables, a powerful organizational tool for computing decomposition matrices.

\begin{example}
For $G = \mathbb{Z}/p\mathbb{Z}$ (a cyclic group of prime order$p$) and$k = \mathbb{F}_p$, the group algebra$k[G] \cong k[x]/(x-1)^p$ is a local ring. Being local, it has a unique primitive central idempotent:$e_1 = 1$. So there is only one block, and$k[G]$ itself is the unique block. All$p$ ordinary irreducible characters (the characters$\chi_j: g \mapsto \zeta_p^j$ for$j = 0, 1, \ldots, p-1$, where$\zeta_p$ is a$p$-th root of unity) belong to this single block. There is also only one Brauer character (the trivial character), since all elements have order$p$ and hence no non-identity element is$p$-regular.
\end{example}

\begin{example}
For $G = S_4$ (the symmetric group) and$k = \mathbb{F}_2$, the group has order 24. The number of simple$k[G]$-modules equals the number of$2$-regular conjugacy classes (those with elements of odd order). The conjugacy classes of$S_4$ have cycle types$1^4$,$2^1 1^2$,$2^2$,$3^1 1^1$,$4^1$, with orders 1, 2, 2, 3, 4. The$2$-regular classes (odd order elements) are those of types$1^4$ (order 1) and$3^1 1^1$ (order 3), giving two simple modules. One can show that the two simples belong to two different blocks: the trivial module to the principal block (the block containing the trivial character), and the other simple to a second block. The principal block contains most of the ordinary irreducible characters, while the second block contains those ordinary characters that reduce to the non-trivial simple modulo 2.
\end{example}

\begin{example}
For $G = A_5$ (the alternating group on 5 letters) and$k = \mathbb{F}_5$, we have$|G| = 60 = 4 \cdot 3 \cdot 5$, so$p = 5 \mid |G|$. The ordinary character table of$A_5$ has five irreducible characters (the trivial, two 3-dimensional, the 4-dimensional, and the 5-dimensional). The$5$-regular conjugacy classes of$A_5$ are those with elements of order not divisible by 5, i.e., orders 1, 2, 3. There are three such classes (identity, 2-cycles-type, 3-cycles-type ... for$A_5$, the conjugacy classes have orders 1, 2, 3, 5, 5), giving three simple modular representations. The block decomposition: the principal block contains the trivial character and some other ordinary characters; by Brauer's first main theorem (to be discussed in \S51.2.3), the number of blocks and their structure is controlled by the Sylow 5-subgroup$\mathbb{Z}/5\mathbb{Z}$.
\end{example}
