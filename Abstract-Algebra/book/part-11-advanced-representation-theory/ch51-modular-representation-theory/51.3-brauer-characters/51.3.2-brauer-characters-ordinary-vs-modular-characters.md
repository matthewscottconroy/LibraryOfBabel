# 51.3.2 Brauer Characters; Ordinary vs. Modular Characters

In characteristic 0, the character $\chi_V(g) = \mathrm{tr}(g \mid V)$ is the central invariant of a representation, and the character determines the representation up to semisimplification. In characteristic$p$, the trace is not directly useful — it takes values in$k$ and loses information. The Brauer character restores the trace-based invariant by lifting eigenvalues from$k$ to characteristic 0 using the Teichmüller lift.

For a $k[G]$-module$M$ and a *$p$-regular element*$g \in G$ (an element whose order is coprime to$p$), the eigenvalues of$g$ acting on$M$ are roots of unity of order prime to$p$ in$\overline{k}$. This follows because$g$ satisfies$g^m = 1$ where$\gcd(m, p) = 1$, so the minimal polynomial of$g$ on$M$ divides$x^m - 1$, which is separable over$k$ (since$p \nmid m$). Thus$g$ is diagonalizable over$\overline{k}$ with eigenvalues that are roots of unity of order dividing$m$.

The *Teichmüller lift* is the unique multiplicative section $\omega: \overline{k}^\times \to W(\overline{k})^\times$ of the natural projection from the ring of Witt vectors$W(\overline{k})$ to$\overline{k}$, which is a complete discrete valuation ring of characteristic 0 with residue field$\overline{k}$. The Teichmüller lift sends a root of unity$\zeta \in \overline{k}$ (of order$m$ with$p \nmid m$) to the unique root of unity$\hat\zeta \in W(\overline{k})$ of the same order. The *Brauer character*$\phi_M$ is the class function on$p$-regular elements of$G$ defined by
$$\phi_M(g) = \sum_i \hat\lambda_i,$$
where $\lambda_i$ are the eigenvalues of$g$ on$M$ (with multiplicity) in$\overline{k}$, and$\hat\lambda_i$ are their Teichmüller lifts to$W(\overline{k})$.

The Brauer character takes values in the ring of algebraic integers in characteristic 0 (specifically, in the ring of integers of $K$ when we embed$W(\overline{k})$ into an algebraic closure of$\mathbb{Q}_p$). Crucially,$\phi_M$ determines$M$ up to composition factors: if$\phi_M = \phi_N$, then$M$ and$N$ have the same composition factors with the same multiplicities. The Brauer characters of the simple$k[G]$-modules$S_1, \ldots, S_s$ form an orthonormal basis for the space of class functions on$p$-regular elements, directly analogous to the way ordinary irreducible characters$\chi_1, \ldots, \chi_r$ form a basis for class functions on all of$G$.

A crucial structural fact is $s =$ (number of conjugacy classes of$p$-regular elements in$G$), which can be much smaller than the number of all conjugacy classes$r$. The elements of order divisible by$p$ contribute nothing to Brauer characters — the Brauer character is literally not defined on$p$-singular elements. This means the characteristic-$p$ representation theory is "coarser" — fewer isomorphism types of simples — but each simple module can have richer internal structure than in characteristic 0. The interplay between the$r$ ordinary characters and the$s$ Brauer characters is recorded in the decomposition matrix, which we take up next.

The orthogonality relations for Brauer characters are analogous to those for ordinary characters, but involve a different inner product. For Brauer characters of simple modules $\phi_i$ and$\phi_j$, the orthogonality relation takes the form$\langle \phi_i, \phi_j \rangle_p = \delta_{ij}$ where the inner product sums only over$p$-regular elements with appropriate weights. This allows one to read off composition multiplicities from inner products, generalizing the character-theoretic approach to representation theory.

\begin{example}
For $G = S_3$ and$p = 3$, the$p$-regular elements are those of order not divisible by 3. In$S_3$, the elements of order 1 (identity) and order 2 (transpositions like$(12)$) are$3$-regular; the elements of order 3 (three-cycles$(123)$ and$(132)$) are$3$-singular. The Brauer characters are class functions on the two$3$-regular conjugacy classes$\{e\}$ and$\{(12), (13), (23)\}$. The trivial module$S_1$ has$\phi_{S_1}(e) = 1$ and$\phi_{S_1}((12)) = 1$ (the identity acts with eigenvalue 1 and a transposition also acts as$+1$ on the trivial module). The sign module$S_2$ has$\phi_{S_2}(e) = 1$ and$\phi_{S_2}((12)) = -1$ (a transposition acts as$-1$). These two Brauer characters are indeed distinct class functions on the$3$-regular elements, as expected.
\end{example}

\begin{example}
For $G = \mathbb{Z}/p\mathbb{Z}$ (cyclic of prime order$p$) and$k = \mathbb{F}_p$, the only$p$-regular element is the identity$e$ (all non-identity elements have order$p$). Therefore there is exactly one$p$-regular conjugacy class, and there is exactly one Brauer character: the trivial Brauer character$\phi(e) = \dim_k M$. This confirms that there is only one simple$k[G]$-module (the trivial module$k$), and its Brauer character takes the value 1 at$e$.
\end{example}

\begin{example}
For $G = A_5$ and$p = 5$, the elements of$A_5$ have orders 1, 2, 3, 5. The$5$-regular elements are those of order 1, 2, or 3 — there are$1 + 15 + 20 = 36$ such elements in$A_5$, belonging to conjugacy classes$C_1$ (identity, size 1),$C_2$ (double-transpositions, size 15), and$C_3 \cup C_3'$ (two conjugacy classes of 3-cycles, each of size 20). So there are 3$5$-regular conjugacy classes, giving 3 simple$k[A_5]$-modules. The Brauer characters can be computed from the ordinary character table by restricting to$5$-regular elements: the five ordinary irreducibles restricted to$5$-regular elements span only a 3-dimensional space (since 5-regular elements see at most 3 simple modular representations), and the Brauer characters of the simples are the "primitive" elements of this space. One finds that the 1-dimensional trivial, the 3-dimensional standard, and the 4-dimensional representation each give distinct Brauer characters, while the 5-dimensional and other ordinary characters restrict to linear combinations of these three.
\end{example}
