# Chapter 13 — Groups and Subgroups

Introduces concrete finite groups — cyclic, unit, dihedral, symmetric, and the Klein four-group — with Cayley tables, element orders, subgroup enumeration, and centers.

## Usage

### Interactive mode
```
cargo run -p ch13-groups
```

### Non-interactive (scriptable)
```
cargo run -p ch13-groups -- --run <cmd> [args] [--format text|svg|dot|tex|ascii]
```

### Visualize
```
cargo run -p ch13-groups -- --run demo --format svg > output.svg
cargo run -p ch13-groups -- --run demo --format dot | dot -Tpdf > output.pdf
cargo run -p ch13-groups -- --run demo --format tex > output.tex
cargo run -p ch13-groups -- --run demo --format ascii
```

### Persist state
```
cargo run -p ch13-groups -- --run demo --save state.toml
cargo run -p ch13-groups -- --load state.toml --run demo
```

## Commands

| Command | Description |
|---------|-------------|
| `cayley <type> <n>` | Print Cayley table for Z (ℤ/nℤ), U ((ℤ/nℤ)*), D (dihedral D_n), S (symmetric S_3 or S_4), or V (Klein V4) |
| `order <g> <type> <n>` | Compute the order of element g, showing successive powers until the identity |
| `subgroups <type> <n>` | Find all subgroups by exhaustive subset search (groups of order ≤ 24) |
| `is_abelian <type> <n>` | Check commutativity; print a counterexample if non-abelian |
| `elements <type> <n>` | List all elements with their orders |
| `cyclic_gen <type> <n>` | Find all generators (elements whose order equals |G|) |
| `center <type> <n>` | Compute the center Z(G) and report the index [G:Z(G)] |
| `demo` | Showcase: Z/6Z element orders and Z(S_3) |
| `help` | Show help |
| `quit` | Exit |

## Mathematical Content

A group is a set with an associative binary operation, an identity, and inverses; the order of an element g is the smallest k ≥ 1 with gᵏ = e. By Lagrange's theorem the order of any subgroup (and of any element) divides the group order. The center Z(G) = {g : gx = xg for all x} is always a normal subgroup; a group is abelian iff Z(G) = G. The dihedral group D_n of order 2n is generated by a rotation r of order n and a reflection s satisfying srs⁻¹ = r⁻¹.

## Visualizations

- **SVG**: Colored Cayley table for the current group (groups of order ≤ 12), with cells shaded by the parity of the product index and the group order and abelian status shown below.
- **DOT**: Subgroup lattice of the current group, with G at the top and each subgroup as a node labeled by its elements, connected by inclusion edges.
- **TikZ**: LaTeX matrix table of the Cayley multiplication, using the `matrix` library, with |G| and abelian status below.
- **ASCII**: Text Cayley table (up to order 8) with a header row and row labels, followed by order and abelian status.

## Default State

- `group_type`: `"Z"` — cyclic group ℤ/nℤ
- `group_n`: `6` — group parameter n
