# Chapter 21 — Ideals and Quotient Rings

Constructs and analyzes ideals in Z/nZ, including prime and maximal ideals, quotient rings, the nilradical, and field extensions via root adjunction.

## Usage

### Interactive mode
```
cargo run -p ch21-ideals
```

### Non-interactive (scriptable)
```
cargo run -p ch21-ideals -- --run <cmd> [args] [--format text|svg|dot|tex|ascii]
```

### Visualize
```
cargo run -p ch21-ideals -- --run demo --format svg > output.svg
cargo run -p ch21-ideals -- --run demo --format dot | dot -Tpdf > output.pdf
cargo run -p ch21-ideals -- --run demo --format tex > output.tex
cargo run -p ch21-ideals -- --run demo --format ascii
```

### Persist state
```
cargo run -p ch21-ideals -- --run demo --save state.toml
cargo run -p ch21-ideals -- --load state.toml --run demo
```

## Commands

| Command | Description |
|---------|-------------|
| `ideal <n> <k>` | Ideal (k) in Z/nZ: generator gcd(k,n), elements, quotient |
| `quotient <n> <k>` | Build Z/nZ/(k) as a ring and show its multiplication table |
| `is_prime_ideal <n> <k>` | Check if (k) is a prime ideal in Z/nZ |
| `is_maximal <n> <k>` | Check if (k) is a maximal ideal in Z/nZ |
| `adjoin_root <coeffs>` | Describe Q[x]/(f): degree, basis, discriminant |
| `radical <n>` | Nilradical of Z/nZ as intersection of prime ideals |
| `contain <n> <k1> <k2>` | Ideal containment check in Z/nZ |
| `demo` | Showcase ideal examples in Z/12Z |
| `help` | Show this help |
| `quit` | Exit |

## Mathematical Content

In Z/nZ every ideal is principal, generated by a divisor of n, so the ideal lattice is isomorphic to the divisor lattice of n. An ideal (k) is prime when the quotient Z/gcd(k,n)Z is an integral domain (gcd is prime), and maximal when the quotient is a field (same condition over Z). The nilradical equals the intersection of all prime ideals, which in Z/nZ consists exactly of multiples of the radical of n. Adjoining a root of a polynomial f via Q[x]/(f) yields a field extension of degree deg(f) when f is irreducible.

## Visualizations

- **SVG**: Hasse diagram of the ideal lattice of Z/nZ, with nodes labeled by generator and size, positioned by the number of prime factors of the divisor; prime ideals are highlighted.
- **DOT**: The same Hasse diagram in bottom-to-top rank direction, with prime ideal nodes colored distinctly.
- **TikZ**: Hasse diagram nodes arranged by prime-factor level, with cover edges drawn in gray.
- **ASCII**: Linear chain of ideals ordered by generator, followed by a list of prime ideals with their residue fields.

## Default State

- `last_n`: the ring modulus; initial value `12`
- `last_k`: the ideal generator; initial value `3`
