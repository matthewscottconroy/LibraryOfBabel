# Chapter 25 — Modules over Rings

Studies Z-modules concretely via Z/nZ: submodules, torsion elements, annihilators, homomorphism groups, direct sums, free modules, and simple modules.

## Usage

### Interactive mode
```
cargo run -p ch25-modules
```

### Non-interactive (scriptable)
```
cargo run -p ch25-modules -- --run <cmd> [args] [--format text|svg|dot|tex|ascii]
```

### Visualize
```
cargo run -p ch25-modules -- --run demo --format svg > output.svg
cargo run -p ch25-modules -- --run demo --format dot | dot -Tpdf > output.pdf
cargo run -p ch25-modules -- --run demo --format tex > output.tex
cargo run -p ch25-modules -- --run demo --format ascii
```

### Persist state
```
cargo run -p ch25-modules -- --run demo --save state.toml
cargo run -p ch25-modules -- --load state.toml --run demo
```

## Commands

| Command | Description |
|---------|-------------|
| `zmod <n>` | Z/nZ as Z-module: submodules, torsion, annihilator Ann(Z/nZ) |
| `torsion <n>` | Torsion elements of Z/nZ (all of them) with individual annihilators |
| `annihilator <n> <a>` | Ann(a) = {r ∈ Z : r·a = 0} in Z/nZ |
| `submodules <n>` | All submodules of Z/nZ with containment lattice |
| `hom <n> <m>` | Hom_Z(Z/nZ, Z/mZ) = Z/gcd(n,m)Z; enumerate all Z-module maps |
| `direct_sum <n> <m>` | Z/nZ + Z/mZ: elements, annihilator, cyclicity criterion |
| `free <rank>` | Free Z-module Z^r: standard basis, rank |
| `simple <n>` | Simple Z-modules (Z/pZ for primes p) vs. non-simple examples |
| `demo` | Showcase: submodules(12), hom(4,6), direct_sum(2,3) |
| `help` | Show this help |
| `quit` | Exit |

## Mathematical Content

Every Z-module M has submodules corresponding to subgroups; for M = Z/nZ these are exactly the ideals of Z/nZ, one for each divisor d of n, generated by n/d. The annihilator Ann(a) of an element a ∈ Z/nZ is the ideal (n/gcd(a,n))Z, and Hom_Z(Z/nZ, Z/mZ) ≅ Z/gcd(n,m)Z, with the gcd counting valid choices for the image of the generator 1. A direct sum Z/nZ ⊕ Z/mZ is cyclic (isomorphic to Z/nmZ) if and only if gcd(n,m) = 1 by the Chinese Remainder Theorem. The simple Z-modules are exactly Z/pZ for primes p, since these have no proper nonzero submodules.

## Visualizations

- **SVG**: Hasse diagram of the submodule lattice of Z/nZ, with M at the top and each submodule node labeled by generator and size.
- **DOT**: Left-to-right graph of Hom_Z(Z/nZ, Z/mZ), with the source and target modules and one intermediate node per valid homomorphism, plus a diamond node summarizing the Hom group.
- **TikZ**: Submodule lattice of Z/nZ with M at top and cover edges drawn in gray.
- **ASCII**: Submodule chain by generators, Hom result with map list, and direct sum annihilator.

## Default State

- `mod_n`: primary module modulus; initial value `12`
- `mod_m`: secondary module modulus (used for Hom/direct sum display); initial value `4`
