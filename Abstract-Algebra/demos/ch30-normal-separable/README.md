# Chapter 30 — Normal and Separable Extensions

The two conditions — all conjugates present, all roots distinct — whose conjunction defines a Galois extension.

## Usage

### Interactive mode
```
cargo run -p ch30-normal-separable
```

### Non-interactive (scriptable)
```
cargo run -p ch30-normal-separable -- --run <cmd> [args] [--format text|svg|dot|tex|ascii]
```

### Visualize
```
cargo run -p ch30-normal-separable -- --run demo --format svg > output.svg
cargo run -p ch30-normal-separable -- --run demo --format dot | dot -Tpdf > output.pdf
cargo run -p ch30-normal-separable -- --run demo --format tex > output.tex
cargo run -p ch30-normal-separable -- --run demo --format ascii
```

### Persist state
```
cargo run -p ch30-normal-separable -- --run demo --save state.toml
cargo run -p ch30-normal-separable -- --load state.toml --run demo
```

## Mathematical Content

A finite extension K/F is normal if every irreducible polynomial over F with a root in K splits completely in K, equivalently K is the splitting field of some polynomial. Separability means every irreducible polynomial has distinct roots, which in characteristic 0 is automatic since gcd(f, f') = 1 whenever f is irreducible; in characteristic p, inseparable polynomials of the form g(xᵖ) exist. An extension is Galois if and only if it is both normal and separable. The Primitive Element Theorem guarantees that every finite separable extension is generated by a single element.

## Visualizations

- **SVG**: Diamond diagram with F at bottom, separable and normal extensions at the two middle nodes, and the Galois (normal + separable) extension at the top, with labeled arrows.
- **DOT**: Directed graph of the same diamond lattice of extension types.
- **TikZ**: TikZ diamond with F, separable, normal, and Galois nodes connected by labeled arrows.
- **ASCII**: Text-art diamond showing the relationship between the four extension types.

## Default State

- `p`: characteristic used for separability checks, default `5`
