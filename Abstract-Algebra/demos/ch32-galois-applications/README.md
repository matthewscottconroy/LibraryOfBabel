# Chapter 32 — Applications of Galois Theory

Solvability by radicals, compass-and-straightedge constructibility, and the structure of finite fields.

## Usage

### Interactive mode
```
cargo run -p ch32-galois-applications
```

### Non-interactive (scriptable)
```
cargo run -p ch32-galois-applications -- --run <cmd> [args] [--format text|svg|dot|tex|ascii]
```

### Visualize
```
cargo run -p ch32-galois-applications -- --run demo --format svg > output.svg
cargo run -p ch32-galois-applications -- --run demo --format dot | dot -Tpdf > output.pdf
cargo run -p ch32-galois-applications -- --run demo --format tex > output.tex
cargo run -p ch32-galois-applications -- --run demo --format ascii
```

### Persist state
```
cargo run -p ch32-galois-applications -- --run demo --save state.toml
cargo run -p ch32-galois-applications -- --load state.toml --run demo
```

## Commands

| Command | Description |
|---------|-------------|
| `solvable <degree>` | Is S_n solvable? (yes for n≤4, no for n≥5) |
| `radical_solvable <coeffs>` | Is polynomial solvable by radicals? |
| `quintic` | Example unsolvable quintic x⁵−5x+2 |
| `constructible <n>` | Is regular n-gon constructible? |
| `fermat_primes` | List known Fermat primes |
| `trisect <angle_deg>` | Check if angle is trisectable |

| `demo` | Run a showcase of key results |
| `help` | Show this help |
| `quit` | Exit |

## Mathematical Content

The Abel-Ruffini theorem states there is no radical formula for degree ≥ 5 polynomials in general; Galois theory explains this precisely: a polynomial is solvable by radicals if and only if its Galois group is a solvable group. For the specific quintic x⁵ − 5x + 2, the Galois group is S₅ (proved using the 5-cycle from irreducibility and a transposition from complex conjugation), which is not solvable because A₅ is simple. The Gauss-Wantzel theorem characterizes constructible regular n-gons as those where the odd part of n is a product of distinct Fermat primes. Finite fields GF(pⁿ) are constructed as ℤ/pℤ[x]/(f) for an irreducible f of degree n, and their Galois groups over ℤ/pℤ are cyclic of order n, generated by the Frobenius automorphism x ↦ xᵖ.

## Visualizations

- **SVG**: Radical tower diagram showing successive adjunctions of n-th roots leading to a splitting field, with a note marking the unsolvable case Gal(f) = S₅.
- **DOT**: Directed graph of the radical tower from base field F through intermediate radical extensions to the splitting field.
- **TikZ**: TikZ chain diagram of the radical tower with root labels on each step.
- **ASCII**: Text-art radical tower with the Abel-Ruffini impossibility noted at the bottom.

## Default State

- `degree`: degree used for solvability summary, default `5`
