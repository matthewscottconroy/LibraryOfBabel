The tool layer. Your ability to implement, scale, and share computational biology work depends entirely on the quality of your CS foundations.

## Programming

### Python (Primary Language)
Python is the lingua franca of computational biology. Master it thoroughly.

**Core Language**
- Data types: int, float, str, bool, NoneType
- Sequences: list, tuple, range; slicing and indexing
- Mappings: dict; sets
- Control flow: if/elif/else, for, while, comprehensions
- Functions: arguments, *args, **kwargs, default values, closures, decorators
- Classes and OOP: inheritance, dunder methods, properties, classmethod/staticmethod
- Exceptions: try/except/finally, raising custom exceptions
- Context managers: the `with` statement, writing `__enter__`/`__exit__`
- Generators and iterators: yield, lazy evaluation for large datasets
- Modules and packages: imports, `__init__.py`, namespace packages
- Virtual environments: venv, conda

**Scientific Python Stack**
- **NumPy**: ndarray, vectorized operations, broadcasting, linear algebra, random module
  - Avoid Python loops over arrays — vectorize everything
- **Pandas**: DataFrame, Series, indexing (loc/iloc), groupby, merge/join, missing data, I/O
- **Matplotlib**: figure/axes model, common plot types, styling, saving
- **Seaborn**: statistical visualization, theming
- **SciPy**: integration (solve_ivp), optimization (minimize), linear algebra, statistics, signal processing, sparse matrices

**Biology-Specific Libraries**
- **Biopython**: sequence I/O, alignment, BLAST, PDB parsing, phylogenetics
- **scikit-learn**: machine learning (classification, regression, clustering, dimensionality reduction)
- **NetworkX**: graph creation and analysis

### R (Secondary Language)
Essential for statistical genomics and the Bioconductor ecosystem.

**Core R**
- Vectors, matrices, data frames, lists, factors
- Control flow, functions, apply family
- Formula syntax (~) for statistical models

**Key Packages**
- **tidyverse**: dplyr, ggplot2, tidyr, readr, purrr
- **ggplot2**: grammar of graphics — layers, aesthetics, geoms, facets
- **Bioconductor**: DESeq2, edgeR, limma, GenomicRanges, SummarizedExperiment, Biostrings
- **Seurat**: single-cell RNA-seq analysis

### Bash Scripting
- Variables, conditionals, loops
- File manipulation: find, grep, awk, sed, sort, uniq, cut, paste
- Pipes and redirection
- Shell scripts for automating analysis pipelines
- SSH, rsync for working on remote servers

### Version Control (Git)
Non-negotiable for reproducible research.
- `git init`, `git add`, `git commit`
- Branches: `git branch`, `git checkout`, `git merge`
- Remote repositories: `git push`, `git pull`, `git fetch`
- Resolving merge conflicts
- GitHub/GitLab: pull requests, issues, CI/CD
- `.gitignore`: excluding data files, credentials, build artifacts
- Tagging releases for reproducibility

## Algorithms & Data Structures

### Fundamental Data Structures
- **Arrays**: contiguous memory, O(1) random access, O(n) insert/delete
- **Linked lists**: O(1) insert/delete, O(n) access
- **Hash tables**: O(1) average lookup, collisions, load factor
- **Trees**: binary search trees, balanced trees (AVL, red-black), heaps
- **Graphs**: adjacency matrix (dense), adjacency list (sparse)
- **Stacks and queues**: LIFO/FIFO, BFS/DFS implementations

### Algorithm Analysis
- Big O notation: O(1), O(log n), O(n), O(n log n), O(n²), O(2^n)
- Best, average, worst case
- Space complexity
- Amortized analysis

### Sorting & Searching
- Comparison sorts: merge sort O(n log n), quicksort, heapsort
- Linear sorts: counting sort, radix sort (genome position sorting)
- Binary search: O(log n) on sorted arrays
- Hash-based lookup: O(1) average

### Dynamic Programming
- Overlapping subproblems and optimal substructure
- Memoization vs. tabulation
- Classic problems in bioinformatics:
  - Needleman-Wunsch (global alignment): O(nm) time and space
  - Smith-Waterman (local alignment): O(nm)
  - Longest common subsequence
  - Shortest path (Viterbi algorithm for HMMs)

### String Algorithms
- Exact string matching: Knuth-Morris-Pratt, Boyer-Moore
- Suffix arrays and suffix trees: O(n) construction, powerful for indexing
- k-mer counting: the basis of genome assembly and many bioinformatics tools
- Burrows-Wheeler transform: the basis of BWA and bowtie2 alignment

### Probabilistic Data Structures
- Bloom filters: space-efficient approximate set membership (jellyfish for k-mer counting)
- Count-Min Sketch: approximate frequency counting
- MinHash: estimating Jaccard similarity (genome distance estimation)

### Graph Algorithms
- Breadth-first search (BFS): shortest paths in unweighted graphs
- Depth-first search (DFS): topological sort, connected components
- Dijkstra's algorithm: shortest paths in weighted graphs
- Minimum spanning tree: Kruskal, Prim
- de Bruijn graph: directed graph of k-mer overlaps — the core data structure for sequence assembly

## Databases

### Relational Databases (SQL)
- Tables, rows, columns, primary keys, foreign keys
- SELECT, WHERE, JOIN (inner, left, right, full), GROUP BY, ORDER BY, HAVING
- Aggregation functions: COUNT, SUM, AVG, MAX, MIN
- Subqueries and CTEs
- Indexing for performance
- Normalization: 1NF, 2NF, 3NF

### Biological Databases (Architecture and APIs)
**Sequence Databases**
- NCBI GenBank/RefSeq: nucleotide sequences, protein sequences; Entrez E-utilities API
- UniProt/Swiss-Prot: protein sequences and functional annotation; REST API
- Ensembl: vertebrate genomes with annotation; BioMart for batch queries

**Structure Databases**
- PDB (Protein Data Bank): X-ray, NMR, cryo-EM structures; mmCIF format; PDBe API
- AlphaFold Database: predicted structures for most known proteins

**Functional Databases**
- GO (Gene Ontology): hierarchical functional annotation; three domains (MF, BP, CC)
- KEGG: metabolic pathways, orthology, genomes
- Reactome: manually curated human pathways
- InterPro: protein domains and families

**Variant Databases**
- dbSNP: single nucleotide polymorphisms
- ClinVar: clinically significant variants
- gnomAD: population allele frequencies

### NoSQL and Big Data
- Key-value stores: Redis (caching BLAST results)
- Document stores: MongoDB (flexible schema for heterogeneous biological data)
- Column-family stores: HBase, Cassandra (genomic position data)
- HDF5 / Zarr: hierarchical array storage for large genomic datasets (AnnData uses HDF5)

## Software Engineering

### Code Quality
- PEP 8 style guidelines for Python
- Naming conventions: descriptive names, snake_case for Python
- Functions: single responsibility, small, testable
- DRY principle: Don't Repeat Yourself
- Type hints (Python 3.5+): `def align(seq1: str, seq2: str) -> float:`

### Testing
- Unit tests: pytest, unittest
- Integration tests
- Test coverage: pytest-cov
- Test-driven development (TDD) for algorithmic code
- Property-based testing: hypothesis library for edge case discovery

### Documentation
- Docstrings: NumPy/Google style
- Sphinx for generating HTML documentation
- README files: installation, usage examples
- Jupyter notebooks as interactive documentation

### Reproducible Research

**Workflow Managers**
- **Snakemake**: Python-based, rules define input/output, DAG of jobs, cluster support
- **Nextflow**: DSL2, containerization-friendly, strong for production pipelines
- **WDL/CWL**: workflow description languages for portability

**Environment Management**
- Conda/Mamba: cross-language package management, environment files (`environment.yml`)
- pip + venv: Python-only
- Poetry: dependency resolution and packaging

**Containerization**
- **Docker**: images, containers, Dockerfile, docker-compose
  - Layer caching for efficient builds
  - Multi-stage builds to minimize image size
- **Singularity/Apptainer**: rootless containers for HPC environments

**Configuration**
- YAML/JSON for configuration files
- Environment variables for secrets
- Hydra (Python) for complex experiment configuration

### High-Performance Computing (HPC)
- SLURM job scheduler: `sbatch`, `squeue`, `sacct`
- SLURM directives: `--ntasks`, `--cpus-per-task`, `--mem`, `--time`, `--array`
- Array jobs: running many parameter combinations
- MPI basics: message passing between processes
- Parallel file systems: Lustre, GPFS
- Checkpointing long-running jobs

### Code Performance
- Profiling: `cProfile`, `line_profiler` (`%lprun` in Jupyter)
- Vectorization with NumPy vs. Python loops (10–100x speedup)
- Numba JIT compilation (`@jit`, `@njit`) for numeric loops
- Cython: annotated Python compiled to C
- ctypes/cffi: calling C libraries from Python
- Multiprocessing: `concurrent.futures`, Dask for parallel workflows
- GPU: CuPy (NumPy on GPU), JAX (auto-differentiation + GPU/TPU)
