# Section 1: Programming

In 1995, the human genome project was generating sequence data at an unprecedented rate and the computational tools to analyze it barely existed. Biologists were learning C and Perl on the fly, writing parsers for text files, inventing conventions for sequence formats, stitching together fragments of code from different labs. Python had just reached version 1.2. R did not yet exist in its modern form. The field was making up its computational infrastructure as it went.

Thirty years later, you inherit the result: a mature, remarkably coherent programming ecosystem built specifically for biological data analysis. Python with NumPy, SciPy, Pandas, and BioPython handles everything from ODE simulation of gene circuits to genome-scale k-mer counting. R with Bioconductor provides the gold-standard statistical tools for RNA-seq, single-cell analysis, and genomic interval operations. Bash scripting ties command-line tools into coherent pipelines. Git version control tracks every change to every analysis, makes results reproducible, and enables collaboration. Learning to use these tools fluently is not an optional enrichment activity — it is the prerequisite for doing modern computational biology.

This section moves through these four languages in order of scope: from Python (general-purpose computational work), to R (statistical genomics), to bash (pipeline infrastructure), to git (the foundation beneath everything else).

**Python** is where most computational biology lives. The goal of the first subsection is not a survey of syntax — Python tutorials exist in abundance — but a focused treatment of the specific patterns and libraries that come up constantly in biological research: generators for memory-efficient file processing, NumPy vectorization for large numerical arrays, SciPy's ODE integrator for systems biology modeling, Pandas for RNA-seq count matrices and metadata, and BioPython for sequence I/O and alignment.

**R** earns its place through statistics and Bioconductor. You will use R when you need DESeq2 for differential expression analysis, ggplot2 for publication-quality figures, or GenomicRanges for genomic interval arithmetic. These tools have no real equivalents in any other language — they were developed by statisticians and bioinformaticians who understood both the mathematics and the biology, and they remain the state of the art for their specific domains.

**Bash scripting** is the plumbing. Every genome aligner, variant caller, and assembly tool is a command-line program. Connecting them into pipelines, processing samples in loops, parsing outputs, and checking for errors all require bash. The subsection covers variables, pipes, loops, error handling, awk for text processing, and a complete example pipeline from FASTQ files to an aligned, indexed BAM.

**Version control with Git** underpins reproducible computational biology. Every change to your code is tracked, every version is recoverable, every collaboration is managed through a coherent branching model. The subsection covers the mental model of what git actually tracks, the core workflow, what belongs in `.gitignore`, how to use branches for development, and how to tag releases for manuscript submission.
