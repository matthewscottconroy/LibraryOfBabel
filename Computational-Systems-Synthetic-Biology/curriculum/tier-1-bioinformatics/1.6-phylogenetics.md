# 1.6 Phylogenetics

Reconstructing evolutionary history from sequence data — the discipline that gives biology its comparative dimension.

---

## Core Concepts

### What Phylogenetics Answers
- How are organisms or genes related to each other?
- When did lineages diverge?
- How has a gene or trait evolved?
- Are two sequences homologous (sharing common ancestor)?
- Is a gene under positive or purifying selection?

### Key Terminology
- **Phylogenetic tree**: branching diagram representing evolutionary relationships
- **Node**: branching point (ancestor)
- **Tip/leaf**: observed sequence (extant taxon)
- **Branch length**: evolutionary distance (substitutions/site, or time)
- **Root**: common ancestor of all taxa in the tree
- **Clade/monophyletic group**: ancestor + all descendants
- **Outgroup**: taxon outside the ingroup; used to root trees
- **Topology**: branching pattern, independent of branch lengths

### Homology
- **Ortholog**: homolog arising by speciation → usually same function across species
- **Paralog**: homolog arising by gene duplication → often diverged function
- **Xenolog**: homolog arising by horizontal gene transfer
- Sequence similarity ≠ homology: convergent evolution can produce similar sequences
- Homology is a hypothesis, not a measurement

## Distance Methods

### Computing Pairwise Distances
- Raw p-distance: fraction of sites that differ
- Problem: underestimates true evolutionary distance (multiple substitutions at same site)
- Substitution models correct for multiple hits:
  - Jukes-Cantor (JC69): single parameter (uniform substitution rate)
  - Kimura 2-parameter (K2P): transitions and transversions at different rates
  - GTR: six rate parameters + base frequencies

### UPGMA (Unweighted Pair Group Method with Arithmetic Mean)
- Builds tree by iteratively joining closest pair and averaging distances
- Assumes constant molecular clock (all lineages evolve at same rate)
- Produces ultrametric tree (all tips equidistant from root)
- Fast but unrealistic assumption makes it poor for most real data

### Neighbor-Joining (NJ)
- Q-matrix: accounts for total branch length; joins pair with minimum corrected distance
- Does not assume molecular clock
- Fast: O(n³) time
- Produces unrooted tree
- Good for: quick exploratory analysis, very large datasets
- Tool: `FastTree` (approximate ML, also fast), `neighbor` in PHYLIP

## Maximum Parsimony

### Principle
- Choose tree topology that minimizes total number of evolutionary changes
- Fitch parsimony: for each site, find minimum changes over all topologies

### Limitations
- Long branch attraction: highly divergent lineages attracted to each other regardless of true relationship (inconsistent estimator under certain conditions)
- Ignores branch length information
- Computationally intractable for exact solution with many taxa

## Maximum Likelihood

### The Statistical Framework
- Define a probabilistic model of sequence evolution (substitution model)
- Likelihood: P(data | tree topology, branch lengths, model parameters)
- Find the tree, branch lengths, and parameters that maximize L

### Substitution Models for Nucleotides
- **JC69**: equal base frequencies, equal rates
- **K2P/K80**: transitions at rate κ × transversions
- **HKY85**: unequal base frequencies + κ rate ratio
- **GTR (General Time Reversible)**: 6 rate parameters + 4 base frequencies — most general
- **GTR+Γ**: rate heterogeneity across sites modeled by gamma distribution
- **GTR+Γ+I**: adds invariant sites fraction

### Substitution Models for Amino Acids
- **WAG**: Whelan and Goldman; derived from empirical protein alignments
- **LG**: Le and Gascuel; more recent empirical matrix
- **JTT**: Jones, Taylor, Thornton

### Model Selection
- AIC (Akaike Information Criterion): AIC = 2k - 2ln(L); lower is better
- BIC (Bayesian Information Criterion): stronger penalty for complexity
- LRT (Likelihood Ratio Test): nested model comparison
- Tools: ModelTest-NG, ModelFinder (in IQ-TREE)

### Tree Search Algorithms
- Exact NP-hard for >10 taxa; heuristics required
- **Nearest Neighbor Interchange (NNI)**: swap subtrees around internal edge
- **Subtree Pruning and Regrafting (SPR)**: remove subtree, reattach elsewhere
- **Tree Bisection and Reconnection (TBR)**: most powerful; split tree into two, rejoin
- Start from multiple random trees to avoid local optima

### Tools
- **IQ-TREE2**: gold standard for ML phylogenetics; fast, accurate, model testing built in
- **RAxML-NG**: alternative; very fast for large datasets; bootstrap support
- **PhyML**: widely used; good for moderate datasets

## Bayesian Phylogenetics

### Bayesian Framework
- **Prior**: P(tree, model) — beliefs before seeing data
- **Likelihood**: P(data | tree, model) — how well model explains data
- **Posterior**: P(tree, model | data) ∝ Prior × Likelihood
- Report: posterior probability distribution over trees (credibility intervals)

### MCMC Sampling
- Cannot analytically compute posterior over all possible trees
- Markov Chain Monte Carlo (MCMC) approximates posterior by sampling
- Metropolis-Hastings: proposed moves accepted/rejected probabilistically
- After burn-in: sample from posterior distribution
- **Convergence diagnostics**: ESS (effective sample size), PSRF, trace plots

### MrBayes
- Classic Bayesian phylogenetics tool
- Blocks of sequences partitioned into separate substitution models
- Posterior tree probabilities as branch supports

### BEAST2 (Bayesian Evolutionary Analysis by Sampling Trees)
- Bayesian framework + molecular clock models
- Divergence time estimation using calibration priors (fossils, biogeography)
- Implements: strict clock, relaxed clock (log-normal, exponential)
- Applications: epidemiological phylodynamics, ancient DNA, species tree estimation
- FigTree: BEAST tree visualization

## Bootstrap and Tree Support

### Nonparametric Bootstrap
- Resample alignment columns with replacement
- Build tree from each bootstrap replicate (usually 100–1000)
- Bootstrap support: percentage of bootstrap trees containing each clade
- Bootstrap ≥70%: reasonably supported; ≥95%: well-supported
- Conservative: often underestimates support for true clades

### Ultrafast Bootstrap (IQ-TREE)
- UFboot: UFBS algorithm; 10–40× faster than standard bootstrap
- Corrects for potential bias; UFboot ≥95% ≈ standard bootstrap ≥70%
- Implemented in IQ-TREE2 with `--bb 1000`

### SH-aLRT (Approximate Likelihood Ratio Test)
- Shimodaira-Hasegawa test; fast per-branch test
- Complements bootstrap; use both: SH-aLRT ≥80% AND UFBoot ≥95%

## Molecular Clock and Divergence Time

### Strict Clock
- All lineages evolve at the same rate (substitutions/site/time)
- Clock rate calibrated from known divergence events (fossil record, biogeography)

### Relaxed Clock
- Rate varies across lineages
- Log-normal relaxed clock (BEAST): rate drawn from log-normal distribution
- Uncorrelated: rates of branches independent
- Autocorrelated: daughter rate correlates with parent rate

### Calibration
- Node calibration: prior on divergence time of specific node (from fossils)
- Tip dating: include ancient sequences with known sampling dates (viruses, ancient DNA)
- Secondary calibration: from other published time trees

## Gene Tree / Species Tree Discordance

### Sources of Discordance
- **Incomplete Lineage Sorting (ILS)**: ancestral polymorphism not resolved before speciation
- **Horizontal Gene Transfer (HGT)**: especially in bacteria
- **Gene duplication/loss**: orthologs vs. paralogs misidentified
- ILS expected when speciation is rapid (short internal branches)

### Coalescent-Based Methods
- Model ILS explicitly using the multi-species coalescent
- **ASTRAL**: estimates species tree from input gene trees; minimizes quartet distance
- **StarBEAST2**: full Bayesian co-estimation of gene trees + species tree
- Use when: rapid radiation, many conflicting gene trees

### Concordance Factors
- Site concordance factor (sCF): fraction of informative sites supporting a branch
- Gene concordance factor (gCF): fraction of gene trees containing a bipartition
- Both more informative than bootstrap for assessing actual support

## Molecular Evolution & Selection

### dN/dS Analysis (ω)
- dN: nonsynonymous substitution rate (changes amino acid)
- dS: synonymous substitution rate (silent, treated as neutral reference)
- ω = dN/dS
  - ω < 1: purifying selection (functional constraint)
  - ω = 1: neutral evolution
  - ω > 1: positive selection (adaptive evolution)

### Tests for Selection
**PAML (Phylogenetic Analysis by Maximum Likelihood)**
- Branch models: test for elevated ω on specific lineages
- Site models: test for sites with ω > 1 (M8 vs. M7/M8a)
- Branch-site models: positive selection on specific sites in specific lineages
- BEB (Bayes Empirical Bayes): identifies specific positively selected sites

**HyPhy**
- FEL (Fixed Effects Likelihood): site-by-site dN/dS
- FUBAR (Fast, Unconstrained Bayesian AppRoximation): Bayesian site-specific rates
- MEME: mixed effects for episodic diversifying selection
- aBSREL: branch-specific adaptive evolution

### McDonald-Kreitman Test
- Compares polymorphism within species to divergence between species
- Expected under neutrality: Pn/Ps ≈ Dn/Ds
- Excess nonsynonymous divergence → positive selection (McDonald-Kreitman α)

## Practical Phylogenetics Workflow

```
Sequences (FASTA)
       │
       ▼
Multiple Alignment: MAFFT L-INS-i
       │
       ▼
Alignment trimming: trimAl (remove gapped columns)
       │
       ▼
Model selection: ModelFinder (in IQ-TREE)
       │
       ▼
Tree inference: IQ-TREE2 --bb 1000 --alrt 1000
       │
       ▼
Visualization: FigTree, iTOL, ggtree (R)
       │
       ▼
Selection analysis: HyPhy / PAML
```
