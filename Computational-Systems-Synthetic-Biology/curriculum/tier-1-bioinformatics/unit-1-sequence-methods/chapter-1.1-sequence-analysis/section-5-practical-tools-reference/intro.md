# Section 5: Practical Tools Reference

The preceding sections developed the algorithmic and conceptual foundations of sequence analysis: alignment theory, file formats, mapping and assembly. This section is the practical guide that connects those foundations to day-to-day research.

Bioinformatics has a tool for every task — and for many tasks, multiple competing tools with overlapping capabilities. The challenge is knowing which tool to reach for and how to configure it. Using the right aligner for the wrong data type, setting quality thresholds without understanding what they mean, or stringing together tools that produce incompatible output formats are among the most common sources of errors in bioinformatics analysis. This section provides the conceptual map that makes those choices principled rather than arbitrary.

The organization mirrors the workflow of a typical sequencing analysis. You start with raw reads, assess their quality, trim adapters and low-quality bases, align to a reference or assemble de novo, post-process the alignments, and quantify biological signal. At each stage, there are best-practice tools, and the choices you make cascade forward through the pipeline. Selecting STAR over HISAT2 for RNA-seq alignment determines which junction format you will work with downstream. Using Salmon instead of featureCounts for quantification changes the statistical model appropriate for differential expression analysis.

The tools presented here are not exhaustive — the field moves quickly and new tools continuously emerge. What is intended to be durable is the framework: understanding the algorithmic basis of each tool type (BWT indexing for short-read aligners, de Bruijn graphs for assemblers, profile HMMs for database search) lets you evaluate new tools as they appear, understand their benchmarked advantages, and anticipate where they will succeed or fail. A bioinformatician who can only run tools is at the mercy of tutorials. A bioinformatician who understands the tools can adapt.
