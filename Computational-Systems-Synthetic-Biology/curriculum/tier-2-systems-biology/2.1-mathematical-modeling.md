# 2.1 Mathematical Modeling of Biological Systems

The shift from describing biology to explaining it — from cataloguing parts to understanding dynamics.

---

## Why Models?

A model is a precisely stated hypothesis. Unlike verbal descriptions:
- It can be simulated to produce quantitative predictions
- Inconsistencies are immediately apparent (equations must balance)
- It can be falsified by comparison to data
- It communicates unambiguously

The goal is not the most detailed model, but the simplest model that explains the phenomenon.

## ODE-Based Deterministic Modeling

### From Chemistry to Equations

The law of mass action: reaction rate proportional to concentrations of reactants.

```
A + B → C      rate = k·[A]·[B]
A → B + C      rate = k·[A]
```

For a species X:
```
d[X]/dt = (sum of rates of reactions producing X) - (sum of rates of reactions consuming X)
```

**Example: Simple Gene Expression**
```
Gene → mRNA     (transcription, rate α)
mRNA → ∅        (degradation, rate δ·m)
mRNA → Protein  (translation, rate β·m)
Protein → ∅    (degradation, rate γ·p)

dm/dt = α - δ·m
dp/dt = β·m - γ·p
```

Steady state: dm/dt = 0 → m* = α/δ; dp/dt = 0 → p* = βα/(δγ)

### Enzyme Kinetics as ODEs

**Full Michaelis-Menten mechanism:**
```
E + S ⇌ ES → E + P

d[S]/dt  = -k₁[E][S] + k₋₁[ES]
d[E]/dt  = -k₁[E][S] + k₋₁[ES] + kcat[ES]
d[ES]/dt =  k₁[E][S] - k₋₁[ES] - kcat[ES]
d[P]/dt  =  kcat[ES]
```

Quasi-steady-state assumption (d[ES]/dt ≈ 0):
```
v = Vmax[S] / (Km + [S])      where Km = (k₋₁ + kcat) / k₁
```

This simplifies a 4-ODE system to one algebraic equation — valid when [E]₀ << [S]₀.

### Hill Functions

Cooperative binding of transcription factor X to promoter:
```
Activation:   f(X) = X^n / (K^n + X^n)      → saturates at 1
Repression:   f(X) = K^n / (K^n + X^n)      → saturates at 0
```

- K: threshold concentration for half-maximal effect
- n (Hill coefficient): controls steepness of transition
  - n = 1: hyperbolic (Michaelis-Menten)
  - n > 1: sigmoidal, ultrasensitive
  - n = ∞: perfect switch (step function)

**Combined regulation:**
```
Activation by A AND Repression by R:
f(A,R) = [A^nA / (KA^nA + A^nA)] × [KR^nR / (KR^nR + R^nR)]
```

### Stability Analysis

For a system dx/dt = f(x), find fixed points where f(x*) = 0.

**Linearization:**
Jacobian matrix J_ij = ∂f_i/∂x_j evaluated at x*

Eigenvalues λ of J determine stability:
- All Re(λ) < 0: stable fixed point (node or spiral)
- Any Re(λ) > 0: unstable
- Re(λ) = 0, Im(λ) ≠ 0: Hopf bifurcation condition (oscillation onset)
- λ all real: node; complex: spiral

**Phase plane analysis:**
- Nullclines: curves where dx/dt = 0 or dy/dt = 0
- Intersections = fixed points
- Flow arrows between nullclines reveal trajectory structure

### Bifurcation Theory

As a parameter p changes, system behavior can change qualitatively:

**Saddle-Node Bifurcation**
- Two fixed points collide and annihilate
- Creates bistability: two stable states separated by unstable saddle
- Biological example: irreversible cell fate commitment

**Pitchfork Bifurcation**
- Single stable point splits into two stable + one unstable
- Occurs in symmetric systems
- Supercritical: continuous transition; subcritical: discontinuous (hysteresis)

**Hopf Bifurcation**
- Fixed point transitions from stable spiral to unstable spiral + limit cycle
- Condition: eigenvalues cross imaginary axis (Re(λ) = 0)
- Supercritical Hopf: small stable oscillations emerge
- Subcritical Hopf: discontinuous jump to large-amplitude oscillations

**SNIC (Saddle-Node on Invariant Circle)**
- Limit cycle arises from coalescence of saddle and node
- Produces oscillations with variable period near bifurcation

**Practical bifurcation analysis:**
- Vary parameter, track fixed points and their stability
- XPPAUT: phase plane analysis + numerical bifurcation tracking
- MATCONT (MATLAB), PyDSTool (Python): numerical continuation
- COPASI: GUI-based, accessible entry point

## Stochastic Modeling

### Why Stochasticity Matters

Gene expression involves small numbers of molecules:
- Typical cell: ~1-10 copies of a transcription factor gene
- mRNA copy number: often single digits
- At low copy numbers, the Poisson noise CV = 1/√N becomes large

Deterministic models predict average behavior. Stochastic models capture distributions.

### Chemical Master Equation (CME)

For a state space of molecular numbers, the CME describes:
```
dP(n,t)/dt = Σ_j [ a_j(n - ν_j) P(n - ν_j, t) - a_j(n) P(n,t) ]
```

Where P(n,t) = probability of being in state n at time t, a_j(n) = propensity of reaction j, ν_j = stoichiometric change from reaction j.

Exact solution exists for: monomolecular reactions, some bimolecular systems
Most systems: solved numerically via simulation

### Gillespie Algorithm (SSA)

Exact simulation of the CME:

1. Calculate propensity a_j = k_j × (reactant copy numbers) for each reaction j
2. Calculate total propensity a₀ = Σ a_j
3. Sample time to next reaction: τ ~ Exponential(a₀) = -ln(r₁)/a₀
4. Sample which reaction fires: j chosen with probability a_j/a₀
5. Update molecule counts, advance time by τ
6. Repeat

Properties:
- Exact: generates exact samples from CME
- Slow: one reaction per step; expensive for fast reactions
- All fast "housekeeping" reactions slow down the simulation

### Tau-Leaping

Approximate method for speed:
- Instead of one reaction at a time, allow multiple reactions in time interval τ
- Number of firings of reaction j ~ Poisson(a_j × τ)
- Must choose τ small enough that propensities don't change too much
- 10–100× faster than SSA; small approximation error

### Stochastic Differential Equations (Langevin Equation)

Chemical Langevin Equation:
```
dx_i/dt = f_i(x) + Σ_j ν_{ij} √(a_j(x)/Ω) · ξ_j(t)
```

Where ξ_j is white Gaussian noise, Ω is system volume.

Valid when: molecule numbers large enough to treat as continuous, but noise still significant.

### Noise Decomposition

**Intrinsic noise**: fluctuations due to stochastic reaction events in the cell itself
**Extrinsic noise**: fluctuations due to differences between cells (cell size, global regulator concentration)

Measurement: two-reporter assay (Elowitz et al. 2002)
- Two distinguishable reporters driven by identical promoters
- Intrinsic noise: uncorrelated fluctuations between reporters in same cell
- Extrinsic noise: correlated fluctuations between reporters

**Noise metrics:**
- CV (coefficient of variation): σ/μ
- Fano factor: σ²/μ
  - Poisson process: Fano = 1
  - Bursty transcription: Fano > 1 (super-Poisson)

### Stochastic Gene Expression Models

**Two-state promoter model (bursty expression):**
```
Promoter OFF ⇌ Promoter ON     (rates kon, koff)
Promoter ON → mRNA             (rate α)
mRNA → ∅                       (rate δ)
```

Analytical solution: mRNA follows a negative binomial distribution
Mean: α·kon / (δ·(kon + koff))
Fano factor: 1 + α·koff / (δ·(kon + koff))
- High koff/kon: promoter mostly off → bursty → high Fano
- Low koff/kon: promoter mostly on → more Poisson → Fano ≈ 1

## Spatial Modeling

### When Spatial Structure Matters
- Morphogen gradients (Bicoid in Drosophila)
- Intracellular signaling where components are localized
- Cell-cell communication over short distances
- Min protein oscillations in *E. coli* division
- Turing patterns: self-organizing spatial patterns

### Reaction-Diffusion PDEs

For species u(x,t):
```
∂u/∂t = D_u ∇²u + f(u,v)
∂v/∂t = D_v ∇²v + g(u,v)
```

**Turing Instability (Pattern Formation)**
Conditions for Turing pattern:
1. Activator-inhibitor pair (A activates A and I; I inhibits A)
2. Inhibitor diffuses faster than activator: D_v >> D_u
3. System homogeneous steady state must be stable without diffusion, unstable with diffusion

Canonical example: Gierer-Meinhardt model
- Short-range activation + long-range inhibition
- Produces stripe or spot patterns

Biological examples:
- Skin pigmentation patterns (zebrafish, leopard spots)
- Digit formation in limb patterning
- Left-right asymmetry

### Numerical Methods for PDEs
- Finite difference: discretize space into grid; approximate derivatives
- Finite element: irregular meshes; better for complex geometries
- Finite volume: conserves fluxes; good for transport equations
- Tools: FEniCS (Python), COMSOL (commercial), VCell (GUI-based), PyChaos

### Particle-Based Spatial Stochastic

When both discreteness and diffusion matter:
- Smoldyn: particles diffuse and react in 3D space; efficient for cytoplasm
- MCell: Monte Carlo; synaptic physiology; irregular geometries
- ReaDDy (Python): reaction-diffusion dynamics

## Parameter Estimation

### The Inverse Problem
Given ODE model and experimental data, find parameters that minimize discrepancy.

**Least Squares (Deterministic)**
Minimize: Σ_i (y_i^obs - y_i^model(θ))²

Methods:
- Gradient-based: L-BFGS-B, Nelder-Mead (gradient-free)
- Problem: multiple local minima for nonlinear ODE systems
- Multi-start: run from many random initial parameter sets

**Bayesian Parameter Estimation**
Posterior: P(θ | data) ∝ P(data | θ) × P(θ)
- Accounts for parameter uncertainty
- Prior encodes biological knowledge
- MCMC samples from posterior distribution
- Tools: emcee (Python), PyMC, Stan, AMICI + pyPESTO

### Identifiability

**Structural Identifiability**
Can parameters ever be uniquely determined from perfect, noise-free data?
- Differential algebra approach: eliminate unobserved variables
- DAISY (MATLAB), SIAN (Julia)
- Non-identifiable parameters: must fix or reparameterize

**Practical Identifiability**
Given finite, noisy data: can parameters be estimated with acceptable uncertainty?
- Profile likelihood: vary one parameter, optimize all others
- Flat profile → parameter not identifiable in practice
- Confidence intervals from likelihood ratio test

### Sensitivity Analysis

**Local Sensitivity**
- Partial derivative: s_ij = ∂y_i/∂θ_j
- Logarithmic sensitivity (more interpretable): s_ij = (∂ln y_i / ∂ln θ_j)
- Identifies which parameters most affect output

**Global Sensitivity**
- Explores full parameter space
- Morris method: efficient screening; elementary effects
- Sobol indices: variance decomposition; total-order vs. first-order effects
- SALib (Python): systematic sensitivity analysis library

## Model Building Philosophy

### The Modeling Cycle
1. **Identify** the biological question and observable
2. **Hypothesize** the mechanism in words
3. **Translate** to mathematical equations
4. **Analyze/simulate** to generate predictions
5. **Compare** to experimental data
6. **Revise** hypothesis if predictions don't match
7. Repeat

### Principles for Good Models
- Start simple: one or two variables; add complexity only when simpler model fails
- Every parameter must be measurable or constrained by data
- Robustness: good models work over a range of parameters, not just one value
- Distinguish between data-fitting and mechanistic explanation
- A model that fits everything predicts nothing

### Common Mistakes
- Over-parameterization: more parameters than data points → always fits, explains nothing
- Implicit assumptions: units, normalizations, reference states not stated
- Ignoring identifiability: fitting non-identifiable parameters gives false confidence
- Forgetting noise: deterministic model applied to inherently stochastic data
