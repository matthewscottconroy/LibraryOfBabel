Quantitative understanding of cellular metabolism — from stoichiometry to genome-scale models to flux prediction.

## The Stoichiometric Matrix Framework

### Building the Stoichiometric Matrix

For a metabolic network with m metabolites and n reactions:
- Stoichiometric matrix **S** is m × n
- S_ij = stoichiometric coefficient of metabolite i in reaction j
  - Positive: metabolite is produced
  - Negative: metabolite is consumed
  - Zero: metabolite not involved

**Example:**
```
Reaction 1: A → B          S[:,1] = [-1, +1, 0, ...]
Reaction 2: B + C → D      S[:,2] = [0, -1, -1, +1, ...]
```

### Steady-State Assumption

At metabolic steady state, metabolite concentrations don't change:
```
S · v = 0
```

Where v is the flux vector (rates of all reactions).

This is the central constraint in constraint-based modeling.

### The Null Space

The set of all v satisfying S·v = 0 is the null space (kernel) of S.
- Dimensionality of null space = degrees of metabolic freedom
- Any flux distribution is a linear combination of null space basis vectors
- Extreme rays (elementary flux modes): irreducible feasible flux distributions

### Flux Constraints

Add thermodynamic and capacity constraints:
```
v_min ≤ v ≤ v_max
```
- Reversible reactions: -1000 ≤ v ≤ 1000 (mmol/gDW/h)
- Irreversible reactions: 0 ≤ v ≤ 1000
- Exchange fluxes: constrain nutrient uptake from medium
- Measured fluxes: fix v_j = measured_value

The feasible flux space is a convex polytope.

## Flux Balance Analysis (FBA)

### Linear Programming Formulation

Maximize (or minimize) a linear objective function over the feasible flux space:
```
maximize:   c^T · v
subject to: S · v = 0
            v_min ≤ v ≤ v_max
```

Common objective functions:
- **Maximize biomass**: biomass reaction with stoichiometric coefficients from cell composition data
- **Maximize ATP production**: proxy for maintenance and growth capacity
- **Minimize total flux** (parsimony): Occam's razor for flux distributions
- **Maximize product yield**: metabolic engineering objective

### Biological Interpretation
- FBA predicts the optimal flux distribution assuming the cell maximizes growth
- Works best for: exponential growth in rich medium, aerobic conditions
- Fails for: stationary phase, stress responses, non-growth conditions

### Performing FBA in Practice (COBRApy)

```python
import cobra
from cobra.io import read_sbml_model

model = read_sbml_model('iJO1366.xml')  # E. coli GEM

# Standard growth simulation
solution = model.optimize()
print(f"Growth rate: {solution.objective_value:.3f} h⁻¹")
print(f"Glucose uptake: {model.reactions.get_by_id('EX_glc__D_e').flux:.3f}")

# Knockout simulation
with model:
    model.reactions.get_by_id('PFK').knock_out()  # phosphofructokinase knockout
    ko_solution = model.optimize()
    print(f"KO growth rate: {ko_solution.objective_value:.3f}")

# Gene knockout
with model:
    model.genes.get_by_id('b3916').knock_out()
    print(model.optimize().objective_value)
```

### Flux Variability Analysis (FVA)

For each reaction, find the min and max flux compatible with a given optimum:
```python
from cobra.flux_analysis import flux_variability_analysis

fva = flux_variability_analysis(model, fraction_of_optimum=0.9)
```
Identifies:
- Essential reactions (min = max = required flux)
- Flexible reactions (large range)
- Coupled reactions (always fixed relative to each other)
- Alternative optimal solutions

## Genome-Scale Metabolic Models (GEMs)

### What Makes a GEM
- All known metabolic reactions in an organism
- Derived from genome annotation + biochemical databases
- Typical size: 1,000–4,000 reactions, 800–3,000 metabolites
- Validated against phenotypic data: growth/no-growth in different media

### Major GEMs
- **iJO1366**: *E. coli* K-12; 1366 genes, 2583 reactions; the most studied bacterial GEM
- **iML1515**: newer *E. coli* GEM; 1515 genes
- **Recon3D**: human metabolism; 3288 genes, 10,600 reactions
- **yeast8**: *S. cerevisiae*; consensus reconstruction
- **AGORA2**: 7302 gut microbiome models; for microbiome community modeling

### Reconstruction Workflow
1. Draft model from genome annotation + KEGG/BiGG databases
2. Manual curation: gap filling, charge/mass balancing
3. Consistency checks: can model grow? blocked reactions?
4. Validation: compare growth phenotypes to Biolog phenotype microarray

**Tools:**
- **CarveMe**: automated GEM reconstruction from annotated genome
- **ModelSEED**: RAST annotation → GEM; includes gap filling
- **MEMOTE**: standardized quality metrics for GEMs

### Gap Filling
- Incomplete networks cannot carry flux to produce biomass
- Gap filling: add minimum set of reactions to make network producible
- GapFind/GapFill (MATLAB), fastgapfill (COBRApy)
- Biological interpretation: missing annotation, uncharacterized enzymes

## Advanced Constraint-Based Methods

### Incorporating Regulatory Constraints

**rFBA (Regulatory FBA)**
- Boolean gene regulatory rules constrain enzyme activity
- At each time point: evaluate Boolean conditions → set reaction bounds → run FBA
- Captures growth-phase-dependent regulation

**TRFBA (Transcriptional Regulatory FBA)**
- Continuous transcriptomic data mapped to reaction bounds
- Expression → enzyme level → flux bounds
- SPOT, E-flux: methods for expression-to-flux mapping

**GECKO (GEM with enzymatic constraints using kcat values)**
- Replace each reaction with enzyme-catalyzed form
- Add constraints on total enzyme usage (proteome allocation)
- Predicts enzyme saturation, optimal proteome composition

### Dynamic FBA (dFBA)
- Couple FBA to dynamic equations for external metabolites:
```
d[S]/dt = -v_exchange(S) × X      (X = biomass)
dX/dt   = μ(S) × X
```
- At each time step: solve FBA given current metabolite concentrations
- Output: time courses of biomass, substrate, product

### Multi-Organism Community Modeling
- Stack GEMs of multiple organisms with shared extracellular compartment
- SteadyCom: steady-state community FBA with equal growth rate constraint
- micom: multi-organism community modeling with cooperation/competition
- Applications: gut microbiome, soil communities, co-culture bioprocesses

## Thermodynamic Analysis

### ΔrG and Reaction Directionality

Gibbs free energy change under physiological conditions:
```
ΔrG = ΔrG° + RT ln Q
```

Where Q is the reaction quotient (actual vs. standard concentrations).

A reaction is thermodynamically feasible only when ΔrG < 0.

### eQuilibrator
- Web tool and Python API for calculating ΔrG°' under specified conditions
- Accounts for pH, ionic strength, magnesium concentration
- `equilibrator-api` Python package for programmatic access
- Uses component contribution method for >4,000 metabolites

### Max-Min Driving Force (MDF) Optimization
- Find metabolite concentrations that maximize the minimum ΔrG across all reactions in a pathway
- Ensures all reactions are thermodynamically feasible simultaneously
- Identifies the thermodynamic bottleneck reaction
- Implemented in: EFMtool (MDF option), pytfa

### Enzyme Cost Minimization (ECM)
- Find kinetically optimal enzyme concentrations for a given flux distribution
- Minimizes total enzyme investment (proteome cost)
- Balances saturation and thermodynamics
- Predicts enzyme levels in metabolic engineering strains

## 13C Metabolic Flux Analysis

### Principle
Feed cells with 13C-labeled carbon source (e.g., [1-¹³C]glucose or [U-¹³C6]glucose).
Measure isotope labeling pattern of metabolites by MS or NMR.
Fit labeling data to stoichiometric model to infer intracellular fluxes.

### Why This Is Needed
FBA predicts optimal fluxes; actual fluxes depend on enzyme levels, regulation, kinetics.
Parallel pathways (e.g., glycolysis vs. pentose phosphate pathway) cannot be resolved by metabolite concentrations alone.
¹³C MFA provides absolute, quantitative fluxes.

### Isotopologue vs. Positional Labeling
- **Isotopologue**: molecules differing by number of ¹³C atoms
- **Mass isotopologue distribution (MID)**: fraction of molecules at each mass shift
- **Positional isotopomers**: specific positions labeled (resolved by NMR, not MS)

### EMU Framework (Elementary Metabolite Units)
- Decomposes network into minimal subunits for isotope simulation
- Dramatic computational speedup vs. full isotopomer models
- Implemented in INCA, IsoDesign, WUFlux, OpenMebius

### INCA (Isotopomer Network Compartmental Analysis)
- MATLAB-based ¹³C MFA software
- Nonlinear least squares fitting to MS data
- Confidence intervals by continuation or bootstrap
- Industry standard for quantitative flux analysis

## Kinetic Modeling of Metabolism

### Kinetic Rate Laws
Beyond stoichiometry: rate equations with explicit enzyme kinetics.
- Michaelis-Menten for each reaction
- Feedback inhibition (product inhibition, allosteric regulation)
- Regulation by co-factors (ATP/ADP ratio, NADH/NAD+ ratio)

### Challenges of Kinetic Models
- Parameter explosion: kcat, Km for each substrate, inhibition constants for each effector
- Parameters often not measurable under in vivo conditions
- Ensemble modeling: sample from plausible parameter distributions

### Ensemble Modeling (EnsembleFBA)
- Generate large ensemble of kinetic models consistent with measured steady-state fluxes
- Use ensemble to make probabilistic predictions about perturbation responses
- Handles parameter uncertainty explicitly

### ME-Model (Metabolism and Expression)
- Couples GEM with gene expression machinery
- Includes: transcription, translation, RNA polymerase allocation, ribosome allocation
- Predicts proteome composition alongside metabolic fluxes
- iJO1366 → iJL1678b-ME: most detailed mechanistic model of E. coli
