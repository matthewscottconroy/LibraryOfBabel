## Network Motifs: The Grammar of Regulation

A motif is a pattern of connections that appears more frequently in biological networks than expected by chance (Milo et al. 2002, Science). Each motif has a characteristic dynamical function.

### Autoregulation

**Negative Autoregulation (NAR)**
- Transcription factor represses its own gene
- Most common motif in bacterial transcription networks
- Dynamical consequences:
  - **Faster response time**: overshoot toward steady state corrected earlier
  - **Noise reduction**: reduces cell-to-cell variability in protein levels
  - **Robustness**: steady-state level less sensitive to production rate fluctuations
- Math: dp/dt = α/(1 + (p/K)^n) - δp vs. dp/dt = α - δp (unregulated)
- NAR reaches steady state faster by factor of ~2 (for n=1) to ~√(2n-1) for high n

**Positive Autoregulation (PAR)**
- Transcription factor activates its own gene
- Slower response time (memory effect)
- Bistability possible with sufficient cooperativity
- All-or-none switching behavior
- Increases cell-to-cell variability

### Feedforward Loops (FFLs)

Three nodes: X → Y → Z, X → Z
X activates (or represses) Y and Z; Y activates (or represses) Z.

8 possible FFLs (2³ sign combinations):

**Coherent Type 1 (C1-FFL)**: X→Y, X→Z, Y→Z (all activation)
- **Sign-sensitive delay**: activation of Z delayed until X is sustained; deactivation of Z is fast
- Filters transient ON pulses; responds only to sustained input
- Pulse generator when sign changes

**Incoherent Type 1 (I1-FFL)**: X→Y, X→Z, Y⊣Z (X activates both; Y represses Z)
- **Pulse generator**: Z shows transient expression then returns to baseline
- **Adaptation**: accelerated response; signal detected but not maintained
- Fold-change detection: responds to fold change in X, not absolute level

Learn all 8 FFL types and their biological examples — this knowledge directly transfers to synthetic circuit design.

### Feedback Loops

**Negative Feedback**
- A → B ⊣ A (or through longer chain)
- Generates homeostasis: system returns to set point after perturbation
- Can generate oscillations if delay in feedback loop is large enough
  - Goodwin oscillator: three-node negative feedback + cooperativity
  - Repressilator: three-node ring of repressors (Elowitz & Leibler 2000)

**Positive Feedback**
- A → B → A (or direct A → A)
- Bistability: two stable steady states
- Switch-like behavior: hysteresis
- Memory: state persists after removal of inducing signal
- Examples: lac operon bistability, CDK/cyclin cell cycle switches, cell fate commitment

## Boolean Network Models

### When to Use Boolean Models
- Mechanism known qualitatively but kinetic parameters not available
- Interest in attractors (cell fates) rather than quantitative dynamics
- Large networks (tens to hundreds of nodes)
- Regulatory logic established from literature

### Boolean Network Formalism
- Each gene is ON (1) or OFF (0)
- Update rule: each gene updated based on Boolean function of its regulators
- Synchronous update: all genes update simultaneously
- Asynchronous update: random or priority-based; better for biological fidelity

**Example (lac operon):**
```
LacY(t+1) = LacI_OFF AND Glucose_OFF
LacI_OFF(t+1) = NOT LacI OR Allolactose
```

### Attractors as Cell States
- **Fixed point attractor**: network reaches stable state → corresponds to stable cell type
- **Limit cycle attractor**: oscillatory behavior → corresponds to cell cycle, circadian rhythm
- **Number of attractors** ≈ number of possible cell types/fates

### Tools
- **GINsim**: GUI-based Boolean network analysis; steady state, reachability
- **PyBoolNet**: Python; attractor analysis, control interventions
- **CellCollective**: web-based; published Boolean models
- **BooleanNet** (Python): simulation and analysis

### From Boolean to Continuous
- Quasi-Boolean (SQUAD): continuous relaxation using sigmoidal functions
- Gives qualitative dynamics matching Boolean attractors
- Useful for visualization and perturbation predictions

## Inferring GRNs from Expression Data

### The Inference Problem
Given expression data across conditions or single cells, infer which genes regulate which.

**Challenges:**
- Correlation ≠ causation: indirect correlations through common regulators
- Underdetermined: more possible edges than observations
- Signal is noisy: stochastic expression, measurement noise

### Information-Theoretic Methods
**ARACNE (Algorithm for the Reconstruction of Accurate Cellular Networks)**
- Mutual information between all gene pairs
- Data Processing Inequality (DPI): if A → B → C, MI(A,C) < min(MI(A,B), MI(B,C))
- Remove indirect interactions using DPI
- Good for: identifying direct gene-gene relationships

**CLR (Context Likelihood of Relatedness)**
- Z-score normalization of mutual information against background
- Better at distinguishing real from spurious correlations

### Regression-Based Methods
**GENIE3**
- Random forest regression: predict each gene's expression from all others
- Feature importance → regulatory weight
- Works well across conditions and single-cell data

**GRNBoost2 (SCENIC)**
- Gradient boosting version of GENIE3 concept; 10× faster
- Part of SCENIC pipeline for scRNA-seq

### SCENIC (Single-Cell rEgulatory Network Inference and Clustering)
- Combines GRN inference with regulon identification
- pySCENIC workflow:
  1. GRNBoost2: identify TF-target candidate links
  2. RcisTarget: filter by motif enrichment in target gene promoters
  3. AUCell: score regulon activity per cell
- Output: regulon activity matrix → cell type annotation independent of clustering

### Network Controllability
- Liu et al. 2011 (Nature): minimum driver nodes to control network state
- Maximum matching algorithm to find minimum control set
- Stem cell reprogramming factors often correspond to driver nodes
- Application: identify minimal gene set to reprogram cell fate (Yamanaka factors)

## Epigenetic Network Modeling

### Chromatin State as Memory
- Positive feedback in histone modification spreads epigenetic marks
- PRC2 (Polycomb): reads H3K27me3 → methylates nearby nucleosomes → positive feedback
- This creates a bistable system: active or silenced chromatin
- Mathematical model: bistable switch with two attractors

### DNA Methylation Dynamics
- DNMT3A/B: de novo methylation
- DNMT1: maintenance methylation (copies pattern after replication)
- TET enzymes: demethylation (5mC → 5hmC → 5fC → 5caC → cytosine)
- Modeling: differential equations for methylation fraction at each CpG
- Key insight: methylation is not binary — partial methylation at single-cell level

### Chromatin Accessibility Models
- Nucleosome occupancy as a function of sequence (DNase I footprinting, ATAC-seq)
- Nucleosome positioning energy landscape: AT-rich regions exclude nucleosomes
- Transcription factor binding competition with nucleosomes
- Mechanistic model: Thermodynamic model of regulatory element occupancy

## Circadian Clock as a Model System

The circadian clock is the best-studied biological oscillator — ideal for learning oscillator modeling.

### Architecture (Mammals)
- CLOCK-BMAL1 heterodimer: activates Per1/2, Cry1/2, Rev-erb, Ror
- PER-CRY: represses CLOCK-BMAL1 (delayed negative feedback)
- REV-ERBα: represses Bmal1 (reinforcing negative feedback)
- Core loop period: ~24 hours
- Temperature compensation: period insensitive to temperature

### Goldbeter-Leloup Model (16 ODE model)
- Detailed kinetic model of mammalian circadian clock
- Includes: phosphorylation states of PER and CRY
- Captures: oscillation, light entrainment, temperature compensation
- Used as: benchmark for circadian drug target identification

### Simpler Models for Teaching
- Goodwin oscillator: X → Y → Z ⊣ X; oscillates with n > 8 (steep repression)
- Kim-Forger model (3 variables): captures essential clock dynamics
- Key: negative feedback + time delay = oscillation potential

### Lessons from Circadian Clock
1. Oscillation requires strong nonlinearity (high Hill coefficients)
2. Robustness can come from redundant feedback loops
3. Temperature compensation: parameter compensation balances different temperature sensitivities
4. Entrainment: input signals (light/temperature) entrain the oscillator

## Cell Fate Decision Networks

### Bistability as Decision-Making

When a cell commits to a fate (stem cell → neuron), the gene network transitions between attractors.

**Requirements for bistability:**
1. Positive feedback (directly or via double negative)
2. Nonlinearity (Hill coefficient > 1 helps)
3. Cross-repression between alternative states

**Example: GATA1/PU.1 bistable switch (hematopoiesis)**
- GATA1 (erythroid) and PU.1 (myeloid) mutually repress each other
- Each also activates itself (positive autoregulation)
- Double mutual repression with autoregulation → robust bistability
- External signals (cytokines) tip the balance

### Waddington Landscape
- Conceptual: cell states as balls in valleys; differentiation as rolling down slopes
- Mathematical formalization: quasipotential landscape
- Computing landscapes: solve for stationary distribution of stochastic dynamics
- Limitations: landscape changes with cell state (landscape is not static)

### Overriding Cell Fate: Yamanaka Reprogramming
- 4 transcription factors (Oct4, Sox2, Klf4, c-Myc) reprogram somatic → iPSC
- Network analysis: these factors are "master regulators" with high connectivity
- Bistability: reprogramming is a transition between two attractors
- Path through state space: not smooth but jump through specific intermediate states

## Practical Network Analysis

```python
import networkx as nx
import pandas as pd

# Build directed graph from edge list
edges = pd.read_csv('grn_edges.csv')  # source, target, weight, sign
G = nx.DiGraph()
for _, row in edges.iterrows():
    G.add_edge(row['source'], row['target'], 
               weight=row['weight'], sign=row['sign'])

# Basic statistics
print(f"Nodes: {G.number_of_nodes()}")
print(f"Edges: {G.number_of_edges()}")
print(f"Density: {nx.density(G):.4f}")

# Hub genes (high out-degree = master regulators)
out_degrees = sorted(G.out_degree(), key=lambda x: x[1], reverse=True)
print("Top regulators:", out_degrees[:10])

# Strongly connected components
sccs = list(nx.strongly_connected_components(G))
print(f"SCCs: {len(sccs)}")

# Feedback loops (cycles)
cycles = list(nx.simple_cycles(G))
feedback = [c for c in cycles if len(c) >= 2]
```
