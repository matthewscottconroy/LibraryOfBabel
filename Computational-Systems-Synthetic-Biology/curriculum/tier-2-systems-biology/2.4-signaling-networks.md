# 2.4 Signaling Networks

How cells receive, process, and respond to information from their environment.

---

## Signal Transduction Principles

### What Signaling Achieves
- Converts extracellular information (ligand concentration, mechanical force, light) into intracellular response
- Amplification: small number of ligand-receptor events → large intracellular response
- Filtering: distinguish signal from noise; respond to rates of change, not absolute levels
- Integration: combine multiple inputs
- Adaptation: return to baseline despite persistent signal

### The MAPK Cascade as Canonical Model

The Mitogen-Activated Protein Kinase (MAPK) cascade appears in virtually every eukaryote:
```
Growth factor → Receptor → RAS → RAF → MEK → ERK
```

**Why a cascade?**
1. **Signal amplification**: each kinase activates multiple downstream kinases
2. **Ultrasensitivity**: each phosphorylation-dephosphorylation cycle can produce switch-like response
3. **Insulation**: different cascades can operate independently despite shared substrates
4. **Temporal filtering**: cascade introduces multiple time constants

### Goldbeter-Koshland Zero-Order Ultrasensitivity

A single phosphorylation-dephosphorylation cycle:
```
Kinase + Substrate ⇌ K:S → Kinase + Substrate-P
Phosphatase + Substrate-P ⇌ PP:S-P → Phosphatase + Substrate
```

When both kinase and phosphatase are near saturation (zero-order kinetics), the response becomes extremely switch-like:
- Small change in kinase/phosphatase ratio → large change in phosphorylation
- Hill coefficient equivalent can approach 20-40
- Mechanism: kinase "wastes cycles" on already-phosphorylated substrate; only when unphosphorylated substrate is limiting does net phosphorylation change sharply

Significance: explains ultrasensitive responses without requiring cooperative binding.

## Receptor-Ligand Interactions

### Simple Binding Equilibrium
```
Receptor + Ligand ⇌ RL      Kd = [R][L]/[RL]
```

Occupancy fraction: θ = [L] / (Kd + [L])
- This is a Hill function with n=1 (hyperbolic, not switch-like)
- To get ultrasensitivity from receptor alone: cooperative binding required (n > 1)

### G Protein-Coupled Receptors (GPCRs)

Signal transduction chain:
1. Agonist binds GPCR → conformational change
2. GPCR exchanges GDP for GTP on Gα subunit → activation
3. Gα-GTP and Gβγ dissociate → each activates effectors
4. Gα-GTP hydrolyzes GTP → Gα-GDP → reassociation with Gβγ → inactivation

**Second messenger pathways:**
- Gαs → adenylyl cyclase → ↑cAMP → PKA activation
- Gαi → adenylyl cyclase inhibition → ↓cAMP
- Gαq → PLCβ → IP3 + DAG → Ca²⁺ release + PKC activation
- Gβγ → PI3K, ion channels

### Receptor Tyrosine Kinases (RTKs)

1. Ligand binding (often dimerization of two monomers)
2. Transautophosphorylation of activation loop
3. Recruitment of SH2-domain proteins to phosphotyrosines
4. Activation of downstream pathways: RAS-MAPK, PI3K-AKT, STAT

**Receptor internalization and trafficking:**
- Receptor endocytosis: clathrin-mediated or caveolae
- Endosome → lysosome: degradation (signal termination)
- Endosome → recycling: receptor recycled to surface
- Spatial control: nuclear vs. cytoplasmic signaling

### TGF-β / Smad Pathway (Pattern Formation)

TGF-β family ligands establish morphogen gradients:
1. BMP/TGF-β → receptor serine/threonine kinase
2. Type I receptor phosphorylates R-Smad (Smad1/5/8 or Smad2/3)
3. R-Smad + co-Smad4 → nucleus → gene expression
4. I-Smads (Smad6/7): negative feedback; recruited by receptor, competes with R-Smad

Mathematical model: receptor activation + Smad shuttling + transcriptional response

## Calcium Signaling

### Why Calcium?

Ca²⁺ is a near-universal second messenger:
- Resting cytoplasmic [Ca²⁺] ≈ 100 nM
- ER lumen [Ca²⁺] ≈ 0.1–1 mM (1,000–10,000× higher)
- Extracellular [Ca²⁺] ≈ 1.2 mM
- Steep gradient maintained by SERCA pumps and plasma membrane ATPases

### IP3-Induced Ca²⁺ Release

1. Gαq → PLCβ → IP3 + DAG
2. IP3 binds IP3R on ER membrane → channel opens → Ca²⁺ release
3. Calcium-induced calcium release (CICR): Ca²⁺ activates ryanodine receptors
4. Ca²⁺ feedback: activates and inhibits IP3R (bell-shaped dependence)

**Calcium oscillations** emerge from this feedback:
- At low IP3: sub-threshold pulses, no oscillation
- At intermediate IP3: regular oscillations (encoding: frequency modulated)
- At high IP3: sustained elevated Ca²⁺

**Modeling:** De Young-Keizer model (9 ODEs for IP3R states + [Ca²⁺])

### Calcium-Regulated Proteins
- Calmodulin: binds 4 Ca²⁺ → activates CaM kinases, adenylyl cyclases, phosphodiesterases
- Troponin C: muscle contraction
- PKC: activated by Ca²⁺ + DAG (from same IP3-generating pathway)

## Signal Integration & Information Processing

### AND Gate Logic in Signaling

Many signaling decisions require co-incident signals:
- T cell activation: TCR signal AND CD28 co-stimulation
- B cell activation: BCR signal AND T cell help
- mTORC1 activation: growth factor signal AND amino acid sufficiency

Mathematical implementation:
- Multiplicative: output ∝ signal_A × signal_B
- Requires threshold nonlinearities on each input for sharp switching

### Adaptation

System returns to baseline despite persistent signal. Required for: perfect adaptation.

**Exact adaptation mechanisms:**
1. **Integral feedback control**: system integrates the error and adjusts until output = setpoint
   - Implementation: slow negative feedback through an integrating enzyme
   - Example: *E. coli* chemotaxis methylation system (perfect adaptation)
2. **Incoherent feedforward with specific parameters**

*E. coli* chemotaxis:
- Receptor methylation: adapted state
- CheR: methylates receptors (activating)
- CheB: demethylates receptors (phosphorylated by kinase CheA) → feedback
- At any steady-state attractant concentration: CheB-P brings tumbling rate back to baseline

### Signal Duration Encoding (Proliferation vs. Differentiation)

In PC12 cells (Bhalla & Iyengar 1999):
- EGF (transient ERK activation) → proliferation
- NGF (sustained ERK activation) → differentiation
- Difference: NGF activates Rap1 → B-Raf pathway → sustained ERK
- ERK activation duration encoded as binary decision by positive feedback bistability

Lesson: the same concentration of two different ligands can produce qualitatively different outcomes based on signal duration → cells are not just measuring concentration.

## Network Crosstalk and Specificity

### The Paradox

Many signaling pathways share components (Ras, Erk, PI3K) but produce distinct responses. How is specificity maintained?

**Mechanisms of specificity:**
1. **Scaffold proteins**: MAPK scaffolds (KSR, IQGAP) co-localize pathway components; prevent crosstalk by sequestering
2. **Compartmentalization**: signals at different subcellular locations (PM vs. endosome vs. nucleus)
3. **Kinetics**: different time courses activate different downstream targets
4. **Signal amplitude**: weak vs. strong activation of same kinase → different outcomes
5. **Combinatorial coding**: unique combinations of active components → unique outputs

### Phosphoproteomics of Signaling

Map signaling network states experimentally:
- Treat cells with ligands → timecourse phosphoproteomic measurements
- Hundreds to thousands of phosphosites quantified
- Network inference: which kinase phosphorylates which substrate (KSEA, PhosphoSitePlus)
- ODE modeling of signaling dynamics from phosphoproteomic timecourses (PLSR, ODE fitting)
