# 3.2 Genetic Circuit Design

Composing parts into systems that compute — the synthetic biology equivalent of digital logic design.

---

## Circuit Design Philosophy

### The Design-Build-Test-Learn (DBTL) Cycle

1. **Design**: specify desired function; model mathematically; select parts
2. **Build**: assemble DNA; transform into cell
3. **Test**: measure circuit behavior (flow cytometry, plate reader, microscopy)
4. **Learn**: compare measurement to prediction; update model; identify failure modes
5. Return to step 1

Modern synthetic biology compresses this cycle. Key tools:
- DNA synthesis: design → physical DNA in days (not weeks of cloning)
- Automated liquid handling: test many variants in parallel
- High-throughput measurement: flow cytometry for single-cell distributions
- Machine learning: guide next design iteration

### Modeling Before Building

Always model before building. A model that doesn't predict the data forces you to understand why.

**Transfer function framework:**
- Each part: input concentration → output concentration (or activity)
- Fit Hill function: f(x) = α·xⁿ / (Kⁿ + xⁿ)
- Compose parts: output of part A is input to part B
- Predict circuit behavior from part parameters

**When models fail:**
- Context effects: part parameters changed by neighboring sequences
- Retroactivity: downstream load changes upstream behavior
- Off-target binding: TF binds unintended genomic sites
- Metabolic burden: high expression drains resources, slows growth

## Logic Gates

### Biological Implementation of Logic

**NOT gate (Inverter)**
```
Input signal (X) → Transcriptional repressor → Output OFF
Output ON when Input OFF
```
- Input: presence of X (or concentration above threshold)
- Mechanism: X activates or IS a transcriptional repressor of output gene
- Simplest: pTet-repressor-pTarget construction

**AND gate**
```
Output ON only when Input A AND Input B are both present
```
Two implementations:
1. **Protein-fragment complementation**: two halves of a TF fused to dimerization domains; reconstitute only when both inputs present
2. **Sequential promoters**: Input A controls expression of activator; activator at activatable promoter only responds when Input B also present
3. **Two-input operators**: some promoters have two operator sites; both must be occupied for maximal expression

**OR gate**
```
Output ON when Input A OR Input B present
```
- Two promoters, each responding to one input, driving same output gene
- OR logic naturally follows from additive transcription

**NOR gate (most powerful basic gate)**
```
Output ON when neither A nor B present
```
- A and B each encode repressors of the output
- Natural two-repressor design
- Why NOR is important: NOR gates are functionally complete — any Boolean function can be constructed from NOR gates alone

**NAND gate**
```
Output OFF only when both A and B present
```
- One input must be absent to relieve repression
- A encodes repressor 1; B encodes repressor 2
- Both repress output only when both present simultaneously (cooperativity needed)

### Implementing in Cells

**Transcription Factor-Based**
- Mostly zinc fingers, TALEs, or synthetic TFs
- Requires a separate promoter for each gate output

**CRISPR-Based (CRISPR-gates)**
- dCas9 with different sgRNAs implement different gate logic
- Multiplexable: many sgRNAs at once
- dCas9 is a shared resource → saturation at high circuit complexity

**RNA-Based Gates**
- Toehold switches: programmable logic at RNA level
- No translation until trigger RNA present
- Cell-free: particularly powerful without cellular constraints

## Two-State Memory: The Toggle Switch

### Gardner, Cantor & Collins (2000)

Two repressors, each repressing the other's expression:
```
Repressor1 ⊣ promoter2 → Repressor2
Repressor2 ⊣ promoter1 → Repressor1
```

**Bistable conditions (necessary):**
- Cooperativity: Hill coefficient n > 1 for at least one repressor
- Symmetric: roughly equal repressor strengths

**ODE Model:**
```
du/dt = α₁/(1 + v^β) - u      (u = repressor 1)
dv/dt = α₂/(1 + u^γ) - v      (v = repressor 2)
```

Bistable if: both nullclines have an odd-number intersection pattern (3 intersections: 2 stable, 1 unstable)

**Switching:**
- Expose cells to inducer of repressor 1 (e.g., IPTG for LacI) → tips to State 2
- Remove inducer: stays in State 2 (memory)
- Expose to inducer of repressor 2 (aTc for TetR) → tips to State 1

**State report:** fluorescent protein driven by each promoter → read switch state by flow cytometry

**Why it sometimes fails:**
- Asymmetric expression levels: one state dominates; monostable
- Insufficient cooperativity: bistability condition not met
- Plasmid copy number variation: affects absolute expression levels

## Oscillators

### Elowitz & Leibler Repressilator (2000)

Three repressors in a cycle:
```
TetR ⊣ λcI ⊣ LacI ⊣ TetR
```

**Conditions for oscillation:**
- Negative feedback loop with odd number of repressors (all-repressor ring)
- Sufficient nonlinearity (high Hill coefficient)
- Delay in the loop (protein synthesis time acts as delay)
- Repressor degradation must be fast enough

**ODE model (6 variables: 3 mRNAs + 3 proteins):**
```
dm_i/dt = -m_i + α/(1 + p_j^n) + α₀
dp_i/dt = -β(p_i - m_i)
```

Period ≈ few hours; heterogeneous across cells (high cell-to-cell variability in original paper).

**Improved oscillators:**
- Stricker et al. 2008: mixed positive-negative feedback; more robust, tunable
- Danino et al. 2010: microfluidic synchronization via quorum sensing
- Castillo-Hair et al. 2020: single-cell oscillators with improved consistency

**Synchronization:**
- Autonomous oscillators are noisy → cell populations desynchronize
- Solution: couple oscillators via quorum sensing signal
- Degradation tags (ssrA): fast protein degradation sharpens oscillation

## Feedforward Pulse Generators

**I1-FFL pulse generator:**
```
X → Y (fast path)
X → Z ← ⊣ Y (Z activated by X, repressed by Y)
```

When X turns ON:
- Z activates immediately (direct X→Z activation)
- Y slowly accumulates, then represses Z
- Result: transient pulse of Z expression

When X turns OFF:
- Y quickly degrades (no longer made)
- Z activates briefly (Y repression relieved)
- Result: OFF-pulse

Applications:
- Biosensors: detect transient signals
- Pulse-width modulation: control timing of downstream events
- Edge detection: detect changes in input

## Band-Pass Filters

Output ON only when input is in a specific range.

**Two-threshold implementation:**
- Low threshold: input activates activator A; A activates output
- High threshold: input activates repressor R; R represses output
- Result: output ON for intermediate input concentrations

**Biological applications:**
- Detect specific concentration range of a metabolite
- React to a "normal" level, not too low or too high
- Used in: synthetic homeostatic circuits, therapeutic cell control

## Retroactivity and Loading

### The Problem

When you connect circuit A (upstream) to circuit B (downstream):
- Circuit B has receptors/TFs that bind the output of circuit A
- This binding "titrates" the output molecule away
- The upstream circuit "sees" a changed load → its dynamics change
- This is **retroactivity**: downstream affects upstream

**Analogy:** In electronics, connecting a low-impedance load to a high-impedance amplifier drops output voltage.

### Mathematical Treatment (Del Vecchio et al.)

For a gene A producing protein p, loaded by downstream target with n binding sites:
```
dp/dt = α_A - δ_A·p - (retroactivity term)
```

Retroactivity = (dp_bound/dt) where p_bound = p·[target] / (Kd + p)

**Solutions:**
1. Increase production rate (α_A): higher expression compensates for titration
2. Insulation device: amplifier between stages (phosphorylation-dephosphorylation cycle acts as insulator)
3. Add more degradation tags: fast turnover reduces steady-state titration

### Metabolic Burden

High-expression genetic circuits compete with host cell for:
- Ribosomes (largest burden: protein synthesis)
- RNA polymerase
- Amino acids and nucleotides
- ATP
- Molecular chaperones

**Consequences:**
- Growth rate reduction: circuit "taxes" the cell
- Feedback on circuit itself: host regulates global translation in response to stress
- Evolved resistance: cells with disrupted circuits grow faster → take over population

**Mitigation:**
- Use tightly regulated promoters: express only when needed
- Minimize protein length: smaller proteins cost fewer ribosomes
- Orthogonal expression systems: T7 RNAP + T7 promoter circuits independent of host RNAP
- Protein degradation tags: rapid turnover reduces steady-state levels

## CELLO: Automated Circuit Design

### What CELLO Does

CELLO (2016, Nielsen et al.) automates the Design step:
- Input: desired Boolean function (as truth table or Verilog-like HDL)
- Output: DNA sequences implementing the function using characterized genetic gates

### How It Works

1. **Gate library**: characterized transcription factor gates (input→output Hill functions with parameters)
2. **Assignment**: map abstract Boolean gates to biological gates; combinatorial search
3. **Optimization**: minimize total circuit output variability; score using ON/OFF ratios
4. **Constraint checking**: verify no input-output signal mismatches between connected gates

### Gate Scoring

For a circuit with multiple gates: circuit output is the product of all gate transfer functions.
- Score = ratio of lowest ON output to highest OFF output
- High score → robust circuit; low score → ambiguous output

### Organism-Specific Gate Libraries

- cSynBio (E. coli): well-characterized TF library
- Yeast gate library under development
- Expanding to mammalian cells (more limited characterized gates)

**Lesson:** circuit automation requires quantitatively characterized parts. The investment in part characterization enables automated design.

## Practical Design Checklist

Before building any circuit:
- [ ] Write down the Boolean or analog function you want
- [ ] Select parts with compatible input/output ranges (signal matching)
- [ ] Model with ODEs; confirm steady states and dynamics
- [ ] Check bistability conditions if memory is required; check Hopf conditions if oscillation required
- [ ] Include degradation tags on TFs (ssrA or equivalent)
- [ ] Add insulators between transcription units
- [ ] Design negative controls (each part knocked out individually)
- [ ] Choose assay: flow cytometry (single-cell distributions), plate reader (bulk), microscopy (spatial/temporal)
