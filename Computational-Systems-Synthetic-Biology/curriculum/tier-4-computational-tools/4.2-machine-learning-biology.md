## Classical Machine Learning

### Why Classical ML Still Matters

Deep learning dominates headlines, but:
- Small tabular datasets (proteomics, metabolomics): random forest consistently outperforms DL
- Interpretability: feature importance tells you which genes or measurements drive predictions
- Compute: train in seconds, not hours
- Robustness: less likely to overfit on small datasets

### Decision Trees and Ensemble Methods

**Random Forest**
- Ensemble of decision trees trained on bootstrap samples with random feature subsets
- Aggregation by voting (classification) or averaging (regression)
- Out-of-bag (OOB) error: built-in cross-validation
- Feature importance: mean decrease in impurity at splits using that feature
- Works well for: expression data, variant effect prediction, clinical genomics

**Gradient Boosting (XGBoost, LightGBM)**
- Sequential trees: each corrects errors of previous ensemble
- State of the art on tabular data competitions (Kaggle)
- XGBoost: `xgboost.XGBClassifier`; native handling of missing values
- LightGBM: 10–100× faster than XGBoost for large datasets; leaf-wise splitting

### Support Vector Machines

- Find maximum-margin hyperplane separating classes
- Kernel trick: implicitly map to high-dimensional feature space
  - RBF kernel: works for most biological data
  - String kernel: for raw sequence data
- SVR (Support Vector Regression): predict continuous values
- Applications: protein function prediction, splice site detection
- scikit-learn: `SVC(kernel='rbf', C=1.0, gamma='scale')`

### Clustering

**k-means**
- Partition into k clusters minimizing within-cluster variance
- Must specify k in advance; use elbow plot or silhouette score
- Sensitive to initialization (run multiple times, use k-means++)
- Limitation: assumes spherical clusters; fails for elongated or non-convex clusters

**Hierarchical clustering**
- Build dendrogram by iterative merging (agglomerative) or splitting (divisive)
- Linkage methods: single, complete, average, Ward
- Ward's method: minimizes within-cluster variance; often best for gene expression
- Visualize with heatmap + dendrogram: `seaborn.clustermap`

**DBSCAN**
- Density-based: clusters are dense regions; outliers are low-density points
- No need to specify k; discovers arbitrary-shaped clusters
- Good for: noisy data, unknown number of clusters
- Two parameters: eps (neighborhood radius) and minPts (min cluster size)

### Dimensionality Reduction

**PCA (Principal Component Analysis)**
- Linear projection maximizing variance
- PC1 = direction of maximum variance; PC2 = orthogonal to PC1, next maximum
- Eigendecomposition of covariance matrix (or SVD)
- Use for: sample QC, batch effect visualization, variance explained
- Key: always use PCA before UMAP/t-SNE; UMAP/t-SNE on top 30-50 PCs

**UMAP (Uniform Manifold Approximation and Projection)**
- Non-linear; constructs high-dimensional fuzzy topological structure → optimize low-dimensional analog
- Preserves local neighborhood structure better than t-SNE
- Faster than t-SNE for large datasets
- Key parameters: n_neighbors (local vs. global balance), min_dist (cluster compactness)
- **Warning**: distances in UMAP space are not meaningful; only topology/neighborhood

**t-SNE**
- Minimizes KL-divergence between high-dim and low-dim pairwise distance distributions
- Excellent for revealing cluster structure
- Perplexity parameter: effective number of neighbors (~5–50; default 30)
- Non-deterministic; run multiple times; compare
- Slower than UMAP; does not scale well to >100,000 points

## Deep Learning

### Neural Network Fundamentals

**Architecture**
- Layers: input → hidden → output
- Activation functions: ReLU (default hidden layers), sigmoid/softmax (output for classification)
- Weights: initialized randomly; updated by backpropagation

**Training**
- Loss function: cross-entropy (classification), MSE (regression)
- Optimizer: Adam (adaptive learning rates per parameter; default)
- Batch normalization: normalize activations within mini-batch; speeds training
- Dropout: randomly zero activations during training; regularization
- Early stopping: monitor validation loss; stop when it increases

**Overfitting Diagnosis**
- Training loss decreases, validation loss increases → overfitting
- Solutions: more data, dropout, L2 regularization, simpler model, data augmentation

### Convolutional Neural Networks (CNNs) for Sequences

DNA/RNA sequences treated as 1D signals:
```python
import torch
import torch.nn as nn

class SequenceCNN(nn.Module):
    def __init__(self, n_filters=64, kernel_size=8, seq_length=1000):
        super().__init__()
        self.conv1 = nn.Conv1d(4, n_filters, kernel_size)  # 4 = one-hot DNA
        self.relu = nn.ReLU()
        self.pool = nn.MaxPool1d(4)
        self.fc = nn.Linear(n_filters * ((seq_length - kernel_size + 1) // 4), 1)
    
    def forward(self, x):  # x: (batch, 4, seq_len) one-hot encoded
        x = self.pool(self.relu(self.conv1(x)))
        x = x.flatten(1)
        return torch.sigmoid(self.fc(x))
```

**Applications:**
- DeepBind: TF binding prediction from sequence
- DeepSEA: chromatin effects of sequence variants
- Enformer: predict gene expression from sequence (200 kb context window)
- SpliceAI: splice site prediction; clinical variant interpretation

**What CNNs learn from sequence:**
- First layer filters: often correspond to known TF binding motifs
- Visualization: saliency maps show which positions drive predictions
- Motif discovery from learned filters: compare to JASPAR/HOCOMOCO

### Recurrent Neural Networks (RNNs / LSTMs)

Handle variable-length sequences with long-range dependencies:
- LSTM (Long Short-Term Memory): gated cells remember/forget; handles sequences up to ~1000 nt
- Bidirectional LSTM: process sequence in both directions; captures full context
- Applications: protein secondary structure prediction, splicing, codon usage

**Largely superseded by Transformers for most sequence tasks.**

### Transformers

Self-attention mechanism: each position attends to all other positions simultaneously:
```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

Where Q, K, V are learned linear projections of the input.

**Key advantages over RNNs:**
- No sequential bottleneck: parallel computation
- Global context: every position directly attends to every other
- Scales to very long sequences with attention modifications (linear attention, sparse attention)

**Transformer applications in biology:**
- AlphaFold2 Evoformer: processes MSA + pairwise features with attention
- ESM-2: protein language model (650M to 15B parameters)
- DNABERT, Nucleotide Transformer: DNA language models
- Enformer: chromatin state prediction with Transformer architecture

### Protein Language Models

Trained on sequences in UniRef/UniProt using masked language model objective (predict masked residues):

**ESM-2 (Meta, Lin et al. 2023)**
- Trained on 250M protein sequences
- 15B parameter version achieves near AlphaFold accuracy for some tasks
- Embeddings: 1280-dimensional per residue; capture:
  - Structural context
  - Evolutionary conservation
  - Functional class
  - Contact map

```python
import torch
from esm import pretrained

model, alphabet = pretrained.esm2_t33_650M_UR50D()
batch_converter = alphabet.get_batch_converter()
model.eval()

data = [("protein1", "MKTIIALSYIFCLVFA")]
batch_labels, batch_strs, batch_tokens = batch_converter(data)

with torch.no_grad():
    results = model(batch_tokens, repr_layers=[33], return_contacts=True)

token_representations = results["representations"][33]  # per-residue embeddings
```

**Fine-tuning for downstream tasks:**
- Freeze embeddings; train linear head for property prediction
- Full fine-tuning: adjust all weights; requires more data
- Tasks: thermostability, catalytic activity, binding affinity, disorder prediction

### Graph Neural Networks (GNNs) for Molecular Data

Molecules as graphs: atoms = nodes, bonds = edges.

**Message passing:**
```
h_v^(k+1) = UPDATE(h_v^(k), AGGREGATE({h_u^(k) : u ∈ N(v)}))
```

**Architectures:**
- SchNet: radial basis functions on distances; continuous-filter convolution
- DimeNet: directional message passing using bond angles
- GearNet: protein backbone graph; geometric features

**Applications:**
- Molecular property prediction: toxicity, solubility, binding affinity
- Drug-target interaction: graph representation of protein + ligand
- Reaction prediction: model chemical reactions as graph transformations

### Generative Models in Biology

**Variational Autoencoders (VAEs)**
- Encoder: sequence → latent code z
- Decoder: z → sequence
- Latent space: interpolate between sequences; sample new sequences
- EVE: unsupervised fitness prediction from evolutionary sequences

**Diffusion Models**
- Forward process: add noise to data
- Reverse process: learn to denoise
- RFdiffusion: protein backbone generation
- Chroma, FrameDiff: alternative protein diffusion models

**Language Model Sampling (ESM-2 / ProtGPT2)**
- Generate protein sequences by sampling from trained language model
- Condition on: partial sequence, functional keywords, structure

## Application-Specific Models

### Regulatory Element Prediction

**Predicting TF binding from sequence:**
- JASPAR: position weight matrix (PWM) motifs; traditional
- DeepBind: CNN learning from SELEX-seq data; outperforms PWMs
- Basenji/Enformer: predict chromatin accessibility and gene expression from sequence

**Predicting chromatin states:**
- DeepSEA: predict 919 chromatin marks from 1 kb sequence window
- ChromDragoNN: integrates sequence + accessibility for expression prediction
- ENCODE models: large consortium of trained models

### Variant Effect Prediction

**In silico mutagenesis:**
- Feed reference and alternate allele to model
- Difference in output score = predicted functional effect

**Specific tools:**
- AlphaMissense: missense variant pathogenicity (Google DeepMind)
- ESM-1v: zero-shot variant effect prediction from language model
- EVCouplings: evolutionary constraint at each position
- CADD: combined annotation-dependent depletion score

### Drug-Target Interaction

- Graph-based: both drug (molecular graph) and target (protein graph) encoded
- TransformerDTA, DeepPurpose: transformer-based encoding
- AlphaFold + docking: structure-based approach
- QSAR (Quantitative Structure-Activity Relationship): classical ML on molecular features

## Evaluation and Pitfalls

### Data Leakage

The most common mistake in biological ML:
- Homologous sequences in train and test sets → inflated performance
- Split data by protein family or species, not random split
- Temporal split for time-series predictions

### Proper Cross-Validation

```python
from sklearn.model_selection import StratifiedKFold, cross_val_score

# Stratified: maintains class balance in each fold
cv = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
scores = cross_val_score(model, X, y, cv=cv, scoring='roc_auc')
```

For sequence data: cluster-based CV (split by sequence cluster, not random)

### Interpretability

**SHAP (SHapley Additive exPlanations)**
```python
import shap
explainer = shap.TreeExplainer(rf_model)
shap_values = explainer.shap_values(X_test)
shap.summary_plot(shap_values[1], X_test, feature_names=gene_names)
```

**Saliency maps for neural networks:**
```python
# Gradient of output w.r.t. input
x.requires_grad_(True)
output = model(x)
output.backward()
saliency = x.grad.abs()  # high gradient = important position
```
