## Graph Theory Fundamentals for Biology

### Basic Metrics

```python
import networkx as nx

G = nx.DiGraph()  # or nx.Graph() for undirected

# Add edges with weights
G.add_edge('TF_A', 'Gene_B', weight=1.5, sign='activation')

# Degree
print(G.in_degree('Gene_B'))   # number of regulators
print(G.out_degree('TF_A'))    # number of targets

# Density
print(nx.density(G))  # fraction of possible edges present
```

### Degree Distribution

The distribution of degrees across all nodes.

**Scale-free networks:** P(k) ~ k^(-γ)
- A few nodes (hubs) with very high degree; most nodes with low degree
- Power-law distribution
- Often found in PPI networks; though statistical tests disputed
- Biological implication: hub proteins (like TP53, EGFR) are bottlenecks; disruption is catastrophic

**Exponential networks:** P(k) ~ e^(-k/k₀)
- Degree capped; no extreme hubs
- Found in some GRNs (E. coli regulatory network)

### Clustering Coefficient

Fraction of a node's neighbors that are also connected to each other (triangle density):
- Local clustering: how embedded a node is in its neighborhood
- Global clustering: average over all nodes
- High clustering → modular, redundant network topology

### Path Length and Small World

- Average shortest path length L: diameter of network
- Small world: high clustering + short path length (relative to random graph)
- Watts-Strogatz model: interpolation between regular lattice and random graph
- Most biological networks are small world

### Centrality Measures

```python
# Betweenness centrality: fraction of all shortest paths passing through node
betweenness = nx.betweenness_centrality(G)

# Eigenvector centrality: importance = neighbor importance (Google PageRank)
eigenvector = nx.eigenvector_centrality(G)

# Closeness centrality: how close to all other nodes
closeness = nx.closeness_centrality(G)

# PageRank: random walk-based; good for directed networks
pagerank = nx.pagerank(G, alpha=0.85)
```

**Biological interpretation:**
- High betweenness: bottleneck; disruption disconnects network
- High eigenvector: connected to important nodes (master regulators)
- Hubs + bottlenecks overlap often but not always

## Community Detection

### Why Communities Matter

Biological networks are modular:
- Protein complexes form cliques
- Metabolic pathways form functional modules
- Regulons form co-regulated gene communities

### Algorithms

**Louvain algorithm**
- Optimize modularity Q = Σ [A_ij - k_ik_j/2m] δ(c_i, c_j)
- Two-phase: local optimization; aggregate
- Non-deterministic; run multiple times
- Good for: large networks; fast
- NetworkX: `nx.community.louvain_communities(G, seed=42)`

**Leiden algorithm**
- Corrects Louvain's tendency to produce badly connected communities
- Preferred for high-quality community detection
- python-igraph: `g.community_leiden(objective_function='modularity')`

**Hierarchical clustering**
- Dendrograms reveal nested community structure
- Girvan-Newman: iteratively remove highest-betweenness edges
- Reveals hierarchy of modules (appropriate for metabolic networks)

**Infomap**
- Information-theoretic; minimize description length of random walk
- Excellent for directed networks
- python-igraph: `g.community_infomap()`

### Evaluating Communities

- **Modularity Q**: how much better than random? Q > 0.3 = reasonable; Q > 0.6 = strong
- **Silhouette score**: within-community vs. between-community distances
- Biological validation: do communities correspond to known pathways or complexes?

## Network Motif Analysis

Network motifs: subgraph patterns significantly overrepresented relative to random graphs.

```python
# Using pymotifs or manual implementation
# For small networks: enumerate all subgraphs

# Compare to randomized networks (configuration model preserves degree sequence)
def generate_random_network(G, n_swaps=100):
    """Erdős-Gallai: preserve degree sequence via edge swaps"""
    G_rand = G.copy()
    for _ in range(n_swaps * G.number_of_edges()):
        edges = list(G_rand.edges())
        e1, e2 = np.random.choice(len(edges), 2, replace=False)
        a, b = edges[e1]
        c, d = edges[e2]
        if a != c and b != d and not G_rand.has_edge(a, d) and not G_rand.has_edge(c, b):
            G_rand.remove_edge(a, b)
            G_rand.remove_edge(c, d)
            G_rand.add_edge(a, d)
            G_rand.add_edge(c, b)
    return G_rand
```

Z-score: (N_real - <N_random>) / σ_random > 2: motif is overrepresented

**Canonical biological motifs:**
- FFL (feedforward loop): #3 of 13 possible 3-node motifs in E. coli
- Bi-fan: two TFs co-regulate two genes; most significant motif in E. coli GRN
- Dense overlapping regulons (DORs): many TFs regulate many genes combinatorially

## Protein-Protein Interaction (PPI) Networks

### Data Sources

- **BioGRID**: experimentally validated interactions; yeast-two-hybrid, AP-MS, genetic
- **STRING**: scored interactions including text mining, co-expression, synteny, experiments
- **IntAct / MINT**: curated high-confidence interactions
- **Human Interactome (HuRI)**: Y2H-based comprehensive human binary interaction map
- **IsoformSwitchAnalyzeR**: isoform-level interactions

### Key Considerations

**Experimental biases:**
- Y2H: binary interactions; misses transient or context-dependent interactions
- AP-MS: co-complex; includes indirect (within complex) interactions
- Co-fractionation: lower resolution; detects large complexes

**Network integration:**
- STRING scores: evidence from multiple sources; use score > 700 (medium confidence)
- False positive rate in PPI data: estimated 50-90% depending on method

**Hub proteins:**
- Date hubs: interact with different partners in different contexts
- Party hubs: interact with all partners simultaneously (core complex)
- Essential proteins overrepresented as hubs (but selection bias exists)

## Metabolic Network Analysis

### Representing Metabolism as a Graph

**Two representations:**
- **Metabolite-reaction graph**: bipartite (metabolites and reactions as different node types)
- **Metabolite-metabolite graph**: connect two metabolites if they share a reaction
  - Problem: currency metabolites (ATP, NADH) create hubs that dominate and obscure structure
  - Solution: exclude currency metabolites; use atom mapping to trace carbon flow

### Elementary Flux Mode (EFM) Analysis

Every feasible steady-state flux is a non-negative combination of EFMs.
- Each EFM: a minimal pathway with defined in/out metabolites
- Enumeration: computationally expensive for large networks (exponential in size)
- Tool: efmtool (MATLAB), EFMlrs
- Applications: identifying alternative routes, calculating maximum theoretical yield

### Flux Sampling

Sample uniformly from the feasible flux polytope:
```python
from cobra.sampling import sample

# Flux samples: explore the space of feasible metabolic states
flux_samples = sample(model, n=1000, method='optgp')
# flux_samples is a DataFrame: reactions × samples
```

Applications:
- Characterize metabolic variability
- Compare model predictions to experimental data
- Identify correlated reaction groups (coupled reactions)

## Co-Expression Networks

### Building from RNA-seq Data

**Pearson correlation** (assumes linear relationships, normal distributions):
```python
corr_matrix = pd.DataFrame(expression_data.T).corr()
```

**WGCNA (Weighted Gene Co-expression Network Analysis)**
- Power transformation of correlation: adjacency = |corr|^β
- Soft thresholding: choose β such that network has scale-free topology
- Topological Overlap Measure (TOM): accounts for shared neighbors
- Hierarchical clustering → modules (groups of co-expressed genes)
- Module eigengene: first PC of each module; represents module expression pattern
- Correlate module eigengenes with traits of interest

```r
library(WGCNA)
# Soft threshold
powers = c(c(1:10), seq(from = 12, to=20, by=2))
sft = pickSoftThreshold(datExpr, powerVector = powers)
# Build network
net = blockwiseModules(datExpr, power = 6, TOMType = "unsigned", ...)
```

### Mutual Information Networks

- ARACNE, CLR: mutual information-based GRN inference
- Less biased than Pearson toward linear relationships
- Better for: regulatory network inference where TF-target relationships are non-linear

## Network-Based Drug Target Identification

### Disease Module Hypothesis

Disease genes tend to cluster in network neighborhoods (modules).
- Build disease gene interactome subnetwork
- Identify module: connected component containing known disease genes
- Module reflects: perturbed pathways; candidate drug targets nearby

### Network Propagation

Propagate signal from disease genes through network:
```
F(t+1) = α · W · F(t) + (1-α) · Y
```
Where W = normalized adjacency, Y = seed gene scores, α = propagation parameter.

After convergence: high F values near seed genes → candidate genes

Applications:
- Gene prioritization in GWAS
- Drug repurposing (propagate from known drug targets)
- Network-based patient stratification

### Synthetic Lethality Networks

Two genes are synthetic lethal if individually viable but lethal in combination.
- Genetic interaction network (DIXY database, Costanzo et al.)
- Cancer relevance: cancer-specific essential genes; oncogene-specific synthetic lethal partners
- CRISPR screens: identify synthetic lethal partners at genome scale
- Network structure: negative genetic interactions form "spoke" patterns around functional modules
