Mathematical models are the medium through which systems biologists make quantitative predictions, compare hypotheses, and communicate mechanistic understanding. But a model that lives only in a lab's MATLAB scripts or a Python notebook is not yet a community resource — it is a private artifact. To be useful to other researchers, a model must be expressible in a format that other tools can read, that databases can curate, and that simulators can execute without manual transcription. The history of systems biology is littered with published models that could not be independently simulated because they were described only in equations in a paper, with implementation details buried in supplementary files that no longer existed.

This section covers the three major model exchange formats in computational systems and synthetic biology, each suited to a different regime of model complexity. The choice of format is not arbitrary — it reflects the nature of the biological system being modeled and the tradeoffs between expressiveness, readability, and computational tractability.

The first subsection introduces SBML, the Systems Biology Markup Language. SBML is the lingua franca of systems biology: an XML-based standard that can represent any network of biochemical reactions, from simple Michaelis-Menten kinetics to complex multi-compartment gene regulatory networks. Over a thousand published models are available in the BioModels Database in SBML format, and every major simulation tool — COPASI, roadrunner, libSBML — can read and write it. If you are building an ODE model of a signaling pathway, SBML is almost certainly the right deposition format.

The second subsection covers Antimony, a human-readable model definition language that compiles to SBML. Where SBML is verbose by design — it must be unambiguous to automated parsers — Antimony is terse by design: a repressilator model that requires 200 lines of SBML can be written in 12 lines of Antimony. This is not merely convenient. Models that appear in publications should be comprehensible to readers. Antimony is also the native language of the tellurium Python ecosystem, which provides a complete workflow from model specification to simulation to visualization.

The third subsection introduces BioNetGen, a rule-based modeling framework for systems where combinatorial complexity makes explicit ODE formulations impractical. When a receptor has five phosphorylation sites and three binding partners, the number of possible molecular states can exceed thousands — far more than any realistic ODE model could enumerate. BioNetGen solves this by describing molecular interactions as rules that apply to patterns of molecular states, generating the full network automatically. EGFR signaling, T cell receptor activation, and many other immunological pathways have been modeled successfully only with rule-based approaches.
