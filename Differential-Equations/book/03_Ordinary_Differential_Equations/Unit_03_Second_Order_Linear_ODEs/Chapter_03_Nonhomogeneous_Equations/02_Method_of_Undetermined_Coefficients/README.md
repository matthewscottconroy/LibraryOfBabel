# Method of Undetermined Coefficients

The method of undetermined coefficients (also called the method of educated guessing) finds particular solutions when the forcing function $g(x)$ belongs to the class of functions whose derivatives are finite-dimensional: polynomials, exponentials, sines, cosines, and their products. The method proposes a trial form for $y_p$ based on the form of $g$, then determines the unknown coefficients by substitution.

## The Guessing Rules

The basic rule: the trial $y_p$ should be of the same "type" as $g$, meaning it should contain the same kind of terms and all the terms generated by differentiating $g$ repeatedly.

**Polynomial forcing.** If $g(x) = P_n(x)$ (a polynomial of degree $n$), try $y_p = A_n x^n + A_{n-1}x^{n-1} + \cdots + A_0$.

**Exponential forcing.** If $g(x) = e^{\alpha x}$, try $y_p = Ae^{\alpha x}$.

**Sinusoidal forcing.** If $g(x) = \cos(\beta x)$ or $\sin(\beta x)$, try $y_p = A\cos(\beta x) + B\sin(\beta x)$ (both terms, even if only one appears in $g$, because differentiation mixes sine and cosine).

**Products.** If $g(x) = P_n(x)e^{\alpha x}\cos(\beta x)$, try $y_p = e^{\alpha x}[(A_n x^n + \cdots + A_0)\cos\beta x + (B_n x^n + \cdots + B_0)\sin\beta x]$.

**Sums.** By superposition, if $g = g_1 + g_2$, take $y_p = y_{p1} + y_{p2}$ where each $y_{pk}$ handles $g_k$.

## The Modification Rule

If any term in the initial trial $y_p$ is itself a solution of the homogeneous equation $L[y] = 0$, then that trial will give $L[y_p] = 0$ identically, not $g(x)$. In this case, multiply the trial by $x$ (or $x^2$, etc.) until no term in the modified trial is a homogeneous solution.

**Resonance example.** For $y'' + \omega^2 y = \cos(\omega x)$: the homogeneous solutions are $\cos(\omega x)$ and $\sin(\omega x)$. The initial trial $y_p = A\cos\omega x + B\sin\omega x$ is a homogeneous solution, so it fails. Multiply by $x$: try $y_p = x(A\cos\omega x + B\sin\omega x)$.

## Worked Example 1: Polynomial Forcing

Solve $y'' - 3y' + 2y = 2x^2 - 1$.

Homogeneous: $r^2 - 3r + 2 = (r-1)(r-2) = 0$, so $y_h = c_1 e^x + c_2 e^{2x}$.

Trial: $y_p = Ax^2 + Bx + C$. Then $y_p' = 2Ax + B$ and $y_p'' = 2A$. Substituting:

$$2A - 3(2Ax + B) + 2(Ax^2 + Bx + C) = 2x^2 - 1.$$

$$2Ax^2 + (-6A + 2B)x + (2A - 3B + 2C) = 2x^2 - 1.$$

Matching coefficients: $2A = 2$ (so $A = 1$), $-6A + 2B = 0$ (so $B = 3$), $2A - 3B + 2C = -1$ (so $2 - 9 + 2C = -1$, giving $C = 3$).

$y_p = x^2 + 3x + 3$. General solution: $y = c_1 e^x + c_2 e^{2x} + x^2 + 3x + 3$.

## Worked Example 2: Resonance Case

Solve $y'' + 4y = 3\sin(2x)$.

Homogeneous: $r^2 + 4 = 0$, roots $r = \pm 2i$, so $y_h = c_1\cos 2x + c_2\sin 2x$. The forcing $3\sin(2x)$ has the same frequency as the homogeneous solutions, so resonance occurs.

Initial trial $A\cos 2x + B\sin 2x$ is a homogeneous solution; multiply by $x$: try $y_p = x(A\cos 2x + B\sin 2x)$.

Computing $y_p'$ and $y_p''$ and substituting into $y_p'' + 4y_p = 3\sin 2x$: after calculation,

$$y_p'' + 4y_p = -4A\sin 2x + 4B\cos 2x = 3\sin 2x.$$

So $-4A = 3$ and $4B = 0$: $A = -3/4$, $B = 0$. Thus $y_p = -\frac{3}{4}x\cos 2x$.

The $x\cos$ factor causes the amplitude to grow linearly with $x$, the signature of resonance.

## Limitations

The method applies only when $g(x)$ is of the special exponential-polynomial type. For $g(x) = \tan x$, $\ln x$, $1/x$, or other functions whose derivatives generate infinitely many independent terms, undetermined coefficients fails and variation of parameters must be used.
