# 18.6 Randomness — The Martin-Löf Approach

What does it mean for an individual infinite sequence to be random? This sounds philosophical, but it has a precise mathematical answer — and finding that answer was one of the great achievements of twentieth-century mathematics.

The naive answer — a sequence is random if it is generated by a fair coin — doesn't work as a definition of individual randomness. Every sequence has probability zero under the fair coin measure, so no individual sequence is "more likely" than any other. We need a different approach.

Earlier attempts relied on statistical tests: a sequence is random if it passes the frequency test (roughly half 0s and half 1s), the $\chi^2$ test, the correlation test, and so on. But for any fixed collection of tests, a sequence can pass them all by design. The question is: which tests count?

Per Martin-Löf's 1966 solution: *all* of them, simultaneously.

**Definition 18.6.1 (Martin-Löf Statistical Test).** A *statistical test* (in Martin-Löf's sense) is a sequence of r.e. open sets $\{U_n\}_{n \geq 1}$ with $\mu(U_n) \leq 2^{-n}$ for all $n$ (where $\mu$ is the fair coin measure). A sequence $\omega \in \{0,1\}^{\mathbb N}$ *fails* the test if $\omega \in \bigcap_n U_n$.

The idea: $U_n$ is a "region of suspicion" at level $n$ — the sequences that look suspicious to precision $2^{-n}$. A sequence fails the test if it is suspicious at every precision level simultaneously. The set $\bigcap_n U_n$ has measure zero (since $\mu(U_n) \leq 2^{-n} \to 0$), so failing any individual test is rare.

**Definition 18.6.2 (Martin-Löf Randomness).** A sequence $\omega$ is *Martin-Löf random* (w.r.t. a computable measure $\mu$) if it passes all statistical tests: $\omega \notin \bigcap_n U_n$ for every Martin-Löf test.

The crucial insight: the class of all Martin-Löf tests is itself effectively computable, and there is a *universal* test that subsumes all others:

**Theorem 18.6.3 (Universal Martin-Löf Test).** There exists a *universal Martin-Löf test* $\{V_n\}$ such that $\omega$ is ML-random iff it passes the universal test.

The universal test captures everything that can go wrong with a sequence: all computable regularities, all statistical anomalies, all patterns that a Turing machine could detect. A sequence passes it iff no Turing machine can "expose" it as non-random.

The equivalence with incompressibility — the connection back to Kolmogorov complexity — is the Schnorr/Levin characterization:

**Theorem 18.6.4 (Levin-Schnorr Theorem).** $\omega$ is ML-random w.r.t. the uniform (fair coin) measure iff:
$$K(\omega_{|n}) \geq n - O(1) \quad \text{for all } n,$$
where $\omega_{|n}$ denotes the first $n$ bits of $\omega$.

*In words: a sequence is random iff no initial segment can be significantly compressed.*

This is the most satisfying characterization of randomness: $\omega$ is random iff all of its finite initial segments are incompressible. A single compressible initial segment doesn't disqualify $\omega$ — the $O(1)$ allowance handles that. But if initial segments can be compressed by a growing amount, the sequence is not random.

**Theorem 18.6.5 (Van Lambalgen's Theorem).** $(\omega, \rho)$ is ML-random (as a pair, viewed as a product sequence) iff $\omega$ is ML-random and $\rho$ is ML-random *relative to $\omega$* (using $\omega$ as an oracle).

Van Lambalgen's theorem is elegant and surprising: the randomness of a pair is not the same as the conjunction of the randomness of its parts. You need the second component to be random even with the first as a resource. This theorem is used in the theory of computability and in proofs about algorithmic randomness under transformations.
