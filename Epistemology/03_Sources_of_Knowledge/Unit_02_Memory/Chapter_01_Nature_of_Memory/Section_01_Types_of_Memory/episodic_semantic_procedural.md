# Types of Memory: Episodic, Semantic, and Procedural

Memory is not a single faculty but a family of related capacities that can be distinguished by their content, their phenomenological character, and their neural implementation. The division of memory into types — most influentially, episodic, semantic, and procedural — has been philosophically productive and empirically well-supported, shaping both cognitive psychology and epistemology.

## Episodic Memory

Episodic memory is memory of particular events located in one's personal past — what Endel Tulving, who developed the framework, called "memory for personally experienced events." When you remember that you had coffee with a friend last Tuesday, or that you saw a particular sunset on a particular holiday, you are exercising episodic memory. The experience is of a past event as having happened to you, at a particular time and place.

Episodic memory has a distinctive phenomenological character. Tulving described it as involving "mental time travel": you appear to re-experience or relive a past event, projecting yourself back to the time and place of the original experience. The memory has what Tulving called autonoetic consciousness — a sense of self-awareness connected to the temporal context.

This phenomenological feature sets episodic memory apart from other kinds of memory: you know the memory is yours, and you have a sense of its temporal location. When you remember a childhood event, you seem to see it from the perspective of the past self who had the experience.

## Semantic Memory

Semantic memory is memory of general facts, concepts, and world knowledge — the kind of thing you know without necessarily remembering when you learned it. You know that Paris is the capital of France, that mammals are warm-blooded, that 7 × 8 = 56. These are pieces of semantic memory: propositional knowledge without episodic temporal context.

Tulving distinguished semantic from episodic memory partly on the basis of double dissociation in neurological cases. Patients with severe amnesia affecting episodic memory (such as the famous patient H.M.) can retain semantic memory relatively intact. Other patients with semantic dementia lose general world knowledge while episodic memory is relatively preserved. The dissociation suggests these are distinct memory systems.

Philosophically, semantic memory corresponds closely to propositional knowledge (knowing-that) in the epistemological tradition. When epistemologists discuss knowledge, they are usually discussing something like semantic memory: justified, stable beliefs about facts.

## Procedural Memory

Procedural memory is memory for how to do things — skills, habits, and conditioned behaviors. Knowing how to ride a bicycle, play the piano, or tie a shoelace involves procedural memory. It is typically implicit: you don't consciously recall the "procedure"; you simply execute it when the appropriate situation arises.

Procedural memory is robust in contexts where episodic and semantic memory are severely impaired. Patients with Korsakoff's syndrome or severe amnesia can still acquire new motor skills and conditioning responses, even while unable to recall learning them. This is one of the clearest pieces of evidence for the reality of the episodic/procedural distinction.

Procedural memory connects directly to Ryle's knowing-how (discussed in Chapter 2 of Unit 2 of Topic 2). The philosophical question is whether procedural memory is genuinely a form of knowledge or merely a disposition — and the cognitive science of implicit memory has enriched that philosophical debate.

## Working Memory and Prospective Memory

Beyond the episodic/semantic/procedural triad, cognitive science identifies other memory types. Working memory is the short-term, capacity-limited store that maintains information for immediate use in reasoning and action. Prospective memory is memory for future intentions: remembering to do things ("take your medication after dinner"). These types raise different epistemological questions — working memory about the moment-by-moment structure of reasoning, prospective memory about the relationship between memory and intention.

## Philosophical Significance

The taxonomy of memory types has several important philosophical consequences:

It shows that "memory" is not a single epistemic capacity. Different types of memory have different epistemic profiles: episodic memory is fallible, reconstructive, and subject to distortion; semantic memory is more stable but can be systematically wrong; procedural memory is extremely reliable for the actions it supports but doesn't deliver propositional knowledge.

It challenges simple analyses of memory as "preserved past experience." Much of what we know through memory was never consciously encoded and cannot be recalled as episodes. Semantic and procedural knowledge just accumulates without any episodic record of its acquisition.

It connects to debates about the unity of the self: episodic memory provides the narrative thread of personal history, and some philosophers (Locke, Parfit) have argued that personal identity is constituted by continuity of memory.
