# The Causal Theory of Memory

The causal theory of memory holds that genuine remembering requires an appropriate causal connection between the current memory state and the original experience being remembered. Without such a causal chain, even an accurate belief about a past event is not a memory in the epistemically relevant sense — it is mere knowledge about the past, not remembrance of it.

## The Basic Statement

C.B. Martin and Max Deutscher's "Remembering" (1966) provides the classic statement of the causal theory. For S to remember that P (where P is some past event), the following must hold:

1. S currently has a state (the memory state) that represents the event.
2. S experienced the event originally.
3. The current memory state is appropriately causally connected to the original experience.

The causal connection distinguishes genuine memory from coincidental accuracy. Suppose you are told a false story about your childhood and come to believe it. Even if the story happens to be accurate (by coincidence), you do not remember the childhood event — you have a present belief about it that lacks the right causal history.

## What Makes the Causal Connection "Appropriate"?

The causal theory faces the challenge of specifying what makes a causal chain "appropriate." Not just any causal connection will do. Suppose you experienced an event E, which caused a change in your brain, which somehow causally influenced a completely different person's belief about E, and you acquired that belief through a normal social process. This might be a causal chain connecting your experience to your belief, but it doesn't seem to constitute your remembering E.

Martin and Deutscher specified that the causal chain must run through *within-subject* processes — through memory traces in your own nervous system, not through external causal routes. The chain must preserve some of the informational content of the original experience.

## Deviant Causal Chains

As with other causal theories in epistemology and philosophy of action, causal theories of memory face the problem of deviant causal chains: causal connections that are technically present but intuitively wrong. Consider: you experience an event E; the experience causes a brain tumor; the tumor causes your therapist to hypnotize you; the hypnosis causes you to produce accurate beliefs about E. Is this remembering? There is a causal chain from the original experience to your current state, but something seems wrong.

The causal theorist must say that the chain must run through the right kind of causal pathway — one that preserves the information carried by the original experience in the right way. Specifying this precisely is difficult and remains an open problem for the causal theory.

## Memory as Extended Testimony

An interesting variant of the causal theory treats external memory supports as part of the causal chain. You wrote a note about an appointment; the note reminds you; you remember the appointment. Is this genuine remembering, or consulting testimony (your past self's testimony)? The causal chain runs through an external medium.

Philosophers like John Sutton and the extended mind theorists argue that external memory supports — notes, photographs, recordings — can be part of the memory process in a way that makes the resulting states genuine memories. The causal theory needs to be extended to accommodate this possibility.

## The Epistemological Import

The causal theory gives memory its distinctive epistemic character. Memory knowledge is special because it preserves a connection to first-hand experience — to the perceiving, experiencing self that witnessed the original event. This is what distinguishes remembering from merely knowing about the past.

But this also reveals the limits of memory's epistemic warrant. Memory is only as reliable as the causal chains connecting the present state to the original experience. As those chains degrade — through time, interference, and reconstruction — the epistemic warrant for memorial beliefs weakens. The causal theory implies that the strength of memorial justification is partly a function of the integrity of the underlying trace.

This connects to practical epistemics: the longer ago an event occurred, the more reconstruction is needed, and the less secure the causal connection. Courts recognize this in limiting the weight given to eyewitness testimony about events from long ago. The causal theory provides a principled rationale for this practice.

## Beyond the Causal Theory

The causal theory gives necessary conditions for genuine remembering but arguably not sufficient conditions. You might have an appropriate causal connection to a past experience while also confabulating much of the content. The resulting state is causally connected to the experience but not a reliable representation of it. This suggests that the causal theory must be supplemented with reliability or accuracy conditions.

Alternatively, some philosophers have proposed that what matters is not just causal history but causal-functional role: a genuine memory state is one that plays the right functional role in the subject's cognitive economy — influencing behavior, connecting to related memories, responding appropriately to cues. On this view, the causal and functional dimensions of memory jointly determine its epistemic status.
