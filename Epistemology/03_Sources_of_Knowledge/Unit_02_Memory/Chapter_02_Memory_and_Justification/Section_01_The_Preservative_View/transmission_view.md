# The Transmission View of Memory Justification

The transmission view of memory justification is a specific formulation of preservationism: justification is *transmitted* from the original belief, at the time of its formation, to subsequent memorial beliefs about the same proposition. Just as electrical current is transmitted through wire, epistemic justification is transmitted through time via the memory trace.

## The Basic Framework

On the transmission view:

1. You originally form a belief P based on adequate evidence or reliable perception: this belief is justified.
2. A memory trace of the belief persists.
3. Later you recall P by activating that trace: the resulting belief is justified because justification has been transmitted along the causal chain.

This is different from a view on which the current memory experience provides fresh justification. The transmission view says no new justification is added; what exists is the original justification, carried forward.

## Audi's Account

Robert Audi has developed a careful version of the transmission view. On his account, the memorial state transmits rather than generates justification: "if a belief is initially justified by experience, inference, or some other source, it remains so justified as long as it is retained in memory, provided no defeaters appear."

Audi is careful to distinguish between the *justification* of a belief (which can be transmitted) and the *evidence* for a belief (which may not persist in the same form). The evidence that originally justified the belief may no longer be accessible; but the justification itself — the epistemic status of the belief — persists as long as the belief is retained in memory without defeat.

This has the practical virtue of allowing long-retained beliefs to remain justified even when their original evidential basis is inaccessible. If justification required continued access to the original evidence, our epistemic position would be desperately insecure, since most of our knowledge is from long ago.

## Justification Decay?

One question the transmission view faces: does transmitted justification decay over time? As memory traces degrade and are reconstructed, as more time passes from the original justifying experience, should we expect the transmitted justification to weaken?

The transmission view as typically stated says no: justification is either transmitted or not, and if transmitted, it is preserved in full until a defeater appears. But this seems overly strict. A vivid memory from yesterday seems better justified than a hazy one from thirty years ago, independently of whether a defeater has appeared.

One response: what decays over time is not the justification itself but the accessibility of justification-supporting factors (the vividness of the memory, the retrieval of associated evidence). The original epistemic status is preserved, but our confidence in the memory's accuracy — a meta-level assessment — may reasonably decline.

## The Basing Relation

The transmission view raises questions about the *basing relation*: what must be true for a belief to be *based on* the appropriate justification? Even if justification exists (has been transmitted), the belief must be based on that justification — not on some independent factor — to count as justified.

In memory cases, the basing is typically unproblematic: you believe P because you remember P, and the memory is the appropriate basis. But in cases where the memory is prompted by suggestion, or where you are no longer sure whether you remember P or were told P, the basing relation is less clear.

## Testimony and Transmission

An interesting parallel: testimony also involves a transmission of justification from original knowers to hearers. Just as memory transmits justification through time, testimony transmits it through social networks. Anti-reductionist views of testimony hold that testimony can generate new justification; reductionist views hold it only transmits.

This parallel suggests that the debate about memory's epistemic status (generationist vs. preservationist) is structurally similar to the debate about testimony's epistemic status (anti-reductionist vs. reductionist). In both cases, the question is whether the conduit is purely passive (transmitting pre-existing justification) or actively contributes something new.

## Implications for Skepticism about Memory

The transmission view has a clear implication for skepticism about memory: if memory only transmits justification from original sources, and if those original sources are reliable (perception, careful inference), then memory beliefs are as secure as their origins. The skeptic who challenges memory knowledge must challenge the reliability of the original sources, not just the reliability of memory as a transmitter.

This is reassuring in one way — it shows that general memory skepticism is no worse than general perceptual skepticism. But it also shows that memory's epistemic status is hostage to the reliability of original sources, which must be established independently.
