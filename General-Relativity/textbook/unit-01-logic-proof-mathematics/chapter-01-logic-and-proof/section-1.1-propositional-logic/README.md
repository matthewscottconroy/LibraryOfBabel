# Section 1.1: Propositional Logic

---

## Section Introduction

Logic begins with the simplest possible objects: statements that are either true or false. A *proposition* is any declarative sentence that has a definite truth value. "The number 7 is prime" is a proposition — it is true. "The number 8 is prime" is a proposition — it is false. "Close the door" is not a proposition — it has no truth value. "This sentence is false" is not a proposition — it is self-referential in a way that breaks the true/false dichotomy (this is the Liar's Paradox, which we will return to).

From simple propositions, we build compound propositions by combining them with logical connectives: *and*, *or*, *not*, *if...then*, and *if and only if*. We then ask: given the truth values of the component propositions, what is the truth value of the compound? This question has a precise, tabular answer — the truth table. Together, propositions and connectives form *propositional logic*, also called *sentential logic* or *propositional calculus*.

Propositional logic is the simplest formal system, and it has real limitations. It cannot express statements like "every real number has a square root" or "there exists a prime between n and 2n for all n ≥ 1." Those require *predicate logic*, which we take up in Section 1.2. But propositional logic is the right place to start, because it makes the ideas of truth, connective, and inference concrete before we add the complexity of quantifiers and variables.
