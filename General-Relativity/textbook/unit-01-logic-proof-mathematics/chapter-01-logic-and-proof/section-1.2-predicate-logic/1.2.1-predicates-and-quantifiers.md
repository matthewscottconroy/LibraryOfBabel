# 1.2.1 Predicates and Quantifiers

---

## Predicates: Propositions with Variables

A **predicate** (or **propositional function**) is an expression that contains one or more free variables and becomes a proposition once those variables are assigned values from a specified domain.

**Examples:**
- P(x) = "x is a prime number" (domain: positive integers). P(7) is True; P(8) is False.
- Q(x, y) = "x < y" (domain: real numbers). Q(2, 5) is True; Q(5, 2) is False.
- R(f) = "f is differentiable on ℝ" (domain: functions ℝ → ℝ). R(sin) is True; R(|·|) is False.
- C(M, g) = "g is a Lorentzian metric on the manifold M" (domain: pairs of manifolds and metrics). This becomes the predicate used to define spacetime.

The **domain of discourse** (or **universe of discourse**) specifies the collection of objects from which the variables take values. The domain must be specified for a predicate to be meaningful. "x > 0" means something different when x ranges over integers than when it ranges over real numbers (in the first case, x ≥ 1; in the second, x could be 0.001).

---

## The Universal Quantifier (∀)

The **universal quantifier** ∀ (read "for all" or "for every") turns a predicate into a proposition by asserting the predicate holds for *every* object in the domain.

$$\forall x\, P(x)$$

This reads: "For every x in the domain, P(x) is true."

**Examples:**
- ∀x ∈ ℤ (x² ≥ 0): "For every integer x, x² is non-negative." (True)
- ∀x ∈ ℝ (x² ≥ 0): "For every real number x, x² is non-negative." (True)
- ∀x ∈ ℝ (x² > 0): "For every real number x, x² is positive." (False — x = 0 is a counterexample)
- ∀f ∈ C¹(ℝ), ∀x ∈ ℝ: "Every continuously differentiable function is continuous." (True)

A universally quantified statement is **false** if there exists even one element of the domain for which the predicate fails. Such an element is called a **counterexample**.

Finding a counterexample is a powerful technique for disproving conjectured universal statements. Much of the history of mathematics involves proposed "universal" laws being overturned by a single ingenious counterexample.

**Historical example**: For centuries it was believed that if f'(x) = 0 for all x in an interval, then f must be constant on that interval (True for connected intervals). Karl Weierstrass's 1872 example of a function that is continuous everywhere but differentiable nowhere overturned intuitions about what "generic" functions look like (Weierstrass, 1872, unpublished lecture; published by du Bois-Reymond, 1875).

---

## The Existential Quantifier (∃)

The **existential quantifier** ∃ (read "there exists" or "there is") turns a predicate into a proposition by asserting the predicate holds for *at least one* object in the domain.

$$\exists x\, P(x)$$

This reads: "There exists at least one x in the domain for which P(x) is true."

**Examples:**
- ∃x ∈ ℝ (x² = 2): "There exists a real number whose square is 2." (True — x = √2)
- ∃x ∈ ℚ (x² = 2): "There exists a rational number whose square is 2." (False — classical result, attributed to the Pythagoreans, see subsection 3.2)
- ∃x ∈ ℝ (x² = -1): "There exists a real number whose square is -1." (False — all real squares are non-negative)
- ∃c ∈ ℝ⁺ (G_μν = (8πG/c⁴)T_μν): "There exists a positive constant c such that the Einstein field equations hold." (This is the form of the field equations with the speed of light set to c; this is True with c being the speed of light in vacuum.)

An existentially quantified statement is **true** if even one element of the domain satisfies the predicate. To prove ∃x P(x), it suffices to produce a *specific* x — a **witness** — and verify that P holds for it.

---

## The Existential-Unique Quantifier (∃!)

Sometimes we want to say "there exists exactly one x satisfying P(x)." This is expressed by the **uniqueness quantifier** ∃!:

$$\exists!\, x\, P(x) \equiv (\exists x\, P(x)) \land (\forall x \forall y\, (P(x) \land P(y) \to x = y))$$

That is: there exists x satisfying P, and any two objects satisfying P are equal (i.e., the same object).

**Example**: ∃! x ∈ ℝ (x² = 0): "There exists a unique real number whose square is zero." (True — only x = 0.)

**Example**: In general relativity, Birkhoff's theorem states that the Schwarzschild metric is the *unique* spherically symmetric vacuum solution to the Einstein field equations (up to coordinate choice). This is a statement of the form ∃! g satisfying certain conditions — a uniqueness result of profound physical importance (Birkhoff, 1923).

---

## Quantifiers and the Domain of Discourse

The domain of discourse is not always made explicit in mathematical writing — it is often inferred from context. But it matters enormously. "For all x, x > 0" is true when the domain is positive integers and false when the domain is all integers.

In physics, the domain is often implicit: when we write "for all events p in spacetime, the metric tensor g_{μν}(p) is non-degenerate," the domain is understood to be the set of events (points) in the spacetime manifold M.

It is good practice to always specify the domain when introducing a quantified statement, especially in formal proofs. Ambiguity about the domain is one of the most common sources of error in mathematical arguments.

## Using Quantifiers to Express Mathematical Definitions

The precision of predicate logic becomes apparent when we use it to express definitions that are typically stated more loosely in informal mathematics.

**The ε-δ definition of a limit** (Cauchy, 1821; Weierstrass, ca. 1861):

> "The limit of f(x) as x approaches a is L"

is formally defined as:

$$\lim_{x \to a} f(x) = L \quad \stackrel{\text{def}}{\iff} \quad \forall \varepsilon > 0\, \exists \delta > 0\, \forall x \in \mathbb{R}\, (0 < |x - a| < \delta \to |f(x) - L| < \varepsilon)$$

The quantifier structure is: ∀ε ∃δ ∀x, and the order matters critically, as we see in the next subsection.

**Continuity**:

$$f \text{ is continuous at } a \quad \iff \quad \lim_{x \to a} f(x) = f(a)$$

Expanding:
$$\forall \varepsilon > 0\, \exists \delta > 0\, \forall x\, (|x - a| < \delta \to |f(x) - f(a)| < \varepsilon)$$

**Uniform continuity**:

$$f \text{ is uniformly continuous on } D \quad \iff \quad \forall \varepsilon > 0\, \exists \delta > 0\, \forall x \in D\, \forall y \in D\, (|x - y| < \delta \to |f(x) - f(y)| < \varepsilon)$$

The difference from ordinary continuity is subtle but significant: in uniform continuity, the same δ works for all x simultaneously, whereas in ordinary continuity, δ may depend on x. This is precisely captured by the quantifier order: ∀ε ∃δ ∀x (uniform) vs. ∀ε ∀x ∃δ (ordinary, where δ can depend on x). Reordering the quantifiers changes the meaning.

This quantifier dependence will reappear in Chapter 13 when we distinguish between pointwise and uniform convergence of sequences of functions.

---

## Summary

- A **predicate** is an expression with free variables that becomes a proposition when values are assigned.
- The **universal quantifier** ∀x P(x) asserts P holds for every x in the domain. It is false iff a counterexample exists.
- The **existential quantifier** ∃x P(x) asserts P holds for at least one x. It is true iff a witness exists.
- The **uniqueness quantifier** ∃! asserts exactly one x satisfies P.
- The **domain of discourse** must be specified; quantified statements are meaningless without it.
- **Quantifier order matters**: swapping ∀ and ∃ generally changes the meaning and truth value of a statement.
