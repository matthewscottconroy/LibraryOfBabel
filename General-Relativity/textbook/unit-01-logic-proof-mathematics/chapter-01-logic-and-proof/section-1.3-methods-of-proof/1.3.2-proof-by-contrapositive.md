# 1.3.2 Proof by Contrapositive

---

## The Logical Foundation

Recall from Section 1.1.2 that P → Q is logically equivalent to ¬Q → ¬P. This equivalence — the **contrapositive** — is not merely a logical curiosity. It gives us a second strategy for proving implications: instead of proving P → Q directly, we can prove its contrapositive ¬Q → ¬P.

Since the two are logically equivalent, a proof of the contrapositive is a proof of the original — no information is lost.

**When is this useful?** Proof by contrapositive is most useful when:
- The negation of Q (¬Q) is a rich hypothesis: it gives you something concrete to work with.
- The negation of P (¬P) is a clean conclusion: it is easier to prove.
- A direct proof from P would require discovering the connection to Q, while the contrapositive makes the connection more transparent.

---

## Structure of a Proof by Contrapositive

> **Theorem**: If P, then Q.
>
> **Proof** (by contrapositive): We prove the equivalent statement: if ¬Q, then ¬P. Assume ¬Q. [Derive ¬P.] Therefore ¬P. Since we have proved ¬Q → ¬P, we conclude P → Q. □

---

## Example 1: An Elementary Number Theory Result

**Theorem**: For any integer n, if n² is odd, then n is odd.

**Direct approach**: Given that n² is odd, we must show n is odd. How? It's not immediately clear how to extract information about n from knowing about n².

**Contrapositive approach**: We prove instead that if n is even, then n² is even.

**Proof** (by contrapositive): Assume n is even. Then n = 2k for some integer k. Therefore n² = 4k² = 2(2k²). Since 2k² is an integer, n² is even. Having proved that n even implies n² even (i.e., ¬"n odd" implies ¬"n² odd"), we conclude that n² odd implies n odd. □

The contrapositive turned an awkward problem (deducing parity of n from parity of n²) into a trivial one (computing n² when n has a known form).

## Example 2: Irrationality Via Contrapositive

We will prove a partial result that sets up the full irrationality theorem.

**Theorem**: For any real number x, if x² = 2, then x is not a ratio of two integers with denominator 1 (i.e., x is not an integer).

**Proof** (by contrapositive): We prove: if x is an integer, then x² ≠ 2. Assume x is an integer. Then x² = x·x is also an integer. Since the only perfect squares among integers near 2 are 1 (= 1²) and 4 (= 2²), and 2 lies strictly between 1 and 4, no integer squares to 2. Therefore x² ≠ 2. □

(The full irrationality of √2 — that it is not a ratio p/q for any integers p, q — requires a more involved argument; see subsection 3.2.)

## Example 3: A Linear Algebra Result

**Theorem**: If a linear map T: V → W is injective (one-to-one), then the only vector v ∈ V with T(v) = 0 is v = 0. (Equivalently: the null space ker(T) = {0}.)

We will prove the contrapositive.

**Proof** (by contrapositive): We prove: if there exists a nonzero v with T(v) = 0, then T is not injective.

Assume there exists v ≠ 0 such that T(v) = 0. Since T is linear, T(0) = 0 as well (because T(0) = T(0 · v) = 0 · T(v) = 0). So T(v) = T(0) = 0. But v ≠ 0, meaning two distinct vectors v and 0 map to the same image 0 under T. Therefore T is not injective (the definition of injective is that distinct inputs have distinct outputs, which fails here). □

This theorem is fundamental to linear algebra (Chapter 9): it says that the null space of an injective linear map contains only the zero vector. Its converse is also true, so ker(T) = {0} ↔ T is injective, an equivalence proved by combining the two implications.

## Example 4: A Metric Space Result (Preview of Chapter 13)

**Theorem**: Let (X, d) be a metric space and {xₙ} a sequence. If {xₙ} converges to a limit L, then {xₙ} is a Cauchy sequence.

**Direct proof** is straightforward here, so we also provide a **conceptual reason for contrapositive**: if you tried to prove this directly, you would use the convergence hypothesis to get |xₙ - L| < ε/2 for large n, then apply the triangle inequality: |xₙ - xₘ| ≤ |xₙ - L| + |L - xₘ| < ε. This works perfectly and is the right approach here. But the contrapositive — "if {xₙ} is not Cauchy, then {xₙ} does not converge" — is also a valid theorem, and its proof illustrates the contrapositive strategy in a richer setting. We leave it as an exercise.

## Comparison with Direct Proof

Neither direct proof nor proof by contrapositive is universally superior. They are tools, and the skill lies in choosing the right tool for the problem. A rough heuristic:

- If the hypothesis P is explicit and rich (gives you a formula or a specific object), try direct proof first.
- If the conclusion Q is explicit and specific, try direct proof.
- If the negation ¬Q is more explicit or usable than Q itself, try the contrapositive.
- If the hypothesis P is a negation (e.g., "n is not divisible by 3"), the negation ¬P (n is divisible by 3) may be easier to work with — try contrapositive.

In practice, experienced mathematicians try direct proof first and switch to contrapositive when the direct approach stalls.

---

## Summary

- Proof by contrapositive proves P → Q by instead proving ¬Q → ¬P, which is logically equivalent.
- It is most useful when ¬Q provides a richer hypothesis than P does, or when ¬P is a simpler target.
- The contrapositive of "if n² is odd then n is odd" is the easier statement "if n is even then n² is even."
- The strategy is grounded in the tautology (P → Q) ↔ (¬Q → ¬P).
