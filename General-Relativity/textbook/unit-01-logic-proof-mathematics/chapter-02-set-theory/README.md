# Chapter 2: Set Theory

---

## Chapter Introduction

Everything in mathematics is built from sets. A function is a set of ordered pairs. A vector space is a set equipped with operations. A manifold is a set equipped with a topological structure and a smooth atlas. The metric tensor at a point in spacetime is a function from pairs of tangent vectors — themselves elements of a set — to real numbers. Tracing any mathematical object back to its foundations, you always arrive at sets.

Set theory began as an innocent project: Georg Cantor's investigation, starting in 1874, of different *sizes* of infinity. Cantor discovered that not all infinite sets are the same size — there are genuinely different infinite cardinalities. The real numbers are *more numerous* than the rational numbers, in a precise mathematical sense. This discovery was revolutionary and disturbing. Cantor's contemporaries were skeptical or hostile; Kronecker reportedly called Cantor a "corrupter of youth." Cantor himself suffered repeated mental breakdowns.

The foundation crisis came later. Cantor's naive set theory — the idea that any property defines a set — turned out to be inconsistent. Bertrand Russell's 1901 paradox (the set of all sets that don't contain themselves) showed that unrestricted set formation leads to contradictions. The response was the development of axiomatic set theory: Zermelo's axioms (1908), later refined to the Zermelo-Fraenkel system with the Axiom of Choice (ZFC), which remains the standard foundation of mathematics today (Zermelo, 1908; Fraenkel, 1922; Skolem, 1922).

For our purposes, a working knowledge of naive set theory — sets, elements, subsets, operations, functions, and cardinality — is sufficient for everything through general relativity. The axiomatic subtleties become important when you need to worry about existence theorems for infinite-dimensional spaces (Chapter 13) or the precise construction of the real numbers (Section 3.3).

This chapter develops set theory at the level of detail needed for the rest of the book. We cover naive set theory (Section 2.1), glance at the axiomatic foundations (Section 2.2), develop the theory of relations and functions (Section 2.3), and conclude with Cantor's theory of cardinality (Section 2.4).
