Proofs are trees. This is not a metaphor or a simplification for beginners — it is the literal structure that natural deduction imposes on formal derivations. Each node in the tree carries a formula, justified by one of a fixed set of inference rules applied to the nodes below it. Hypotheses are leaves; the conclusion is the root. The tree structure is what makes proofs *checkable*: a machine can verify a proof tree by visiting each node and confirming that the rule was applied correctly, without needing to understand the overall argument.

The Compactness Theorem for propositional logic — if every finite subset of a set of formulas is satisfiable, the whole set is satisfiable — sounds like a curiosity. It is in fact one of the most powerful tools in mathematical logic, with consequences that run through model theory, combinatorics, and the foundations of first-order reasoning. It also makes a striking philosophical point: truth in propositional logic is entirely a *local* affair. No infinite conspiracy of formulas can be jointly unsatisfiable if every finite fragment of the conspiracy can be satisfied. Infinity, in this sense, adds no new logical pressure.

Together, natural deduction and the Compactness Theorem mark the boundary between what formal propositional logic can and cannot capture. You should leave this section understanding both how derivations are mechanically constructed and why the completeness and compactness results are not just technically useful but structurally illuminating — they describe the exact expressive and deductive limits of the system before we extend it toward predicate logic, type theory, and automated proof search.
