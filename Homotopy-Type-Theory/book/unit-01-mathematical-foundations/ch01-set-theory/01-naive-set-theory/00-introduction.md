Cantor did not intend to found mathematics. He was solving a specific technical problem about trigonometric series, and he needed a way to reason about arbitrary infinite subsets of the real line. The tools did not exist, so he built them — and in doing so, created a theory so natural, so expressive, and ultimately so dangerous that it reshaped the entire discipline.

The naturalness is the trap. Naive set theory's central principle — that every property defines a set — feels obviously correct. Of course the collection of all even numbers is a set. Of course the collection of all continuous functions is a set. Of course the collection of all sets is a set. The last one destroys the theory: Russell's paradox shows that the collection of all sets that do not contain themselves cannot exist without contradiction. The principle is not just slightly wrong in edge cases; it is fundamentally incompatible with itself.

This section develops the naive theory — set operations, relations, functions, cardinality — before examining the contradictions it generates. This ordering is deliberate. You need to understand what naive set theory achieves before you can understand why the ZFC axioms replace it in the particular way they do. The naive theory is the mathematics; the axiomatic theory is the discipline imposed to save the mathematics from itself. And lurking further ahead: type theory replaces both, by treating the distinction between sets and their elements not as a convention but as a structural feature of the formal language.
