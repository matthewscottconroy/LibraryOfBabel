Counting a finite set does two things at once that feel so inseparable we rarely notice them: it imposes an order (first, second, third) and it records a quantity (five). For finite sets, the order you impose does not affect the quantity you record. Infinity tears these two measurements apart, and keeping track of both — ordinal order-type and cardinal size — requires genuinely different theories.

The elegance of von Neumann's construction is worth pausing over. Each ordinal *is* the set of all smaller ordinals: zero is the empty set, one is the set containing zero, two is the set containing zero and one. This is not a cute encoding trick. It means that the membership relation ∈ on ordinals is literally the less-than relation, that well-foundedness is built into the structure, and that transfinite recursion has an explicit target to recurse over. The ordinals do not merely *model* an ordering — they *are* a canonical well-ordering of themselves. The cardinals, extracted from the ordinals via the Axiom of Choice, then measure which collections of ordinals can be put in bijection with one another.

For the path toward HoTT, the key fact is that ordinals are the indexing structure for the cumulative hierarchy of sets: V₀ = ∅, Vα₊₁ = 𝒫(Vα), and at limit ordinals Vλ = ⋃_{α<λ} Vα. Every set appears at some stage. This hierarchical picture of the universe of sets has a direct analogue in type theory's universe levels — a stratification that prevents the universe from containing itself and thereby avoids the paradoxes that destroyed naive set theory.
