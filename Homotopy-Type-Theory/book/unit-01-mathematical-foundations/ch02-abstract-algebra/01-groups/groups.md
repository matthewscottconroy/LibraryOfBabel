# Groups

## The Axioms

A *group* is a set G equipped with a binary operation · : G × G → G satisfying:

**G1 (Closure).** For all a, b ∈ G, a · b ∈ G.

**G2 (Associativity).** For all a, b, c ∈ G, (a · b) · c = a · (b · c).

**G3 (Identity).** There exists an element e ∈ G such that a · e = e · a = a for all a ∈ G.

**G4 (Inverses).** For every a ∈ G, there exists a⁻¹ ∈ G such that a · a⁻¹ = a⁻¹ · a = e.

If additionally the operation is commutative — a · b = b · a for all a, b — the group is *abelian* (or *commutative*). We often write abelian group operations additively, using + instead of ·, 0 instead of e, and -a instead of a⁻¹.

## Immediate Consequences

The axioms imply several facts that are not stated but are essential.

**Uniqueness of identity.** If e and e' both satisfy G3, then e = e · e' = e'. The identity is unique.

*Proof.* e = e · e' (using e' as identity for e) = e' (using e as identity for e'). □

**Uniqueness of inverses.** Each element has a unique inverse.

*Proof.* Suppose a · b = e and a · c = e. Then b = e · b = (a⁻¹ · a) · b = a⁻¹ · (a · b) = a⁻¹ · e = a⁻¹. Similarly c = a⁻¹. □

Here we used the uniqueness of left inverses, but the axioms give two-sided inverses. In fact, you can weaken the axioms: a left identity (e · a = a) and left inverses (a⁻¹ · a = e) suffice to get a full group.

**Cancellation.** If a · b = a · c, then b = c (left cancellation). If b · a = c · a, then b = c (right cancellation).

*Proof.* From a · b = a · c, multiply both sides on the left by a⁻¹: b = a⁻¹ · a · b = a⁻¹ · a · c = c. □

**(a · b)⁻¹ = b⁻¹ · a⁻¹.** The inverse of a product reverses the order.

*Proof.* (a · b) · (b⁻¹ · a⁻¹) = a · (b · b⁻¹) · a⁻¹ = a · e · a⁻¹ = a · a⁻¹ = e. By uniqueness of inverses, (a · b)⁻¹ = b⁻¹ · a⁻¹. □

## A Zoo of Examples

**The integers (ℤ, +, 0).** Associativity: (a+b)+c = a+(b+c). Identity: 0. Inverse: -a. This is an abelian group.

**ℤ/nℤ.** The integers modulo n, with addition mod n. Elements: {0, 1, 2, ..., n-1}. Identity: 0. Inverse of k: n - k (mod n). Abelian. This group is *cyclic* — generated by the single element 1: {0, 1·1, 2·1, ..., (n-1)·1} = ℤ/nℤ.

**The symmetric group Sₙ.** The group of all permutations of {1, 2, ..., n}, with composition as the group operation. |Sₙ| = n!. Identity: the identity permutation. Inverse: the inverse permutation. Non-abelian for n ≥ 3 (the permutations (12) and (13) do not commute: (12)(13) ≠ (13)(12)).

**The dihedral group D_n.** The symmetries of a regular n-gon: n rotations and n reflections. |D_n| = 2n. Non-abelian for n ≥ 3. Presented as ⟨r, s | rⁿ = s² = e, srs = r⁻¹⟩.

**GL_n(k).** The invertible n × n matrices over a field k, with matrix multiplication. Identity: the identity matrix. Inverse: the matrix inverse. Non-abelian for n ≥ 2.

**The trivial group.** {e} with e · e = e. Every element is the identity, and each group G has a unique homomorphism to and from the trivial group.

## Subgroups

**Definition.** A subset H ⊆ G is a *subgroup* if it is a group under the restricted operation of G.

**Subgroup criterion.** H ⊆ G is a subgroup iff:
- H is non-empty (equivalently, e ∈ H)
- For all a, b ∈ H, a · b ∈ H (closure)
- For all a ∈ H, a⁻¹ ∈ H (closure under inverses)

Equivalently (for finite groups): H is non-empty and closed under multiplication.

**Examples:**
- nℤ = {nk | k ∈ ℤ} is a subgroup of ℤ for any n.
- {e, (12), (13), (23), (123), (132)} = S₃ is a subgroup of itself.
- The alternating group Aₙ (even permutations) is a subgroup of Sₙ of index 2.
- SL_n(k) = {A ∈ GL_n(k) | det(A) = 1} is a subgroup of GL_n(k).

**Lagrange's Theorem.** If G is a finite group and H is a subgroup, then |H| divides |G|.

*Proof sketch.* The *cosets* of H partition G: for any a ∈ G, the left coset aH = {ah | h ∈ H} has the same size as H (the map h ↦ ah is a bijection). And distinct cosets are disjoint. So G is partitioned into |G|/|H| cosets, each of size |H|. □

**Corollary.** The order of any element g ∈ G (the smallest k > 0 with gᵏ = e) divides |G|.

*Proof.* The cyclic subgroup ⟨g⟩ = {e, g, g², ..., gᵏ⁻¹} has order k, and by Lagrange k | |G|. □

## Normal Subgroups and Quotient Groups

**Definition.** A subgroup N ⊆ G is *normal* if gng⁻¹ ∈ N for all g ∈ G and n ∈ N. Equivalently, gN = Ng for all g ∈ G (left cosets equal right cosets).

Not every subgroup is normal. Example: in S₃, the subgroup H = {e, (12)} is not normal: (123)(12)(123)⁻¹ = (123)(12)(132) = (23) ∉ H.

Normal subgroups matter because they let us form quotient groups.

**Definition.** If N is normal in G, the *quotient group* G/N is the set of cosets {gN | g ∈ G} with multiplication (aN)(bN) = (ab)N.

This is well-defined precisely because N is normal: if a' ∈ aN and b' ∈ bN, then a'b' ∈ abN. The identity is eN = N. Inverses: (aN)⁻¹ = a⁻¹N.

**Example.** ℤ/nℤ = ℤ/(nℤ), where nℤ is the subgroup of multiples of n (which is normal in ℤ, since ℤ is abelian). The cosets are {0+nℤ, 1+nℤ, ..., (n-1)+nℤ}, matching our earlier description.

## Homomorphisms and the Isomorphism Theorems

**Definition.** A *group homomorphism* φ: G → H is a function preserving the group operation: φ(ab) = φ(a)φ(b) for all a, b ∈ G.

Consequences: φ(e_G) = e_H and φ(a⁻¹) = φ(a)⁻¹.

The *kernel* of φ is ker(φ) = {g ∈ G | φ(g) = e_H}. The *image* is Im(φ) = {φ(g) | g ∈ G}.

**Key fact.** ker(φ) is always a normal subgroup of G. Im(φ) is always a subgroup of H.

**First Isomorphism Theorem.** If φ: G → H is a homomorphism, then G/ker(φ) ≅ Im(φ).

*Proof.* Define ψ: G/ker(φ) → Im(φ) by ψ(gK) = φ(g), where K = ker(φ). This is well-defined (if g'K = gK, then g'g⁻¹ ∈ K, so φ(g'g⁻¹) = e, so φ(g') = φ(g)). It is a homomorphism (ψ(aKbK) = ψ(abK) = φ(ab) = φ(a)φ(b) = ψ(aK)ψ(bK)). It is surjective (every element of Im(φ) is φ(g) = ψ(gK)). It is injective (if ψ(gK) = e, then φ(g) = e, so g ∈ K, so gK = K). □

**Second Isomorphism Theorem.** If H ≤ G and N ⊴ G, then H/(H ∩ N) ≅ HN/N.

**Third Isomorphism Theorem.** If N ⊴ K ⊴ G and N ⊴ G, then (G/N)/(K/N) ≅ G/K.

These three theorems describe how quotients and subgroups interact. They are the algebraic structure theorems that make everything else in group theory tractable — including the analysis of fundamental groups and their quotients.

## Groups in HoTT

In HoTT, a group G is a *connected 1-type* (a type where all path spaces are sets). The fundamental group π₁(X, x₀) of a topological space (or a type, in HoTT) is the prototypical example: its elements are loops at the basepoint, concatenation is the group operation, reflexivity is the identity, path reversal is the inverse.

The quotient group G/N corresponds to a *pushout* type in HoTT — the type obtained from G by making the elements of N equal to the identity. The normal subgroup condition corresponds to a compatibility requirement for the pushout to be well-defined.

Homomorphisms correspond to maps between connected 1-types that preserve the group structure — in HoTT, these are the group homomorphisms between the corresponding loop spaces. The First Isomorphism Theorem has a direct type-theoretic translation: the image of a group homomorphism is the quotient of the domain by the kernel, which corresponds to a certain pushout factorization in the world of types.

This is not an analogy. When you learn the isomorphism theorems in this section, you are learning their type-theoretic incarnation simultaneously.
