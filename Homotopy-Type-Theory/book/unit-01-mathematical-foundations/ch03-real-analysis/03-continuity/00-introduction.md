Continuity is the condition that functions must satisfy to preserve structure across the passage from input to output. The ε-δ definition makes this precise: a function is continuous at a point if small perturbations to the input produce small perturbations to the output, with the size of the input perturbation controlled by the size of the output perturbation you want. This asymmetry in the quantifier order — output tolerance demanded first, input tolerance supplied in response — is not a quirk of the definition but a reflection of what continuity actually means.

The surprise, which this section develops carefully, is that continuity has multiple equivalent characterizations that look nothing like each other. Sequential continuity (limits of sequences are preserved) looks like a dynamic condition. The open set characterization (preimages of open sets are open) looks like a structural condition. The closed set characterization is formally dual. These equivalences are theorems, not definitions, and they reveal that continuity is a robust concept: however you probe it, you find the same boundary between the continuous and the discontinuous.

For topology and HoTT, the open set characterization is the correct generalization. When you move from metric spaces to topological spaces, the ε-δ definition loses its meaning (there is no metric), but the open set definition survives intact. Continuous functions between topological spaces are exactly functions such that preimages of open sets are open. In HoTT, the analogous condition for functions between types involves the behavior of the function on identity types — how it transports paths. A function preserves paths (is "continuous" in the homotopical sense) not as an additional axiom but as a consequence of being a well-defined function between types.
