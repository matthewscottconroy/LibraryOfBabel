Propositional logic, captured by STLC, is expressive enough for propositional reasoning but too weak for mathematics. The theorem "for all natural numbers $n$, there exists $m > n$" cannot be expressed as an STLC type. The problem is quantification: the proposition $\exists m : \mathbb{N}, m > n$ has a type that depends on the value $n$, and STLC provides no mechanism for types that depend on terms. The Curry-Howard correspondence for propositional logic is complete but narrow; extending it to predicate logic requires a genuinely new idea.

That idea is *dependent types*. The $\Pi$-type $\Pi_{x:A} B(x)$ is the type of functions $f$ such that $f(a) : B(a)$ for each $a : A$ — the output type depends on the input value. When $B$ is constant, this reduces to the ordinary function type. The $\Sigma$-type $\Sigma_{x:A} B(x)$ is the type of pairs $(a, p)$ where $a : A$ and $p : B(a)$ — the type of the second component depends on the value of the first. Universal quantification becomes $\Pi$; existential quantification becomes $\Sigma$. Predicate logic becomes type theory.

The extension from STLC to dependent types is the move from propositional to predicate logic, and simultaneously the move from simple functional programming to Martin-Löf Type Theory. Everything that follows in this book — the univalence axiom, higher inductive types, the homotopy interpretation — lives in a type theory with dependent types. What you learn here about $\Pi$ and $\Sigma$ types, about how type formation rules generalize typing rules, and about why this extension preserves normalization while dramatically increasing expressiveness, is foundational for the entire remaining project.
