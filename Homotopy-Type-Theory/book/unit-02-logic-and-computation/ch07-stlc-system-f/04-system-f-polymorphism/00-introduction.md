STLC requires a separate identity function for every type: one for naturals, one for booleans, one for each product type. This is mathematically absurd. The identity function is one concept. In System F — Girard's polymorphic lambda calculus — you write it once: $\Lambda \alpha.\, \lambda x : \alpha.\, x$, with type $\forall \alpha.\, \alpha \to \alpha$. The type abstraction $\Lambda \alpha$ binds a type variable, and the type application $t\,[B]$ instantiates it. Polymorphism is quantification over types, and universal quantification over types corresponds, under Curry-Howard, to universal quantification in second-order logic.

The power of System F is startling. Church encodings that only approximated data types in STLC become fully adequate in System F: $\mathsf{Bool} = \forall \alpha.\, \alpha \to \alpha \to \alpha$, $\mathsf{Nat} = \forall \alpha.\, (\alpha \to \alpha) \to \alpha \to \alpha$. Every primitive recursive function can be encoded. The logical strength of System F corresponds to second-order Peano arithmetic — a very strong theory that encompasses most of ordinary mathematics.

The key theorem is Reynolds's parametricity. Every term of type $\forall \alpha.\, A$ behaves *uniformly* across all type instantiations — it cannot inspect the type it receives, only abstract over it. This uniformity principle has striking consequences: a closed term of type $\forall \alpha.\, \alpha \to \alpha$ must be the identity function; a term of type $\forall \alpha.\, \alpha \to \alpha \to \alpha$ must be either the first or second projection. The type itself is so constraining that it determines the behavior. Parametricity is a form of free theorem, and it becomes a central tool in programming language theory and, eventually, in establishing properties of type-theoretic constructions in HoTT.
