The most natural rule for a type theory in which types are terms is also, as it turns out, inconsistent. If types are terms, then types need types, and writing Type : Type — the type of all types is itself a type — seems unavoidable. Per Martin-Löf's original 1971 formulation included it. In 1972, Girard showed it was contradictory: from Type : Type alone, you can derive a proof of the empty type, making the theory useless. The culprit is self-reference of exactly the Burali-Forti kind — a universe that contains itself is larger than any of its own elements, including itself.

The fix is a universe hierarchy: Type₀ : Type₁ : Type₂ : ⋯, each universe a type in the next, none containing itself. Small types live in Type₀; type families over Type₀ live in Type₁; and so on, stratified so that no circularity is possible. The hierarchy is infinite, which may feel like it kicks the problem upward rather than solving it — but what matters is that no single universe is self-containing, and the paradox cannot get started. Cumulativity handles the bookkeeping: a type in Typeᵢ is automatically a type in Typeᵢ₊₁, so you rarely need to track levels explicitly.

What universes make possible is equally important as what they forbid. Once you have a universe, you can form Π(A:Type₀).B(A) — you can quantify over types as if they were ordinary values, because in the presence of a universe they are. Generic programming, parametric polymorphism, and the type-level constructions needed for HoTT all depend on this. The univalence axiom itself — the claim that equivalent types are equal — is a statement about elements of a universe. Without a careful universe hierarchy, that statement cannot even be formed without producing a paradox.
