Every formal system needs equality, and equality is almost always treated as a relation — a predicate on pairs of terms, governed by reflexivity, symmetry, transitivity, and substitution. Martin-Löf's innovation is to make equality a type. Not a predicate about a pair (a, b), but a type a =_A b whose elements are proofs that a equals b. This shift from relation to type is the decision that opens the door to Homotopy Type Theory.

The immediate consequence is that proofs of equality become first-class objects. You can form Π types over them, Σ types over them, and functions that take them as arguments and return things that depend on them. Two different proofs of the same equality are, a priori, different terms — there is no reason to assume that all proofs of a = b are identical. This is not a bug or an accident; it is what the rules produce. The identity type has exactly one constructor, reflexivity, and its elimination rule (J) says only that every path from a can be assumed, for the purpose of a proof, to be the trivial path at a. Nothing in those rules forces all paths to be equal. The question of whether they are — Uniqueness of Identity Proofs — turns out to be independent of MLTT's basic axioms.

That independence is the hinge on which HoTT turns. If you add Axiom K, you force all identity proofs to be equal, and the theory collapses to something close to set theory. If instead you add Higher Inductive Types — types with non-trivial path constructors — you get a system where identity types can have rich structure, where a =_A b is not just a truth value but a space whose points are proofs and whose higher structure reflects genuine mathematical content. The identity type introduced here is the seed of all of that.
