Mathematical induction works because every natural number is either zero or a successor. The structure of ℕ is exhausted by two cases. Path induction works by an analogous exhaustion, but the claim is far more striking: to prove a property of all paths p : a =_A b starting at a, it suffices to prove the property for the trivial path refl_a at a. Every path from a, for the purpose of proving properties, reduces to the reflexivity path.

This seems wrong. In topology, a non-trivial path from a to b cannot be contracted to the constant path at a — you would need b = a, and you would need to actually move the endpoint. In type theory, you can induct over paths precisely because the based path space Σ(b:A).(a =_A b) — all paths out of a, to any endpoint — is contractible. Every element (b, p) in this space is connected to (a, refl_a) by a path in the total space. Path induction captures this contractibility as a proof principle. The endpoint b is not fixed; it moves. What looks impossible in topology is valid in type theory because both the endpoint and the path are allowed to vary in the motive.

Path induction is the elimination principle for the identity type, and understanding it is the key to working with equality in MLTT. Every standard property of equality — symmetry, transitivity, congruence — is proved by invoking it, sometimes in a single line. More importantly, path induction is the tool through which HoTT derives the rich algebraic structure of identity types: concatenation of paths, inversion, and higher coherence laws. The J rule is not a technical device for checking formal proofs; it is the fundamental principle that makes identity types a viable notion of equality and makes paths behave like paths.
