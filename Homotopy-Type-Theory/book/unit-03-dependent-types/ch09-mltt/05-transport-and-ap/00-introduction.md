The J rule is the single elimination principle for the identity type, but virtually no proof in HoTT applies J directly. Instead, two derived operations carry almost all the work: transport and ap. Understanding them is understanding how paths propagate through the rest of the type theory.

Transport captures the idea that a path between two points in a base type can be used to move data between the corresponding fibers. Given a type family B : A → Type and a path p : a =_A b, transport along p gives a function B(a) → B(b). An element computed under the assumption that a point is a can be moved, along the path, to an element computed under the assumption that the point is b. This is parallel transport from differential geometry, and it becomes the algebraic mechanism behind the substitution principle: if a = b and you have P(a), you can derive P(b) by transporting along the proof of equality. What is non-obvious is that transport is not merely coercion — it carries full computational content, satisfying functoriality laws that make it behave like genuine path-lifting in a fibration.

The operation ap is the other face of the same coin. Where transport moves elements along paths, ap moves paths along functions: given f : A → B and a path p : a =_A b, ap produces a path f(a) =_B f(b). Every function sends equal inputs to equal outputs — but in dependent type theory, this is not an axiom; it is a derived theorem proved by J, and the resulting path carries the full computational witness. Together, transport and ap are the two tools through which equality propagates in MLTT. Everything in HoTT about functors, fibrations, and the action of type constructors on paths is ultimately derived from these two operations, which are themselves derived from J alone.
