Every sufficiently structured category carries a type theory as its internal language, and every type theory has a category of models. This correspondence is not an analogy — it is a precise mathematical equivalence, bidirectional and complete. When you write a derivation in dependent type theory, you are simultaneously constructing a morphism in a locally cartesian closed category. When a category theorist proves a theorem about LCCCs, the result translates immediately into a fact about dependent types.

What is non-obvious is the hierarchy this correspondence induces. Cartesian closed categories model simply typed lambda calculus. Adding the LCCC structure models full dependent type theory. Adding path objects and weak factorization systems models identity types. Adding a subobject classifier reaches higher-order logic. At the top of the hierarchy: an $\infty$-topos models all of HoTT, including univalence. Each categorical axiom is exactly one type-theoretic axiom, and the soundness and completeness theorems hold at every level.

For you, the practical consequence is this: you can verify properties of a type theory by finding a single categorical model that fails them. Hofmann and Streicher disproved UIP by constructing a groupoid model where identity types have non-trivial structure. Voevodsky validated univalence by constructing the simplicial set model. The categorical semantics is not the final word on what type theory *means* — but it is the most powerful tool available for understanding what type theory can and cannot prove. Every result in this section is a tool for that understanding.
