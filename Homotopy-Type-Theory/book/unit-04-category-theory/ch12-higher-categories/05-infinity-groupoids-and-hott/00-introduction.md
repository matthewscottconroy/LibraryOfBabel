HoTT is not merely inspired by homotopy theory — it *is* a homotopy theory, expressed in the language of type theory. Every type is an ∞-groupoid, with elements as objects, identity proofs as 1-morphisms, proofs of equality between proofs as 2-morphisms, and so on through all dimensions. The ∞-groupoid structure is not imposed from outside; it is built into the rules of the identity type. The $J$ eliminator gives you path induction; path induction gives you path concatenation, inversion, and all higher coherence data. You do not add ∞-groupoid structure to types — you discover that it was always there.

What is non-obvious is how completely the match runs. The loop space $\Omega(A, a) = (a =_A a)$ is the ∞-group of self-equivalences of the basepoint $a$. The higher loop spaces $\Omega^n(A, a)$ are progressively more commutative: $\Omega^2$ is a group, $\Omega^3$ is an abelian group, and by the Eckmann-Hilton argument, higher loop spaces are all abelian. This is exactly the homotopy-theoretic pattern for loop spaces of topological spaces, now visible in the pure type-theoretic syntax.

The semantic validation of this picture is Voevodsky's simplicial set model: interpret types as Kan complexes, dependent types as Kan fibrations, terms as sections, and identity types as path-space fibrations. In this model, univalence is a theorem (not an axiom of the model), and HoTT becomes the internal language of the ∞-topos of spaces. The connection between ∞-groupoids and HoTT is not a correspondence you prove once and then set aside — it is the organizing principle that gives HoTT its power as a foundation for mathematics and its utility as a language for automated proof.
