Not every simplicial set behaves like a topological space. A general simplicial set may have "gaps" — collections of lower-dimensional simplices that ought to bound a higher-dimensional one but do not, because the higher simplex was never declared to exist. A Kan complex is a simplicial set without gaps of this kind: every horn — every collection of all but one face of a simplex — can be filled. The filling need not be unique; only existence is required. This single condition transforms a combinatorial object into a combinatorial model of a topological space.

What makes this precise is the distinction between inner and outer horns. An inner horn $\Lambda^n_k$ for $0 < k < n$ specifies all faces of an $n$-simplex except the $k$-th; filling it corresponds to composing morphisms. An outer horn specifies all faces except the first or last; filling it corresponds to having inverses. A simplicial set filling all horns — inner and outer — models an $\infty$-groupoid: a structure where every morphism at every dimension is invertible, which is precisely what a topological space gives you when you work up to homotopy. Filling only inner horns gives you a quasi-category, which models an $(\infty, 1)$-category instead.

The Kan condition is the simplicial-set analogue of a space having well-behaved path structure. In HoTT, you expect that for any two terms $a, b : A$, the identity type $a = b$ is inhabited when $a$ and $b$ are connected by a path — and that paths can be composed and inverted. The horn-filling condition packages exactly these requirements, dimension by dimension: 2-horns encode composition and inverses of paths, 3-horns encode associativity up to homotopy, and so on. Kan complexes are, in this sense, the combinatorial incarnation of the path-structure that HoTT builds into the identity type by axiom.
