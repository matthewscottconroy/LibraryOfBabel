Every formal system requires a model before it can be trusted. A model is a mathematical structure — built in some accepted foundation, typically set theory — in which all the axioms of the system hold. If the structure exists and the foundation is consistent, the system is consistent relative to the foundation. For Homotopy Type Theory, this is non-trivial: HoTT includes the univalence axiom, which asserts that equivalent types are identical, and univalence does not hold in the classical set-theoretic models of Martin-Löf type theory. A new model was needed. Voevodsky provided it.

The construction assigns meaning to every piece of HoTT's syntax within the world of simplicial sets. A type becomes a Kan complex. A term becomes a vertex. A type family $P : A \to \mathcal{U}$ becomes a Kan fibration $E \to A$ with Kan complex fibers. The identity type $a =_A b$ becomes the path-space Kan complex: the simplicial set of simplices of $A$ connecting $a$ to $b$, which is the fiber of the diagonal $A \to A \times A$ over the pair $(a, b)$. The reflexivity term $\mathsf{refl}_a$ is the degenerate simplex $s_0 a$ — the constant path at $a$, generated by the degeneracy map. Path induction holds because the Kan fibration representing a type family has the extension property that path induction requires.

The climax of the model is the interpretation of univalence. The universe $\mathcal{U}$ is the Kan complex whose $n$-simplices are Kan fibrations over $\Delta[n]$ — a "space of Kan complexes." Equivalences of types correspond to homotopy equivalences of Kan complexes, and homotopy equivalences of Kan complexes are the same as paths in $\mathcal{U}$. Univalence holds because paths in $\mathcal{U}$ between two Kan complexes are precisely the homotopy equivalences between them. The entire geometric intuition of this unit — paths as proofs, deformations as equalities, homotopy type as identity — is here shown to be not just an analogy but a theorem: HoTT is a language in which homotopy theory is the native semantics, and Voevodsky's model is the proof.
