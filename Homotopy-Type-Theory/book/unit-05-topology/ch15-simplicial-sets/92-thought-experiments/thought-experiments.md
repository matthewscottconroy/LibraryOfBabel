# Thought Experiments: Simplicial Sets

## 1. The Combinatorial Topology Machine

Imagine a machine that takes as input a finite description — a list of sets $X_0, X_1, X_2, \ldots$ and a list of face and degeneracy maps satisfying the simplicial identities — and outputs a topological space (by geometric realization). The machine is purely algebraic: it takes discrete combinatorial data and produces a continuous geometric object.

*Questions:*
- What inputs produce the circle? (One vertex $v$, one non-degenerate 1-simplex $e$ with $d_0 e = d_1 e = v$, plus all the degenerate simplices generated by these. This is the simplicial set description of $S^1$.)
- What inputs produce $S^2$? (One vertex $v$, no non-degenerate 1-simplices, one non-degenerate 2-simplex $f$ with all three faces being the degenerate edge at $v$. This gives $S^2$ as the quotient of a triangle with all edges collapsed to a point.)
- Can every topological space be described this way? (No: only CW complexes arise as geometric realizations of simplicial sets with finitely many non-degenerate simplices. But every space has a weakly equivalent simplicial set, namely its singular complex — and the singular complex is always a Kan complex.)

The thought experiment highlights the combinatorial-geometric duality: topological spaces are geometric realizations of combinatorial data, and simplicial sets are combinatorial encodings of topological spaces.

## 2. The Horn-Filling Oracle

You are given a simplicial set $X$ (as lists of sets with face and degeneracy maps). You have access to an oracle that, given any horn $\Lambda^n_k \to X$, tells you whether a filling exists.

*Questions:*
- If the oracle says "all horns fill," can you trust the simplicial set to model a homotopy type? (Yes: this is the Kan condition. Kan complexes correctly model homotopy types.)
- If the oracle says "only inner horns fill" (not the outer ones $\Lambda^n_0$ and $\Lambda^n_n$), what kind of mathematical object does $X$ model? (An $(\infty, 1)$-category, or quasi-category: a category where 2-morphisms and above are invertible but 1-morphisms need not be.)
- If no horns need to fill, what is $X$? (Just an arbitrary simplicial set, modeling nothing in particular unless you do something with it. The homotopy-theoretically interesting content requires the Kan condition.)

The oracle thought experiment clarifies why the Kan condition is precisely the right condition: it is the minimum required to ensure the simplicial set correctly encodes all the composition and invertibility structure of a homotopy type.

## 3. Degeneracy Maps Are Not Trivial

A common misconception: degeneracy maps in a simplicial set are "trivial" or "just extra copies." In fact, they are essential.

Consider a simplicial set without degeneracy maps — a *semi-simplicial set*. It has sets $X_0, X_1, X_2, \ldots$ and face maps, but no degeneracy maps. Can such a semi-simplicial set model a homotopy type?

Answer: Not directly. The degeneracy maps encode the "identity morphisms" at each dimension: $s_0 a$ is the "degenerate edge" at vertex $a$, representing the identity path at $a$. Without degeneracy maps, you have no identity morphisms, and you cannot form an $\infty$-groupoid — you only have an $\infty$-category where composition need not be unital.

*The HoTT analog:* The degeneracy map $s_0 : X_0 \to X_1$ sends each vertex $a$ to the degenerate edge $s_0 a$, which is the "reflexivity" path at $a$. In HoTT, this is the term $\mathsf{refl}_a : a =_A a$. The simplicial identity $d_0 s_0 a = a$ and $d_1 s_0 a = a$ says the reflexivity path starts and ends at $a$ — as expected. Without degeneracy maps (without $\mathsf{refl}$), there is no reflexivity, and identity types are not types of paths but something weaker.

## 4. The Universe as a Space

The universe $\mathcal{U}$ in HoTT is a type — and in the simplicial set model, it is a Kan complex. What does this mean geometrically?

The $0$-simplices of $\mathcal{U}$ are types (Kan complexes). The $1$-simplices of $\mathcal{U}$ are maps between types (Kan fibrations over $\Delta[1]$, equivalently, maps between Kan complexes). The $2$-simplices of $\mathcal{U}$ are homotopies between maps. And so on.

The path space $\mathcal{U}(A, B)$ (the "type of paths from $A$ to $B$ in $\mathcal{U}$") consists of all $1$-simplices from vertex $A$ to vertex $B$. Univalence says: this path space is equivalent to the space of homotopy equivalences from $A$ to $B$.

*The thought experiment:* Imagine walking through the universe $\mathcal{U}$ as a topological space. Each point you visit is a type. Paths between points are homotopy equivalences between types. Loops (paths from a type back to itself) are self-equivalences — automorphisms of the type. The fundamental group $\pi_1(\mathcal{U}, A)$ is the group of self-equivalences of $A$.

For $A = \text{Bool}$ (the type with two elements), the only self-equivalences are the identity and the swap (exchange the two elements). So $\pi_1(\mathcal{U}, \text{Bool}) = \mathbb{Z}/2\mathbb{Z}$.

For $A = \mathbb{N}$ (the natural numbers), the self-equivalences are all bijections $\mathbb{N} \to \mathbb{N}$. The group of self-equivalences of $\mathbb{N}$ is the symmetric group on a countably infinite set — an infinite, non-abelian group. So $\pi_1(\mathcal{U}, \mathbb{N})$ is this infinite symmetric group.

Univalence makes these self-equivalences into loops in the universe — actual topological loops. The higher homotopy groups of the universe encode the space of homotopies between self-equivalences, and so on up the tower.

## 5. From Triangulation to Proof

In classical topology, you *triangulate* a space — decompose it into simplices — to compute its homology. The triangulation replaces a continuous space with a combinatorial object (a simplicial complex), and the algebra is done on the combinatorial side.

In HoTT, you do not triangulate types — types are already "combinatorial" in the sense that they come with a built-in identity type structure (the path space). The identity types are the "edges" of the type, the identity types of identity types are the "triangles," and so on. The type itself plays the role of the simplicial set.

*The thought experiment:* Consider the type $\mathbb{Z}$ (the integers) in HoTT. What is its "triangulation"?
- The $0$-simplices are the integers: ..., $-2$, $-1$, $0$, $1$, $2$, ...
- The $1$-simplices are paths between integers: $p : m = n$ for integers $m, n$. But $\mathbb{Z}$ is a set in HoTT (a $0$-type), so all identity types $m = n$ are either empty (if $m \neq n$) or the singleton $\{\mathsf{refl}_m\}$ (if $m = n$).
- There are no non-trivial higher simplices.

So the "triangulation" of $\mathbb{Z}$ is a discrete simplicial set: just a set of vertices with no edges. The geometric realization is a discrete set of points — which is correct, since $\mathbb{Z}$ as a topological space is discrete.

For a non-trivial type, like $S^1$ (the circle HIT), the "triangulation" is:
- $0$-simplices: just $\text{base}$.
- $1$-simplices: the loop $\text{loop}$ and all its powers.
- Higher simplices: all coherence data.

This is exactly the singular complex of the topological circle — the Kan complex that corresponds to $S^1$ in the Voevodsky model.
