The question at the center of everything is deceptively simple: what does it mean for two things to be equal? Classical logic has an answer, and the answer is too simple. Either two things are equal or they are not. There is nothing more to say. The proof of equality is not an object — it is a verdict. Once rendered, it vanishes.

Homotopy type theory refuses this. Here, equality is not a verdict but a type. The statement that a equals b is not a proposition to be checked but a space to be inhabited. An element of the identity type `a =_A b` is a path — a specific, concrete witness to how a and b are the same. Two paths connecting the same endpoints may be genuinely different objects, carrying different information, connecting to different proofs in different ways.

This single move — from equality-as-proposition to equality-as-type — is the fulcrum on which all of HoTT turns. The identity type has formation rules, introduction rules, and an elimination principle called J, which is the right way to formalize the intuition that equal things can be substituted for one another. From J alone, all the path structure of the theory follows: concatenation, inversion, transport, the entire infinity-groupoid. Before you see where this goes, the J eliminator looks almost too sparse to be useful. What follows will show you that it is not sparse at all — it is exactly enough.
