Classical logic has a category of truth values: true and false. Constructive logic, taken seriously, complicates this picture, because proofs are objects and proofs can differ. Homotopy type theory provides the resolution: a mere proposition is a type where any two elements are equal. The specific proof you have of a proposition carries no information beyond the fact that you have one. Whether the proposition is inhabited is all there is to know.

This is the type-theoretic formalization of classical logic's truth values, and it has real teeth. The empty type is a proposition: false. The unit type is a proposition: true. And the critical insight is that propositions are closed under exactly the operations you expect — conjunction, implication, universal quantification — while existential quantification requires care. The statement "there exists x satisfying P" is not automatically a proposition, because the witness x might carry information. To get a genuine proposition you need the propositional truncation, which collapses all the witnesses together and tells you only that one exists.

The distinction between propositions and proof-relevant types runs through everything that follows. When you are working with univalence, you need equivalence to be a proposition rather than a structure with potentially many distinct elements. When you compute fundamental groups, you need to distinguish between the mere existence of a loop and the specific loop itself. Propositions are the types where these distinctions vanish — and understanding exactly when a type is a proposition, and when it is not, is one of the central skills of working in HoTT.
