Most of mathematics, most of the time, takes place in sets. The natural numbers are a set. The real numbers are a set. Groups, rings, vector spaces — all of these are sets with additional structure. The ordinary tools of algebra and analysis do not need to distinguish between different proofs that two elements are equal. They only need to know whether equality holds.

In homotopy type theory, a set is a type at h-level 0: a type where all path types are propositions. Two elements of a set are either equal or not, and when they are equal, there is exactly one proof of their equality. The identity type `a = b` in a set is either empty or contractible. No higher path structure, nothing to remember beyond the verdict.

This is Uniqueness of Identity Proofs, and it is not provable for arbitrary types — there are types, like the circle and the universe, where identity types have genuinely non-trivial structure. But the natural numbers are a set, the integers are a set, and any type with decidable equality is a set (Hedberg's theorem). The classical mathematical world sits safely inside the h-level-0 stratum of HoTT, which is exactly the right relationship: HoTT extends classical mathematics by enriching equality, without disturbing it. When higher structure is absent, the theory reduces to what you already know. When it is present, you have genuinely new mathematics.
