The pattern established by contractible types, propositions, and sets does not stop at h-level 0. It continues: a type is an n-type if all its path types are (n-1)-types. Starting from contractible types at level -2, the hierarchy extends upward through every non-negative integer, each level allowing one more layer of non-trivial path structure before the tower collapses.

At h-level 1, path types are sets — elements can be equal in at most one way, but the elements themselves can differ. This is the level of groupoids. At h-level 2, path types are groupoids, and so on. Each new level is a strictly larger class of types, and the cumulative property — that every n-type is also an (n+1)-type — ensures the hierarchy is well-ordered and coherent.

What this classification does is give you a language for asking how complex a type is. The circle is a 1-type: its path types are sets (the integers, once you have computed the fundamental group), but the circle itself is not a set. The universe is not any finite n-type — it sits above the hierarchy, containing types of arbitrary complexity. The n-type classification is not merely organizational. It is the right measure of homotopy-theoretic complexity, and it governs what you can and cannot do with a type: what kinds of truncations apply, what kinds of eliminations are valid, and how much information survives when you project down to a lower level.
