A type can carry more information than you need. The path structure of a type may be rich and interesting in itself while being irrelevant to the computation or proof at hand. Truncation is the operation that strips away the excess — it forces a type down to a given h-level, collapsing everything above that level to a single point while preserving everything below.

The two most important truncations are propositional and set truncation. The propositional truncation of A, written ‖A‖, converts A into a proposition: it tells you whether A is inhabited but forgets which element you have. This distinction — between having a specific element and merely knowing one exists — is the type-theoretic version of the difference between constructive and classical existence. The set truncation ‖A‖₀ takes the connected components of A: it collapses paths while preserving the distinction between elements that cannot be connected.

These operations are not merely formal tools. They are the mechanism by which HoTT mediates between proof-relevant and proof-irrelevant mathematics. Whenever you want to state that something merely exists without committing to a specific witness, you use propositional truncation. Whenever you want to take a quotient that forgets path information and gets a set, you use set truncation. The general theory of n-truncations unifies both: for each n, there is a universal way to approximate any type by an n-type, and this approximation is functorial, well-behaved, and — as the next chapter will show — constructible as a higher inductive type.
