Every path gives an equivalence. This is provable from the J eliminator alone: given a proof that A equals B as types, you can transport along that path to get a function from A to B, and this function is an equivalence. The direction from paths to equivalences is not in question.

The Univalence Axiom states that the other direction holds too, and that the map from paths to equivalences is itself an equivalence. Every equivalence between types comes from a path between types. This is not provable in standard Martin-Löf type theory — it is an axiom, added by Voevodsky, and it changes the theory fundamentally.

The philosophical weight of this axiom is difficult to overstate. In ordinary mathematics, isomorphic structures are "the same" in the sense that anything true of one is true of the other. But they are not literally equal — the real numbers and the complex numbers are isomorphic as additive groups, but they are not the same additive group, and mathematics carefully distinguishes them. Univalence collapses this distinction at the type level: if two types are equivalent, they are equal. Not just interchangeable, not just "morally the same" — literally, formally, provably equal in the identity type of the universe. Properties that are invariant under equivalence transfer not by argument but by substitution, because equivalence is equality. This is what "invariance under isomorphism" means when it is taken all the way to its logical conclusion.
