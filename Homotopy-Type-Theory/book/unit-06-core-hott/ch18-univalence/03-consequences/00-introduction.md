An axiom earns its keep by what it proves. The Univalence Axiom is not merely a philosophical statement about the nature of equality — it has immediate and powerful mathematical consequences, the most important of which is function extensionality: two functions that agree on every input are equal. This sounds obvious, perhaps even like it should be definitionally true. In standard Martin-Löf type theory, it is neither. It cannot be proved. You can know that f and g agree everywhere and still be unable to conclude f = g as elements of the function type. Univalence fixes this.

The proof is elegant: construct the interval as a higher inductive type with two points and a path between them, use the pointwise homotopy to build a function from the interval into the function type, and read off the path. Alternatively, use univalence directly. Either way, function extensionality — which had been an additional axiom in earlier formulations of type theory — is now a theorem.

Propositional extensionality follows as a special case: propositions that are logically equivalent are equal. Structure invariance follows as the general principle: any property expressible in the type theory is invariant under equivalence. Taken together, these consequences mean that univalence does not just license a new way of thinking about equality. It transforms what mathematics can express internally. Every statement that in ordinary foundations requires "up to isomorphism" qualifications can be stated simply, as an ordinary equality, because equivalence is equality.
