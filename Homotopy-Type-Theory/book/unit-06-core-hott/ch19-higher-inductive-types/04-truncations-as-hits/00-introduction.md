Earlier in this unit, truncations were introduced by their universal properties: the propositional truncation of A is the best proposition approximating A, and the set truncation is the best set. Universal properties characterize objects up to unique equivalence, which is fine for proving things about truncations — but it leaves open the question of existence. Do these truncations actually exist within the type theory, or must they be assumed?

Higher inductive types answer this question constructively. Truncations are HITs. The propositional truncation ‖A‖ is defined with a point constructor that injects A and a path constructor that forces any two elements to be equal. The set truncation ‖A‖₀ adds a path-of-path constructor that forces all path types to be propositions. Each additional level of truncation requires one additional level of path constructor, and the pattern is completely uniform.

This is significant for two reasons. First, it means truncations are not additional axioms — they are derived constructions, built from the same rules as everything else in HoTT. Second, it makes the computational content of truncation explicit. The squash constructor of ‖A‖ is not an abstract assertion that the type is a proposition; it is a specific path constructor, present in the eliminator, that you must account for whenever you define a function out of ‖A‖. The condition that you can only eliminate into propositions is not a restriction imposed by hand — it falls out of the elimination rule for the HIT. The theory is consistent, and the constraints are built in.
