# Chapter 19: Higher Inductive Types

Ordinary inductive types let you build things from scratch: you build N from zero and successor, you build trees from leaves and nodes. Higher inductive types let you build things with EQUATIONS built in. You declare not just constructors — points — but path constructors — equations between points, and homotopy constructors — equations between those equations. The circle S^1 has one point and one path from that point to itself. That is the whole definition. And from this minimal data, HoTT can prove that its fundamental group is Z.

This is a new kind of mathematical definition. It is not just building a set from constructors. It is building a *space* from points and paths. When we define the circle as a HIT, we are saying: "There is one point, called base. There is one loop, called loop, which is a path from base to base. The circle is the type freely generated by these." Every other element of the circle is a quotient of these generators, and every other path is a consequence of the loop.

The word "freely generated" is the key. HITs give you the *free type* with the specified points and paths — the smallest type containing the specified data, with no additional identifications beyond the ones you declare. This is analogous to how a free group on generators {a, b} is the smallest group containing a and b with no relations other than the group axioms.

## Why HITs Are Necessary

Without HITs, HoTT can reason about homotopy types that already exist in the simplicial set model, but cannot *construct* new ones inside the type theory. We can *use* the fact that the circle has fundamental group Z (since the simplicial set model tells us so), but we cannot *define* the circle as a type and *derive* this fact from first principles.

HITs provide the missing constructive mechanism. The circle S^1 is defined by its generators (one point, one loop). The sphere S^2 is defined by one point and one 2-cell. The torus T^2 is defined by two loops and a relation between them. These are not post-hoc descriptions — they are genuine definitions, from which all topological properties of these spaces can be derived within the type theory.

## The Scope of HITs

The class of higher inductive types is remarkably expressive. With HITs, we can define:

- All spheres and suspension types (Section 2)
- All pushouts and related colimit constructions (Section 3)
- All truncation operations (Section 4)
- All Eilenberg-MacLane spaces (Section 5)
- The interval type (Section 1) — which gives function extensionality without Univalence

In fact, it appears that all homotopy types can be built from HITs (this is the conjecture that HoTT with HITs "presents" all homotopy types in a suitable sense). The synthetic homotopy theory of Chapter 20 provides evidence for this by proving classical theorems about these HIT-defined types using only type-theoretic methods.

## How HITs Work

An ordinary inductive type like N is defined by specifying:
- Point constructors: 0 : N and S : N → N
- An elimination principle: to prove P(n) for all n : N, prove P(0) and P(S(m)) from P(m)
- Computation rules: the eliminator computes on the constructors

A HIT like S^1 is defined by specifying:
- Point constructors: base : S^1
- Path constructors: loop : base = base
- An elimination principle: to prove P(x) for all x : S^1, prove P(base) and a "path-over" transport^P(loop, P(base)) = P(base)
- Computation rules: the eliminator computes on base, and the dependent action on loop is specified

The path constructors force certain equations to hold. The elimination principle says: to define something on the whole HIT, you must be compatible with the equations. The computation rules say: the definitions on points compute definitionally, and the definitions on paths compute propositionally.

## Chapter Roadmap

Section 1 gives the interval I and the circle S^1 — the two simplest HITs. Both have clean eliminators and illustrate the general pattern.

Section 2 develops suspensions and spheres. The suspension of A is a HIT with two poles and a path for each element of A. Iterating gives all spheres.

Section 3 treats pushouts — the most general "gluing" construction. Colimits, quotients, and the van Kampen theorem all live here.

Section 4 shows that truncations — defined informally in Chapter 17 — are HITs. The propositional truncation is a HIT with a path constructor forcing all elements to be equal.

Section 5 introduces Eilenberg-MacLane spaces K(G,n), which are the building blocks of cohomology theory. These are HITs with complex path structure, and they connect HoTT to the classical theory of cohomology.

HITs are where HoTT becomes a genuine theory of spaces, not just a type-theoretic framework. After this chapter, we have the spaces. Chapter 20 uses them.
