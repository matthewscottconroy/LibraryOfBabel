Knowing that paths exist and knowing how to compute with them are different things. The circle has a loop, and that loop generates a non-trivial fundamental group, but proving this requires more than pointing at the HIT definition and noting that the loop is non-trivial. You must show that the loop space of the circle is equivalent to the integers — that every loop at the basepoint is determined by an integer (its winding number), and that distinct integers give non-homotopic loops.

The encode-decode method is the systematic technique for doing this. You define a family of types over the target space — the code family — chosen so that the fiber over the basepoint is the type you want to show the loop space is equivalent to. You then construct two maps: encode, which sends loops to elements of the code by transporting a basepoint element around the loop, and decode, which goes the other way. Proving these are mutually inverse establishes the equivalence.

The creative work is in choosing the code family. The wrong choice makes the proof impossible; the right choice makes it almost automatic. For the circle, the right code family uses the Univalence Axiom to define a type family over S^1 that transports by the successor function on the integers — exactly capturing the intuition that going around the loop once increments the winding number. The method thus illustrates something general about synthetic homotopy theory: the deep theorems require creative insight, but once the insight is in hand, the proof is a clean type-theoretic argument that compiles directly into a formal proof.
