# The Hopf Fibration

## A Remarkable Discovery

In 1931, Heinz Hopf discovered a map h : S³ → S² with the extraordinary property that every point of S² has a fiber homeomorphic to S¹. Before Hopf, topologists knew that any map between spheres of different dimensions is "trivial" in homology. Hopf showed that homotopy is different: the map h is not homotopic to a constant map, even though it induces the zero map on all homology groups.

The Hopf fibration is the first and simplest example of a non-trivial fibration in homotopy theory. It generates the group π₃(S²) = Z (Hopf proved this in the same 1931 paper). It is the starting point for a vast theory of fibrations, K-theory, and stable homotopy.

In HoTT, the Hopf fibration can be constructed using the join construction, and its properties follow from the general theory of fibration sequences.

## The Classical Hopf Fibration

Classically, the Hopf fibration is constructed as follows:

View S³ as the unit sphere in C²: S³ = {(z₀, z₁) ∈ C² : |z₀|² + |z₁|² = 1}.
View S² as the Riemann sphere CP¹ = C ∪ {∞}.

The Hopf map h : S³ → S² is:
```
h(z₀, z₁) = z₀/z₁ ∈ CP¹ = S²
```

(where z₁ = 0 maps to ∞, and the "fraction" is complex division).

The fiber over each point w ∈ S² is the circle {(z₀, z₁) ∈ S³ : z₀/z₁ = w} ≅ S¹. So the Hopf fibration is a fiber bundle S¹ → S³ →^h S².

## The HoTT Construction

In HoTT, the Hopf fibration is constructed using the *join* construction.

**Step 1: The join S¹ * S¹.** The join of two circles is a 3-sphere: S¹ * S¹ ≃ S³. This is proved using the fact that the join of two (n-1)-spheres is a 2n-1-sphere: S^{n-1} * S^{m-1} ≃ S^{n+m-1}.

For n = m = 1: S^0 * S^0 = Bool * Bool ≃ S¹, and iterating gives S^1 * S^1 ≃ S^3.

**Step 2: The Hopf map.** The join S¹ * S¹ has points:
- `inl(a)` for a : S¹
- `inr(b)` for b : S¹
- `jn(a, b, t)` for a, b : S¹ and t : I (the path from inl(a) to inr(b))

The Hopf map h : S³ = S¹ * S¹ → S² is constructed by "projecting out one S¹ coordinate." More precisely, h is the map that, for each point in S¹ * S¹, gives its "base S¹ coordinate" in the suspension ΣS¹ = S².

**The key structure.** For each b : S¹, the fiber h⁻¹(b) = {points mapping to b} is equivalent to S¹. This gives the Hopf fibration S¹ → S³ →^h S².

## The Hopf Family

The Hopf family is a type family `H : S² → Type` with H(x) = S¹ for each x : S² and the total space Σ(x:S²).H(x) = S³.

In HoTT, the Hopf family is defined using the S²-eliminator:
- `H(base) := S¹`
- `ap_H(surf) := ua(rot)` — where surf : base = base in S² is the 2-cell (the "surface" of S²) and rot : S¹ ≃ S¹ is the rotation equivalence.

The rotation equivalence rot : S¹ ≃ S¹ is the equivalence defined by rot(base) = base and `ap_rot(loop) = loop · loop` — it rotates the circle by a full turn.

By Univalence, ua(rot) is a path S¹ = S¹, and this gives the Hopf family.

**Verification.** The total space Σ(x:S²).H(x) should be S³. This is proved by showing that the map Σ(x:S²).H(x) → S² is the Hopf fibration with fiber S¹.

## The Fibration Sequence

Any fibration F → E →^p B gives a *long exact sequence of homotopy groups*:

```
... → πₙ(F) → πₙ(E) → πₙ(B) →^∂ πₙ₋₁(F) → ... → π₁(B) →^∂ π₀(F) → ...
```

For the Hopf fibration S¹ → S³ →^h S²:
- F = S¹, E = S³, B = S²

The long exact sequence gives:
```
π₃(S¹) → π₃(S³) → π₃(S²) → π₂(S¹) → π₂(S³) → π₂(S²) → π₁(S¹) → π₁(S³) → π₁(S²)
```

Computing the terms:
- π₃(S¹) = 0 (S¹ is a K(Z,1), so πₙ(S¹) = 0 for n ≥ 2)
- π₃(S³) = Z (π₃ of the 3-sphere is Z, generated by the identity map)
- π₂(S¹) = 0 (same reason)
- π₂(S³) = 0 (S³ is 2-connected)
- π₂(S²) = Z (from Freudenthal: π₂(S²) ≅ π₃(S³) = Z)
- π₁(S¹) = Z
- π₁(S³) = 0 (S³ is simply connected)
- π₁(S²) = 0 (S² is simply connected)

From the exact sequence:
- `0 → π₃(S³) → π₃(S²) → π₂(S¹) = 0`
- So π₃(S²) ≅ π₃(S³) = Z ✓

**Theorem.** π₃(S²) = Z, generated by the Hopf fibration h : S³ → S².

This is Hopf's 1931 theorem, now with a synthetic proof in HoTT.

## Brunerie's Theorem: π₄(S³) = Z/2Z

The next computation is much harder. Guillaume Brunerie proved in his 2016 PhD thesis:

**Theorem (Brunerie).** π₄(S³) = Z/2Z.

The proof in HoTT uses:
1. The Hopf fibration to give a map S³ → S².
2. The fiber sequence of this map.
3. The long exact sequence in homotopy groups.
4. A careful analysis of the boundary map π₄(S²) → π₃(S¹).

The computation requires knowing π₄(S²) and the boundary map, which in turn requires the Freudenthal theorem, the Hopf fibration, and substantial additional machinery.

Brunerie's original proof used a "Brunerie number" β : Z and proved π₄(S³) = Z/|β|Z, but could not compute β directly in the proof assistant — it required computer-assisted computation. Later work (by Ljungström and others) showed β = 2 definitively using computational verification.

## Why Higher Homotopy Groups Are Hard

The higher homotopy groups of spheres are extraordinarily complex. Here is a table of known values:

| n | π_n(S¹) | π_n(S²) | π_n(S³) |
|---|---|---|---|
| 1 | Z | 0 | 0 |
| 2 | 0 | Z | 0 |
| 3 | 0 | Z | Z |
| 4 | 0 | Z/2Z | Z/2Z |
| 5 | 0 | Z/2Z | Z/2Z |
| 6 | 0 | Z/12Z | Z/12Z |
| 7 | 0 | Z/2Z | Z/2Z |

The pattern is irregular, complex, and seems to have no simple formula.

**Why HoTT helps.** In HoTT, the homotopy groups of spheres are *computable* from the definitions. The encode-decode method, the fibration sequence, and the Freudenthal theorem give algorithms for computing specific groups. Brunerie's computer-verified proof of π₄(S³) = Z/2Z is a proof of concept: with enough computation, these groups can be determined within the type theory.

This does not mean the problem is easy — the computations are still fiendishly complex. But HoTT provides a framework in which they can be *checked* formally, unlike the classical setting where proofs of these results require substantial unverified calculations.

## Summary

| Construction | Definition | Key property |

| Hopf fibration | Σ(x:S²).H(x) → S² | Fiber = S¹ |

The Hopf fibration is the first non-trivial fibration in homotopy theory, and its synthetic construction in HoTT using the join and Univalence demonstrates the full power of the framework. The long exact sequence gives π₃(S²) = Z, and the Brunerie computation extends this to π₄(S³) = Z/2Z — the frontier of what has been formally verified.
