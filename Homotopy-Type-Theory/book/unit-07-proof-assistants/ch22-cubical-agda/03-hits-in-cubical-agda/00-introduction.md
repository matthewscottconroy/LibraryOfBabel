In the HoTT Book, the circle is an axiom. You declare a type `S¹` with a basepoint and a loop, declare an eliminator, and postulate computation rules — but those rules hold only propositionally. The circle is a mathematical object you can reason about in the sense of writing propositions about it, but you cannot compute with it: the eliminator applied to the loop constructor does not reduce. It is a formal system with the right logical behavior but no computational content at the path level.

In Cubical Agda, the circle is a `data` declaration with two constructors. The computation rules hold definitionally, because the loop constructor produces an element of a path type, and path types in Cubical Agda are functions on the interval. When you apply the eliminator to a loop, you get a function application, and function application *reduces*. The abstract mathematical object has become a computable program. This is not a matter of implementation convenience — it changes what you can prove and how easily you can prove it, because definitional equalities can be used silently while propositional equalities require explicit transport.

This section works through the higher inductive types that matter most for HoTT: the circle, the sphere, the torus, suspensions, pushouts, and set truncations. For each, you will see the `data` declaration, the eliminator, and at least one substantial result — the fundamental group of the circle is `ℤ`, the suspension of `S¹` is `S²`, the set truncation of a type strips its higher homotopy. These are not toy examples. They are the theorems that motivated HoTT, now machine-verified in a system where the proofs actually run.
