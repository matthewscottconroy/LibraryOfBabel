The Cubical Agda library is the closest thing that exists to a complete computational implementation of Homotopy Type Theory. Starting from the primitive interval type and the `Glue` constructor, it derives univalence, builds the higher inductive types, establishes the algebraic hierarchy, and proves homotopy-theoretic results — including Brunerie's calculation that the fourth homotopy group of `S³` is `ℤ/2ℤ` — in a single coherent system where every step computes. To work in this library is to work in HoTT not as a foundation you accept on faith but as a structure you can run.

The library is organized to mirror the mathematical development: primitive constructors in `Cubical.Core`, general-purpose foundations in `Cubical.Foundations` (equivalences, univalence, h-levels, function extensionality), higher inductive types in `Cubical.HITs`, and progressively richer algebraic and homotopy-theoretic content above that. Navigating it efficiently means understanding this organization — knowing that the circle lives in `Cubical.HITs.S1`, that the Seifert-van Kampen theorem lives in `Cubical.Homotopy`, that the universal property of set truncation is in `Cubical.HITs.SetTruncation` — so you can find what you need rather than rediscovering it.

This section connects the mathematical content of the preceding units to the library structure that implements it. You will read and write files that import from multiple parts of the library, combine results across modules, and extend the library with new theorems. By the end, you are not just a user of the Cubical Agda library — you understand enough of its internal architecture to know where a new result belongs, how to state it so it fits the existing conventions, and how to contribute a proof that the library can absorb.
