The complement operation that makes cubical type theory work is also what prevents it from internalizing category theory. Path reversal — the map `sym : (a = b) → (b = a)` — is definitional in CCHM precisely because the interval has a complement $\sim i$ swapping its endpoints. Every path goes both ways. But in a category, morphisms are directed: $f : a \to b$ does not automatically produce a morphism $b \to a$. The symmetry built into the cubical interval is exactly what category theory must lack.

Simplicial type theory resolves this by introducing a second interval — the directed interval $\mathbf{2}$ — alongside the undirected cubical interval $\mathbb{I}$. The directed interval has endpoints and an ordering but no complement. A function $f : \mathbf{2} \to A$ with $f(0) = a$ and $f(1) = b$ is a *morphism* from $a$ to $b$, not a path. The absence of $\sim$ means there is no automatic reverse. The hom type $\mathsf{hom}_A(a, b)$ and the hom type $\mathsf{hom}_A(b, a)$ are genuinely distinct types. Directed asymmetry is built into the theory at the level of its intervals.

The architecture that results is a two-level system: an outer tope layer reasoning about combinatorial shapes — simplices, horns, the directed interval — with strict extensional equality, and an inner homotopy layer where types are spaces with directed morphisms. You already understand the inner level well; HoTT lives there. What is new is the outer level supplying the indexing shapes, and the extension type construction that ties them together. The two intervals are not in conflict — they serve different purposes, and simplicial type theory needs both.
