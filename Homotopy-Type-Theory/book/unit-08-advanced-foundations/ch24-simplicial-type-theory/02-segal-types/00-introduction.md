The question of when a type behaves like a category has a precise answer in simplicial type theory, and it is stated entirely as a property — not as extra structure. You do not add composition to a type; you ask whether the type already has it, in the sense that certain restriction maps are equivalences. A type either satisfies the Segal condition or it does not, and the condition itself is a proposition.

The Segal condition says that the restriction map from 2-simplices to inner horns — from filled triangles to composable pairs — is an equivalence. This packs in two things simultaneously. Existence: every composable pair has a composite, meaning every inner horn can be filled. And uniqueness: the space of fillings is contractible, meaning composition is essentially unique. The contractibility is crucial. A strict category would demand a unique composite on the nose; an $\infty$-category demands a contractible space of composites, encoding all the coherence data that strict uniqueness would otherwise require by fiat. The Segal condition states both demands in a single equivalence.

What is surprising, and worth sitting with, is that every type in ordinary HoTT is Segal. Path types are the hom types; path concatenation is composition; the Segal condition holds because path composites form a contractible space. This means ∞-groupoids embed into the world of Segal types — HoTT is a special case of simplicial type theory, not a separate subject. The Segal condition distinguishes the types that have additional directed structure from those that are already symmetric. Ordinary HoTT types happen to be symmetric Segal types, i.e., ∞-groupoids. What you are learning here is the broader class that contains them.
