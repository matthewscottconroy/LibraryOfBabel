Being Segal is not enough. A Segal type has well-defined composition — every composable pair has an essentially unique composite — but composition is a fact about morphisms, not about objects. The Segal condition says nothing about when two objects should be considered "the same." You can have a Segal type in which two objects are isomorphic by an invertible morphism while remaining strictly distinct as elements of the type. Such a type fails to satisfy the principle that equivalent objects are equal — the categorical analogue of univalence.

The Rezk condition closes this gap. It asks that the canonical map from the identity type $a =_A b$ to the type of isomorphisms $\mathsf{Iso}_A(a, b)$ is an equivalence, for all objects $a$ and $b$. The map always exists: `refl` maps to the identity isomorphism. The Rezk condition says it is an equivalence in both directions — every isomorphism comes from a path, and every path produces an isomorphism. Isomorphism and equality coincide. This is exactly what univalence asserts for the universe, but stated internally for a Segal type rather than for `Type` globally.

The resulting notion — a Segal type that is also Rezk — is what simplicial type theory calls a Rezk type, and it is the correct internal notion of $(\infty,1)$-category. The category $\mathsf{Type}$ is itself a Rezk type: the Segal condition holds by function composition, and the Rezk condition holds by univalence. Every $(\infty,1)$-category that mathematics cares about is a Rezk type in this sense, and the definitions, theorems, and proofs from classical category theory now internalize into type-theoretic statements about Rezk types — proved once, applicable everywhere.
