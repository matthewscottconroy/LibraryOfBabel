Three modalities in an adjoint triple encode geometry. This is the central claim of cohesive HoTT, and it is surprising because geometry seems to live far from the world of adjunctions and reflective subcategories. But the adjoint triple $\int \dashv \flat \dashv \sharp$ — shape, flat, sharp — precisely captures the relationship between a space's geometric structure, its underlying homotopy type, and its underlying set of discrete points. Add these three modalities with specified adjunction data to HoTT, and the type theory acquires the capacity to speak about smooth manifolds, continuous maps, and locally constant functions, all without coordinates.

The shape modality $\int$ strips away geometric structure and returns the underlying homotopy type. For a smooth manifold $M$, $\int M$ is its topological realization — the homotopy type of $M$ considered as a space, forgetting smoothness. The flat modality $\flat$ takes a type and returns its underlying discrete set of points with no continuous structure; a map into $\flat V$ is a locally constant map to $V$. The sharp modality $\sharp$ goes in the other direction, treating a type as having all possible maps into it, with no restriction to continuous ones. The adjunctions tie these together: $\int$ is left adjoint to $\flat$, which is left adjoint to $\sharp$, and the chain of adjunctions imposes coherence conditions that encode the relationship between topology and geometry.

What you gain from this framework is coordinate-free differential geometry as a native language of the type theory. A statement involving only the cohesive modalities applied to a smooth type $M$ is automatically invariant under diffeomorphism — not because you proved an invariance theorem, but because diffeomorphism is equality in the type theory and equal types satisfy the same propositions. The geometry is not encoded; it is constitutive.
