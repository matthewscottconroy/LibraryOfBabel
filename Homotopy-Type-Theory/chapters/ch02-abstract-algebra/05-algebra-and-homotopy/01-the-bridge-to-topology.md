# 5.1 The Bridge to Topology and Homotopy Type Theory

## Two Worlds, One Story

We've spent this chapter building algebraic tools: groups, subgroups, quotients, homomorphisms, free groups, presentations, actions. These might feel like purely abstract constructions — interesting for their own sake but perhaps disconnected from geometry or type theory.

This section is where we reveal the connection. The algebraic structures we've studied are not just analogous to topological and type-theoretic ones — they are literally the same, seen from different angles. Let's trace the correspondences carefully.

## The Correspondence Table

Here is the core table, which we'll unpack piece by piece:

| Algebra | Topology | Homotopy Type Theory |
|---|---|---|
| Group $G$ | Fundamental group $\pi_1(X, x_0)$ | Loop space $\Omega(A, a)$ |
| Group element $g \in G$ | Loop (path from $x_0$ back to $x_0$) | Term $p : a =_A a$ |
| Group multiplication $g \cdot h$ | Path concatenation $\gamma_1 \cdot \gamma_2$ | Path composition `p ∘ q` |
| Identity $e$ | Constant loop at $x_0$ | Reflexivity `refl_a : a = a` |
| Inverse $g^{-1}$ | Reversed loop $\bar\gamma$ | Path inversion `p⁻¹ : a = a` |
| Normal subgroup $N \unlhd G$ | Based covering space | Subtype of loop space |
| Quotient group $G/N$ | Deck transformation group | Quotient type |
| Free group $F(S)$ | $\pi_1$ of a bouquet of circles | Identity type of a HIT circle |
| Group presentation $\langle S \mid R \rangle$ | CW complex | Higher inductive type |
| Homomorphism $G \to H$ | Continuous map (on $\pi_1$) | Function type (on identity types) |
| Isomorphism | Homotopy equivalence | Type equivalence |

Each row is a theorem, not just an analogy. Let's discuss the most important ones.

## Fundamental Groups and Loops

**The fundamental group** of a pointed space $(X, x_0)$ is the group $\pi_1(X, x_0)$ whose elements are *homotopy classes of loops* based at $x_0$: continuous maps $\gamma: [0, 1] \to X$ with $\gamma(0) = \gamma(1) = x_0$, modulo continuous deformation (homotopy rel endpoints).

The group operation is *concatenation*: $([\gamma_1] \cdot [\gamma_2])(t)$ follows $\gamma_1$ for $t \in [0, 1/2]$, then $\gamma_2$ for $t \in [1/2, 1]$. This is well-defined on homotopy classes.

The identity is the constant loop at $x_0$: $\varepsilon(t) = x_0$ for all $t$.

The inverse of $[\gamma]$ is $[\bar\gamma]$ where $\bar\gamma(t) = \gamma(1-t)$ (the loop traversed backwards).

**Why this is a group:** Associativity holds up to homotopy (both $((\gamma_1 \cdot \gamma_2) \cdot \gamma_3)$ and $(\gamma_1 \cdot (\gamma_2 \cdot \gamma_3))$ traverse the same loops in the same order, just at different speeds — and you can homotope between them). Identity works: $\varepsilon \cdot \gamma \simeq \gamma$ (going nowhere then following $\gamma$ is homotopic to just following $\gamma$). Inverses work: $\gamma \cdot \bar\gamma \simeq \varepsilon$ (going along $\gamma$ then immediately reversing can be contracted to a constant).

**Comparison with free groups:** The free group $F(S)$ is generated by elements $s \in S$ with no relations. The fundamental group of a bouquet of $|S|$ circles — one circle for each $s \in S$ — is exactly $F(S)$. Each circle contributes one generator (a loop around that circle), and there are no relations because the circles only meet at one point.

This is not a coincidence: topological spaces are essentially "presentations" of groups (and higher algebraic structures), and the circles in a bouquet play the same role as generators in a free group.

## In HoTT: Paths as Proofs of Equality

In Homotopy Type Theory, the *identity type* `a =_A b` (pronounced "the type of proofs that $a$ equals $b$ in $A$") is not just a proposition — it's a type that can have multiple distinct elements (different "reasons" why $a = b$).

The central idea of HoTT is: **identity types behave like path spaces**.

- A term `p : a = a` is a "proof of $a = a$", which we think of as a *loop* at $a$.
- Reflexivity `refl_a : a = a` is the constant loop.
- Given `p : a = b` and `q : b = c`, their *concatenation* `p ∘ q : a = c` (sometimes written `p · q`) is the composed path.
- The *inverse* `p⁻¹ : b = a` of `p : a = b` is the reversed path.

These operations satisfy the group laws *up to higher paths*:
- Associativity: `(p ∘ q) ∘ r = p ∘ (q ∘ r)` holds up to a path of paths (a 2-path).
- Identity: `refl ∘ p = p` holds up to a path.
- Inverse: `p ∘ p⁻¹ = refl` holds up to a path.

This "up to higher paths" structure is not just looseness — it's the signature of an *∞-groupoid*, which is the correct algebraic model for homotopy types. Groups capture the first layer (loops form a group). ∞-Groupoids capture all layers (paths between paths between paths...).

## The Univalence Axiom and Isomorphism as Equality

The *Univalence Axiom* in HoTT states: **for types $A$ and $B$, there is an equivalence between $(A = B)$ and $(A \simeq B)$** (paths between types correspond to type equivalences).

Applied to groups: if two groups $G$ and $H$ are isomorphic (there is a bijective homomorphism $G \cong H$), then in HoTT, they are *equal* as types. Isomorphism implies identity.

This is a radical departure from set theory (where two isomorphic-but-distinct sets remain distinct), and it's philosophically motivated: in mathematics, we never care about the specific construction of a group, only its structure. Univalence makes this into a *theorem*: if you can't tell $G$ and $H$ apart structurally, they are the same.

The group theory we've developed — defining groups by universal properties, proving uniqueness up to isomorphism — is the correct preparation for Univalence, because it already treats isomorphic groups as "the same."

## Free Groups as Fundamental Groups of Circles

Let's make the free group / circle connection precise.

**Claim:** In HoTT, the fundamental group of the circle $S^1$ is $\mathbb{Z}$.

The circle $S^1$ is defined in HoTT as a higher inductive type (HIT):
```
data S¹ : Type where
  base : S¹
  loop : base = base
```
One point (`base`) and one non-trivial loop.

The *loop space* $\Omega(S^1, \text{base}) = (\text{base} = \text{base})$ is the type of all loops. The claim is that $\Omega(S^1, \text{base}) \simeq \mathbb{Z}$.

The proof uses the universal property: to define a function from $\Omega(S^1, \text{base})$ to any type $T$, it suffices to specify where to send `loop`. Sending `loop` to the element $1 \in \mathbb{Z}$ gives the winding number map. The inverse gives the map $n \mapsto \text{loop}^n$.

This is the algebraic-topological theorem $\pi_1(S^1) = \mathbb{Z}$, proven *synthetically* — without constructing $S^1$ as a subset of $\mathbb{R}^2$.

## Higher Groups and ∞-Groupoids

Group theory is the study of 1-dimensional algebra: elements, one operation, one level of inverses. But homotopy theory naturally involves higher dimensions:
- Loops (1-dimensional paths)
- Homotopies between loops (2-dimensional paths-between-paths)
- Homotopies between homotopies (3-dimensional)
- ...

The algebraic structure that captures all of this is an *∞-groupoid*: a structure with morphisms at every level, all invertible. This is exactly what types are in HoTT.

In this sense, all of group theory is the study of the *first level* of a richer ∞-dimensional theory. The theorems about groups (isomorphism theorems, presentations, free groups, Cayley's theorem) all have higher-dimensional analogs, and HoTT provides the framework to state and prove them.

The table at the beginning of this section should now be read not as a list of analogies, but as a list of *identifications*. When we do group theory, we're doing low-dimensional homotopy theory. When we state the universal property of the free group, we're stating the mapping-out property of the bouquet of circles. When we prove the First Isomorphism Theorem, we're proving a theorem about homotopy pushouts.
