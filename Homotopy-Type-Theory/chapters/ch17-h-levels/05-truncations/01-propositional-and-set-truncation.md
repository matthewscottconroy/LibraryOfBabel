# 5.1 Truncations

## The Idea

Given a type $A$ at any h-level, we can "force" it down to a lower h-level by *truncating* it. Truncation keeps all the essential information up to a certain level and collapses everything above.

Think of it like a lossy photograph: you can resize a high-resolution image to a lower resolution, keeping the broad structure but losing fine detail. Truncation does the same thing to types: it keeps the "broad" homotopy structure (the lower h-levels) and collapses the "fine" structure (higher h-levels) to trivial.

The key operations:
- **Propositional truncation** $\|A\| = \|A\|_{-1}$: "Does $A$ have an element?" — collapses all information to a mere truth value
- **Set truncation** $\|A\|_0$: "What are the connected components of $A$?" — collapses all path structure to a discrete set
- **$n$-truncation** $\|A\|_n$: Keeps the homotopy structure through dimension $n$, collapses above

Truncations are *higher inductive types* (HITs) — they're defined by their constructors plus path constructors that force the appropriate structure. We'll defer the general HIT machinery to Chapter 19 and focus here on how truncations work and what they're good for.

## Propositional Truncation

The most important truncation is propositional truncation, which converts any type into a mere proposition.

**Definition 5.1 (Propositional truncation).** For a type $A$, the *propositional truncation* $\|A\|$ (also written $\|A\|_{-1}$ or sometimes $\mathsf{Squash}(A)$) is defined by:
- Constructor: $|{-}| : A \to \|A\|$ (every element of $A$ gives an element of $\|A\|$)
- Path constructor: $\mathsf{squash} : \prod_{x, y : \|A\|}\, x = y$ (any two elements of $\|A\|$ are equal)

The path constructor forces $\|A\|$ to be a proposition.

**Informal reading:** $\|A\|$ is "the proposition that $A$ is inhabited." It's true (inhabited) if $A$ has an element, and false (empty) if $A$ is empty.

**The universal property.** Propositional truncation is characterized by its universal property:

**Theorem 5.2 (Universal property of $\|A\|$).** For any proposition $P$ (with $\mathsf{isProp}(P)$):
$$(A \to P) \simeq (\|A\| \to P)$$

That is, there's an equivalence between functions from $A$ to $P$ and functions from $\|A\|$ to $P$.

*Proof.* One direction is precomposition with $|{-}| : A \to \|A\|$: any function $g : \|A\| \to P$ gives $g \circ |{-}| : A \to P$.

Other direction: given $f : A \to P$, we want to define $\tilde{f} : \|A\| \to P$. For elements $|a| \in \|A\|$ (from the constructor), define $\tilde{f}(|a|) = f(a)$. For paths $\mathsf{squash}(x, y) : x = y$ in $\|A\|$, we need $\tilde{f}(x) = \tilde{f}(y)$ — this holds because $P$ is a proposition (any two elements of $P$ are equal).

These are inverse to each other, giving the equivalence. $\square$

**What this says:** To define a function $\|A\| \to P$ to a proposition, it suffices to define a function $A \to P$. The propositional truncation is the "free proposition generated by $A$."

## Existential vs. Existence

Here's where propositional truncation has striking logical consequences.

In dependent type theory, there are *two* ways to say "there exists an $x : A$ such that $P(x)$":
1. $\sum_{x:A} P(x)$: a dependent pair — gives both the *existence* and the *witness* $x$
2. $\|\sum_{x:A} P(x)\|$: the propositional truncation — gives only the *mere existence*, no computational witness

**Type theory distinguishes these;** classical logic does not (since in classical logic, both reduce to the same truth value "there exists").

**Example 5.3 (The Intermediate Value Theorem).** Consider $f : [0,1] \to \mathbb{R}$ continuous with $f(0) < 0 < f(1)$. The IVT says there exists a root:
- **Classical IVT**: $\exists x \in [0,1],\, f(x) = 0$ — a truth value
- **Constructive strong IVT**: $\sum_{x : [0,1]} (f(x) = 0)$ — a computable root
- **Constructive weak IVT**: $\|\sum_{x : [0,1]} (f(x) = 0)\|$ — a mere existence, no computable witness

Classical logic gives the weak form. Constructive mathematics (via bisection algorithm) gives the strong form. In HoTT:
- The classical proof (non-constructive) establishes the weak form
- The constructive proof (bisection) establishes the strong form
- These are literally different types with different computational behaviors

**Example 5.4 (Axiom of Choice).** The Axiom of Choice in its strong form:
$$\mathsf{AC}: \prod_{x:A} \|\sum_{y:B(x)} P(x, y)\| \to \|\sum_{f : \prod_{x:A} B(x)} \prod_{x:A} P(x, f(x))\|$$

This says: if for each $x$ there *merely exists* a $y$ with $P(x,y)$, then there *merely exists* a choice function. This is a non-trivial axiom in HoTT (it holds in classical logic but its status in constructive HoTT is subtle).

The *strong* Axiom of Choice:
$$\mathsf{SAC}: \prod_{x:A} \sum_{y:B(x)} P(x, y) \to \sum_{f : \prod_{x:A} B(x)} \prod_{x:A} P(x, f(x))$$

This says: if for each $x$ there *constructively exists* a $y$, then there *constructively exists* a choice function. This is provable in HoTT (it's essentially just the projection function on a $\Pi \Sigma$ type).

The difference: $\mathsf{SAC}$ is trivial (the choice function is just the projection), while $\mathsf{AC}$ is non-trivial (it involves propositional truncations).

## Computing with Propositional Truncation

When can we "extract" information from $\|A\|$?

By the universal property, we can map out of $\|A\|$ into any proposition. So if we want to prove a proposition $P$ using an element $a : A$, and we only have $\|A\|$ (mere existence), that's fine — we can still prove $P$.

**But:** If we want to extract a *non-propositional* value $B$ (with $B$ not a proposition), we **cannot** map $\|A\| \to B$ unless $B$ is a proposition.

**Theorem 5.5 (Elimination of truncation).** For any type $B$ and $t : \|A\|$:
- If $\mathsf{isProp}(B)$: we can define $\tilde{f} : \|A\| \to B$ from any $f : A \to B$.
- If $B$ is not a proposition: we generally cannot define $\tilde{f} : \|A\| \to B$ from $f : A \to B$.

This restriction is fundamental. It separates "proof content" (which can be extracted from $\|A\|$) from "computational content" (which requires the actual witness in $A$, not just $\|A\|$).

**Example 5.6.** You cannot write a program that extracts a natural number from $\|\mathbb{N}\|$ — the propositional truncation of $\mathbb{N}$ — because $\mathbb{N}$ is not a proposition. All we know from $\|\mathbb{N}\|$ is that "some natural number exists," not which one.

## Set Truncation

The *set truncation* $\|A\|_0$ converts any type into a set, keeping the "connected components" information.

**Definition 5.7 (Set truncation).** For a type $A$, the *set truncation* $\|A\|_0$ is defined by:
- Constructor: $|{-}|_0 : A \to \|A\|_0$
- Path truncation: any two paths $p, q : x = y$ in $\|A\|_0$ are equal (forcing $\|A\|_0$ to be a set)

**The universal property.** For any set $B$ (with $\mathsf{isSet}(B)$):
$$(A \to B) \simeq (\|A\|_0 \to B)$$

To define a function $\|A\|_0 \to B$ to a set, it suffices to define a function $A \to B$.

**What $\|A\|_0$ computes.**

$\|A\|_0$ identifies all elements of $A$ that are connected by paths (i.e., elements in the same connected component). The result is the discrete set of connected components:
$$\|\cdot\|_0 : A \mapsto \pi_0(A)$$

**Examples:**
- $\|\mathbb{N}\|_0 = \mathbb{N}$ (since $\mathbb{N}$ is already a set)
- $\|S^1\|_0 = \mathbf{1}$ (the circle is connected — one component)
- $\|A + B\|_0 = \|A\|_0 + \|B\|_0$ (disjoint union splits into components)
- $\|\Sigma_{n:\mathbb{N}} P(n)\|_0 =$ the set of natural numbers satisfying $P$ (where $P$ is a proposition)

**The homotopy group $\pi_0$.** The set truncation is the type-theoretic version of $\pi_0$: the set of connected components of a space. In HoTT:
$$\pi_0(A) :\equiv \|A\|_0$$

And more generally:
$$\pi_n(A, a) :\equiv \|\Omega^n(A, a)\|_0$$

(the set of connected components of the $n$-fold loop space — the $n$-th homotopy group as a set).

## Higher Truncations

For any $n \geq -2$, the $n$-truncation $\|A\|_n$ is the universal $n$-type with a map from $A$.

**Definition 5.8 ($n$-truncation).** The $n$-truncation $\|A\|_n$ is the HIT generated by:
- Constructor: $|{-}|_n : A \to \|A\|_n$
- Truncation constructors: for all $k > n$, all $k$-dimensional paths in $\|A\|_n$ are equal (forced by the HIT constructors)

The exact construction uses the HIT machinery of Chapter 19.

**The universal property.** For any $n$-type $B$:
$$(A \to B) \simeq (\|A\|_n \to B)$$

This makes $\|A\|_n$ the *$n$-type reflection* of $A$ — the "best approximation" of $A$ by an $n$-type.

**The Postnikov tower.** The sequence of truncations:
$$A \xrightarrow{|{-}|_n} \|A\|_n \xrightarrow{} \|A\|_{n-1} \xrightarrow{} \cdots \xrightarrow{} \|A\|_0 \xrightarrow{} \|A\|_{-1} \xrightarrow{} \|A\|_{-2} \simeq \mathbf{1}$$

gives the Postnikov tower: each level "truncates" one more layer of higher homotopy.

**The maps:** There are canonical maps $\|A\|_{n+1} \to \|A\|_n$ (truncating from level $n+1$ to level $n$), and these compose to give the tower.

**Whitehead's theorem (HoTT version).** A map $f : A \to B$ is an equivalence if and only if $\|f\|_n : \|A\|_n \to \|B\|_n$ is an equivalence for all $n$.

This is the HoTT version of the classical theorem that a map between CW complexes is a homotopy equivalence iff it's an isomorphism on all homotopy groups.

## Truncations and Logic

The interplay between truncations and logic is rich:

**The logic of propositions.** In the sub-universe $\mathsf{hProp}$ of propositions, we have intuitionistic propositional logic:
- $\top = \mathbf{1}$ (truth)
- $\bot = \mathbf{0}$ (falsity)
- $P \wedge Q = P \times Q$ (conjunction)
- $P \vee Q = \|P + Q\|$ (disjunction, using truncation)
- $P \Rightarrow Q = P \to Q$ (implication)
- $\neg P = P \to \mathbf{0}$ (negation)

Without truncation, $P + Q$ would be a sum type (carrying information about *which* of $P$ or $Q$ holds), not a mere truth value. Truncation makes the disjunction propositional.

**The logic of types.** In the full type theory (not restricted to propositions), we have a richer logic:
- $\sum_{x:A} P(x)$ (constructive existence — with witness)
- $\|\sum_{x:A} P(x)\|$ (mere existence — without witness)
- $\prod_{x:A} P(x)$ (universal quantification)
- Higher inductive types (existential higher structure)

This is the "proof-relevant" logic, where the distinction between proofs matters.

## Propositional Resizing

In HoTT, there's a potential issue: propositions at different universe levels might be different. A proposition in $\mathsf{Type}_0$ and a proposition in $\mathsf{Type}_1$ might not be the same, even if they're logically equivalent.

**Propositional Resizing Axiom.** Every proposition in $\mathsf{Type}_1$ is equivalent to a proposition in $\mathsf{Type}_0$.

This is an optional axiom (consistent with HoTT) that ensures propositions are "small" — they don't "grow" as we go up the universe hierarchy. It simplifies the logic considerably.

Without resizing, we need to be careful about universe levels when working with propositions. With resizing, propositions are essentially universe-independent.

## Summary

Truncations are the operations that force types down the h-level hierarchy:

| Truncation | Name | Universal property |
|---|---|---|
| $\|A\|_{-1}$ | Propositional truncation | $A \to P \simeq \|A\|_{-1} \to P$ for propositions $P$ |
| $\|A\|_0$ | Set truncation / $\pi_0$ | $A \to S \simeq \|A\|_0 \to S$ for sets $S$ |
| $\|A\|_n$ | $n$-truncation | $A \to T \simeq \|A\|_n \to T$ for $n$-types $T$ |

They capture the "essential content" of a type at each level, discarding higher homotopy information. Together with the h-level hierarchy (the levels themselves) and the h-level closure properties (products, Σ-types, function types are $n$-types if the components are), truncations give a complete toolkit for stratifying the complexity of types in HoTT.

The propositional truncation $\|A\|$ is especially central: it mediates between the constructive world (where witnesses matter) and the classical world (where existence is all that matters). This mediation is one of HoTT's great features — it can speak both languages, with precision about which is being used.
