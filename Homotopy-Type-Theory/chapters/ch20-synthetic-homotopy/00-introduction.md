# Chapter 20: Synthetic Homotopy Theory

## Mathematics from the Inside

Classical homotopy theory is *analytic*: you build spaces as sets with extra structure (topologies, CW-complex structures), define continuity as a condition on functions, and prove theorems by reasoning about these constructions.

Synthetic homotopy theory is different: you reason about spaces (types) using only the axioms of the type theory. There are no sets, no open sets, no point-set constructions. A type *is* a space, and the type theory's rules *are* the rules of homotopy theory. Everything is proved from the inside.

This is not just philosophical — it has practical consequences:
- **Every function is continuous.** There's no need to check continuity; it's automatic.
- **Proofs have computational content.** The proof that $\pi_1(S^1) = \mathbb{Z}$ is a program that computes winding numbers.
- **Machine verification is possible.** These proofs can be checked by Agda, Lean, or other proof assistants.
- **New proofs of old theorems.** The synthetic proofs of van Kampen, Freudenthal, and Blakers-Massey use different techniques from the classical proofs — illuminating the mathematics from a new angle.

## The Core Technique: Encode-Decode

The central computational technique in synthetic homotopy theory is the *encode-decode method*:
1. To compute the loop space $\Omega(X, x_0)$ of a type $X$, define a "code" type family $\mathsf{code} : X \to \mathsf{Type}$
2. The code at $x_0$ should be the group you expect $\pi_1(X)$ to be
3. Show that the loop space and the code are equivalent via explicit encode/decode maps

This technique reduces the computation of homotopy groups to a type-theoretic calculation, using the HIT structure of $X$ and the computation rules for transport.

## The Main Theorems

This chapter proves the central theorems of (low-dimensional) synthetic homotopy theory:

**$\pi_1(S^1) = \mathbb{Z}$** — The fundamental group of the circle is the integers. This is the benchmark computation.

**Seifert-van Kampen** — The fundamental group of a pushout is the amalgamated free product of the fundamental groups of the pieces.

**Freudenthal Suspension** — For $n$-connected types, suspension raises connectedness. This gives the stability of homotopy groups.

**Hopf Fibration and $\pi_3(S^2) = \mathbb{Z}$** — The first "exotic" homotopy group computation: $\pi_3(S^2) = \mathbb{Z}$, generated by the Hopf fibration.

**Brunerie's Theorem** — $\pi_4(S^3) = \mathbb{Z}/2\mathbb{Z}$, the first computational result that required a computer to verify.
