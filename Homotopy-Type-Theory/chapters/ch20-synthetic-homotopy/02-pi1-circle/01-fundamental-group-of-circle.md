# 2.1 $\pi_1(S^1) = \mathbb{Z}$: Full Proof

## The Benchmark Computation

The computation $\pi_1(S^1) = \mathbb{Z}$ is the "hello world" of synthetic homotopy theory. It's the first non-trivial computation, and it illustrates every key technique: HIT eliminators, transport, Univalence, and encode-decode.

Classically, this is obvious: the circle's fundamental group is the integers, generated by the winding number. But proving it rigorously requires some topology. In HoTT, the proof is *constructive* and *computable*: the winding number is literally the transport function.

## The Circle HIT

Recall from Chapter 19:
$$S^1 = \{ \mathsf{base} : S^1, \quad \mathsf{loop} : \mathsf{base} =_{S^1} \mathsf{base} \}$$

To define a function $f : S^1 \to B$ (non-dependent), we specify:
- $f(\mathsf{base}) = b : B$
- $\mathsf{ap}_f(\mathsf{loop}) = \ell : b = b$

(a point in $B$ and a loop at that point).

To define a *dependent* function $s : \prod_{x:S^1} P(x)$, we specify:
- $s(\mathsf{base}) = b : P(\mathsf{base})$
- $\mathsf{apd}_s(\mathsf{loop}) = \ell : \mathsf{transport}^P(\mathsf{loop}, b) = b$

(a point in the fiber over $\mathsf{base}$ and a proof that transporting along $\mathsf{loop}$ returns it).

## Step 1: The Code Family

Define the code family $\mathsf{code} : S^1 \to \mathsf{Type}$ by:

**At the base point:** $\mathsf{code}(\mathsf{base}) :\equiv \mathbb{Z}$

**At the loop:** The non-dependent eliminator for $S^1$ into $\mathsf{Type}$ requires a path $\mathbb{Z} = \mathbb{Z}$ in the universe. By Univalence, a path $\mathbb{Z} = \mathbb{Z}$ is an equivalence $\mathbb{Z} \simeq \mathbb{Z}$.

We choose the *successor equivalence* $\mathsf{succ} : \mathbb{Z} \simeq \mathbb{Z}$ (adding 1). By Univalence:
$$\mathsf{ua}(\mathsf{succ}) : \mathbb{Z} = \mathbb{Z}$$

Define: $\mathsf{ap}_\mathsf{code}(\mathsf{loop}) :\equiv \mathsf{ua}(\mathsf{succ})$.

**What this means:** Transport along $\mathsf{loop}$ in the family $\mathsf{code}$ is the successor function:
$$\mathsf{transport}^\mathsf{code}(\mathsf{loop}) = \mathsf{succ} : \mathbb{Z} \to \mathbb{Z}$$

(by the computation rule for Univalence: $\mathsf{transport}(\mathsf{ua}(e), -) = e(-)$).

Similarly, transport along $\mathsf{loop}^{-1}$ is the predecessor:
$$\mathsf{transport}^\mathsf{code}(\mathsf{loop}^{-1}) = \mathsf{pred} : \mathbb{Z} \to \mathbb{Z}$$

## Step 2: The Encode Map

Define:
$$\mathsf{encode} : \prod_{x:S^1}\, (\mathsf{base} = x) \to \mathsf{code}(x)$$

by: $\mathsf{encode}(x, p) :\equiv \mathsf{transport}^\mathsf{code}(p, 0_\mathbb{Z})$

where $0_\mathbb{Z} : \mathbb{Z}$ is the integer zero.

**What $\mathsf{encode}$ does.** For a loop $p : \mathsf{base} = \mathsf{base}$, $\mathsf{encode}(\mathsf{base}, p)$ transports $0 \in \mathbb{Z}$ along $p$. Each traversal of $\mathsf{loop}$ increments by 1 (transport = successor). Each traversal of $\mathsf{loop}^{-1}$ decrements by 1. So $\mathsf{encode}(\mathsf{base}, \mathsf{loop}^n) = n$ — the winding number!

**Key computation:**
$$\mathsf{encode}(\mathsf{base}, \mathsf{loop}^n) = n \quad \text{for all } n : \mathbb{Z}$$

*Proof by induction on $n$:*
- $n = 0$: $\mathsf{encode}(\mathsf{refl}) = \mathsf{transport}^\mathsf{code}(\mathsf{refl}, 0) = 0$. ✓
- $n+1$: $\mathsf{encode}(\mathsf{loop}^{n+1}) = \mathsf{encode}(\mathsf{loop}^n \cdot \mathsf{loop})$
  $= \mathsf{transport}^\mathsf{code}(\mathsf{loop}^n \cdot \mathsf{loop}, 0)$
  $= \mathsf{transport}^\mathsf{code}(\mathsf{loop}, \mathsf{transport}^\mathsf{code}(\mathsf{loop}^n, 0))$  (transport over concatenation)
  $= \mathsf{succ}(\mathsf{encode}(\mathsf{loop}^n))$  (transport along $\mathsf{loop}$ = succ)
  $= \mathsf{succ}(n) = n+1$.  ✓
- $n$ negative: similar using $\mathsf{loop}^{-1}$ and predecessor. ✓

## Step 3: The Decode Map

Define:
$$\mathsf{decode} : \prod_{x:S^1}\, \mathsf{code}(x) \to (\mathsf{base} = x)$$

At $\mathsf{base}$: $\mathsf{decode}(\mathsf{base}) : \mathbb{Z} \to (\mathsf{base} = \mathsf{base})$ by $\mathsf{decode}(\mathsf{base}, n) :\equiv \mathsf{loop}^n$.

where $\mathsf{loop}^n$ is the $n$-fold concatenation:
$$\mathsf{loop}^0 :\equiv \mathsf{refl}_\mathsf{base}$$
$$\mathsf{loop}^{n+1} :\equiv \mathsf{loop}^n \cdot \mathsf{loop}$$
$$\mathsf{loop}^{-1} :\equiv \mathsf{loop}^{-1} \quad (\text{the inverse path})$$
$$\mathsf{loop}^{-(n+1)} :\equiv \mathsf{loop}^{-n} \cdot \mathsf{loop}^{-1}$$

**To extend $\mathsf{decode}$ to all of $S^1$**, use the dependent eliminator with:
- $\mathsf{decode}(\mathsf{base}, -) = \lambda n.\, \mathsf{loop}^n$ (as defined above)
- The transport condition: need $\mathsf{apd}_\mathsf{decode}(\mathsf{loop})$, i.e., need to show that transporting the family of functions $\lambda n.\, \mathsf{loop}^n$ along $\mathsf{loop}$ gives... the same family.

The transport condition: $\mathsf{transport}^{(\mathsf{code}(-) \to \mathsf{base} = -)}(\mathsf{loop}, \mathsf{decode}(\mathsf{base})) = \mathsf{decode}(\mathsf{base})$.

This reduces (by the transport computation for function types) to showing:
$$\lambda n.\, \mathsf{transport}^{(\mathsf{base} = -)}(\mathsf{loop}, \mathsf{loop}^{\mathsf{pred}(n)}) = \lambda n.\, \mathsf{loop}^n$$

Since transport in a path type concatenates: $\mathsf{transport}^{(\mathsf{base}=(-)}(\mathsf{loop}, p) = p \cdot \mathsf{loop}$.

So the condition becomes: $\mathsf{loop}^{\mathsf{pred}(n)} \cdot \mathsf{loop} = \mathsf{loop}^n$ — which holds since $\mathsf{loop}^{n-1} \cdot \mathsf{loop} = \mathsf{loop}^n$ by definition of powers.

So $\mathsf{decode}$ is well-defined as a dependent function.

## Step 4: The Round Trips

**$\mathsf{encode} \circ \mathsf{decode} = \mathsf{id}$** (on $\mathbb{Z}$):

Need: for all $n : \mathbb{Z}$, $\mathsf{encode}(\mathsf{base}, \mathsf{decode}(\mathsf{base}, n)) = n$.

$\mathsf{encode}(\mathsf{base}, \mathsf{loop}^n) = n$ — this is the key computation from Step 2. ✓

**$\mathsf{decode} \circ \mathsf{encode} = \mathsf{id}$** (on paths):

Need: for all $x : S^1$ and $p : \mathsf{base} = x$, $\mathsf{decode}(x, \mathsf{encode}(x, p)) = p$.

*Proof by path induction (J) on $p$.* It suffices to check the case $x = \mathsf{base}$ and $p = \mathsf{refl}_\mathsf{base}$:

$\mathsf{decode}(\mathsf{base}, \mathsf{encode}(\mathsf{base}, \mathsf{refl})) = \mathsf{decode}(\mathsf{base}, 0) = \mathsf{loop}^0 = \mathsf{refl}$ ✓.

Wait — path induction doesn't quite work here because the type of $\mathsf{encode}$ and $\mathsf{decode}$ depends on $x$, and we're induction on $p : \mathsf{base} = x$... Let me be more careful.

The statement is: $\prod_{x:S^1}\, \prod_{p:\mathsf{base}=x}\, \mathsf{decode}(x, \mathsf{encode}(x, p)) = p$.

This is a dependent statement over $S^1$. To prove it using J, we induct on $p$: the motive is $C(x, p) :\equiv (\mathsf{decode}(x, \mathsf{encode}(x, p)) = p)$. By J, it suffices to prove $C(\mathsf{base}, \mathsf{refl})$:

$\mathsf{decode}(\mathsf{base}, \mathsf{encode}(\mathsf{base}, \mathsf{refl})) = \mathsf{decode}(\mathsf{base}, 0) = \mathsf{loop}^0 = \mathsf{refl}$ ✓. $\square$

## The Main Theorem

**Theorem 2.1.** $(\mathsf{base} =_{S^1} \mathsf{base}) \simeq \mathbb{Z}$.

*Proof.* The maps $\mathsf{encode}(\mathsf{base})$ and $\mathsf{decode}(\mathsf{base})$ are inverses (by the round trip proofs). So they form an equivalence. $\square$

**Corollary 2.2.** $\pi_1(S^1, \mathsf{base}) = \mathbb{Z}$.

*Proof.* $\pi_1(S^1, \mathsf{base}) = \|\Omega(S^1, \mathsf{base})\|_0 = \|(\mathsf{base} = \mathsf{base})\|_0 \simeq \|\mathbb{Z}\|_0 = \mathbb{Z}$ (since $\mathbb{Z}$ is already a set, its 0-truncation is itself). $\square$

## What This Proof Shows

The proof of $\pi_1(S^1) = \mathbb{Z}$ demonstrates:

**1. Univalence is essential.** The code family is defined using $\mathsf{ua}(\mathsf{succ})$. Without Univalence, we couldn't define a type family that "counts" loop traversals.

**2. Computation rules are essential.** The key calculation $\mathsf{transport}^\mathsf{code}(\mathsf{loop}) = \mathsf{succ}$ uses the Univalence computation rule.

**3. The proof is constructive.** The encode function literally computes the winding number: given a loop $p$, $\mathsf{encode}(p)$ is the integer count of how many times $p$ wraps around the circle. This is a program, not just a proof.

**4. Higher paths matter.** We needed $\mathsf{decode} \circ \mathsf{encode} = \mathsf{id}$ for *all* paths, not just for loops. This required the full dependent structure.

## Generalizations

The same encode-decode technique applies to other spaces:

**$\pi_2(S^2) = \mathbb{Z}$.** Apply encode-decode to $\Omega(S^2, \mathsf{base})$, using a code family over $S^2$ that captures the 2-dimensional winding.

**$\pi_1(K(G, 1)) = G$.** The classifying space $K(G, 1)$ has code family $\mathsf{code} : K(G,1) \to \mathsf{Type}$ with $\mathsf{code}(\mathsf{pt}) = G$ and transport along each loop $g$ given by left-multiplication by $g$. The encode-decode argument then gives $\Omega(K(G,1)) \simeq G$.

**$\pi_n(K(G, n)) = G$.** Iterated application to higher loop spaces.

## The Winding Number as a Program

One remarkable consequence: $\mathsf{encode}$ is literally a *program* that computes the winding number of a loop in the circle.

In a proof assistant implementing HoTT (like Cubical Agda):
```agda
windingNumber : base ≡ base → ℤ
windingNumber p = encode base p
```

This function:
- Takes a loop `p : base ≡ base` in the circle $S^1$
- Returns the integer winding number $n \in \mathbb{Z}$

And you can literally *run* it: `windingNumber loop = 1`, `windingNumber (loop ∙ loop) = 2`, etc.

This is the power of HoTT over classical homotopy theory: not just a proof that $\pi_1(S^1) = \mathbb{Z}$, but a *computable* proof — a program that witnesses the bijection.
