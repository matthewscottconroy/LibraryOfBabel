# 1.1 The Interval and Path Types

## The Core Idea: Paths are Functions

In Martin-Löf type theory, the identity type $a =_A b$ is an *inductive* type generated by reflexivity: the only basic element is `refl : a = a`, and the elimination principle J tells you that to prove something about all paths, you only need to prove it for `refl`.

This is elegant and sufficient for classical type theory, but it creates the canonicity problem. The type $a =_A b$ is an "atomic thing" — you can't look inside it, can't compute with its endpoints, can't define operations on it that use its structure directly.

Cubical type theory changes this: **a path from $a$ to $b$ is literally a function from an interval to the type, with specified endpoints**. The path *is* the function. This makes paths computable objects with a rich internal structure.

## The Interval $\mathbb{I}$

The interval $\mathbb{I}$ is a new *primitive* in cubical type theory. It is not defined from other types — it is added to the theory directly.

Formally, $\mathbb{I}$ is a *sort* separate from types. It doesn't live in the universe. You can't form a dependent type over $\mathbb{I}$ in the usual sense (if you could, you'd be able to state things like "there exists a term of the interval," which is not the right intuition). Instead, you can *parametrize* constructions by elements of $\mathbb{I}$.

The interval has:
- Two constant elements: $0 : \mathbb{I}$ and $1 : \mathbb{I}$
- A De Morgan algebra structure: complement $\sim$, meet $\wedge$, join $\vee$

### The De Morgan algebra

```
~0 = 1      ~1 = 0      ~(~r) = r
r ∧ 0 = 0   r ∧ 1 = r   r ∧ r = r
r ∨ 0 = r   r ∨ 1 = 1   r ∨ r = r
~(r ∧ s) = ~r ∨ ~s       (De Morgan)
~(r ∨ s) = ~r ∧ ~s       (De Morgan)
r ∧ ~r = 0  r ∨ ~r = 1
```

These are the laws of a De Morgan algebra (a Boolean algebra without excluded middle applied to every element, but with De Morgan duality). The interval is not just a linear order; it has this algebraic structure built in.

Why De Morgan? Because we need:
- **Complement $\sim r$** to define path reversal: `sym p = λ i → p (~ i)`
- **Meet $r \wedge s$** for path connections and higher coherences
- **Join $r \vee s$** for the same

Without $\sim$, path reversal wouldn't be definitional (as in Cartesian cubical type theory — see Section 4).

## Dimension Variables

Cubical type theory extends the typing context $\Gamma$ to include *dimension variables*:

$$\Gamma ::= \cdot \mid \Gamma, x : A \mid \Gamma, i : \mathbb{I}$$

A dimension variable $i : \mathbb{I}$ is like an ordinary term variable but ranges over the interval. In a context with dimension variables, a type $A$ may depend on those variables — making $A$ a "family of types" parametrized by positions in the interval.

The dimension variables `i, j, k, ...` are the indices that parametrize cubes:
- With one dimension variable `i`, we get a 1-cube (a path)
- With two dimension variables `i, j`, we get a 2-cube (a square / homotopy)
- With `n` dimension variables, we get an $n$-cube

## Face Formulas

A *face formula* $\phi$ specifies which faces of a cube are relevant. It's built from dimension variables and the algebra:

$$\phi ::= 0 \mid 1 \mid i \mid (i = 0) \mid (i = 1) \mid \phi \wedge \psi \mid \phi \vee \psi$$

The formula $\phi$ defines a sub-interval: the set of points $(i_1, \ldots, i_n)$ where $\phi$ evaluates to $1$.

Examples:
- $\phi = (i = 0)$: the "left face" of dimension $i$ (the sub-cube where $i = 0$)
- $\phi = (i = 1)$: the "right face" of dimension $i$
- $\phi = (i = 0) \vee (j = 1)$: the union of the left $i$-face and the top $j$-face
- $\phi = (i = 0) \wedge (j = 1)$: the intersection (a corner)
- $\phi = 1$: the entire cube (everything)
- $\phi = 0$: empty (nothing)

The formula $\phi = 1$ means "we are on this face." The formula $\phi = 0$ means "this face is empty."

## Path Types

With the interval, we can define the path type $a =_A b$ as:

$$a =_A b \;\;\;:\equiv\;\;\; \{ p : \mathbb{I} \to A \mid p(0) = a \;\text{ and }\; p(1) = b \}$$

where the equalities $p(0) = a$ and $p(1) = b$ are *definitional* equalities.

More precisely: in the context with a dimension variable $i : \mathbb{I}$, a term $p : A$ (where $A$ is a type in the ambient context, not depending on $i$) is a path from $p[0/i]$ to $p[1/i]$.

### Paths as terms

To introduce a path $a =_A b$, you give a function:
$$\lambda i. t : a =_A b$$
where $t$ is a term in context $\Gamma, i : \mathbb{I}$ with $t[0/i] = a$ and $t[1/i] = b$ (definitionally).

To eliminate a path $p : a =_A b$, you evaluate it at a point of the interval: $p(r) : A$ for any $r : \mathbb{I}$, with $p(0) = a$ and $p(1) = b$ definitionally.

### Reflexivity

$$\mathsf{refl}_a \;:\equiv\; \lambda i. a : a =_A a$$

The constant function. At $0$: $\lambda i. a$ applied to $0$ gives $a$. At $1$: same. ✓

### Path inversion (symmetry)

$$\mathsf{sym}(p) \;:\equiv\; \lambda i. p(\sim i) : b =_A a$$

where $p : a =_A b$.

Check: $\mathsf{sym}(p)(0) = p(\sim 0) = p(1) = b$ ✓ and $\mathsf{sym}(p)(1) = p(\sim 1) = p(0) = a$ ✓.

This is not an axiom — it's a definition using the complement operation on $\mathbb{I}$.

### The path computation rules

Because paths are functions, we get computation rules:
- $(\lambda i. t)(0) = t[0/i]$
- $(\lambda i. t)(1) = t[1/i]$
- For $p : a =_A b$: $p(0) = a$ and $p(1) = b$ (definitionally)

These *definitional* rules are what make cubical type theory computational. When you evaluate a path at a specific endpoint, you get the actual value there — no stuck terms.

## Higher-Dimensional Paths

With two dimension variables $i, j : \mathbb{I}$, a term $H : \mathbb{I}^2 \to A$ is a *2-cube* or *square* in $A$.

A 2-cube has four faces:
- $H(0, j)$ — the left face (a path in $A$)
- $H(1, j)$ — the right face
- $H(i, 0)$ — the bottom face
- $H(i, 1)$ — the top face

A *homotopy* between paths $p, q : a =_A b$ is a 2-cube $H : \mathbb{I}^2 \to A$ with:
- $H(0, j) = a$ for all $j$ (left face constant)
- $H(1, j) = b$ for all $j$ (right face constant)
- $H(i, 0) = p(i)$ (bottom face is $p$)
- $H(i, 1) = q(i)$ (top face is $q$)

This is exactly the type $p =_{a =_A b} q$ — a path between paths.

In HoTT terms, 2-cubes are paths in path types, which are paths between paths, which are 2-cells in the $\infty$-groupoid structure. The cubical structure makes this explicit.

## The J Rule (Path Induction)

In Martin-Löf type theory, J is the *primitive* elimination principle for identity types. In cubical type theory, J is a *derived* rule.

**Theorem (J is derivable).** For any motive $P : (b : A) \to a =_A b \to \mathsf{Type}$ and base case $d : P(a, \mathsf{refl})$, there exists:

$$\mathsf{J}(P, d) : (b : A) \to (p : a =_A b) \to P(b, p)$$

*Proof sketch.* The key observation: for any $p : a =_A b$, the term $p$ itself is a function $\mathbb{I} \to A$ with $p(0) = a$. We can use *transport* (defined in the next section) to transport $d : P(a, \mathsf{refl})$ along the path of types $\lambda i. P(p(i), ?)$. The precise construction requires the composition operation to handle the fact that $?$ needs to be a path ending at $p$.

The critical point: **J is derivable from the path type definition + transport**. It is not a primitive. This is a significant architectural difference from MLTT.

The computation rule for J:

$$\mathsf{J}(P, d)(a, \mathsf{refl}) = d$$

This holds *definitionally* in cubical type theory — not just propositionally. In MLTT, J's computation rule is usually also definitional. But the derivation of J in cubical theory is more complex; it requires the Kan condition on path types.

## Dependent Path Types

For reasoning about paths in families, we need *dependent* path types (called `PathP` in Cubical Agda):

$$\mathsf{PathP}(B, p, a_0, a_1)$$

where $B : \mathbb{I} \to \mathsf{Type}$, $p : \mathbb{I} \to A$ (not used here), $a_0 : B(0)$, $a_1 : B(1)$.

An element of $\mathsf{PathP}(B, -, a_0, a_1)$ is a term $t : (i : \mathbb{I}) \to B(i)$ with $t(0) = a_0$ and $t(1) = a_1$.

This is the "path from $a_0$ to $a_1$ lying over the path of types $B$." The endpoints live in different types ($B(0)$ and $B(1)$), but the path interpolates between them as the type changes.

In Cubical Agda:

```agda
-- PathP B a0 a1 : Type
-- where B : I → Type, a0 : B i0, a1 : B i1
PathP (λ i → A) a0 a1 ≡ a0 ≡ a1   -- non-dependent case
```

Dependent paths are used everywhere when working with transport: if you transport $a_0 : A_0$ along a path of types $B : A_0 =_\mathsf{Type} A_1$, the result is a term of type $A_1$, and the "path" from $a_0$ to the result is a dependent path over $B$.

## Why This Design Works

The key insight of cubical type theory is that the computational properties we want from path types follow from their being *function types*:

1. **Endpoints are values**: $p(0)$ and $p(1)$ evaluate to actual terms (not stuck forms).
2. **Functoriality (ap) is just application**: $\mathsf{ap}_f(p) = \lambda i. f(p(i))$ — apply $f$ pointwise.
3. **Homotopies are 2D functions**: $H : \mathbb{I}^2 \to A$ — a path of paths is a function of two interval variables.
4. **Composition involves higher dimensions**: filling a square when you have three sides — this is the `hcomp` operation developed in Section 2.

All the structure of the $\infty$-groupoid — reflexivity, inversion, composition, coherences — falls out of the function-type nature of paths, plus the De Morgan algebra on $\mathbb{I}$.
