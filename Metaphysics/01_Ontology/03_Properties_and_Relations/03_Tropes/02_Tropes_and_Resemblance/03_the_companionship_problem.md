# The Companionship Problem

The companionship problem is a challenge specific to resemblance nominalism that trope theory helps address. The problem arises when two properties always accompany each other — when every instance of one property is also an instance of the other. Suppose (for argument's sake) that every red thing is also round, and every round thing is also red, as a matter of nomological necessity. Then the resemblance class of red things and the resemblance class of round things contain exactly the same objects. Resemblance nominalism, on a simple formulation, would identify the property red with the property round, since their instances are identical and all the members of each class resemble all the members of the other.

This is clearly wrong: red and round are distinct properties even if their instances happen to coincide. The problem is not that the view gives the wrong result only in this odd stipulated case — it is that resemblance nominalism as stated cannot distinguish properties that are merely co-extensive from properties that are genuinely different.

One response is to appeal to possible worlds: red and round are distinct because in some possible worlds they come apart — there are red non-round things or round non-red things. This helps, but it requires that resemblance nominalism have the resources to individuate properties across possible worlds, which requires some notion of tropes persisting or corresponding across worlds — which is itself metaphysically demanding.

Trope theory handles the companionship problem more naturally. Even if every actual object that has a red-trope also has a round-trope, the redness-trope and the roundness-trope are numerically distinct entities. The property red is the resemblance class of redness-tropes; the property round is the resemblance class of roundness-tropes. Since the tropes themselves are distinct — even if their bearers always co-occur — the properties are distinct. The companionship problem does not arise for trope-based resemblance nominalism in the same way it does for object-based versions.

This is part of the reason why most sophisticated contemporary resemblance nominalists work with tropes rather than with objects as the primary resemblance-relata.

## The Problem Stated Precisely

The companionship problem targets object-based resemblance nominalism. Given:
- Definition: Property P is the resemblance class of all P-instances — the set of objects that resemble paradigm P-instances sufficiently.
- Problem case: Every red thing is also round, and every round thing is also red (by law or necessity).

Under these conditions:
- The class of red things = the class of round things = {all actually red-and-round things}.
- Therefore, the resemblance class of red things = the resemblance class of round things.
- Therefore, the property red = the property round.

But this is false: red and round are clearly distinct properties. The failure reveals that resemblance nominalism (object-level) cannot individuate properties that are co-extensive in the actual world. It must appeal to possible worlds to distinguish them.

## The Trope-Theoretic Solution

Trope theory dissolves the companionship problem at the object level by moving the primary resemblance to the trope level:

- The property red = the resemblance class of redness-tropes.
- The property round = the resemblance class of roundness-tropes.
- Even if every object has both a redness-trope and a roundness-trope, these tropes are *numerically distinct* entities.
- Therefore, the redness-resemblance-class ≠ the roundness-resemblance-class, even though both are subsets of tropes belonging to the same objects.

The trope-theoretic solution works because tropes are already individuated by their specific qualitative character: a redness-trope is a *different kind of thing* from a roundness-trope, even when they cohabit the same object. The qualitative distinctness of the tropes guarantees the distinctness of the resemblance classes, independently of the distribution of trope-bearers.

## The Coextension Problem vs. the Companionship Problem

Related to the companionship problem is the *coextension problem*: even if two properties can come apart in possible worlds, they may have the same actual instances, making them definitionally equivalent for any actual-world analysis. The coextension problem is less severe than the companionship problem: it only requires appealing to possible worlds, while the companionship problem (in its strongest form) involves necessities that prevent the properties from coming apart even counterfactually.

Trope theory handles both:
- **Coextension problem**: Redness-tropes and renate-tropes (kidney-having tropes) are distinct entities even if their bearers always coincide in the actual world. The resemblance classes are distinct.
- **Companionship problem**: Even if it is nomologically or metaphysically necessary that all red things are round, the redness-tropes and roundness-tropes are distinct. Necessity of co-occurrence does not entail identity of the co-occurring tropes.

## The Imperfect Community Problem

Rodriguez-Pereyra distinguishes the companionship problem from the *imperfect community problem*, which concerns sets of objects that pairwise resemble but share no common property:

Example: {a red-round thing, a red-loud thing, a round-loud thing}. Each pair resembles in some respect: the first and second share redness; the first and third share roundness; the second and third share loudness. But there is no single property shared by all three.

Object-level resemblance nominalism might identify this set as a "property class" since its members all pairwise resemble. But it corresponds to no genuine property.

Trope theory handles this by requiring that resemblance classes consist of tropes of *the same type*. A redness-resemblance-class contains only redness-tropes; a roundness-resemblance-class contains only roundness-tropes. The imperfect community set of objects does not generate a single trope-type resemblance class — its members' resemblances involve different trope types.

The trope-theoretic move thus provides a principled distinction between genuine property classes (resemblance classes of tropes of a single type) and gerrymandered collections (sets of objects that happen to pairwise resemble through a variety of different trope-types).
