# In Re Structuralism

In re structuralism is a version of mathematical structuralism that locates structures within their instantiations rather than positing structures as independently existing abstract entities. The natural number structure exists, on this view, but only insofar as there are concrete or physical systems that instantiate it.

The "in re" label comes from the medieval distinction between universals ante rem (before the thing, independently existing), in re (in the thing, existing only as instantiated), and post rem (after the thing, existing only as mental constructs). In re structuralism about mathematical structures holds that structures are something like structural universals: they are real, but they exist only in and through their instantiations.

The attraction of in re structuralism is its ontological conservatism. We do not need to posit a special realm of abstracta to explain mathematical truth; we need only the concrete systems that actually satisfy mathematical axioms. The truths of arithmetic hold because there are concrete omega-sequences that satisfy the Peano axioms.

The main difficulty is that in re structuralism faces the possibility of structures with no concrete instantiations. Many mathematical structures have no physical instantiation. If the real number structure has no physical instances, then in re structuralism cannot account for the truths of real analysis.

One response is to extend "instantiation" to include possible or ideal systems: the real number structure is instantiated by possible omega-sequences of the right density, even if no such sequence is physically actual. But this move brings in modal notions that are no less metaphysically demanding than the abstract structures the in re structuralist hoped to avoid.

In re structuralism is therefore best understood as a research program with a clear motivation but significant technical challenges, rather than a completed account of mathematical ontology.

## The Formal Position

In re structuralism holds the following theses:

**T1 (Structures are real)**: There are genuine mathematical structures — the natural number structure, the real number structure, group structures, etc. These are objective features of reality, not merely convenient descriptions.

**T2 (Structures are instantiated)**: A structure exists if and only if some system of objects instantiates it. The natural number structure exists because there are concrete (or mathematical) systems that satisfy the Peano axioms.

**T3 (Mathematical truth is structural truth)**: A mathematical sentence φ is true iff φ holds in every system that instantiates the relevant structure. "2 + 2 = 4" is true because in every omega-sequence, the element in the fourth position is what you get by adding the element in the second position to itself.

**T4 (No ante rem structures)**: Structures do not exist prior to or independently of their instantiations. If no system instantiated the natural number structure, there would be no natural number structure.

## The Instantiation Problem

The central challenge for in re structuralism is the instantiation problem: many mathematical structures — arguably most structures studied in advanced mathematics — have no concrete physical instantiation.

**Uncountable structures**: The real number structure ℝ is uncountably infinite. No physical system contains uncountably many distinct elements. (Physical reality, if it is discrete at the quantum scale, contains only finitely many distinguishable states; even if it is continuous, the real number structure requires the full power of second-order logic to characterize.)

**Large cardinals**: Set theory studies large cardinal structures — inaccessible cardinals, measurable cardinals, supercompact cardinals — with cardinalities vastly exceeding anything physically instantiated. If in re structuralism requires physical instantiation, most of higher set theory is false.

**Ideal structures**: Euclidean geometry describes perfectly flat space, perfectly straight lines, and perfectly circular circles — idealizations with no physical instances. If Euclidean geometry is true, in re structuralism requires that these ideal structures be instantiated somehow.

**Three responses**:

**(a) Restrict the domain**: In re structuralism is correct for the mathematical structures that are physically instantiated (finite combinatorics, some parts of number theory and analysis). Higher mathematics that exceeds physical instantiation is either false or a useful fiction. This is a revisionary position that conflicts with mathematical practice.

**(b) Extend to possible instantiation**: A structure exists if it is *possible* that some system instantiate it. This preserves more of mathematics but introduces modal notions. The modal qualification may be as ontologically demanding as positing abstract structures.

**(c) Extend to mathematical instantiation**: A structure exists if it is instantiated within some mathematical domain, including abstract set theory. But set theory itself contains abstract objects, so this response seems to reintroduce the abstract objects that in re structuralism was meant to avoid.

## In Re Structuralism and Aristotelian Universals

The in re structuralist position on mathematical structures parallels Armstrong's immanent realism about universals. Armstrong holds that properties exist only in their instances — the universal redness exists only where red things are, not in a Platonic realm. Similarly, the in re structuralist holds that mathematical structures exist only in their instances.

Armstrong's view faces the parallel challenge: what about uninstantiated properties? Can there be a property — say, being 10⁸⁰ meters in diameter — that nothing instantiates? Armstrong's restrictive answer: no, uninstantiated properties do not exist. The cost is that possible but uninstantiated properties raise difficulties for modality.

For mathematical structures, the parallel restriction (no uninstantiated structures) seems even more costly. The history of mathematics is full of structures studied long before any physical instantiation was found — non-Euclidean geometry was developed in the nineteenth century before it was found to describe physical spacetime in general relativity. On in re structuralism, non-Euclidean geometry was about nothing until general relativity was confirmed. This seems to mischaracterize mathematical practice.

## The Connection to Aristotelian Platonism

Some philosophers (Balaguer, Linsky and Zalta) have proposed intermediate positions that combine elements of in re and ante rem structuralism. *Aristotelian Platonism* holds that:

- Mathematical structures are abstract objects (not physically located, not causally efficacious).
- Abstract objects exist only if they are instantiated — not in the physical world, but in some mathematical domain.
- The mathematical domain itself includes all logically possible structures, making every consistent structure in some sense instantiated.

This is closer to ante rem structuralism than to in re structuralism, but it shares the in re commitment that existence requires instantiation. The difference is that "instantiation" is broadened to include instantiation in an abstract domain.

Whether this combination is coherent — whether it genuinely occupies a middle ground or collapses into ante rem structuralism — is a matter of ongoing philosophical discussion.
