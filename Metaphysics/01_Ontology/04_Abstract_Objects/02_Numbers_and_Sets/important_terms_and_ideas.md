# Important Terms and Ideas: Numbers and Sets

**Peano axioms**: The standard axioms characterizing the natural number system: there is a first number (0), every number has a unique successor, no two numbers have the same successor, 0 is not a successor, and induction holds. Any omega-sequence satisfies these axioms.

**Logicism**: The program of reducing arithmetic (and perhaps all of mathematics) to pure logic. Frege's version defined numbers as extensions of concepts; Russell and Whitehead's version used type theory.

**Iterative conception of sets**: The view that sets form a cumulative hierarchy generated stage by stage: beginning with the empty set (or urelements), then forming all sets of those, then all sets of those, and so on through all ordinals.

**Extensionality**: The axiom that two sets are identical iff they have the same members. This is the defining principle of set identity: what a set is is exhausted by its membership.

**Cantor's theorem**: The result that for any set S, the power set of S (the set of all subsets of S) has strictly greater cardinality than S. This shows that there is no largest cardinal and that the set-theoretic universe is inexhaustible.

**Structuralism about numbers**: The view that numbers are not objects with intrinsic properties but positions in abstract structures. The number 3 is defined by its structural relations (being the successor of 2, being preceded by 0, 1, 2, etc.) not by any non-structural properties.

**Benacerraf's identification problem**: The observation that there are multiple, equally adequate set-theoretic identifications of the natural numbers, and no non-arbitrary basis for preferring one — therefore numbers are not sets.
