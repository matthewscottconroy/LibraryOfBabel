# Abundant Properties

The abundant conception of properties holds that for every predicate (or, more liberally, for every condition we can express or describe), there is a corresponding property. The property of being a dog, the property of being either green or not prime, the property of being thought of by someone on a Tuesday — all of these count as properties on the abundant view. Properties, on this conception, are extremely liberal: every predicate, however gerrymandered, picks out some property.

This conception contrasts with the sparse or natural properties conception, which restricts genuine properties to those that correspond to real distinctions in nature — those that cut nature at its joints. On the sparse view, not every predicate corresponds to a genuine property; only predicates that express natural similarities or that figure in laws of nature pick out real properties.

The abundant view is useful for semantic theory. To give truth-conditions for arbitrary predicates, we need some entity for every meaningful predicate to express. If "is grue" is a meaningful predicate, there should be a property — even an unnatural, gerrymandered one — that it expresses. The abundant conception delivers this.

But the abundant conception threatens to trivialize the metaphysics of properties. If every condition specifies a property, and conditions are cheap (we can describe any set of objects using a predicate), then properties are as plentiful as sets of possible objects. They no longer do the metaphysical work of explaining natural laws, objective similarity, or causation — because for those purposes, we need properties that are special, not arbitrary.

Lewis's response was to maintain both conceptions: abundant properties for semantic purposes (they are just sets of possible objects, a relatively deflationary posit) and sparse properties for metaphysical purposes (they are the fundamental features that ground naturalness). The two conceptions serve different theoretical roles and need not conflict.

## The Lewis Distinction in Detail

David Lewis's mature position distinguishes two property-concepts that serve different theoretical purposes:

**Abundant properties** (for semantics):
- There is a property for every meaningful predicate.
- Abundant properties are identified with sets of possible objects: the property of being red is the set of all (actual and possible) red objects.
- Abundant properties are as plentiful as sets — there are at least as many as there are subsets of the set of possible objects.
- They are not "real" in any deep metaphysical sense; they are just a mathematical device for giving semantic values to predicates.

**Sparse (natural) properties** (for metaphysics):
- Natural properties correspond to genuine similarities in nature.
- They are the properties that figure in laws of nature, in causal explanations, and in objective resemblance relations.
- They are discovered by science, not stipulated by language.
- Lewis takes naturalness as primitive: some properties (charge, mass, spin) are perfectly natural; others are more or less natural depending on how they are built from natural ones.

The distinction is not between two different categories of entities but between two different theoretical roles for properties. Abundant properties and sparse properties might be identified with the same entities (sets of possible objects) — but only some of those sets are natural, and the natural ones do the real metaphysical work.

## Goodman's Grue and the Projection Problem

Nelson Goodman's grue example in *Fact, Fiction, and Forecast* (1955) shows why not all properties are equal for induction:

Define: x is **grue** iff x is examined before 2100 and found to be green, or x is not examined before 2100 and is blue.

All emeralds examined before 2100 are grue (since they are green and examined). By induction on the grue predicate, we should expect unexamined emeralds to be blue (the grue of unexamined objects). But we should expect them to be green (the green of all examined ones). Both "green" and "grue" are satisfied by all examined emeralds, but only "green" supports projectable inductive generalizations.

**Why green but not grue?** One natural answer: "green" expresses a genuine natural property; "grue" does not. Green is a property that carves nature at its joints — it corresponds to an objective feature of surfaces that reflects a certain range of wavelengths. "Grue" is a gerrymandered, time-indexed predicate that does not correspond to any natural property.

This answer requires distinguishing natural from non-natural properties. Without this distinction, we cannot explain why "All emeralds are green" supports inductive inference while "All emeralds are grue" does not. The natural/abundant distinction is not merely semantic — it is required for the epistemology of induction.

## Abundant Properties and Truthmakers

Abundant properties create complications for truthmaker theory. If every predicate corresponds to a property, then for every sentence "a is F," there is a property being-F that a has. The truthmaker for "a is F" is then the state of affairs of a having being-F.

But if being-F is an abundant property — a gerrymandered, arbitrary set of possible objects — then the state of affairs of a having being-F is thin: it says nothing about any genuine feature of a. The abundant conception makes truthmaking too easy. Everything is true in virtue of some (abundant) state of affairs, but this trivializes truthmaking.

Armstrong's response: truthmakers must involve *natural* (sparse) properties. The state of affairs of a having property P is a genuine truthmaker only if P is a natural property. For statements involving gerrymandered predicates ("a is grue"), the truthmaker is some natural property fact (a is green) that grounds the gerrymandered predicate's application.

This response uses the abundant/sparse distinction to constrain truthmaker theory: the relevant states of affairs for truthmaking purposes are those involving sparse, natural universals, not arbitrary abundant properties.

## The Proliferation Problem

One objection to abundant properties is the proliferation problem: if there are abundant properties for every predicate, then the ontology is unacceptably large. There are uncountably many predicates (using mathematical language, for instance), and so uncountably many abundant properties. More significantly, there are properties corresponding to complex, self-referential, and paradox-generating descriptions.

The standard response is to restrict abundant properties to *predicative* open sentences that do not generate paradoxes (using Russell's type theory or a similar restriction). The property of being a property that does not instantiate itself generates Russell's paradox if admitted; type theory blocks it by distinguishing orders of properties.

Lewis's response is deflationary: abundant properties are just sets, and set theory already tells us which sets there are (subject to the axioms of ZFC). The "proliferation" is the proliferation of sets, which is well-understood and mathematically tractable. The ontological cost of abundant properties is the same as the ontological cost of sets — not obviously excessive given that sets are already needed in mathematics.
