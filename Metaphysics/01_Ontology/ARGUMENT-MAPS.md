# Argument Maps: Ontology

## Map 1: The Ontological Landscape — Existence and Categories

```
                         ONTOLOGICAL REALISM
                         (mind-independent reality)
                                  │
              ┌───────────────────┼───────────────────┐
              │                   │                   │
         PLATONISM          IMMANENT REALISM     TROPE REALISM
    (universals exist       (universals exist    (property-instances
     separately from         only in instances;   are particular;
     instances)              Armstrong)           D.C. Williams)
              │                   │                   │
              └──────────────┬────┘                   │
                             │                         │
                   vs.       │        vs.              │
                             │                         │
                        NOMINALISM ←──────────────────┘
                    (only particulars exist)
                             │
           ┌─────────────────┼─────────────────┐
           │                 │                 │
   PREDICATE NOM.    RESEMBLANCE NOM.    CLASS NOM.
   (no shared entity  (primitive          (property =
    beyond predicate)  resemblance)        class of instances)
```

**Key entailments:**
- Platonism → abstract objects are countenanced → Benacerraf's epistemological challenge applies
- Immanent realism → universals require instantiation → uninstantiated universals are impossible
- Trope realism → resemblance classes replace universals → resemblance primitive or regress threatens
- Class nominalism → abstract objects (classes) still required → not fully nominalist

**Key incompatibilities:**
- Platonism ⊥ nominalism (universals either exist or they do not)
- Immanent realism ⊥ Platonism over whether uninstantiated universals are possible
- Trope theory compatible with both realism (tropes are real entities) and nominalism (tropes are particular, not universal)

## Map 3: The Grounding Hierarchy

```
FUNDAMENTAL (ungrounded)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Physical particles / fields / spacetime structure
                    │
                    │ grounds (via physical laws)
                    ▼
  Chemical properties, molecular configurations
                    │
                    │ grounds (via composition)
                    ▼
  Biological organisms, functional properties
                    │
                    │ grounds (via realization)
                    ▼
  Mental states, phenomenal properties, persons
                    │
                    │ grounds (via participation in practices)
                    ▼
  Social facts, institutional entities
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DERIVATIVE (grounded)
```

**Controversies at each level:**
- Is the physical fundamental or also grounded in some deeper structural reality?
- Can the mental be fully grounded in the physical? (Hard problem of consciousness)
- Are social facts fully grounded in physical and mental facts, or do they have irreducible normative components?
- Is the grounding relation itself part of the fundamental ontology, or is it definable?

**Key positions:**
- **Schaffer (priority monism)**: The cosmos is the single fundamental entity; all else grounds in it.
- **Sider (atomism)**: Smallest physical entities are fundamental; everything else is grounded up.
- **Fine (pluralism)**: Multiple categories may be mutually irreducible; ground floors may be plural.

## Map 4: Substance Theory — The Main Positions

```
SUBSTANCE REALISM
(Objects persist, bear properties, are ontologically basic)
          │
          ├────────────────┬────────────────┐
          │                │                │
    SUBSTRATUM         BUNDLE THEORY     LOWE'S
    THEORY             (no substratum;   FOUR-CATEGORY
    (bare particular   substances =      ONTOLOGY
     + properties)     bundles of        (substances,
                        universals/       kinds, attributes,
                        tropes)           modes — all
                                          irreducible)
          │                │
          │                │
     OBJECTION:        OBJECTION:
     Black's spheres   Bare particular
     refutes bundle    is unintelligible
     theory            "I know not what"
```

**Key argument against bundle theory:**
- P1: Two qualitatively identical bundles would be numerically identical (Leibniz's Law)
- P2: Two qualitatively identical spheres can be numerically distinct (Black's spheres)
- C: Bundle theory fails to individuate

**Key argument against substratum theory:**
- P1: Bare particulars bear no properties of their own
- P2: Something that bears no properties is unidentifiable and unknowable
- C: Bare particulars are either unintelligible or a confusion

**Trope-bundle hybrid response**: Tropes serve as the bundle-elements and individuate one another by their own particularity (no need for a substratum; no need for universals in the bundle).
