# Rodriguez-Pereyra

---

Gonzalo Rodriguez-Pereyra's *Resemblance Nominalism: A Solution to the Problem of Universals* (2002) is the most careful and technically sophisticated contemporary defense of resemblance nominalism. The book's ambition is to show that the traditional objections to resemblance nominalism — the companionship problem, the imperfect community problem, the coextension problem — can all be answered within a consistently nominalist framework.

Rodriguez-Pereyra begins by distinguishing the *ontological* problem of universals from the merely linguistic one: the problem is not about why the same word applies to many things, but about what makes it true that multiple things share a property. He then argues that resemblance nominalism provides a better answer to this ontological problem than universals realism does.

His central innovation is to appeal to *possible* as well as actual cases. The companionship problem arises when two properties are necessarily coextensive in the actual world — they apply to all and only the same things. Rodriguez-Pereyra responds that even if being red and being round happen to apply to the same things actually, the properties are distinct because they apply to different things in other possible worlds. The resemblance classes that constitute each property include merely possible red things and merely possible round things, and these differ.

## The Companionship Problem

The companionship problem can be stated sharply. Suppose properties F and G always accompany each other in the actual world: every F-thing is G and every G-thing is F. Then the resemblance class of F-things and the resemblance class of G-things are identical. But F and G are intuitively distinct properties — being equiangular and being equilateral, for instance, are necessarily coextensive in triangles but are different properties.

Rodriguez-Pereyra's solution: extend the resemblance classes to include possible objects. Even if all actual equiangular triangles are equilateral, there are *possible* equiangular non-equilateral triangles (equiangular but scalene). These possible objects resemble all actual equiangular triangles (in being equiangular) but do not resemble all actual equilateral triangles (they are not equilateral). The resemblance class for EQUIANGULAR and the resemblance class for EQUILATERAL therefore differ, even if their actual-world members coincide.

Formally, if F-class = {x : x resembles all actual F-things as much as actual F-things resemble each other}, and G-class is defined analogously, then if possible equiangular non-equilateral triangles exist, x resembles actual equiangular triangles but not actual equilateral ones, giving F-class ≠ G-class. This solution works within Lewis's modal realism, where possible objects are just as real as actual ones. If possible objects are not real, the solution must be recast as a claim about what would be true, which requires modal primitives.

## The Imperfect Community Problem

Goodman named the *imperfect community problem*. Consider a set S = {a, b, c} where a is red and round, b is round and heavy, and c is heavy and red. Every pair in S resembles each other (a and b share roundness, b and c share heaviness, a and c share redness), so S meets the mutual resemblance condition for being a natural kind — but there is no single property shared by all three.

Rodriguez-Pereyra's solution involves the notion of a *maximal* resemblance class. S is not maximal in the relevant sense: there are other things that are red-and-round that resemble a to the degree required for the RED class, but those things are not heavy; and there are other things that are heavy that resemble c to the required degree, but those things are not red-and-round. The maximal resemblance classes for RED, ROUND, and HEAVY are distinct, and no maximal resemblance class corresponds to {a, b, c}.

This solution requires careful formulation of what "maximal resemblance class" means and what "resemble as much as" means across different respects. Critics have argued that the formulation is either circular or requires properties to define the respects in which resemblance is measured.

## Theoretical Economy

Rodriguez-Pereyra argues that resemblance nominalism is theoretically superior to universals realism on grounds of parsimony. Resemblance nominalism's primitives are concrete particulars (actual and possible, in the Lewisian framework) plus the resemblance relation. Universals realism (Armstrong) requires concrete particulars, universals (an additional ontological category), and the instantiation relation.

The realist's response: the economy comparison is misleading. The resemblance nominalist must appeal to possible objects, making the ontology potentially far larger than any plausible universals ontology. A sparse universals realism posits a small number of fundamental universals (the properties of fundamental physics); a resemblance nominalist who appeals to Lewis's modal realism posits as many possible concrete particulars as there are possible objects — an uncountably large ontology. Rodriguez-Pereyra accepts this cost but argues that Lewisian modal realism is independently motivated and that resemblance nominalism can exploit its resources without further expense.
