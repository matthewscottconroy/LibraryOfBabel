# Argument Maps: Universals and Particulars

## Map 1: The Realism/Nominalism Spectrum

```
REALISM ──────────────────────────────────────── NOMINALISM
(shared entities exist)                    (only particulars exist)
    │                                               │
    ├─ PLATONISM                    ├─ PREDICATE NOMINALISM
    │  (universals ante rem,        │  (no entity beyond the predicate)
    │   separate from instances)    │
    │                               ├─ RESEMBLANCE NOMINALISM
    ├─ ARISTOTELIANISM              │  (objective resemblance classes,
    │  (universals in re,           │   no shared entity)
    │   immanent in instances)      │
    │                               ├─ CLASS NOMINALISM
    │                               │  (property = class of instances)
    │                               │
    │                               └─ OSTRICH NOMINALISM
    │                                  (no analysis needed;
    │                                   reject the problem)
    │
    ├─ TROPE THEORY (intermediate)
       (property-instances are particular;
        resemblance classes replace universals;
        bundle theory with tropes)
```

**Logical relations between positions:**
- Platonism → uninstantiated universals are possible → triangularity exists even if no triangles exist
- Aristotelianism → universals require instantiation → no uninstantiated universals
- Trope theory → no universals; resemblance is primitive among tropes → avoids Bradley's regress if resemblance is internal
- Resemblance nominalism → resemblance is primitive; no universal resemblance itself → iterates unless resemblance is internal
- Class nominalism → classes are abstract objects → not purely nominalist (classes require abstract entities)

## Map 3: Bradley's Regress and Its Responses

```
BRADLEY'S REGRESS
           │
The particular a instantiates universal F
           │
But what relates a to F? A further relation R1
           │
But what relates a and F to R1? A further relation R2
           │
→ Infinite regress of relations
           │
    RESPONSES:
           │
    ┌──────┴──────────────────────┐
    │                             │
ARMSTRONG:                  FINE:
Instantiation is an         Predicational nexus
"internal tie" — it         is primitive and
holds necessarily           sui generis — not
in virtue of its relata;    a relation at all
no further grounding
needed
    │
LEWIS:
The regress is harmless —
it is an infinite series of
truths, not of distinct entities;
no ontological explosion occurs
```
