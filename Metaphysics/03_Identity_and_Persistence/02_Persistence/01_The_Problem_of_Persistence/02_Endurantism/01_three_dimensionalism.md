# Three-Dimensionalism

*The endurantist view that objects are three-dimensional and wholly present at each moment.*

---

When I return to my apartment and find my table still there, I experience it as the *same* table — not as a numerically distinct but similar table-stage connected to yesterday's table by a temporal counterpart relation. The numerical identity of the table across times seems to be a datum of everyday experience, not a theoretical construction. Three-dimensionalism takes this experience at face value: a persisting object is wholly present at each moment of its existence, and what persists is the very same three-dimensional thing, not a series of stages.

Three-dimensionalism holds that ordinary persisting objects have three spatial dimensions but no temporal dimension in the relevant sense. Objects are not spread through time the way they are spread through space. A table occupies a volume of space; it does not occupy an interval of time by having table-stages at each moment. Instead, the table itself — the complete three-dimensional table — exists at many different moments. "Wholly present" at a time means: every part of the object exists at that time. Formally:

> **(3D)** For any persisting object x, if x exists at times t₁ and t₂, then WP(x, t₁) and WP(x, t₂).

where WP(x, t) abbreviates "x is wholly present at t." This contrasts directly with the perdurantist view, on which only a *part* of the object (a temporal stage) is present at each time.

## Handling Change: Time-Indexed Properties

Three-dimensionalism handles change by time-indexing properties. When the apple changes from green to red, the apple (one complete object) has the property *green-at-t₁* and the property *red-at-t₂*. These are consistent with each other and with Leibniz's Law: the properties are different relations to different times.

Lewis's objection is that this makes all "intrinsic" properties relational, destroying the distinction between intrinsic and extrinsic properties. The standard three-dimensionalist response is that time-indexed properties can still be intrinsic in the relevant sense. The claim is not that being-green-at-t₁ is a relation between the apple and t₁ in the way "being taller than Napoleon" is a relation to Napoleon. It is that being-green is a property instantiated *at* t₁ — the time is a parameter for *when* the property is instantiated, not a relatum of a relation.

Haslanger (1989) articulates this by distinguishing: *relational properties* (whose instantiation essentially involves a relation to a distinct entity) from *temporally located properties* (instantiated at a time, where the time specifies when without making the property itself relational). Whether this distinction can be made out in a fully satisfying way is contested. But it provides a conceptual framework within which the collapse of intrinsic into relational properties can be resisted.

## The Coincidence Problem

Three-dimensionalism faces a distinct challenge from cases of coincident entities. The statue and the clay are both wholly present at the same place at the same time but seem to differ in their persistence conditions. If both are wholly present at the same place, and they are numerically distinct, then two distinct objects occupy the same spatial region simultaneously.

This is the *colocation problem* for endurantism. Perdurantism handles it by distinguishing temporal worms with different temporal extents. Endurantism must either accept coincident objects (Baker's constitution view), deny that the statue and clay are genuinely distinct (Wiggins's sortal view), or give some other account of why the apparent two reduce to one. Each response has costs. Accepting coincident objects threatens the principle that two distinct material objects cannot occupy the same place at the same time — a principle with strong pre-theoretical support.

## The "Wholly Present" Relation

A further challenge: what does it mean for an object to be "wholly present" at a time? The straightforward reading is that all of the object's parts exist at that time. But on the perdurantist view, the object's temporal stages are also its parts — so the perdurantist can say: the object is wholly present at t only if all its temporal parts exist at t, which is false for any persisting object (future stages do not yet exist). The dispute then is about whether temporal stages are genuine parts.

If we define "wholly present" as "having no temporal parts left out," then the claim that three-dimensional objects are wholly present at each time becomes the claim that they have *no temporal parts* — which is a commitment, not a neutral observation. The endurantist must argue for the absence of temporal parts, not merely assert it.

Despite these challenges, endurantism remains the commonsense view and has strong defenders. Its core advantage — matching ordinary experience and language — is not to be underestimated. The pre-theoretical datum that the same complete thing is present across time is what any adequate account of persistence must either vindicate or explain away.
