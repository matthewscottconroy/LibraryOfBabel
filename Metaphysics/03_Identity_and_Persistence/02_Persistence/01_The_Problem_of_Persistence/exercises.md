# Exercises — The Problem of Persistence

*Problems for engaging with the metaphysics of persistence.*

---

**Exercise 1 — Temporary Intrinsics**
Lewis argues that endurantism cannot accommodate intrinsic temporary properties without making them relational. Evaluate the time-indexing response: being-spherical-at-t is a distinct property from being-spherical. Does this response save the intrinsicality of the property, or does it make it relational? What would have to be true for time-indexed properties to be genuinely intrinsic?

**Exercise 2 — The Grain of Four-Dimensionalism**
Four-dimensionalism posits a temporal part for every instant (or interval) of an object's existence. How many temporal parts does this table have? Is the proliferation of temporal parts metaphysically extravagant? Construct both a cost-benefit argument for and against four-dimensionalism based on its ontological commitments.

**Exercise 3 — Stage Theory**
On stage theory, "I will do X tomorrow" means something like "my temporal counterpart will do X tomorrow." Does this change the meaning of first-person future-tense claims? Is there a practical difference between thinking "I will survive tomorrow" (numerical identity claim) and "my temporal counterpart will exist tomorrow" (stage-theoretic claim)?

**Exercise 4 — Presentism and Persistence**
Presentism holds that only the present exists. If so, what makes "this table existed yesterday" true? Construct a presentist truthmaker theory for past-tensed claims. Is there any version of presentism that can handle temporal parts?

**Thought Experiment — The Gradual Replacement**
Your cells are gradually replaced, one by one, over seven years. At the end, none of the original cells remain. From the endurantist's perspective: same person? From the perdurantist's: same temporal worm? From the animalist's: same organism? Do the three views give the same answer? If they differ, what determines which answer is correct?
