# The Problem of Many

*Peter Unger's puzzle about how many objects occupy a region and the threat of coincident entities.*

---

The statue-clay puzzle looks like an exotic case manufactured by philosophers for the purpose of stress-testing their theories. Peter Unger's Problem of Many (1980) shows that something structurally similar infects the most ordinary cases. Consider a cloud. A cloud is a collection of water droplets. But any proper subset of those droplets that includes all the "core" droplets also constitutes something that looks and behaves exactly like the cloud. Remove one peripheral droplet: still a cloud. Remove two: still a cloud. It seems there are indefinitely many overlapping cloud-like collections, each with an equal claim to be the cloud, all occupying the same region.

The argument:

- Let C be the cloud.
- Let C' be the same cloud minus one peripheral droplet.
- C' is also cloud-like, overlaps maximally with C, is in the same meteorological region, and has essentially the same causal effects.
- If C is a cloud and C' is a cloud, and they are in the same place at the same time, they are coincident clouds.
- But there should be only one cloud there.

This argument multiplies without bound. For each peripheral droplet we can add or remove, we get a slightly different candidate-cloud. If all candidates are genuine clouds, then where we see "one cloud," there are actually billions of coincident clouds. The same problem arises for tables (any table-minus-one-peripheral-molecule is also a table-like object), persons (any person-minus-one-peripheral-cell is a person-like organism), mountains, and virtually any ordinary object with imprecise spatial boundaries. The problem of many is not a peripheral puzzle but a challenge to any ontology that takes ordinary objects seriously.

## Proposed Solutions

*The vagueness response*: there is one cloud, but it is indeterminate which collection of droplets it is. The multiplicity is an artifact of vagueness, not a real plurality of objects. The cloud is *determinately* one object; the question of *which* droplets constitute it is vague. The challenge: if it is genuinely vague which collection of droplets constitutes the cloud, then the existence of the cloud seems to be indeterminate across the different candidate-collections. Evans's argument (discussed elsewhere) suggests that vagueness cannot be ontically located at the level of identity — and a similar argument threatens to show that vagueness cannot be located at the level of existence.

*Ontological parsimony* (van Inwagen's response): there are no objects corresponding to every collection of droplets; ordinary objects are ontologically special. Van Inwagen holds that only organisms and fundamental particles exist. "Clouds" are not genuine objects — they are regions where water droplets are concentrated. When we say "there is a cloud," we mean: there are droplets arranged cloud-wise. The problem of many does not arise because "clouds" are not genuine objects; only the droplets are. The cost: revisionism about ordinary existence claims — tables, chairs, mountains, and clouds do not strictly exist.

*Constitution-plural acceptance*: there genuinely are many coincident cloud-like objects, but only one of them is "the cloud" — the one we conventionally pick out. Ordinary language singles out the most prominent or largest as "the cloud." Coincidence is accepted but confined to the semantics of ordinary singular reference.

*Epistemicism about vagueness*: there is a precise boundary for the cloud; we simply do not know exactly where it is. If epistemicism is true, there is exactly one cloud with a precise boundary, and the problem of many does not arise because only one of the candidate-collections is the cloud. The cost: it seems arbitrary that there should be a precise boundary we cannot know, and the epistemicist owes an account of what fixes the precise boundary in the absence of any semantic or physical marker.

*The supervaluationist response*: each admissible precisification of "cloud" picks out one precise cloud. Under each precisification, there is exactly one cloud. It is *supertrue* that there is exactly one cloud (because it comes out true under every admissible precisification), even though there is no unique candidate-collection that is *determinately* the cloud.

The problem of many connects to debates about composition and mereological essentialism. If objects are mereological sums of their parts, then a cloud is identical to the sum of its constituent droplets. Any variation in the constituents — including the addition or subtraction of a peripheral droplet — produces a numerically distinct sum, and thus a numerically distinct cloud. Mereological essentialism (Chisholm) accepts this multiplicity and lives with it. Most philosophers find this unacceptable (it implies that an organism is destroyed by losing a single cell) and seek a middle path — and the search for that middle path is one of the driving forces in contemporary mereology and ontology.
