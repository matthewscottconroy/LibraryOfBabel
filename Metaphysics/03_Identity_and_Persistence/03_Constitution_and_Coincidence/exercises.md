# Exercises — Constitution and Coincidence

*Problems for engaging with material constitution and coincident objects.*

---

**Exercise 1 — Leibniz's Law and the Statue**
State the argument that GOLIATH (the statue) and LUMP (the clay) are numerically distinct using Leibniz's Law. Identify all the premises. Now construct a response that accepts the premises but rejects the argument for distinctness — perhaps by arguing that modal properties are not genuine properties of objects but artifacts of description.

**Exercise 2 — Four-Dimensionalism and Constitution**
How does four-dimensionalism dissolve the coincident objects puzzle? Draw a diagram representing the temporal worms of GOLIATH and LUMP. Does this resolution fully capture the intuition that GOLIATH and LUMP differ modally, or does it merely relocate the issue?

**Exercise 3 — Evans's Argument**
State Evans's argument against vague identity. Evaluate the metalinguistic response: the relevant property ("being determinately identical with a") is a semantic property, so Leibniz's Law does not apply. Is this response convincing? If Evans's argument fails, what follows about the possibility of vague objects?

**Exercise 4 — The Problem of Many**
How many tables are there in a room with a table that has 10^23 molecules? If every proper subset of those molecules that includes all the "core" ones constitutes a table-like object, are there uncountably many tables in the room? Evaluate two responses: (a) ordinary objects are vague, so there is only one (indeterminate) table; (b) there are many table-like objects but only one that counts as "the table" by our conventions.

**Thought Experiment — The Ship of Theseus Redux**
A ship has all its planks replaced over ten years. Simultaneously, the original planks are stored and later reassembled into a second ship. Which (if either) is the original ship? Apply: (a) endurantism; (b) perdurantism; (c) the constitution view. Do the views give different answers? Which gives the most intuitively satisfying one?
