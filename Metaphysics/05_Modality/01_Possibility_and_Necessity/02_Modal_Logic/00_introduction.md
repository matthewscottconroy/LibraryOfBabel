# Modal Logic

Modal logic is the formal study of the logical relations among modal claims. Adding the operators □ (necessarily) and ◇ (possibly) to classical propositional or predicate logic, and specifying axioms that govern them, generates a family of modal logical systems with different strength and different philosophical implications. Modal logic is not merely a technical tool; it embeds philosophical commitments about the nature of possibility and necessity, and the choice among logical systems reflects — or should reflect — metaphysical positions about what modality is.

The basic axiom of all normal modal logics is the K axiom: if it is necessary that if P then Q, and it is necessary that P, then it is necessary that Q. This is the modal analogue of modus ponens and seems uncontroversially correct. Adding stronger axioms generates stronger systems. The T axiom — "what is necessary is actual" (□P → P) — captures the truism that necessary truths are true. The S4 axiom — "if it is necessary that P, then it is necessarily necessary that P" (□P → □□P) — holds if the accessibility relation among possible worlds is transitive. The S5 axiom — "if it is possible that P, then it is necessarily possible that P" (◇P → □◇P) — holds if accessibility is an equivalence relation.

S5 is typically taken to be the correct logic for metaphysical possibility: if something is metaphysically possible, it is possible in all possible worlds, since the space of metaphysical possibility is the same from every vantage point. But this conclusion is not uncontroversial: some philosophers hold that there are iterated modalities that violate S5, and the question of which modal logic is "correct" for metaphysical modality remains open.

Quantified modal logic — extending modal logic to include quantifiers — generates distinctive puzzles about existence across possible worlds, the interaction of quantification and modality, and the semantics of de re modal claims (claims about what properties a particular individual must or might have). This section develops the formal tools of modal logic with attention to their philosophical significance.
