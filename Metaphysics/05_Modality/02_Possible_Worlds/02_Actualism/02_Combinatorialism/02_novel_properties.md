# Novel Properties and the Limits of Combinatorialism

Combinatorialism's most pressing challenge is not about individuals but about properties. If possible worlds are restricted to recombinations of actual properties, then any property not in the actual world cannot figure in any possible world. But there is strong intuitive reason to think that some possibilities involve properties nothing actual has — genuinely novel fundamental properties, not constructible from anything that exists.

## The Problem

Consider a thought experiment: could there have been a new fundamental force of nature — one that repels all things equally, with no charge-analogue in the actual world — involving a property P* genuinely novel, not structurally reducible to any actual universals? Combinatorialism says no world contains P*, since P* is not an actual universal, and possible worlds are restricted to recombinations of actual universals.

Yet the intuition that such a world is possible seems strong. Physics itself has discovered fundamental properties — charge, spin, color charge — that were previously unknown and were not constructible from properties previously recognized. It seems epistemically open, at minimum, that there could be further fundamental properties yet to be discovered, or that metaphysically possible circumstances might involve properties that do not exist in our world.

More formally: if we let PossibleUniversals = ActualUniversals (strict combinatorialism), then ◇P* is false for any alien property P*. Many philosophers find this conclusion implausible. The space of metaphysical possibility seems to extend beyond what actual universals allow.

## Armstrong's Responses

Armstrong offered several responses, none fully satisfying.

**Structural combination**: Properties can be "structural" combinations of actual simple properties — novel points in the space defined by actual properties' dimensions. A novel color might occupy a new position in the structural space defined by actual hue, saturation, and brightness. This accommodates a kind of novelty without strictly alien fundamental properties.

**Challenging the intuition**: Armstrong argued that the intuition that alien properties are possible may rest on confusing epistemic and metaphysical possibility. We can imagine language for alien properties; we can describe scenarios that seem to involve them. But this imaginative capacity may outrun genuine metaphysical possibility. The challenge to this response: why should the space of metaphysical possibility be constrained to actual universals? The constraint seems ad hoc unless there is a principled reason why actual universals exhaust the possible ones, and Armstrong does not provide one.

**Honest concession**: Armstrong frankly acknowledged that combinatorialism cannot accommodate alien properties in the strict sense and argued that this is a limitation but not a fatal defect. The theory is correct for a large range of possibilities and is the most parsimonious actualist account available.

## Lewis's Response

Lewis's modal realism provides a straightforward accommodation: worlds with alien properties are real concrete worlds, and the alien properties exist in them. Lewis's principle of recombination entails that for any consistent combination of properties, including alien ones, there is a world exemplifying them. Properties are not restricted to actual exemplifications but include all properties exemplified anywhere in modal space.

The cost: Lewis's account is less parsimonious — it posits infinitely many concrete worlds containing exotic entities. The benefit: it accommodates the full intuitive space of possibilities without the restrictions that afflict actualist accounts.

## The Diagnostic Significance

The alien property problem reveals a fundamental tension in actualism. Actualists restrict the ontological inventory to actual entities. But the space of genuine possibilities seems to require more than what actually exists. Any actualist account must choose among unappealing options: accept an inflated actual ontology (Plantinga: uncountably many abstract properties exist necessarily); restrict the space of possibilities to what actual entities allow (Armstrong: combinatorialism); or use non-actual but abstractly-grounded possibilities (ersatzism: abstract representations of alien possibilities).

Beyond combinatorialism, some philosophers have proposed **structural ersatzism**: abstract structures that represent alien properties without requiring those properties to be actual. A structure includes a node representing an alien property Q, representing a world with Q, even if no actual entity instantiates Q. The challenge for structural ersatzism is the representation problem: what determines that the node represents Q rather than some other property? Without an account of how abstract structures represent alien properties, the ersatzist account is incomplete. This is the same problem that Lewis pressed against all abstract accounts of possible worlds, and it applies with particular force when the property being represented has no actual realization to anchor the representation.
