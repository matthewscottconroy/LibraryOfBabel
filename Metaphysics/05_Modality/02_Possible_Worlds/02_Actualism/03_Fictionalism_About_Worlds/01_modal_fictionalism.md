# Modal Fictionalism

There is a third option, distinct from Lewis's concrete worlds and Plantinga's abstract ones: treat possible-worlds discourse as a useful fiction. We speak *as if* possible worlds were real to exploit the logical and semantic resources of possible-worlds reasoning, without actually believing in them. Modal fictionalism, developed by Gideon Rosen in "Modal Fictionalism" (1990), is the most sophisticated defense of this option.

## The Core Thesis

Rosen's fictionalism is modeled on mathematical fictionalism — Hartry Field's view that mathematical claims are useful but not literally true, since there are no mathematical objects. Just as the mathematical fictionalist holds that "there are infinitely many primes" is useful but not literally true, the modal fictionalist holds that "there is a possible world where dragons exist" is useful but not literally true — there are no possible worlds, concrete or abstract.

The key move: modal claims are analyzed as claims about what holds according to a fiction — specifically, Lewis's theoretical fiction of the plurality of worlds. When we say "possibly there are dragons," we mean: *according to Lewis's theory (taken as a fiction)*, there is a possible world where dragons exist. We speak as if Lewis's theory were true in order to exploit its logical and semantic resources, while remaining uncommitted as to whether Lewis's worlds actually exist.

The prefix analysis: for any modal claim M, the fictionalist paraphrase is "According to the Lewisian fiction [Lewis's *On the Plurality of Worlds*], M." So:

- "Possibly P" becomes: "According to the Lewisian fiction, there is a world where P."
- "Necessarily P" becomes: "According to the Lewisian fiction, P is true at all worlds."

This preserves the inferential structure of possible-worlds reasoning (we can reason within the fiction) while avoiding metaphysical commitment.

## Motivation

The motivation is clear. Possible worlds talk is theoretically useful — it systematizes modal reasoning, counterfactual conditionals, propositional attitudes, and content. But concrete possible worlds (Lewis) are ontologically extravagant, and abstract possible worlds (Plantinga, linguistic ersatzism) face the representation problem and their own ontological mysteries. If we can capture the theoretical utility of possible worlds talk without committing to actual possible worlds, that would be preferable.

## The Problem of Value

The deepest problem for fictionalism is the **problem of value**: if possible worlds are a fiction, what explains their theoretical utility? If "possibly there are dragons" is merely a claim about what holds in a fiction, why does this capture something true about the actual world's modal structure?

We seem to know absolutely — not merely fiction-relatively — that dragons are possible and that round squares are impossible. Fictionalism seems to reduce modal truths to claims about what holds in a story, which cannot do justice to the genuine normative force of modal claims. Impossibility is not the impossibility of being true according to a story — it is genuine metaphysical impossibility.

The fictionalist response: the Lewisian fiction is *co-ordinated* with genuine modal truths. It is not arbitrary that we use the Lewisian fiction — it is the one that correctly systematizes genuine modal truths. But this response seems to presuppose that there are genuine modal truths (independently of the fiction) to be systematized — which is precisely what fictionalism was supposed to avoid presupposing.

## The Parity Problem

Rosen identified a specific challenge he called the **parity problem**:

(A) Possibly, there are talking donkeys.
(B) According to the Lewisian fiction, there is a world where talking donkeys exist.

The fictionalist says A is true iff B is true. But B is a claim about the Lewisian fiction — a claim that is true if Lewis's theory entails what it needs to entail, false if it doesn't. The truth of B depends on the content of a contingent text.

Now compare: (A') Necessarily, 2 + 2 = 4. (B') According to the Lewisian fiction, at every world, 2 + 2 = 4. The necessity of mathematics seems to be a stronger claim than any fiction-relative one. Making mathematical necessity depend on Lewis's fiction — a contingent artifact — seems to make mathematical necessity an empirical matter about a contingent text. This is not right.

## Neo-Fictionalism and Subtler Positions

Rosen and others have explored more sophisticated variants. **Agnosticism**: we do not believe in possible worlds, but we do not disbelieve either — we simply use possible worlds talk as a theoretical framework while suspending ontological judgment. **Pragmatic fictionalism**: possible worlds talk is useful as an organizational framework, and utility is all we need. **Credentialed fictionalism**: possible worlds are theoretical posits that earn their place through explanatory work, without claiming concrete or abstract existence.

These subtler positions face the same fundamental problem: they must either presuppose genuine modal truths (in which case fictionalism is incomplete as an account of what makes modal claims true) or reduce modal truths to fiction-relative claims (in which case genuine necessity is lost). The search for a fully satisfactory fictionalist account of modality remains ongoing, and the parity problem has not been resolved to general satisfaction.
