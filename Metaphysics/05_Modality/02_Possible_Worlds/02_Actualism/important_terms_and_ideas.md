# Important Terms and Ideas: Actualism

**Actualism**
The thesis that everything that exists actually exists—there are no merely possible objects or non-actual possible worlds as concrete particulars. Modal claims can be true, but their truth does not require the existence of entities beyond what is actually the case.

**Maximal Possible State of Affairs**
Plantinga's ontological basis for possible worlds: a state of affairs S is a possible world if it is possible and, for every state of affairs T, either S includes T or S precludes T. Actual possible worlds are abstract entities existing in the actual world.

**World-Stories**
Adams's alternative actualist account: a world-story is a maximally consistent set of propositions. Possible worlds are such sets, and modal truths are truths about which propositions belong to which world-stories—all of which exist as abstract objects in the actual world.

**Serious Actualism**
The stronger thesis that not only does everything exist actually, but nothing could have had properties without existing—there are no cases where an object has a property at a world where it does not exist. This rules out "haecceitism" about non-existents.

**Haecceity**
An individual essence or "thisness"—the property of being that particular individual, distinct from any qualitative properties it has. Plantinga uses haecceities to explain transworld identity within actualism: an individual's haecceity is an actually existing abstract property.

**Possibilism**
The rival view to actualism: there genuinely are merely possible objects—entities that do not exist but could have. Lewis's modal realism is one form; Meinongian accounts of non-existent objects are another. Actualists argue that possibilism multiplies ontology beyond necessity.
