# Important Terms and Ideas: Anti-Essentialism

**Quinean Anti-Essentialism**
Quine's view that the distinction between essential and accidental properties of an object is not an objective metaphysical distinction but depends on how the object is described. A cyclist is essentially two-legged qua animal but not qua cyclist—showing that "essential" is description-relative, not absolute.

**Nominalism about Modality**
The view that modal facts (necessities and possibilities) are not genuine features of mind-independent reality but are instead grounded in conventions, linguistic rules, or concepts. On strict nominalism, there are no modal truths beyond truths about how we use language.

**Conventionalism about Essence**
Sidelle's position: what properties are essential to things is determined by our conceptual conventions—the rules governing how we apply sortal concepts. "Water is essentially H₂O" is true in virtue of the convention governing "water," not in virtue of a mind-independent essentialist fact.

**Description-Relativity**
The anti-essentialist claim that whether a property is essential to an object depends on which description of the object is in play. Under one description an object has a property essentially; under another it has it accidentally. There is no absolute fact about which description is correct.

**Haecceitism (Anti-)**
Anti-haecceitism holds that there are no primitive individual essences or "thisnesses"—nothing makes this individual rather than a qualitative duplicate in another world the very same individual. Modal claims about individuals reduce to qualitative claims or are indeterminate.

**Modal Deflationism**
A broad family of views that aim to deflate modal claims from substantive metaphysical commitments to mere logical, linguistic, or conceptual truths. Modal deflationists resist the idea that necessity and possibility reflect deep features of reality.
