## Map 2: Kripke's A Posteriori Necessities

```
KRIPKE'S SEMANTIC THESIS:
Proper names and natural kind terms are RIGID DESIGNATORS
(they refer to the same entity in every possible world)
               │
               ▼
"WATER" rigidly designates the actual watery stuff
               │
               ▼
Empirical discovery: the actual watery stuff = H₂O
               │
               ▼
"WATER IS H₂O" is TRUE IN EVERY WORLD WHERE WATER EXISTS
               │
               ▼
Therefore: METAPHYSICALLY NECESSARY
(true in every possible world)
               │
               ▼
But we discovered it EMPIRICALLY
(Empirically = a posteriori)
               │
               ▼
A POSTERIORI NECESSARY TRUTH

IMPLICATIONS:
├── "Water is H₂O" is not definitional or conceptual
├── "Hesperus is Phosphorus" is necessary (same planet)
├── Origin essentialism: this very person could not have
│   had different parents
└── Challenges: two-dimensionalists (Chalmers) argue the
    water example requires distinguishing primary and
    secondary intensions to preserve the a priori/
    a posteriori distinction
```

## Map 3: Fine's Essence vs. Modality

```
MODAL REDUCTION OF ESSENCE (traditional):
Essential properties of x = properties x has in every
world where x exists
           │
           ▼
COUNTEREXAMPLE (Fine 1994):
Socrates is necessarily a member of {Socrates}
(true in every world where Socrates exists)
           │
BUT: Being a member of {Socrates} is NOT part of
     Socrates's nature — it is essential to the
     singleton {Socrates}, not to Socrates
           │
           ▼
CONCLUSION: Essential properties ≠ necessary properties

           FINE'S PICTURE:
           Essence is primitive; it is what
           constitutes what x is
                    │
                    ▼
           Necessary truths FLOW FROM essence
           (not: essence = necessary truth about x)
                    │
           DIRECTION: Essence → Necessity
           NOT: Necessity → Essence
                    │
           This makes essence more fundamental
           than modality (contra Kripke's framework
           which analyzes essence via modality)
```
