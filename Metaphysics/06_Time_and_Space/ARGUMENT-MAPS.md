## Map 2: McTaggart's Argument for the Unreality of Time

```
MCTAGGART (1908)
          │
P1: For time to be real, there must be genuine change
          │
P2: Genuine change requires the A-series
    (events must be past, present, then future)
          │
P3: The A-series generates a contradiction:
    Every event must be past, present, AND future
    (but these are incompatible)
          │
APPARENT RESPONSE: "Events have them at different times"
          │
P4: This response reintroduces the A-series
    (using "at different times" implies prior A-properties)
          │
C: Infinite regress → A-series is self-contradictory
          │
C*: B-series alone does not constitute time
          │
C**: Time is UNREAL

     B-THEORIST RESPONSE:
          │
     P2 is false: Change consists in
     an object having different properties
     at different B-related times.
     A-properties are analyzed as
     relational (to the time of utterance).
     No contradiction arises.
          │
     A-THEORIST RESPONSE:
          │
     P3 is not genuinely contradictory:
     events have A-properties *successively*,
     not simultaneously. The regress is
     harmless because A-temporal predication
     is sui generis — it does not require
     a meta-level A-series.
```
