# Responses to Multiple Realizability

Multiple realizability was widely accepted as decisive against type identity theory after Putnam's formulation — but the apparent decisiveness did not last. Responses have been developed that either limit the scope of the argument or argue that it does not undermine type identity in the way Putnam claimed.

The first response is the *grain objection*: Putnam's argument assumes that the relevant physical descriptions are at the level of C-fiber firing, X-fiber firing, and so on. But type identities could be drawn at a higher level of physical description — at the level of functional neural organization or information-processing patterns — at which the same physical type might obtain across different organisms. "Pain" might be identical to a type that abstracts over specific chemistry while capturing the common computational or organizational feature. Critics respond that this is just functionalism, not type identity — and so it concedes the debate to Putnam.

The more interesting response comes from Jaegwon Kim's "Multiple Realization and the Metaphysics of Reduction" (1992). Kim argued that multiple realizability, far from supporting non-reductive physicalism, actually supports *local*, species-specific reductions. Human pain is identical to C-fiber firing in humans; octopus pain is identical to a different neural state in octopi; Martian pain to a silicon state in Martians. There is no single universal reduction — but there are multiple local reductions, and this is all we should expect. Mental properties "fracture" into many physical realizers, each of which can be locally identified.

The philosophical cost of Kim's strategy: if human pain and octopus pain are not instances of a single mental type, then psychological generalizations that apply across species — "pain causes avoidance behavior in organisms with sufficiently developed nervous systems" — cannot be captured at the type level. They would have to be stated as generalizations over a disjunction of species-specific mental types. This disjunctive character is precisely what non-reductive physicalists claim is absent from genuine scientific explanations.

## Lawrence Shapiro on Genuine Multiple Realizability

Lawrence Shapiro has argued that genuine multiple realizability — not mere multiple implementation — requires that the different realizers work in fundamentally different ways while producing the same functional output. Most purported examples of multiple realizability are actually cases of multiple implementation of the same physical principle. Consider mousetraps: spring trap, glue trap, electronic trap all catch mice, but they all operate by exploiting related mechanisms. If the relevant scientific kind is "device that operates on mechanism X to capture mice," each trap type is a different scientific kind, not multiple realizations of the same kind.

Applied to mental states: if human pain and octopus pain are genuinely the same mental kind, this requires that they share some non-trivial property beyond mere superficial behavioral similarity. If the neural mechanisms are sufficiently different, "pain" may be ambiguous between different mental kinds — in which case the multiple realizability argument relies on an equivocation. John Polger and Shapiro's *The Multiple Realization Book* (2016) provides a systematic reconsideration, arguing that the evidence for multiple realizability is weaker than assumed and that scientific practice often converges on unique physical realizers for mental function types.

## The Significance for Non-Reductive Physicalism

Multiple realizability was the central argument for non-reductive physicalism — the view that mental properties are real and distinct from physical properties, but supervenient on them. If the responses to multiple realizability succeed, non-reductive physicalism loses its main empirical motivation. The alternatives become type identity theory (reduction) or some form of property dualism.

This is the dialectical context for Kim's exclusion argument: he argues that non-reductive physicalism, motivated by multiple realizability, faces the exclusion problem, and the only coherent escape is either reduction or epiphenomenalism. Multiple realizability was supposed to be an argument against reduction; Kim argues it actually motivates a more thorough understanding of the options, which reveals that reduction is preferable to epiphenomenalism. Whether Kim is right about this depends on whether the exclusion problem is as severe as he claims — and that debate continues.
