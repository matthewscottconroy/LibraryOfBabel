# Exercises and Thought Experiments

1. **Supervenience and zombies**: If physicalism requires metaphysical supervenience of the mental on the physical, and if philosophical zombies are metaphysically possible, then physicalism is false. Evaluate this argument. Is metaphysical supervenience the right formulation of physicalism?

2. **Davidson's anomalous monism**: Davidson holds that mental events cause physical events but that mental properties play no independent causal role. Is this a coherent position? Design a thought experiment to test whether the mental content of an event (its being a belief about rain vs. a belief about snow) ever makes a causal difference to the physical outcome.

3. **Causal closure**: Does quantum indeterminacy leave room for non-physical causation? If physical events are probabilistically but not deterministically determined by prior physical events, does this create "causal space" for mental causation without violating causal closure?

4. **The explanatory gap**: Can you explain, using purely physical terms, why 650nm light looks red rather than blue? If not, does this show a genuine metaphysical gap between physical and phenomenal facts, or merely an epistemic limitation?

5. **Hempel's dilemma**: If physicalism means "everything studied by current physics," it's probably false (current physics doesn't include consciousness). If it means "everything studied by ideal/complete physics," we don't know what it means. Is there a way to define physicalism that avoids this dilemma?
