# Exercises and Thought Experiments

1. **The zombie thought experiment**: Conceive of a world physically identical to ours but containing no consciousness. Is this coherent? If yes, does it follow that consciousness is not physical? Chalmers argues yes; physicalists argue the conceivability only reflects conceptual gaps, not metaphysical ones. Which response is more convincing?

2. **Psychophysical laws**: Chalmers proposes that psychophysical laws connect physical processes to phenomenal properties. What would such a law look like? Would "whenever neurons fire in pattern P, experience E occurs" count? Is this kind of law explanatorily satisfying, or does it just restate the correlation without explaining it?

3. **The combination problem for naturalistic dualism**: If consciousness is a fundamental property, how do micro-level phenomenal properties combine to produce macro-level unified conscious experiences? This problem (the "combination problem") threatens panpsychist views. Does it also threaten Chalmers's naturalistic dualism?

4. **Phenomenal concepts**: Brian Loar argues that phenomenal concepts refer to physical states but do so via a distinctive mode of presentation (direct, introspective acquaintance). This explains why there seems to be a gap without there being a metaphysical gap. Is this explanation adequate? Could the same strategy be used to explain away any apparent gap between any two theories?

5. **Jackson's reversal**: Frank Jackson initially defended the knowledge argument and then reversed his position, arguing that Mary only learns which physical state is the one she previously knew about as "the state that causes such-and-such behavior." Is this reversal convincing? Does it adequately account for what Mary learns?
