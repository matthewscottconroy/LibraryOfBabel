# Exercises and Thought Experiments

1. **Multiple realizability test**: Consider the following systems: (a) a biological brain, (b) a silicon computer running the same program, (c) a network of people each following simple rules, (d) a thermostat. For each, at what level of description would you apply mental state attributions? What criterion distinguishes the mental from the merely computational?

2. **Turing Test**: Turing proposed that a computer passes as intelligent if it can converse indistinguishably from a human in text. Is passing the Turing Test sufficient for consciousness? Necessary for intelligence? Could a perfectly trained large language model pass the Turing Test without understanding anything?

3. **Putnam's machine functionalism**: If the mind is the software of the brain, what follows about the possibility of mind uploading? If your neural architecture were perfectly simulated in silicon, would the simulation be you? Would it be conscious?

4. **Causal role definitions**: Using Lewis's Ramsey-Lewis method, try to define "belief that it will rain tomorrow" by its causal role. What are the relevant inputs, outputs, and interactions with other mental states? Does the resulting definition capture all and only beliefs about tomorrow's rain?

5. **Functional duplicates**: If two systems have identical functional organization but different causal histories (one evolved, one designed), do they necessarily have the same mental states? Does the origin of a functional organization matter for mental state attribution?
