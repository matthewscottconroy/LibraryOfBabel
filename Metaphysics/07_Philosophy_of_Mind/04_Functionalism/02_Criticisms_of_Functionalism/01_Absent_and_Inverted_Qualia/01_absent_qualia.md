# Absent Qualia

Suppose you could build a system that implements exactly the functional organization of a conscious human brain — same causal relations to inputs, same causal relations to outputs, same pattern of state-to-state transitions. If functionalism is true, this system would be conscious: it would have pain when C-fiber firing produces the right functional output, beliefs and desires when the right states play the right roles. Now ask: is it conceivable that this system has no qualitative experience whatsoever? That there is nothing it is like to be this system, even though its functional profile is indistinguishable from that of a conscious being?

This is the absent qualia objection, stated most forcefully by Ned Block in "Troubles with Functionalism" (1978). The formal version:

- P1: There is a possible system S that satisfies all the functional role conditions for pain but has no phenomenal experience — no "what it is like" to be in that state.
- P2: If functionalism is true, any system satisfying all functional role conditions for pain is in pain.
- P3: A system with no phenomenal experience of pain is not in pain.
- C: Functionalism is false.

Block's "China Brain" thought experiment makes P1 vivid. Suppose the entire population of China is organized to simulate the functional organization of a single human brain. Each person simulates one neuron; satellite communication networks simulate synaptic connections. The system has exactly the same causal organization as a conscious brain — the same functional profile. If functionalism is true, the China Brain is conscious. But Block argues that the system clearly has no unified experience, no "what it is like" to be it. If absent qualia are possible for the China Brain, they are possible for any purely functional realization, which refutes functionalism.

Chalmers's fading qualia thought experiment presses the same point from a different angle. Imagine gradually replacing neurons with silicon chips that perfectly replicate each neuron's functional profile. Functional organization is preserved at every step. If qualia fade at some point during the replacement, behavior must change at that point — but it was stipulated not to. So either qualia never fade (silicon systems can have qualia, and the absent qualia scenario is impossible) or qualia are not required for functional behavior (they are absent in purely silicon systems, and the absent qualia scenario is possible). The argument places the functionalist in a dilemma.

## Responses and What Rides on Them

The most direct response is to accept the counterintuitive conclusion: the China Brain would be conscious. Our intuition that it is not is a failure of imagination — we cannot imaginatively inhabit the perspective of a system this large and distributed. Functionalism is true, the China Brain satisfies the conditions, we must accept it is conscious. This response has a certain philosophical rigor, but it asks us to revise a very strong intuition without giving us any positive account of what consciousness the China Brain has.

The more common response draws on Block's own distinction between access consciousness and phenomenal consciousness. A-consciousness is functional: information is access-conscious when it is available for reasoning, reporting, and behavioral control. P-consciousness is phenomenal: there is something it is like to have the state. Functional organization may be sufficient for A-consciousness without being sufficient for P-consciousness. The China Brain may have A-consciousness — information available to it functionally — while having no P-consciousness. This reframes rather than resolves the objection: it concedes that functionalism is not a complete theory of mind, only a theory of the functional dimension. Whether there is a dimension beyond the functional is precisely what the absent qualia objection was trying to establish. The connection to the hard problem is direct: absent qualia seem possible because there appears to be a gap between functional organization and phenomenal experience — the same gap that defines the hard problem. Closing the absent qualia problem and solving the hard problem are, for all practical purposes, the same task.
