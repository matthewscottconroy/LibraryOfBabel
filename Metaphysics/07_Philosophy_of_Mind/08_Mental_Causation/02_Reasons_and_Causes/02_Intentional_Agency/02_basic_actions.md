# Basic Actions

Killing a mosquito is done by swatting. Swatting is done by moving the hand. Moving the hand is done by... what? At some point in the chain of instrumental action descriptions, the regress terminates. There is something the agent does that is not done by performing any further action — something done directly, without means. Arthur Danto introduced the term **basic action** for this: an action is basic if and only if it is not performed by means of any other action.

For Danto, bodily movements are the paradigm basic actions. I do not move my body by doing something else; I just move it. Everything else I do is done by moving my body in some way. Basic actions ground the **instrumental structure** of intentional action: complex actions are built from basic actions by chains of instrumental relations of the form "A by B-ing." This structure can be represented as an action tree, with the basic action at the root and increasingly complex non-basic actions branching upward.

The structure is philosophically useful because it identifies the point at which intentional control interfaces with the physical world, clarifies the connection between mental states (intentions) and physical events (movements), and provides a basis for distinguishing what is "up to" the agent — the basic action — from its downstream effects, which depend on the world cooperating with the agent's efforts.

## Puzzles about Basic Actions

What exactly constitutes a basic action? If bodily movements are basic, what exactly is moved "directly"? The agent seems to control muscle contractions, which cause limb movements. But can the agent control muscle contractions directly? Or does the agent control neural events that cause muscle contractions? At the lowest level, the agent's control interfaces with neural firing. Does this mean neural events are basic actions — despite the fact that the agent has no conscious access to them and cannot directly control them?

Libet's readiness potential experiments (1983) sharpen this challenge. The neural preparation for voluntary movement begins approximately 350 milliseconds before the agent has any conscious intention to move. If the neural events that initiate movement precede and cause the conscious intention, then the agent's "direct" control of movement is less direct than the concept of basic action suggests. The agent seems to be ratifying or not vetoing a process that has already begun, rather than initiating it.

Danto later revised his view: basic actions are mental events — acts of will or intentions — that directly cause bodily movements. The bodily movement is not the basic action but its result. The agent directly wills; the will causes movement. But this revives the volitionist picture and the regress problem: what makes the willing itself an action? Is willing an act of will? If so, there is a prior willing, and so on indefinitely.

## The Interface Problem

The concept of basic action highlights what might be called the **interface problem**: where does the agent's intentional control interface with the physical world? Wherever we draw the line, difficulties follow. If at the bodily movement: what causes the movement in the right way to make it a basic action, and how do we distinguish intended from unintended movement? If at the neural event: the agent has no direct access to neural events, and they precede conscious intention. If at the volition or intention: these are mental events, and the connection between mental events and physical movements reopens the mind-body problem.

The concept of basic action thus does not resolve the question of how intentional agency is possible but locates it precisely. The question "what is the basic action?" is equivalent to the question "where and how does mental causation interface with physical causation?" — and that is the question at the heart of the philosophy of mental causation.
