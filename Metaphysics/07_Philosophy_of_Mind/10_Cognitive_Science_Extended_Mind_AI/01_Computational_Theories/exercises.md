# Exercises and Thought Experiments

1. **LOT necessity**: Fodor argues that thought requires a language of thought because thought is productive and systematic. Is the language of thought hypothesis the only way to explain productivity and systematicity? Could connectionist networks accommodate these features without positing LOT?

2. **Modularity test**: Fodor distinguishes modular (encapsulated, domain-specific) from non-modular (holistic) cognitive processes. Can you identify a cognitive process that is partially modular? Does partial modularity fit Fodor's strict account?

3. **Clark's parity principle**: Clark argues that if a process would be cognitive if it occurred inside the head, it should be recognized as cognitive when it occurs outside. Apply this principle to a smartphone that assists with navigation. Is GPS navigation cognitive? Is it extended mind?

4. **Embodied cognition in the lab**: George Lakoff argues that abstract concepts like 'argument' are understood through bodily metaphors (argument is war, argument is a journey). Design an experiment that would test whether these metaphors are constitutive of concept possession or merely expressive of it.

5. **Connectionism vs. LOT**: Connectionist models learn by adjusting weights in response to training data, not by manipulating symbolic representations. Fodor argues that connectionism cannot account for systematicity. Is this objection decisive?
