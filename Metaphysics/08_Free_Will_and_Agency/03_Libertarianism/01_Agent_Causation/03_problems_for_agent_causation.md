# Problems for Agent Causation

Agent causation faces a cluster of serious philosophical problems that have led many philosophers — including some libertarians — to seek alternatives. Understanding these problems is not merely to catalog difficulties; it explains why event causal libertarianism and non-causal libertarianism emerged as competing options, and it sharpens the sense of what any successful libertarian account must achieve.

## The Intelligibility Problem

The first and most fundamental problem is metaphysical obscurity. Event causation gives us a reasonably clear picture: one state of affairs (the cause) brings about another (the effect) in accordance with causal laws. We understand this through paradigm cases — billiard balls, falling objects, fire causing heat. We can say what the mechanism of causation is, or at least give a regularity account of what causal connection amounts to.

Agent causation is supposed to be *substance* causation: an entity — the agent — not an event or state, causes an event (the action). But what does this mean? Normally, when we say a substance has causal power, we cash this out in terms of properties or states of the substance: the ball causes motion because it has mass and velocity. But in agent causation, the agent's causing is not supposed to be reducible to any prior state of the agent. We are told what agent causation is not (not event causation) and what it is supposed to do (ground freedom), but the positive account of the mechanism remains elusive.

As van Inwagen puts it: agent causation is introduced as a posit rather than a theory. Timothy O'Connor's response — that agent causation is an *emergent* causal power arising when physical systems reach sufficient complexity — gives the concept a naturalistic home. But critics question whether emergence is sufficient: emergent properties are still realized in physical states, and the causing in question still seems to involve those states. If the agent's causing is grounded in the agent's physical/neural states, it collapses back into event causation.

## The Integration Problem

Agent causation is supposed to occur in the physical world and have physical effects — limb movements, speech, environmental changes. But the physical world is governed by physical laws, including the principle of causal closure: physical effects have sufficient physical causes. If agent causation intervenes in neural processes, it appears to introduce a non-physical cause of physical events, violating causal closure by adding energy from nowhere or deflecting physical processes without a physical cause.

The integration problem takes two forms. The *violation objection*: agent causation of neural events requires that something non-physical cause a change in physical states. If neural states are physical events governed by physical laws, adding a non-physical cause seems to violate those laws. The *redundancy objection*: suppose agent causation operates in the gaps of indeterministic processes — the quantum gaps where physical events are not fully determined by prior physical states. In that case, agent causation is not needed as a cause: the neural process would occur within normal probabilistic parameters without any agent-causal intervention. The agent-causal intervention is redundant; the physical story is complete without it.

Libertarians have responded in different ways. O'Connor accepts that agent causation operates within quantum gaps without violating causal closure — it selects among probabilistically available outcomes without adding energy or breaking conservation laws. Others hold that agent causation is a *sui generis* form of causation that does not fit neatly within the physical framework but is nonetheless real. Whether either response adequately addresses the integration problem is contested.

## The Luck Objection

The luck objection is the most powerful challenge, and the one that has generated the most philosophical work. It comes in several forms.

*The basic luck objection*: If the agent's causing of an action is not determined by prior events, then what makes it the case that the agent causes *this* action rather than some other? Without prior determination, the specific action seems arbitrary. Two agents who are identical in all relevant respects — same character, same reasons, same deliberation — might produce different actions simply because agent causation is indeterministic. But if the specific action is not determined by anything about the agent, in what sense is it the agent's? It seems to be a matter of luck which action occurs.

*The agent-causal luck objection*: Even granting that the agent causes the action, the agent's causing is undetermined. Is there something that makes the agent cause this action rather than another? If yes, that something determines the causing, and agent causation collapses into event causation. If no, the causing is undetermined — and undetermined causation is a form of chance. Agent causation appears to be randomness dressed in different language.

*The retrospective luck objection*: After the action, we can ask whether the action was genuinely the agent's own. If the same agent, in the same situation, with the same character and reasons, could have caused a different action, then the actual action seems as much a matter of luck as a coin flip. An action that could equally have been otherwise given the identical agent and reasons does not seem to express anything definitive about the agent.

## Agent-Causal Responses

Chisholm acknowledges the force of the luck objection but argues it reflects a misunderstanding. Agent causation does not require that there be a reason why the agent caused *this* specific action rather than another. The agent simply causes — this is what it means to be a genuine originator. The demand for a further reason why she caused this rather than that is the demand for a prior determining cause, which is precisely what agent causation is meant to transcend.

O'Connor adds that agent causation is a form of rational causation: the agent causes the action in response to reasons, and this rational responsiveness distinguishes agent causation from mere randomness. The action is not arbitrary because it is a rational response to reasons; it is not determined because the rational response could have gone otherwise.

The difficulty with both responses: they assert that agent causation is not randomness without fully explaining what distinguishes it from randomness. If two agents with identical reasons, characters, and agent-causal powers might cause different actions, the specific action still seems arbitrary in the relevant sense. The assertion that the agent "simply chose" does not illuminate why one choice rather than another occurred.

## The Explanatory Regress

A final objection: when we ask why the agent caused a particular action, agent causation theorists typically appeal to the agent's reasons. But reasons are states of the agent, and their causal influence seems to be event causation, not agent causation. If the reasons (as events) cause the action (as event), agent causation appears otiose — the reasons do all the explanatory work. If instead we say the agent causes the action in light of reasons without the reasons causing the action, we need an account of what "in light of" means when it is not a causal relation.

## The Skeptical Conclusion

Many philosophers conclude that agent causation as characterized by Chisholm and Taylor is either metaphysically incoherent or empirically unacceptable. If incoherent, libertarianism loses its positive account of freedom. If merely empirically unacceptable — because neuroscience gives no evidence for substance causation of neural events — libertarianism is empirically implausible.

This has led libertarians to develop alternatives. Event causal libertarianism (Kane) attempts to secure libertarian freedom without the mysterious metaphysics of substance causation, by invoking genuinely indeterministic probabilistic event causation. Non-causal libertarianism (Ginet) attempts to secure libertarian freedom without any causation at all, through the concept of basic acts with their distinctive phenomenal character. The problems for agent causation set the agenda for the entire libertarian program.
