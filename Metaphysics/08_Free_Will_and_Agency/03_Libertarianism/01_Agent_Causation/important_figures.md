# Important Figures: Agent Causation

## Thomas Reid (1710–1796)
The originator of the modern agent causation view: ordinary event causation cannot explain free action because events are necessitated by prior events, while agents initiate causal chains from themselves. The agent as substance is a genuine cause that is not caused by prior events.

## Roderick Chisholm (1916–1999)
The leading twentieth-century defender of agent causation; distinguished event causation (one event causing another) from agent causation (an agent qua substance causing an event) and argued that only agent causation can ground genuine freedom.

## Timothy O'Connor (born 1965)
A contemporary defender of agent causation who has worked to make the view scientifically respectable, arguing that agent causal powers can be understood as emergent properties of complex physical systems and do not require violation of physical law.

## William Rowe (1931–2015)
Philosopher of religion and free will who engaged critically with agent causation, examining what is required for it to be coherent and whether it avoids the randomness objection to libertarianism.
