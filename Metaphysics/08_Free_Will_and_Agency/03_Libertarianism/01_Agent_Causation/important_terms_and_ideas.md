# Important Terms and Ideas: Agent Causation

**Agent Causation**
The thesis that free actions are caused by agents as substances—not by prior events involving the agent, but by the agent itself exercising a distinctive causal power. This is distinguished from event causation (where causes are events or states of affairs) and from randomness (where nothing is a sufficient cause).

**Immanent vs. Transeunt Causation**
Chisholm's distinction: immanent causation is agent causation—the agent directly produces an effect from within themselves. Transeunt causation is event causation—one event causes another. Immanent causation is irreducible and grounds free action; transeunt causation alone cannot.

**Substance Causation**
An older term for agent causation: the substance (the person as a unified entity) is the cause, not any state or event occurring within the substance. This posits a special metaphysical category of causation over and above event causation.

**The Randomness Objection**
The main challenge to libertarian free will including agent causation: if an action is not fully determined by prior causes, it seems random or arbitrary—a matter of chance, not choice. If the agent's exercise of causal power is itself undetermined, it seems like a random occurrence. Agent causationists argue that agent causation is a third category beside determination and randomness.

**Emergence and Agent Causation**
O'Connor's move: agent causal power is an emergent property of persons that arises from but is not reducible to physical organization. As with consciousness, complexity can give rise to genuinely new causal powers. This attempts to make agent causation scientifically respectable.

**Initiation of Causal Chains**
Reid's idea: a free action is one where the agent initiates a causal chain ex novo—from themselves—without that initiation being caused by prior events. This preserves genuine authorship of action while avoiding the regress of prior causes.
