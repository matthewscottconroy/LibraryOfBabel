# Important Terms and Ideas: Perdurance vs. Endurance

**Intrinsic Properties and Change**
An intrinsic property is one that an object has (or lacks) purely in virtue of how it is in itself, independently of other things. The problem of temporary intrinsics: if an object has an intrinsic property F at t₁ and lacks F at t₂, how is this possible for a wholly present enduring object?

**Relativizing Properties to Times**
The endurantist response to the problem of temporary intrinsics: properties are instantiated relative to times—being bent at t₁, being straight at t₂. The object is wholly present at both times; its properties vary because they are time-indexed. Critics argue this makes "bent at t" a relation, not an intrinsic property.

**Adverbialism**
An endurantist strategy: instead of relativizing property instantiation to times, modify how the object instantiates a property. The object "bently instantiates" shape at t₁ and "straightly instantiates" shape at t₂. This preserves properties as intrinsic while accounting for change.

**Presentism and Endurance**
Many presentists are endurantists: only the present exists, so objects are wholly present (at the one time that exists). The combination is natural but not required: eternalists can be endurantists, and presentists could be perdurantists (though the combination is unusual).

**The Problem of the Many**
Unger's and Lewis's puzzle: for any ordinary object, there are many overlapping aggregates of particles that seem to have equal claim to be that object. Perdurantism, with its abundant temporal parts, may face this problem acutely. Endurantism must also address it.

**Extrinsicality of Relations (Lewis)**
Lewis's argument for temporal parts: change in intrinsic properties requires different intrinsic properties at different times; if the same object is wholly present at both times with different intrinsic properties, this violates the transitivity of identity. Temporal parts avoid this by having different stages bear different intrinsic properties.
