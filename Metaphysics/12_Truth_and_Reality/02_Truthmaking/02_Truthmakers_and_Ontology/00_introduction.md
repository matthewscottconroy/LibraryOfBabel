# Truthmakers and Ontology

Truthmaker theory has direct ontological implications: if we accept the truthmaker principle, we must posit the existence of whatever entities are required to serve as truthmakers for all the truths we acknowledge. This connection between truth and ontology makes truthmaker theory a powerful tool for the metaphysician: one way to determine what exists is to ask what is needed as a truthmaker for the truths in our best theory.

Armstrong used this method extensively. Mathematical truths require mathematical truthmakers — so either there are mathematical entities (Platonism) or mathematics is not genuinely truth-apt (fictionalism). Negative truths ("There are no unicorns") require negative truthmakers — so either there are totality states of affairs (facts about everything that exists) or negative truths have their own distinctive truthmakers. Modal truths ("It is possible that there be more than N elementary particles") require modal truthmakers — so either there are possible worlds or there are dispositional properties or some other modal reality.

The scope of truthmaker theory extends beyond simple predications. "There are no dinosaurs" is true; what makes it true? The totality of existing things — all the things that exist, none of which is a dinosaur. "It is possible that it rain tomorrow" is true; what makes it true? Not an actual rainstorm (which doesn't exist), but perhaps a disposition of the actual weather system, or a real but unactualized state of affairs (if we accept possible worlds), or a primitive modal fact about the actual world. Each choice of truthmaker commits us to a different ontology.

This "ontological proof" use of truthmaker theory — working backward from the truth to the truthmaker — is methodologically productive but requires care. The inference from "p is true" to "there is a truthmaker for p" is valid only if we accept the truthmaker principle; and some philosophers deny that all truths need truthmakers.

This section examines how truthmaker theory shapes ontological commitments across the range of truths — positive, negative, modal, mathematical, and moral.
