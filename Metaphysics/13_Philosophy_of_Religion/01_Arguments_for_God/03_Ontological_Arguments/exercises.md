# Exercises: Ontological Arguments

1. **Anselm's argument.** Reconstruct the Proslogion argument step by step. Identify which step is the most controversial. Is it premise 1 (the definition of God), premise 3 (existence in reality is greater than in understanding alone), or something else?

2. **Gaunilo's parody.** Does the perfect island parody succeed? Anselm replied that the argument only works for necessary beings. Is this reply satisfactory? Could you construct a parody involving a necessary island?

3. **Kant's objection.** Kant says existence is not a predicate. Explain this claim. Does it refute the ontological argument? Or does it only refute the claim that *contingent* existence is a predicate?

4. **Plantinga's modal argument.** Reconstruct Plantinga's argument using possible worlds. Is the key premise—"it is possible that a maximally great being exists"—question-begging? How does Plantinga defend it?

5. **The parody problem.** A "maximally evil being" would necessarily exist (if the concept is coherent) by the same reasoning. What is the best response to this parody? What determines which perfect-being concepts are coherent?

6. **Does it prove too much?** Even if the ontological argument is sound, what properties has it shown God to have? Does "maximally great" entail omnibenevolence? Could a maximally great being be morally indifferent?
