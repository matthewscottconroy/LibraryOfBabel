## Map 2: Plantinga's Modal Ontological Argument

```
PLANTINGA'S MODAL ONTOLOGICAL ARGUMENT
              │
DEFINITIONS:
Maximal excellence (ME) = omnipotence + omniscience + moral perfection
Maximal greatness (MG) = having ME in every possible world
              │
P1: ◇∃x MG(x)
    "It is possible that a maximally great being exists"
              │
P2: Necessarily, if a maximally great being exists,
    it exists in every possible world:
    □(MG(x) → □(MG(x) exists))
              │
P3: By S5 modal logic (◇□p → □p):
    If it is possible that something necessarily exists,
```
