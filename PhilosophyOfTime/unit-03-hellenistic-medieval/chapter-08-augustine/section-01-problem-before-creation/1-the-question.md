# 8.1.1 — "What Was God Doing Before Creation?"

---

## The Question and Its Philosophical Force

"What was God doing before He made heaven and earth?" This question appears in *Confessions* XI.10.12, where Augustine presents it as a challenge — or a taunt — that he must take seriously. He does not dismiss it. He takes it as philosophically deep: it points to a genuine puzzle about the relationship between God's eternity and the creation of the world.

The question's implicit structure is this: creation is an event that occurs at a time. It had a beginning. But if it had a beginning, there was time before it — and God was doing... what, exactly? Presumably existing, knowing, willing — all the things that God does. But then God existed *before* creation, in a time before the creation of the world. This seems to make God's existence temporal, even if very long. And if God's existence is temporal, then there was time before there was a world — which conflicts with any account that ties time to the world.

The question also has an implicit skeptical reading: if God waited an infinite time before creating, what triggered the decision to create *then* rather than at some other time? An infinitely old God with an infinity of time before creation faces a Leibnizian-style problem: why this moment and not another? If all prior moments were equivalent (as they would be in a featureless infinite time), there was no sufficient reason to create *now* rather than at any other time. This anticipates the Principle of Sufficient Reason arguments that Leibniz will later deploy against absolute time (Chapter 10).

## Augustine's Response: There Was No Before

Augustine's response to the question is not evasion; it is a genuine philosophical claim: "there was no 'then' when there was no time. You, the Eternal Creator of all times, are before all times, and no time is co-eternal with you, nor is any creature even if it transcended time" (*Confessions* XI.13.16, trans. Chadwick 1991: 231).

The argument is compact but powerful. Time is a feature of the created world — it was made along with the world, not prior to it. To ask "what was God doing before the world?" is to presuppose that there was time before the world, which is precisely what Augustine denies. The question contains a false presupposition. It is not like asking "what was happening at the North Pole before anyone traveled there?" — that question has a perfectly good answer. It is like asking "what is north of the North Pole?" — a question that is grammatically well-formed but presupposes a spatial framework that does not extend to the point in question (cf. Hawking 1988: 8–9, who uses a similar analogy in a different context).

This is a genuine metaphysical claim about the nature of time: time is not prior to creation; it is part of creation. The world was not created in a pre-existing temporal void; time itself came into being with the world. This means that "before creation" is not a temporal location at all — it is a grammatical construction that gestures toward something (God's eternal existence) that has no temporal structure.

## The Philosophical Force of "Time Was Created"

What is at stake philosophically in the claim that time was created?

First, it distinguishes between two possible views of God's relationship to time: (a) God is *in* time but has always existed — a sempiternal God who has never had a beginning; and (b) God is *outside* time entirely — not located in any temporal framework at all. Augustine is clearly arguing for (b). God is not very old; God is eternal in the strong, atemporal sense.

Second, it makes time ontologically dependent on the created order. Time does not exist independently of creation; it is a feature of creation. This is a relational claim about the ontological status of time — not quite the same as the Epicurean relational account (which holds that time supervenes on events), but sharing the insight that time is not an independently existing container.

Third, it makes a claim about the logic of temporal questions: questions that presuppose the existence of time cannot be asked about periods "before" time existed. This is not an arbitrary limitation but a consequence of taking seriously what time is. If time is a feature of the created order, then the sentence "before creation, God did X" contains a referential failure: the temporal phrase "before creation" fails to pick out any time.

This third point connects to contemporary philosophy of physics in an interesting way. The question "what happened before the Big Bang?" has a structurally similar character. If time itself began with the Big Bang (as some cosmological models suggest), then "before the Big Bang" does not pick out any time. The question is grammatically well-formed but ontologically empty. Augustine's analysis, though arrived at on theological grounds, anticipates this physical and philosophical point by fifteen centuries (Hawking 1988: 8–9; Craig and Smith 1993: 21–22).
