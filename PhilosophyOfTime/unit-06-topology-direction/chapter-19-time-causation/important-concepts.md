# Chapter 19 Important Concepts

---

**Temporal Priority of Causation**
The condition that causes precede their effects in time. Hume included this as one of three components of causal relations (alongside constant conjunction and contiguity). Whether temporal priority is a conceptual requirement of causation or a contingent feature of the actual causal structure of the world is a central question in the philosophy of causation.

**Constant Conjunction**
Hume's term for the regular co-occurrence of cause-type and effect-type events. On Hume's analysis, this is the objective component of causation: there is no necessary connection in the world, only observable regularity. Causation is constituted by constant conjunction together with contiguity and temporal priority.

**Counterfactual Dependence**
Lewis's foundational concept for the analysis of causation: event E counterfactually depends on event C iff, had C not occurred, E would not have occurred. Used to define causation: C causes E iff there is a chain of counterfactual dependences from C to E.

**Counterfactual Conditional**
A conditional of the form "If P had been the case, Q would have been the case," where P is contrary to actual fact. Lewis analyzed counterfactuals using possible worlds semantics: the conditional is true iff Q is true in the closest possible worlds where P is true.

**Asymmetry of Counterfactual Dependence**
Lewis's thesis that forward counterfactuals (from earlier to later events) are typically true while backward counterfactuals (from later to earlier events) are typically false. This asymmetry grounds the temporal asymmetry of causation and derives from the physical asymmetry of overdetermination.

**Overdetermination**
A causal situation in which two simultaneous, independent causes are each sufficient for the effect. Challenges Lewis's counterfactual analysis: if either cause alone would suffice, the effect does not counterfactually depend on either cause individually.

**Preemption**
A causal situation in which one causal process prevents another from completing its work. The preempting cause produces the effect; the preempted cause is cut off before it can. Challenges the counterfactual analysis of causation, particularly in cases of "late preemption."

**Trumping**
A case (due to Schaffer) in which two simultaneous, sufficient causes compete, but one "trumps" the other in virtue of priority, rank, or precedence — even though both are sufficient. Neither the counterfactual analysis nor the overdetermination framework handles this well.

**Backward Causation**
A hypothetical causal relation in which a later event (the "cause") brings about an earlier event (the "effect"). Dummett argued that backward causation is conceptually coherent; the bilking argument raises challenges to its instantiation.

**Bilking Argument**
The objection to backward causation that if C (later) causes E (earlier), an agent could systematically decouple E from C by choosing to bring about C only when E has not occurred — "bilking" the causal relation. This seems to show that backward causation cannot be a stable feature of the world.

**Wheeler-Feynman Absorber Theory**
An interpretation of classical electromagnetism (Wheeler and Feynman, 1945) that uses both retarded (forward in time) and advanced (backward in time) electromagnetic waves to describe radiation. The theory makes the same empirical predictions as standard electromagnetism but describes radiation in a time-symmetric, causally symmetric way.

**Causal Set**
A discrete, partially ordered set of fundamental events in which the partial order represents causal precedence. The fundamental object of study in causal set quantum gravity. Spacetime and time are emergent approximations to the underlying causal structure.

**Partial Order**
A relation on a set that is transitive, irreflexive, and asymmetric. In causal set theory, the partial order represents causal priority: x ≺ y means x is in the causal past of y. Unlike a total order, a partial order does not require every pair of elements to be comparable.

**Spacetime Emergence**
The idea that spacetime, with all its geometric and temporal properties, is not fundamental but emerges from a more basic structure (such as a causal set, in causal set theory). If spacetime is emergent, then temporal facts are derived, not primitive.

**Price's Circularity Objection**
Huw Price's argument that attempts to ground temporal direction in causal direction are circular, because our ordinary concept of causation already presupposes temporal direction (causes precede effects). A non-circular grounding would require a notion of causation that is temporally neutral.
