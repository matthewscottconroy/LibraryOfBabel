# 19.5.1 — The Causal Set Program: Spacetime from Causal Order

---

The causal set program is a candidate theory of quantum gravity that takes the causal structure of spacetime as fundamental, rather than treating spacetime itself as fundamental. Developed by Luca Bombelli, Joohan Lee, David Meyer, and Rafael Sorkin in 1987, and significantly advanced by Sorkin and collaborators since, causal set theory proposes that the continuum spacetime of general relativity is an approximation to a more fundamental discrete causal structure.

## The Basic Idea

A **causal set** is a set of discrete elements (representing fundamental events or spacetime "atoms") equipped with a partial order relation (representing the causal precedence relation: element x precedes element y iff x is in the causal past of y). The partial order must satisfy:

- **Transitivity:** If x ≺ y and y ≺ z, then x ≺ z.
- **Irreflexivity:** No element precedes itself (no causal loops).
- **Local finiteness:** The number of elements between any two elements in the order is finite.

Local finiteness is the key discreteness condition: it means that between any two events (in the causal order sense), there are only finitely many intermediate events. This contrasts with the continuum spacetime of classical general relativity, in which infinitely many spacetime points lie between any two events.

Bombelli, Lee, Meyer, and Sorkin showed that if you know the causal set — the partial order — you can, under suitable conditions, recover the full continuous spacetime geometry up to an overall scale factor (Bombelli et al. 1987: 521–524). The causal structure essentially determines the spacetime structure (at the macroscopic level), with the remaining information (the conformal factor) fixed by the discreteness scale.

## Causal Order as Fundamental

On the causal set picture, causal order is more fundamental than spacetime. Spacetime — with its metric, its distances, its curvature — is an emergent approximation to the underlying discrete causal structure. Time is not a fundamental feature of the universe; it emerges from the partial order of a causal set as a coarse-grained, macroscopic description.

This inverts the ordinary relationship between time and causation. In everyday thinking (and in standard physics), we think of events as temporal first — they occur at certain times — and then we ask which ones are causally connected. Causal set theory reverses this: the causal relations among events are primary, and temporal facts (which events are earlier, which later, how much earlier) are derived.

## Philosophical Implications

The causal set program has several important philosophical implications.

**Causation is more fundamental than time.** If causal set theory is correct, then the direction and structure of time are derivative from the causal partial order. This directly addresses the question of the relationship between time and causation: causation is prior. But note that the causal order in a causal set is not the ordinary everyday causation of human agency; it is a formal mathematical relation that may have little in common with the causal notions analyzed by Hume, Lewis, and Reichenbach.

**Time is discrete at the fundamental level.** The local finiteness condition implies that time is fundamentally discrete — there is a minimum temporal scale (roughly the Planck time) below which temporal distinctions are not defined. This supports the discrete time scenario discussed in Chapter 17.2.2.

**Spacetime emergence.** If spacetime emerges from a more fundamental causal structure, then the distinction between space and time, and the metric properties of spacetime (distances, durations, curvature), are all emergent rather than fundamental. This has implications for the philosophy of space and time that extend beyond the topics of this unit.

**The partial order and the arrow of time.** The partial order relation in a causal set is asymmetric and irreflexive — it is already "directed." The causal set approach thus builds temporal asymmetry into the fundamental structure: the causal order is not time-symmetric, even though the laws governing the dynamics of causal sets may be. This is an important difference from the thermodynamic approach, where temporal asymmetry is imposed by boundary conditions.

## Philosophical Assessment

Causal set theory is a speculative but serious research program in quantum gravity. Its philosophical appeal is that it takes a genuinely fundamental relationship — causal priority — as its ontological basis, avoiding the puzzles associated with a fundamental spacetime continuum. Its philosophical challenge is that the "causal" relation in a causal set is a formal partial order, not obviously connected to the richer, agency-involving notion of causation analyzed in the philosophical literature.

Whether Reichenbach's project — grounding temporal direction in causal direction — finds its best realization in causal set theory, or whether causal set theory involves a very different notion of "causal order," is a question that connects cutting-edge physics to classical philosophical concerns.
