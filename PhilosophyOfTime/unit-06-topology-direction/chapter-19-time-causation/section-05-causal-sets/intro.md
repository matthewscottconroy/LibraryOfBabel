# Section 19.5: Causal Set Theory

---

## Section Introduction

The causal set program in quantum gravity proposes that spacetime is not fundamental but emerges from a more basic structure: a discrete, partially ordered set of events — a "causal set" — in which the partial order encodes causal relations among the events. This section presents the causal set approach and examines its philosophical implications for the grounding relationship between time and causation.
