# 36.3.1 Causal Sets and the Physics of Becoming

---

## What Is a Causal Set?

Causal set theory, developed primarily by Rafael Sorkin and collaborators beginning in the late 1980s (Bombelli et al. 1987: 521–524; Sorkin 1990: 227–240), starts from the observation that the causal structure of spacetime — the ordering of events by the possibility of causal influence — encodes most of the metrical structure of spacetime. In general relativity, if you know which events can causally influence which others (i.e., the causal order), you know the conformal structure of the metric (the light cone structure at each point). The only additional information needed to recover the full metric is the volume of spacetime regions, which can be provided by the number density of causal set elements.

The conjecture underlying causal set theory is that the underlying structure of spacetime is discrete, not continuous. Instead of a smooth four-dimensional manifold, the fundamental reality is a *partially ordered set* — a set of discrete elements with a partial order that represents causal precedence. The smooth spacetime of general relativity, in this picture, emerges from the collective behavior of many discrete causal set elements, much as the smooth texture of water emerges from many discrete molecules.

Formally, a causal set is a pair (C, ≺) where C is a countable set and ≺ is a partial order (irreflexive, transitive, and locally finite) representing "causally precedes." The local finiteness condition is physically crucial: any "causal interval" (the set of elements between two related elements) is finite. This is the discreteness condition.

## Becoming as Sequential Growth

The most philosophically significant feature of the standard causal set dynamics is its treatment of *growth*. In the preferred dynamical framework for causal sets (Rideout and Sorkin 2000: 024002), the causal set grows by the accretion of new elements, one at a time. At each step, a new element is added to the existing partial order, extending the causal set by one more event.

This growth is a form of intrinsic becoming. The causal set does not exist all at once as a completed, timeless structure; it *grows* — element by element, step by step. Each new element that is added represents a genuine *coming-to-be*, a transition from non-existence to existence. The growing process is itself a form of temporal passage, built into the fundamental dynamics.

This is a striking contrast with the block universe framework that underlies most approaches to classical general relativity. In the block universe, all spacetime events exist simultaneously in the eternal manifold; there is no growth, no becoming, no genuine passage. In causal set theory, growth is fundamental: the universe literally grows, element by element, in the sequential accretion dynamics.

## Connection to the Growing Block

The causal set picture has a natural affinity with the growing block view examined in Chapter 17. The growing block holds that the past and present are real but the future is not yet real — that reality grows as new moments are actualized. In causal set theory, this ontological picture is built into the physics: the elements that have been added to the causal set are real; the elements that will be added in the future accretion have not yet been added and are not yet real.

The parallel is not perfect: causal set dynamics involves a stochastic process, with each new element added according to probability distributions over where in the partial order it is inserted (satisfying certain physically motivated conditions). This stochastic character introduces quantum-like randomness at the fundamental level — the particular history of the causal set is not predetermined but genuinely random.

But the structural parallel to the growing block is striking, and philosophically productive. Causal set theory provides a physical realization of the growing block ontology: a framework in which becoming is intrinsic to the fundamental physics, not a merely phenomenological or phenomenal addition.

## The Meaning of "Fundamental Becoming"

Sorkin (2003: 307–324) has been explicit about the philosophical significance of the causal set dynamics. He describes the sequential accretion as a form of "becoming" that is more fundamental than the ordinary temporal becoming described by A-theory, because it is built into the dynamics of the theory itself rather than being an additional postulate about the relationship between mind and world.

The philosophical subtlety is this: in causal set theory, the "becoming" that is fundamental is not the becoming of *moments* (as in the A-series) but the becoming of *elements* — discrete events that accrete to form the causal structure of spacetime. Each new element that accretes is like an objective "becoming present" — it transitions from non-existence to existence as part of the causal set. But this is not quite the A-series, because the elements do not have A-properties (present, past, future) in the standard sense; they are simply added to the partially ordered structure.

What causal set theory provides is a form of temporal ontology that is neither the timeless block universe nor the standard A-series. It is a universe that genuinely *grows* — that has an intrinsic direction of change — without requiring a privileged present moment or an A-series passage. It is a novel position in the metaphysics of time, one whose philosophical implications are still being worked out.
