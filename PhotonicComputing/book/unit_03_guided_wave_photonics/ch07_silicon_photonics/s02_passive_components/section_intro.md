# Section 7.2: Passive Components

Passive photonic components are the structural elements of a photonic circuit: they route, split, combine, and filter light without requiring electrical power for their basic function. (Tunable versions require heaters, but the base functionality is passive.) This section covers the essential building blocks of a silicon photonic computing chip.
