# LibraryOfBabel
A repository filled with books, lessons, and quiz programs to teach people stuff. Apart from producing specific content, the goal of this project to cultivate a process for generating text, tutorials, labs, quizzes, tests, applications, and study guides that help people learn new skills.

Ideally, workflows will be developed that automatically generate new material on-demand that is accurate, pedogogically sound, and useful for learning concepts and skills.
