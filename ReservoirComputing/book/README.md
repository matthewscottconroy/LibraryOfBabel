# Reservoir Computing: From First Principles to the Frontier

## A Textbook in Ten Units

This directory contains the full manuscript of a textbook on reservoir computing. It is organized hierarchically: Units contain Chapters, Chapters contain Sections, Sections contain Subsections. Each Chapter ends with Exercises, Further Reading, Key Researchers, and Key Concepts.

## How to Read This Book

**The mathematician's path:** Read all Math Boxes carefully. Work every exercise. Unit IX before Unit VII.

**The engineer's path:** Read introductions, skip Math Box derivations on first pass, complete all Programming Projects. Return to theory when intuition fails.

**The neuroscientist's path:** Unit I → Chapter 6 → Chapter 24 → Chapter 11 → Unit X.

**The hacker's path:** Chapter 4 → Chapter 5 → Programming Projects → wherever curiosity leads.

---

## Conventions

- **Math Boxes** contain full derivations, stepping through every line.
- **Worked Examples** apply theory to concrete cases.
- **Thought Experiments** are conceptual exercises with no single correct answer.
- **Lab Exercises** are hands-on computational experiments.
- **Programming Projects** are larger implementations (hours to days of work).
- Citations are formatted as [AuthorYear] and collected in each chapter's `references.md`.
