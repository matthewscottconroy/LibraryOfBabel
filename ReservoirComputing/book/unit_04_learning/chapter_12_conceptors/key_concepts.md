# Chapter 12: Key Concepts

See the Key Concepts section at the end of `exercises.md` for the complete list of 10 key concepts for this chapter. They are included there for cohesion with the exercises that reference them.

For quick reference:

1. Conceptor Matrix — $C = R(R + \alpha^{-2}I)^{-1}$
2. State Covariance Matrix $R$
3. Aperture $\alpha$
4. Conceptor NOT — $\lnot C = I - C$
5. Conceptor OR — $C \vee B = C(C+B-CB)^{-1}B$
6. Conceptor AND — $C \wedge B = \lnot(\lnot C \vee \lnot B)$
7. Bounded Distributive Lattice
8. Conceptor Quota — $\text{tr}(C)/N$
9. Pattern Recall via Conceptor Constraint
10. Aperture Adaptation — $C^{(\gamma\alpha)} = C(C + \gamma^{-2}(I-C))^{-1}$
