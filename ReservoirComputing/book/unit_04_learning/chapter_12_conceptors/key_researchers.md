# Chapter 12: Key Researchers

## Herbert Jaeger

See the Key Researchers section at the end of `exercises.md` for the detailed profile of Herbert Jaeger, who is the sole originator of the conceptors framework.

A brief summary: Jaeger developed conceptors in the 2014 monograph [Jaeger2014] as a framework for controlled memory storage, retrieval, and composition in recurrent neural networks. The framework builds on the echo state network (which Jaeger also invented) and extends it with a mathematical language for manipulating reservoir state subspaces using Boolean-like operations.

Jaeger is currently a professor at Constructor University Bremen (formerly Jacobs University Bremen). His broader research program spans computational neuroscience, machine learning, and the theoretical foundations of reservoir computing. Conceptors represent his most mathematically sophisticated contribution to the field — a synthesis of dynamical systems theory, linear algebra, and logic into a unified framework for neural memory.

Key publications:
- [Jaeger2001] Echo state networks (Science, 2001)
- [Jaeger2002memory] Short-term memory in ESNs (GMD Technical Report, 2002)
- [Jaeger2007] Tutorial on ESNs (Scholarpedia, 2007)
- [Jaeger2014] Conceptors monograph (arXiv, 2014)
- [Jaeger2017] Neural long-term memories (JMLR, 2017)
