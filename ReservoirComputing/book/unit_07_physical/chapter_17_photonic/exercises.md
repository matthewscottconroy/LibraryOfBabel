## Conceptual Exercises

**Exercise 17.1 — Ikeda Stability Analysis**

Consider the scalar Ikeda DDE (in discrete-time approximation with step size $\theta$):

$$x_{k} = \beta \sin^2\!\left(x_{k-1} + \phi_0\right) + \gamma m u$$

(a) Find all fixed points $x^* = \beta \sin^2(x^* + \phi_0)$ for $\phi_0 = \pi/4$ and $\beta = 0.5$. (There may be multiple; solve numerically or graphically.)

(b) For a fixed point $x^*$, show that the linearized map is $\delta x_k = \beta \sin(2(x^* + \phi_0)) \delta x_{k-1}$. What condition on $\beta$ and $x^*$ ensures stability?

(c) For $\beta = 1.5$ and no input, run the discrete map for 1000 steps starting from $x_0 = 0.1$ and $x_0 = 0.11$. Do the two trajectories diverge? What does this tell you about the ESP in this regime?

**Exercise 17.2 — Virtual Node Coupling Analysis**

In the Appeltant system with $N$ virtual nodes, the coupling structure is approximately a ring: node $k$ influences node $k+1$.

(a) Write the $N \times N$ recurrent weight matrix $W^{ring}$ for a ring ESN with weight $\beta$.

(b) What is the spectral radius $\rho(W^{ring})$ as a function of $\beta$ and $N$?

(c) For what values of $\beta$ does the ring reservoir satisfy the ESP sufficient condition? Compare to the fully random ESN condition ($\rho(W) < 1$).

(d) For $N = 100$ and $\beta = 0.8$, compute $\rho(W^{ring})$. Is the ESP guaranteed?

**Exercise 17.3 — Coupled Mode Theory**

A single micro-ring resonator with coupling time $\tau_e = 10$ ps, intrinsic loss time $\tau_0 = 100$ ps, and resonance $\omega_0 = 2\pi \times 194$ THz (1550 nm).

(a) At steady state ($da/dt = 0$) with no nonlinearity, solve for $a$ as a function of $s_{in}$ and the detuning $\Delta\omega = \omega - \omega_0$.

(b) Compute the transmission $|s_{out}/s_{in}|^2$ at resonance ($\Delta\omega = 0$) and at one linewidth off resonance ($\Delta\omega = 1/\tau_e$).

(c) The photon lifetime is $\tau_{ph} = 1/(1/\tau_e + 1/\tau_0)$. Compute $\tau_{ph}$ for the values above. What is the maximum processing speed in symbols/second if the memory time constant is $\tau_{ph}$?

**Exercise 17.4 — Speed and Power Comparison**

A task requires processing $10^9$ input symbols per second.

(a) A GPU-based ESN (N=1000) can run at $5 \times 10^5$ symbols/second. How many GPUs are needed for the task? At 250 W per GPU, what is the total power?

(b) An optoelectronic single-node reservoir (N=100) runs at $10^7$ symbols/second. Can it handle the task? What speed improvement factor is needed?

(c) A silicon photonic chip (N=16, carrier-lifetime limited) runs at $2 \times 10^9$ symbols/second. Can it handle the task? What is its power consumption if each ring resonator consumes 1 µW?

(d) Discuss: if the silicon photonic chip is $16\times$ smaller reservoir than the GPU-based ESN, is the speed advantage worth the accuracy loss?

**Exercise 17.5 — TPA Nonlinearity**

The silicon ring resonator field equation with TPA (simplified):

$$\frac{da}{dt} = \left(-\frac{1}{\tau_{ph}} + i\omega_0\right)a - \frac{\alpha_{TPA}|a|^2}{2} a + \kappa s_{in}$$

where $\alpha_{TPA}$ is the TPA coefficient.

(a) For the linearized system (TPA $\approx 0$), the ring's response is linear. At what input power level does the TPA term become comparable to the loss term $1/\tau_{ph}$?

(b) Show that the TPA term creates a power-dependent resonance shift. Is this a true nonlinearity in the sense of Chapter 16 Condition 1?

(c) The free carriers generated by TPA have a recombination lifetime $\tau_c$. Write a simplified equation for the free carrier density $N_c$ and the resulting refractive index change $\Delta n = -\alpha_0 N_c$. How does this introduce temporal memory into the ring's response?

**Lab 17.1 — Simulating the Optoelectronic Reservoir**

*Objective:* Simulate the Appeltant et al. 2011 system and reproduce the NARMA-10 result.

```python
import numpy as np

def ikeda_dde_discrete(u_seq, N, beta, gamma, phi0=np.pi/4, seed=42):
    """
    Discrete-time simulation of the Ikeda delay-feedback reservoir.
    Time step = theta = tau / N.
    Uses the discrete approximation: x_k = f(beta * x_{k-1} + gamma * m_k * u)
    
    Returns states: (T, N)
    """
    rng = np.random.default_rng(seed)
    T = len(u_seq)
    mask = rng.choice([-1.0, 1.0], size=N)
    
    states = np.zeros((T, N))
    x_prev = np.zeros(N)
    
    for t in range(T):
        x_curr = np.zeros(N)
        for k in range(N):
            x_lag = x_prev[N-1] if k == 0 else x_curr[k-1]
            v = beta * x_lag + gamma * mask[k] * u_seq[t]
            x_curr[k] = np.sin(v + phi0)**2
        states[t] = x_curr
        x_prev = x_curr.copy()
    
    return states, mask

def narma10(T, seed=42):
    rng = np.random.default_rng(seed)
    u = rng.uniform(0, 0.5, T)
    y = np.zeros(T)
    for t in range(10, T):
        y[t] = 0.3*y[t-1] + 0.05*y[t-1]*np.sum(y[t-10:t]) + 1.5*u[t-10]*u[t-1] + 0.1
    return u, y
```

```python
import numpy as np

def silicon_ring_step(a, s_in, tau_ph, tau_c, kappa, alpha_tpa, dt=1e-12):
    """
    Euler integration of coupled mode + TPA + free carrier equations.
    a: complex field amplitude in ring
    s_in: complex input field amplitude
    tau_ph: photon lifetime (s)
    tau_c: carrier lifetime (s)
    Returns updated a.
    """
    # Free carrier density (simplified single-rate equation)
    N_c_update = alpha_tpa * np.abs(a)**4 / (2 * 1.054e-34 * 1.93e14) - 1/tau_c
    # (simplified: ignore exact normalization)
    
    # Ring field update (linear + TPA loss)
    da = (-1/tau_ph - alpha_tpa * np.abs(a)**2 / 2) * a + kappa * s_in
    a_new = a + dt * da
    return a_new
```

**Lab 17.3 — Delay-Feedback Memory Curve**

*Objective:* Measure the memory capacity of the Ikeda delay-feedback system as a function of feedback gain.

```python
# Memory capacity: for each delay k, train a readout to predict u[t-k] from x[t].
# Memory capacity = sum_k R^2_k (coefficient of determination at each delay)

def memory_capacity(states, u_seq, max_delay=50, reg=1e-4):
    """
    Compute memory capacity of reservoir with states (T, N) driven by input u (T,).
    """
    T = states.shape[0]
    mc_per_delay = []
    for d in range(1, max_delay+1):
        if d >= T:
            break
        X = states[d:]
        y = u_seq[:T-d]
        w = np.linalg.solve(X.T @ X + reg*np.eye(X.shape[1]), X.T @ y)
        y_pred = X @ w
        ss_res = np.sum((y - y_pred)**2)
        ss_tot = np.sum((y - np.mean(y))**2)
        r2 = 1 - ss_res/ss_tot
        mc_per_delay.append(max(r2, 0))
    return mc_per_delay, sum(mc_per_delay)
```

**Thought Experiment 17.B — The Bandwidth-Memory Tradeoff**

The carrier lifetime in silicon sets the memory time constant to $\sim 0.5$ ns. The photon lifetime sets the processing speed to $\sim 10$ GHz.

(a) The memory is $\sim 1$ carrier lifetime. For tasks requiring memory of 10 time steps at 10 GHz, what carrier lifetime would be needed?

(b) Reducing the carrier lifetime (e.g., by ion implantation damage) reduces memory but increases speed. Design a hybrid system that combines a fast passive chip (short memory, high speed) with a slower active feedback loop (long memory) to get both.
