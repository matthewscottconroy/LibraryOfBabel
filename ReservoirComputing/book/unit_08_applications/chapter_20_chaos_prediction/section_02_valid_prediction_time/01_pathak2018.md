# 20.2.1 Valid Prediction Time: Definition and Pathak et al. 2018

## Precise Definition of Valid Prediction Time

The **valid prediction time** (VPT) quantifies how long a model can maintain accurate closed-loop (autonomous) predictions before its trajectory diverges from the true trajectory of the chaotic system.

**Setup.** Let $\mathbf{s}_t \in \mathbb{R}^n$ be the true state of the chaotic system and $\hat{\mathbf{s}}_t$ be the model's prediction, both starting from the same initial condition $\hat{\mathbf{s}}_0 = \mathbf{s}_0$. Let $\sigma_s = \text{std}(\mathbf{s})$ be the root-mean-square amplitude of the attractor (a characteristic scale).

**Definition (VPT).** The valid prediction time is:

$$T_{VPT} = \min\left\{t \geq 0 : \frac{\|\hat{\mathbf{s}}_t - \mathbf{s}_t\|}{\sigma_s} > \epsilon_{VPT}\right\}$$

where $\epsilon_{VPT}$ is a threshold, typically taken as $\epsilon_{VPT} = 0.4$ in the literature (following [Pathak2018]). This threshold is chosen so that any prediction with NRMSE $> 0.4$ is considered to have "lost the signal" — the prediction error is 40% of the attractor's amplitude.

**In Lyapunov units.** VPT is typically reported as $T_{VPT}^{Ly} = \lambda_1 T_{VPT}$ where $\lambda_1$ is the largest Lyapunov exponent. For the Lorenz system, $\lambda_1 \approx 0.906$ nats/second (or $\approx 0.023$ per integration step at $\Delta t = 0.025$). Multiplying by $\lambda_1$ normalizes out the system's natural timescale.

**Statistical averaging.** Because the VPT depends on the initial condition (some starting points on the attractor are harder to predict than others), results are always averaged over many initial conditions:

$$\langle T_{VPT}^{Ly} \rangle = \frac{1}{K}\sum_{k=1}^K T_{VPT}^{Ly}(k)$$

Pathak et al. [Pathak2018] average over $K = 50$–$100$ initial conditions randomly sampled from the attractor.

## Pathak et al. 2018: Key Results

Pathak, Hunt, Girvan, Lu, and Ott [Pathak2018] published two related papers: the 2017 *Chaos* paper on the Lorenz system [Pathak2017] and the 2018 *Physical Review Letters* paper on the Kuramoto-Sivashinsky equation. We focus on the PRL paper here, as it is the more significant result.

**The Kuramoto-Sivashinsky (KS) equation.** The KS equation:

$$\partial_t u + u\partial_x u + \partial_{xx} u + \partial_{xxxx} u = 0$$

is a model of spatiotemporal chaos. On the periodic domain $[0, L]$ with $L = 22$ (the standard "turbulent" parameter), the solution $u(x, t)$ exhibits spatiotemporally chaotic behavior with approximately 10 positive Lyapunov exponents and an attractor dimension $d_A \approx 30$–$40$. Discretizing on $N_{spatial} = 64$ spatial grid points gives a 64-dimensional ODE system.

The task is to predict the evolution of this system over the test set, given a training set of past observations.

**Reservoir computer setup (Pathak et al.):**
- Reservoir size: $N = 2400$ neurons
- Input: all 64 spatial grid points $u(x_k, t)$ at each time step
- Input coupling: sparse random $W^{in}$ (average degree 3)
- Recurrent: sparse random $W^{rec}$ (average degree 3, spectral radius $\rho = 0.6$)
- Leaking rate: $\alpha = 1$ (no leaky integration; standard discrete update)
- Training: $T_{train} = 100000$ steps (approximately 250 Lyapunov times)
- Test evaluation: $K = 50$ initial conditions, each run for $T_{test} = 1000$ steps

**Results:**
- Mean VPT: $\langle T_{VPT}^{Ly} \rangle \approx 8$ Lyapunov times on KS equation
- Comparison with prior methods: the best Gaussian process regression method achieved $\approx 2$–$3$ Lyapunov times; linear autoregression $\approx 1$ Lyapunov time; persistence model (predict tomorrow = today) $\approx 0.5$ Lyapunov times
- **Key result:** RC outperforms all prior model-free methods by a factor of 3–4 in VPT

**Lorenz system results [Pathak2017]:**
- $N = 500$ neurons, Lorenz observable $\mathbf{u}_t = [x_t, y_t, z_t]$
- Mean VPT: $\approx 5$–$6$ Lyapunov times
- Comparison: auto-regressive models $\approx 1.5$ Lyapunov times; Gaussian process $\approx 2$ Lyapunov times

## Why Does Reservoir Computing Achieve These Results?

Three factors contribute:

**1. Attractor reconstruction.** By Takens' theorem, the reservoir state provides a generalized embedding of the true attractor. The closed-loop RC model effectively learns the dynamics on this reconstructed attractor, which is topologically equivalent to the true attractor. This gives the model access to the full phase space structure, including all the folding and stretching that makes the dynamics chaotic.

**2. Nonlinear state space.** Unlike a linear model (ARIMA) or a kernel with a fixed basis (Gaussian process), the reservoir's nonlinear state provides a flexible function space that can represent the chaotic flow. The tanh activations produce the mixing necessary to approximate the Lorenz or KS flow.

**3. High-dimensional readout.** With $N = 500$–$2400$ neurons, the reservoir provides a high-dimensional feature vector. The linear readout over this high-dimensional feature vector can approximate the (nonlinear, high-dimensional) state transition map with low error, limited primarily by the training set size and regularization.

## Estimating Lyapunov Exponents from RC Models

A reservoir model trained to predict a chaotic system can be used to estimate the system's Lyapunov exponents. The procedure:

1. Train the RC model on the target system's attractor.
2. Run the trained model in closed-loop mode from an initial condition $\mathbf{x}_0$.
3. Simultaneously, run a slightly perturbed copy $\mathbf{x}_0 + \delta\mathbf{x}_0$ where $\|\delta\mathbf{x}_0\| = \epsilon_0 \ll 1$.
4. Track the growth of the perturbation $\|\delta\mathbf{x}_t\|$. Periodically renormalize to prevent overflow.
5. The largest Lyapunov exponent is: $\hat{\lambda}_1 = \lim_{T \to \infty} \frac{1}{T}\sum_{t} \ln\frac{\|\delta\mathbf{x}_{t+1}\|}{\|\delta\mathbf{x}_t\|}$ (before renormalization).

For the full Lyapunov spectrum, repeat with multiple orthogonal perturbations and use the QR decomposition method (Benettin et al.).

Pathak et al. [Pathak2018] validate this approach and show that the RC model's estimated Lyapunov spectrum agrees well with the true KS equation spectrum — confirming that the model has genuinely captured the attractor's dynamic structure.
