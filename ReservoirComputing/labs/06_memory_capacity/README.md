**Corresponds to:** Chapter 8 — Memory Capacity: How Much Can a Reservoir Remember? (Unit 3)

**Prerequisites:** Chapter 5 (ESN basics), Chapter 6 (echo state property), linear algebra (ridge regression), basic statistics (R²)

**Learning Objectives:**
- Measure the per-delay memory profile MC_k = R²_k and visualise how it decays with increasing delay
- Verify the Jaeger bound: total MC = Σ_k MC_k ≤ N empirically
- Understand that a linear reservoir driven by white noise achieves MC = N exactly, while nonlinearity trades linear memory for nonlinear computation
- Compare memory profiles for different spectral radii and interpret the geometric vs. slow-decay tradeoff
- Explore the Simple Cycle Reservoir (SCR) architecture and its structured memory distribution
