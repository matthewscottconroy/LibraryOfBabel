**Corresponds to:** Chapter 13 — Conceptors: Soft Projections and Multi-Pattern Memory (Unit 4)

**Prerequisites:** Chapter 5 (ESN basics), Chapter 12 (FORCE learning), linear algebra (eigendecomposition, PSD matrices), Chapter 8 (memory capacity)

**Learning Objectives:**
- Understand conceptors as soft projections onto the subspace spanned by reservoir states during a particular pattern: C = R(R + α⁻²I)⁻¹
- Compute the conceptor C from the state correlation matrix R and understand the aperture parameter α
- Apply conceptors during autonomous recall to lock the reservoir to a specific attractor
- Implement Boolean operations (NOT, OR, AND) on conceptors and interpret them geometrically
- Store multiple patterns in a single reservoir using conceptor interference management
