**Corresponds to:** Chapter 16 — Physical Reservoir Computing: One Node to Rule Them All (Unit 7)

**Prerequisites:** Chapter 5 (ESN basics), delay differential equations (conceptual), Chapter 9 (NARMA-10 benchmark)

**Learning Objectives:**
- Understand how a single time-delayed nonlinear node can emulate an N-neuron reservoir by multiplexing inputs in time (virtual nodes)
- Simulate the optoelectronic delay-feedback system of Appeltant et al. (2011) in software
- Understand the role of the feedback gain η: insufficient feedback gives poor memory; excessive feedback causes instability
- Compare the delay reservoir to a standard random-matrix ESN on NARMA-10 at equivalent N
- Explore how the number of virtual nodes N affects performance and understand the tradeoff with processing speed
