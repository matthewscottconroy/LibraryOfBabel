**Corresponds to:** Chapter 20 — Predicting Chaos: From Lorenz to the Kuramoto-Sivashinsky Equation (Unit 8)

**Prerequisites:** Chapter 5-9 (core ESN), Lorenz system (Lab 02), Lyapunov exponents (Chapter 2), Valid Prediction Time definition

**Learning Objectives:**
- Apply an ESN to full-state Lorenz prediction and measure Valid Prediction Time (VPT) in Lyapunov times
- Implement closed-loop (autonomous) prediction and understand why it is harder than open-loop
- Reconstruct the Lorenz attractor from predictions and compare correlation dimension D₂ with the true value ≈ 2.05
- Explore partial observation: predict from x(t) only using delay embedding (Takens' theorem)
- Reproduce the Pathak et al. (2018) benchmark: ~5-6 Lyapunov times VPT with N=500
