# Problems

This directory contains exercises, assignments, and challenges organized by chapter.
Each chapter folder contains:

- Conceptual exercises (multiple choice, short answer)
- Translation exercises (English ↔ FOL)
- Proof assignments (state and prove)
- Partial proof files (fill in the `sorry` / `admit` gaps)
- Challenges (harder, open-ended problems)

## Difficulty Guide
- ★: straightforward application of definitions
- ★★: requires combining 2-3 concepts
- ★★★: challenging; may require creativity
- ★★★★: research-adjacent or advanced
