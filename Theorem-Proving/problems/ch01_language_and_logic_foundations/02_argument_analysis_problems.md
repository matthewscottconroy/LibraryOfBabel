# Argument Analysis Problems

## Section 1: Identifying Arguments (★)

**1.** Identify the premises and conclusion of each argument:
  a. "Since all mammals are warm-blooded, and whales are mammals, whales are warm-blooded."
  b. "You should eat less sugar. Sugar causes tooth decay and obesity. You want to be healthy."
  c. "God exists. The universe must have a cause. God is the uncaused cause."

**2.** Rewrite each argument from Q1 in standard form (P1, P2, ... ∴ C).

## Section 2: Validity and Soundness (★★)

**3.** For each argument, determine whether it is valid, invalid, sound, or unsound.
Justify your answer. (Remember: an invalid argument cannot be sound.)
  a. P1: All cats are reptiles. P2: All reptiles are cold-blooded. ∴ All cats are cold-blooded.
  b. P1: If it rains, the ground is wet. P2: The ground is wet. ∴ It is raining.
  c. P1: All bachelors are unmarried. P2: John is a bachelor. ∴ John is unmarried.
  d. P1: Some birds can't fly. P2: Tweety is a bird. ∴ Tweety can't fly.

**4.** Construct a counterexample to show argument (b) from Q3 is invalid.

## Section 3: Formalizing Arguments (★★)

**5.** Formalize each argument in propositional logic. Determine if the argument form is valid
using a truth table.
  a. "If the program compiles, it has no syntax errors. The program compiles. So it has no syntax errors."
  b. "Either Alice is home or Bob is home. Alice is not home. Therefore Bob is home."
  c. "If you study hard, you will pass. You will pass only if you studied or got lucky. You did not get lucky. Therefore you studied hard." [Is this valid?]

## Section 4: Proofs and Persuasion (★★★)

**6.** A classmate argues: "I know my program is correct because I tested it on 1000 random
inputs and it gave the right answer each time." Is this a proof? Is it convincing?
What would a proof of correctness require?

**7.** Find a historical example of a "proof" that turned out to be wrong. What was the error?
What does this tell us about the need for formal proof?

**8. Challenge (★★★)**: Can a valid argument prove a false conclusion? Under what conditions?
What does this imply about the relationship between validity and truth?
