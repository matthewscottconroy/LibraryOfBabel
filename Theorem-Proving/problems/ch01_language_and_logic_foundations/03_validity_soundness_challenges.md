# Validity and Soundness Challenges

## Formal Fallacy Identification (★)

**1.** Identify which formal fallacy each argument commits:
  a. "If P, then Q. Q. Therefore P." (name the fallacy)
  b. "If it rains, I'll bring an umbrella. It didn't rain. So I didn't bring an umbrella."
  c. "All P are M. All Q are M. Therefore all P are Q."

**2.** For each fallacy in Q1, provide a specific substitution that makes all premises true
but the conclusion false (a counterexample).

## Informal Fallacy Analysis (★★)

**3.** Identify the informal fallacy in each:
  a. "We shouldn't listen to Einstein's views on quantum mechanics — he was famously bad at
     accepting it." (Is this fully an ad hominem? Analyze carefully.)
  b. "Either you support this policy completely or you want the country to fail."
  c. "The ancient Greeks believed the Earth was round, so it must be true."

**4. Nuanced case**: "We should not trust this politician's economic proposals because she
has been convicted of tax fraud." Is this ad hominem? When does a person's character become
logically relevant to their claims?

## Constructing Counterexamples (★★)

**5.** For each invalid argument form, exhibit an instance where the premises are true and
the conclusion is false:
  a. P → Q, Q → P ∴ P ↔ Q
  b. ∀x P(x) ∴ ∃x P(x)  [Note: is this actually valid? Under which logical conditions?]
  c. ∃x P(x), ∃x Q(x) ∴ ∃x (P(x) ∧ Q(x))

## Open-Ended Challenges (★★★)

**6.** Design an argument that is:
  - Valid with false premises and a true conclusion
  - Invalid with true premises and a true conclusion
  - Sound (must be valid with true premises)

**7.** Is the following argument valid?
P1: If this argument is valid, then 2+2=5.
P2: 2+2 ≠ 5.
∴  This argument is invalid.
(Carefully analyze the self-reference.)
