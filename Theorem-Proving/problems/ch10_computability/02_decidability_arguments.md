# Decidability and Undecidability

## Section 1: Decidable Problems (★)

**1.** For each problem, state whether it is decidable. If decidable, give an algorithm:
  a. Given a propositional formula φ, is φ a tautology?
  b. Given n, is n prime?
  c. Given a DFA and a string w, does the DFA accept w?
  d. Given a context-free grammar and a string w, is w generated by the grammar?
  e. Given two regular expressions, do they define the same language?

## Section 2: Reductions (★★)

**2.** Prove that the following problem is undecidable by reducing HALT to it:
  "Does program P ever print the character 'X'?"

  (Hint: Given (M, w) for the halting problem, construct a program P that runs M on w
   and if M halts, prints 'X'. Show that deciding your problem solves HALT.)

**3.** Show that the Emptiness problem for Turing machines is undecidable:
  E_TM = {⟨M⟩ | L(M) = ∅}

## Section 3: Rice's Theorem (★★)

**4.** Apply Rice's theorem to determine which of the following properties are decidable:
  a. "M accepts the empty string"
  b. "M is a Turing machine" (the set of valid TM encodings)
  c. "M accepts all strings over {0,1}"
  d. "M has fewer than 100 states"
  e. "M accepts at least one string of length 5"

## Section 4: Gödel Incompleteness (★★★)

**5.** Gödel's first incompleteness theorem implies there are true statements about
natural numbers that cannot be proved in PA (Peano Arithmetic).

  a. Does this mean PA is useless? What *can* PA prove?
  b. Can we extend PA with new axioms to make it complete? What does Gödel's theorem
     say about any such extension?
  c. The Gödel sentence G says "G is not provable in PA." If PA is consistent, is G
     true? Can you prove G is true? In what system?

**6. Challenge**: Look up the statement of Goodstein's theorem. It is:
  - True (provable in ZFC)
  - Unprovable in PA (by Kirby and Paris, 1982)

  Explain informally why this is a "natural" mathematical statement that PA cannot prove.
