# Modus Ponens

**Statement**: P, P→Q ⊢ Q

Modus Ponens ("mode of putting") is the fundamental rule of inference.
It is valid in every logic and is the simplest non-trivial argument form.

## Files
- `paper_proof.md`: natural deduction proof tree
- `lean_proof.lean`: term-mode and tactic Lean 4 proof
- `coq_proof.v`: Coq proof
- `python_check.py`: truth-table verification
