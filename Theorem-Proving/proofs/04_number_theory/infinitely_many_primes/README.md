# There Are Infinitely Many Primes

**Statement**: The set of prime numbers is infinite.

This is one of the oldest theorems in mathematics (Euclid's *Elements*, Book IX, Prop. 20, ~300 BCE).
It has many elegant proofs; Euclid's original is a proof by contradiction.

## Files
- `paper_proof.md`: Euclid's proof + Euler's product formula proof
- `lean_proof.lean`: Lean 4 formalization
- `coq_proof.v`: Coq formalization
- `python_verify.py`: computational exploration
