# Well-Formed Formulas

## Overview
Not every string of symbols is a formula. A **well-formed formula (wff)** is one
generated by the grammar of propositional logic. Knowing what counts as a wff is
the first syntactic competence required.

## Learning Objectives
- Determine whether a given string is a wff
- Parse a wff into its tree structure
- Identify the main connective of a wff

## Parse Trees
Every wff has a unique parse tree (due to the unambiguous grammar).
The **main connective** is the root of the parse tree — the last connective applied.

Example: (p ∧ q) → (q ∨ r)
- Main connective: →
- Left subtree: p ∧ q (main connective: ∧)
- Right subtree: q ∨ r (main connective: ∨)

## Unique Readability Theorem
Every wff has a unique parse tree. This is proved by induction on formula complexity.
It ensures that truth tables are well-defined (each formula has exactly one evaluation).

## Haskell: Representing Formulas
```haskell
module Formula where

data Formula
  = Atom String
  | Top | Bot
  | Not Formula
  | And Formula Formula
  | Or  Formula Formula
  | Imp Formula Formula
  | Iff Formula Formula
  deriving (Eq, Show)

-- example
exampleFml :: Formula
exampleFml = Imp (And (Atom "p") (Atom "q")) (Or (Atom "q") (Atom "r"))
```
