# Appendices

```{=latex}
\appendix
```

Five references, none of which teaches a new idea.

The book proper is an argument, read in order. These are not. They collect the
practical material that the argument kept deferring — how to get a program
compiled, how to run a test, how to write a comment worth reading, how to keep a
history of your work, and what the syntax was again.

Appendix A is worth reading before Chapter 5, or at the point where `javac` first
refuses to do what you expected. The rest are for looking things up.

None of them assumes a chapter you have not reached, except where a reference is
marked with the chapter that explains it.
