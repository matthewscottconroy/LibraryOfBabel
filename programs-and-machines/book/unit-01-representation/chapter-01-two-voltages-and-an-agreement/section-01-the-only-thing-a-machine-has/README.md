# The Only Thing a Machine Has

Three short lessons, all circling one fact: a machine holds voltage, and nothing
else.

We start with the physical situation and what it means to read a value off a
wire. Then we sharpen "bit" from a vague noun into something precise — one
resolved yes-or-no — and find that the way bits combine is a counting fact rather
than an electrical one. Then we take seriously the question you have probably
already asked: if we count in tens, why does the machine not?

That last question has a real answer, and people built the alternatives before
settling it.
