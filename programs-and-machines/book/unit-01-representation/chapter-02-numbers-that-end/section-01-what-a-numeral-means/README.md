# What a Numeral Means

You have been reading numerals fluently for so long that the rule doing the work
has gone invisible. These three lessons make it visible again.

First, positional notation in general — the idea that a digit's value depends on
where it sits, which is what makes arithmetic something a machine can do at all.
Then the same rule with the base set to two, which is binary and which will stop
feeling strange after about the fifteenth conversion. Then hexadecimal, which
exists because thirty-two binary digits in a row defeat human eyes, and which is
better understood as compressed binary than as a number system of its own.

Have a pencil. This section is the one place in the book where drilling is the
right approach, and it is over quickly.
