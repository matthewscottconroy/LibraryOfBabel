# Arithmetic in a Box

Now we make the numbers do something, inside a box of fixed size.

The first lesson adds two binary numbers using the same column-by-column
procedure you learned as a child, and follows the carry to the point where it
runs off the left-hand end and has nowhere to go. That moment is the whole
chapter in miniature.

The second lesson asks how to represent a negative number when every pattern is
already spoken for, rejects the answer everyone invents first, and arrives at
two's complement — which is elegant enough that it is worth slowing down for. The
third takes the consequence honestly: some sums have no representable answer, and
something has to happen anyway.

By the end, `2147483647 + 1 == -2147483648` should read as inevitable rather than
strange.
