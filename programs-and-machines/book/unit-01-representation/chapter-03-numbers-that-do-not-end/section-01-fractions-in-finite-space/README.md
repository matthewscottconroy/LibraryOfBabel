# Fractions in Finite Space

Two lessons, and the first is entirely about arithmetic you already do.

We start by asking what the digits after a decimal point actually mean, and then
run the same rule in base two. That gets us binary fractions, and immediately a
question: which fractions can be written exactly with finitely many digits? You
know the decimal answer without having phrased it — one half is fine, one third
is not — and the reason generalizes to any base in a way that explains the whole
chapter.

The second lesson introduces the format itself. Floating point is scientific
notation with a fixed budget, and once you see it that way the peculiar decisions
in it stop looking arbitrary.
