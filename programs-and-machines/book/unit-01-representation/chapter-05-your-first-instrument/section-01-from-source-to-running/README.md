# From Source to Running

You type text into a file. Some seconds later a machine that only holds voltages
is doing what the text described. Three lessons on what happens in between.

The first is about compilation — what the compiler reads, what it produces, and
what it refuses. The second is about the Java Virtual Machine, which is the
unusual part of Java's arrangement and the reason the same file runs unchanged on
machines with entirely different processors. The third is the program itself,
line by line, with an honest account of which parts are being deferred.
