# Looking at the Bits

Three lessons that turn Java into the microscope this chapter promised.

First, output — how to get a program to tell you things, and the formatting
tools that make the telling legible. Then the primitive types, which are exactly
the fixed-width boxes of Chapters 2 and 3 with Java names attached, and which
should feel like meeting people you have already been told about.

Then we build the instrument: a program that takes a value and shows you its
bits, its hexadecimal form, and its decimal value side by side. Run it on the
examples from the last four chapters and every claim I made becomes something you
verified yourself.
