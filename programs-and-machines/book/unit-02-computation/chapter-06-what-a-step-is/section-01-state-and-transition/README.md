# State and Transition

Three lessons building the model.

First, what state is: the observation that a computation in progress has to hold
something beyond its data, and that this something is the thing that makes
"continue from here" meaningful. Then the step, treated as a function from state
to state — which is a small idea with large consequences, because a function is
something we can reason about.

Then we build a machine out of a table and watch it compute. It will be an
absurdly small machine. That is the point: if you can see the whole thing, you
can see that there is no magic in it.
