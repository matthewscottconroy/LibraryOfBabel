# Two Famous Machines

The parity machine could not count, because its memory was fixed. Give a machine
unbounded memory and everything changes. Two lessons on how that was done, and
one on where Java sits relative to both.

Turing's machine, from 1936, adds an infinite tape. It was invented not to
compute anything but to prove something *about* computation — the sharpest
possible definition of "mechanical procedure", constructed so that a claim about
all such procedures could be made. It remains the standard against which
computational power is measured.

The stored-program machine, described in 1945, is the practical one. Its central
idea is that instructions and data live in the same memory, which sounds like an
engineering convenience and is in fact the deepest idea in the book.
