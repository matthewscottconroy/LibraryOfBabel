# Naming a Value

Three lessons on the most-used construct in programming.

First, what a variable is: a named cell of state, in Chapter 6's exact sense, and
what it means for the machine to have one. Then the operator that catches every
beginner with a mathematical education — `=`, which is not equality and does not
claim anything. Then types, which we met in Unit I as agreements about bit
patterns, seen now from the other side: as promises the compiler holds you to.
