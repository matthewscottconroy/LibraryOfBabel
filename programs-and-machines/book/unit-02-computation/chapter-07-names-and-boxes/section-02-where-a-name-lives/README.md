# Where a Name Lives

Two lessons about the boundaries around a name.

Scope answers *where* a name is visible, and lifetime answers *how long* its cell
exists. They are related and not identical, and the difference matters once
objects arrive.

Then mutation: the fact that a variable's value can change. This is what
variables are *for*, and it is also the reason programs are hard to reason about,
and the tension between those two facts runs through the rest of the book.
