# The Logic Underneath

Three lessons that go from a table to a working adder.

First, truth tables: the complete specification of what a logical operator does,
which is possible only because there are finitely many inputs. Then gates, which
are those tables built out of Chapter 1's switches — and the moment where the
arithmetic of Chapter 2 turns out to be constructible from them.

Then boolean algebra, which is what lets you take a condition you have written
and transform it into a different condition you can prove means the same thing.
That is a practical skill and not merely a theoretical one; a great deal of
unreadable code is a readable condition badly stated.
