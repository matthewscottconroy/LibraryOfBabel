# Choice in a Program

Three lessons on Java's conditionals.

The first is `if` and `else`, which is Chapter 6's transition-table entry with
better notation. The second is short-circuit evaluation — the reason Java has two
sets of logical operators, and a mechanism you will rely on constantly once you
know it exists. The third is `switch`, which is what you write when the choice is
among many values rather than between two.
