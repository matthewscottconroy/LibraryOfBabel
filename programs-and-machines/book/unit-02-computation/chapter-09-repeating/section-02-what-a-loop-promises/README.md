# What a Loop Promises

This is the section the chapter exists for.

Three lessons. The **loop invariant** — a claim about the state that survives
every iteration — and how to use one to establish that a loop is correct for all
inputs rather than for the ones you tried. Then **termination**, which is a
separate obligation and is proved differently. Then off-by-one errors, treated
not as carelessness but as the specific failure of a boundary claim, which is
what makes them findable.

Take this section slowly. It is the first place in the book that asks you to
reason rather than to run, and the technique is worth more than any syntax in
this unit.
