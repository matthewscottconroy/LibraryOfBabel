# Generics and Iteration

A collection that holds anything is a collection you must inspect on the way out,
and that is how Java worked until 2004.

The angle brackets you have been typing since the last section are what replaced
that — a promise, checked by the compiler, about what is inside. This section is
what they mean, plus the loop that walks a collection and the one trap it has.

Three lessons.

Generics — the angle brackets — are a promise about what a collection contains,
checked by the compiler. Iteration is walking a collection, which has one trap
worth knowing about and one mechanism worth understanding. And then a short guide
to choosing, which pulls the chapter together.
