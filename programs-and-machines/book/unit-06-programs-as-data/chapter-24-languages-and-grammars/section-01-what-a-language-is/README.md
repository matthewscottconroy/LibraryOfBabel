# What a Language Is

You have written Java for eighteen chapters. Here is a question you have never had
to answer: what makes a piece of text *be* Java?

Not "what does the compiler accept" — that is a fact about one program. The
question is whether there is something the compiler is consulting, something
written down before any compiler existed, from which its behavior follows.

There is, and it is smaller than you would guess.

Three lessons, all definitions, all short.

A language as a set of strings — which sounds like a technicality and turns out
to be the definition everything else rests on. Then grammars, the finite
description of an infinite set. Then ambiguity, and how a grammar is repaired to
say what you meant about precedence.
