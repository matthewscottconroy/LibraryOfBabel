# Cost in Practice

The apparatus is built. Now it meets a real machine, which does not behave the way
the apparatus assumes.

Complexity analysis models a computer where every operation costs the same and all
memory is equally far away. No such computer exists, and this section is about
where the model pays off, where it misleads, and one measurement in it that
disagrees with its own prediction.

Three lessons.

Searching and sorting, which is where the classes stop being abstract and where
one genuine lower bound appears. Then space, which is a cost too and is more often
the binding constraint than people expect. Then measuring honestly — including a
measurement in this chapter that disagrees with this chapter's prediction, left in
rather than tidied away.
