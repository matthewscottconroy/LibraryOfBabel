# Descriptions

Chapter 33 measured information with probabilities, which requires knowing what was
likely. There is another way, and it needs no probabilities at all.

It asks a different question: how short is the shortest program that would print
this string? That is a property of the string itself rather than of any source —
which is cleaner, and turns out to be uncomputable for reasons closely related to
the halting problem.

Two lessons.

Kolmogorov complexity — the length of the shortest program that prints a string,
which is Chapter 33's information measure without probabilities, and which turns
out to be uncomputable for reasons related to Section 34.1. Then randomness
defined as incompressibility, which makes precise a word everyone uses loosely and
which closes both this chapter's arguments and Chapter 33's.
