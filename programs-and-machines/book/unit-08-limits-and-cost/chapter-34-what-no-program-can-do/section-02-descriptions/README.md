# Descriptions

Chapter 33 measured information with probabilities, which requires knowing what was
likely. There is another way, and it needs no probabilities at all.

It asks a different question: how short is the shortest program that would print
this string? That is a property of the string itself rather than of any source —
which is cleaner, and turns out to be uncomputable for reasons closely related to
the halting problem.

First, Kolmogorov complexity: the length of the shortest program that prints a
given string. It is the previous chapter's measure of information with the
probabilities taken away, and it is uncomputable — for reasons that will feel
familiar within about two paragraphs of meeting them.

Then a definition of **randomness** as incompressibility, which takes a word
everybody uses loosely and makes it exact. It closes the arguments of this chapter
and the last one at the same time, which is a satisfying thing for a definition to
do.
